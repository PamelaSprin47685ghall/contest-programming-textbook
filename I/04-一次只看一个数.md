# 04　一次只看一个数

运动会上，老师依次报出每次跳远的距离：132、145、139、145。你手里只有一张小纸片，不想抄下全部记录，可最后要说出最远的一次。要找最远的一次，需要记住什么？如果还要知道它出现几次呢？

这一章练的不是更多循环写法，而是：**每看一个新数，怎样改好手里的记录。**

## 暂时领先的答案

先看 132，把它记为“目前最远”。再看 145，比手里的 132 大，改成 145。接着是 139，比 145 小，不动。最后又读到 145，不比 145 大，也不动。答案就是 145。

“目前最远”不是猜的，而是**已经看过的那些数中的最大值**。每看完一个数，这句话都对；等全部数据看完，它就变成了最终最大值。每轮前后都能说清手里这个数是什么意思，程序就容易检查。

**停笔 1**　依次读到 −7、−12、−3。如果开始把“目前最大”设成 0，会得到什么错答案？为什么从第一条记录开始更合适？

扫一遍就能得到的结果，用不着把整排数据存下来：手里只要有一份“目前最好”，或者一对两端的最值，边看边改就够。下面两题都是这个形状。

**例题：寻找奶牛**　Bessie 躲在一片高草里，约翰趴在地上，只看见一串由 `(` 和 `)` 组成的括号，长度 N（1 到 50000）。Bessie 的后腿像一对相邻的左括号 `((`，前腿像一对相邻的右括号 `))`，所以她的位置是一对下标 x < y：x 处是 `((`，y 处是 `))`。要数一数一共有多少种可能位置。输入一行括号串，输出一个整数。样例输入 `)((()())())`，输出 4。

数位置的办法是：从左往右扫，手里记一个数 `left`，表示到目前为止已经出现过多少对 `((`。每遇到一对 `))`，它和之前出现过的每一对 `((` 都能组成一个位置，就把 `left` 加进答案。这样每对 `((` 只和它后面的 `))` 配对，正好满足 x < y。样例里两对 `((` 在第 2、3 位，后面有两对 `))`，2 × 2 = 4，正好对上。手里只维护“已见左腿对数”这一个数，扫完一遍答案就出来了。这是 USACO 2012 年 11 月 Bronze 组第一题，叫“寻找奶牛”。

**例题：正方形牧场**　约翰有两块长方形围栏牧场，想把它们合并成一块**正方形**牧场，要求正方形能完全盖住原来两块地的所有区域，边和 x 轴、y 轴平行，问面积至少多大。输入两行，每行四个整数 `x1 y1 x2 y2`（都在 0 到 10 之间），表示一块牧场的左下角和右上角。输出一个整数：最小正方形面积。样例输入：

```text
6 6 8 8
1 8 4 9
```

样例输出：

```text
49
```

两块地分别是 (6,6) 到 (8,8)、(1,8) 到 (4,9)。要盖住两块地，先看所有坐标的极值：最左 1、最下 6、最右 8、最上 9，这四个值框出一个能包住两块地的最小长方形。正方形必须同时盖住这个长方形的宽和高，所以边长取宽和高里较大的那个：宽 7、高 3，取 7，面积 7 × 7 = 49。宽和高里较大的一边，正方形无论如何都得盖住，所以不可能更小。手里维护的是四个极值，读完 8 个数就够，不用存整块地。这是 USACO 2016 年 12 月 Bronze 组第一题，叫“正方形牧场”。

## 最大值与出现次数一起维护

光记最大值还不够，有时还要记它出现几次。遇到更大的值，旧纪录的次数就没用了，改成 1；遇到相同的值，次数加 1；遇到更小的值，两个都不动。

**片段：**先读入 n 和第一个数（约定 1 ≤ n ≤ 10000，每个整数在 `int` 范围内），然后循环读后面的数：

```cpp
// 位于 main 内；best 已读入第一个数，times 已设为 1
for (int i = 1; i < n; ++i) {
    int value = 0;
    if (std::scanf("%d", &value) != 1) {
        return 1;
    }
    if (value > best) {
        best = value;
        times = 1;
    } else if (value == best) {
        ++times;
    }
}
std::printf("%d %d\n", best, times);
```

第一条记录已经在循环前读过，所以循环从 `i = 1` 开始，再读 n − 1 条。只读一个数时，循环一次也不执行，次数仍是 1。注意顺序：先判断、后更新，`value > best` 和 `value == best` 两个分支不会同时成立。

**停笔 2**　输入为 `5` 和 `8 8 5 10 10`。每次读完后，写下 `best` 与 `times`。若遇到新纪录时忘了把次数改成 1，最后会错成多少？

### 想查类型的边界怎么办

有时程序不是从第一条记录开始，想找一个“肯定比所有数据都小”的起点，可以用 `<limits>` 查类型范围。**查阅片段：**

```cpp
#include <limits>
std::numeric_limits<int>::lowest();
std::numeric_limits<int>::max();
```

前者是最小可表示值，后者是最大可表示值。对整数，`min()` 与 `lowest()` 相同；对 `double`，`min()` 却是最小的正的正规值，不是“最负的数”。要找最小值边界，用 `lowest()` 更不容易混淆。

边界值也是合法数据，不能随便把它当成“不存在”。空数据没有最大值，应另行说明“没有数据”，而不是输出一个类型边界假装是答案。

最大值不是唯一要维护的东西：出现次数、变化次数常常要和它一起照顾，而且要在更新时同时改好。

**例题：产奶量测量**　约翰有三头奶牛 Bessie、Elsie、Mildred，一开始每天各产 7 加仑奶。接下来的 100 天里，他会不定期记录一些变化，比如 `35 Bessie -2` 表示第 35 天 Bessie 的产奶量比上次少了 2。约翰在谷仓墙上挂出**当前产奶量最高**的奶牛照片，并列最高就都挂出来。问 100 天里他一共要**更换**多少次展示。输入第一行是记录条数 N，接下来 N 行每行是 `天 奶牛名 变化量`（天在 1 到 100，变化量非零，每头牛的产奶量始终在 0 到 1000 之间；记录不一定按时间顺序，同一天最多一条）。输出一个整数：更换次数。样例输入：

```text
4
7 Mildred +3
4 Elsie -1
9 Mildred -1
1 Bessie +2
```

样例输出：

```text
3
```

一开始三头牛都是 7。第 1 天 Bessie 变成 9，成为唯一最高，换一次；第 4 天 Elsie 降到 6，最高仍是 Bessie，不换；第 7 天 Mildred 升到最高，换一次；第 9 天 Mildred 降到和 Bessie 并列，又换一次，共 3 次。

这里“最高”不是一个数，而是一组牛：要判断换不换，得知道每天结束后**哪些牛并列最高**，和前一天挂的是不是同一组。做法是先把记录按天排好序，再按时间逐天处理：应用变化、找出当前最高产奶量、把所有达到这个值的牛放进新展示集合；新集合和旧集合不一样就计数加一。注意产奶量可能变成负数，找最大值时要从一个真实存在的值开始比较。这是 USACO 2017 年 12 月 Bronze 组第三题，叫“产奶量测量”。

## 第二个位置到底允许什么

“第二大”有两种常见意思。记录是 9、9、4，按从大到小排好后取第二个，得到 9；要求“比最大值小的最大值”，则是 4。先说明题意，代码才能有对错。

下面采用**允许相同数值占两个位置**的意思。已读过前两个数，并整理好 `first >= second` 后，每个新数这样处理：

**片段：**

```cpp
if (value > first) {
    second = first;
    first = value;
} else if (value > second) {
    second = value;
}
```

新数成为第一名时，要先把旧第一名放到第二名。如果先覆盖 `first`，旧值就丢了。

**片段：**输入 2 ≤ n ≤ 10000 及 n 个 `int`，输出排在前两个位置的数。开头先读前两个数并排好序：

```cpp
// 位于 main 内
int first = 0;
int second = 0;
if (std::scanf("%d%d", &first, &second) != 2) {
    return 1;
}
if (first < second) {
    std::swap(first, second);
}
// 之后从 i = 2 循环读入，按上面片段更新两名
```

**停笔 3**　对 6、2、8、8 逐步更新两名。若题目改成“两个不同的数值”，哪一步不应照原样处理？全部数都相同时，还存在第二个不同数值吗？

## 每轮拿走一点，问题就变小一点

整数 406 的最后一位是 `406 % 10`，去掉最后一位是 `406 / 10`。重复这两个动作，可以从右向左读出十进制各位。

**片段：**输入 0 到 1000000000 的整数，输出各位数字之和：

```cpp
// 位于 main 内；remaining 已读入并检查过范围
int sum = 0;
do {
    int digit = remaining % 10;
    sum += digit;
    remaining /= 10;
} while (remaining != 0);
std::printf("%d\n", sum);
```

这里用 `do-while`，让输入 0 也按一个数字处理一次。`remaining` 表示还没处理的部分，`sum` 表示已经处理的那些数字之和。每轮少掉一位，最终会停。

**停笔 4**　处理 406 时，按轮写出 `digit`、更新后的 `remaining` 和 `sum`。最后一位是 0 时，程序会不会误以为整件事已经做完？

重复更新不限于取数位。比如把待分发的 25 份材料每轮分走一半，剩下不足一半时也要写清规则。下面**片段**规定每轮留下整数商 `waiting / 2`：

```cpp
int waiting = 25;
while (waiting > 0) {
    std::printf("%d\n", waiting);
    int next = waiting / 2;
    waiting = next;
}
```

先根据旧状态算 `next`，再整体更新。若下一个状态依赖几个旧变量，别在旧值还没用完时就覆盖它。循环能否结束，要按自己的更新规则检查，不能只凭“总会越来越小吧”。

每轮拿走一点，问题就小一点。取一位数字、分成两半、沿一条线往返，都是这个形状：写清“这一轮做什么”和“什么时候停”，程序就不容易乱。下面四题都是按规则一步步模拟。

**例题：走失的奶牛**　约翰的奶牛 Bessie 走丢了，好在路是一条笔直的长路，Bessie 一定在路上某个位置。把路看成数轴，约翰在位置 x，Bessie 在位置 y（约翰不知道 y）。天黑看不见，约翰只能来回走动，直到碰到 Bessie。搜索办法是：先走到 x+1，转身走到 x−2，再走到 x+4，如此“之字形”来回，每一步离出发点的距离都翻一倍（1、2、4、8、……），方向左右交替。输入两个不同的整数 x 和 y（0 到 1000），输出约翰找到 Bessie 时走过的总距离。样例输入 `3 6`，输出 9。

从 3 出发，先向右走到 4（走了 1），再向左走到 1（走了 3），然后向右朝 7 走，中途到 6 就碰到了 Bessie（走了 5）。总距离 1 + 3 + 5 = 9。最后这一段不必走完，碰到就停。模拟时注意：每一段出发前约翰一定在起点 x 处（走完一段都会原路折返回来），所以这一段的目标是 `x + dir × step`，途中覆盖的区间是 `[min(x, target), max(x, target)]`。如果 y 落在这个区间里，这一段的实际花费是 |y − x|，加进答案就结束；否则完整走一个来回，花费 2 × step，然后步长翻倍、方向取反，继续下一段。步长每轮翻倍，循环最多十来次必然找到。这是 USACO 2017 年 3 月 Bronze 组第一题，叫“走失的奶牛”。

**例题：混合牛奶**　约翰有三只容积各不相同的桶，分别装有一定量的牛奶，按固定顺序连续倒 100 次：第 1 次桶 1 倒入桶 2，第 2 次桶 2 倒入桶 3，第 3 次桶 3 倒入桶 1，第 4 次又回到桶 1 倒入桶 2，如此循环。每次倒出尽可能多的牛奶，直到源桶变空或目标桶装满。输入三行，每行两个整数：桶的容量 c 与初始牛奶量 m（容量 1 到 10^9，奶量 0 到容量）。输出三行，分别是最终桶 1、桶 2、桶 3 的奶量。样例输入：

```text
10 3
11 4
12 5
```

样例输出：

```text
0
10
2
```

模拟的关键是写清“倒多少”：实际倒出的量是源桶剩余奶量与目标桶剩余空间的较小值，即 `min(milk[source], capacity[target] - milk[target])`，从源桶扣除、加进目标桶。第 step 步时，源桶编号是 step 对 3 取余，目标桶是下一个。固定循环 100 轮，每轮 O(1)，总共就是 100 步。这是 USACO 2018 年 12 月 Bronze 组第一题，叫“混合牛奶”。

**例题：拐杖糖盛宴**　约翰有 N 头奶牛（1 到 2×10^5），第 i 头身高 h_i，还有 M 根不同高度的拐杖糖（1 到 2×10^5）。拐杖糖竖直立在地面上，初始时位于高度区间 [0, C]。奶牛按编号 1 到 N 依次走上前：身高为 H 的牛能吃到 [0, H] 范围内还没被吃掉的糖段；吃掉长度 L 的糖后，自身身高立即增长 L。问吃完所有 M 根糖后每头牛的最终身高（用 64 位整数）。输入第一行 N 和 M，第二行 N 个身高，第三行 M 根糖的初始高度。输出 N 行，每行一头牛的最终身高。样例输入：

```text
3 2
3 2 5
6 1
```

样例输出：

```text
7
2
7
```

对每根糖只记一个数：当前已被吃到的高度上限 `eatenUpTo`（初始 0）。牛走上前时，如果身高大于 `eatenUpTo`，就能吃到 `[eatenUpTo, min(h_i, C)]` 这一段，吃到的长度是 `min(h_i, C) - eatenUpTo`；牛的身高加上这个长度，糖的下边缘也上升这么多。当 `eatenUpTo` 等于 C 时整根糖吃完，这一轮提前结束。样例里第一根糖高 6：牛 1 身高 3，吃到 [0, 3] 共 3，变 6，糖还剩 [3, 6]；牛 2 身高 2，够不着；牛 3 身高 5，吃到 [3, 5] 共 2，变 7，糖还剩 [5, 6]。第二根糖高 1：牛 1 现在身高 6，一口吃完，变 7；牛 2、牛 3 再上前已没有糖可吃。三头牛最终是 7、2、7，正好对上。因为每次成功吃糖都会让牛的身高增长，一根糖很快被吃完，整题扫一遍就够。这是 USACO 2023 年 12 月 Bronze 组第一题，叫“拐杖糖盛宴”。

**例题：炮弹**　数轴上有 N 个位置（编号 1 到 N，N 最大 10^5），贝茜被装在炮弹里在数轴上弹跳。初始位置 S、威力 1、方向向右。每个位置可能是：跳板（type=0），把方向取反并把威力增加 v；或者目标（type=1），若当前威力 ≥ 阻力 v 就被击碎（击碎后仍保留在原地，不消耗威力）。每次在当前格子触发事件后，贝茜沿当前方向前进当前威力的距离；飞出 [1, N] 范围运动就结束。问总共击碎了多少个不同的目标。输入第一行 N 和 S，接下来 N 行每行两个整数描述位置 i 的类型和属性值 v。输出一个整数。样例输入：

```text
5 2
0 1
1 1
1 2
0 1
1 1
```

样例输出：

```text
1
```

从位置 2 出发，位置 2 本身就是目标、阻力 1，威力 1 正好够，击碎（记 1 个），前进 1 到位置 3；位置 3 是目标、阻力 2，威力不够，前进 1 到位置 4；位置 4 是跳板，方向变左、威力变 2，向左 2 步回到位置 2；位置 2 已被击碎，不再计数，再向左 2 步飞出范围，结束。只击碎了一个目标。模拟时注意威力只会越变越大，一旦大了弹几步就飞出界；唯一可能反复震荡的情况是威力始终为 0 在两个位置之间来回。所以直接一步步模拟，设一个安全步数上限，越界或超步就跳出。这是 USACO 2024 年 1 月 Bronze 组第二题，叫“炮弹”。

这一章的动作合起来看：扫一遍时手里只维护一个或几个数，每轮按规则改好它们；遇到“每轮拿走一点”的题，写清这一轮做什么、什么时候停。能这样把“看一个数、改一个数”说清楚，就可以读下一章了。

## 核对

1. 会错报成 0。输入里没有 0，负数更新不掉它；从第一条记录开始，就不会凭空造出一个候选值。
2. 依次是 `(8,1)`、`(8,2)`、`(8,2)`、`(10,1)`、`(10,2)`。忘了重设次数，会把旧纪录的两次一起带过去，最后错成 3。
3. 前两条整理成 `(6,2)`，之后是 `(8,6)`、`(8,8)`。若要求两个不同的数值，第二个 8 不能放进第二名；全相同时没有第二个不同数值，要报告不存在。
4. 三轮分别是 `(6,40,6)`、`(0,4,6)`、`(4,0,10)`。判断的是剩余部分是否为 0，不是刚取出的数字是否为 0。
