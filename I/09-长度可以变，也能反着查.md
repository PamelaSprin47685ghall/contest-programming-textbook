# 09　长度可以变，也能反着查

数据存下以后，位置编号和长度还有几处容易踩错：长度会变，无符号减法会绕圈，边界要自己守。想回头找某个值出现过在哪，也不一定只能按输入顺序记。

## 长度可以变，但不是随便访问

**操作片段：**从空 `vector<int> v` 开始，依次执行下面每一句：

```cpp
v.emplace_back(6);
v.emplace_back(9);
v.pop_back();
v.resize(4);
v.resize(2);
v.clear();
```

`emplace_back` 在尾部添加一项；`pop_back` 删掉末项但不返回它；`resize` 改元素数量，增加的 `int` 元素补零，缩短就删去后面的元素；`clear` 删光全部元素。

用 `v.size()` 查元素数量，用 `v.empty()` 问是否为空。`v.back()` 访问最后一项，但空序列没有最后一项，不能调用它；空序列也不能 `pop_back()`。`v[i]` 和原生数组一样，要求下标有效。

**停笔 1**　每执行完上面一句，写出 `v` 的内容。哪一步之后不能调用 `back()`？最后两项“消失”和“变成零”是一回事吗？

### 长度减一，不一定会变成 −1

`size()` 返回无符号整数类型，常用名字是 `std::size_t`。无符号数没有负值：空序列的 `v.size() - 1` 不会是 −1，而会绕成一个很大的正数。

**有风险的片段：**这样写反向循环会踩坑——

```cpp
for (int i = v.size() - 1; i >= 0; --i) {
    std::printf("%d\n", v[i]);
}
```

问题在于“先做了无符号减法”。本书题目长度最多 1000、能放进 `int`，所以先转换、再减一：

```cpp
int length = static_cast<int>(v.size());
for (int i = length - 1; i >= 0; --i) {
    std::printf("%d\n", v[i]);
}
```

这是**替换片段**。若实际长度可能超过 `int` 范围，不能不检查就转换。只想看每一个元素、根本不需要下标时，后面会学更简单的范围 `for`。

`vector<bool>` 比较特殊，元素按位压缩，访问得到的也不是普通的 `bool&`，不能简单认定它一定更快或更慢。初学时要保存一排小标记，可以选 `vector<char>`：每项一个字节，0 表示否、1 表示是。

**停笔 2**　空 `vector` 下，`length` 是多少？`length - 1` 是多少？循环体会执行吗？为什么必须先转换再减一？

## 不只是按顺序记，也可以反着查

4 台设备各拿到一个储物柜，柜号恰好是 1 到 4 的一个排列。按设备顺序输入的柜号是 `3 1 4 2`。我们想按柜号知道是谁在用。

**片段：**读入柜号，把“柜号 → 设备”的对应关系存下来。

```cpp
// 位于 main 内；假设 n、柜号 locker、设备号 device 已按约定读入
std::vector<int> owner(n + 1);
owner[locker] = device;
```

题目保证柜号不重复，不是让程序解决多人抢同一个柜子的情况。这里故意多开一个位置：0 号不用，柜号可以直接当下标，所以长度是 `n + 1`，最大下标才到 `n`。存好之后，按柜号 1 到 n 依次输出 `owner[1]` 到 `owner[n]`，就是每个柜子的使用者。

数组表示的不是“输入的原样复印”，而是“每个柜子的使用者”。数据放在哪个位置，由以后要问的问题决定。

**停笔 3**　为示例画出 `owner[1]` 到 `owner[4]`。若少开一个位置，只写 `owner(n)`，哪个柜号会越界？

记下“上一次看到它在哪”，比每次从头找省事；需要按位置反着查时，就把这层对应关系整个翻过来。下面几道题都在这两种动作里打转。

### 品种相近

2013 年 3 月铜组第二题“品种相近”：N 头牛站成一排，每头牛有一个整数品种编号。同品种的两头牛如果位置差不超过 K，就说它们“拥挤”。问存在拥挤的一对牛中，最大的品种编号是多少。

输入第一行两个整数 N 和 K（1 ≤ N ≤ 50000，1 ≤ K < N），接下来 N 行每行一个品种编号（0 到 10^6）。输出一个整数；没有拥挤的一对就输出 −1。

样例输入：

```text
6 3
7
3
4
2
3
4
```

样例输出：

```text
4
```

品种 3 的两头牛位置差 3，拥挤；品种 4 的两头牛位置差 2，也拥挤。取大的，答案是 4。

从左往右扫，对每个品种只记**上一次出现的位置**。读到一头牛，如果这个品种之前出现过，就看当前位置减上次位置是否 ≤ K；是，就说明这对牛拥挤，用这个品种更新答案。然后无论是否拥挤，都把上次位置改成当前位置。

品种编号范围很大（到 10^6），不能按编号开一排格子，要另想办法记“每个品种的上次位置”——这正是后面章节要讲的按值查表。这里先抓住动作本身：只记上一次出现的位置，就能判断“相邻两次出现”够不够近；同品种只要有一对够近，必然有某对相邻出现也够近，所以不用记它全部的出现。

### 奶牛航线

“先出现 A，再出现 B”这种判断，也要在一排数据里反着找。2015 年 1 月铜组第一题“奶牛航线”：一家公司有 N 架飞机，每架沿一条固定航线飞，航线由两个或更多城市按顺序组成，不重复。选一条航线，可以在航线**任意**城市上机、在**靠后**的任意城市下机；每条航线有固定费用，用了任何一段都要付。贝茜想从城市 A 飞到城市 B，只用一条航线，问最少花多少钱。

输入第一行三个整数 A、B、N（1 ≤ N ≤ 500）。接下来每两条线描述一条航线：第一行是费用（1 到 1000）和城市数，第二行是按顺序列出的城市（1 到 10000）。输出最小费用；没有可行航线输出 −1。

样例输入：

```text
1 2 3
3 3
3 2 1
4 4
2 1 4 3
8 5
4 1 7 8 2
```

样例输出：

```text
8
```

第三条航线 4 1 7 8 2 里，1 在 2 前面，费用 8。虽然用两条航线能更便宜，但题目只许用一条。

做法：逐条检查航线，在它的城市序列里先找 A，再从 A 之后的位置找 B；找到了就说明可行，记下费用。所有可行航线里取最小，一条都没有输出 −1。这里存的是当前这条航线的城市序列——判断“A 在 B 之前”必须知道整条序列，不能只留一个“见过 A 没有”的记号。

### 奶牛为什么过马路

2017 年 2 月铜组第一题“奶牛为什么过马路”：约翰有 10 头奶牛，记录了一整天 N 次观察，每次是一头奶牛的编号和它当时在路的哪一边（0 或 1）。当同一头奶牛连续两次被观察到、所在侧不同，就算它过了一次马路。问总共确认过马路多少次。

输入第一行 N（1 到 100），接下来 N 行每行两个整数：编号（1 到 10）和位置（0 或 1）。输出一个整数。

样例输入：

```text
8
3 1
3 0
6 0
2 1
4 1
3 0
4 0
3 1
```

样例输出：

```text
3
```

奶牛 3 先 1 侧、后 0 侧、再回 1 侧，过了两次；奶牛 4 从 1 侧到 0 侧，过了一次。共 3 次。奶牛 2、6 各只出现一次，不算。

对每头牛只记它**最近一次**被看到在哪一侧。读到一条新记录：这头牛之前出现过、且上次侧和这次不同，计数加一；相同或第一次出现，都不算。然后用这次的位置更新它。奶牛只有 10 头，按编号开一排格子正好：每格存“最近一次在哪侧”，初值设成 −1 之类“还没出现”的记号，才能区分第一次出现和确实换了侧。这又是“只记上一次”，只是记的内容从位置换成了侧别。

### 奶牛洗牌

“反着查”还有一种用法：把对应关系整个翻过来。2017 年 12 月铜组第二题“奶牛洗牌”：N 头奶牛排成一排，一次洗牌用 N 个数描述：位置 i 上的奶牛走到位置 a_i，所有 a_i 互不相同。奶牛连续做三次洗牌。给出三次洗牌后的排列顺序（每头牛有一个 7 位 ID），推出三次洗牌**之前**的初始顺序。

输入第一行 N（1 ≤ N ≤ 100），第二行 N 个整数 a_1 到 a_N，第三行是三次洗牌后按位置排列的 N 个 ID。输出 N 行，每行一个 ID，表示初始顺序。

样例输入：

```text
5
1 3 4 5 2
1234567 2222222 3333333 4444444 5555555
```

样例输出：

```text
1234567
5555555
2222222
3333333
4444444
```

先弄清方向：一次洗牌把位置 i 的牛送到位置 a_i。初始在位置 i 的牛，三次后站在 a_{a_{a_i}}。题目给的是三次之后的位置，所以反过来：初始在位置 i 的牛，就是三次后站在位置 a_{a_{a_i}} 的那头。

做法：把 a 数组存下来（下标从 0 开始），对每个初始位置 i，沿数组连续跳三次得到最终位置，把那个位置上的 ID 输出。存下 a 数组，是为了能沿着它“跳”；跳的方向反过来，就得到洗牌前的顺序。这题的数组存的是“位置之间的对应关系”，不是数据本身。

### 贪睡牛排队

2019 年 1 月铜组第二题“贪睡牛排队”：N 头奶牛排成一队，每头牛贴着 1 到 N 的专属编号，构成一个排列。约翰每次取出队伍**最前面**的牛，插到后面任意位置（其他牛相对顺序不变）。问最少操作多少次，队伍能按编号 1 到 N 严格升序排好。

输入第一行 N（1 ≤ N ≤ 100），第二行是当前队伍从队首到队尾的编号。输出一个整数。

样例输入：

```text
4
1 2 4 3
```

样例输出：

```text
3
```

每次只能动最前面的牛。看末尾：如果末尾有一段连续升序（a_k < a_{k+1} < … < a_n），前面任何一头牛拿出来，都能恰好插进这段有序后缀的合适位置，让有序后缀长一格。反过来，后缀中间只要有一对倒序，那对相邻元素不拆散就永远排不好。所以最终不用动的，最多是原序列最长的一段连续升序后缀；它前面的牛每头都要动一次。答案就是 N 减最长升序后缀的长度。

样例里末尾的 3 后面没有数，最长升序后缀只有它自己，长度 1，答案 4 − 1 = 3。做法：从倒数第二位往前扫，数一数连续升序能走多远。这里存的是整支队伍；判断却从右往左做，跟上一章“奶牛慢跑”一个道理——存下整排，才能换个方向扫。

### 打印序列

最后一题把“存整排、反着查”用到嵌套的循环结构上。2025 年 2 月铜组第三题“打印序列”：有一种简单的循环编程语言，只支持循环打印语句，最多嵌套 K 层（1 ≤ K ≤ 3）。给出若干个目标正整数序列，判断每个序列能不能由嵌套深度不超过 K 层的程序打印出来。

输入第一行是测试用例数 T；每个用例第一行两个整数 N 和 K，第二行 N 个整数。每个用例输出一行 `YES` 或 `NO`。

样例输入：

```text
2
1 1
1
4 1
1 1 1 1
```

样例输出：

```text
YES
YES
```

看序列的分块结构：K = 1 时，程序只能重复单个字符，所以整个序列必须全是同一个数；K = 2 时，可以重复一个长度固定的周期模板，形如 (c_1, c_2, …, c_m) 循环；K = 3 时，最外层再套一层大循环，序列由若干个满足 K = 2 的块拼接而成。判断时先把相邻的相同数并成一块，再按周期检查各层循环。

样例两个用例 K 都是 1：`1` 和 `1 1 1 1` 都全是同一个数，所以都输出 YES。这题存下整条序列，是为了能来回比较“隔固定距离的两项是否相等”——周期的检查要反复回头取数，只留一个“当前值”根本不够。

## 核对

1. 依次为 `[6]`、`[6,9]`、`[6]`、`[6,0,0,0]`、`[6,0]`、`[]`。最后为空，不能取末项。缩短删掉了元素，不是把原位置保留为零。
2. 长度为 0，减一为 −1，循环体执行零次。转换放在后面，先发生的无符号减法就无法被撤销。
3. 依次为 2、4、1、3。柜号 `n` 会访问 `owner[n]`，长度为 `n` 时该位置不存在。

能分清“长度会变”和“下标要自己守”，再读下一章。下一章要存的不再是数字，而是一段文本——字符和字符串的存取规则，跟整数数组很不一样。
