# 11　把规则交给函数

走路时数了步数，还想知道用了多少秒。每步 3 秒，12 步就是 36 秒；一会儿又走了 7 步，又要算一遍 21 秒。同一道乘法写两次，第二次和第一次一样，却可能抄错。与其把规则抄来抄去，不如给它起个名字：告诉它步数，它交回秒数。以后两处都叫这个名字，规则只写一份。

## 先约定输入，再约定答案

**函数定义片段：**

```cpp
// 每步 seconds_per_step 秒，走 steps 步，返回总秒数
int walk_seconds(int steps, int seconds_per_step) {
    return steps * seconds_per_step;
}
```

`walk_seconds` 是函数名，括号里的两个 `int` 变量叫**参数**。调用 `walk_seconds(12, 3)` 时，第一个参数收到 12，第二个收到 3。最前面的 `int` 说明这个函数交回一个整数；`return` 把计算结果送回调用处。

定义放在这里，不代表程序一开始就执行它。程序从 `main` 开始，遇到调用才进入函数。编译器需要先见到函数，才能判断调用对不对，所以本书把完整定义写在所有调用之前。

调用处是这样用的：

```cpp
// 位于 main 内
int first = walk_seconds(12, 3);
int second = walk_seconds(7, 3);
std::printf("%d %d\n", first, second);
```

每个参数都要写自己的类型：`int steps, int seconds_per_step`，不能偷懒写成 `int steps, seconds_per_step`。调用时参数的数目和顺序要符合约定，类型要匹配，或者能作允许的转换。允许转换不等于没有损失：把小数时间塞给整数参数，小数部分就丢了，不能随便这么干。

这个函数约定两个输入都在 0 到 1000 之间，乘积放得进 `int`。换了数据范围，要重新检查这一点，函数自己不会替你查。

## 一旦交回答案，这次调用就结束

**函数定义片段：**

```cpp
// 容量 capacity，已用 used，返回剩余空间；已满或超出按 0 算
int remaining_space(int capacity, int used) {
    if (used >= capacity) {
        return 0;
    }
    return capacity - used;
}
```

这个函数约定 `capacity`、`used` 都是非负数。空间已满或已经超出容量时，剩余量按零算。注意第一个 `return` 一旦执行，本次调用立即结束，不会再往下执行——不会先返回 0，再“继续”返回 `capacity - used`。

如果函数只做动作、不交回数值，返回类型写成 `void`：

**函数定义片段：**

```cpp
// 只做动作、不交回数值的函数
void print_separator() {
    std::printf("---\n");
}
```

调用时写 `print_separator();`。`void` 函数里可以用不带值的 `return;` 提前结束，也可以直接走到末尾。需要交回整数的函数，则要让每一条可能走到的路径都交回答案，不能漏掉一边。

## 传进去的通常是一份副本

**函数定义片段：**

```cpp
void add_one(int value) {
    ++value;
    std::printf("inside: %d\n", value);
}
```

**调用片段：**

```cpp
// 位于 main 内
int points = 8;
add_one(points);
std::printf("outside: %d\n", points);
```

第一行输出 `inside: 9`，第二行却是 `outside: 8`。`value` 是参数自己的副本，改它不会自动改调用者的 `points`。这叫**值传递**。它很有用：一个只需要数值的函数，不该顺手改变外面的数。

若确实要改原变量，就在参数类型后写 `&`，表示**引用**：

**替换片段：**

```cpp
// 替换上一段的 add_one 函数定义
void add_one(int& value) {
    ++value;
    std::printf("inside: %d\n", value);
}
```

换成这一版，两行输出才分别是 `inside: 9`、`outside: 9`。这里的 `&` 不是“取地址”，是参数声明里的“引用”。同一个符号放在不同位置，可以有不同用途。

## 引用是别名，不是第二份数据

**片段：**

```cpp
// 位于 main 内
int points = 8;
int& alias = points;
alias = 12;
```

现在 `points` 也变成 12，因为 `alias` 是它的另一个名字。普通引用必须在创建时绑定一个对象，此后不能换成别的对象。写 `alias = other;` 是把 `other` 的值赋给原来的 `points`，不是让 `alias` 改去代表 `other`。

不想通过这个名字修改时，加 `const`：

**片段：**

```cpp
// 位于 main 内
const int& view = points;
```

`view` 不能用来赋新值，`points` 自己仍可修改。它是只读访问，不是把原对象永久封住。

有些表达式指向一个已经存在、位置能识别的对象，例如变量 `points`、元素 `values[0]`，常叫**左值**。普通 `int&` 引用要绑定这类合适的对象。`3`、`points + 1` 这种临时算出来的结果是常见的右值，不能交给 `int&` 当作可改的原变量。

名字容易误导：`const int fixed = 3;` 里的 `fixed` 也是左值，却不能赋值。不是“能写在等号左边的才是左值”。现阶段会区分“已有对象”和“临时结果”就够用了，不必先学完整的表达式分类。

`const int&` 可以绑定临时结果：

**片段：**

```cpp
// 位于 main 内
const int& sum = 3 + 4;
```

直接这样绑定时，临时对象能活到该局部引用结束。不能据此推断“引用会让所有对象永远活着”。函数结束、返回引用、把引用保存起来时，都有额外的寿命问题，第 18 章会说明。

## 大数据不想复制，也不想被修改

一个 `vector<int>` 可能有很多元素。若参数写 `std::vector<int> values`，调用时通常要复制整排数据。只是读取时，用 `const std::vector<int>&`：不复制这排元素，也不能通过参数修改它。

**函数定义片段：**

```cpp
// 统计 values 中大于 threshold 的元素个数
int count_above(const std::vector<int>& values, int threshold) {
    int count = 0;
    for (std::size_t i = 0; i < values.size(); ++i) {
        if (values[i] > threshold) {
            ++count;
        }
    }
    return count;
}
```

**调用片段：**

```cpp
// 位于 main 内
std::vector<int> values{4, 9, 3, 9};
std::printf("%d\n", count_above(values, 5));
```

本例元素很少，复制也不贵；这个写法说明的是函数没有修改权限。以后遇到真正变大的数据，规则也不必换。

| 需要什么 | 小型数据，如 `int` | `vector`、`string` 等可能较大的数据 |
|---|---|---|
| 只要读到值 | 按值 `int x` | 只读引用 `const ...& x` |
| 要修改调用者的对象 | 引用 `int& x` | 可修改引用 `...& x` |

这是本书的常用选择，不是说所有自定义类型都一定很大。指针本身也很小，常按值传递；复制指针不等于复制它指向的内容。

## 一次得到两个结果

**函数定义片段：**

```cpp
// 把 total_minutes 拆成小时和剩余分钟，结果写进两个引用参数
void split_time(int total_minutes, int& hours, int& minutes) {
    hours = total_minutes / 60;
    minutes = total_minutes % 60;
}
```

`total_minutes` 是输入，后两个参数是输出位置。调用者要传两个不同的变量：

**调用片段：**

```cpp
// 位于 main 内
int hours = 0;
int minutes = 0;
split_time(135, hours, minutes);
std::printf("%d %d\n", hours, minutes);
```

如果两个引用参数都绑定同一个变量，后一次赋值会覆盖前一次。本例也约定总分钟数非负。

下一章会把“小时和分钟”装成一个记录，再直接返回它。两种办法都要会读；不要为了多拿几个结果，就让函数偷偷修改无关的全局变量。

## 核对

1. 输出 `36 21`。乘法可交换只是这次碰巧成立的性质；`remaining_space(20, 7)` 和 `remaining_space(7, 20)` 就不一样。
2. 分别为 13 和 0。执行 `return` 后本次调用结束，不会返回第二次。
3. 不能。参数可以按值，也可以按引用；名字表示意图，参数类型和说明才确定允许的作用。
4. `int& a = 5;` 不可行；只读引用 `b` 可以。对引用赋值没有重新绑定，仍修改原来的对象。
5. 返回 2。按值通常答案不变，却要复制元素；非 `const` 引用给了修改权限，但不要求一定修改。
6. 依次是 `(0,0)`、`(0,59)`、`(1,0)`、`(2,15)`。两个输出引用都绑定 `x` 时，先写入 2 又覆盖成 15，所以最终是 15。
