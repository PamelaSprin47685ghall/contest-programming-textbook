# 把问题写成程序

这本小册写给小学高年级、还没有学过编程的你。会做整数四则运算、会读简单表格，就可以从第一页开始。遇到负数、小数或新的记号，书里会先解释，不默认你已经学过。

我们先让程序完成一件小事，再学着处理一排数据、保存一段文字、把规则交给函数。每次只添一点新本领。书里凡是讲到一种用法，就近配一道真实的竞赛题——题目、数据、想法都在正文里，不必再去别处找；题面大多取自 USACO 铜组（美国计算机奥林匹克的入门级），我们按自己的话重述，样例照原样给出。

读到“停笔做一做”，就遮住后文，在纸上记下每一步的数，或补一小段代码，再找一个会算错的例子；答案放在章末。一天读一两小节很好。有电脑时把代码补成完整程序运行一下，看结果和你的预测是否相同；没有电脑，纸笔也够。

## 本书怎么写代码

示例使用 **C++14**。为了让你把注意力放在规则上，正文里的代码大多是**片段**：只保留要观察的几句，缺的上下文用注释交代（例如“位于 `main` 内”）。片段不能单独交给编译器；全书只有第一章留了一个完整的小程序骨架，教你怎么把代码变成能跑的程序。照着一段段补全，是你自己的练习。

代码里经常有 `std::`，例如 `std::printf`。先把它看作标准库工具名字的一部分：标准库是 C++ 已经准备好的一套工具，`std` 是它们所在的“命名空间”的名字。你可能在别处看到 `using namespace std;`，那是在告诉编译器可以在当前范围里省去前缀；本书写出前缀，你不必额外记这条简写。

数值练习主要用 `<cstdio>` 的输入输出；文本章介绍适合字符串的读写工具。最初的练习约定输入符合题目；学过判断后，再检查读取是否成功。读错了数据，不能随便编一个答案。

学习时要区分三类错误：编译器拒绝的程序；能运行但算错的程序；触犯语言规则、结果根本没有保证的程序。第三类叫**未定义行为**，“我这次运行没出事”不能证明它安全。

## 给带读者：怎样使用，检查到了哪里

一次只读到下一道“停笔”题，不用按文件数赶进度。开头几章先建立读程序、算一步、改一步的习惯；函数和容器每次只加一种新用法。第 17 章的自定义键、第 18、19 章以及数学工具页后半部分，可以另安排时间带读；它们没有被删去，也不要求第一次接触就独立读透。内联的竞赛题按话题放在正文里，先读故事还是先读数据都可以；每题只给样例和思路，不给现成程序，让孩子自己把片段接起来，正合本册的用意。

本册有 19 章正文、2 份查阅页和 1 份收束任务，另有本导读。正文与查阅页合计 89 组“停笔”练习，均附核对答案；内联 USACO 铜组例题 68 道，各附题面、输入输出约定、照抄的样例与思路，不给现成解答程序。

代码核对使用 GCC 16.2.1，以 `-std=c++14 -Wall -Wextra -Werror -pedantic` 编译。全书共 114 个代码块：第一章的骨架程序可独立编译运行；4 个刻意示警的危险片段（整数溢出对照、无符号反向循环、悬垂指针、返回引用捕获的 lambda）只用于辨认，没有作为安全示例运行；其余 109 个片段全部在补全上下文后编译通过并实际运行，且每一章的片段合并进同一个翻译单元整体编译，结果符合预期。内联例题的样例输入输出共约 130 组，数值照抄题目原档，并经脚本复算核对。

除“走出本册”中注明出处的四条外部网址外，全书链接均为本册内部相对链接，已逐一核对；本册不依赖任何外部题目文件，例题所依据的 USACO 题面信息已全部写入正文。

## 全书的题从哪来

书里的竞赛题都来自 USACO（USA Computing Olympiad，美国计算机奥林匹克）铜组过去十几年的月赛。每题在正文中重述题面、照抄样例、给出与本章工具相配的想法，并以一句话交代出处，例如“USACO 2013 年 11 月 Bronze 组第一题”，表示 2013 年 11 月月赛的第一题；不附官方解答代码。想按原格式做题或查更多题，可以自行访问 usaco.org；本册不承诺这些外部网址长期有效。
