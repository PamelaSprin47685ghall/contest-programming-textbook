# 把问题写成程序

这本书写给小学高年级、还没有学过编程的你。会做整数四则运算、会读简单表格，就可以从第一页开始。遇到负数、小数或新的数学记号，书里会先解释，不默认你已经学过。

我们先让程序完成一件小事，再试着处理一排数据、保存一段文字、安排一个接一个的任务。每次只加一点新本领，不急着把整章读完。

读到“停笔做一做”，就遮住后文，在纸上记下每一步的数、补一小段代码，或找一个会算错的例子；答案放在章末。一天完成一两小节也很好。有电脑时再运行程序，看它和你的预测是否相同。没有电脑，也能先把这些纸笔练习做好。

## 本书怎么写代码

示例使用 **C++14**。每个“完整程序”都可独立保存、编译；“片段”用于观察某条规则，不能单独交给编译器。两者会明确区分。示例不使用省略号代替必要代码。

代码里经常有 `std::`，例如 `std::printf`。先把它看作标准库工具名字的一部分。标准库是 C++ 已经准备好的一套工具，`std` 是它们所在的“命名空间”的名字。你可能在别处看到 `using namespace std;`，那是在告诉编译器，可以在当前范围里省去这些前缀；本书写出前缀，不必额外记这条简写。

数值练习主要使用 `<cstdio>` 的输入输出；文本章再介绍适合字符串的读写工具。每个完整程序各用一套，不要求把两套混在一起。最初的练习约定输入符合题目；学过判断后，再检查读取是否成功。不能因为读错了数据，就随便编一个答案。

学习时要区分三类错误：编译器拒绝的程序；能够运行但算错的程序；触犯语言规则、结果根本没有保证的程序。第三类叫**未定义行为**，不能用“我这次运行没出事”来证明安全。

## 给带读者：怎样使用，检查到了哪里

一次只读到下一道“停笔”题，不用按文件数赶进度。前四章先建立读程序、算一步、改一步的习惯；函数和容器每次只加一种新用法。第 11 章的自定义键、第 12、13 章，以及数学工具页后半部分，可以另安排时间带读。它们没有被删去，也不要求孩子在第一次接触时独立读透。

本册有 13 章正文、2 份查阅页和 1 份收束任务，另有本导读。正文与查阅页合计 89 组“停笔”练习，均附核对答案；末尾综合题另附解题思路。示例的检查不代表已经做过真实小学生试读，实际带读时应以孩子能否用自己的话解释为准。

代码核对使用 GCC 16.2.1，以 `-std=c++14 -Wall -Wextra -Werror -pedantic` 编译，并启用未定义行为检查。52 个完整程序均编译通过并实际运行；含样例、边界、错误输入、随机数据与替换写法，共检查 355 组运行场景，结果符合预期。文件示例还实际覆盖了输入缺失、输入不完整、输出打开失败和关闭失败。

16 个本地文档链接已核对。刻意列出的错误片段用于辨认问题，没有作为安全示例运行；这些检查不声称证明所有输入、所有编译器或所有平台都正确。
