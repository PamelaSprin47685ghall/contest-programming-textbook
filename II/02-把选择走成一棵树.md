# 02　把选择走成一棵树

有三件工具，重量是 2、3、5。背包能承受 5。可以不拿，也可以拿一些，每件最多一件。怎样确保所有拿法都试过？

## 一个位置只有两个决定

先决定第一件拿不拿，再决定第二件，最后决定第三件。每条走到底的路线是一份完整决定。三件有 `2*2*2 = 8` 份决定，包括什么也不拿。

这张分叉图叫**搜索树**。从一个分叉一直走到头，再回来试另一边，是深度优先搜索，常缩写为 DFS。

“回来”时，必须恢复离开前的状态。若选择表是大家共用的一排标记，拿完这一支要撤销；如果只把当前总重量按值传给下一层，每层有自己的副本，就不用手动减回来。

**停笔 1**　按“不拿在前，拿在后”的顺序，写出三件工具的八种拿法。重量相同的不同工具，是否仍算不同选择？

## 函数可以请自己处理剩下的事

下面用函数处理“从第 `index` 件起还没决定的工具”。递归调用就是函数调用自己，不是另一种魔法循环。必须有结束条件，而且每次离结束更近。

**完整程序：**输入 `0 <= n <= 20`、容量 `0 <= capacity <= 1000000`，再输入 `n` 个 0 到 1000000 的重量。输出不超过容量的选择数，包括空选择。

```cpp
#include <cstdio>
#include <vector>

long long count_choices(const std::vector<int>& weights, int index,
                        int total, int capacity) {
    if (total > capacity) {
        return 0;
    }
    if (index == static_cast<int>(weights.size())) {
        return 1;
    }
    return count_choices(weights, index + 1, total, capacity)
         + count_choices(weights, index + 1, total + weights[index], capacity);
}

int main() {
    int n = 0;
    int capacity = 0;
    if (std::scanf("%d%d", &n, &capacity) != 2 || n < 0 || n > 20) {
        return 1;
    }
    std::vector<int> weights(n);
    for (int& weight : weights) {
        if (std::scanf("%d", &weight) != 1) {
            return 1;
        }
    }
    std::printf("%lld\n", count_choices(weights, 0, 0, capacity));
    return 0;
}
```

输入：

```text
3 5
2 3 5
```

输出：

```text
5
```

拿与不拿两组不重合，合起来又覆盖全部选择，所以可以相加。最坏仍有 `O(2^n)` 个分叉，调用栈深度为 `O(n)`；函数参数引用同一份只读重量表，没有每次复制整排数据。

## 哪条岔路可以提前封住

总重量已经超出容量，以后又只会增加，可以立即返回零。这叫**剪枝**。依据是“后面不可能修好”，不是“我猜没希望”。

若允许负重量，超重后可能再拿一件负重量工具回到合法范围，这条剪枝就不成立。若要找最大价值，可以先算一个乐观上界；连乐观上界都不比已有答案好，才可剪掉。上界必须真的不低估剩余机会。

**停笔 2**　重量为 `6,-2`、容量 5 时，上面的提前返回会漏掉哪份选择？为什么不能把“剪得更多”直接当作“更好的算法”？

## 把一组决定写成几位二进制

三件工具可以用三位标记：`101` 表示选第 0 和第 2 件。一个这样的整数叫位掩码。`1u << i` 把一个 1 左移 `i` 位；`mask & (1u << i)` 非零表示该位是 1。这里 `&` 是按位与，不是取地址，也不是逻辑并且 `&&`。

逐个枚举 `0` 到 `(1u << n)-1`，每个整数正好是一份子集。要求 `n` 小于无符号类型的位数；本章 `n <= 20` 没有移位越界。逐位重新求和需 `O(n*2^n)`，不一定比递归更快。

排列搜索则不同：每层选一件**尚未使用**的工具，选择后作标记，回来撤销。若只要不同数值排列，先排序并跳过同层重复选择，不能事后靠“数量大概对”判断去重成功。

**停笔 3**　四件工具的掩码 `0101` 选了哪些下标？若只允许选两件，应该统计哪种掩码？三件不同工具的排列有几种，为什么不是八种？

## 核对

1. 空、第三件、第二件、第二和第三件、第一件、第一和第三件、第一和第二件、全部。不同工具仍分别作决定。
2. 会漏掉同时选两件、总重量 4 的合法选择。剪枝删去的是整组方案，理由不对就会删掉答案。
3. 下标 0、2。只统计恰有两个 1 的掩码；三件排列有 `3*2*1 = 6` 种，排列还关心先后。
