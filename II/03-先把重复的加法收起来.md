# 03　先把重复的加法收起来

班里的图书角每天记一笔：今天借出几本。月底老师问：“3 号到 10 号一共借出多少？”过一会儿又问：“12 号到 20 号呢？”每问一次，就把那几天的数从头加一遍。值日生想了个办法：在每天那一行旁边再写一个数，是“从 1 号到这一天一共借出多少”。再有人问 3 号到 10 号，只要拿 10 号旁边的数，减去 2 号旁边的数。

这一章练的就是这件事：**同一批数要被一段一段反复加，就先把“前面一共多少”存起来，每问一次只做一次减法。**反过来，若是要给一段数各加上同一个值，也有对应的办法。最后把这两件事搬到方格纸上。

## 保存的不是原数，而是前面一共多少

设一排数是 a[0]、a[1]、……、a[n − 1]。另开一排 `prefix`，`prefix[i]` 是前 i 个数的和，也就是 a[0] 到 a[i − 1] 的和。`prefix[0]` 是 0：一个数也没加。往后每一项只比前一项多加一个数：`prefix[i] = prefix[i - 1] + a[i - 1]`。

这排数叫**前缀和**。半开区间 [left, right) 里的数的和，就是 `prefix[right] - prefix[left]`：前 right 个数的和，去掉前 left 个数的和。例如 a 是 4、1、3、5，`prefix` 是 0、4、5、8、13，[1, 3) 的和是 8 − 4 = 4，正是 1 + 3。

`prefix` 比 a 多一项，正因为有 `prefix[0] = 0`，left 等于 0 时也不用另写一个判断。

### 品种计数

N 头牛排成一排（N 到 10 万），每头牛的品种是 1、2、3 之一。有 Q 个询问（Q 到 10 万），每个询问给 a 和 b（a ≤ b），问第 a 头到第 b 头牛里，三个品种各有几头。

输入第一行 N 和 Q；之后 N 行，按顺序是每头牛的品种；再之后 Q 行，每行一个询问。每个询问输出一行三个数。

样例输入：

```text
6 3
2
1
1
3
2
1
1 6
3 3
2 4
```

样例输出：

```text
3 2 1
1 0 0
2 0 1
```

整排有三头品种 1、两头品种 2、一头品种 3；第 3 头是品种 1；第 2 到第 4 头是 1、1、3。这是 USACO 2015 年 12 月银组第三题[“品种计数”](../USACO/银组/2015_2016/2015.12/P3.md)。

每个询问都把那一段数一遍，最坏是 10 万个询问各数 10 万头牛，10¹⁰ 次，来不及。可是“第 a 到第 b 头里品种 1 有几头”正是一段的和：把品种 1 的牛记作 1，别的牛记作 0，加起来就是。三个品种各建一排前缀和，每个询问做三次减法。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2) {
        return 1;
    }
    // count[b][i]：前 i 头牛（第 0 到第 i - 1 头）里，品种 b 有几头
    std::vector<std::vector<int>> count(4, std::vector<int>(n + 1, 0));
    for (int i = 1; i <= n; ++i) {
        int breed = 0;
        if (std::scanf("%d", &breed) != 1 || breed < 1 || breed > 3) {
            return 1;
        }
        for (int b = 1; b <= 3; ++b) {
            count[b][i] = count[b][i - 1];
        }
        ++count[breed][i];
    }
    for (int i = 0; i < q; ++i) {
        int a = 0;
        int b = 0;
        if (std::scanf("%d%d", &a, &b) != 2) {
            return 1;
        }
        // 题目的第 a 到第 b 头，就是程序里的 [a - 1, b)
        std::printf("%d %d %d\n", count[1][b] - count[1][a - 1],
                    count[2][b] - count[2][a - 1], count[3][b] - count[3][a - 1]);
    }
    return 0;
}
```

题目的牛从 1 编号，程序里的牛从 0 编号，第 a 头到第 b 头是 [a − 1, b)，所以拿 `count[1][b]` 减 `count[1][a - 1]`。建表要做 3N 次复制，每个询问三次减法，一共 O(N + Q)。读到的品种不在 1 到 3 之间时，`++count[breed][i]` 会越界，所以读入时一并检查。

### 和为 7 的倍数的子序列

N 头牛排成一排（N 到 50,000），每头牛有一个编号（0 到 10⁶），各不相同。约翰只拍一段连续的牛，并且这段牛的编号和必须是 7 的倍数。问这样的一段最多几头？没有就输出 0。

输入第一行 N，之后 N 行，每行一个编号。输出最长的长度。

样例输入：

```text
7
3
5
1
6
2
14
10
```

样例输出：

```text
5
```

5 + 1 + 6 + 2 + 14 = 28，是 7 的倍数，这一段 5 头。这是 USACO 2016 年 1 月银组第二题[“和为 7 的倍数的子序列”](../USACO/银组/2015_2016/2016.01/P2.md)。

[left, right) 的和是 7 的倍数，就是 `prefix[right]` 和 `prefix[left]` 的差是 7 的倍数，也就是两者除以 7 的余数相同。所以对每个右端 right，要找的是余数和它相同、而且最靠左的那个 left。余数只有 0 到 6 七种，为每种记下它最早出现的位置就够了。

编号和最大到 5 × 10¹⁰，`int` 放不下。我们也不需要和本身，只要余数：加上一个数以后的余数，等于“原来的余数加上这个数”的余数。

**片段：**

```cpp
// 位于 main 内；id 已读入，共 n 个
// first[r]：使“前 i 头牛的编号和”除以 7 余 r 的最小的 i，-1 表示还没出现过
std::vector<int> first(7, -1);
first[0] = 0;
int remainder = 0;
int best = 0;
for (int i = 1; i <= n; ++i) {
    remainder = (remainder + id[i - 1]) % 7;
    if (first[remainder] == -1) {
        first[remainder] = i;
    } else if (i - first[remainder] > best) {
        best = i - first[remainder];
    }
}
```

`first[0] = 0`，对应 `prefix[0] = 0`：从第一头牛开始的那些段，也要能被找到。一个余数第一次出现时，只记下位置；以后再出现，就用当前位置减去最早的位置。最早的位置不会改，因为后来的位置只会让段变短。

**停笔 2**　对样例写出 i = 0 到 7 时的 `remainder`。哪两个 i 的余数相同，给出了答案 5？

## 若不是问一段，而是给一段加水

前缀和让“问一段的和”变快。还有一种相反的需求：很多次“把一段数各加上 1”，最后才问每个数是多少。

### 干草堆叠放

N 个空位排成一排（N 是奇数，到 10⁶），约翰下 K 条指令（K 到 25,000），每条给 A 和 B，意思是在第 A 到第 B 个位置上各放一捆干草。全部放完，问各堆高度的中位数：从小到大排好，正中间的那个数。

输入第一行 N 和 K，之后 K 行，每行一条指令。输出中位数。

样例输入：

```text
7 4
5 5
2 4
4 6
3 5
```

样例输出：

```text
1
```

放完后七堆的高度是 0、1、2、3、3、1、0，排好是 0、0、1、1、2、3、3，正中间是 1。这是 USACO 2012 年 1 月铜组第二题[“干草堆叠放”](../USACO/铜组/2011_2012/2012.01/P2.md)。

每条指令老老实实加一遍，最坏是 25,000 × 10⁶，太多了。换一种记法：不记每堆有多高，只记**每堆比前一堆高出几捆**，叫它 `change`。在 [left, right) 上各加 1，这一段内部相邻两堆的高度差都不变；变的只有两处：第 left 堆比前一堆多高出 1，第 right 堆比前一堆少高出 1。一条指令只改两个数。

全部指令记完，再从左往右把 `change` 累加起来，加到第 i 项，就得到第 i 堆的高度。这正是对 `change` 求前缀和。“相邻两项的差”这排数叫**差分**，它和前缀和互为反过程：对一排数先做差分再求前缀和，得回原来那排数。

**片段：**

```cpp
// 位于 main 内；n、k 已读入，堆在程序里从 0 编号
// change[i]：第 i 堆比第 i - 1 堆高出几捆
std::vector<int> change(n + 1, 0);
for (int i = 0; i < k; ++i) {
    int a = 0;
    int b = 0;
    if (std::scanf("%d%d", &a, &b) != 2) {
        return 1;
    }
    ++change[a - 1];    // 题目的第 a 到第 b 堆，是程序里的 [a - 1, b)
    --change[b];
}
std::vector<int> height(n);
int current = 0;
for (int i = 0; i < n; ++i) {
    current += change[i];
    height[i] = current;
}
std::sort(height.begin(), height.end());
std::printf("%d\n", height[n / 2]);
```

`change` 开 n + 1 项，因为 b 可以等于 n，`--change[b]` 要落在最后一堆的后面。那一项不参加累加，只是让下标合法。整件事是 O(N + K)，再加上排序，排序用的是[第一卷第 13 章](../I/13-把一段数据交给算法.md)的 `std::sort`。

### 扑克牌

一种扑克牌有 N 种点数（N 到 10 万），点数 i 的牌有 aᵢ 张（0 到 10 万）。出牌只有一种方式：选 i ≤ j，点数 i 到 j 各出一张，叫一个顺子。最少出几个顺子，能把牌出完？

输入第一行 N，之后 N 行依次是 a₁ 到 a_N。输出最少的顺子数。

样例输入：

```text
5
2
4
1
2
3
```

样例输出：

```text
6
```

可以出 1 到 5、1 到 2、4 到 5 各一次，2 到 2 两次，5 到 5 一次，共 6 个。这是 USACO 2013 年 3 月银组第一题[“扑克牌”](../USACO/银组/2012_2013/2013.03/P1.md)。

一个顺子就是“给一段各减 1”，所以先看差分。约定 a₀ = 0。盖住点数 i 的顺子恰好有 aᵢ 个，盖住 i − 1 的有 aᵢ₋₁ 个。盖住 i 的顺子要么也盖住 i − 1，要么从 i 开始。前一种至多 aᵢ₋₁ 个，所以从 i 开始的顺子至少有 aᵢ − aᵢ₋₁ 个。每个顺子只有一个开头，把各处的下限加起来，就是顺子总数的下限：所有正的差分之和。

这个下限能做到。从左往右，在点数 i 处让 min(aᵢ₋₁, aᵢ) 个顺子从 i − 1 接着延伸过来，其余的顺子在 i 结束；不够的 aᵢ − aᵢ₋₁ 个在 i 新开。这样新开的顺子恰好是下限那么多。

**片段：**

```cpp
// 位于 main 内；n 已读入
long long straights = 0;
int previous = 0;        // 第 0 种点数之前，当作有 0 张
for (int i = 0; i < n; ++i) {
    int count = 0;
    if (std::scanf("%d", &count) != 1) {
        return 1;
    }
    if (count > previous) {
        straights += count - previous;
    }
    previous = count;
}
std::printf("%lld\n", straights);
```

样例的差分是 2、2、−3、1、1，正的加起来是 6。总数最多是 10 万种点数各开 10 万个，10¹⁰，要用 `long long`。

## 在方格纸上做同样的减法

前缀和与差分都能搬到方格纸上。先看前缀和。

设 a 是一张 n 行 m 列的数表，行列都从 0 编号。令 `sum[x][y]` 是行在 [0, x)、列在 [0, y) 的那些格子之和，也就是左上角一块 x 行 y 列的长方形。那么行在 [x1, x2)、列在 [y1, y2) 的长方形之和是

`sum[x2][y2] - sum[x1][y2] - sum[x2][y1] + sum[x1][y1]`

去掉上面一条、去掉左边一条，左上角那一小块被去掉了两次，要加回一次。建表也用同一个道理：`sum[x][y]` 等于 a[x − 1][y − 1] 加上 `sum[x - 1][y]` 和 `sum[x][y - 1]`，再减去被加了两次的 `sum[x - 1][y - 1]`。

拿一张小表核对：

| | 列 0 | 列 1 | 列 2 |
|---|---|---|---|
| 行 0 | 1 | 2 | 0 |
| 行 1 | 3 | 1 | 4 |
| 行 2 | 0 | 2 | 5 |

全部 9 格加起来是 18，所以 `sum[3][3]` = 18。行 [1, 3)、列 [1, 3) 是右下角四格 1、4、2、5，和为 12。用公式：`sum[3][3]` = 18，`sum[1][3]` = 3，`sum[3][1]` = 4，`sum[1][1]` = 1，18 − 3 − 4 + 1 = 12。

### 粉刷谷仓

约翰在墙上刷了 N 个矩形（N 到 10 万），边都和坐标轴平行。每个矩形用左下角 (x₁, y₁) 和右上角 (x₂, y₂) 给出，坐标都在 0 到 1000 之间，面积都大于 0。矩形里面刷上一层漆。问：刷完以后，恰好有 K 层漆的面积是多少？

输入第一行 N 和 K，之后 N 行，每行 x₁ y₁ x₂ y₂。输出面积。

样例输入：

```text
3 2
1 1 5 5
4 4 7 6
3 3 8 7
```

样例输出：

```text
8
```

把墙分成 1 × 1 的小格，用左下角称呼一个小格。第一个矩形和第三个矩形重叠在 x、y 都在 [3, 5) 的 4 格；第二个矩形整个落在第三个里面，6 格。这 10 格里，(4, 4) 那一格三个矩形都盖住了，算了两次，要从两边各去掉：4 + 6 − 2 = 8。这是 USACO 2019 年 2 月银组第二题[“粉刷谷仓”](../USACO/银组/2018_2019/2019.02/P2.md)。

一个矩形刷过的小格，x 在 [x₁, x₂)、y 在 [y₁, y₂)。照搬一维的办法：在左下角记 +1，在右边、上边紧挨着矩形外面的两个角各记 −1，在右上角外面记 +1。对这张表求二维前缀和，每格得到的数，就是盖住它的矩形个数。为什么？一个在矩形里面的格子，它左下方的那块长方形只包含 +1 那一角，加起来是 1；在矩形右边外面的格子，同时包含左下角的 +1 和右下角的 −1，抵消成 0；右上方外面的格子四个角都包含，1 − 1 − 1 + 1 = 0。

**片段：**

```cpp
// 位于 main 内；n、k 已读入。小格 (x, y) 指左下角为 (x, y) 的 1 × 1 方格
std::vector<std::vector<int>> coat(1001, std::vector<int>(1001, 0));
for (int i = 0; i < n; ++i) {
    int x1 = 0;
    int y1 = 0;
    int x2 = 0;
    int y2 = 0;
    if (std::scanf("%d%d%d%d", &x1, &y1, &x2, &y2) != 4) {
        return 1;
    }
    // 刷的是 x 在 [x1, x2)、y 在 [y1, y2) 的小格
    ++coat[x1][y1];
    --coat[x2][y1];
    --coat[x1][y2];
    ++coat[x2][y2];
}
int area = 0;
for (int x = 0; x < 1000; ++x) {
    for (int y = 0; y < 1000; ++y) {
        if (x > 0) {
            coat[x][y] += coat[x - 1][y];
        }
        if (y > 0) {
            coat[x][y] += coat[x][y - 1];
        }
        if (x > 0 && y > 0) {
            coat[x][y] -= coat[x - 1][y - 1];
        }
        if (coat[x][y] == k) {
            ++area;
        }
    }
}
std::printf("%d\n", area);
```

表开 1001 × 1001，是因为 x₂、y₂ 可以等于 1000，记 −1 的位置要落在表里。真正的小格只有 x、y 都在 [0, 1000) 的那些，所以累加只走到 999。这里没有另开一张前缀和表，而是原地改：算到 `coat[x][y]` 时，它左边、上边、左上那三格都已经改成了层数，这一格还是原来记的加减。

一共一百万格，每格几次加减；N 个矩形各记四次。

**停笔 5**　只刷一个矩形 `1 1 3 2`，写出记完四个角以后 `coat` 在 x、y 都在 [0, 4) 的那些格子，再做完前缀和，核对哪几格是 1。

**停笔 6**　若把累加的条件写成 `x < 1001`、`y < 1001`，样例的答案会变吗？在什么样的输入上会算错？

## 核对

1. 0、0、1、2、2、2、3。第三个询问是第 2 到第 4 头，`count[1][4] - count[1][1]` = 2 − 0 = 2。
2. `remainder` 依次是 0、3、1、2、1、3、3、6。i = 1 和 i = 6 的余数都是 3，6 − 1 = 5，对应第 2 到第 6 头牛。i = 2 和 i = 4 的余数都是 1，只给出 2。
3. `change` 是 0、1、1、1、0、−2、−1、0。第 4 项上 `5 5` 加 1、`2 4` 减 1，抵消成 0。前七项累加得 0、1、2、3、3、1、0。
4. 差分是 3、−2、2，答案是 3 + 2 = 5。点数 1 处开 3 个顺子；到点数 2，只有 1 个接过去，另外 2 个在点数 1 结束；到点数 3，那 1 个接过去，再新开 2 个。五个顺子是：1 到 1 两个，1 到 3 一个，3 到 3 两个。
5. 记完后 `coat[1][1]` = 1，`coat[3][1]` = −1，`coat[1][2]` = −1，`coat[3][2]` = 1，其余是 0。做完前缀和，只有 (1, 1) 和 (2, 1) 两格是 1，正是这个 2 × 1 的矩形。
6. 样例不会变。x = 1000 或 y = 1000 的那些格子不在墙上，没有矩形盖住它们，累加出来都是 0。K 至少是 1，它们碰巧不会被数进去；若题目问“恰好 0 层”，就会多数出 2001 格。
