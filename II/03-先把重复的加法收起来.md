# 03　先把重复的加法收起来

一排花盆每天各收到一些水。老师不断问：“第 2 盆到第 5 盆一共多少？”每次从头加也能做，但相同的加法做了很多遍。

## 保存的不是原数，而是前面一共多少

把前 `i` 项的和记为 `prefix[i]`，特意让 `prefix[0] = 0`。原序列下标从 0 开始：

```text
原数       3  1  4  2
前缀和  0  3  4  8 10
```

半开区间 `[left,right)` 的和是 `prefix[right]-prefix[left]`。大段里减掉左边不需要的那段，正好留下问题要的部分。

**停笔 1**　求上面下标 `[1,3)` 的和。空区间 `[2,2)` 呢？为什么留一个开头的零，反而能少写一种特殊情况？

**完整程序：**输入 `0 <= n <= 100000`、`0 <= q <= 100000`，再输入 `n` 个绝对值不超过一百万的整数。随后每次查询给出 `0 <= left <= right <= n`，输出这段的和。

```cpp
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2 || n < 0 || n > 100000 || q < 0) {
        return 1;
    }
    std::vector<long long> prefix(n + 1, 0);
    for (int i = 0; i < n; ++i) {
        int value = 0;
        if (std::scanf("%d", &value) != 1) {
            return 1;
        }
        prefix[i + 1] = prefix[i] + value;
    }
    for (int i = 0; i < q; ++i) {
        int left = 0;
        int right = 0;
        if (std::scanf("%d%d", &left, &right) != 2 || left < 0 || left > right || right > n) {
            return 1;
        }
        std::printf("%lld\n", prefix[right] - prefix[left]);
    }
    return 0;
}
```

输入：

```text
4 3
3 1 4 2
1 3
0 4
2 2
```

输出：

```text
5
10
0
```

建表 `O(n)`，每问一次 `O(1)`，合计 `O(n+q)`。累计和可能超过 `int`，所以表里用 `long long`。如果原数发生变化，后面的许多前缀都会变；本办法适合先固定数据、再查询。

## 若不是问一段，而是给一段加水

倒过来想：把相邻两项的变化记下来。令 `difference[0]=a[0]`，后面 `difference[i]=a[i]-a[i-1]`，累加就能还原原序列。

给 `[left,right)` 每项加 `v`，只需在 `difference[left]` 加 `v`，在 `difference[right]` 减 `v`。前者打开影响，后者关闭影响。多开一个末端位置，允许 `right == n`。

这是**操作片段**，假设 `difference` 长度为 `n+1`：

```cpp
difference[left] += value;
difference[right] -= value;
```

全部修改登记完再累加还原，总工作量 `O(n+q)`。不能在每次登记后就声称立刻得到了任意位置的最新数值；要交错修改查询，需要第 15 章的结构。

**停笔 2**　四个零，先给 `[1,4)` 加 2，再给 `[2,3)` 减 1。写出差分表和最终四项。空区间修改为什么没有效果？

## 在方格纸上做同样的减法

二维前缀 `P[x][y]` 保存前 `x` 行、前 `y` 列的和。求矩形 `[x1,x2) × [y1,y2)`：

$$P[x2][y2]-P[x1][y2]-P[x2][y1]+P[x1][y1].$$

两块不要的区域相交，被减了两遍，要补回一次。建表也按“上方加左方，减掉重叠，再加本格”更新。多一行零、多一列零，边缘也用同一公式。

在更高维，每个坐标有“取上界”与“取下界”两种选择，合计 `2^d` 个角；按减去的维数奇偶决定符号。维数增加并不是免费。

**停笔 3**　方格的两行是 `1 2 3` 与 `4 5 6`。求全部六格的和、右两列的和。为什么后者不能只减去第一行？

## 核对

1. 5 与 0。起点为零时仍用两个前缀相减，不必另写分支。
2. 差分为 `[0,2,-1,1,-2]`，还原为 `[0,2,1,2]`。空区间在同一位置加减，互相抵消。
3. 21 与 16。列与行是不同方向；应从整块减去左边一列的和 5。
