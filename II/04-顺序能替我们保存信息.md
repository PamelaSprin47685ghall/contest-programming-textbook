# 04　顺序能替我们保存信息

体检那天，校医要找出全班最高的三位同学。一个办法是每次把全班看一遍，挑出最高的，记下，再看一遍挑第二高的。另一个办法是先让大家按身高站成一排，然后看排头三位。站好以后，“谁比谁高”这件事就写在了队伍里，不用再问。

[第一卷第 13、14 章](../I/13-把一段数据交给算法.md)学过怎样让 `std::sort` 按自己的规则排序。这一章不再讲怎样调用它，而是问：**排好以后，哪些比较就不必再做了？**有时要先换一个东西来排；有时两排都排好了，只要从开头往后走；有时要排的是坐标，可我们只关心它们的先后。

## 比较以前，先决定比较什么

排序省下来的是比较。可是题目里的东西，常常不能直接拿来排。先把每个对象换成一个能比较的量，比较才有意义。

### 山景

远处有 N 座山（N 到 10 万）。每座山是一个底边在 x 轴上的等腰直角三角形，直角在山顶，两条斜边都和地面成 45°，所以一座山由山顶 (x, y) 完全确定；没有两座山的山顶在同一点，0 ≤ x ≤ 10⁹，1 ≤ y ≤ 10⁹。一座山的山顶若落在另一座山的三角形里（含边上），这座山就看不见。问能看见几座山。

输入第一行 N，之后 N 行，每行是一座山顶的 x 和 y。输出能看见的座数。

样例输入：

```text
3
4 6
7 2
2 5
```

样例输出：

```text
2
```

第二座山顶 (7, 2) 落在第一座山里：第一座山在 x = 7 处高 6 − 3 = 3，比 2 高。另两座互不包含。这是 USACO 2019 年 1 月银组第三题[“山景”](../USACO/银组/2018_2019/2019.01/P3.md)。

两座山两两比较要 50 亿次。先换一个东西来比。山顶在 (x, y) 的山，底边是 x 轴上的 [x − y, x + y]。山顶 (x', y') 落在这座山里，就是 y' ≤ y − |x' − x|，拆开绝对值，等于两个不等式同时成立：x' − y' ≥ x − y，x' + y' ≤ x + y。也就是说，一座山的底边被另一座山的底边整个盖住。三角形之间的问题，变成了数轴上区间之间的问题。

样例的三条底边是 [−2, 10]、[5, 9]、[−3, 7]。[5, 9] 在 [−2, 10] 里面。

区间怎样排？按左端从小到大排。排好以后，从左往右看，前面每一条的左端都不比当前这条大，所以当前这条被前面某条盖住，只取决于右端：前面有没有一条的右端不比它小。只要记住前面的右端最远到哪里。左端相同的两条，让右端大的排前面：宽的那条先登场，窄的那条到时就会被认出是被盖住的。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

struct Base {
    long long left;
    long long right;
};

// 左端小的在前；左端相同，右端大的（更宽的山）在前
bool comes_before(const Base& a, const Base& b) {
    if (a.left != b.left) {
        return a.left < b.left;
    }
    return a.right > b.right;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<Base> bases(n);
    for (int i = 0; i < n; ++i) {
        long long x = 0;
        long long y = 0;
        if (std::scanf("%lld%lld", &x, &y) != 2) {
            return 1;
        }
        bases[i] = Base{x - y, x + y};
    }
    std::sort(bases.begin(), bases.end(), comes_before);
    // farthest：已经看过的山里，底边右端最远到哪里
    int visible = 1;
    long long farthest = bases[0].right;
    for (int i = 1; i < n; ++i) {
        if (bases[i].right > farthest) {
            ++visible;
            farthest = bases[i].right;
        }
    }
    std::printf("%d\n", visible);
    return 0;
}
```

排好的样例是 [−3, 7]、[−2, 10]、[5, 9]。第一条一定看得见，`farthest` 是 7；第二条右端 10 比 7 远，看得见，`farthest` 改成 10；第三条右端 9 不比 10 远，被盖住。答案 2。

x − y 可以是负数，x + y 可以到 2 × 10⁹，用 `long long`。排序 O(N log N)，扫描 O(N)。题目保证 N 至少是 1，`bases[0]` 存在。正好相等时也算被盖住，所以条件是 `>`，不是 `>=`。

对拍用的慢程序不换成区间，直接对每一对山检查 |x' − x| ≤ y − y'，两两比较。它和程序 A 没有共用“三角形等于区间”这一步，所以那一步若推错了，对拍也能抓到。

**停笔 1**　把 `comes_before` 里左端相同时的规则改成“右端小的在前”，找一组两座山的输入，让程序输出错误的答案。

## 两排已排好，只需沿着开头走

两排数各自排好了，要把它们按先后合成一排，不用重排。两排的开头各是自己那排最小的，合起来最小的一定是两个开头之一。拿走它，那一排露出新的开头，再比一次。每次比较拿走一个，总共比较的次数不超过两排的长度之和。

### 贝西减速

贝西在滑 1000 米。开始每秒 1 米，每减速一次慢一档：减速 k 次以后，每秒 1/(k + 1) 米。N 个减速事件（N 到 10,000）次序打乱给出：`T x` 表示第 x 秒时减速，`D x` 表示滑到 x 米处时减速。事件都发生在滑完以前；几个事件同时发生，就连着减速几次。问滑完 1000 米用几秒，四舍五入到整数（恰好 .5 时进位）。

输入第一行 N，之后 N 行，每行一个事件。输出秒数。

样例输入：

```text
2
T 30
D 10
```

样例输出：

```text
2970
```

前 10 米用 10 秒；减速一次，每秒 1/2 米，到第 30 秒又滑了 10 米；再减速，剩下 980 米每米 3 秒，用 2940 秒。共 10 + 20 + 2940 = 2970。这是 USACO 2014 年 1 月银组第一题[“贝西减速”](../USACO/银组/2013_2014/2014.01/P1.md)。

两种事件各自按 x 排好。时间事件按时刻有序，距离事件按距离有序，而贝西的时刻和距离一起增大，所以两排事件各自都已按发生先后排好。只有两排之间的先后要比：照当前速度，下一个距离事件会在什么时刻发生？比下一个时间事件早，就先处理它。

**片段：**

```cpp
// 位于 main 内；times、distances 已读入，并且各自从小到大排好
double now = 0;         // 已经滑了几秒
double position = 0;    // 已经滑了几米
int slowdowns = 0;      // 已经减速几次；此刻每秒滑 1 / (slowdowns + 1) 米
std::size_t t = 0;      // times 里下一个还没发生的事件
std::size_t d = 0;      // distances 里下一个还没发生的事件
while (t < times.size() || d < distances.size()) {
    int seconds_per_meter = slowdowns + 1;
    bool distance_first = false;
    if (t == times.size()) {
        distance_first = true;
    } else if (d < distances.size()) {
        double reach = now + (distances[d] - position) * seconds_per_meter;
        distance_first = reach < times[t];
    }
    if (distance_first) {
        now += (distances[d] - position) * seconds_per_meter;
        position = distances[d];
        ++d;
    } else {
        position += (times[t] - now) / seconds_per_meter;
        now = times[t];
        ++t;
    }
    ++slowdowns;
}
now += (1000 - position) * (slowdowns + 1);
std::printf("%lld\n", std::llround(now));
```

`t`、`d` 是两排的开头。一排用完了，另一排的事件只能一个个接着处理。`seconds_per_meter` 是整数，滑一段距离的时间用乘法，时间事件推进距离才用除法。最后剩下的路程用最后的速度滑完，`std::llround` 四舍五入，见第一卷[查阅：数学工具](../I/查阅-数学工具.md)。

两个事件恰好同时，先处理哪一个都一样：先处理的那个让速度变慢，可另一个紧接着在同一时刻发生，中间滑过的距离是 0。

**停笔 2**　输入是 `D 10` 和 `D 20` 两个事件，写出循环每一轮以后的 `now`、`position`、`slowdowns`，再算出答案。

## 不同排序，省的是不同工作

同样是排序，做法不同，省下的工作也不同。`std::sort` 大约做 N log N 次比较，什么都不保证，只给结果。冒泡排序每一趟从左往右扫，相邻两个逆序就交换，一趟一趟扫到没有交换为止。它慢，可它每一趟做了什么，说得清清楚楚。有时题目问的正是这种过程。

### 失序

贝茜写了冒泡排序：每一趟先打印一个 `moo`，再从左往右扫，遇到 A[i + 1] < A[i] 就交换两数；某一趟一次也没交换，就停。给出 N 个数（N 到 10 万，值在 0 到 10⁹，可能相同），问一共打印几个 `moo`。

输入第一行 N，之后 N 行依次是各个数。输出次数。

样例输入：

```text
5
1
5
3
8
2
```

样例输出：

```text
4
```

数组依次变成 [1, 3, 5, 2, 8]、[1, 3, 2, 5, 8]、[1, 2, 3, 5, 8]；第四趟一次也没交换，停下。这是 USACO 2018 年 3 月银组第一题[“失序”](../USACO/银组/2017_2018/2018.03/P1.md)。

照着模拟最坏要 N 趟，每趟 N 次比较。先看一趟里一个数 v 怎样动。扫描时，被一路往右带的，是当前扫过的那一段里最大的数。v 的左边若有比它大的数，扫到 v 跟前时，带过来的那个数一定比 v 大，两者交换，v 往左挪一格；之后扫描已经越过它，这一趟它不会再往左。v 的左边若没有比它大的数，它这一趟不会往左。

记 L 为 v 左边比它大的数的个数。每一趟，若 L 大于 0，恰好有一个比 v 大的数从 v 的左边越到右边，L 减 1；从右边越过来的数都比 v 小，不影响 L。整排排好，就是每个数的 L 都是 0。所以排好需要的趟数，是所有数的 L 中最大的那个；再加上最后那一趟“检查一遍，没有交换”。

L 要一个个数，还是慢。可是 L 最大的那个数 v，右边不会有比它小的数：若有一个比它小的 u 在它右边，v 左边那些比 v 大的数也都比 u 大，再加上 v 自己，u 的 L 就比 v 的还大。右边没有比 v 小的数，v 往左挪了 L 格就到了自己的最终位置，所以它的 L 等于“原来的位置减去排好后的位置”。别的数的这个差都不会超过它们自己的 L。于是：

趟数 = 所有数的（原位置 − 排好后的位置）中最大的那个，再加 1。

排好后的位置要和冒泡排序一致：相等的数冒泡排序不交换，原来在前的仍在前。所以给每个数带上原来的位置，值相同时按原位置排。

**片段：**

```cpp
struct Item {
    int value;
    int index;     // 排序以前的位置
};

// 值小的在前；值相同，原来靠前的仍在前，和冒泡排序一致
bool comes_before(const Item& a, const Item& b) {
    if (a.value != b.value) {
        return a.value < b.value;
    }
    return a.index < b.index;
}
```

**片段：**

```cpp
// 位于 main 内；value 已读入，共 n 个
std::vector<Item> items(n);
for (int i = 0; i < n; ++i) {
    items[i] = Item{value[i], i};
}
std::sort(items.begin(), items.end(), comes_before);
int most_left = 0;      // 一个数要往左挪的最远距离
for (int i = 0; i < n; ++i) {
    if (items[i].index - i > most_left) {
        most_left = items[i].index - i;
    }
}
std::printf("%d\n", most_left + 1);
```

样例排好是 1、2、3、5、8，原位置分别是 0、4、2、1、3，差是 0、3、0、−2、−1，最大 3，答案 4。`most_left` 从 0 开始：数组已经有序时，答案是 1。

## 大号码可以换成小名次

坐标常常很大，到 10⁹，可点只有一千个。若只关心坐标之间的先后，就可以把每个坐标换成它在所有坐标里的**名次**：最小的记 0，第二小的记 1……相同的坐标名次相同。名次只有一千种，可以直接当下标。这种换法叫**离散化**。

### 负载均衡

N 头牛（N 到 1000）站在不同的位置，坐标都是不超过 10⁶ 的正奇数。约翰修一道竖栅栏 x = a 和一道横栅栏 y = b，a、b 都是偶数，把牧场分成四块。他想让牛最多的那一块尽量少。问这个最大值最小是几。

输入第一行 N，之后 N 行，每行一头牛的 x 和 y。输出最小的最大值。

样例输入：

```text
7
7 3
5 5
7 13
3 1
11 7
5 3
9 1
```

样例输出：

```text
2
```

取 a = 6、b = 4：左下有 (3, 1)、(5, 3)，左上有 (5, 5)，右下有 (7, 3)、(9, 1)，右上有 (7, 13)、(11, 7)，最多两头。这是 USACO 2016 年 2 月银组第二题[“负载均衡”](../USACO/银组/2015_2016/2016.02/P2.md)。

竖栅栏放在两个相邻的不同 x 之间，放在这段空隙的哪里都一样，所以竖栅栏只有“左边有几种 x”这么多种不同的放法，横栅栏也一样，最多各 N + 1 种。把 x、y 都换成名次，“竖栅栏放在名次 a 前面”就是名次小于 a 的牛在左边。

剩下的是数四块里各有几头。四块的头数都能由“左下角有几头”算出来，这正是[第 3 章](03-先把重复的加法收起来.md)的二维前缀和。名次只到 N − 1，表只有 (N + 1) × (N + 1)。

**片段：**

```cpp
// 把一排坐标换成名次 0、1、2、……；坐标相同，名次也相同
std::vector<int> to_rank(const std::vector<int>& values) {
    int n = static_cast<int>(values.size());
    std::vector<Item> items(n);
    for (int i = 0; i < n; ++i) {
        items[i] = Item{values[i], i};
    }
    std::sort(items.begin(), items.end(), comes_before);
    std::vector<int> rank(n);
    int current = -1;
    for (int i = 0; i < n; ++i) {
        if (i == 0 || items[i].value != items[i - 1].value) {
            ++current;
        }
        rank[items[i].index] = current;
    }
    return rank;
}
```

`to_rank` 借用上一节的 `Item` 和 `comes_before`。排好以后从左往右扫，值和前一个不同，名次就加 1；名次写回原来的位置 `items[i].index`。

**片段：**

```cpp
// 位于 main 内；x、y 已读入，共 n 头牛
std::vector<int> rank_x = to_rank(x);
std::vector<int> rank_y = to_rank(y);
// below[a][b]：x 的名次小于 a、y 的名次小于 b 的牛有几头
std::vector<std::vector<int>> below(n + 1, std::vector<int>(n + 1, 0));
for (int i = 0; i < n; ++i) {
    ++below[rank_x[i] + 1][rank_y[i] + 1];
}
for (int a = 1; a <= n; ++a) {
    for (int b = 1; b <= n; ++b) {
        below[a][b] += below[a - 1][b] + below[a][b - 1] - below[a - 1][b - 1];
    }
}
int best = n;
for (int a = 0; a <= n; ++a) {
    for (int b = 0; b <= n; ++b) {
        int left = below[a][n];           // 竖栅栏左边
        int bottom = below[n][b];         // 横栅栏下面
        int left_bottom = below[a][b];
        int most = std::max(std::max(left_bottom, left - left_bottom),
                            std::max(bottom - left_bottom, n - left - bottom + left_bottom));
        best = std::min(best, most);
    }
}
std::printf("%d\n", best);
```

`below[a][n]` 是名次 x 小于 a 的牛，也就是竖栅栏左边的全部；`below[n][b]` 是横栅栏下面的全部。右上那一块用容斥：全部减去左边、减去下面，左下被减了两次，加回一次。两种栅栏各 N + 1 种放法，一共约 10⁶ 种，每种 O(1)。

## 核对

1. 例如两座山 (2, 2) 和 (1, 1)：底边 [0, 4] 和 [0, 2]。右端小的在前，先看 [0, 2]，算看得见；再看 [0, 4]，右端 4 比 2 远，也算看得见，输出 2。实际 (1, 1) 在第一座山里，答案是 1。
2. 第一轮 `now` = 10，`position` = 10，`slowdowns` = 1；第二轮每米 2 秒，`now` = 30，`position` = 20，`slowdowns` = 2。剩下 980 米每米 3 秒，答案 30 + 2940 = 2970。
3. 两个 2 的 L 都是 0，1 的 L 是 2。排好是 1、2、2，原位置是 2、0、1，差是 2、−1、−1，最大 2，答案 3。模拟：[2, 1, 2]、[1, 2, 2]，第三趟不交换，3 个 `moo`。不比原位置时，`std::sort` 可能把两个相等的数对调。这组输入碰巧不受影响，差变成 2、0、−2，最大仍是 2；输入 `2` 和 `2 2` 时，对调后差是 1、−1，答案错成 2，正确的是 1。
4. x 依次是 7、5、7、3、11、5、9，名次是 2、1、2、0、4、1、3。y 依次是 3、5、13、1、7、3、1，名次是 1、2、4、0、3、1、0。a = 2 是 x = 6，b = 2 是 y = 4，就是样例走过的那组栅栏：四块是 2、1、2、2。
