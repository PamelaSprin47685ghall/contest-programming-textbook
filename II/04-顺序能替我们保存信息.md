# 04　顺序能替我们保存信息

一排号码是 `8 3 6 3`。排好得到 `3 3 6 8`，相同的挨在一起，最小的在开头。可是原来谁先来这件事，也可能被打乱了。

## 比较以前，先决定比较什么

整数可以按大小；记录可以先按分数、再按编号。比较器回答“前者是否严格在后者前面”，同一个对象与自己比较必须是假。用 `<=` 冒充 `<`，会破坏排序要求。

排序不是题目的默认步骤。要找原位置，就把位置也存在记录里；只想合并相邻重复，不能先把原顺序扔掉。稳定排序会保留比较器认为等价的元素的原先后，`std::stable_sort` 提供这种保证；`std::sort` 不提供。

**停笔 1**　三个记录依次为 `(小林,8)`、`(小周,9)`、`(小陈,8)`，只按分数从小到大稳定排序，顺序怎样？若还按名字比较，原先后是否仍由“稳定”保证？

## 两排已排好，只需沿着开头走

把一排分成两半，分别排好，再把两半较小的开头不断取出，这叫**归并排序**。长度为一或零时已经有序。每层合并总共处理 `n` 项，大约 `log n` 层，所以是 `O(n log n)`，另用 `O(n)` 暂存空间。

合并还能数**逆序对**：原来左边的数比右边的数大的一对位置。当右半的一个数比左半当前数小，左半剩下的所有数都与它构成逆序。

**完整程序：**输入 `0 <= n <= 100000` 及 `n` 个 `int` 范围内的整数，输出逆序对数。相等不算逆序。

```cpp
#include <cstdio>
#include <vector>

long long arrange(std::vector<int>& a, std::vector<int>& buffer, int left, int right) {
    if (right - left <= 1) {
        return 0;
    }
    int middle = left + (right - left) / 2;
    long long answer = arrange(a, buffer, left, middle)
                     + arrange(a, buffer, middle, right);
    int i = left;
    int j = middle;
    int k = left;
    while (i < middle && j < right) {
        if (a[i] <= a[j]) {
            buffer[k++] = a[i++];
        } else {
            answer += middle - i;
            buffer[k++] = a[j++];
        }
    }
    while (i < middle) {
        buffer[k++] = a[i++];
    }
    while (j < right) {
        buffer[k++] = a[j++];
    }
    for (int p = left; p < right; ++p) {
        a[p] = buffer[p];
    }
    return answer;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 0 || n > 100000) {
        return 1;
    }
    std::vector<int> a(n);
    std::vector<int> buffer(n);
    for (int& value : a) {
        if (std::scanf("%d", &value) != 1) {
            return 1;
        }
    }
    std::printf("%lld\n", arrange(a, buffer, 0, n));
    return 0;
}
```

输入：

```text
4
8 3 6 3
```

输出：

```text
4
```

## 不同排序，省的是不同工作

插入排序把新数向前挪到合适位置，最坏 `O(n²)`，但接近有序时移动少。快速排序选一个轴，把小、大分到两侧再递归；分得坏会达 `O(n²)`，随机选轴使期望代价为 `O(n log n)`。重复值多时可分成小于、等于、大于三段。堆排序每次取堆顶，最坏 `O(n log n)`，下一些章节会亲手维护堆。

若值只有 0 到 100，开 101 个计数格，按值输出即可：计数排序为 `O(n+U)`，`U` 是值域大小。基数排序按一位一位稳定分桶，例如先个位再十位；前一位形成的顺序不能被后一轮随便打散。

只想要第 `k` 小，不一定全排。划分后只进入含第 `k` 项的一边，叫快速选择，随机轴的期望工作量 `O(n)`；`std::nth_element` 提供选择操作，但不把两侧各自排好。

## 大号码可以换成小名次

把出现过的不同值排好，用它的位置作新编号，叫**离散化**。`100, -7, 100, 40` 可变成 `2,0,2,1`。相等与大小关系保留，距离没有保留：新编号相差 1，不代表原值相差 1。

**停笔 3**　对 `50 10 50 30` 离散化。若题目求原坐标两点距离，只保存新编号够不够？

## 核对

1. 小林、小陈、小周。加了名字规则后，等分但不同名已不等价，由新规则决定先后。
2. 从 0 开始编号，是 `(0,1)`、`(0,2)`、`(0,3)`、`(2,3)`。改成 `<` 会把相等项也按右半较小的分支处理，多算逆序。
3. `2 0 2 1`。还需保存原坐标，或相邻原坐标差，不能用名次差冒充距离。
