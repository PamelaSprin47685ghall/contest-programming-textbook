# 05　每次划掉一半候选

猜数游戏：同桌心里想一个 1 到 100 之间的数，你每猜一次，他只说“大了”或“小了”。从 1 开始一个个猜，最坏要猜 100 次。先猜 50：若他说“大了”，51 到 100 一下子全划掉。再猜 25，又划掉一半。七次以内一定猜中，因为 100 对半分七次就不到 1 了。

[第 4 章](04-顺序能替我们保存信息.md)把数据排好了。这一章在排好的东西里找：**每问一次，划掉一半候选。**难处不在“对半”，而在说清两件事：每一轮手里剩下的候选是哪一段；找不到的时候停在哪里。后来会发现，要找的不一定是数组里的一个数，也可以是答案本身。

## 先说清没找到时停在哪里

在排好的一排数里找 target，最常要的不是“它在不在”，而是“第一个不小于 target 的数在哪里”。target 在里面，这就是它第一次出现的位置；不在里面，这就是它该插进去的位置；比所有数都大，答案是 n，表示“一个也没有”。

手里拿着两个下标 `left`、`right`，并且每一轮都让这句话成立：**[0, left) 里的数都小于 target，[right, n) 里的数都不小于 target。**开始时 `left` 是 0，`right` 是 n，两段都是空的，这句话当然成立。中间 [left, right) 是还没判定的候选。看中间那个数：它小于 target，它和它左边的就都小于 target，`left` 挪到它右边；否则它和它右边的都不小于 target，`right` 挪到它。每轮至少划掉一半，候选空了就停，`left` 等于 `right`，正是要找的位置。这样找的办法叫**二分查找**。

### 干草堆计数

一条路上有 N 个干草堆（N 到 10 万），位置各不相同，在 0 到 10⁹ 之间。Q 个询问（Q 到 10 万），每个询问给 A ≤ B，问位置在 A 到 B 之间（含两端）的干草堆有几个。

输入第一行 N 和 Q，第二行 N 个位置（不一定有序），之后 Q 行，每行一个询问。每个询问输出一行。

样例输入：

```text
4 6
3 2 7 5
2 3
2 4
2 5
2 7
4 6
8 10
```

样例输出：

```text
2
2
3
4
1
0
```

排好的位置是 2、3、5、7。[2, 3] 里有 2、3；[4, 6] 里只有 5；[8, 10] 里一个也没有。这是 USACO 2016 年 12 月银组第一题[“干草堆计数”](../USACO/银组/2016_2017/2016.12/P1.md)。

“位置在 A 到 B 之间”就是“不小于 A，而且小于 B + 1”。小于 B + 1 的有 `first_not_less(B + 1)` 个，小于 A 的有 `first_not_less(A)` 个，两者相减。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

// positions 已从小到大排好。返回第一个不小于 target 的下标；
// 全都小于 target 时，返回 positions 的长度
int first_not_less(const std::vector<int>& positions, int target) {
    int left = 0;
    int right = static_cast<int>(positions.size());
    // 每一轮都成立：[0, left) 里的都小于 target，[right, n) 里的都不小于 target
    while (left < right) {
        int middle = left + (right - left) / 2;
        if (positions[middle] < target) {
            left = middle + 1;
        } else {
            right = middle;
        }
    }
    return left;
}

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2) {
        return 1;
    }
    std::vector<int> positions(n);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d", &positions[i]) != 1) {
            return 1;
        }
    }
    std::sort(positions.begin(), positions.end());
    for (int i = 0; i < q; ++i) {
        int a = 0;
        int b = 0;
        if (std::scanf("%d%d", &a, &b) != 2) {
            return 1;
        }
        // 位置在 [a, b + 1) 里的干草堆
        std::printf("%d\n", first_not_less(positions, b + 1) - first_not_less(positions, a));
    }
    return 0;
}
```

`middle` 写成 `left + (right - left) / 2`，不写 `(left + right) / 2`：本题两者都放得进 `int`，但长度到 10⁹ 的下标或答案上，`left + right` 会溢出。`left < right` 时 `middle` 一定落在 [left, right) 里，所以 `positions[middle]` 不会越界。B + 1 最大是 10⁹ + 1，`int` 放得下。

每轮候选至少减半，一次查找最多约 17 轮；排序 O(N log N)，Q 个询问 O(Q log N)。

样例的询问 `8 10`：`first_not_less(11)` 和 `first_not_less(8)` 都找不到，都返回 4，答案 0。“没找到”不必另写分支，它就是一个合法的位置。

## 不容易直接求答案，可以先问能不能做到

有些题问“最小要多大才行”。直接求不好求，可是给一个具体的值，问“这么大行不行”，常常很好回答。若还满足：一个值行，比它大的值也都行，就可以在答案上做二分查找。“行不行”这个问题的答案从“不行”一路变到“行”，中间只变一次，这种性质叫**单调**。

### 愤怒的奶牛

数轴上有 N 个干草堆（N 到 50,000），位置互不相同，在 0 到 10⁹ 之间。有 K 头牛（K 到 10），威力都是同一个整数 R：一头牛落在 x，就炸掉 [x − R, x + R] 里的所有干草堆。问能用 K 头牛炸掉全部干草堆的最小的 R。

输入第一行 N 和 K，之后 N 行，每行一个位置。输出最小的 R。

样例输入：

```text
7 2
20
25
18
8
10
3
1
```

样例输出：

```text
5
```

排好是 1、3、8、10、18、20、25。R = 5 时，一头牛落在 6，炸掉 1 到 11 的四堆；另一头落在 23，炸掉 18 到 28 的三堆。R = 4 时，两头牛不够。这是 USACO 2016 年 1 月银组第一题[“愤怒的奶牛”](../USACO/银组/2015_2016/2016.01/P1.md)。

先回答：R 给定时，最少要几头牛？看最左边的那堆，总得有一头牛炸到它。这头牛落得越靠右，右边能顺带炸掉的越多，可它还得够得着最左那堆，所以落在“最左那堆 + R”。这样落，炸掉的是从最左那堆起、长 2R 的一段。别的落法够得着最左那堆，炸掉的部分也不会更多，因为左边已经没有要炸的了。炸完这一段，再看剩下的最左那堆，同样处理。这样数出来的头数就是最少的；不超过 K，就是“够”。

R 够，R + 1 也一定够：每头牛落在原地，炸的范围只大不小。所以“够不够”是单调的，可以二分。

**片段：**

```cpp
// positions 已从小到大排好。威力是 power 时，cows 头牛够不够炸掉全部干草堆
bool enough(const std::vector<int>& positions, int power, int cows) {
    int n = static_cast<int>(positions.size());
    int used = 0;
    int i = 0;
    while (i < n) {
        // 最左边还没炸掉的是 positions[i]；让一头牛落在 positions[i] + power
        ++used;
        long long reach = positions[i] + 2LL * power;
        while (i < n && positions[i] <= reach) {
            ++i;
        }
    }
    return used <= cows;
}
```

**片段：**

```cpp
// 位于 main 内；positions 已排好，k 是牛的头数
int low = 0;
int high = 500000000;      // 威力 5 × 10⁸ 时，一头牛就能炸掉 0 到 10⁹ 的全部
// 每一轮都成立：威力小于 low 都不够，威力 high 够
while (low < high) {
    int middle = low + (high - low) / 2;
    if (enough(positions, middle, k)) {
        high = middle;
    } else {
        low = middle + 1;
    }
}
std::printf("%d\n", low);
```

这两段合起来，和程序 A 是同一个样子：程序 A 找“第一个不小于 target 的下标”，这里找“第一个让 `enough` 为真的威力”。`low`、`high` 各自的意思写在注释里。威力的上限取 5 × 10⁸：炸掉的一段长 10⁹，什么位置都够。`reach` 最大约 2 × 10⁹，用 `long long`。

二分大约 29 轮，每轮 O(N)，加上排序。

## 小数也能二分，但停止方式不同

答案若是小数，同样可以问“x 行不行”，划掉一半区间。不同的是，实数区间划不到空：`low` 和 `high` 越来越近，却不会相等。所以不能写 `while (low < high)`，要另定什么时候停。

### 破坏

一排 N 台挤奶机（N 是 3 到 10 万），第 i 台产奶 Mᵢ（1 到 10,000）。保罗要拆掉连续的一段，这一段至少一台，而且不能包括第一台和最后一台。他想让剩下的机器平均产奶量最低。问这个最低的平均值，保留三位小数。

输入第一行 N，之后 N 行依次是各台的产奶量。输出最低平均值。

样例输入：

```text
5
5
1
7
8
2
```

样例输出：

```text
2.667
```

拆掉 7 和 8，剩下 5、1、2，平均 8/3 ≈ 2.667。这是 USACO 2014 年 3 月金组第二题[“破坏”](../USACO/金组/2013_2014/2014.03/P2.md)。

直接枚举要拆的那一段，约 N²/2 种，太多。改问：平均值能不能不超过 x？剩下的机器平均值不超过 x，就是它们的 (Mᵢ − x) 加起来不超过 0。全部机器的 (Mᵢ − x) 之和是固定的，要让剩下的和尽量小，就要让拆掉的那一段 (Mᵢ − x) 之和尽量大。

一段的和是两个前缀和之差，这在[第 3 章](03-先把重复的加法收起来.md)见过。右端固定时，要让差最大，就减去它左边最小的那个前缀和。从左往右扫，一边扫一边记最小的前缀和，像[第一卷第 4 章](../I/04-一次只看一个数.md)记“目前最小”那样。x 越大，越容易做到，单调成立。

**片段：**

```cpp
// milk 共 n 台（n ≥ 3）。能不能拆掉中间一段，让剩下的平均值不超过 x
bool can_reach(const std::vector<int>& milk, double x) {
    int n = static_cast<int>(milk.size());
    double total = 0;
    for (int i = 0; i < n; ++i) {
        total += milk[i] - x;
    }
    // 拆掉 [i, j)，1 ≤ i < j ≤ n - 1。prefix 是前 j 台的 milk - x 之和；
    // smallest 是 i 取 1 到 j - 1 时，前 i 台之和里最小的
    double smallest = milk[0] - x;
    double prefix = smallest + (milk[1] - x);
    double removed = prefix - smallest;
    for (int j = 3; j <= n - 1; ++j) {
        smallest = std::min(smallest, prefix);
        prefix += milk[j - 1] - x;
        removed = std::max(removed, prefix - smallest);
    }
    return total - removed <= 0;
}
```

**片段：**

```cpp
// 位于 main 内；milk 已读入
double low = 0;          // 平均值不超过 low 做不到
double high = 10000;     // 平均值不超过 high 做得到
for (int round = 0; round < 100; ++round) {
    double middle = (low + high) / 2;
    if (can_reach(milk, middle)) {
        high = middle;
    } else {
        low = middle;
    }
}
std::printf("%.3f\n", high);
```

拆掉的是 [i, j)，第一台的下标是 0、最后一台是 n − 1，所以 i 至少是 1，j 至多是 n − 1。`smallest` 一开始就是 i = 1 的前缀和，`removed` 一开始就是 j = 2 的那一段：n ≥ 3，这一段一定存在，不必拿一个很小的数当初值。

停止方式是固定做 100 轮。区间长度从 10,000 开始，每轮减半，100 轮以后远远小于 0.0005，三位小数不会受影响。每轮 O(N)，一共 100 × N 次左右。输出 `high`，因为“不超过 `high`”一直是做得到的。

拿样例核对 x = 3：Mᵢ − 3 是 2、−2、4、5、−1，总和 8。拆掉的一段最大是 4 + 5 = 9，8 − 9 = −1 ≤ 0，做得到，平均值确实能不超过 3。

**停笔 6**　把 `for` 循环改成 `while (low < high)`，程序可能怎样？说出 `low` 和 `high` 靠得极近时，`middle` 会等于什么。

这一章的例题都在划掉一半候选。“干草堆计数”划的是数组下标，靠一句每轮都成立的话说清找不到时停在哪里；“愤怒的奶牛”划的是答案本身，先把“最小要多大”换成“这么大够不够”，再用单调性二分；“破坏”的答案是小数，把平均值换成和，再固定轮数停下。能写出每轮都成立的那句话，并说清“行不行”为什么单调，再读下一章。下一章让两个下标一起往前走，已经走过的路不再回头。

## 核对

1. 第一轮 `left` = 0，`right` = 4，`middle` = 2，5 < 6，`left` 变成 3。第二轮 `middle` = 3，7 不小于 6，`right` 变成 3。`left` 等于 `right`，返回 3，即 7 所在的下标。
2. 例如一个干草堆在 2，找 target = 5。`left` = 0，`right` = 1，`middle` = 0，2 < 5，`left` 仍是 0，之后每轮都一样。`right - left` 为 1 时 `middle` 等于 `left`，必须让 `left` 越过 `middle`。
3. 三头牛落在 5、14、24：第一头炸 1、3、8，第二头炸 10、18，第三头炸 20、25。K = 3 时，R = 4 够了；R = 3 时要落在 4、11、21，还剩 25，要四头，所以答案是 4。
4. 对，单调性保证第一个够的就是最小的。可 R 最大要到约 5 × 10⁸，每次试还要 O(N)，太慢；二分只要约 29 次。
5. Mᵢ − 2.5 是 2.5、−1.5、4.5、5.5、−0.5，`total` = 10.5。中间可拆的段里和最大的是 4.5 + 5.5 = 10，`removed` = 10。10.5 − 10 = 0.5 > 0，返回 `false`：平均值不能压到 2.5。
6. 可能永远不停。`low` 和 `high` 是两个相邻的 `double` 时，`(low + high) / 2` 只能等于其中一个；若等于 `low` 又做不到，`low` 不变，下一轮还是这样。
