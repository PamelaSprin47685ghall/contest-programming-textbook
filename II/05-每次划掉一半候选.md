# 05　每次划掉一半候选

一本按页码排好的索引，不用从第一页开始找。先看中间：目标在后面，就把前半放下。能这样做，是因为已经知道顺序。

## 先说清没找到时停在哪里

在升序序列中找第一个不小于 `x` 的位置。保持半开区间 `[left,right)`，开始是整排。如果中间值小于 `x`，答案一定在它后面；否则中间值仍可能是答案，不能删掉它。

结束时 `left == right`。这个位置可以等于长度，表示所有元素都小于 `x`。标准库的 `std::lower_bound` 就做这种查找；`upper_bound` 找第一个严格大于 `x` 的位置。两者相减，可得排好序后 `x` 的出现次数。

**停笔 1**　在 `2 4 4 9` 中，对 4 和 10 分别写出这两个位置。位置等于 4 时能直接读取吗？

## 不容易直接求答案，可以先问能不能做到

一排木板必须按原顺序分给至多 `groups` 个工作组，每组接一段连续木板。每块的工作量为正整数。要让最忙那组的工作量尽量小。

先猜上限 `limit`。从左往右装给一组，再放一块会超上限，就开下一组。若开的组数不超过允许数，上限就可行。上限越大只会越容易，不会从可行又变不可行。这叫**单调性**。

为什么贪心检查可信？同一上限下，第一组尽量往后接，不会比其他合法分法更早结束。接着对剩下部分重复比较，贪心用了最少的组。

**完整程序：**输入 `1 <= n <= 100000`、`1 <= groups <= n`，再输入 `n` 个 1 到 10000 的工作量，输出最小上限。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

bool possible(const std::vector<int>& work, int groups, long long limit) {
    int used = 1;
    long long current = 0;
    for (int value : work) {
        if (value > limit) {
            return false;
        }
        if (current + value > limit) {
            ++used;
            current = 0;
        }
        current += value;
    }
    return used <= groups;
}

int main() {
    int n = 0;
    int groups = 0;
    if (std::scanf("%d%d", &n, &groups) != 2 || n < 1 || n > 100000 || groups < 1 || groups > n) {
        return 1;
    }
    std::vector<int> work(n);
    long long left = 0;
    long long right = 0;
    for (int& value : work) {
        if (std::scanf("%d", &value) != 1 || value < 1 || value > 10000) {
            return 1;
        }
        left = std::max(left, static_cast<long long>(value));
        right += value;
    }
    while (left < right) {
        long long middle = left + (right - left) / 2;
        if (possible(work, groups, middle)) {
            right = middle;
        } else {
            left = middle + 1;
        }
    }
    std::printf("%lld\n", left);
    return 0;
}
```

输入：

```text
3 2
2 3 4
```

输出：

```text
5
```

最小答案在最大单项与总和之间；右端总是可行。不可行就连中点一起删掉，可行则留下中点。每轮区间都严格变短，不会卡在相邻两个数之间。复杂度 `O(n log S)`，`S` 为总工作量。

## 小数也能二分，但停止方式不同

求非负数的平方根，可以比较 `middle*middle` 与原数，在足够大的区间中逐次缩小。这里不使用 `middle+1`：小数之间没有“下一个整数”。固定做一定轮数，或区间宽度小于约定误差后停止，并考虑数据大小及舍入。

若函数先严格下降再严格上升，可以比较两个分点，舍弃不可能含最小值的一侧，称为三分。没有单峰条件就不能使用；平坦段、离散端点和浮点误差也要单独处理。不要把“二分很快”误当成“任何答案都能二分”。

**停笔 3**　某个判断对候选 1、2、3、4、5 依次回答假、真、假、真、真。能按本章方法找第一个真吗？缺少什么条件？

## 核对

1. 对 4 是 1、3；对 10 是 4、4。末端没有可读元素。
2. 三组、两组、一组。区间 `[4,5]` 的中点为 4，只令左端等于中点就可能不动。
3. 不能使用相同的排除规则。必须先证明一旦可行，后面始终可行。
