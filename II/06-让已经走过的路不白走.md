# 06　让已经走过的路不白走

沿一条走廊连续看三间教室的温度。窗口向前一间，刚才第二、第三间还在，何必重新从零开始？

## 两个端点也可以一起往前

一排非负数中，找总和不超过 7 的最长连续段。右端逐项加入；若总和超出 7，就把左端逐项移出去，直到合法。左右端都不后退，各至多移动 `n` 次，所以是 `O(n)`，尽管代码里可能有两层循环。

依据是非负：左端前进不会让和增加，右端前进不会让和减少。若有负数，超标的一段可能再加一个负数而变合法，原先删掉左端就未必正确。

把排序后的一排数两头夹住寻找目标和，也是双指针。当前和太小则移左端，太大则移右端；每次排除的方案必须能由大小关系说明。要数重复值的位置对时，还要把同值的一整组数量算进去。

**停笔 1**　对 `2 1 4 2`、上限 7，画出右端逐步前进时的窗口。最长几项？为什么“两层循环一定平方级”是错的？

## 窗口里谁还有机会成为最大值

温度是 `4 2 5 1 3`，窗口宽度为 3。读到 5 时，左边的 4、2 都可从候选表删除：它们比 5 小，又比 5 更早离开窗口。在它们还在的时候，5 一定也在；以后它们再无成为最大值的机会。

候选表存**下标**，从前到后温度递减。新项加入前，从尾部删去不比它大的旧项；窗口前进时，从头部删去过期下标。两头都要操作，用 `deque`。

**完整程序：**输入 `1 <= k <= n <= 100000` 和 `n` 个 `int` 温度，逐行输出每个宽度为 `k` 的窗口最大值。

```cpp
#include <cstdio>
#include <deque>
#include <vector>

int main() {
    int n = 0;
    int k = 0;
    if (std::scanf("%d%d", &n, &k) != 2 || n < 1 || n > 100000 || k < 1 || k > n) {
        return 1;
    }
    std::vector<int> values(n);
    std::deque<int> candidates;
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d", &values[i]) != 1) {
            return 1;
        }
        while (!candidates.empty() && candidates.front() <= i - k) {
            candidates.pop_front();
        }
        while (!candidates.empty() && values[candidates.back()] <= values[i]) {
            candidates.pop_back();
        }
        candidates.emplace_back(i);
        if (i + 1 >= k) {
            std::printf("%d\n", values[candidates.front()]);
        }
    }
    return 0;
}
```

输入：

```text
5 3
4 2 5 1 3
```

输出：

```text
5
5
5
```

每个下标入队一次、出队至多一次，总时间 `O(n)`。某一轮能弹出很多项，并不代表每轮都会重复弹出它们。

**停笔 2**　宽度为 2、读数为 `5 5 1`。用 `<=` 删除旧候选时，第二个 5 为什么可以替代第一个？如果只存温度、不存位置，怎样判断过期？

## 只从一端删，就成了单调栈

要找每项右边第一个严格更大的数。向右扫描，把还没等到答案的下标压栈。新数比栈顶大，就取出栈顶，并给它登记当前下标；一直处理到栈顶不小于新数，再压入新下标。

被弹出的项为什么得到的是“第一个”？在它入栈后到现在，没有更大的数曾出现，否则早已把它弹出。相等时不能弹，因为问的是严格更大。这个**单调栈**同样每项只进出一次。

扫描线是同一种安排思路：把二维问题按一个坐标排好，沿这一维扫，另一维交给合适的数据结构维护。扫之前先定清同坐标事件的先后，否则“严格小于”可能错变成“小于等于”。

**停笔 3**　`2 2 1 3` 中，各项右边第一个严格更大值的下标是什么？没有答案用 −1。若想找大于等于，弹栈条件应怎样变？

## 核对

1. 最长三项，`2+1+4=7` 或 `1+4+2=7`。所有左端移动加起来至多 `n` 次，不是每个右端都从零重来。
2. 新 5 一样大、过期更晚，能承担旧 5 的所有机会。只存值无法区分同值来自哪个位置，必须另记时间或下标。
3. 从 0 编号，答案为 `3,3,3,-1`。找大于等于时，新值等于栈顶也可弹出。
