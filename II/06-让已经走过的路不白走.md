# 06　让已经走过的路不白走

学校门口的公交站贴着一张时刻表。小芳想知道：哪一段连续的一小时里，到站的车最多？她先看 7:00 到 8:00，数一遍；再看 7:05 到 8:05，又从头数一遍。其实第二段只是在第一段的基础上，去掉 7:00 到 7:05 来的车，加上 8:00 到 8:05 来的车。中间那些车已经数过了。

这一章练的是：**区间的两头都只往前走时，留住中间那一段的结果，只处理进来的和出去的。**先是两个端点一起往前；再问，一段数里最大的那个怎样跟着窗口走；最后，只从一端进出时，同样的想法变成了一个栈。

## 两个端点也可以一起往前

在一排排好的东西里找一段满足条件的连续区间，最直接的是枚举左端、再枚举右端，O(N²) 段。可是很多条件有这样的性质：左端往右挪，满足条件所需的最小右端不会往左退。这时右端只要接着上次的位置往右走，两个端点一共走 2N 步。

### 奶牛排队

N 头牛（N 到 50,000）站在一条直线上，每头牛有一个位置和一个品种编号，都是不超过 10⁹ 的正整数。约翰要拍一张照片，拍到的是位置在某一段里的全部牛，照片里每个出现过的品种都要至少有一头。照片的代价是拍到的牛里最大位置减最小位置。问最小代价。

输入第一行 N，之后 N 行，每行一头牛的位置和品种。输出最小代价。

样例输入：

```text
6
25 7
26 1
15 1
22 3
20 1
30 1
```

样例输出：

```text
4
```

一共三个品种 1、3、7。拍位置 22 到 26 的三头牛，品种是 3、7、1，代价 4。这是 USACO 2011 年 11 月银组第二题[“奶牛排队”](../USACO/银组/2011_2012/2011.11/P2.md)。

按位置排好，照片就是排好后连续的一段 [left, right)，代价是两头的位置差。固定 left，要的是凑齐全部品种的最短的那一段，也就是最小的 right。left 往右挪一格，窗口里少了一头牛，品种只会少不会多，所以新的最小 right 不会比原来小。right 只往右走。

窗口里每个品种有几头，用[第一卷第 16 章](../I/16-给数据一个可查的名字.md)的 `map` 记：牛进窗口，那个品种的头数加 1，从 0 变成 1 时，窗口里的品种数加 1；牛出窗口，反过来。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <map>
#include <set>
#include <vector>

struct Cow {
    int position;
    int breed;
};

bool comes_before(const Cow& a, const Cow& b) {
    return a.position < b.position;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<Cow> cows(n);
    std::set<int> breeds;
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d%d", &cows[i].position, &cows[i].breed) != 2) {
            return 1;
        }
        breeds.insert(cows[i].breed);
    }
    std::sort(cows.begin(), cows.end(), comes_before);
    int kinds = static_cast<int>(breeds.size());

    // 窗口是排好后的 [left, right)；in_window[b] 是窗口里品种 b 有几头
    std::map<int, int> in_window;
    int covered = 0;           // 窗口里出现了几个品种
    int right = 0;
    int best = cows[n - 1].position - cows[0].position;
    for (int left = 0; left < n; ++left) {
        while (right < n && covered < kinds) {
            ++in_window[cows[right].breed];
            if (in_window[cows[right].breed] == 1) {
                ++covered;
            }
            ++right;
        }
        if (covered < kinds) {
            break;             // 从 left 起一直到最后，也凑不齐了
        }
        best = std::min(best, cows[right - 1].position - cows[left].position);
        --in_window[cows[left].breed];
        if (in_window[cows[left].breed] == 0) {
            --covered;
        }
    }
    std::printf("%d\n", best);
    return 0;
}
```

`best` 的初值是整排牛的位置差：拍全部的牛一定合格。left 循环里，先让 right 走到凑齐为止；走到头也凑不齐，后面的 left 更凑不齐，直接停。凑齐时窗口里最后一头是 `cows[right - 1]`。

left 走 N 步，right 也最多走 N 步，每一步改一次 `map`，一共 O(N log N)，加上排序也是 O(N log N)。

“两个端点一起往前”有个名字，叫**双指针**；这里的“指针”只是两个下标，和[第一卷第 18 章](../I/18-谁在使用这块内存.md)的指针不是一回事。

对拍用的慢程序不用窗口，直接枚举坐标区间 [lo, hi] 的两端，把位置落在里面的牛的品种放进 `set`，看是不是全部品种。位置只取 1 到 12，这样同一位置站两头牛的情况也会出现。

## 窗口里谁还有机会成为最大值

窗口往前走时，若还要随时知道窗口里最大的数，就麻烦一些：最大的那个出了窗口，下一个最大的是谁？每次重扫一遍窗口太慢。

换个问法：窗口里哪些数**还有机会**成为最大值？一个数 a 比后来进窗口的 b 小或相等，a 就再也没有机会了：只要 a 还在窗口里，b 也在，而且 b 不比 a 小；a 先离开。所以 a 可以直接丢掉。丢完以后，留下的数按进窗口的先后排，大小一定从大到小。最大的在最前面；它离开窗口时，下一个就是新的最大值。

留下的这排数，新数从后面进，过期的从前面出，比新数小的也从后面出。两头都要进出，用[第一卷第 15 章](../I/15-按访问方式挑容器.md)的 `deque`。这种队列里的数总保持单调，叫**单调队列**。

### 拥挤的奶牛

N 头牛（N 到 50,000）站在栅栏旁，位置各不相同，第 i 头在 xᵢ、高 hᵢ（都在 1 到 10⁹）。一头牛左边距离 D 以内有一头至少比它高一倍的牛，右边距离 D 以内也有，它就觉得拥挤。问有几头牛觉得拥挤。

输入第一行 N 和 D，之后 N 行，每行 x 和 h。输出头数。

样例输入：

```text
6 4
10 3
6 2
5 3
9 7
3 6
11 2
```

样例输出：

```text
2
```

位置 5、高 3 的牛，左边 3 处有高 6 的，右边 9 处有高 7 的；位置 6、高 2 的牛也一样。别的牛总有一边找不到。这是 USACO 2013 年 11 月银组第二题[“拥挤的奶牛”](../USACO/银组/2013_2014/2013.11/P2.md)。

按位置排好。“左边距离 D 以内有没有至少高一倍的牛”，只要看左边距离 D 以内最高的那头。从左往右扫，窗口是“当前这头牛左边、距离不超过 D 的牛”，左端和右端都只往右走。

**片段：**

```cpp
// 位于 main 内；cows 已按位置排好，共 n 头，d 已读入
// left_tall[i]：第 i 头左边距离 d 以内，有没有至少两倍高的牛
std::vector<bool> left_tall(n, false);
std::deque<int> window;    // 下标；从队首到队尾，位置越来越靠右，高度越来越矮
for (int i = 0; i < n; ++i) {
    while (!window.empty() && cows[i].position - cows[window.front()].position > d) {
        window.pop_front();                 // 离得太远，以后只会更远
    }
    if (!window.empty() && cows[window.front()].height >= 2LL * cows[i].height) {
        left_tall[i] = true;
    }
    while (!window.empty() && cows[window.back()].height <= cows[i].height) {
        window.pop_back();                  // 比第 i 头矮，又比它先离开窗口
    }
    window.push_back(i);
}
```

三个 `while` 的次序有讲究。先把过期的从队首弹掉，这时队首就是窗口里最高的；查完再把第 i 头放进去，因为它不算自己左边的牛。比它矮或一样高的，从队尾弹掉。高度到 10⁹，乘 2 会超过 `int`，写成 `2LL * ...`。两个位置相减不超过 10⁹，所以写成“差大于 d”，不写成 `position < ... - d`；右边那一份要比“大于 position + d”，那样写会溢出。

右边那一份从右往左再扫一遍，比的是右边距离 D 以内最高的牛。两份都为真的牛就是拥挤的。每头牛进队一次、出队至多一次，扫描是 O(N)，加上排序。

## 只从一端删，就成了单调栈

单调队列丢掉的，是“被后来的数压住、再也没有机会”的数。若窗口的左端从不往右挪，就没有过期这回事，队首永远不出，只剩队尾进出。只在一头进出的序列是栈，所以这样维护的一排数叫**单调栈**。它常用来回答：每个数往左看，第一个比它高的在哪里？

### 奶牛飞盘

N 头牛（N 到 3 × 10⁵）排成一排，高度恰好是 1 到 N 的一个排列。位置 i < j 的两头牛能互相抛飞盘，当且仅当她们中间的每头牛都比两人中矮的那位还矮。一对能抛飞盘的牛，距离记作 j − i + 1。问所有能抛飞盘的对的距离之和。

输入第一行 N，第二行依次是各头牛的高度。输出总和。

样例输入：

```text
7
4 3 1 2 5 6 7
```

样例输出：

```text
24
```

能抛的位置对（从 1 数）是 (1, 2)、(1, 5)、(2, 3)、(2, 4)、(2, 5)、(3, 4)、(4, 5)、(5, 6)、(6, 7)，距离之和 2 + 5 + 2 + 3 + 4 + 2 + 2 + 2 + 2 = 24。这是 USACO 2022 年 1 月银组第二题[“奶牛飞盘”](../USACO/银组/2021_2022/2022.01/P2.md)。

从左往右看，轮到 j 时问：j 能和左边哪些牛抛？先看哪些 i 中间没有比 i 高的牛，也就是从 j 往左看过去、没被更近更高的牛挡住的那些牛。它们从近到远一个比一个高，正是一个单调栈：栈顶是 j − 1，往下越来越高。

这些牛里，能和 j 抛的还要满足：中间的牛也都比 hⱼ 矮。栈顶那些比 hⱼ 矮的牛，各自上面的牛都更矮，都能和 j 抛；它们以后都被 j 挡住了，弹出。弹完以后，栈顶若还有牛，它比 hⱼ 高，中间的牛刚才都弹掉了、都比 hⱼ 矮，它也能和 j 抛。再往下的牛和 j 之间隔着这头更高的牛，不能抛。

**片段：**

```cpp
// 位于 main 内；height 已读入，共 n 头，是 1 到 n 的一个排列
long long total = 0;
std::vector<int> stack;    // 下标；从栈底到栈顶，高度越来越矮
for (int j = 0; j < n; ++j) {
    while (!stack.empty() && height[stack.back()] < height[j]) {
        total += j - stack.back() + 1;      // 栈顶和 j 能抛飞盘
        stack.pop_back();
    }
    if (!stack.empty()) {
        total += j - stack.back() + 1;      // 留下的栈顶比 j 高，也能和 j 抛
    }
    stack.push_back(j);
}
std::printf("%lld\n", total);
```

每头牛进栈一次、出栈至多一次，所以整段是 O(N)，虽然 `for` 里套着 `while`，用的是[第 1 章](01-先问办法靠不靠谱.md)数整件事的办法。每个 j 加进去的对数，是弹出的个数再多一个，所以能抛的对不超过 2N 对；每对距离不超过 N，总和可到 10¹¹ 量级，要用 `long long`。高度是排列，不会有两头一样高，所以弹栈的条件用 `<` 和 `<=` 都一样。

三道例题都没有让已经处理过的东西重来。“奶牛排队”的左右端都只往右，窗口里的品种用 `map` 记账；“拥挤的奶牛”的窗口里只留下还有机会成为最高的牛；“奶牛飞盘”的窗口不再有左端，留下的牛排成一个单调栈，每头牛只进出一次。能说出窗口里留下的是哪些数、为什么被丢掉的数不会再有用，再读下一章。下一章换一种省法：一大步拆成几小步，小步可以提前准备好。

1. 排好后是 15(1)、20(1)、22(3)、25(7)、26(1)、30(1)。left = 0：right 走到 4，`covered` = 3，代价 10；15 出去后品种 1 还剩一头。left = 1：不用走，代价 5；20 出去后品种 1 没了，`covered` = 2。left = 2：right 走到 5，代价 4；22 出去，`covered` = 2。left = 3：right 走到 6 仍缺品种 3，`break`。答案 4。
