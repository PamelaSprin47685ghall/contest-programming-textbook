# 07　把一大步拆成几小步

折纸游戏：一张纸对折一次变成两层，再对折变成四层，折十次就是 1024 层。要是一层一层往上叠，得叠一千多次；对折只做了十次，因为每一次都把已经有的那一叠整个再叠一份。

这一章练的是：**要做很多次同样的事，就先准备好“做一次”“做两次”“做四次”……的结果，再把它们拼起来。**乘方是这样，一排牛按同一套规则换位置很多轮也是这样。最后一节换一个方向：一件事分成前后两半，各自做完，在中间对上。

## 每次只解决一半

先看一个小问题：3 的 13 次方除以 1000 余几？

一次乘一个 3，要乘 12 次。13 大了还好说，指数到 10¹⁸ 就乘不完。可是 3¹³ = 3⁶ × 3⁶ × 3：只要知道 3⁶，再乘两次就行。3⁶ = 3³ × 3³，3³ = 3¹ × 3¹ × 3，3¹ = 3⁰ × 3⁰ × 3。指数每次减半，一共只往下问了四层。

这正是[第 2 章](02-把选择走成一棵树.md)的递归：函数把“指数一半”的那件事交给自己。

**片段：**

```cpp
// 返回 base 的 exponent 次方除以 mod 的余数；base、mod 都不超过 2 × 10⁹
long long power(long long base, long long exponent, long long mod) {
    if (exponent == 0) {
        return 1 % mod;
    }
    long long half = power(base, exponent / 2, mod);
    long long result = half * half % mod;
    if (exponent % 2 == 1) {
        result = result * (base % mod) % mod;
    }
    return result;
}
```

指数是偶数时，结果是一半的平方；是奇数时，再多乘一个底数。每一层都先取余，所以每次相乘的两个数都小于 `mod`，乘积小于 4 × 10¹⁸，`long long` 放得下。取余可以随时做，因为乘积除以 `mod` 的余数，只取决于两个因数各自的余数。`exponent` 为 0 时返回 `1 % mod`，不是 1：`mod` 等于 1 时，任何数的余数都是 0。

指数每层减半，到 0 要约 log₂ exponent 层，指数 10¹⁸ 时约 60 层。这种做法叫**快速幂**。

## 平方一次，等于准备两份相同的路

递归是从上往下拆；也可以从下往上拼。把指数写成二进制：13 是 `1101`，也就是 8 + 4 + 1，所以 3¹³ = 3⁸ × 3⁴ × 3¹。底数自己乘自己，依次得到 3¹、3²、3⁴、3⁸……，每平方一次，指数翻一倍；指数的二进制哪一位是 1，就把那一项乘进结果。

**片段：**

```cpp
const long long MOD = 1000000007;

// 返回 base 的 exponent 次方除以 MOD 的余数
long long power(long long base, long long exponent) {
    long long result = 1;
    base %= MOD;
    // 每一轮开始时：所求 = result × base 的 exponent 次方（都按 MOD 取余）
    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result = result * base % MOD;
        }
        base = base * base % MOD;
        exponent /= 2;
    }
    return result;
}
```

循环每转一圈都成立的那句话写在注释里。开始时 `result` 是 1，那句话就是题目本身；`exponent` 是奇数时，从 base 的 exponent 次方里拿出一个 base 乘进 `result`；然后 base 平方、exponent 减半，那句话仍然成立。`exponent` 到 0，所求就是 `result`。`exponent % 2` 和 `exponent /= 2` 就是在读二进制的最低位、再去掉它，和[第 2 章](02-把选择走成一棵树.md)的 `(mask >> i) & 1` 读的是同一种东西。

### 奶牛写诗

贝茜认识 N 个词（N 到 5000），第 i 个词有 sᵢ 个音节（1 到 K），属于韵脚类 cᵢ（1 到 N）。她要写一首 M 行的诗（M 到 10⁵），每行恰好 K 个音节（K 到 5000），一行就是一串词，词可以重复用。韵脚格式给每行一个大写字母，字母相同的行，最后一个词必须属于同一个韵脚类；字母不同的行没有要求。问能写出几首诗，答案除以 1,000,000,007 取余。

输入第一行 N、M、K；之后 N 行，每行 sᵢ 和 cᵢ；再之后 M 行，每行一个字母。输出方案数。

样例输入：

```text
3 3 10
3 1
4 1
3 2
A
B
A
```

样例输出：

```text
960
```

凑满 10 个音节、以韵脚类 1 收尾的一行有 8 种写法，以韵脚类 2 收尾的有 4 种。第 1、3 行是 A，要同一类：8² + 4² = 80 种；第 2 行是 B：8 + 4 = 12 种。80 × 12 = 960。这是 USACO 2019 年 1 月金组第一题[“奶牛写诗”](../USACO/金组/2018_2019/2019.01/P1.md)。

先数一行。`ways[s]` 记“音节恰好凑成 s 的词串有几种”：最后一个词是 w，前面就是凑成 s − s_w 的一串，所以 `ways[s]` 是所有 `ways[s - s_w]` 之和，`ways[0]` 是 1（什么词都不放）。一行以韵脚类 c 收尾的写法数 `ending[c]`，就是把最后一个词固定成 c 类的某个词，前面凑成 K − s_w。这种“用小的格子填大的格子”的表，[第 8 章](08-给已经解决的小问题留个位置.md)会专门讲；这里它只是几行加法。

再看整首诗。字母 e 出现了 m 次，这 m 行要选同一个韵脚类 c，各行独立地写，有 `ending[c]` 的 m 次方种；对所有 c 加起来。不同字母之间互不相干，相乘。m 最大 10⁵，韵脚类最多 5000 种，一次次乘要 5 × 10⁸ 次；用快速幂，每次约 17 圈。

**片段：**

```cpp
// 位于 main 内；n 个词的 syllables、rhyme 已读入，k 是每行音节数，
// letter_count[e] 是韵脚格式里字母 e 出现的行数
// ways[s]：音节数加起来恰好是 s 的词串有几种（按 MOD 取余）
std::vector<long long> ways(k + 1, 0);
ways[0] = 1;
for (int s = 1; s <= k; ++s) {
    for (int w = 0; w < n; ++w) {
        if (syllables[w] <= s) {
            ways[s] = (ways[s] + ways[s - syllables[w]]) % MOD;
        }
    }
}
// ending[c]：一整行恰好 k 个音节、最后一个词属于韵脚类 c，有几种
std::vector<long long> ending(n + 1, 0);
for (int w = 0; w < n; ++w) {
    ending[rhyme[w]] = (ending[rhyme[w]] + ways[k - syllables[w]]) % MOD;
}
long long answer = 1;
for (int e = 0; e < 26; ++e) {
    if (letter_count[e] == 0) {
        continue;
    }
    long long sum = 0;     // 字母 e 的那些行一起选一个韵脚类
    for (int c = 1; c <= n; ++c) {
        sum = (sum + power(ending[c], letter_count[e])) % MOD;
    }
    answer = answer * sum % MOD;
}
std::printf("%lld\n", answer);
```

建 `ways` 要 K × N 次加法，约 2.5 × 10⁷。每次乘法前两个数都小于 MOD，乘积小于 10¹⁸ 多一点，放得进 `long long`。

## 连走很多次，也能提前准备

乘方能拆，是因为“乘 8 次 3”等于“先乘 4 次，再乘 4 次”。很多别的操作也能这样拆：一套规则做 K 轮，等于先做 K/2 轮，再做 K/2 轮。只要能把“做一轮的效果”写成一个对象，再写出“两个效果接起来”是什么，就能照搬快速幂。

### 翻转再翻转

N 头牛（N 到 10 万）排成一排，从左数第 i 头编号为 i。约翰给出 M 个区间（M 到 100），一轮流程是：依次把第 Lᵢ 到第 Rᵢ 个位置上的牛整段翻转。这一轮流程要做 K 次（K 到 10⁹）。问最后每个位置上是几号牛。

输入第一行 N、M、K，之后 M 行，每行 Lᵢ 和 Rᵢ（Lᵢ < Rᵢ）。输出 N 行。

样例输入：

```text
7 2 2
2 5
3 7
```

样例输出：

```text
1
2
4
3
5
7
6
```

第一轮：[1, 2, 3, 4, 5, 6, 7] 翻转第 2 到 5 个变成 [1, 5, 4, 3, 2, 6, 7]，再翻转第 3 到 7 个变成 [1, 5, 7, 6, 2, 3, 4]。第二轮照做，得到样例输出。这是 USACO 2020 年 2 月银组第一题[“翻转再翻转”](../USACO/银组/2019_2020/2020.02/P1.md)。

做一轮要 O(NM)，做 K 轮来不及。但一轮的效果是固定的：做完一轮，位置 i 上站的，总是这一轮开始时位置 `step[i]` 上的牛，与开始时站的是谁无关。`step` 可以这样得到：让 0、1、2、……号站好，照着翻转一轮，最后每个位置上的号码就是 `step`。

两个效果怎样接起来？先做 `first`，位置 j 上是原来 `first[j]` 上的牛；再做 `second`，位置 i 上是刚才 `second[i]` 上的牛，也就是原来 `first[second[i]]` 上的牛。这就是 `compose`。`step` 接上自己，是两轮的效果；再接上自己，是四轮。这种每次把步数翻倍、准备好 1、2、4、8……步结果的做法，叫**倍增**。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

// 一轮流程的效果写成 move：做完一轮，位置 i 上站的是原来位置 move[i] 上的牛。
// 先做 first、再做 second，位置 i 上站的是原来位置 first[second[i]] 上的牛
std::vector<int> compose(const std::vector<int>& first, const std::vector<int>& second) {
    int n = static_cast<int>(first.size());
    std::vector<int> result(n);
    for (int i = 0; i < n; ++i) {
        result[i] = first[second[i]];
    }
    return result;
}

int main() {
    int n = 0;
    int m = 0;
    long long k = 0;
    if (std::scanf("%d%d%lld", &n, &m, &k) != 3) {
        return 1;
    }
    std::vector<int> step(n);
    for (int i = 0; i < n; ++i) {
        step[i] = i;
    }
    for (int i = 0; i < m; ++i) {
        int left = 0;
        int right = 0;
        if (std::scanf("%d%d", &left, &right) != 2) {
            return 1;
        }
        // 题目的第 left 到第 right 个位置，是程序里的 [left - 1, right)
        std::reverse(step.begin() + (left - 1), step.begin() + right);
    }
    // answer：已经做了的那些轮的效果，一开始是“一轮也没做”
    std::vector<int> answer(n);
    for (int i = 0; i < n; ++i) {
        answer[i] = i;
    }
    // 每一轮循环开始时，step 是 2^j 轮的效果，k 是还没处理的那几位
    while (k > 0) {
        if (k % 2 == 1) {
            answer = compose(answer, step);
        }
        step = compose(step, step);
        k /= 2;
    }
    for (int i = 0; i < n; ++i) {
        std::printf("%d\n", answer[i] + 1);
    }
    return 0;
}
```

`std::reverse` 见[第一卷第 14 章](../I/14-旋转、比较规则与排列.md)，它翻转半开区间，所以题目的第 left 到第 right 个位置写成 `begin() + (left - 1)` 到 `begin() + right`。主循环和上一节的 `power` 一模一样，只是乘法换成了 `compose`。`compose(answer, step)` 先做 `answer` 再做 `step`，次序反过来也一样：它们都是同一个 `step` 接了若干次，先接几次后接几次，结果相同。一般的两个效果，次序不能随便换。

翻转一轮最多 M × N = 10⁷ 次交换，之后约 30 次 `compose`，每次 O(N)。

对拍的慢程序老老实实做 K 轮翻转，生成器把 K 限在 40 以内，N 在 8 以内。

## 从两头各走一半，在中间对上

还有一种“拆成两半”，拆的不是步数，而是选择。N 个是非决定一起枚举有 2ᴺ 种，N = 40 时约 10¹²，来不及。可是前 20 个各有 2²⁰ ≈ 10⁶ 种，后 20 个也是。前一半的每种选法，要配上后一半的哪些选法才合格？若这个问题能靠查找回答，就只需各枚举 10⁶ 种，再配对。这种做法叫**折半搜索**。

### 机器人指令

机器人从原点出发，要停在 (x_g, y_g)。有 N 条指令（N 到 40），第 i 条让它向右走 xᵢ、向上走 yᵢ（负数表示向左、向下；坐标绝对值都不超过 10⁹）。对每个 K = 1 到 N，问选出 K 条指令、让机器人恰好停在目标点的选法有几种。目标点不是原点，每条指令也不是 (0, 0)。

输入第一行 N，第二行 x_g 和 y_g，之后 N 行，每行一条指令。输出 N 行。

样例输入：

```text
7
5 10
-2 0
3 0
4 0
5 0
0 10
0 -10
0 10
```

样例输出：

```text
0
2
0
3
0
1
0
```

横向要凑出 5：{5}、{−2, 3, 4}。纵向要凑出 10：{10} 有两种（两条 `0 10` 选一条），{10, −10, 10} 一种。横向 1 条配纵向 1 条有 2 种，K = 2；横 1 配纵 3 有 1 种、横 3 配纵 1 有 2 种，K = 4 共 3 种；横 3 配纵 3 有 1 种，K = 6。这是 USACO 2022 年 2 月银组第二题[“机器人指令”](../USACO/银组/2021_2022/2022.02/P2.md)。

前一半选出的指令总位移是 (a, b)，后一半就必须正好补上 (x_g − a, y_g − b)。把后一半每种选法的位移换成“目标减去它”，问题就变成：前一半的位移和后一半换过的位移相等。两份都按位移排好，像[第 4 章](04-顺序能替我们保存信息.md)合并两排那样，从开头往后走，相等的一组碰到相等的一组，就把条数配起来。

**片段：**

```cpp
struct Record {
    long long x;
    long long y;
    int count;     // 用了几条指令
};

bool comes_before(const Record& a, const Record& b) {
    if (a.x != b.x) {
        return a.x < b.x;
    }
    return a.y < b.y;
}

// 指令 [from, to) 的每个子集，各算一份 (总位移, 条数)
std::vector<Record> all_subsets(const std::vector<long long>& dx, const std::vector<long long>& dy,
                                int from, int to) {
    int size = to - from;
    std::vector<Record> records;
    for (int mask = 0; mask < (1 << size); ++mask) {
        Record r{0, 0, 0};
        for (int i = 0; i < size; ++i) {
            if (((mask >> i) & 1) == 1) {
                r.x += dx[from + i];
                r.y += dy[from + i];
                ++r.count;
            }
        }
        records.push_back(r);
    }
    std::sort(records.begin(), records.end(), comes_before);
    return records;
}
```

**片段：**

```cpp
// 位于 main 内；n 条指令 dx、dy 和目标 goal_x、goal_y 已读入
int half = n / 2;
std::vector<Record> front = all_subsets(dx, dy, 0, half);
std::vector<Record> back = all_subsets(dx, dy, half, n);
// 后一半要补上的位移，是目标减去它；这样两边找的就是“相等”
for (Record& r : back) {
    r.x = goal_x - r.x;
    r.y = goal_y - r.y;
}
std::sort(back.begin(), back.end(), comes_before);
std::vector<long long> answer(n + 1, 0);
std::size_t j = 0;
for (std::size_t i = 0; i < front.size(); ) {
    // front 里位移相同的一组是 [i, i_end)
    std::size_t i_end = i;
    std::vector<long long> by_count(n + 1, 0);
    while (i_end < front.size() && !comes_before(front[i], front[i_end])) {
        ++by_count[front[i_end].count];
        ++i_end;
    }
    while (j < back.size() && comes_before(back[j], front[i])) {
        ++j;
    }
    // back 里和这组位移相同的，都和这组里每个子集配成一个答案
    for (std::size_t t = j; t < back.size() && !comes_before(front[i], back[t]); ++t) {
        for (int c = 0; c + back[t].count <= n; ++c) {
            answer[c + back[t].count] += by_count[c];
        }
    }
    i = i_end;
}
for (int k = 1; k <= n; ++k) {
    std::printf("%lld\n", answer[k]);
}
```

`by_count[c]` 是前一半里位移相同、用了 c 条指令的选法数。后一半里每个位移相同的选法，都和这组里的每一个配成一种答案，条数相加。`j` 只往前走：前一半的位移越来越大，后一半要找的也越来越大。

两半各 2²⁰ 种，排序 O(2²⁰ × 20)。配对时，后一半每条记录至多和一组前一半配上，每次加 N 个数，一共约 4 × 10⁷ 次。位移之和到 2 × 10¹⁰，用 `long long`。

## 核对

1. 最里层 `exponent` = 0，返回 1。往外一层 `exponent` = 1，`half` = 1，返回 3。`exponent` = 3，`half` = 3，返回 3 × 3 × 3 = 27。`exponent` = 6，`half` = 27，返回 729。`exponent` = 13，`half` = 729，729 × 729 = 531,441，余 441，再乘 3 得 1323，余 323。
2. `ways` 是 1、0、0、2、1、0、4、4：`ways[3]` 有两个三音节词；`ways[4]` 是那个四音节词；`ways[6]` = 2 × `ways[3]`；`ways[7]` = 2 × `ways[4]` + `ways[3]`。`ending[1]` = `ways[7]`（最后是三音节的 1 类词）+ `ways[6]`（最后是四音节词）= 8；`ending[2]` = `ways[7]` = 4。
3. `step` 是 0、4、6、5、1、2、3（第一轮结束时位置 i 上是原来的几号，减 1）。两轮是 `compose(step, step)`：位置 i 上是原来 `step[step[i]]` 号，依次是 0、1、3、2、4、6、5，加 1 正是样例输出。
4. 5 是二进制 `101`。第一圈：最低位是 1，`answer` 是 1 轮，`step` 变成 2 轮。第二圈：这一位是 0，`answer` 仍是 1 轮，`step` 变成 4 轮。第三圈：这一位是 1，`answer` 是 1 + 4 = 5 轮，`step` 变成 8 轮，`k` 变成 0，结束。
5. 2²⁰ × 2²⁰ ≈ 1.1 × 10¹² 次。两份都排好了，位移不相等的一对根本不去碰：`j` 跳过比当前小的，`t` 只走过相等的那一段。
