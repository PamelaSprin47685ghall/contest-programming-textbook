# 08　给已经解决的小问题留个位置

上台阶时，一次能上一级或两级。到第四级有几种走法？若直接画出所有路线，会反复遇到“剩下两级怎样走”这个相同问题。

## 表格里每个数都要有一句含义

令 `ways[i]` 表示恰好走到第 `i` 级的走法数。最后一步要么来自 `i-1`，要么来自 `i-2`，两类不重合，因此可以相加。

`ways[0]=1`：什么也不做，是到起点的一种走法。`ways[1]=1`，随后为 2、3、5。先算小下标，再算大下标，所需答案都已经准备好了。

把重复的小问题合并，保存结果，按依赖顺序计算，叫**动态规划**，常写 DP。记忆化搜索则仍按递归请求答案，第一次算完存下，再遇到直接返回。两者都要先有正确的状态含义，不能把任何一张表都叫 DP。

**停笔 1**　上五级有几种走法？如果把 `ways[0]` 设成 0，哪一类完整走法会从计算里消失？

## 从“剩下什么”看，怎样才能合并

两个过去不同的选择，只要对以后允许的动作及其代价有完全相同的影响，就能归到同一状态。若过去是否拿过红卡还会改变未来，只记重量就不够，必须把这个信息加入状态。

不一定保存所有过去。最大价值问题中，状态相同，只保留价值最大的方案；较差的在以后也不会翻身。计数问题却不能只保留一份，必须把属于同一状态的数量相加。

## 每件只能拿一次

`best[c]` 表示“已考虑过的物品里，总重量不超过 `c` 时的最大价值”。全为零是因为允许什么也不拿。处理重量 `w`、价值 `v` 的物品，比较不拿与拿：`best[c-w]+v`。

**完整程序：**输入 `0 <= n <= 1000`、`0 <= capacity <= 10000`，每件给重量 1 到 10000、价值 0 到 10000。每件最多一件，输出容量内的最大总价值。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    int capacity = 0;
    if (std::scanf("%d%d", &n, &capacity) != 2 || n < 0 || n > 1000
        || capacity < 0 || capacity > 10000) {
        return 1;
    }
    std::vector<int> best(capacity + 1, 0);
    for (int i = 0; i < n; ++i) {
        int weight = 0;
        int value = 0;
        if (std::scanf("%d%d", &weight, &value) != 2 || weight < 1 || weight > 10000
            || value < 0 || value > 10000) {
            return 1;
        }
        for (int c = capacity; c >= weight; --c) {
            best[c] = std::max(best[c], best[c - weight] + value);
        }
    }
    std::printf("%d\n", best[capacity]);
    return 0;
}
```

输入：

```text
3 5
2 4
3 5
4 8
```

输出：

```text
9
```

这是 **0/1 背包**。容量倒着走，`best[c-weight]` 还没有处理当前物品，所以不会重复使用它。时间 `O(n*capacity)`，空间 `O(capacity)`。这不是按输入数字的位数衡量的多项式算法；容量一万与容量十亿是不同问题。

若每种物品可取不限次，容量正着走，才会让本轮结果继续参与。这叫完全背包。每种至多 `k` 件，可以拆成 1、2、4 等大小的成组物品及最后余数，再做 0/1 背包；拆分必须能表达 0 到 `k` 的每个数量。

## “不超过”与“恰好”不是同一张表

若要求恰好装满，不能把所有容量都初始化成可行的零价值。应只让重量 0 可行，其余标记不可达；转移前先检查来源可达。负无穷哨兵不能随便参与加法。

最长严格上升子序列也能用 DP。`length[i]` 表示以第 `i` 项结束的最大长度；从所有 `j<i` 且 `a[j]<a[i]` 的位置接过来，取最大再加一。找不到来源就为 1，答案是所有结束位置的最大值。这里不要求所选位置连续。

`3 1 2` 的答案是 2，不是连续排序整排。直接检查每个前驱为 `O(n²)`；以后把“按数值查最大长度”交给数据结构，可再加速。

## 核对

1. 8 种。`ways[0]` 为零会丢掉以一次两级从起点跳出的路线，并进一步影响后续计数。
2. 应为 3；正向会重复使用同一物品，错误地得到 6。
3. 2；不下降改为 `a[j] <= a[i]`。恰好装满 3 不可达，应报告无解，不是假装有一份价值零的方案。
