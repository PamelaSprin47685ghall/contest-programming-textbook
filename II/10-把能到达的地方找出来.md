# 10　把能到达的地方找出来

走进一座没去过的大楼找会议室，最笨的办法是记下走过的每一个门口：这一层还有哪些门没推开，推开以后又通到哪里。只要每个门口只进一次，楼再大也有走完的时候。

这一章先把“地方”和“通道”写成程序能存的样子，再练两种走法：一种是一圈圈往外扩，先把一步能到的都看完，再看两步能到的；另一种是沿一条路一直走到尽头，再退回来换一条。

## 地点是点，通道是边

把每个地方叫作一个**点**，两个地方之间的通道叫作一条**边**，一组点和边合起来叫作**图**。双向的通道是无向边，只能单向走的是有向边。走廊、传送带、“谁把消息转给谁”“哪两种状态之间差一步”，都能写成边。

程序里最常用的存法，是给每个点开一个 `std::vector`，记下从它走一步能到的点。这叫**邻接表**。

**片段：**

```cpp
// 位于 main 内；n 个地点、m 条双向通道，地点从 0 编号
std::vector<std::vector<int>> adj(n);     // adj[u]：从 u 走一步能到的地点
for (int i = 0; i < m; ++i) {
    int a = 0;
    int b = 0;
    if (std::scanf("%d%d", &a, &b) != 2) {
        return 1;
    }
    adj[a].push_back(b);
    adj[b].push_back(a);    // 双向通道，两头都要记；单向的只记这一头
}
for (int u = 0; u < n; ++u) {
    std::printf("%d:", u);
    for (int v : adj[u]) {
        std::printf(" %d", v);
    }
    std::printf("\n");
}
```

比如 5 个地点、5 条双向通道 0–1、0–2、1–2、2–3、3–4，输出是：

```text
0: 1 2
1: 0 2
2: 0 1 3
3: 2 4
4: 3
```

每条无向边在表里出现两次，所以所有列表的长度加起来是 2M。存下来要 O(N + M) 的空间；要遍历“从 u 走一步能到哪”，就扫一遍 `adj[u]`。

也可以开一个 N × N 的 `bool` 表，第 a 行第 b 列记“a、b 之间有没有边”。点少时这样写更直接；点到 10⁵ 时，表有 10¹⁰ 格，放不下，而邻接表只存真有的边。

## 先看一步，再看两步

### 背驮同行

贝茜和埃尔茜要从各自的草地走回谷仓。N 块草地（N 到 40000）由 M 条双向连接相连，贝茜从 1 号出发，埃尔茜从 2 号出发，谷仓是 N 号。贝茜每走一条连接耗 B 单位能量，埃尔茜耗 E；两头牛在同一块草地时，贝茜可以驮着埃尔茜一起走，每条连接耗 P。问两头牛都到谷仓，最少一共耗多少能量。

输入第一行 B、E、P、N、M，都是不超过 40000 的正整数；之后 M 行，每行一条连接的两端。保证从 1 号和 2 号都能走到 N 号。输出最少的总能量。

样例输入：

```text
4 4 5 8 8
1 4
2 3
3 4
4 7
2 5
5 6
6 8
7 8
```

样例输出：

```text
22
```

贝茜走 1–4，耗 4；埃尔茜走 2–3–4，耗 8；两头牛在 4 号会合，一起走 4–7–8，耗 10。共 22。这是 USACO 2014 年 12 月银组第一题[“背驮同行”](../USACO/银组/2014_2015/2014.12/P1.md)。

先把方案拆开。两头牛总要在某块草地 meet 会合（不会合就当作在谷仓会合），会合前各走各的，会合后一起走。三段路各自一定走最少的边数，否则换成更短的那条只会更省。所以只要知道三件事：从 1 号、从 2 号、从谷仓到每块草地最少走几条边。

“最少走几条边”可以一圈圈求。起点是第 0 圈。和起点相邻、还没到过的点是第 1 圈。和第 1 圈相邻、还没到过的点是第 2 圈……每个点第一次被碰到时所在的那一圈，就是它的最少边数：要是有更短的路，它会在更早的一圈就被碰到。按圈处理，用一个队列就够：先进队的点先处理，第 k 圈的点都在第 k + 1 圈的点前面出队。这种走法叫**广度优先搜索**，常简称 BFS。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <queue>
#include <vector>

// 从 start 出发，每个草地最少要走几条边；到不了的记 -1
std::vector<int> steps_from(const std::vector<std::vector<int>>& adj, int start) {
    std::vector<int> dist(adj.size(), -1);
    std::queue<int> pending;
    dist[start] = 0;
    pending.push(start);
    while (!pending.empty()) {
        int u = pending.front();
        pending.pop();
        for (int v : adj[u]) {
            if (dist[v] == -1) {
                // 第一次碰到 v，就是从离 start 最近的那一层碰到的
                dist[v] = dist[u] + 1;
                pending.push(v);
            }
        }
    }
    return dist;
}

int main() {
    int cost_b = 0;
    int cost_e = 0;
    int cost_p = 0;
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d%d%d%d", &cost_b, &cost_e, &cost_p, &n, &m) != 5) {
        return 1;
    }
    std::vector<std::vector<int>> adj(n);
    for (int i = 0; i < m; ++i) {
        int a = 0;
        int b = 0;
        if (std::scanf("%d%d", &a, &b) != 2) {
            return 1;
        }
        // 题目从 1 编号，这里改成从 0 编号；通道是双向的，两头都记
        adj[a - 1].push_back(b - 1);
        adj[b - 1].push_back(a - 1);
    }
    std::vector<int> from_bessie = steps_from(adj, 0);
    std::vector<int> from_elsie = steps_from(adj, 1);
    std::vector<int> from_barn = steps_from(adj, n - 1);

    // 在 meet 会合：各自走最短路过去，再一起走最短路到谷仓。不会合就是在谷仓会合
    long long best = -1;
    for (int meet = 0; meet < n; ++meet) {
        if (from_bessie[meet] < 0 || from_elsie[meet] < 0 || from_barn[meet] < 0) {
            continue;
        }
        long long total = 1LL * cost_b * from_bessie[meet] + 1LL * cost_e * from_elsie[meet]
                          + 1LL * cost_p * from_barn[meet];
        if (best < 0 || total < best) {
            best = total;
        }
    }
    std::printf("%lld\n", best);
    return 0;
}
```

`dist` 同时记两件事：是 −1 说明还没碰到过，否则是最少边数。每个点进队一次，每条边从两头各看一次，一次 BFS 是 O(N + M)，三次也是。能量是边数乘系数，到 4 × 10⁴ × 4 × 10⁴ = 1.6 × 10⁹，三项相加会超过 `int`，所以先乘 `1LL`。

我写了一个不拆三段的检查程序：状态是“贝茜在哪、埃尔茜在哪”，每一步让一头牛走、或者两头在同一处时一起走，反复松弛直到不再变小。对 N 到 8 的四百张随机图，它和程序 A 的答案全部相同。

### 牛奶桶

约翰有两只空桶，容量 X 和 Y（都到 100），要凑 M 单位牛奶（M 到 200）。他至多做 K 次操作（K 到 100），每次是下面之一：装满一只桶；倒空一只桶；把一只桶倒进另一只，直到前者空或后者满。他也许凑不出恰好 M。两只桶里的总量与 M 最少差多少？

输入一行 X、Y、K、M，输出最小的差。

样例输入：

```text
14 50 2 32
```

样例输出：

```text
18
```

两步之内，总量能是 0、14、50、64，最接近 32 的是 14 和 50，都差 18。这是 USACO 2016 年 2 月银组第三题[“牛奶桶”](../USACO/银组/2015_2016/2016.02/P3.md)。

这里的“地方”是两只桶的一种装法 (a, b)，共 (X + 1) × (Y + 1) 种；一次操作就是一条边。题目问的是至多 K 步能到哪些状态，正好是一圈圈往外扩：第 step 圈是至多 step 步能到的状态。这种用状态做点的图，常叫**状态图**；图不必先存下来，每个状态的六条边当场算出。

**片段：**

```cpp
// 位于 main 内；x、y、k、m 已读入
// can[a][b]：至多走 step 步，能不能让两桶分别装 a 和 b
std::vector<std::vector<bool>> can(x + 1, std::vector<bool>(y + 1, false));
can[0][0] = true;
for (int step = 0; step < k; ++step) {
    std::vector<std::vector<bool>> next = can;    // 允许什么也不做，原来的状态都留着
    for (int a = 0; a <= x; ++a) {
        for (int b = 0; b <= y; ++b) {
            if (!can[a][b]) {
                continue;
            }
            next[x][b] = true;      // 装满第一只
            next[a][y] = true;      // 装满第二只
            next[0][b] = true;      // 倒空第一只
            next[a][0] = true;      // 倒空第二只
            int to_second = std::min(a, y - b);
            next[a - to_second][b + to_second] = true;
            int to_first = std::min(b, x - a);
            next[a + to_first][b - to_first] = true;
        }
    }
    can = next;
}
int best = m;
for (int a = 0; a <= x; ++a) {
    for (int b = 0; b <= y; ++b) {
        if (can[a][b]) {
            best = std::min(best, std::abs(a + b - m));
        }
    }
}
std::printf("%d\n", best);
```

和程序 A 的队列不同，这里每一圈把整张表扫一遍。状态只有约 10⁴ 个，K 圈一共约 10⁶ 次，扫表比维护队列更好写。`next` 从 `can` 复制过来，因为题目说“至多 K 次”，原地不动也算。

我用一个把所有操作序列都试一遍的程序，对 X、Y 到 9、K 到 4 的三百组随机输入检查了这段代码。

## 也可以先走到尽头

### 冰淇淋周长

一张 N × N 的网格（N 到 1000），`#` 是冰淇淋格，`.` 是空地。上下左右相邻的冰淇淋格属于同一块。一块的面积是它的格子数；周长是它的格子与非冰淇淋格（包括网格外和块里的洞）相邻的边数。求面积最大的那块的面积和周长；面积并列时取周长最小的。

输入第一行 N，之后 N 行，每行 N 个字符。保证至少有一个 `#`。输出面积和周长。

样例输入：

```text
6
##....
....#.
.#..#.
.#####
...###
....##
```

样例输出：

```text
13 22
```

左上角的两格是一块，面积 2，周长 6；其余 13 格连成一块，周长 22。这是 USACO 2019 年 1 月银组第二题[“冰淇淋周长”](../USACO/银组/2018_2019/2019.01/P2.md)。

这题不关心距离，只关心哪些格子连在一起。图里互相能走到的一组点，叫一个**连通块**。找连通块不必一圈圈来：从一格出发，见到没去过的邻居就先过去，从那里再往下走，走到没有新邻居时退回上一格，看它的下一个邻居。这种走法叫**深度优先搜索**，常简称 DFS。用[第 2 章](02-把选择走成一棵树.md)的递归写，最自然。

**片段：**

```cpp
// 从 (r, c) 出发，把同一块里还没访问的冰淇淋格都标上；grid 四周已经围了一圈 '.'
void fill(const std::vector<std::string>& grid, std::vector<std::vector<bool>>& seen,
          int r, int c, int& area, int& perimeter) {
    seen[r][c] = true;
    ++area;
    const int dr[4] = {-1, 1, 0, 0};
    const int dc[4] = {0, 0, -1, 1};
    for (int d = 0; d < 4; ++d) {
        int nr = r + dr[d];
        int nc = c + dc[d];
        if (grid[nr][nc] != '#') {
            ++perimeter;        // 这一条边的另一侧不是冰淇淋
        } else if (!seen[nr][nc]) {
            fill(grid, seen, nr, nc, area, perimeter);    // 先往这个方向走到尽头
        }
    }
}
```

网格四周先围一圈 `.`，邻居就不会越界，网格外也自然算作非冰淇淋格。每格只在第一次被碰到时进入 `fill`，每条边看一次，一块 O(面积)。

问题在递归的深度。一块冰淇淋若是一条蛇形的长带，或者整张图都是 `#`，`fill` 会一层套一层，深到接近 10⁶ 层。每层都在栈上占一块空间，加起来超过程序默认的栈大小。我在 1000 × 1000 全是 `#` 的输入上试过：递归版崩溃，下面的版本正常输出 `1000000 4000`。

办法是自己管一个栈。[第一卷](../I/15-按访问方式挑容器.md)讲过栈：后放进去的先取出来。把“还要处理的格子”放进 `std::vector`，每次从末尾取一个，它的新邻居放回末尾。

**片段：**

```cpp
// 位于 main 内；grid 是围了一圈 '.' 的 (n + 2) × (n + 2) 网格
std::vector<std::vector<bool>> seen(n + 2, std::vector<bool>(n + 2, false));
const int dr[4] = {-1, 1, 0, 0};
const int dc[4] = {0, 0, -1, 1};
int best_area = 0;
int best_perimeter = 0;
for (int sr = 1; sr <= n; ++sr) {
    for (int sc = 1; sc <= n; ++sc) {
        if (grid[sr][sc] != '#' || seen[sr][sc]) {
            continue;
        }
        int area = 0;
        int perimeter = 0;
        // 自己管一个栈，代替递归：栈里是已经标上、还没看过四个邻居的格子
        std::vector<int> stack;
        seen[sr][sc] = true;
        stack.push_back(sr * (n + 2) + sc);
        while (!stack.empty()) {
            int cell = stack.back();
            stack.pop_back();
            int r = cell / (n + 2);
            int c = cell % (n + 2);
            ++area;
            for (int d = 0; d < 4; ++d) {
                int nr = r + dr[d];
                int nc = c + dc[d];
                if (grid[nr][nc] != '#') {
                    ++perimeter;
                } else if (!seen[nr][nc]) {
                    seen[nr][nc] = true;    // 进栈时就标上，同一格不会进栈两次
                    stack.push_back(nr * (n + 2) + nc);
                }
            }
        }
        if (area > best_area || (area == best_area && perimeter < best_perimeter)) {
            best_area = area;
            best_perimeter = perimeter;
        }
    }
}
std::printf("%d %d\n", best_area, best_perimeter);
```

格子用 `r × (n + 2) + c` 一个整数表示，取出来再拆回行和列。进栈时就标 `seen`，同一格不会进栈两次，栈至多 N² 个整数，放在堆上，不受栈大小限制。这个版本处理格子的先后和递归版不完全一样，但这题只要每块的面积和周长，处理顺序不影响结果。把 `std::vector` 的末尾换成 `std::queue` 的队头，就是 BFS，结果也一样。

## 核对

1. 读到这条边时只做 `adj[a].push_back(b)`，不做 `adj[b].push_back(a)`；输入里要有办法区分单向和双向。`adj[2]` 是 0、1、3，`adj[3]` 只有 4。
2. 按草地 1 到 8：从 1 号是 0、3、2、1、4、4、2、3；从 2 号是 3、0、1、2、1、2、3、3；从 8 号是 3、3、3、2、2、1、1、0。在 4 号会合：4 × 1 + 4 × 2 + 5 × 2 = 22。在 8 号会合：4 × 3 + 4 × 3 = 24。
3. 一步之后：(0, 0)、(14, 0)、(0, 50)。两步之后再加上 (14, 50)、(0, 14)、(14, 36)，共 6 个。
4. 左边那格：上、左、下三条边，右边是冰淇淋格。右边那格：上、右、下三条边。共 6。
5. 每格至多进栈一次，所以至多 N² = 10⁶ 个。
