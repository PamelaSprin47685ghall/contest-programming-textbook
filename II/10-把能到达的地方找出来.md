# 10　把能到达的地方找出来

几座展馆之间有通道。地图画得弯弯曲曲，程序不必保存曲线形状，只需知道哪些展馆之间能直接走。

## 地点是点，通道是边

点和边组成**图**。本卷给点编号 0 到 `n-1`。通道能双向走，叫无向边；只能单向走，叫有向边。边上若写距离或花费，那个数叫边权。

邻接表为每个点保存它能直接到达的邻居。无向边 `(u,v)` 要在 `u`、`v` 的表里各放一次。邻接矩阵用 `n*n` 个格子记录连接情况，查询两点是否相邻方便，但点多边少时浪费空间。

一段接一段走的路线是游走；若不重复点，通常称简单路径；绕回起点可形成圈。题目对“路径”是否允许重复有时约定不同，先读清楚。

**停笔 1**　三个点，只有无向边 `(0,1)`。写出三个邻接表。从 0 出发能到 2 吗？“每个点都有编号”是否等于“每个点都可达”？

## 先看一步，再看两步

广度优先搜索，缩写 BFS，用队列安排待处理的点。起点距离为 0；先把一步能到的点登记，再处理两步能到的点。

第一次发现一个点就标记并入队，不要等出队才标记，否则同一个点可能被反复排入队列。因为队列按层前进，第一次给它的步数就是最短边数。

**完整程序：**输入 `1 <= n <= 100000`、`0 <= m <= 200000` 及 `m` 条无向边，端点都合法。输出从 0 到 `n-1` 的最少通道数；到不了输出 −1。允许重边和自环。

```cpp
#include <cstdio>
#include <queue>
#include <vector>

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2 || n < 1 || n > 100000 || m < 0 || m > 200000) {
        return 1;
    }
    std::vector<std::vector<int>> graph(n);
    for (int i = 0; i < m; ++i) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= n || v < 0 || v >= n) {
            return 1;
        }
        graph[u].emplace_back(v);
        graph[v].emplace_back(u);
    }
    std::vector<int> distance(n, -1);
    std::queue<int> waiting;
    distance[0] = 0;
    waiting.emplace(0);
    while (!waiting.empty()) {
        int u = waiting.front();
        waiting.pop();
        for (int v : graph[u]) {
            if (distance[v] == -1) {
                distance[v] = distance[u] + 1;
                waiting.emplace(v);
            }
        }
    }
    std::printf("%d\n", distance[n - 1]);
    return 0;
}
```

输入：

```text
5 4
0 1
1 2
0 3
3 4
```

输出：

```text
2
```

邻接表里的每条记录被看一次，时间与空间都是 `O(n+m)`。想还原路线，发现 `v` 时另记 `parent[v]=u`，从终点反向追到起点再翻转。

**停笔 2**　在上例中，把终点换成 2，路线是什么？若只想找最少边数，能用边权为 2、100 的图照搬 BFS 吗？

## 也可以先走到尽头

DFS 用栈保存未完成的工作。递归能自然表达它，但长链可能递归过深。只求可达性时，可用显式栈：弹出一个点，把尚未标记的邻居标记后压入。

从每个尚未访问的点重新搜索一次，可给无向图的每个连通块编号。注意是继续完成同一份访问表，不是每个起点都清空再扫一遍。

方格迷宫也能看成图：每个可走格子是点，相邻可走格之间是边。通常不必真的建立全部邻接表，处理一格时计算上下左右并检查边界即可。若状态还有钥匙，点应是“格子与钥匙状态”，只按格子标记就会错删路线。

**停笔 3**　同一格子，没钥匙与有钥匙时，未来可走的路相同吗？为何 DFS 能找一条路，却不保证首先找到最短路？

## 核对

1. 分别为 `[1]`、`[0]`、`[]`。到不了 2；编号只是名字。
2. `0→1→2`。BFS 只保证边数最少；不同边权下，边数少可能更贵。
3. 不相同，需分状态。DFS 可能先深入一条很长的岔路，没有按总步数从小到大安排。
