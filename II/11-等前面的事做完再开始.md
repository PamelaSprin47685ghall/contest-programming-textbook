# 11　等前面的事做完再开始

做一架纸桥，要先裁纸再折叠，先折叠再粘接。有些步骤可以同时做，有些必须等。图不只画道路，也能画这种先后。

## 箭头表达“必须先于”

从 A 指向 B，表示 A 完成后 B 才能开始。若 A 等 B、B 又等 A，就没有合法开始顺序。这是一种有向圈。

没有有向圈的有向图叫 DAG。把所有点排成一列，使每条边都从前指向后，叫**拓扑排序**。它不是把编号排小到大。

每个点的入度是指向它的边数。先把入度为零的点放进队列；完成一个点，就删掉它发出的边，相邻点入度减一。新的零入度点再入队。

## 最早什么时候全部完成

任务 `v` 的耗时为 `time[v]`。最早完成时刻等于所有前置任务最晚完成时刻，再加自己的耗时。多个前置不是把耗时都相加，因为它们可以同时做；本题假定人员和工具足够。

**完整程序：**输入 `1 <= n <= 100000`、`0 <= m <= 200000`，再输入每项 0 到 10000 的耗时和 `m` 条依赖边。输出全部任务最早完成时刻；存在圈则输出 `CYCLE`。

```cpp
#include <algorithm>
#include <cstdio>
#include <queue>
#include <vector>

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2 || n < 1 || n > 100000 || m < 0 || m > 200000) {
        return 1;
    }
    std::vector<int> duration(n);
    std::vector<long long> finish(n);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d", &duration[i]) != 1 || duration[i] < 0 || duration[i] > 10000) {
            return 1;
        }
        finish[i] = duration[i];
    }
    std::vector<std::vector<int>> graph(n);
    std::vector<int> indegree(n, 0);
    for (int i = 0; i < m; ++i) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= n || v < 0 || v >= n) {
            return 1;
        }
        graph[u].emplace_back(v);
        ++indegree[v];
    }
    std::queue<int> ready;
    for (int v = 0; v < n; ++v) {
        if (indegree[v] == 0) {
            ready.emplace(v);
        }
    }
    int completed = 0;
    long long answer = 0;
    while (!ready.empty()) {
        int u = ready.front();
        ready.pop();
        ++completed;
        answer = std::max(answer, finish[u]);
        for (int v : graph[u]) {
            finish[v] = std::max(finish[v], finish[u] + duration[v]);
            if (--indegree[v] == 0) {
                ready.emplace(v);
            }
        }
    }
    if (completed != n) {
        std::printf("CYCLE\n");
    } else {
        std::printf("%lld\n", answer);
    }
    return 0;
}
```

输入：

```text
3 2
2 5 3
0 2
1 2
```

输出：

```text
8
```

时间、空间 `O(n+m)`。计数不到 `n` 时，剩下的点未必都在圈上，也可能只是被圈堵住；但足以证明整套任务没有合法拓扑顺序。

## 把 DP 的依赖画出来

每个状态当作点，来源指向结果，就得到状态转移图。台阶 DP 是沿编号向右的图；背包二维状态沿“已考虑物品数”前进，也是 DAG。

如果依赖成圈，不能随便按编号算一遍。可能要反复松弛、解方程，或证明某种额外顺序。第三卷会区分这些情况。改变计算次序是算法设计的一部分，不是排版调整。
