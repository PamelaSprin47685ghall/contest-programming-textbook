# 13　只记住谁和谁是一组

几支队伍不断合并。我们只问两个人是否已在同队，不关心合并后的队形。每次把整队成员重新抄一遍，做了多余的事。

## 一组只需要一个代表

每个元素指向一个父亲，沿父亲向上能找到组的代表。代表的父亲是自己。合并两组时，只接两个代表，不挨个改成员。

让小组代表接到大组代表下面，叫按大小合并；查找时顺手让经过的点靠近根，叫路径压缩。这是**并查集**。它不保存两点间的道路，不能用来还原路径，也不能直接拆开一组。

## 用最少总长度接通全部地点

从带权无向图选一些边，使所有点相通且没有圈，得到生成树。总权最小的叫**最小生成树**。不是从某个起点到每点的最短路树。

Kruskal 把边按权从小到大检查。两端已相连，加入就会成圈，跳过；还不相连就加入并合并两组。

**完整程序：**输入 `1 <= n <= 100000`、`0 <= m <= 200000`，每条边给合法端点和绝对值不超过一百万的权值。输出最小生成树总权，不连通输出 `DISCONNECTED`。

```cpp
#include <algorithm>
#include <cstdio>
#include <numeric>
#include <vector>

class DisjointSets {
    std::vector<int> parent;
    std::vector<int> size;
public:
    explicit DisjointSets(int n) : parent(n), size(n, 1) {
        std::iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool merge(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) {
            return false;
        }
        if (size[a] < size[b]) {
            std::swap(a, b);
        }
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

struct Edge {
    int u;
    int v;
    int weight;
};

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2 || n < 1 || n > 100000 || m < 0 || m > 200000) {
        return 1;
    }
    std::vector<Edge> edges(m);
    for (Edge& edge : edges) {
        if (std::scanf("%d%d%d", &edge.u, &edge.v, &edge.weight) != 3
            || edge.u < 0 || edge.u >= n || edge.v < 0 || edge.v >= n) {
            return 1;
        }
    }
    std::sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.weight < b.weight;
    });
    DisjointSets groups(n);
    long long total = 0;
    int used = 0;
    for (const Edge& edge : edges) {
        if (groups.merge(edge.u, edge.v)) {
            total += edge.weight;
            ++used;
        }
    }
    if (used == n - 1) {
        std::printf("%lld\n", total);
    } else {
        std::printf("DISCONNECTED\n");
    }
    return 0;
}
```

输入：

```text
3 3
0 1 4
1 2 2
0 2 3
```

输出：

```text
5
```

并查集的两份表是私有状态，使用者只请求合并，不在外面代它维护组大小。排序为 `O(m log m)`；并查集每次操作的均摊代价极小，常写 `O(α(n))`，这里先知道它增长极慢，而不是把它误写为严格常数。

## 为什么选便宜边不会后悔

把当前一个连通块与其他点分成两边，任何最终生成树都必须跨过这个分界。选择跨界的最便宜边，若某棵最优树没有它，加上它会形成圈；圈中另有一条跨界边，不比它便宜。删掉那条边，仍是树，总权不增加。

Prim 则从一个点的集合开始，反复选连接集合内外的最便宜边。它依靠同一条分界性质，不是把 Dijkstra 的距离相加公式换个名字。

沿 Kruskal 的合并过程另建树：每次新建一个父节点，存当前边权，两个连通块的树根成为孩子，称为 Kruskal 重构树。原图中两点“使其连通所需的最小最大边权”，等于重构树中两叶最近公共祖先的权值；不是两点最短距离。
