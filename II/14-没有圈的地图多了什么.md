# 14　没有圈的地图多了什么

翻开一本家谱，最上面是一位老祖宗，往下一代代分开。要找两个人的关系，不必在整本谱里乱翻：各自往上数，数到同一位祖先就停。家谱里没有圈，一个人不会是自己的爷爷，所以“往上”总有尽头，“往下”也分得清清楚楚。

上一章最后得到的生成树，就是这样一张没有圈的地图。这一章问：没有圈，能多做哪些事？挑一个起点，每条边就有了上下；任意两点之间只有一条路，“最远”“中间”“共同祖先”都有了确定的意思；一个点下面的全部后代，可以排成连续的一段；每个点的答案，可以等孩子们算完再合起来。

## 挑一个起点，关系就有了方向

N 个点、N − 1 条边、连通的图，叫**树**。它没有圈：有圈的话，拿掉圈上一条边仍然连通，N 个点只用 N − 2 条边就连通了，做不到。反过来，没有圈又连通，任意两点之间就只有一条不走回头路的路。

在树里挑一个点当**根**。从根出发，每个点和根之间只有一条路，路上紧挨着它、更靠近根的那个点叫它的**父亲**，它是父亲的**孩子**。没有孩子的点叫**叶**。一个点连同它下面所有的后代，叫它的**子树**。点到根要走几条边，叫它的**深度**。

要把这些关系算出来，从根开始搜一遍就行。下面是**片段**，用一个 `vector` 当栈（第一卷第 15 章的栈，只在尾部进出），边弹边排出一个次序 `order`：

```cpp
// 位于 main 内；roads[v] 是和 v 相连的点，点从 1 编号，根是 1；parent 全为 0
std::vector<int> order;
std::vector<int> pending{1};
while (!pending.empty()) {
    int v = pending.back();
    pending.pop_back();
    order.push_back(v);
    for (int next : roads[v]) {
        if (next != parent[v]) {
            parent[next] = v;
            pending.push_back(next);
        }
    }
}
```

一个点被压进栈时，它的父亲已经弹出、排进了 `order`，所以在 `order` 里，父亲一定排在孩子前面。倒过来走 `order`，孩子就一定在父亲前面。这两条，本章后面一直要用。

为什么 `next != parent[v]` 就能挡住回头路？树里和 v 相连的点，除了父亲，都是还没见过的孩子；没有圈，就不会从另一条路又绕回一个见过的点。根的 `parent` 是 0，不是任何点，不会误挡。

### 奶牛传染病

N 个农场（1 到 10 万）由 N − 1 条路连成一棵树。农场 1 有一头病牛，别处没有。以后每天恰好发生下面一件事：某个农场的病牛数翻一倍；或者一头病牛沿一条路走到相邻的农场。问最少几天，每个农场都至少有一头病牛。

输入第一行 N，接下来 N − 1 行，每行一条路的两端。输出最少天数。

样例输入：

```text
4
1 2
1 3
1 4
```

样例输出：

```text
5
```

农场 1 先翻倍两次，有 4 头；再用 3 天各送一头去 2、3、4。这是 USACO 2020 年 12 月银组第一题[“奶牛传染病”](../USACO/银组/2020_2021/2020.12/P1.md)。

以农场 1 为根。每个别的农场都只能从父亲那里收到病牛，所以每条路至少要走一次，共 N − 1 天。走一次就够了：一头牛进了农场，就在那里翻倍，再往孩子们送。一个农场有 c 个孩子，它自己要留一头，要送出去 c 头，一共要有 c + 1 头。手里从 1 头开始，翻倍到不少于 c + 1，要 ⌈log₂(c + 1)⌉ 次；少一次都不够。各农场的翻倍互不相干，加起来，再加上 N − 1，就是答案。

孩子数不必真的建出根来算：根的孩子数等于它连着的路数，别的点要减去通往父亲的那一条。

**片段：**

```cpp
// 位于 main 内；degree[v] 是农场 v 连着几条路，农场从 1 编号
long long days = n - 1;  // 每条路恰好走一次
for (int v = 1; v <= n; ++v) {
    int need = (v == 1) ? degree[v] + 1 : degree[v];  // 孩子数加上自己留的一头
    int cows = 1;
    while (cows < need) {
        cows *= 2;
        ++days;
    }
}
std::printf("%lld\n", days);
```

样例里根有 3 个孩子，要 4 头，翻倍 2 次；三个叶子各要 1 头，不翻倍。2 + 3 = 5。

## 走得最远的两个点

树里两点之间只有一条路，路长是确定的。距离最远的两点之间的那条路，叫树的**直径**。

找直径不必试所有点对。从任意一点出发搜一遍，找到离它最远的点 u；再从 u 出发搜一遍，找到离 u 最远的点 w；u 到 w 就是一条直径。

拿一棵 8 个点的树试：1—2—3—4—5 连成一条线，另有 6、7、8 三片叶子都挂在 1 上。从 3 出发，5 离它 2 步，6、7、8 离它 3 步，取 u = 6。从 6 出发，最远的是 5，6—1—2—3—4—5 共 5 步。这棵树的直径就是 5。

为什么第一次找到的 u 一定是某条直径的一端？设真正的直径是 a 到 b。从起点 s 走到 a、走到 b 的两条路，总有一段和 a—b 重合，或者先走到 a—b 上的某一点。从 s 出发最远的 u，比 a 和 b 都不近；要是 u 不是一端，就能把 a—b 的一半换成通往 u 的路，得到一条更长的路，与“a—b 最长”矛盾。这条理由要求边长都不是负数：边长可以为负时，“离得最远”和“走得最长”就不一定是一回事了。

## 中心与重心，不是同一个“中间”

“树的中间”有两种说法。

一种按距离：一个点到最远的点有多远，叫它的偏心距；偏心距最小的点叫**中心**。中心一定在直径上，而且就在直径的正中间：直径长 5 时，正中间是一条边，两端都是中心；直径长为偶数时，中心只有一个。上面那棵树，直径是 6—1—2—3—4—5，正中间是 2—3 这条边，2、3 都是中心，偏心距都是 3。

另一种按点数：拿掉一个点，树断成几块，最大的一块越小越好；最大的块不超过 N/2 的点，叫**重心**。上面那棵树 N = 8。拿掉 1，剩 {2, 3, 4, 5} 和三片单独的叶子，最大块 4 个点，不超过 4，1 是重心。拿掉 2，剩 {1, 6, 7, 8} 和 {3, 4, 5}，最大块 4，2 也是重心。拿掉 3，{1, 2, 6, 7, 8} 有 5 个点，3 不是重心。

所以中心是 2 和 3，重心是 1 和 2。三片叶子挂在 1 上，点数往那一头偏，重心跟着偏；可是它们离得不远，最远的路仍由那条长线决定，中心不跟着偏。

算重心用子树大小。倒着走 `order`，每个点把自己的大小加给父亲。拿掉点 v，断出来的块是它每个孩子的子树，再加上“上面那一块”，有 N − size[v] 个点。

重心最多两个，而且有两个时它们相邻。拿掉重心以后每块都不过半，后面讲树上分治时，它就是每次下刀的地方。

## 子树可以变成一段

第一节的 `order` 还有一个性质：一个点的子树在 `order` 里排成连续的一段，就从这个点开始。原因在栈：点 v 弹出后，它的孩子压在栈顶，v 的子树没走完以前，栈里 v 下面的点都轮不到。

记 v 在 `order` 里的位置为 `tin[v]`，子树大小为 `size[v]`，那么 v 的子树正好是 `order` 的 `[tin[v], tin[v] + size[v])` 这一段。这个位置叫 v 的**先序编号**。于是“u 是不是 v 的祖先”变成一次比较：`tin[u] <= tin[v]` 并且 `tin[v] < tin[u] + size[u]`。“给子树里所有点加一”“数子树里有几个点满足某条件”，也都变成了对一段的操作，可以交给第 3 章《先把重复的加法收起来》和下一章的工具。

### 牛奶访问

N 个农场（到 10 万）连成一棵树，第 i 个农场的牛产 Tᵢ 型牛奶（1 ≤ Tᵢ ≤ N）。M 位朋友（到 10 万），第 i 位沿树上 Aᵢ 到 Bᵢ 的路走一趟，只喝 Cᵢ 型牛奶。路上（含两端）有 Cᵢ 型的农场，他就满意。对每位朋友，满意输出 `1`，否则输出 `0`，连成一行。

输入第一行 N、M；第二行 T₁ 到 T_N；接下来 N − 1 行是路；再 M 行，每行 A、B、C。

样例输入：

```text
5 5
1 1 2 1 2
1 2
2 3
2 4
1 5
1 4 1
1 4 2
1 3 2
1 3 1
5 5 1
```

样例输出：

```text
10110
```

1 到 4 的路是 1—2—4，类型都是 1，所以第一位满意，第二位不满意。1 到 3 是 1—2—3，农场 3 是 2 型，第三位满意；第四位也满意。第五位只到农场 5，它是 2 型，不满意。这是 USACO 2019 年 12 月金组第二题[“牛奶访问”](../USACO/金组/2019_2020/2019.12/P2.md)。

以 1 为根，A 到 B 的路，是 A 往上走到两人的最近共同祖先，再往下走到 B。先只看 A 往上这半边：从 A 到根的路上，离 A 最近的 C 型农场 y 在不在 A 到共同祖先这一段上？

找 y：从根往下搜，手里为每种类型留一个栈，进入一个点就把它压进自己类型的栈，离开时弹出。走到 A 时，C 型栈的栈顶就是 y。

判断 y 在不在这一段：若 y 就是 A，在。否则设 Y 是 y 往 A 方向的那个孩子。B 不在 Y 的子树里，说明两人的共同祖先在 y 或更高处，y 在 A 往上的那一段上；B 也在 Y 的子树里，共同祖先在 Y 下面，y 在整条路的上方，不在路上。“B 在不在 Y 的子树里”，正是先序编号的一次比较。B 那半边同样做一次，两边有一边找到就满意。

为什么只看栈顶？栈里更深处的点都是 y 的祖先，y 不在路上时，它们离路更远。全部询问挂在两个端点上，一次搜索里统一回答，是 O(N + M)。

## 两个点一起往上找

开头的家谱里，找两个人的最近共同祖先：先让辈分低的那个往上走，走到两人同辈；然后两人一起往上，一步一步，直到走到同一个人。这个人叫两点的**最近共同祖先**，常写作 LCA。

一步一步走，树很深时太慢。改成一次跳很多步。给每个点准备一张表：`up[j][v]` 是 v 往上走 2ʲ 步到达的点。`up[0][v]` 是父亲；往上走 2ʲ 步，就是先走 2ʲ⁻¹ 步，再从那里走 2ʲ⁻¹ 步，所以 `up[j][v] = up[j - 1][up[j - 1][v]]`。父亲排在孩子前面算，右边用到的格子都已经算好。这样按 2 的次方准备跳法，叫**倍增**。第 7 章《把一大步拆成几小步》连走很多次时提前准备，也是这个道理。

有了表，往上走 d 步，就把 d 拆成几个 2 的次方，每个跳一次，至多 log N 次。找 LCA：先把深的那个点往上跳到同一深度；若已经重合就是答案；否则 j 从大往小试，`up[j][a]` 和 `up[j][b]` 不同就一起跳，相同就不跳。试完以后 a、b 是两个不同的点，父亲却相同，这个父亲就是 LCA。

为什么相同就不跳？跳过去落到的是公共祖先，但不一定是最近的那个；跳过头就回不来了。只在“仍然不同”时跳，a、b 始终停在 LCA 下面，最后差的正好一步。

### 逃离谷仓

N 个牧场（到 20 万）连成一棵以牧场 1 为根的树。奶牛只往远离谷仓的方向走，总路程不超过 L（L 到 10¹⁸）。对每个牧场 i，问从 i 出发能到几个牧场（含 i 自己）。

输入第一行 N 和 L；接下来 N − 1 行，第 i 行是牧场 i + 1 的父亲 p 和这条路的长度 l（1 ≤ p < i + 1，1 ≤ l ≤ 10¹²）。输出 N 行。

样例输入：

```text
4 5
1 4
2 3
1 5
```

样例输出：

```text
3
2
1
1
```

牧场 1 能到 2（距离 4）和 4（距离 5），到不了 3（距离 7），连自己共 3 个。牧场 2 能到 3（距离 3）。这是 USACO 2012 年 12 月金组第三题[“逃离谷仓”](../USACO/金组/2012_2013/2012.12/P3.md)。

逐个牧场往下数，一条长链上就是 O(N²)。换个方向数：牧场 v 会被哪些牧场数到？是它的祖先里，离它不超过 L 的那些。它们从 v 往上连成一段，顶端是离 v 不超过 L 的最高祖先 top。于是 v 给 v 到 top 这一段的每个牧场都贡献 1。

“给一段往上的路都加 1”可以用第 3 章的差分：在 v 处记 +1，在 top 的父亲处记 −1，最后每个点的答案是它子树里所有记号之和。一个点 x 在 v 到 top 这一段上，恰好是 v 在 x 的子树里而 top 的父亲不在，+1 被算进来、−1 没有；在这一段以上，两者都算进来，抵消。

找 top 用倍增：从 v 出发，j 从大往小试，跳上去仍不超过 L 就跳。题目给的父亲编号总比孩子小，所以按编号从小到大就是“父亲在前”的次序，不必另外搜索。下面是**片段**：

```cpp
// 位于 main 内；up[j][v] 是 v 往上走 2 的 j 次方步到达的牧场，走过头记为 0；
// dist[v] 是 v 到谷仓的路长，parent[1] 是 0，reach 全为 0
for (int v = 1; v <= n; ++v) {
    int top = v;  // 已经确认 v 往上能被谁数到
    for (int j = levels - 1; j >= 0; --j) {
        int higher = up[j][top];
        if (higher != 0 && dist[v] - dist[higher] <= limit) {
            top = higher;
        }
    }
    reach[v] += 1;
    reach[parent[top]] -= 1;  // top 是根时记在不用的 0 号格
}
for (int v = n; v >= 2; --v) {
    reach[parent[v]] += reach[v];  // 孩子编号大，先算完再交给父亲
}
```

`levels` 取 18 就够：2¹⁸ = 262144，比 20 万大。`dist` 最大约 2 × 10⁵ × 10¹² = 2 × 10¹⁷，要用 `long long`。往上跳的距离只会越来越大，所以“跳上去仍不超过 L”能从大往小逐个试：某个 2ʲ 跳不了，以后更小的跳法组合起来也到不了那么高。

拿样例走一遍：`dist` 是 0、4、7、5。牧场 3 往上跳到 2，7 − 4 = 3 ≤ 5；再到 1，7 − 0 = 7 > 5，停，`top` 是 2，于是 +1 记在 3、−1 记在 1。牧场 2 和 4 的 `top` 都是 1，−1 记在 0 号格。牧场 1 自己记 +1、在 0 号格记 −1。合并后牧场 1 是 1 − 1 + 1 + 2 = 3，牧场 2 是 1 + 1 = 2，与样例相同。

## 孩子先交账，父亲再合并

一个点的子树，由它自己和各个孩子的子树拼成。要是一个子树的答案，只靠“孩子子树的答案”再加上自己就能合出来，那就倒着走 `order`：孩子先算完，交给父亲，父亲合并。这种按子树记表格的做法叫**树形 DP**。表格里每个数都要有一句含义，这是第 8 章《给已经解决的小问题留个位置》的老规矩。

### 粉刷谷仓

N 个谷仓（到 10 万）连成一棵树，要用 3 种颜色把每个谷仓刷上，有路直接相连的两个谷仓不能同色。其中 K 个谷仓已经刷好了。问剩下的有几种刷法，除以 10⁹ + 7 取余数。

输入第一行 N 和 K；接下来 N − 1 行是路；再 K 行，每行 b、c，表示谷仓 b 已刷成颜色 c（1 到 3）。输出方案数。

样例输入：

```text
4 1
1 2
1 3
1 4
4 3
```

样例输出：

```text
8
```

谷仓 4 是颜色 3，谷仓 1 只能从另两种里选，2 种；谷仓 2、3 各避开谷仓 1 的颜色，各 2 种。2 × 2 × 2 = 8。这是 USACO 2017 年 12 月金组第二题[“粉刷谷仓”](../USACO/金组/2017_2018/2017.12/P2.md)。

以 1 为根。`ways[v][c]` 的意思是：v 刷成颜色 c 时，v 的子树一共有几种刷法。v 的孩子之间没有路相连，互不牵制，各自只要和 v 不同色。所以 `ways[v][c]` 是每个孩子“刷成 c 以外颜色的刷法总数”的乘积；v 已经刷好、而 c 不是那个颜色时，为 0。叶子没有孩子，乘积为 1。答案是根的三种颜色加起来。

下面是**完整程序 A**。颜色在程序里从 0 编号。

```cpp
#include <cstdio>
#include <vector>

const long long MOD = 1000000007;

int main() {
    int n = 0;
    int k = 0;
    if (std::scanf("%d%d", &n, &k) != 2) {
        return 1;
    }
    std::vector<std::vector<int>> roads(n + 1);
    for (int i = 0; i < n - 1; ++i) {
        int a = 0;
        int b = 0;
        if (std::scanf("%d%d", &a, &b) != 2) {
            return 1;
        }
        roads[a].push_back(b);
        roads[b].push_back(a);
    }
    std::vector<int> painted(n + 1, -1);  // -1 表示还没刷
    for (int i = 0; i < k; ++i) {
        int barn = 0;
        int color = 0;
        if (std::scanf("%d%d", &barn, &color) != 2) {
            return 1;
        }
        painted[barn] = color - 1;
    }
    std::vector<int> parent(n + 1, 0);
    std::vector<int> order;
    std::vector<int> pending{1};
    while (!pending.empty()) {
        int v = pending.back();
        pending.pop_back();
        order.push_back(v);
        for (int next : roads[v]) {
            if (next != parent[v]) {
                parent[next] = v;
                pending.push_back(next);
            }
        }
    }
    // ways[v][c]：v 刷成颜色 c 时，v 的子树有几种刷法
    std::vector<std::vector<long long>> ways(n + 1, std::vector<long long>(3, 1));
    for (int i = n - 1; i >= 0; --i) {  // 倒着走：孩子都已交账
        int v = order[i];
        for (int c = 0; c < 3; ++c) {
            if (painted[v] != -1 && painted[v] != c) {
                ways[v][c] = 0;
            }
        }
        int up = parent[v];
        if (up == 0) {
            continue;
        }
        for (int c = 0; c < 3; ++c) {
            long long other = 0;  // 父亲刷成 c 时，v 的子树有几种刷法
            for (int d = 0; d < 3; ++d) {
                if (d != c) {
                    other += ways[v][d];
                }
            }
            ways[up][c] = ways[up][c] * (other % MOD) % MOD;
        }
    }
    long long total = (ways[1][0] + ways[1][1] + ways[1][2]) % MOD;
    std::printf("%lld\n", total);
    return 0;
}
```

`ways` 开始全是 1，表示“还没乘上任何孩子”。倒着走到 v 时，v 的孩子都在它后面，早已乘进来，所以这时 `ways[v]` 已经是定数，可以交给父亲。每个数都先取过余数，小于 10⁹ + 7；`other` 是两个这样的数相加，再取余后与另一个相乘，不超过约 10¹⁸，`long long` 放得下。

已刷好的颜色放在乘完以后才清零，也没关系：乘法不管先后，0 乘什么都是 0。只有一个谷仓时 `order` 里只有根，答案是根能取的颜色数。

慢办法直接照题意：每个谷仓试 3 种颜色，3ᴺ 种全部检查一遍，N 不超过 8 时一眨眼就完。拿它和程序 A 对拍 300 组 8 个点以内的随机树、随机预先刷好的谷仓，答案全部相同。两份程序只共用了读入，慢程序没有用到“孩子之间互不牵制”这条想法。

## 核对

1. 4 天。以 1 为根，农场 1、2 各有一个孩子，各要 2 头，各翻倍 1 次；农场 3 不翻倍；再加两条路各走一次。日程：第 1 天农场 1 翻倍，第 2 天送一头到 2，第 3 天农场 2 翻倍，第 4 天送一头到 3。农场 1 唯一的牛走掉，农场 1 就没有病牛了，所以它先要翻倍。
2. 从 5 出发，最远的是 6、7、8（都是 5 步），u 取其中之一，比如 6。从 6 出发最远是 5，直径是 6 到 5，长 5。
3. 子树大小：1 是 8，2 是 4，3 是 3，4 是 2，5、6、7、8 都是 1。拿掉 4，孩子 5 那块 1 个点，上面那块 8 − 2 = 6 个点，最大 6。
4. 走到 4 时，根到 4 的路是 1—2—4，没有 2 型，栈是空的。走到 1 时，路上只有 1，也是空的。两边都没找到，不满意。
5. 输出 4、2、1、1。只有牧场 3 的 `top` 变了：7 − 0 = 7 ≤ 7，它能跳到 1，牧场 1 现在也能到 3。
6. 谷仓 2 刷成 3：谷仓 1 只能取 1 或 2（避开 2 和 4 的颜色 3），2 种；谷仓 3 避开谷仓 1，2 种；共 4 种。谷仓 1 刷成 3：它和谷仓 4 同色而相邻，0 种。
