# 14　没有圈的地图多了什么

一张连通地图没有圈，两点间就只有一条简单路径。若有两条不同路径，沿一条去、另一条回，就会找出一个圈。这样的无向图叫**树**。

## 挑一个起点，关系就有了方向

任选一个点为根。除根外，每点在通向根的路径上有一个父亲，其余向下邻居是孩子。子树包括自己和全部后代。根的选择改变父子、深度和子树，不改变原图两点间的距离。

树有 `n-1` 条边；“恰有 `n-1` 条边”单独不能证明是树，还须连通。遍历时先登记父亲，再按反向遍历序累加，可以算每个点的子树大小，不必冒险递归十万层。

## 走得最远的两个点

树的最长简单路径叫直径。无权树可以从任一点 BFS 到一个最远点 A，再从 A BFS 到最远点 B，A、B 的距离就是直径。依据是树路径的唯一性：离起点最远的方向，总能取到一条最长路的端点。

这条结论也适合非负边权树，但求距离要累计权值；若权允许负数，不能照搬“两次最远”。

**完整程序：**输入 `1 <= n <= 100000`，随后 `n-1` 条合法无向边，保证构成树。输出无权直径长度。

```cpp
#include <cstdio>
#include <queue>
#include <utility>
#include <vector>

std::pair<int, int> farthest(const std::vector<std::vector<int>>& tree, int start) {
    std::vector<int> distance(tree.size(), -1);
    std::queue<int> waiting;
    distance[start] = 0;
    waiting.emplace(start);
    int best = start;
    while (!waiting.empty()) {
        int u = waiting.front();
        waiting.pop();
        if (distance[u] > distance[best]) {
            best = u;
        }
        for (int v : tree[u]) {
            if (distance[v] == -1) {
                distance[v] = distance[u] + 1;
                waiting.emplace(v);
            }
        }
    }
    return {best, distance[best]};
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 1 || n > 100000) {
        return 1;
    }
    std::vector<std::vector<int>> tree(n);
    for (int i = 1; i < n; ++i) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= n || v < 0 || v >= n) {
            return 1;
        }
        tree[u].emplace_back(v);
        tree[v].emplace_back(u);
    }
    int a = farthest(tree, 0).first;
    std::printf("%d\n", farthest(tree, a).second);
    return 0;
}
```

输入：

```text
4
0 1
1 2
2 3
```

输出：

```text
3
```

时间、空间 `O(n)`。本程序依赖输入确实是树，不把两次 BFS 误说成一般图直径算法。

## 中心与重心，不是同一个“中间”

树的中心使到最远点的距离最小，位于直径的中间：无权树有一个或两个。逐轮删掉所有叶子，最后剩的一个或两个也是中心。

重心则要求删掉它后，每个剩余连通块点数不超过 `n/2`。已知子树大小，检查各孩子子树及父亲方向 `n-size[u]` 的最大值，就能找重心。重心适合把树按**点数**均衡拆开，中心适合控制**距离**。

## 子树可以变成一段

DFS 首次进入一个点时给它顺序号，走完全部后代再离开。每个子树在首次进入序里占一段连续区间。这是把树问题交给区间数据结构的入口。

另一种欧拉游走序，在走过边回来时也记当前点。两点的最近公共祖先 LCA，是它们共同祖先里最深的点。欧拉序上，两次首次出现之间深度最小的位置正是 LCA；也可用倍增祖先表，先把两点升到同深度，再同时向上跳到祖先分叉处。

## 核对

1. 根为 0 时是 `{1,2,3}`；根为 2 时是 `{1,0}`。
2. `0,1,3,4,2`；分别为 1、0。子树 1 对应进入序中的连续三项。
3. `distance[u]+distance[v]-2*distance[LCA(u,v)]`。根到公共祖先的一段在两份距离中各算了一遍。
