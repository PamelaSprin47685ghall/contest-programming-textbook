# 15　修改以后还想马上查询

前缀和建好后，只改第一项，后面所有累计值都要变。我们想保留“由几块拼出前缀”的便利，又不愿修改整张表。

## 每个位置负责一块，不负责全部前面

内部从 1 编号。`tree[i]` 负责末端为 `i`、长度为 `lowbit(i)` 的一块。`lowbit(i)` 是二进制最右侧那个 1 代表的数，可以写 `i & -i`；本章只对不超过十万的正 `int` 使用，不涉及最小负数取反。

位置 12 的二进制为 `1100`，最右侧的 1 代表 4，所以它管 9 到 12。求前 13 项，取 13 管的一项，再取 12 管的四项，再取 8 管的八项，正好拼完。

查询不断 `i -= lowbit(i)`；单点修改不断 `i += lowbit(i)`，沿包含这个点的块向上更新。这个结构叫**树状数组**，也常叫 Fenwick 树。

**停笔 1**　前 7 项由哪些末端位置负责的块拼成？位置 3 的修改，在长度 8 的树状数组中会改哪些内部位置？

**完整程序：**输入 `0 <= n <= 100000`、操作数 `0 <= q <= 100000` 和初始 `n` 个整数。`A index delta` 给一个合法下标加数；`S left right` 查询半开区间和。初值和增量绝对值不超过一百万。

```cpp
#include <cstdio>
#include <vector>

class Fenwick {
    std::vector<long long> tree;
public:
    explicit Fenwick(int n) : tree(n + 1, 0) {}
    void add(int index, long long value) {
        for (int i = index + 1; i < static_cast<int>(tree.size()); i += i & -i) {
            tree[i] += value;
        }
    }
    long long prefix(int count) const {
        long long result = 0;
        for (int i = count; i > 0; i -= i & -i) {
            result += tree[i];
        }
        return result;
    }
    long long sum(int left, int right) const {
        return prefix(right) - prefix(left);
    }
};

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2 || n < 0 || n > 100000 || q < 0 || q > 100000) {
        return 1;
    }
    Fenwick values(n);
    for (int i = 0; i < n; ++i) {
        int value = 0;
        if (std::scanf("%d", &value) != 1) {
            return 1;
        }
        values.add(i, value);
    }
    for (int i = 0; i < q; ++i) {
        char kind = '\0';
        int a = 0;
        int b = 0;
        if (std::scanf(" %c%d%d", &kind, &a, &b) != 3) {
            return 1;
        }
        if (kind == 'A' && a >= 0 && a < n) {
            values.add(a, b);
        } else if (kind == 'S' && a >= 0 && a <= b && b <= n) {
            std::printf("%lld\n", values.sum(a, b));
        } else {
            return 1;
        }
    }
    return 0;
}
```

输入：

```text
4 3
3 1 4 2
S 1 3
A 2 -3
S 0 4
```

输出：

```text
5
7
```

每次修改、查询 `O(log n)`，空间 `O(n)`。本版初始化逐项加入为 `O(n log n)`，不把它误写成线性。

## 哪些信息能相减

区间和可以用两份前缀相减。区间最小值不行：知道前四项最小值与前两项最小值，不能还原后两项最小值。因此不能只把上面所有加号换成 `min`，就声称得到任意修改的区间最小值。

数据固定时，最值还可用**稀疏表**，常写 ST 表。`table[p][i]` 保存从 `i` 开始、长 `2^p` 的最小值，用两个长一半的块合并。长度 `len` 查询取 `p=floor(log2(len))`，用左端一块和右端一块覆盖；两块允许重叠，因为重复取同一个数的最小值不变。

建表 `O(n log n)`，最值查询 `O(1)`，前提是区间非空、数据不修改。区间和不能用这两块直接相加，重叠部分会被多算。

**停笔 2**　长 6 的区间，用两块长 4 的区间覆盖，重叠几项？用 `max` 可以吗？用“出现次数之和”可以吗？

**停笔 3**　程序对外是 0 下标，内部是 1 下标。若 `add` 忘记先加一，更新第 0 项时循环为什么可能永远不动？

## 核对

1. 末端 7、6、4，长度分别为 1、2、4。内部位置 3、4、8 会变。
2. 重叠两项。`max` 也不怕重复；和会把两项多算一次。
3. `lowbit(0)=0`，更新仍停在零。因此下标转换属于结构自己的责任，不让每个调用者猜。
