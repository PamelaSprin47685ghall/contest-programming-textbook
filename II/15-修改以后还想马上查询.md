# 15　修改以后还想马上查询

班里记小红花，黑板上写着每位同学得了几朵。老师常问：“1 号到 20 号一共多少朵？”[第 3 章](03-先把重复的加法收起来.md)的前缀和正好管这件事：先算好“前 k 位一共多少”，问一段就做一次减法。可是课间又有同学得了花，黑板上的数改了。前缀和表里，这位同学后面的每一格都要跟着改，改一次要动几十格。

这一章要的是两样都快：改一个数快，问一段的和也快。办法是让每一格不再管“前面全部”，只管前面的一块。最后一节问：这种“先算前面、再相减”的办法，能用在哪些信息上，不能用在哪些上。

## 每个位置负责一块，不负责全部前面

位置从 1 编号。前缀和表的第 k 格管第 1 到第 k 个数，改第 3 个数，第 3 格以后都要改。反过来，要是每格只管自己，改一个数只动一格，问前缀却要加 k 格。两头都不好。

折中的办法：第 k 格管 k 往前的一块，块长是 k 的二进制里最低的那个 1 所代表的数，记作 **lowbit(k)**。8 个位置时是这样：

| k | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 二进制 | 1 | 10 | 11 | 100 | 101 | 110 | 111 | 1000 |
| lowbit(k) | 1 | 2 | 1 | 4 | 1 | 2 | 1 | 8 |
| 管的位置 | 1 | 1–2 | 3 | 1–4 | 5 | 5–6 | 7 | 1–8 |

问前 7 个数的和：第 7 格管 7，还差 1 到 6；第 6 格管 5 到 6，还差 1 到 4；第 4 格管 1 到 4。三格加起来。每一步都是 k 减去 lowbit(k)：7 → 6 → 4 → 0。每减一次，k 的二进制就少一个 1，所以至多 log N 步。

改第 3 个数：哪些格管着位置 3？第 3、4、8 格。每一步是 k 加上 lowbit(k)：3 → 4 → 8。每加一次，最低的那个 1 至少往高处挪一位，也至多 log N 步。

这种每格管一块、改和问都只走 log N 格的表，叫**树状数组**。

lowbit(k) 在 C++ 里写作 `k & -k`。`&` 是[第 2 章](02-把选择走成一棵树.md)《把一组决定写成几位二进制》那一节的按位与。`-k` 在机器里是“把 k 的每一位取反再加 1”：k 最低的那个 1 右边全是 0，取反后变成 1，加 1 又一路进位回 0，正好停在那个位置上变成 1；再往左的每一位都和 k 相反。两者按位与，只剩那一个 1。例如 k = 6 是 `110`，取反加一后低三位是 `010`，与出来是 `010`，等于 2。

### 平衡的照片

N 头牛（1 到 10 万）排成一行，第 i 头身高 hᵢ（0 到 10⁹），身高互不相同。记 Lᵢ 是她左边比她高的牛数，Rᵢ 是她右边比她高的牛数。两数中大的严格大于小的两倍，她就“不平衡”。问有几头不平衡的牛。

输入第一行 N，接下来 N 行各一个身高。输出一个整数。

样例输入：

```text
7
34
6
23
0
5
99
2
```

样例输出：

```text
3
```

身高 34 的牛站在最左，L = 0，右边只有 99 比她高，R = 1，1 > 0，不平衡。身高 5 的牛，左边 34、6、23 都比她高，L = 3；右边只有 99，R = 1；3 > 2，不平衡。身高 2 的牛在最右，L = 5，R = 0，不平衡。别的牛都平衡，例如身高 6 的牛 L = 1、R = 2，2 不大于 2。共 3 头。这是 USACO 2017 年 1 月金组第一题[“平衡的照片”](../USACO/金组/2016_2017/2017.01/P1.md)。

每头牛把左右两边都数一遍是 O(N²)。从左往右扫，手里留一张表，记下“已经走过的牛里，每种身高有没有出现”。走到第 i 头，左边一共 i 头，其中比她矮的个数就是表里“身高小于她”的那一段的和，Lᵢ 等于 i 减去它。比她高的牛全队一共有几头，排一次序就知道，Rᵢ 是这个数减去 Lᵢ。

身高到 10⁹，不能拿身高当表的下标。[第 4 章](04-顺序能替我们保存信息.md)《顺序能替我们保存信息》里，大号码可以换成小名次：把牛按身高排好，最矮的名次是 1，最高的是 N。身高互不相同，名次也互不相同。名次为 r 的牛，全队比她高的有 N − r 头。表的下标改用名次，表里第 r 格是 1 表示名次 r 的牛已经走过。

于是每走一头牛，要做两件事：问前 r 格的和，把第 r 格改成 1。改和问交替进行，正是树状数组的用处。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

// tree[k] 管着第 k − lowbit(k) + 1 到第 k 个位置，位置从 1 编号，tree[0] 不用
void add(std::vector<int>& tree, int k, int delta) {
    int limit = tree.size();
    while (k < limit) {
        tree[k] += delta;
        k += k & -k;  // 下一个也管着位置 k 的格子
    }
}

// 第 1 到第 k 个位置一共多少
int prefix(const std::vector<int>& tree, int k) {
    int total = 0;
    while (k > 0) {
        total += tree[k];
        k -= k & -k;  // 跳到这一块前面紧挨着的那一块
    }
    return total;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<int> height(n);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d", &height[i]) != 1) {
            return 1;
        }
    }
    std::vector<int> by_height(n);
    for (int i = 0; i < n; ++i) {
        by_height[i] = i;
    }
    std::sort(by_height.begin(), by_height.end(), [&](int a, int b) {
        return height[a] < height[b];
    });
    std::vector<int> rank(n);  // 最矮的名次是 1
    for (int r = 0; r < n; ++r) {
        rank[by_height[r]] = r + 1;
    }
    std::vector<int> tree(n + 1, 0);
    int unbalanced = 0;
    for (int i = 0; i < n; ++i) {
        int left = i - prefix(tree, rank[i]);  // 左边 i 头里比她高的
        int right = (n - rank[i]) - left;      // 全队比她高的共 n − rank[i] 头
        if (std::max(left, right) > 2 * std::min(left, right)) {
            ++unbalanced;
        }
        add(tree, rank[i], 1);
    }
    std::printf("%d\n", unbalanced);
    return 0;
}
```

`prefix(tree, rank[i])` 数的是“名次不超过 rank[i]”的已走过的牛。她自己这时还没加进表，所以数到的都比她矮。先问再加，次序不能反。`tree` 开 n + 1 格，下标 1 到 n 都能用；`add` 里 `k` 一旦到了 n + 1 或更大，就不再有格子管它，停下。

整个程序一次排序，再做 N 次改、N 次问，是 O(N log N)。

慢办法照定义，每头牛把左边、右边都扫一遍。两份程序在 300 组随机数据上对拍，每组至多 8 头牛、身高从 0 到 20 里随机挑不同的数，答案全部相同。慢程序没有用到名次，也没有用到树状数组。

## 哪些信息能相减

程序 A 问的是前缀，可它真正想要的是“名次在 1 到 r 之间”这一段。要是问名次在 l 到 r 之间的一段呢？做一次减法：`prefix(tree, r) - prefix(tree, l - 1)`。第 3 章的前缀和也是这样用的。

减法能用，是因为和有“退回去”的办法：知道前 r 个的和、前 l − 1 个的和，后者是前者的一部分，拿掉它就剩中间那段。计数、异或也一样：异或两次等于没做，前缀异或相“减”就是再异或一次。

最大值就不行。前 7 个数里最大的是 9，前 3 个数里最大的也是 9，第 4 到第 7 个数里最大的是几？说不出来，可能是 9，也可能小得多。最大值合起来容易，拆不开。所以树状数组只能直接回答“前缀最大值”，而且只能在数只增不减的时候：一个数变小了，管着它的格子不知道该退回几。要问任意一段的最大值，或者要把数改小，得换下一章的工具：它把一段直接拆成几块，不靠减法。

减法还能反过来用。第 3 章《若不是问一段，而是给一段加水》那一节，把“给第 l 到第 r 个数都加 v”记成差分：第 l 格加 v，第 r + 1 格减 v，某个数的当前值就是差分的前缀和。把差分放进树状数组，`add(tree, l, v)` 再 `add(tree, r + 1, -v)`，问一个数就是 `prefix(tree, k)`。整段加、单点问，两样都是 log N。这仍然靠和能相减：差分本来就是相邻两数之差。

还有一种用法要分清：表的下标不一定是位置，也可以是值。程序 A 的下标是名次，表里记的是“这个名次出现过几次”，问前缀就是问“比某个值小的有几个”。下面这道题也是这样。

### 中位数之上

N 头牛（1 到 10 万）排成一排，第 i 头身高 Hᵢ。选一段连续的牛拍照，这一段身高的中位数不小于 X（1 ≤ X, Hᵢ ≤ 10⁹）才有效。长为 m 的一段，中位数是排好序后从 0 数第 ⌈(m − 1)/2⌉ 个：长度为偶数时取中间两个里大的那个。问有效的段有几个，答案可能超过 `int`。

输入第一行 N 和 X，接下来 N 行各一个身高。输出一个整数。

样例输入：

```text
4 6
10
5
6
2
```

样例输出：

```text
7
```

10 段里，有效的是 {10}、{6}、{10, 5}、{5, 6}、{6, 2}、{10, 5, 6}、{10, 5, 6, 2}。例如 {10, 5, 6, 2} 排好是 2、5、6、10，取第 2 个，是 6，不小于 6。{5} 和 {2} 太小；{5, 6, 2} 排好取中间的 5，也不够。这是 USACO 2011 年 11 月金组第一题[“中位数之上”](../USACO/金组/2011_2012/2011.11/P1.md)。

中位数不小于 X，换一种说法：这一段里不小于 X 的牛，至少和小于 X 的牛一样多。长为偶数时，中间两个里取大的那个，正好让“一样多”也算数。于是把不小于 X 的牛记 +1，其余记 −1，问题变成：有几段的和不小于 0。

段和是两个前缀和之差。记 P₀ = 0，Pⱼ 是前 j 个数的和。从 i + 1 到 j 这一段有效，就是 Pᵢ ≤ Pⱼ，其中 i < j。于是从左往右扫 j，每到一个 Pⱼ，问前面有几个 Pᵢ 不超过它，再把 Pⱼ 加进表里。表的下标是前缀和的值。前缀和在 −N 到 N 之间，加上 N + 1 就落在 1 到 2N + 1，可以直接当下标。

样例的 ±1 是 +1、−1、+1、−1，前缀和依次是 0、1、0、1、0。走到第二个 0，前面不超过它的有一个（0）；走到第二个 1，前面有 0、1、0 三个；最后一个 0，前面有两个 0。第一个 1 前面有一个 0。1 + 1 + 3 + 2 = 7。

下面是**片段**，`add` 和 `prefix` 照搬程序 A。

```cpp
// 位于 main 内；height 已读入，tree 有 2 * n + 2 格，全为 0
long long photos = 0;
int sum = 0;  // 当前的前缀和，开始是 P₀ = 0
add(tree, sum + n + 1, 1);
for (int i = 0; i < n; ++i) {
    sum += (height[i] >= x) ? 1 : -1;
    photos += prefix(tree, sum + n + 1);  // 前面有几个前缀和不超过它
    add(tree, sum + n + 1, 1);
}
std::printf("%lld\n", photos);
```

`prefix` 返回的是 `int`，一次至多 N + 1，放得下；加起来至多约 N²/2 = 5 × 10⁹，所以 `photos` 用 `long long`。这里用的是计数可以相减吗？没有用到：问的本来就是前缀，“不超过它”的值正好排在表的前面。要是问“前缀和在 a 到 b 之间的有几个”，才要做一次减法。

## 核对

1. 问前 13：13 → 12 → 8 → 0，加第 13、12、8 格（管 13、9–12、1–8）。改第 5：5 → 6 → 8 → 16，改第 5、6、8、16 格。
2. 输出 5。先加再问，`prefix` 把她自己也数成“不比她高”，`left` 比真实的 L 少 1，`right` 跟着多 1。身高 6 的牛变成 L = 0、R = 3，被错判为不平衡；身高 99 的牛变成 L = −1、R = 1，1 > −2，也被错判。
3. 答 9。身高 10、5、6、2 记 +1、+1、+1、−1，前缀和 0、1、2、3、2。不超过当前值的前面个数依次是 1、2、3、3，共 9。变化：{5}、{5, 6, 2} 从无效变有效。
4. 例如身高 9、1、1、1，问第 2 到第 4 头。前 4 头最大 9，前 1 头最大也是 9，“相减”得不出 1。最大值没有“拿掉一部分”的办法。
