# 16　整段的工作先记一张便条

年级组长要给三个班发通知：“三个班每人多领一本练习册。”她不会挨个去找一百多位同学，只在三位班长的本子上各写一张便条。哪天有同学来问自己该领几本，班长翻翻便条再告诉他。工作并没有少，只是推迟到真正有人问的时候，而且没人问的那些，就永远不必一个个去做。

上一章的树状数组改一个数、问一段的和都很快，但它靠的是减法。这一章换一种分法：把一排数对半分，再对半分，每一块记下自己的答案。要合并的是两半的答案，不必能相减，最大值、最长空段都行。第二节再加上便条：整段修改先记在大块上，等需要时才往下传。

## 把一排分成左右两半

位置 [0, 8) 的八个数，先分成 [0, 4) 和 [4, 8)，再各分两半，一直分到每块只剩一个数。每一块记下它这一段的答案，比如最小值。一块的答案由左右两半的答案合出来：最小值就取两者中小的。

```text
               [0,8)
        [0,4)          [4,8)
    [0,2)  [2,4)    [4,6)  [6,8)
   0   1  2   3    4   5  6   7
```

改一个数：它所在的块从下往上一层一块，共 log N + 1 块，每块用两半重新合一次。问一段，比如 [1, 7)：从最上面那块往下看，一块完全落在 [1, 7) 里就直接拿它的答案，完全在外面就不管，跨在边上就往两半里再找。最后用到的是 [1, 2)、[2, 4)、[4, 6)、[6, 7) 四块。每一层至多有两块跨在边上，所以用到的块不超过 4 log N 块。

这样一层层对半分、每块记一份答案的结构，叫**线段树**。块从 1 编号：第 k 块的两半是第 2k 块和第 2k + 1 块。N 个数时开 4N 个格子一定够用。

线段树对“答案”只有一个要求：知道左右两半的答案，就能合出整段的答案。它不要求能相减。下面这道题，要合的是一个比最小值复杂一点的答案。

### 最优挤奶

一排 N 台挤奶机（1 到 4 万），第 i 台每天能挤 M(i)（1 到 10⁵）。一台开着，它左右相邻的两台当天就不能开。约翰每天自己挑开哪几台。一共 D 天（1 到 5 万），每天开始时，他把某一台机器的日产量改成一个新值，从当天起生效。问 D 天里一共最多能挤多少牛奶，答案可能超过 `int`。

输入第一行 N 和 D；接下来 N 行，是各台机器原来的日产量；再 D 行，每行 i 和 m，表示这一天开始时把第 i 台改成 m。输出一个整数。

样例输入：

```text
5 3
1
2
3
4
5
5 2
2 7
1 10
```

样例输出：

```text
32
```

第一天产量是 1、2、3、4、2，开第 2、4 台得 6（开第 1、3、5 台也是 6）。第二天是 1、7、3、4、2，开第 2、4 台得 11。第三天是 10、7、3、4、2，开第 1、3、5 台得 15。6 + 11 + 15 = 32。这是 USACO 2013 年 12 月金组第二题[“最优挤奶”](../USACO/金组/2013_2014/2013.12/P2.md)。

只有一天的话，从左往右做一遍第 8 章的 DP 就行。D 天每天重做，要 4 万 × 5 万 = 2 × 10⁹ 步，太慢。每天只改一台机器，应该只重算受它影响的那一点。

把机器放进线段树。一块要记什么，才能用两半合出整块？只记“这一块最多挤多少”不够：左半最好的方案用了它最右一台，右半最好的方案用了它最左一台，两台挨着，不能直接相加。所以一块要分四种情况记：最左一台许不许用、最右一台许不许用。`best[a][b]` 是：a 为 1 表示最左一台可以用，为 0 表示不许用；b 同样管最右一台；在这个限制下这一块最多挤多少。

合并时只看交界处。左半的最右一台和右半的最左一台不能都开，于是要么左半的最右一台不许用，要么右半的最左一台不许用，两种取大的。“不许用”只会让答案变小或不变，所以两种情况合起来就盖住了所有合法的开法。只有一台的块：两端是同一台，两端都许用时它可以开，答案是它的产量，其余三种都是 0。

下面是**完整程序 A**。机器从 0 编号，一块管 [left, right)。`build` 和 `change` 调用自己，用的是第 2 章《函数可以请自己处理剩下的事》讲的递归。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

// best[a][b]：这一块最多挤多少。a 为 1 表示最左一台可以用，为 0 表示不许用；b 管最右一台
struct Piece {
    long long best[2][2];
};

std::vector<Piece> tree;
std::vector<long long> milk;

Piece single(long long amount) {
    Piece piece;
    piece.best[0][0] = 0;
    piece.best[0][1] = 0;
    piece.best[1][0] = 0;
    piece.best[1][1] = amount;  // 只有一台：两端都许用时才能开
    return piece;
}

Piece merge(const Piece& left, const Piece& right) {
    Piece piece;
    for (int a = 0; a < 2; ++a) {
        for (int b = 0; b < 2; ++b) {
            // 交界处两台不能都开：左半最右一台不许用，或右半最左一台不许用
            piece.best[a][b] = std::max(left.best[a][0] + right.best[1][b],
                                        left.best[a][1] + right.best[0][b]);
        }
    }
    return piece;
}

// 第 node 块管 [left, right)
void build(int node, int left, int right) {
    if (right - left == 1) {
        tree[node] = single(milk[left]);
        return;
    }
    int mid = (left + right) / 2;
    build(2 * node, left, mid);
    build(2 * node + 1, mid, right);
    tree[node] = merge(tree[2 * node], tree[2 * node + 1]);
}

// milk[position] 刚改过，重算所有管着它的块
void change(int node, int left, int right, int position) {
    if (right - left == 1) {
        tree[node] = single(milk[position]);
        return;
    }
    int mid = (left + right) / 2;
    if (position < mid) {
        change(2 * node, left, mid, position);
    } else {
        change(2 * node + 1, mid, right, position);
    }
    tree[node] = merge(tree[2 * node], tree[2 * node + 1]);
}

int main() {
    int n = 0;
    int days = 0;
    if (std::scanf("%d%d", &n, &days) != 2) {
        return 1;
    }
    milk.assign(n, 0);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%lld", &milk[i]) != 1) {
            return 1;
        }
    }
    tree.resize(4 * n);
    build(1, 0, n);
    long long total = 0;
    for (int day = 0; day < days; ++day) {
        int machine = 0;
        long long amount = 0;
        if (std::scanf("%d%lld", &machine, &amount) != 2) {
            return 1;
        }
        milk[machine - 1] = amount;
        change(1, 0, n, machine - 1);
        total += tree[1].best[1][1];  // 整排两端都没有限制
    }
    std::printf("%lld\n", total);
    return 0;
}
```

一天的最多产量可到 4 万 × 10⁵ = 4 × 10⁹，已经超过 `int`，所以块里的数也用 `long long`。递归每深一层，块的长度减半，至多 log N + 1 层，不会太深。每天 `change` 走一条从上到下的路，合并 log N 次，D 天共 O(D log N)。

慢办法每天照题意从左往右做一遍 DP：手里记“到这一台为止、这一台开或不开时最多多少”。和程序 A 在 300 组随机数据上对拍，每组至多 7 台机器、5 天，产量在 1 到 6 之间，答案全部相同。慢程序没有用到“四种情况”的合并。

## 便条不能随意交换次序

现在要给一整段加同一个数。照上一节，[1, 7) 里的每个数各改一次，每次 log N，一段长 N 就是 N log N，太慢。

开头的年级组长给了办法。查一段时，[1, 7) 拆成了四块；改一段时也只动这四块：每块的最小值加上 c，再在块上记一张便条“这一块里每个数还欠着加 c，下面的小块还不知道”。下次要往这一块的里面走，不论是查还是改，先把便条交给两个孩子，再往下。这张便条叫**懒标记**：工作没有消失，只是推迟到有人要看下面的时候。

下面是**片段**，放在 `main` 外面。`low[k]` 是第 k 块的最小值，`pending[k]` 是第 k 块的便条，开始都按原数建好、便条全为 0。

```cpp
std::vector<long long> low;      // 这一块的最小值（便条已经算进去了）
std::vector<long long> pending;  // 这一块每个数还欠着加多少，孩子还不知道

void apply(int node, long long value) {
    low[node] += value;
    pending[node] += value;
}

void push_down(int node) {
    if (pending[node] != 0) {
        apply(2 * node, pending[node]);
        apply(2 * node + 1, pending[node]);
        pending[node] = 0;
    }
}

// 给 [from, to) 里每个数加 value；第 node 块管 [left, right)
void add_range(int node, int left, int right, int from, int to, long long value) {
    if (to <= left || right <= from) {
        return;
    }
    if (from <= left && right <= to) {
        apply(node, value);  // 整块都要加：记一张便条就停
        return;
    }
    push_down(node);
    int mid = (left + right) / 2;
    add_range(2 * node, left, mid, from, to, value);
    add_range(2 * node + 1, mid, right, from, to, value);
    low[node] = std::min(low[2 * node], low[2 * node + 1]);
}

// [from, to) 里的最小值
long long min_range(int node, int left, int right, int from, int to) {
    if (to <= left || right <= from) {
        return NONE;  // 不相交的块不参与；NONE 是一个比所有数都大的常数
    }
    if (from <= left && right <= to) {
        return low[node];
    }
    push_down(node);
    int mid = (left + right) / 2;
    return std::min(min_range(2 * node, left, mid, from, to),
                    min_range(2 * node + 1, mid, right, from, to));
}
```

`apply` 改的 `low[node]` 立刻就是对的：整块每个数都加 c，最小值也加 c。便条只是还没告诉孩子。所以查到一块完全落在范围里时，直接拿 `low[node]`，不必下传。改一段和查一段用到的块，和上一节一样不超过 4 log N 块，便条下传只在这些块上发生。

便条能这样累加，是因为两次加法可以合并成一次：先欠 3、再欠 5，就是欠 8，先后无所谓。换一种修改，就不一定了。“把整段改成 v”这种便条，后来的一张会盖掉先来的一张，只留最新的。要是同一棵树上既有“整段加 c”又有“整段改成 v”，一张便条就得写清两者的先后：先改成 v 再加 c，等于改成 v + c；先加 c 再改成 v，等于只改成 v。往下传的时候，孩子身上原来的便条在前，父亲传下来的在后，合并时次序不能颠倒。

### 安排座位

餐厅一排 N 个座位（到 50 万），开始都空。依次发生 M 件事（到 30 万），只有两种：来了 p 位客人，要坐一段连续的 p 个空座，有多段可坐时选最靠左的一段，坐不下就离开；或者座位 a 到 b 上的客人全部离开。问一共有几批客人被拒绝。

输入第一行 N 和 M；接下来 M 行，每行是 `A p` 或 `L a b`。输出一个整数。

样例输入：

```text
10 4
A 6
L 2 4
A 5
A 2
```

样例输出：

```text
1
```

6 位客人坐 1 到 6。2 到 4 号离开后，空座是 2–4 和 7–10 两段，最长 4 个，5 位客人坐不下，被拒绝。最后 2 位坐 2、3 号。这是 USACO 2013 年 1 月金组第三题[“安排座位”](../USACO/金组/2012_2013/2013.01/P3.md)。

线段树的一块要回答“里面最长的一段空座有多长”。光记这个数合不出整块：最长的一段可能跨过中线，一半在左、一半在右。所以每块记三个数：最长空段、从左端开始的空段长、到右端结束的空段长。整块的最长空段，是左半的最长、右半的最长、左半的右端空段加右半的左端空段，三者里最大的。整块的左端空段，通常就是左半的左端空段；但左半全空时，还要接上右半的左端空段。右端同理。

两种事件都是整段改：坐下是把一段改成“满”，离开是改成“空”。便条就是“整块改成满”或“整块改成空”，新的一张盖掉旧的。一块被改成空，三个数都等于块长；改成满，三个数都是 0。

找最靠左的一段：从最上面那块往下，左半的最长空段够 p，就进左半；不够，看跨中线的那一段，左半右端空段加右半左端空段够 p，起点就是中线往左数左半右端空段那么多；再不够才进右半。先左、再中、后右，找到的就是最靠左的。

## 核对

1. 第一块（5）：`best[1][1]` 是 5，其余 0；第二块（3）同理是 3。合并后 `best[1][1]` = max(左[1][0] + 右[1][1], 左[1][1] + 右[0][1]) = max(0 + 3, 5 + 0) = 5。只取第一种情况时，这个例子得到 0 + 3 = 3，算错：它硬要左边那台不许用。样例也会算错，输出 6 而不是 32，因为每一层合并都强行关掉了左半最右的一台。
2. 先乘 2 再加 3：2x + 3。先加 3 再乘 2：2x + 6。两种不同，便条要记次序。“乘 a 再加 b”能合成：先 (a₁, b₁) 再 (a₂, b₂)，x 变成 a₂(a₁x + b₁) + b₂ = (a₁a₂)x + (a₂b₁ + b₂)，仍是同一种形式。
3. `L 1 10` 后全空；`A 10` 坐满 1 到 10；`A 1` 没有空座，被拒绝（这是第二批被拒绝的）。最后整排全满，三个数都是 0。
