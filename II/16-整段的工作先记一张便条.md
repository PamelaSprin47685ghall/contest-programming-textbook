# 16　整段的工作先记一张便条

八盆花，左半每盆都加 2 毫升水。若只问总量，知道左半有四盆，总量加 8 就够了，不必立刻跑到每个花盆旁边登记。

## 把一排分成左右两半

线段树的每个节点负责一段半开区间，孩子各管一半。节点保存这段的总和。一个任意区间能拆成 `O(log n)` 个这样的完整块。

区间全部被修改覆盖时，更新节点总和，并记下一张“每项还欠加多少”的便条，叫**懒标记**。需要继续进入孩子时，先把便条传下去，再处理更细的区间。父节点的总和已经是最新值，不能传下去以后再给自己重复加一次。

**停笔 1**　长 4 的块每项加 3，总和应加几？两次分别加 3、减 1，便条可以合成多少？

**完整程序：**输入 `1 <= n <= 100000`、`0 <= q <= 100000`，初始全为零。操作 `A left right value` 给合法半开区间加数，`S left right` 查询和。增量绝对值不超过一百万。

```cpp
#include <cstdio>
#include <vector>

class RangeSums {
    int length;
    std::vector<long long> total;
    std::vector<long long> pending;
    void apply(int node, int left, int right, long long value) {
        total[node] += value * (right - left);
        pending[node] += value;
    }
    void push(int node, int left, int right) {
        if (pending[node] == 0 || right - left == 1) {
            return;
        }
        int middle = left + (right - left) / 2;
        apply(node * 2, left, middle, pending[node]);
        apply(node * 2 + 1, middle, right, pending[node]);
        pending[node] = 0;
    }
    void add(int node, int left, int right, int from, int to, long long value) {
        if (to <= left || right <= from) {
            return;
        }
        if (from <= left && right <= to) {
            apply(node, left, right, value);
            return;
        }
        push(node, left, right);
        int middle = left + (right - left) / 2;
        add(node * 2, left, middle, from, to, value);
        add(node * 2 + 1, middle, right, from, to, value);
        total[node] = total[node * 2] + total[node * 2 + 1];
    }
    long long sum(int node, int left, int right, int from, int to) {
        if (to <= left || right <= from) {
            return 0;
        }
        if (from <= left && right <= to) {
            return total[node];
        }
        push(node, left, right);
        int middle = left + (right - left) / 2;
        return sum(node * 2, left, middle, from, to)
             + sum(node * 2 + 1, middle, right, from, to);
    }
public:
    explicit RangeSums(int n) : length(n), total(4 * n, 0), pending(4 * n, 0) {}
    void add(int left, int right, long long value) {
        add(1, 0, length, left, right, value);
    }
    long long sum(int left, int right) {
        return sum(1, 0, length, left, right);
    }
};

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2 || n < 1 || n > 100000 || q < 0 || q > 100000) {
        return 1;
    }
    RangeSums values(n);
    for (int i = 0; i < q; ++i) {
        char kind = '\0';
        int left = 0;
        int right = 0;
        if (std::scanf(" %c%d%d", &kind, &left, &right) != 3 || left < 0 || left > right || right > n) {
            return 1;
        }
        if (kind == 'A') {
            int value = 0;
            if (std::scanf("%d", &value) != 1) {
                return 1;
            }
            values.add(left, right, value);
        } else if (kind == 'S') {
            std::printf("%lld\n", values.sum(left, right));
        } else {
            return 1;
        }
    }
    return 0;
}
```

输入：

```text
4 5
A 0 4 3
A 1 3 -1
S 0 4
S 1 2
S 2 2
```

输出：

```text
10
2
0
```

每次 `O(log n)`，空间 `O(n)`。空区间没有贡献。查询会下传便条，因此这份 `sum` 不是 `const`；外面拿到的却始终只是数值，不能改内部数组。

## 便条不能随意交换次序

先把一段设为 5，再加 2，等于设为 7；先加 2，再设为 5，等于设为 5。若同时支持赋值与加法，必须规定标记怎样按时间合成，不能用“有个数就是懒标记”蒙混过去。

节点信息还可换成最小值、最大值，或一组能从两孩子合并的记录；区间操作也必须能直接更新整块记录。若操作是给每项取平方根，不能只从总和推出新总和，这种简单懒标记就不够。

**停笔 2**　两段数据 `[0,4]` 与 `[2,2]` 的和相同。每项平方后，和分别多少？这说明只存总和缺少什么？

**停笔 3**　若只改一个点、问前缀和，树状数组与线段树都能做。为什么不因为线段树更通用，就在所有题里都用它？

## 核对

1. 加 12；合成每项加 2。
2. 16 与 8。相同总和不能决定平方和；必须增加合适的信息或改算法。
3. 树状数组更短、占空间少，约束已足够时无需承担额外复杂度。选能准确表达操作的最简单结构。
