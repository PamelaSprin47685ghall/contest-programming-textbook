# 17　每次只请最合适的一项出来

绳子不断合并，每合并两根，又产生一根新绳子。完整排序一次不够，每轮重新排序又太浪费。我们只需要知道当前最短的是谁。

## 整排不用有序，只要每位家长不比孩子大

用数组保存一棵尽量填满的二叉树。下标 `i` 的孩子是 `2*i+1`、`2*i+2`，父亲是 `(i-1)/2`。小根堆要求父亲不大于孩子，因此根是全体最小值；左右孩子之间不要求有序。

加入时先放尾部，再向上交换到不违反规则的位置。删除最小值时，把最后一项搬到根，删尾，再不断与较小的孩子交换。每次走一条树高，所以为 `O(log n)`。

## 让堆自己维护自己的规矩

**完整程序：**输入 `0 <= n <= 100000` 及 `n` 个 1 到一百万的绳长。两根合并代价为长度之和，输出合成一根的最小总代价；少于两根时代价为零。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

class MinHeap {
    std::vector<long long> values;
public:
    int size() const {
        return static_cast<int>(values.size());
    }
    void push(long long value) {
        values.emplace_back(value);
        int i = size() - 1;
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (values[parent] <= values[i]) {
                break;
            }
            std::swap(values[parent], values[i]);
            i = parent;
        }
    }
    long long take_min() {
        long long answer = values.front();
        values.front() = values.back();
        values.pop_back();
        int i = 0;
        while (2 * i + 1 < size()) {
            int child = 2 * i + 1;
            if (child + 1 < size() && values[child + 1] < values[child]) {
                ++child;
            }
            if (values[i] <= values[child]) {
                break;
            }
            std::swap(values[i], values[child]);
            i = child;
        }
        return answer;
    }
};

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 0 || n > 100000) {
        return 1;
    }
    MinHeap lengths;
    for (int i = 0; i < n; ++i) {
        int value = 0;
        if (std::scanf("%d", &value) != 1 || value < 1 || value > 1000000) {
            return 1;
        }
        lengths.push(value);
    }
    long long cost = 0;
    while (lengths.size() > 1) {
        long long first = lengths.take_min();
        long long second = lengths.take_min();
        long long combined = first + second;
        cost += combined;
        lengths.push(combined);
    }
    std::printf("%lld\n", cost);
    return 0;
}
```

输入：

```text
3
1 2 10
```

输出：

```text
16
```

`take_min` 的前提是非空；调用者先按数量判断。内部数组私有，外面不能把根改大而不调整。空间 `O(n)`，合并全过程 `O(n log n)`；正确选最短两根的理由在第 9 章。

## 建堆与排序不是一回事

逐项加入是 `O(n log n)` 上界。若全部数据已到齐，从最后一个有孩子的点向前逐个下沉，能在 `O(n)` 建堆：底层点多，却各自只能下沉很少层；能下沉很多层的点很少。

反复交换堆顶与末尾，再缩小堆区并下沉，可做堆排序。若建大根堆，最大数被依次放到后面，最终升序，最坏 `O(n log n)`。

堆不能高效回答任意一个值是否存在，也不支持直接取第 `k` 小。要支持排名，需在有序结构里另外维护子树大小；第三卷会看到这份信息怎样随结构变化。

## 核对

1. 是；父子关系都成立。兄弟的大小关系不受要求。
2. 不能，只会看到同一根。新绳子必须重新与所有剩余绳子比较，不能预先固定后续配对。
3. 依次合成 2、2、4，代价 8。新绳子可能更短，例如 1、1、100 合出 2，仍比 100 短。
