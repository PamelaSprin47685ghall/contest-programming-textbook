# 18　找文字时别总是退回开头

在 `abababa` 中找 `aba`，有三次，起点是 0、2、4。找到一次后跳过整段，会漏掉重叠的出现；每次失败都从头比较，又可能很慢。

本章先处理单字节 ASCII。UTF-8 中文要按题意区分字节、编码点与可见文字，不能把本章下标直接叫作“第几个汉字”。

## 失败之前的比较也提供信息

已匹配 `abab`，下一字节不合。已知末尾的 `ab` 同时是模式开头，不用把它们再比一次。字符串既是前缀又是后缀的部分，叫**边缀**；这里的边缀要求比整串短。

`prefix[i]` 是模式前 `i+1` 个字节的最长边缀长度。模式 `ababa` 得到 `0,0,1,2,3`。不匹配时，让当前匹配长度退到其最长边缀，继续试；不是文本下标向后退。

这是 KMP 算法。K、M、P 来自三位研究者的名字，是名字缩写，不必硬译成另一套术语。

**停笔 1**　`aaaa` 的前缀表是什么？`abcd` 呢？为什么不能把“整个前缀自己”算成边缀？

**完整程序：**依次输入非空 ASCII 模式和文本，均不含空白，长度各不超过一百万。逐行输出所有出现起点，允许重叠；没有则输出 `NONE`。

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::string pattern;
    std::string text;
    if (!(std::cin >> pattern >> text) || pattern.empty()
        || pattern.size() > 1000000 || text.size() > 1000000) {
        return 1;
    }
    int m = static_cast<int>(pattern.size());
    std::vector<int> prefix(m, 0);
    for (int i = 1; i < m; ++i) {
        int j = prefix[i - 1];
        while (j > 0 && pattern[i] != pattern[j]) {
            j = prefix[j - 1];
        }
        if (pattern[i] == pattern[j]) {
            ++j;
        }
        prefix[i] = j;
    }
    int matched = 0;
    bool any = false;
    for (int i = 0; i < static_cast<int>(text.size()); ++i) {
        while (matched > 0 && text[i] != pattern[matched]) {
            matched = prefix[matched - 1];
        }
        if (text[i] == pattern[matched]) {
            ++matched;
        }
        if (matched == m) {
            std::cout << i - m + 1 << '\n';
            any = true;
            matched = prefix[matched - 1];
        }
    }
    if (!any) {
        std::cout << "NONE\n";
    }
    return 0;
}
```

输入：

```text
aba
abababa
```

输出：

```text
0
2
4
```

找到后退到最长边缀，而不是清零，因此保留重叠机会。匹配长度每次增加至多一，回退总次数不超过已经增加的次数；总时间 `O(模式长+文本长)`，额外空间 `O(模式长)`。

## 多个词，先把相同开头共用

登记 `cat`、`car`、`dog`。字典树 Trie 从根沿字母走，`cat` 与 `car` 共用 `c→a`，再分别走 `t`、`r`。节点要另记“这里是否有完整词”，否则登记 `card` 会错误地宣称 `car` 也已登记。

插入：从根逐字走，没有边就新建节点，最后加结束计数。查询完整词：同样走完，再看结束计数；查询前缀数量则在走到的节点看经过计数。总节点不超过所有词长之和加一。固定 26 个孩子适合小写英文字母，不适合不加思考地照搬到任意 Unicode。

哈希可把字符串映射为整数，快速筛选可能相同的对象，但碰撞意味着哈希相同不保证文字相同。若题目需要确定正确，可在候选处比较原文，或使用确定性字符串结构。第三卷再展开多模式、回文、后缀及周期。

**停笔 3**　模式 `aa`、文本 `aaaa`，有几个出现位置？为什么每找到一次便把文本下标加二会漏？

## 核对

1. 分别为 `0,1,2,3` 与 `0,0,0,0`。若允许自身，回退后长度不变，会丢掉“变短”的保证。
2. 结束 1，经过 3；走到 `ab` 后没有 `c` 边。结束与经过不是同一件事。
3. 三个，起点 0、1、2。中间那次与前一次重叠，不能跳掉。
