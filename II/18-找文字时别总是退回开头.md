# 18　找文字时别总是退回开头

在一本书里找“葡萄干”三个字。眼睛扫到“葡萄”，下一个字却是“酒”，没对上。这时不会把目光退回“葡”字后面一格重新看：刚才看过的“葡萄”里没有第二个“葡”，可以直接从“酒”往后找。比较失败了，失败之前对上的那几个字，已经告诉了我们该从哪里接着找。

这一章先把这件事做成一张表，让一次失败不白费；再看一次要找很多个词时，怎样把它们相同的开头放在一起，只走一遍。

## 失败之前的比较也提供信息

在长串 S 里找短串 T，最直接的做法是：从 S 的每个位置起，拿 T 逐字去比。S 长 N、T 长 M 时，最坏要比 N × M 次。例如 S 是一百万个 `a`，T 是 999 个 `a` 加一个 `b`：每个起点都要比到最后一个字才失败。

可是失败的时候，我们已经知道 S 里刚刚对上了 T 的前 j 个字。下一步该从 T 的第几个字接着比，只取决于 T 自己，不取决于 S。

### 一张只看 T 自己的表

对 T 的每个开头，问：这一段的结尾，最长能和 T 的哪一段开头重合（不算整段自己）？记 `fail[i]` 为 T 的前 i + 1 个字里，这样重合的最长长度。拿 T = `aabaa` 算：

| i | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 前 i + 1 个字 | a | aa | aab | aaba | aabaa |
| fail[i] | 0 | 1 | 0 | 1 | 2 |

`aabaa` 的结尾 `aa` 正好是开头的 `aa`，所以 `fail[4]` 是 2；结尾 `baa` 和开头 `aab` 不同，更长的也不行。

用法是这样：在 S 里已经对上 T 的前 j 个字，下一个字对不上，就把 j 改成 `fail[j - 1]` 再比；还对不上，再退；退到 0 为止。退一次，等于把 T 往右挪，挪到“已经对上的这几个字的结尾”和 T 的开头仍然重合的最远处。中间那些起点都不必试：从那里开始，连已经看过的这几个字都对不上。

在 S = `aabaabaa` 里找 `aabaa`：前五个字对上，j = 5，找到一处，从 0 开始。不退回 S 的开头，而是令 j = `fail[4]` = 2，表示 S 末尾刚看过的 `aa` 已经是 T 的前两个字。接着 S 的 `b` 对上 T 的第 3 个字，`a`、`a` 也对上，j 又到 5，第二处从 3 开始。S 的每个字只看了一次。

这张表本身也这样算：T 和自己比。下面是**片段**：

```cpp
// 位于 main 内；word 是要找的词，m 是它的长度
std::vector<int> fail(m, 0);
for (int i = 1; i < m; ++i) {
    int j = fail[i - 1];  // 前 i 个字的结尾，已经和开头重合了 j 个
    while (j > 0 && word[i] != word[j]) {
        j = fail[j - 1];
    }
    if (word[i] == word[j]) {
        ++j;
    }
    fail[i] = j;
}
```

`while` 看上去会转很多圈，但用[第 1 章](01-先问办法靠不靠谱.md)的均摊分析数整件事：j 每轮至多加 1，每退一次至少减 1，又不会小于 0，所以退的总次数不超过加的总次数，也就是不超过 M。在 S 里找 T 同理，总共 O(N + M)。这个办法叫 **KMP 算法**，`fail` 叫 T 的**失败函数**。

### 字符串审查

一本杂志的全文是字符串 S（长不超过 10⁶），要删掉其中出现的 T（T 不比 S 长）。删法是：找到 S 里第一次出现的 T，删掉，再找、再删，直到没有 T。删掉一处以后，两边的字可能拼出新的 T。S、T 只含小写字母，题目保证 S 不会被删空。输出删完以后的 S。

输入两行，第一行 S，第二行 T。

样例输入：

```text
whatthemomooofun
moo
```

样例输出：

```text
whatthefun
```

先删中间的 `moo`，剩 `whatthemoofun`，又拼出一个 `moo`，再删，剩 `whatthefun`。这是 USACO 2015 年 2 月银组第一题[“字符串审查”](../USACO/银组/2014_2015/2015.02/P1.md)。

[第一卷第 15 章](../I/15-按访问方式挑容器.md)见过它的铜组版：T 不超过 100 个字，把结果当作栈，每放进一个字，就看栈顶的 |T| 个字是不是 T。银组的 T 可以长到一百万，每次都比 |T| 个字就太慢了。

栈的想法仍然对：从左往右一个字一个字地放进结果，最早凑齐的 T 一定在结果的末尾。所有 T 一样长，最早结束的那一处也就是最早开始的那一处，所以每次一凑齐就删，正是“删第一次出现的 T”。

要改的只是“末尾是不是 T”怎样判断。给结果里的每个字记一个数：放进这个字以后，结果的末尾和 T 的开头对上了几个字。放进新字时，从栈顶那个字的数出发，用失败函数往下比，一步得出新字的数。数到了 M，就删掉末尾 M 个字，连同它们的数一起删。删完以后，栈顶那个字的数还是当初算好的，正好接着用。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <string>
#include <vector>

int main() {
    std::vector<char> buffer(1000001);
    if (std::scanf("%1000000s", buffer.data()) != 1) {
        return 1;
    }
    std::string text = buffer.data();
    if (std::scanf("%1000000s", buffer.data()) != 1) {
        return 1;
    }
    std::string word = buffer.data();
    int m = word.size();
    // fail[i]：word 前 i + 1 个字的结尾，最长能和 word 的开头重合几个字（不算整段）
    std::vector<int> fail(m, 0);
    for (int i = 1; i < m; ++i) {
        int j = fail[i - 1];  // 前 i 个字的结尾，已经和开头重合了 j 个
        while (j > 0 && word[i] != word[j]) {
            j = fail[j - 1];
        }
        if (word[i] == word[j]) {
            ++j;
        }
        fail[i] = j;
    }
    std::string kept;             // 审查过的结果，当栈用
    std::vector<int> matched{0};  // matched[k]：kept 的前 k 个字，末尾和 word 的开头对上几个
    for (char letter : text) {
        int j = matched.back();
        while (j > 0 && letter != word[j]) {
            j = fail[j - 1];
        }
        if (letter == word[j]) {
            ++j;
        }
        kept.push_back(letter);
        matched.push_back(j);
        if (j == m) {  // 末尾刚好凑成 word：删掉，栈顶的进度还是当初算好的
            kept.resize(kept.size() - m);
            matched.resize(matched.size() - m);
        }
    }
    std::printf("%s\n", kept.c_str());
    return 0;
}
```

`matched` 比 `kept` 多一格，第 0 格是“结果为空时对上 0 个”，所以删光以后 `matched.back()` 仍然存在。j 一到 m 就删，留下来的数都小于 m，`word[j]` 不会越界。`%1000000s` 给读入限了宽度，`buffer` 多留一格放结尾的空字符。

工作量还是 O(N + M) 吗？删除会让 j 从 0 一下子恢复到很大的数，上面的均摊理由要补一句。退的总次数，不超过 j 增加的总量。j 增加有两种：放进一个字时至多加 1，共不超过 N；删除后恢复成栈顶的数，至多 M − 1，而每删一次要先放进 M 个字，删的次数不超过 N / M，恢复的总量也不超过 N。加起来不超过 2N，再加上算失败函数的 M。

慢办法照题意写：反复在整串里找第一处 T、删掉，直到找不到。和程序 A 对拍 300 组，S 至多 12 个字、T 至多 3 个字，都只用 `a`、`b` 两个字母，这样才常常删出新的 T。答案全部相同。

## 多个词，先把相同开头共用

要找的词不止一个时，一个个去找，相同的开头就被看了很多遍。`cat`、`car`、`cow` 都以 `c` 开头，前两个还都以 `ca` 开头。

把它们画成一棵树：根代表空串，每条边上写一个字母，从根往下走一条路，读到的字母连起来就是一个开头。`cat`、`car`、`cow`、`do` 四个词，根下面有 `c` 和 `d` 两个孩子；`c` 下面有 `a` 和 `o`；`ca` 下面有 `t` 和 `r`；`co` 下面有 `w`；`d` 下面有 `o`。词在哪个节点结束，就在那里做个记号。相同的开头只占一条路。这棵树叫**前缀树**。

存的时候，每个节点记 26 个孩子的编号，没有就记 −1。下面是**片段**，放在 `main` 外面；开始时只有根，编号 0。

```cpp
std::vector<std::vector<int>> child{std::vector<int>(26, -1)};  // child[node][c]：沿字母 'a' + c 往下到哪个节点
std::vector<bool> word_end{false};  // 有没有词恰好在这个节点结束

void insert(const std::string& word) {
    int node = 0;
    for (char letter : word) {
        int c = letter - 'a';
        if (child[node][c] == -1) {
            child[node][c] = child.size();  // 新节点的编号，就是它在表里的位置
            child.push_back(std::vector<int>(26, -1));
            word_end.push_back(false);
        }
        node = child[node][c];
    }
    word_end[node] = true;
}
```

插入一个词，走过它的每个字，最多新开那么多个节点。所有词的总长是 L 时，节点不超过 L + 1 个。

### 谁排第一

给 N 个互不相同的字符串（到 3 万个，总长到 30 万），只含小写字母。比较两个串时，找第一个不同的位置，谁的字母在字母表里靠前谁就小；一个串是另一个的开头时，短的小。现在字母表的顺序可以随意重排。问哪些串能在某一种字母表顺序下排在所有串的最前面。

输入第一行 N，接下来 N 行各一个串。输出第一行是能排第一的串的个数，然后按输入顺序列出它们。

样例输入：

```text
4
omm
moo
mom
ommnom
```

样例输出：

```text
2
omm
mom
```

普通字母表里 `m` 在 `o` 前面，`mom` 最小。让 `o` 排在 `m` 前面，`omm` 最小。`ommnom` 以 `omm` 开头，总比 `omm` 大。`moo` 要排第一，得先比 `mom` 小，那要 `o` 在 `m` 前面；又得比 `omm` 小，那要 `m` 在 `o` 前面，做不到。这是 USACO 2012 年 12 月金组第二题[“谁排第一”](../USACO/金组/2012_2013/2012.12/P2.md)。

把所有串放进前缀树。一个串 w 想排第一，沿着它的路从根往下走。走到一个节点，w 要走的字母是 c，这个节点还有别的孩子 d，说明有别的串和 w 在这里分开，w 要比它们小，字母表里 c 必须排在 d 前面。路上要是有别的串已经结束了，那个串是 w 的开头，总比 w 小，w 不可能排第一。

这样收集到一批“c 在 d 前面”的要求。它们能不能同时满足？把 26 个字母当作点，“c 在 d 前面”画成从 c 到 d 的箭头，这正是[第 11 章](11-等前面的事做完再开始.md)《等前面的事做完再开始》里的“必须先于”。能排出一个顺序，当且仅当这些箭头不绕成圈。

下面是收集要求的**片段**，接在 `insert` 后面，同样放在 `main` 外面。

```cpp
// w 想排第一：沿路把“字母 c 要排在 d 前面”记进 before[c][d]；路上有别的词先结束，返回 false
bool collect(const std::string& word, std::vector<std::vector<bool>>& before) {
    int node = 0;
    for (char letter : word) {
        if (word_end[node]) {
            return false;  // 一个更短的词是它的开头，总排在它前面
        }
        int c = letter - 'a';
        for (int other = 0; other < 26; ++other) {
            if (other != c && child[node][other] != -1) {
                before[c][other] = true;
            }
        }
        node = child[node][c];
    }
    return true;
}
```

每个串收集完，在 26 个点上检查有没有圈：照第 11 章的办法，反复拿走没有箭头指向的字母，拿不完就有圈。每个串的检查至多看 26 × 26 个格子，3 万个串约 2 × 10⁷ 次，来得及。收集时每个字看 26 个孩子，总共 26 × 30 万次。

拿样例的 `moo` 走一遍：根有 `o`、`m` 两个孩子，它走 `m`，记“m 在 o 前面”；`m` 下面只有 `o`；`mo` 下面有 `o`、`m`，它走 `o`，记“o 在 m 前面”。两个箭头绕成圈，不行。`ommnom` 走到 `omm` 时，那里有词结束，直接不行。

把这两个片段和一个检查圈的函数接起来，和慢办法对拍：慢办法只用 `a`、`b`、`c` 三个字母造串，试遍 6 种字母表顺序，每种找出最小的串。300 组至多 6 个串、每串至多 4 个字的数据，答案全部相同。

## 核对

1. `abcab`：0、0、0、1、2。`aaaa`：0、1、2、3。在 `aaaaa` 里，第一处从 0 开始；找到时 j = 4，退到 `fail[3]` = 3，下一个 `a` 让 j 回到 4，第二处从 1 开始。
2. 放 `a`：`kept` 为 `a`，新记的数是 1。放 `a`：`aa`，1。放 `b`：2，凑齐，删去 `ab`，剩 `a`，栈顶的数是 1。放 `a`：`aa`，1。放 `b`：2，删，剩 `a`。放 `b`：`ab`，2，删，剩空，`matched` 只剩第 0 格的 0。放 `a`：`a`，1。输出 `a`。
3. `ab`：根下有 `a`、`b`、`c`，记 a 在 b 前、a 在 c 前；`a` 下有 `b`、`c`，记 b 在 c 前。不成圈，能。`ac`：a 在 b、c 前；c 在 b 前。不成圈，能。`b`：b 在 a 前、b 在 c 前，能。`ca`：c 在 a、b 前，`c` 下只有 `a`，能。四个都能。
