# 19　整数身上也有线索

一盒糖要平均分给几位同学，一个不剩。糖有 36 颗，能分给几个人？不必从 1 试到 36：分给 4 人能行，那么分给 9 人也能行，因为 4 × 9 = 36。因数总是一对一对出现的，找到小的那个，大的就跟着来了。

前面几章的数，只用来比大小、做加法。这一章看整数自己带着的线索：谁能整除谁，余数是几，从 n 个里挑 k 个有几种挑法。这些线索能一下子划掉大批候选。

## 一个整除关系能减少很多候选

两个正整数 a、b，能同时整除它们的最大的数，叫它们的**最大公约数**，记作 gcd(a, b)。

求它不必试遍所有数。若 d 同时整除 a 和 b（设 a ≥ b），它也整除 a − b；反过来，同时整除 a − b 和 b 的数也整除 a。所以 a、b 的公约数和 a − b、b 的公约数是同一批，最大的那个也相同。减一次 b 可以，减很多次也可以，一直减到比 b 小，剩下的就是 a 除以 b 的余数。于是 gcd(a, b) = gcd(b, a mod b)，一直做到余数为 0，最后那个不为 0 的数就是答案。

算 gcd(84, 36)：84 除以 36 余 12；36 除以 12 余 0。答案是 12。

这个办法叫**辗转相除**。它很快：每做两步，较大的那个数至少减半（a mod b 要么小于 b，b 本身不超过 a 的一半；要么 b 超过 a 的一半，余数 a − b 不到 a 的一半）。所以对 10¹⁸ 以内的数，至多一百多步。

“减很多次 b，一次做完”，这一步本身就是一条经验：一样的减法重复很多遍时，用一次除法算出次数。下面这道题就用它。

### 变换数对

两堆干草，分别有 a 捆和 b 捆（1 到 10¹⁸）。贝茜可以反复念两种咒语：让第一堆增加“当前第二堆的数量”，或者让第二堆增加“当前第一堆的数量”。问最少念几次，两堆恰好变成 c 捆和 d 捆（1 到 10¹⁸）；做不到输出 −1。有 T 组数据（到 10⁴）。

输入第一行 T，接下来 T 行，每行 a、b、c、d。每组输出一行。

样例输入：

```text
4
5 3 5 2
5 3 8 19
5 3 19 8
5 3 5 3
```

样例输出：

```text
-1
3
-1
0
```

两堆只会变多，第二堆从 3 变不成 2，所以第一组是 −1。第二组：(5, 3) → (8, 3) → (8, 11) → (8, 19)，三次。第四组本来就相同，零次。这是 USACO 2025 年 2 月银组第三题[“变换数对”](../USACO/银组/2024_2025/2025.02/P3.md)。

从 (a, b) 往前推，每一步有两种走法，十几步就有上万条路。倒过来推却只有一条路。看最后一步：念完咒语以后，被加的那一堆等于两堆原来的和，一定比另一堆大。所以 (c, d) 里大的那一堆是最后被加的，它原来的数是两者之差。c 和 d 相等时，不是起点就无路可退：念过咒语以后两堆不可能相等。

一步一步退，像辗转相除里一次次减 b，可能要退 10¹⁸ 步。合成一次：c > d 时，c 要一直减 d，减到不比 a 小的最后一次，可以减 (c − a) / d 次（整数除法）；少于一次时也要减一次，减完会比 a 小，下一轮就判定做不到。

拿第二组走一遍：(8, 19)，19 > 8，可以减 (19 − 3) / 8 = 2 次，到 (8, 3)，记 2 次。8 > 3，减 (8 − 5) / 3 = 1 次，到 (5, 3)，共 3 次。第三组 (19, 8)：减 (19 − 5) / 8 = 1 次，到 (11, 8)；再减 (11 − 5) / 8 = 0 次，按一次算，到 (3, 8)，3 比 5 小，做不到。

每轮至少让较大的数减到不超过“较小的数加上 a 或 b”，轮数和辗转相除一样，是对数级的。

## 为什么试因子只需到平方根

36 的因数成对出现：1 和 36，2 和 18，3 和 12，4 和 9，6 和 6。每一对里，小的那个不超过 6，也就是 √36。所以要列出 n 的全部因数，只要让 t 从 1 试到 √n，每找到一个 t，就同时得到 n / t。n 到 10¹²，也只要试一百万次。

同样的道理，判断 n 是不是**质数**（大于 1、除了 1 和自己没有别的因数），只要试到 √n：n 要是有一个大于 √n 的因数，就有一个与它配对的、小于 √n 的因数，早该试到了。

写循环时用 `t * t <= n`，不要先算 `sqrt(n)` 再比：小数开方可能差一点点，`t` 正好等于平方根时会漏掉。`t * t` 在 n 接近 10¹⁸ 时也不会超过 `long long`，因为 t 至多 10⁹ 左右。

### 奶牛历法

一个星球上有 N 个月（1 到 10⁴），第 i 个月有 aᵢ 天（1 到 4 × 10⁹）。一周有 L 天，L 是正整数，满足两个条件：每个月至少有 4 周那么长；各月天数除以 L 的余数，至多有 3 种不同的值。求所有可能的 L 之和。

输入第一行 N，第二行 N 个天数。输出一个整数。

样例输入：

```text
12
31 28 31 30 31 30 31 31 30 31 30 31
```

样例输出：

```text
28
```

最短的月 28 天，所以 L ≤ 7。天数只有 28、30、31 三种，余数不可能超过 3 种，L 从 1 到 7 都行，和是 28。这是 USACO 2024 年 1 月银组第三题[“奶牛历法”](../USACO/银组/2023_2024/2024.01/P3.md)。

第一个条件给出 L ≤ 最短的月 / 4，可能到 10⁹，不能一个个试。先把天数排序去重。不同的天数不超过 3 种时，什么 L 都满足第二个条件，答案是 1 + 2 + … + L 的上限。

多于 3 种时，拿出最小的 4 种天数。余数至多 3 种，4 个数里一定有两个余数相同，它们的差能被 L 整除。所以 L 一定是这 4 个数两两之差（共 6 个差）中某一个的因数。每个差不超过 4 × 10⁹，用平方根的办法列出因数，每个约要试 6 万多次；一个数的因数通常只有几十到几百个，最多也不过一两千个。把这些候选逐个拿去检查全部月份即可。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

// 一周 week 天时，各月天数除以 week 的余数是不是至多 3 种
bool fits(const std::vector<long long>& months, long long week) {
    long long seen[3] = {0, 0, 0};
    int kinds = 0;
    for (long long days : months) {
        long long rest = days % week;
        bool found = false;
        for (int s = 0; s < kinds; ++s) {
            if (seen[s] == rest) {
                found = true;
            }
        }
        if (!found) {
            if (kinds == 3) {
                return false;  // 第 4 种余数
            }
            seen[kinds] = rest;
            ++kinds;
        }
    }
    return true;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<long long> months(n);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%lld", &months[i]) != 1) {
            return 1;
        }
    }
    std::sort(months.begin(), months.end());
    months.erase(std::unique(months.begin(), months.end()), months.end());
    long long longest_week = months[0] / 4;  // 每个月至少 4 周
    if (months.size() <= 3) {
        std::printf("%lld\n", longest_week * (longest_week + 1) / 2);
        return 0;
    }
    // 最小的 4 种天数里必有两个余数相同，L 整除它们的差
    std::vector<long long> candidates;
    for (int i = 0; i < 4; ++i) {
        for (int j = 0; j < i; ++j) {
            long long diff = months[i] - months[j];
            for (long long t = 1; t * t <= diff; ++t) {
                if (diff % t != 0) {
                    continue;
                }
                if (t <= longest_week) {
                    candidates.push_back(t);
                }
                if (diff / t <= longest_week) {
                    candidates.push_back(diff / t);
                }
            }
        }
    }
    std::sort(candidates.begin(), candidates.end());
    candidates.erase(std::unique(candidates.begin(), candidates.end()), candidates.end());
    long long total = 0;
    for (long long week : candidates) {
        if (fits(months, week)) {
            total += week;
        }
    }
    std::printf("%lld\n", total);
    return 0;
}
```

`t` 和 `diff / t` 相等时会被放进去两次，排序去重以后只剩一个，不会多加。去重用的是第一卷第 13 章的 `sort`、`unique`、`erase` 三步。L 的上限可到 10⁹，1 + 2 + … + 10⁹ 约 5 × 10¹⁷，`long long` 放得下。

去重不会改变答案：相同的天数余数也相同，不会多出一种余数。可是“最小的 4 种”一定要在去重以后取：要是取了两个相同的数，它们的差是 0，什么都推不出。

慢办法照题意，L 从 1 试到上限，每个都检查全部月份。300 组随机数据，每组至多 6 个月、天数在 4 到 60 之间，和程序 A 的答案全部相同。慢程序没有用到“4 个数里必有两个同余”这条理由。

## 余数里能做什么，不能做什么

只关心一个数除以 m 的余数时，加法、减法、乘法都可以先取余数再算，结果的余数不变。例如 37 × 58 除以 7 的余数：37 余 2，58 余 2，2 × 2 = 4，所以余 4；直接算 37 × 58 = 2146 = 7 × 306 + 4，对得上。计数题让答案除以 10⁹ + 7 取余数，就是靠这一条：每乘一次、加一次都取余，数永远不超过 10⁹ 左右，两数相乘不超过 10¹⁸，`long long` 放得下。

减法要小心。[第一卷第 2 章](../I/02-数字也有使用条件.md)说过，C++ 里负数的余数是负的：`(3 - 5) % 7` 是 −2，不是 5。所以写 `(a - b % m + m) % m`，先加上 m 再取余。

不能做的有两样。一是比大小：余数小，不说明原数小。二是除法：12 除以 7 余 5，6 除以 7 余 6，可是 12 / 2 = 6，5 / 2 却不是整数。余数里的“除法”能不能做、怎样做，要等第三卷第 18 章《让不同的余数说同一件事》。

余数还给出周期。看一个数是不是 3 或 5 的倍数，只要看它除以 15 的余数，所以每 15 个数，情况重复一遍。

### 哞哞报数

奶牛从 1 开始依次报数，遇到 3 的倍数或 5 的倍数就改说“哞”。给出 N（1 到 10⁹），问第 N 个被说出口的数是几。

输入一个整数 N，输出一个整数。

样例输入：

```text
4
```

样例输出：

```text
7
```

开头是 1、2、哞、4、哞、哞、7，被说出口的前四个数是 1、2、4、7。这是 USACO 2019 年 12 月银组第一题[“哞哞报数”](../USACO/银组/2019_2020/2019.12/P1.md)。

1 到 15 里，被说出口的是 1、2、4、7、8、11、13、14，共 8 个。下一段 16 到 30，是它们各加 15。所以第 N 个数在第 (N − 1) / 8 段（从 0 数），是这一段里第 (N − 1) mod 8 个（也从 0 数）。

**片段：**

```cpp
// 位于 main 内；n 已读入
const int said[8] = {1, 2, 4, 7, 8, 11, 13, 14};  // 1 到 15 里被说出口的数
long long rounds = (n - 1) / 8;                    // 前面有几个完整的 15
std::printf("%lld\n", rounds * 15 + said[(n - 1) % 8]);
```

N = 10⁹ 时，答案约 1.9 × 10⁹，超过 `int`，所以 `rounds` 用 `long long`，乘法也就在 `long long` 里做。用 N − 1 而不是 N，是为了让第 8 个数落在第 0 段的最后一格，而不是第 1 段的开头。

## 计数不一定要先算阶乘

从 n 个位置里挑 k 个，有几种挑法？这个数叫**组合数**，记作 C(n, k)。课本上的公式要先算 n 的阶乘，再除以 k 的阶乘和 n − k 的阶乘。可是 20 的阶乘就超过了 `long long`，先算阶乘再除，数早就放不下了；取了余数又不能做除法。

换一种算法。看第 n 个位置挑不挑：挑它，剩下 n − 1 个里还要挑 k − 1 个；不挑，剩下 n − 1 个里要挑 k 个。所以 C(n, k) = C(n − 1, k − 1) + C(n − 1, k)，再加上 C(n, 0) = 1。一行行往下算，只做加法，不会产生比答案更大的中间数，也可以每步取余。把它排成三角形，第 n 行第 k 个就是 C(n, k)：

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

每个数是它左上和正上两个数之和。

### 奶牛的编号

约翰只用恰好含 K 个 1 的二进制数当编号（1 ≤ K ≤ 10），从小到大分配，从 K 位全是 1 的那个开始。问第 N 个编号（1 ≤ N ≤ 10⁷）的二进制写法。

输入 N 和 K，输出一个没有前导 0 的二进制串。

样例输入：

```text
7 3
```

样例输出：

```text
10110
```

恰好含 3 个 1 的数从小到大是 111、1011、1101、1110、10011、10101、10110，第 7 个是 10110。这是 USACO 2012 年 2 月银组第二题[“奶牛的编号”](../USACO/银组/2011_2012/2012.02/P2.md)。

一个个数过去，K = 1 时第 10⁷ 个编号有一千万位，数不过来。先定位数：位数为 L 的编号，最高位是 1，后面 L − 1 位里放 K − 1 个 1，共 C(L − 1, K − 1) 个。从 L = K 开始，个数不够 N 就减去，换下一个 L。样例里 L = 3 有 1 个，L = 4 有 3 个，减去以后 N 剩 3，L = 5 有 C(4, 2) = 6 个，够了：要找 5 位编号里的第 3 个。

再一位位定。还剩 p 位、要放 r 个 1 时，这一位放 0 的编号排在前面，有 C(p − 1, r) 个。N 不超过它，就放 0；否则放 1，N 减去它，r 减 1。样例里第二位：剩 4 位放 2 个 1，放 0 的有 C(3, 2) = 3 个，N = 3 不超过，放 0。第三位：剩 3 位放 2 个，放 0 的有 C(2, 2) = 1 个，3 > 1，放 1，N 剩 2。第四位：剩 2 位放 1 个，放 0 的有 C(1, 1) = 1 个，2 > 1，放 1，N 剩 1。最后一位：剩 1 位放 0 个，放 0。得 10110。

组合数会很大：K = 10、位数上千时，C 远远超过 `long long`。但我们只拿它和 N 比大小，N 不超过 10⁷。所以超过某个比 10⁷ 大的数时，一律记成那个数，比较结果不变。

**片段：**

```cpp
// 位于 main 内；n、k 已读入，k 至少为 2（k 为 1 时，编号是 1 后面跟 n − 1 个 0）
const long long cap = 20000000;  // 比 n 的上限大；超过它的组合数都记成它
// choose[p][r]：p 个位置里放 r 个 1 的放法数，r 只用到 k − 1
std::vector<std::vector<long long>> choose{std::vector<long long>(k, 0)};
choose[0][0] = 1;
int length = k;
while (true) {
    while (static_cast<int>(choose.size()) < length) {
        const std::vector<long long>& last = choose.back();
        std::vector<long long> row(k, 0);
        row[0] = 1;
        for (int r = 1; r < k; ++r) {
            row[r] = std::min(cap, last[r - 1] + last[r]);
        }
        choose.push_back(row);
    }
    long long count = choose[length - 1][k - 1];  // 位数为 length 的编号有几个
    if (n <= count) {
        break;
    }
    n -= count;
    ++length;
}
std::string id = "1";
int ones = k - 1;
for (int p = length - 1; p >= 1; --p) {  // 还剩 p 位要定
    long long with_zero = choose[p - 1][ones];
    if (n <= with_zero) {
        id.push_back('0');
    } else {
        n -= with_zero;
        id.push_back('1');
        --ones;
    }
}
std::printf("%s\n", id.c_str());
```

`last` 是对 `choose` 最后一行的引用，`push_back` 可能让 `choose` 换地方存放，引用随之失效（第一卷第 15 章说过）。所以这里先把新行算完放在 `row` 里，最后才 `push_back`，之后不再用 `last`。`n` 是 `long long`。K = 2 时位数不超过约 4500，表格不大。

`ones` 减到 0 以后，`choose[p - 1][0]` 是 1，而这时 N 一定已经是 1，后面全放 0，正好。

## 核对

1. 1071 除以 462 余 147；462 除以 147 余 21；147 除以 21 余 0；gcd 是 21。(7, 5) 倒推：7 > 5，减 (7 − 1) / 5 = 1 次到 (2, 5)；5 > 2，减 (5 − 1) / 2 = 2 次到 (2, 1)；2 > 1，减 (2 − 1) / 1 = 1 次到 (1, 1)。共 4 次。
2. 上限是 20 / 4 = 5。差是 3、6、9、3、6、3，因数里不超过 5 的有 1、2、3。L = 1、3 时余数只有一种；L = 2 时余数是 0、1 两种，也合法。L = 4、5 不是任何差的因数，四个数的余数两两不同：L = 4 时余数 0、3、2、1，L = 5 时 0、3、1、4，都是 4 种，不合法。答案 1 + 2 + 3 = 6。
3. N = 8 输出 14，N = 9 输出 16，N = 16 输出 29。写成 `n / 8`、`n % 8` 时，N = 8 得到第 1 段第 0 格，输出 16。
4. L = 2 有 C(1, 1) = 1 个，N 剩 4；L = 3 有 C(2, 1) = 2 个，N 剩 2；L = 4 有 C(3, 1) = 3 个，够了。剩 3 位放 1 个 1：放 0 的有 C(2, 1) = 2 个，N = 2 不超过，放 0；剩 2 位放 1 个：放 0 的有 C(1, 1) = 1 个，2 > 1，放 1，N 剩 1；剩 1 位放 0 个，放 0。编号 1010，4 位。
