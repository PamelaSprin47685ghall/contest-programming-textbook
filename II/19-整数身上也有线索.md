# 19　整数身上也有线索

24 块红砖、18 块蓝砖，要分成若干份，每份红砖数相同、蓝砖数也相同，而且没有剩余。最多能分几份？

## 一个整除关系能减少很多候选

能整除 24 又能整除 18 的最大整数是 6，叫最大公因数，记为 `gcd(24,18)`。若一个数同时整除 `a`、`b`，它也整除 `a-b`；用除法一次减去很多个 `b`，得到 `gcd(a,b)=gcd(b,a%b)`。反复做到后一个为零，前一个就是答案，这是欧几里得算法。

最小公倍数可先算 `a/gcd(a,b)*b`，先除后乘能减少中间值，但结果仍须检查范围。本章先限非负输入；不要随手对最小负整数取绝对值。

**停笔 1**　按余数链算 `gcd(48,18)`。若两数互质，最大公因数为多少？`gcd(0,7)` 呢？

## 为什么试因子只需到平方根

大于 1 的整数，只有 1 与自身两个正因数，叫素数；不是素数的这类整数叫合数。1 两者都不是。

若合数为 `a*b`，至少有一个因子不超过平方根，否则乘积会超过原数。逐个试除到 `d <= n/d`，可避免判断 `d*d <= n` 时的乘法溢出。每找到一个因子反复除掉，最后剩下大于 1 的数就是一个素因子。

想一次找出 1 到一百万的素数，可以反过来标记每个素数的倍数。埃氏筛从 `p*p` 开始标记，较小倍数早已被处理，总时间 `O(n log log n)`。下面的线性筛给每个合数指定唯一的一次处理。

**完整程序：**输入 `0 <= n <= 1000000`，输出不超过 `n` 的素数个数。

```cpp
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 0 || n > 1000000) {
        return 1;
    }
    std::vector<int> least(n + 1, 0);
    std::vector<int> primes;
    for (int value = 2; value <= n; ++value) {
        if (least[value] == 0) {
            least[value] = value;
            primes.emplace_back(value);
        }
        for (int prime : primes) {
            if (prime > least[value] || prime > n / value) {
                break;
            }
            least[value * prime] = prime;
        }
    }
    std::printf("%zu\n", primes.size());
    return 0;
}
```

输入：

```text
20
```

输出：

```text
8
```

`least[x]` 是最小素因子。只用 `prime <= least[value]` 的素数扩展，保证新合数的最小素因子正是 `prime`；每个合数只产生一次，因此 `O(n)` 时间、`O(n)` 空间。

## 余数里能做什么，不能做什么

模 `m` 的加、减、乘可以随时取余。负余数要按需要归一到 0 到 `m-1`；在不会溢出的范围内可用 `(x % m + m) % m`。除法不能直接照搬：模 6 时，`2*1` 与 `2*4` 同余，不能“约掉 2”得出 1 与 4 同余。

若一个数与模数互质，才有乘法逆元，第三卷用扩展欧几里得说明怎样求。快速幂已在第 7 章出现；它利用乘法规则，不要求模数一定是素数。

## 计数不一定要先算阶乘

从 `n` 件不同物品中选 `k` 件、不看顺序，记为 `C(n,k)`。按“最后一件选不选”分成两类：

$$C(n,k)=C(n-1,k-1)+C(n-1,k).$$

边界 `C(n,0)=C(n,n)=1`。这就是杨辉三角。用加法建表，不必先算很大的阶乘再相除；但表项仍可能超过整数范围，需要大整数或题目允许的模数。

## 核对

1. `48%18=12`、`18%12=6`、`12%6=0`，答案 6；互质为 1；`gcd(0,7)=7`。
2. `2,3,5,7,11,13,17,19`。12 来自 `6*2`；处理 4 时最小素因子为 2，不允许用 3 扩展。
