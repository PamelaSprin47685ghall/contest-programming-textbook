# 让办法站得住

这是《循序渐进编程竞赛》的第二卷，写给读完[第一卷《把问题写成程序》](../I/README.md)的你：会用变量、循环、数组、字符串、函数和结构体，见过 `vector`、`sort`、栈、队列和映射，能把一段片段补成完整程序。别的不用先会。

第一卷里，一道题做完，常常就是样例对上了。这一卷每章多问几句：答案到底在数什么？这个办法凭什么不漏、不重？数据大到十万、一亿时还来得及吗？怎样留下一份能核对它的证据？我们从“把每种选择都试一遍”出发，一章添一种让办法变快、又说得清为什么对的想法：前缀和、排序、二分、双指针、倍增、动态规划、贪心、图上搜索、最短路、并查集、树、树状数组、线段树、堆、字符串匹配和整数。每章围绕一道 USACO 真题写一份完整程序，节末再列出同一想法的更多真题，从铜组一直排到白金组。

读到“停笔”，就遮住后文，在纸上把数一步步算出来，或者先说出自己的理由；答案在章末“核对”里。一天读一节就很好。有电脑时，把完整程序跑起来，再照书里的办法写一份慢而可靠的程序和它对拍；没有电脑，纸笔也够把每一张表填对。

## 本卷怎么写代码

示例使用 **C++14**，沿用第一卷的约定：写出 `std::` 前缀，不写 `using namespace std;`；输入输出用 `<cstdio>` 的 `scanf` 和 `printf`；变量在声明时给初值；`if`、`for`、`while` 一律带花括号；区间从 0 开始，写作 `[left, right)`，题目从 1 编号时在注释里说清。

每章恰好一份标着“**完整程序 A**”的程序，可以直接编译运行，并检查 `scanf` 的返回值。其余代码是**片段**，第一行注释交代它放在哪里、哪些量已经算好，例如 `// 位于 main 内；free_end 已照程序 A 算好`。第一卷没讲过的写法，只在讲它的那一章第一次出现，并当场解释：递归和位运算在第 2 章，`priority_queue` 的比较方向在第 12 章。

**对拍**是本卷反复用到的检查办法：写一份慢、但一眼看得出对的程序，造许多小数据，比较两份程序的输出。第 1 章讲怎样做，第 20 章讲出错以后怎样把失败的输入缩到最小。

## 给带读者：怎样使用，检查到了哪里

一次只读到下一道“停笔”。每章开头先用一个生活里的小场景说出要解决的事，再用一道真题把想法写成完整程序 A；“这一节还可以练”的表格不必全做，铜组和银组的题先做，金组挑一两道，白金组的题都标了“带读”，适合大人陪着读题解、说清楚关键一步，不要求独立做出来。第 1 章的四个问题——在数什么、凭什么对、来不来得及、怎样核对——是全卷的底子，后面每章都会回到它们，带读时可以反复问。第 3、8、10 章篇幅最长、题也最多，可以分几次读。

本卷有 20 章正文、1 份插入点目录和本导读。正文共 97 组“停笔”练习，均附核对答案；20 份完整程序 A，每章一份；共 79 个代码块；13 章的正文具体用到了对拍。各节“这一节还可以练”的表格一共登记 USACO 题 519 道：铜组 132、银组 179、金组 144、白金组 64，其中 64 道白金组题标为“带读”。

代码核对使用 GCC 14.2.0，以 `-std=c++14 -Wall -Wextra -Werror -pedantic` 编译。79 个代码块全部重新从正文抽出编译：完整程序直接编译；片段放进补全了上下文的测试程序里编译，测试程序都包含片段的原文。完整程序 A 另用 `-fsanitize=undefined,address` 跑过样例，并和慢程序在随机小数据上对拍。正文里的 574 个相对链接已逐一核对能打开，全卷没有外部网址。

## 全卷的题从哪来

书里的竞赛题都来自 USACO（USA Computing Olympiad，美国计算机奥林匹克）过去十几年的月赛，铜、银、金、白金四组都有。链接指向仓库里 `USACO/` 目录下的题面与题解，例如 `USACO/银组/2014_2015/2014.12/P3.md` 是 2014 年 12 月银组第三题。正文用自己的话重述题意，样例照原样给出。

四组一共 719 题。核心想法落在本卷的 519 题，按章、节排在[插入点目录 II](插入点目录II.md)里，每题只登记一次；铜组另有 68 题已在第一卷正文里当例题讲过；剩下 132 题要用到第三卷的工具，见[插入点目录 III](../III/插入点目录III.md)。
