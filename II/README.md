# 让办法站得住

这是《彻底颠覆版学生手册》第二卷。第一卷帮你把规则写成 C++，这一卷开始问：这样写为什么对？数据多起来，还来得及吗？

读前会用变量、判断、循环、`vector`、函数和简单结构体就够了。不熟悉时回到[第一卷](../I/README.md)，不要求先学完指针或 lambda。新数学记号会在用到时说明。

## 每次只解决一个疑问

每章先用小数据把问题摆出来，再写记录的含义、更新办法和正确理由。看到“停笔”就遮住核对部分，先画表、算一步，或者找一个反例。有电脑时再运行，不要让屏幕替你作第一次预测。

本卷有 20 章、60 组停笔练习，每章一份独立完整程序。练习不需要付费题库或某个网站账号。不要按文件数量安排每天进度；背包、最短路和线段树都可以分几天读。

## 程序里的约定

延续第一卷，使用 C++14、标准头文件和 `std::`。完整程序不依赖别章的隐藏代码；操作片段不是独立程序。输入范围是题目的承诺，程序检查读取失败及关键下标，并不声称能把任意长非法数字安全解析为整数。

数组、区间默认从 0 编号，区间写作 `[left,right)`；树状数组内部转换为 1 编号，由对象自己负责。图的点也从 0 编号。与其他教材对照时先核对这些约定。

```sh
g++ -std=c++14 -O2 -Wall -Wextra -Werror -pedantic main.cpp -o main
./main
```

检查未定义行为时可另加 `-fsanitize=undefined -fno-sanitize-recover=all -g`。编译通过只是起点，仍须把输出与纸笔答案比。

## 给带读者

“会用”至少包括：能说明表中一格是什么意思；能说清一次更新为何不漏；知道哪条条件改变后办法会失效。不要把读过术语、背出模板或跑过样例当作同一件事。

本卷主要推开算法的门，不把高级数学夹在初次使用之间。需要更深的树、图、字符串和数学工具时，接着读[第三卷](../III/README.md)。第三卷的进阶节可晚些再读，不是小学阶段的限时清单。两卷均未声称经过真实小学生试读。

## 这次实际核对了什么

20 个完整程序使用 GCC 16.2.1，以 `-std=c++14 -O1 -g -Wall -Wextra -Werror -pedantic -fsanitize=undefined -fno-sanitize-recover=all` 编译并实际运行，共 542 组场景通过。包括 20 组印出的样例、480 组固定种子小数据独立对照、20 组缺失输入、19 组上限场景，以及 3 组有向圈与零指数边界。

对照答案分别来自子集或分割枚举、逐项区间操作、全源距离、枚举生成树、全部合并顺序、逐位置匹配及逐点二维计数，不让快程序自己给自己作证。上限场景实际覆盖十万点长链、百万字节文本、超过 `int` 的累计值，以及包含整段修改与查询的十万次操作。

本卷 22 个本地文档链接可解析，60 组停笔均有对应编号的核对答案。程序验证只覆盖上述实现与场景，不证明所有推广、所有编译器或所有输入；课堂阅读效果仍需真实带读检查。
