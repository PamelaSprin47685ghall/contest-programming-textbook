# 01　先摆一个能检查的答案

拼一千片的拼图，没人会一片片乱试。先把四条边找出来，因为边上的那几片有一条直线，最好认；边框拼好了，里面每一片该落在哪儿，就有了可以对照的东西。拼图拼完，也不用别人来夸：每一片都卡得严严实实，这本身就是证明。

这一卷的题，常常不是“算出一个数”，而是“摆出一个样子”：一张摆放、一个排列、一串操作。这样的答案有个好处，摆出来以后可以一条条检查。这一章练三件事：从几个具体的小例子里看出一条能重复的规则；改动一点，看前后什么没变；判断整体对不对时，问一问是不是只要检查几处局部就够了。

## 从具体排列里找一条可重复规则

题目要我们摆出一个样子时，先别急着搜。在纸上把小的情况都摆一遍，看合法的样子长什么模样。常常会发现，合法的样子只有寥寥几类，每一类都能用一句话说清。说清以后还要证明：不在这几类里的，一定不合法。

### 间隔放置

N × N 的方格（N 从 2 到 1000）里放牛，每格至多一头，要求每一个 2 × 2 的小方块里恰好有两头。牛放在第 i 行第 j 列，得 aᵢⱼ 分（0 到 1000）。问合法摆放最多得多少分。

输入第一行 N，接下来 N 行，每行 N 个数。输出一个整数。

样例输入：

```text
4
3 3 1 1
1 1 3 1
3 3 1 1
1 1 3 3
```

样例输出：

```text
22
```

最好的摆放是第一、三行放前两格，第二、四行放后两格，得 3 + 3 + 3 + 1 + 3 + 3 + 3 + 3 = 22。这是 USACO 2021 年 1 月银组第三题[“间隔放置”](../USACO/银组/2020_2021/2021.01/P3.md)。

N = 1000 时有一百万格，一格格去试是不行的。先在纸上摆 3 × 3 的小方格。把第一行写成“放、放、空”，第二行的前两格就只能都空，后两格里第二格空了，第三格只能放；第二行是“空、空、放”。再往下，第三行又只能是“放、放、空”。这时每一列都在“放、空”之间交替。反过来，第一行写成“放、空、放”，第二行每一格都可以选，只要它自己也是交替的。

于是猜：合法的摆放只有两类，要么每一行都交替，要么每一列都交替。

先说这两类都合法。每一行都交替时，任意一个 2 × 2 小方块里，上下两行各占两格相邻的格子，交替的一行在相邻两格里恰好放一头，两行合起来恰好两头。每一行从哪一格开始放，可以各自选。每一列都交替时同理。

再说别的都不合法。设有一列不交替，第 i、i + 1 行在第 j 列的两格相同，都放或都空。看它旁边一列：同一个 2 × 2 方块要恰好两头，那一列的这两格只能都和第 j 列相反。一列一列推过去，第 i、i + 1 两行完全相同，而且各自都是交替的。再看第 i + 1 和 i + 2 行：第 i + 1 行在任意相邻两格里恰好一头，第 i + 2 行在相邻两格里也只能恰好一头，所以它也交替。一行行推下去、推上去，每一行都交替。所以，不是每一列都交替，就一定每一行都交替。

规则有了，算法很简单：每一行都交替的那一类里，每一行各自挑偶数格之和、奇数格之和里大的那个，加起来；每一列都交替的那一类同样做一遍；两类取大的。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <algorithm>
#include <vector>

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<std::vector<long long>> beauty(n, std::vector<long long>(n, 0));
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            if (std::scanf("%lld", &beauty[i][j]) != 1) {
                return 1;
            }
        }
    }

    // 情况一：每一行都是“放、空”交替，每行各自挑一种开头
    long long rows_case = 0;
    for (int i = 0; i < n; ++i) {
        long long even_start = 0;
        long long odd_start = 0;
        for (int j = 0; j < n; ++j) {
            if (j % 2 == 0) {
                even_start += beauty[i][j];
            } else {
                odd_start += beauty[i][j];
            }
        }
        rows_case += std::max(even_start, odd_start);
    }

    // 情况二：每一列都是“放、空”交替，每列各自挑一种开头
    long long columns_case = 0;
    for (int j = 0; j < n; ++j) {
        long long even_start = 0;
        long long odd_start = 0;
        for (int i = 0; i < n; ++i) {
            if (i % 2 == 0) {
                even_start += beauty[i][j];
            } else {
                odd_start += beauty[i][j];
            }
        }
        columns_case += std::max(even_start, odd_start);
    }

    std::printf("%lld\n", std::max(rows_case, columns_case));
    return 0;
}
```

每格最多 1000 分，一百万格加起来是 10⁹，`int` 刚好放得下，这里还是用了 `long long`，省得再算一遍。每一格读两次，O(N²)。

对拍的慢程序不用这条规则：N 不超过 4，把 2^(N²) 种摆放都试一遍，逐个检查每个 2 × 2 方块。和程序 A 对拍 300 组，答案全部相同。

这里的答案是一个数，不是一张摆放。但想出它的过程是先摆：在小方格上摆出合法的样子，说出它们的规则，再证明规则以外没有别的。

## 改一点，比较前后差了什么

题目允许做一些操作，问能不能从一个样子变到另一个。操作可以做任意多次，一个个去搜是搜不完的。办法是找一个**不变量**：一个只看当前样子就能算出、做任何一次操作都不会改变的量。起点和终点的不变量不同，就一定变不过去。不变量只能说“不行”；要说“行”，还得另外给出一串操作。

### COW 操作

一个只含 C、O、W 的串，可以做两种操作：删掉相邻两个相同的字母；把一个字母换成另外两种字母，一前一后，次序随意。给出一个长度到 2 × 10⁵ 的串和 Q 个询问（到 2 × 10⁵），每个询问给出 l、r，问第 l 到第 r 个字母组成的子串能不能化成一个单独的 C。

输入第一行是串，第二行 Q，接下来 Q 行每行 l、r（从 1 编号）。输出一行，第 i 个字符是 Y 或 N。

样例输入：

```text
COW
6
1 1
1 2
1 3
2 2
2 3
3 3
```

样例输出：

```text
YNNNYN
```

第五个询问是 OW：把 O 换成 C 和 W，得 CWW，删掉 WW，剩 C。这是 USACO 2022 年 3 月银组第三题[“COW 操作”](../USACO/银组/2021_2022/2022.03/P3.md)。

记子串里 C、O、W 的个数是 c、o、w。看每种操作让它们怎样变。删掉两个相同的字母，三个数里有一个减 2。把 C 换成 O 和 W，c 减 1，o、w 各加 1。把 O 换成 C 和 W，o 减 1，c、w 各加 1。把 W 换成 C 和 O，w 减 1，c、o 各加 1。

单看 c 的奇偶，每次换字母都会变，靠不住。看 o + w：删字母时不变或差 2；把 C 换掉时加 2；把 O 或 W 换掉时一减一加，不变。o + w 的奇偶不变。同样核对 c + o：删字母时不变或差 2；换 C 或换 O 时一减一加；换 W 时加 2。c + o 的奇偶也不变。

一个单独的 C，o + w 是 0，偶数；c + o 是 1，奇数。所以子串要化成 C，必须 o + w 是偶数、c + o 是奇数。

这只是必要条件，还要说明它够用。任意两个相邻的字母都能并成至多一个：相同就删掉；不同，比如 x 后面跟着 y，就把 x 换成“第三种字母 z，再接一个 y”，得 z y y，删掉 y y，剩 z。这样每次少一个字母，一直并到只剩一个字母或什么都没有。空串的 c + o 是 0，单独的 O 或 W 的 o + w 是 1，都不满足条件；满足条件的串，最后剩下的只能是 C。

每个询问只要三个字母各自的个数，用第二卷第 3 章《先把重复的加法收起来》的前缀和。

下面是**片段**。

```cpp
// 位于 main 内；s 是读入的串，n 是它的长度，询问的答案依次接在 answers 后面
const char letters[3] = {'C', 'O', 'W'};
std::vector<std::vector<int>> before(3, std::vector<int>(n + 1, 0));
for (int k = 0; k < 3; ++k) {
    for (int i = 0; i < n; ++i) {
        before[k][i + 1] = before[k][i] + (s[i] == letters[k] ? 1 : 0);
    }
}
for (int q = 0; q < query_count; ++q) {
    int l = 0;
    int r = 0;
    if (std::scanf("%d %d", &l, &r) != 2) {
        return 1;
    }
    int left = l - 1;  // 题目从 1 编号，换成 [left, right)
    int right = r;
    int c = before[0][right] - before[0][left];
    int o = before[1][right] - before[1][left];
    int w = before[2][right] - before[2][left];
    bool can = (o + w) % 2 == 0 && (c + o) % 2 == 1;
    answers.push_back(can ? 'Y' : 'N');
}
```

预处理 O(n)，每个询问 O(1)。

慢程序真的去做操作：从子串出发广度优先地搜所有能变出的串，长度不超过原长加 2，看能否搜到单独的 C。前面的证明说明，能化成 C 时并字母的过程长度至多多 1，所以这个上限够用。子串长度不超过 6，和片段对拍 300 组，答案全部相同。

## 先问局部，还是先看整体

检查一个答案对不对，有时要看整体，有时只要看几处局部。能拆成局部的检查，往往能提前做好，询问来时只要查表。关键是证明：局部都对，整体一定对。

### 子集相等

两个只含 a 到 r（共 18 种字母）的串 s、t，长度都到 10⁵。Q 个询问（到 10⁵），每个询问给出一组字母。问两个串都只留下这组字母以后，是否相同。

样例输入：

```text
aabcd
caabd
4
a
ac
abd
abcd
```

样例输出：

```text
YNYN
```

只留 a 和 c 时，s 是 aac，t 是 caa，不同；只留 a、b、d 时，两边都是 aabd，相同。这是 USACO 2022 年 3 月银组第二题[“子集相等”](../USACO/银组/2021_2022/2022.03/P2.md)。

整体检查要把两个串都过一遍，10⁵ 个询问每次 2 × 10⁵ 步，太多了。问一问：整体不同时，能不能在一小处看出来？

设只留下一组字母以后，两个串不同。要么长度不同，也就是这组字母在两个串里的总个数不同；要么从头比，第一次不同的位置上一边是 x、一边是 y。这时只留 x、y 两种字母：前面相同的部分删掉别的字母后仍相同，删掉的个数也一样，x 和 y 还站在同一个位置上，所以“只留 x、y”时两串也不同。

反过来，整体相同，留得更少当然也相同。于是：一组字母通过检查，当且仅当总个数相等，并且其中每一对字母都通过检查。

18 种字母一共只有 18 × 17 ÷ 2 = 153 对。事先把每一对都检查一遍，每对把两个串各扫一次，共约 153 × 2 × 10⁵ 步，可以接受。询问来时，算一下总个数，再查表看其中的每一对，至多 153 次查表。

局部检查能代替整体，靠的是那句证明：整体的毛病一定在某一对字母上露出来。没有这句证明，只检查每一对就是在碰运气。

## 核对

1. 六种：四格里挑两格，四选二是 6。每一行都交替的有四种：两行各自选“放、空”或“空、放”。每一列都交替的也有四种。两条对角线的摆法同时属于两类，所以 4 + 4 − 2 = 6。程序 A 不是把两类加起来，而是各自取最大再比较，一种摆放被两类都算到，只是两边都能取到同一个分数，不影响最大值。
2. 能。c = 2、o = 1、w = 1，o + w = 2 是偶数，c + o = 3 是奇数。一串操作：把 O 换成 C 和 W，得 C C W W C；删掉 C C，得 W W C；删掉 W W，得 C。
3. CO。c = 1 是奇数，但 o + w = 1 是奇数，化不成 C。长度为 1 的 C 本身能化，O、W 的 c 都是 0，所以最短是两个字母，CO（或 OC、CW、WC）都可以。
4. 例如 OO：o + w = 2 是偶数，但 c + o = 2 也是偶数，不满足 c + o 是奇数这一条，所以化不成 C。
5. b 和 c：只留 b、c，s 是 bc，t 是 cb。a 和 b 这一对通过检查：只留 a、b，两边都是 ab。
