# 02　换一张坐标纸看顺序

排队买票，先来的站前面，这是一种顺序。学校评“三好学生”，要成绩好、身体好、品德好，两个同学放在一起，常常这一样你强、那一样我强，分不出谁在前。这时候硬排一个名次反而不对；能说的只是，有些人在每一样上都不输给另一个人。

这一章把对象画成坐标纸上的点，看两项条件下的顺序：先沿一个方向扫过去；有些对象之间比不出先后，这也是一种顺序；把数一个个插进几排里，会显出一张形状；区间也能画成点。

## 两个条件，先沿一个方向扫

坐标纸上有一些点。说点 (x₁, y₁) 在 (x₂, y₂) 的**左下方**，是指 x₁ < x₂ 并且 y₁ < y₂。问每个点的左下方有几个点。

第二卷第 20 章《让几种工具接成一件事》里做过这样的事：按 x 从小到大扫过去，扫到一个点时，已经扫过的点 x 都更小，只剩 y 一项条件，交给第二卷第 15 章的树状数组，下标是 y 的名次。

在纸上做一次。五个点 (1, 3)、(2, 1)、(3, 4)、(4, 2)、(5, 5)，x 已经从小到大。扫到 (1, 3)，前面没有点，0 个；扫到 (2, 1)，前面的 (1, 3) 的 y 比 1 大，0 个；扫到 (3, 4)，前面 y 小于 4 的有 (1, 3)、(2, 1)，2 个。

x 相同的点要小心：它们互相不在左下方，扫到时不能把同一个 x 的点算进来。办法是 x 相同的一批点先全部查完，再一起加进树状数组。

下面是**片段**。`points` 的每个元素有 `x`、`y` 两个成员，查询和修改的写法照第二卷第 15 章，下标从 1 开始。

```cpp
// 位于 main 内；points 已按 x 从小到大排好，y 已换成 1 到 m 的名次
std::vector<int> tree(m + 1, 0);
std::vector<int> below(n, 0);  // below[i]：第 i 个点左下方有几个点
int group_start = 0;
while (group_start < n) {
    int group_end = group_start;
    while (group_end < n && points[group_end].x == points[group_start].x) {
        ++group_end;
    }
    // 同一个 x 的点先全部查完
    for (int i = group_start; i < group_end; ++i) {
        for (int k = points[i].y - 1; k > 0; k -= k & -k) {
            below[i] += tree[k];
        }
    }
    // 再一起加进树状数组
    for (int i = group_start; i < group_end; ++i) {
        for (int k = points[i].y; k <= m; k += k & -k) {
            ++tree[k];
        }
    }
    group_start = group_end;
}
```

每个点查一次、加一次，再算上排序，O(n log n)。两层 `while` 看上去像两重循环，其实 `group_start` 每次跳到 `group_end`，每个点只被里面的循环走过一次。

慢办法是对每个点把所有点比一遍。在 x、y 都只取 0 到 5 的小数据上，故意让许多点 x 相同、y 相同，对拍 300 组，结果全部相同。

这样的扫描是第三卷的基本动作。对象有两项条件时，先问：沿哪个方向扫过去，能让一项条件自己成立？

## 只能部分比较，也是一种顺序

左下方的关系有一个特点：有的两个点能比，有的不能。(1, 3) 和 (2, 1) 谁也不在谁的左下方。这样的关系叫**偏序**：能比的两个对象有先后，先后会传递（A 在 B 前、B 在 C 前，A 就在 C 前），但不要求每两个都能比。

在偏序里，一串两两能比的对象叫一条**链**，一群两两都不能比的对象叫一条**反链**。一条链里的对象可以排成一列；一条反链里的对象，任意两个都得分开。下面这道题问的就是：最少分成几条链。

### 奶牛慢跑

N 头牛（N 到 10⁵）在一条跑道上跑 T 分钟（T 到 10⁹）。每头牛的起点互不相同，速度各自不变。跑道分成几条分道；同一条分道上的两头牛，任何时刻（包括第 T 分钟）都不能在同一个位置。问至少要几条分道。

输入第一行 N 和 T，接下来 N 行，每行一头牛的起点和速度，按起点从小到大给出。起点、速度都不超过 10⁹。输出一个整数。

样例输入：

```text
5 3
0 1
1 2
2 3
3 2
6 1
```

样例输出：

```text
3
```

第 T 分钟时五头牛分别在 3、7、11、9、9。这是 USACO 2014 年 12 月金组第三题[“奶牛慢跑”](../USACO/金组/2014_2015/2014.12/P3.md)。

先问两头牛什么时候能在一条分道上。设牛 i 起点在牛 j 后面，也就是 i 在输入里更靠前、起点更小。两头牛的位置都随时间均匀变化，开始时 i 在 j 后面。如果到第 T 分钟 i 的终点仍比 j 小，它一直没追上，可以同道；如果终点大于或等于 j 的，中途或最后一刻一定碰到，不能同道。

所以把每头牛画成点（起点，终点），可以同道的两头牛，一头恰好在另一头的左下方。一条分道就是一条链。分道的最少数目，就是把所有点分成链的最少条数。

下界容易看出：终点序列里，任意一段从左往右不升的子序列（后面的不比前面的大），其中两两不能同道，是一条反链。它有多长，就至少要几条分道。样例的终点 3、7、11、9、9，取 11、9、9，所以至少 3 条。

再说这么多条够用。按起点的次序一头头安排。每条分道记着最后一头牛的终点。新来的牛终点是 f，它能接在终点比 f 小的分道后面。在这样的分道里，挑最后终点最大的那一条；一条也没有，就开一条新的。

这样开出的分道数，恰好等于某一段不升子序列的长度。按这个规则，分道的“最后终点”总是从大到小排着。新开一条时，每条旧分道的最后终点都不比 f 小；对每一条新开的分道，记下开它时排在前一条分道最后的那头牛，一路往回找，得到一串终点不升的牛，长度就是分道数。下界和这个做法碰在一起，所以它是最少的。

这个“链的最少条数等于反链的最长长度”在别的偏序上也成立，叫 Dilworth 定理，这里只用到它在终点序列上的样子。

分道的最后终点从大到小排着，找“第一条最后终点比 f 小的分道”可以二分。`std::upper_bound` 默认找第一个比给定值大的位置；这里传入一个“按从大到小”比较的 lambda，它就改找第一个比 f 小的。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    long long t = 0;
    if (std::scanf("%d %lld", &n, &t) != 2) {
        return 1;
    }
    // lane_last[k]：第 k 条分道上最后一头牛的终点，从大到小排着
    std::vector<long long> lane_last;
    for (int i = 0; i < n; ++i) {
        long long start = 0;
        long long speed = 0;
        if (std::scanf("%lld %lld", &start, &speed) != 2) {
            return 1;
        }
        long long finish = start + speed * t;
        // 找第一条“最后一头牛的终点比 finish 小”的分道
        auto lane = std::upper_bound(lane_last.begin(), lane_last.end(), finish,
                                     [](long long a, long long b) { return a > b; });
        if (lane == lane_last.end()) {
            lane_last.push_back(finish);
        } else {
            *lane = finish;
        }
    }
    std::printf("%d\n", static_cast<int>(lane_last.size()));
    return 0;
}
```

起点和速度乘 T 到 10¹⁸ 左右，用 `long long`。把 f 放进找到的那条分道，这条分道的最后终点变大了，但仍不超过它前面一条分道的，从大到小的次序不会乱。每头牛二分一次，O(N log N)。

跑一遍样例。终点依次是 3、7、11、9、9。3 开第一条分道；7 接在 3 后面；11 接在 7 后面，这条分道最后是 11；9 找不到比 9 小的，开第二条；第二个 9 也找不到，因为另一条的 9 和它一样大，开第三条。答案 3。

慢程序直接按冲突给牛分道：两头不能同道的牛连一条线，从 1 条分道开始试，每次用回溯看能不能把牛分进这么多条分道。和程序 A 对拍 300 组，每组至多 8 头牛，答案全部相同。

## 一次插入也会显出一张形状

把一列数一个个排进几排里，规则是这样的：拿着 x 去第一排，找第一个比 x 大的数。没有，就把 x 放在这一排末尾，结束；有，就把 x 放在那个位置，把原来的数挤出来，拿着它去下一排，照同样的规则做。每一排里的数总是从小到大。

试一列数 3、1、4、5、9、2、6、8、7。

前五个数做完，第一排是 1 4 5 9，第二排是 3：1 挤出了 3。放 2 时，第一排第一个比 2 大的是 4，把 4 挤到第二排，第二排变成 3 4。放 6，挤出 9，第二排变成 3 4 9。放 8，第一排末尾接上。放 7，挤出 8，8 到第二排挤出 9，9 去第三排。最后三排是：

```text
1 2 5 6 7
3 4 8
9
```

第一排有 5 个数，原来这列数最长的上升子序列也是 5 个，比如 1、4、5、6、7。一共 3 排，最长的下降子序列也是 3 个，比如 9、8、7。这不是巧合：第一排的长度总是最长上升子序列的长度，排数总是最长下降子序列的长度。

前一半可以这样看。每放完一个数，第一排的第 k 个数，等于“到目前为止，长 k 的上升子序列最小能以几结尾”。新来的 x 接在所有比它小的结尾后面，能让长度为“比它小的个数加 1”的结尾变成 x；这正好是它在第一排落下的位置，原来那里的数比 x 大，被换掉，结尾变小了。别的长度不受影响。所以第一排有几个数，就有多长的上升子序列。后一半的证明更长，这里只在例子上核对，不展开。

上一节的分道其实也是这样一排：程序 A 的 `lane_last` 从大到小，每头牛换掉第一个比它小的数，或者接在末尾。把终点都取相反数，它就成了这里的第一排。分道数等于最长不升子序列的长度，和第一排的长度等于最长上升子序列的长度，是同一件事的两种说法。

要小心的是，第一排本身不一定是原来那列数的子序列。1 2 5 6 7 里，2 出现在 5 后面，它只是长度对了。要真的取出一条最长上升子序列，还得另外记下每个数是接在谁后面。

## 区间也能画成点

区间 [l, r) 可以画成坐标纸上的点 (l, r)。两个区间的关系就成了两个点的位置：[l, r) 被 [l′, r′) 包住，就是 l′ ≤ l 并且 r ≤ r′，那个点在它的左上方。

于是“每个区间被几个区间包住”，就是每个点的左上方有几个点，可以照 §2.1 扫过去：按 l 从小到大排，l 相同的，r 大的排前面；扫到一个区间时，前面扫过的区间 l′ 都不比它大，只要数其中 r′ ≥ r 的有几个。

例子：[1, 6)、[2, 4)、[3, 8)、[2, 5)。排好是 [1, 6)、[2, 5)、[2, 4)、[3, 8)。扫到 [1, 6)，前面没有，0 个；[2, 5)，前面的 r′ 是 6，1 个；[2, 4)，前面的 6、5 都不小于 4，2 个；[3, 8)，前面没有 r′ 不小于 8 的，0 个。

两个区间相交、相离，同样能写成坐标上的条件。[l, r) 和 [l′, r′) 有公共部分，当且仅当 l < r′ 并且 l′ < r：一个的左端在另一个的右端之前，反过来也是。和 [2, 5) 相交的区间，就是点 (l′, r′) 落在“l′ < 5 并且 r′ > 2”那一块里的区间，这又是一个只看两个坐标的方块，扫描和树状数组都用得上。题目里出现“一段时间”“一段位置”，先试着把它画成点，看看要问的是哪一个方向。

**停笔 5**　l 相同时为什么要让 r 大的排前面？把 [2, 4) 排在 [2, 5) 前面，哪个数会算错？

这一章用“奶牛慢跑”说明了链与反链：可以同道的牛排成链，必须分开的牛组成反链，最少分道数就是最长反链的长度。另外三节用的都是手算的例子：扫描数左下方的点，把数插进几排看出形状，把区间画成点。下一章《树上的路可以分段处理》回到树上，把长路拆成几段来管。

## 核对

1. (4, 2) 的左下方只有 (2, 1)，1 个；(5, 5) 的左下方是前面四个点，4 个。一共 0 + 0 + 2 + 1 + 4 = 7 对。
2. 终点是 1、3、5、5、7。1、3、5 接成一条；第二个 5 找不到更小的，开第二条；7 接在第一条后面。要 2 条分道。
3. 输出 2。`std::lower_bound` 配上这个比较，找的是第一个“不比 f 大”的分道，终点相同的两头牛被放进了同一条。可是终点相同的两头牛在第 T 分钟正好碰在一起，不能同道。样例里两个 9 就被放到了一起。
4. 三排：2 个、2 个、1 个，最后是 1 3 / 2 5 / 4。最长上升子序列如 2、5 或 1、3，长 2；最长下降子序列 4、2、1，长 3。第一排长 2，排数 3，都对得上。
5. 若 [2, 4) 先扫，那时 [2, 5) 还没进来，[2, 4) 只数到 [1, 6)，得 1，少算了包住它的 [2, 5)。l 相同时 r 大的区间包住 r 小的，所以要先把大的放进来。
