# 02　换一张坐标纸看顺序

每张卡片有宽和高。要叠成一串，后一张的宽、高都必须严格更大。按宽排序就够了吗？宽一样的两张不能互相套进去，等号必须先处理。

## 两个条件，先沿一个方向扫

把宽从小到大排；宽相同，高从大到小排。随后在高序列找最长严格上升子序列。相同宽的一组高度不升，不能被同一条上升链同时选中，恰好挡住假答案。

对每个可能长度，只存最小的结尾高度。长度相同，结尾更小，不会减少以后接卡片的机会。新高度用 `lower_bound` 找第一个不小于它的结尾并替换；找不到就延长一位。结尾表不是最终那条子序列，想还原还要保存前驱和位置。

**完整程序：**输入 `0 <= n <= 100000` 及 `n` 对 `int` 宽高，输出严格双增的最长链长度。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

struct Card {
    int width;
    int height;
};

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 0 || n > 100000) {
        return 1;
    }
    std::vector<Card> cards(n);
    for (Card& card : cards) {
        if (std::scanf("%d%d", &card.width, &card.height) != 2) {
            return 1;
        }
    }
    std::sort(cards.begin(), cards.end(), [](const Card& a, const Card& b) {
        if (a.width != b.width) {
            return a.width < b.width;
        }
        return a.height > b.height;
    });
    std::vector<int> tails;
    tails.reserve(n);
    for (const Card& card : cards) {
        auto position = std::lower_bound(tails.begin(), tails.end(), card.height);
        if (position == tails.end()) {
            tails.emplace_back(card.height);
        } else {
            *position = card.height;
        }
    }
    std::printf("%zu\n", tails.size());
    return 0;
}
```

输入：

```text
5
2 2
2 3
3 4
4 5
3 3
```

输出：

```text
3
```

时间 `O(n log n)`，空间 `O(n)`。若改成允许相等，排序、二分和同组处理规则都得重新推导，不能只改一个名字。

## 只能部分比较，也是一种顺序

在坐标值组成的集合上，“宽高都不小于”不是全序：`(2,5)` 与 `(4,3)` 互不压住。满足自反、反对称、传递的关系叫偏序。互相能排先后的点组成链，两两不可比的点组成反链。本节用不严格关系说明定义；开头的卡片题要求严格双增，相同坐标的不同卡片仍各有自己的身份，不能混换等号条件。

一个有限偏序中，最少链划分数等于最大反链大小，这是 Dilworth 定理。直观上每条链至多拿走反链一个点，给出下界；匹配能把尽量多的相邻链段接起来，使这个下界达到。第 10 章会给出可执行的匹配办法。

对一排数，按位置从左到右分成尽量少的非上升子序列，所需条数等于最长严格上升子序列长度。可把每个数放到“结尾不小于它且最小”的那一堆；没有才开新堆。一个严格上升子序列在同一堆只能取一个，所以堆数也给出上升长度的证明。

二维偏序特别方便：位置与值把可比较、不可比较分别变成同向、反向关系；这种互补不能当作任意高维偏序的性质。

## 一次插入也会显出一张形状

不同数值依次插入：在第一行找到第一个大于新数的项，把它顶到下一行；找不到就在行尾追加。对 `3,1,2`，先 `[3]`，再第一行 `[1]`、第二行 `[3]`，最后第一行 `[1,2]`、第二行 `[3]`。

得到行列都递增的杨表，形状是两格加一格。对不同值序列，第一行长度等于最长上升子序列长度，第一列长度等于最长下降子序列长度。这一插入规则把排序、链与形状连起来；相等值的版本要先定“顶走大于还是大于等于”，对应的严格性不同。

## 区间也能画成点

把 `[l,r]` 画成点 `(l,r)`。包含关系变成左端更小、右端更大；定长区间落在一条斜线上；合法区间在对角线一侧。固定长度为 `k` 的区间，必含某个位置为 `k` 的倍数，可按这个标记分配工作，避免让每段独立从头处理。这是间隔采样的一个来源。

嵌套且不交叉的区间可以连成包含树；一般交叉区间不行。树的有根子树在 DFS 序里是区间；无根树删除一条边后的两侧，一侧是子树，另一侧是它的补集。环区间选断口后可能拆成两段。

两组标记沿数轴匹配，也常有顺序。左组位置为 1、4，右组为 2、8，按顺序配的总距离为 5，交叉配为 9。一般相交配对可以交换端点而不增加绝对距离和，于是存在保持顺序的最优匹配；若两边数量相同且全部配对，第 k 个就配第 k 个。两条 0/1 序列中的指定符号，也可先提取出现位置再做这种单调匹配。换成别的费用或允许遗漏时，要重新证明。
