# 03　树上的路可以分段处理

一棵树有很多次两点路径查询。若每次沿边慢慢走，一条长链就足以让程序变慢。第二卷已经把子树化成区间，这次把路径拆开。

## 大孩子走同一条链

每点选子树最大的孩子作重孩子，其余边叫轻边。重边连成链。跨过一条轻边进入孩子，子树大小至少减半，所以根到点至多经过 `O(log n)` 条轻边。

比较两点所在链的链头深度，把更深的链头向父亲跳。直到同链，较浅的点就是 LCA。注意比较链头，不是只比较当前点的深度。

**完整程序：**输入 `1 <= n <= 100000`、`0 <= q <= 100000`，随后树的 `n-1` 条边及 `q` 对查询点，根为 0，逐行输出 LCA。所有端点合法，输入保证是树。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2 || n < 1 || n > 100000 || q < 0 || q > 100000) {
        return 1;
    }
    std::vector<std::vector<int>> tree(n);
    for (int i = 1; i < n; ++i) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= n || v < 0 || v >= n) {
            return 1;
        }
        tree[u].emplace_back(v);
        tree[v].emplace_back(u);
    }
    std::vector<int> parent(n, -1), depth(n, 0), size(n, 1), heavy(n, -1), head(n, 0);
    std::vector<int> order;
    order.reserve(n);
    order.emplace_back(0);
    for (int i = 0; i < n; ++i) {
        int u = order[i];
        for (int v : tree[u]) {
            if (v != parent[u]) {
                parent[v] = u;
                depth[v] = depth[u] + 1;
                order.emplace_back(v);
            }
        }
    }
    for (int i = n - 1; i > 0; --i) {
        int u = order[i];
        int p = parent[u];
        size[p] += size[u];
        if (heavy[p] == -1 || size[u] > size[heavy[p]]) {
            heavy[p] = u;
        }
    }
    for (int u : order) {
        for (int v : tree[u]) {
            if (parent[v] == u) {
                head[v] = (heavy[u] == v) ? head[u] : v;
            }
        }
    }
    for (int i = 0; i < q; ++i) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= n || v < 0 || v >= n) {
            return 1;
        }
        while (head[u] != head[v]) {
            if (depth[head[u]] < depth[head[v]]) {
                std::swap(u, v);
            }
            u = parent[head[u]];
        }
        std::printf("%d\n", depth[u] < depth[v] ? u : v);
    }
    return 0;
}
```

输入：

```text
5 3
0 1
0 2
1 3
1 4
3 4
3 2
4 4
```

输出：

```text
1
0
4
```

预处理 `O(n)`，每问 `O(log n)`。这里的 `order` 只保证父亲在孩子前，足够计算大小与链头，**不是**子树连续的 DFS 序。

若再按“先重孩子、后轻孩子”做 DFS 编号，每条重链与每个子树都成区间。路径拆成 `O(log n)` 段，交给线段树，总查询常为 `O(log² n)`，这就是重链剖分。边权放在较深端点，最后同链的一段要排除 LCA 本身。

## 从孩子收答案，也能把答案传回孩子

树形 DP 先汇总孩子结果。换根时，再把父亲方向的信息交给孩子。例如距离和：已知根 `u` 到所有点距离和，沿边移根到孩子 `v`，`size[v]` 个点近一步，其余远一步，所以 `answer[v]=answer[u]+n-2*size[v]`。两遍遍历算全体，`O(n)`。

合并孩子的颜色集合时，总把小集合搬入大集合。一个元素每次被搬，所在集合至少翻倍，所以搬运总次数 `O(n log n)`。这是启发式合并；若每次插入另需 `log n`，要再乘进去。保留重孩子统计、清除轻孩子统计的 DSU on tree 是另一种实现组织，不能把并查集的路径压缩混进来。

统计全部路径时，也可按 LCA 分账：两端分属某点的不同孩子子树，或一端就是该点。先加全部孩子合起来的贡献，再减各孩子内部贡献，就是容斥在树上的一次应用。问“距离 u 不超过 R 的点有多少”则是邻域问题：重心分治后，沿 u 的重心祖先累计对应距离表，并减掉与 u 同分支的重复贡献。每张距离表要明确只收原点，查询阈值为负时贡献为零。

## 只留下这次真正用得着的点

少数关键点的连通骨架可以建虚树：按 DFS 首次进入序排序，加入相邻关键点的 LCA，去重再排序，用栈连接祖先与后代。补出的 LCA 使分叉不丢失，节点数为 `O(k)`；原树上一长段可压成一条带长度的虚边。虚树不是任意删点后留下的原边子图。

## 把长路按“第一次经过哪里”分账

取重心，统计经过它的路径，再递归各剩余块，是点分治。统计距离对时，依次处理孩子：先查询此前孩子的距离表，再加入当前孩子，避免同一子树内部路径被错误归到重心。各层总点数 `O(n)`、层数 `O(log n)`，实际代价还取决于每层统计工具。

边分治可先把高次数点用零权辅助点改成最大度三的树，再按平衡边切开；辅助边不得改变原点距离，计数时也不能把辅助点当作原点。按长链组织的链分治则让长方向共享工作，证明必须跟着真实的重复访问次数走，不能只说“树上都带一个 log”。

一般有序根树还可用“第一个孩子、下一个兄弟”表示成二叉链接结构。它保存孩子次序，不表示原树距离不变：兄弟链接不是原来的一条父子边。二叉树的前序是根、左、右，中序是左、根、右，后序是左、右、根；按信息何时齐备选择遍历顺序，不必背三份无关代码。

标签为 0 到 n−1、n≥2 的树还可编码为 Prüfer 序列：反复删除编号最小的叶子，写下它的邻居，直到剩两点，得到长 n−2 的序列。反解时每点度数为一加上它的出现次数；每次取最小的度一节点，接到当前序列值，再减两端度数，最后连剩下两点。例如四点星形中心为 1，编码为 `1,1`。两方向互逆，所以 n≥2 时标签树数为 `n^(n−2)`；无根、无标号树不能用这条数量公式。
