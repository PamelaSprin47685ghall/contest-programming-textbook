# 04　换个顺序回答很多问题

一排颜色，问很多区间里有几种颜色。每次重新建集合，会把相同位置反复加入。若相邻两问的边界很接近，就能复用当前窗口。

## 先学会只挪一格

记录每种颜色的出现次数与当前不同颜色数。加入时从 0 变 1，不同数加一；删除时从 1 变 0，不同数减一。只要能让窗口从任意位置走到下一问，就可以重新安排查询顺序。

莫队把左端按块分组，同块按右端排序。左端在块内来回不超过块长，右端每块大致扫一遍。块长约为 `sqrt(n)`，总移动上界 `O((n+q)sqrt(n))`。奇偶块反向排列右端，能减少来回折返，但不改变答案。

**完整程序：**输入 `0 <= n,q <= 50000`、`n` 个 `int` 颜色值，随后给合法半开区间。按输入顺序输出不同值个数，允许空区间。

```cpp
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <vector>

struct Query {
    int left;
    int right;
    int id;
};

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2 || n < 0 || n > 50000 || q < 0 || q > 50000) {
        return 1;
    }
    std::vector<int> values(n);
    for (int& value : values) {
        if (std::scanf("%d", &value) != 1) {
            return 1;
        }
    }
    std::vector<int> keys = values;
    std::sort(keys.begin(), keys.end());
    keys.erase(std::unique(keys.begin(), keys.end()), keys.end());
    for (int& value : values) {
        value = static_cast<int>(std::lower_bound(keys.begin(), keys.end(), value) - keys.begin());
    }
    std::vector<Query> queries(q);
    for (int i = 0; i < q; ++i) {
        if (std::scanf("%d%d", &queries[i].left, &queries[i].right) != 2
            || queries[i].left < 0 || queries[i].left > queries[i].right || queries[i].right > n) {
            return 1;
        }
        queries[i].id = i;
    }
    int block = std::max(1, static_cast<int>(std::sqrt(std::max(1, n))));
    std::sort(queries.begin(), queries.end(), [block](const Query& a, const Query& b) {
        int x = a.left / block;
        int y = b.left / block;
        if (x != y) {
            return x < y;
        }
        return x % 2 == 0 ? a.right < b.right : a.right > b.right;
    });
    std::vector<int> frequency(keys.size(), 0), answer(q);
    int distinct = 0;
    int left = 0;
    int right = 0;
    auto add = [&](int index) {
        if (frequency[values[index]]++ == 0) {
            ++distinct;
        }
    };
    auto remove = [&](int index) {
        if (--frequency[values[index]] == 0) {
            --distinct;
        }
    };
    for (const Query& query : queries) {
        while (left > query.left) { add(--left); }
        while (right < query.right) { add(right++); }
        while (left < query.left) { remove(left++); }
        while (right > query.right) { remove(--right); }
        answer[query.id] = distinct;
    }
    for (int value : answer) {
        std::printf("%d\n", value);
    }
    return 0;
}
```

输入：

```text
5 3
1 2 1 3 2
0 3
1 5
2 2
```

输出：

```text
2
3
0
```

## 分块不是只能用来排查询

每块存总和，单点修改只改一块，区间查询扫两端零散位置、加中间完整块，约 `O(sqrt(n))`。按值大小分类也类似：重对象数量少，预处理；轻对象每次直接做，单次工作受阈值限制。阈值应从两类代价的总和推导，不是看见分块就固定写 320。

固定长度窗口可每隔 `k` 个位置放一个标记，区间必跨某个标记；分治时，长度超过当前半段的区间必经过中点。围绕“它必经过哪里”预处理左右信息，就是采样后微调的用途。

## 时间也能成为一维

修改和查询依次到来，先把“谁先于谁”当作第一维。CDQ 分治先解决左右各自内部，再处理左半修改对右半查询的贡献；合并时按第二维扫描，第三维交给树状数组。贡献必须只在一个分治层首次分开，才能不漏不重。合并用过的数据要撤回，不能污染下一组。

同样，一条边只在某段时间存在，可把存在区间挂到时间线段树的若干节点。进入节点应用边，离开撤销；到叶子回答当时查询。第 5 章说明可回退的并查集。

许多题要二分答案，**整体二分**把查询按当前答案中点分组，一轮扫描同时判定许多题，再递归左右答案段。记录状态随批次回滚或重建，不能把前一批的更改留给后一批。

## 查很多张有序表，也能复用位置

分散层叠在相邻有序表中抽样，把部分下一张表的元素合并到本张，并保存跨表指针。第一次二分后，下一张只在常数个邻近位置修正；在适当的相邻表查询模型下，可把 `k` 次二分从 `O(k log n)` 降到 `O(log n+k)`。不是把任意 `k` 张表串起来就自动成立，抽样密度与指针必须同时维护。

尺度递进 scaling 则先解决取粗尺度后的问题，再把低一位或更小误差加回去修正。它与“抽样后微调”相近，但能否少量修正必须有界，例如容量缩放的流每阶段只开放足够大剩余容量的边。

## 核对

1. 删除下标 1，加入下标 4；最后一份某颜色被删除时，不同数也会变化。
2. 未来的修改不能影响过去。合并只处理左对右，右对左会违反时间因果。
3. 不能。先寻找可回滚记录、持久版本或合法重建办法，并把代价计入复杂度。
