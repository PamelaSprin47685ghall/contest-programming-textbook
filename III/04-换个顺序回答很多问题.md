# 04　换个顺序回答很多问题

图书馆里一上午来了二十个人借书。管理员要是每来一个人就跑一趟书库，一上午要跑二十趟。要是先把借书单收齐，按书架的顺序排好，推着车走一圈，二十本书一次取完。读者要的书没有变，变的是回答的顺序。

很多题一口气给出全部询问，也不要求问一个答一个。这一章讲怎样利用这一点：把询问排成一个只要挪一格的顺序；按出现的多少把对象分成两类，各用各的办法；把时间也当作一维坐标；在很多张有序表里查同一个数时，复用上一次找到的位置。

## 先学会只挪一格

一列数 a，有 q 个询问，每个问一段 [left, right) 里有几种不同的数。一段一段地数，每次 O(n)，总共 O(nq)。

换个想法：手里维护一个窗口 [left, right)，记着窗口里每个值出现几次，以及有几种不同的值。窗口右端往右挪一格，就是加进一个数；左端往右挪一格，就是去掉一个数，都是 O(1)。从一个询问换到下一个，只要把两端一格格挪过去。剩下的问题是，按什么顺序回答，才能让挪动的总步数少。

把位置每 B 个分成一块。询问先按左端所在的块排，同一块里再按右端从小到大排。同一块里的询问，右端只往右走，一块一共走 O(n) 步，所有块合起来 O(n · n / B)；左端每次只在一块里来回，至多 B 步，q 个询问共 O(qB)。B 取 √n 左右，总共 O((n + q)√n)。这种做法叫**莫队**，它要求所有询问事先都拿到，回答的顺序可以打乱，最后按原来的编号输出。

下面是**片段**。询问的结构体 `Query` 有 `left`、`right`、`id` 三个成员，答案按 `id` 填进 `answers`。

```cpp
// 位于 main 内；a 的值都在 0 到 n − 1 之间，每个询问是 [left, right) 和它的编号 id
int block = 1;
while (block * block < n) {
    ++block;
}
std::sort(queries.begin(), queries.end(), [block](const Query& p, const Query& q) {
    if (p.left / block != q.left / block) {
        return p.left / block < q.left / block;
    }
    return p.right < q.right;
});
std::vector<int> seen(n, 0);  // 窗口里每个值出现几次
int distinct = 0;
auto add = [&](int i) {
    if (seen[a[i]] == 0) {
        ++distinct;
    }
    ++seen[a[i]];
};
auto drop = [&](int i) {
    --seen[a[i]];
    if (seen[a[i]] == 0) {
        --distinct;
    }
};
int left = 0;  // 当前窗口是 [left, right)
int right = 0;
for (const Query& query : queries) {
    while (right < query.right) {
        add(right);
        ++right;
    }
    while (left > query.left) {
        --left;
        add(left);
    }
    while (right > query.right) {
        --right;
        drop(right);
    }
    while (left < query.left) {
        drop(left);
        ++left;
    }
    answers[query.id] = distinct;
}
```

四个 `while` 的次序有讲究：先把窗口放大，再缩小。要是先缩，左端可能一时跑到右端右边，窗口成了“负的”，计数会变成负数。

在纸上跑一个小例子：a = 1 2 1 3 2，询问 [0, 3)、[1, 5)、[0, 5)、[2, 4)。n = 5，块长是 3，四个询问的左端都在第一块，于是只按右端排：[0, 3)、[2, 4)，然后是右端都为 5 的两个。答案依次是 2、3、3、2（按原来的次序）。

慢办法是每个询问把那一段直接放进集合数一遍。在 n 不超过 20、值只有几种的小数据上对拍 300 组，答案全部相同。

## 分块不是只能用来排查询

莫队按 √n 把位置分块。√n 还有另一种用法：对象按“多”和“少”分成两类。多的那一类个数少，每个可以花 O(n) 的工夫；少的那一类每个很小，可以花它自己大小的平方。两头一凑，正好都不超过 n√n 这个量级。

### 奶牛的相依

N 头牛排成一排（N 到 10⁵），第 i 头的标签是 aᵢ（1 到 N）。把牛分成若干组，每组的牛标签相同，组里任意两头的位置相差不超过 x。对每个 x = 1, 2, …, N，求最少分几组。

输入第一行 N，第二行 N 个标签。输出 N 行，第 x 行是 x 对应的最少组数。

样例输入：

```text
9
1 1 1 9 2 1 2 1 1
```

样例输出：

```text
7
5
4
4
4
4
4
3
3
```

这是 USACO 2024 年 12 月金组第一题[“奶牛的相依”](../USACO/金组/2024_2025/2024.12/P1.md)。

不同标签互不相干，答案是每个标签各自的组数之和。一个标签、一个 x，组数可以贪心：从最左边一头牛开始一组，它后面 x 以内的同标签牛全并进来，再从下一头开始新的一组。最左边那头牛总要在某一组里，它那组尽量往右多装，留给后面的只会更少。

难处在于 x 有 N 个，标签也可能有 N 种，每一对都贪心一遍太慢。按出现次数 k 把标签分成两类，界线 B 取 √N。

出现得多的标签，k ≥ B，至多 N / B 种。对每个 x，组数至多 N / x + 1，因为每组的起点比上一组的起点至少远 x + 1。事先算出“位置 i 及以后第一头这个标签的牛在哪里”，每一组一步跳到下一组的起点，于是一个 x 只要 O(N / x) 步。所有 x 加起来是 N(1 + 1/2 + 1/3 + …)，O(N log N)。

出现得少的标签，k < B。它的组数随 x 变大只会变少，而且只在 1 到 k 之间取值，所以 x 从 1 到 N 被分成至多 k 段，每段组数相同。从一段的开头起，二分找出这一段的结尾，再用第二卷第 3 章的差分把这个组数记到整段上。一段要二分 O(log N) 次，每次贪心 O(k)，一个标签共 O(k² log N)。

两类加起来，多的那类 O(N / B · N log N)，少的那类 O(Σ k · B · log N) = O(N B log N)，B 取 √N 时都是 O(N√N log N)。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

// 位置从小到大排好，每组的第一头牛之后 x 以内的同标签牛都能并进这一组
int greedy_groups(const std::vector<int>& positions, int x) {
    int groups = 0;
    int count = static_cast<int>(positions.size());
    int left = 0;
    while (left < count) {
        int right = left;
        while (right < count && positions[right] - positions[left] <= x) {
            ++right;
        }
        ++groups;
        left = right;
    }
    return groups;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<std::vector<int>> positions(n + 1);
    for (int i = 0; i < n; ++i) {
        int label = 0;
        if (std::scanf("%d", &label) != 1) {
            return 1;
        }
        positions[label].push_back(i);
    }

    int threshold = 1;
    while (threshold * threshold < n) {
        ++threshold;
    }

    // 少的标签：答案是一段段的常数，用差分记到 change 里
    std::vector<long long> change(n + 2, 0);
    // 多的标签：每个 x 跳着算，直接加到 big 里
    std::vector<long long> big(n + 1, 0);
    std::vector<int> next_at(n + 1, n);  // next_at[i]：i 处及以后第一头这个标签的牛

    for (int label = 1; label <= n; ++label) {
        const std::vector<int>& list = positions[label];
        if (list.empty()) {
            continue;
        }
        if (static_cast<int>(list.size()) < threshold) {
            int x = 1;
            while (x <= n) {
                int groups = greedy_groups(list, x);
                // 二分出最大的 last，使 x 到 last 的组数都是 groups
                int low = x;
                int high = n + 1;
                while (high - low > 1) {
                    int middle = low + (high - low) / 2;
                    if (greedy_groups(list, middle) == groups) {
                        low = middle;
                    } else {
                        high = middle;
                    }
                }
                change[x] += groups;
                change[low + 1] -= groups;
                x = low + 1;
            }
        } else {
            for (int i = 0; i <= n; ++i) {
                next_at[i] = n;
            }
            for (int position : list) {
                next_at[position] = position;
            }
            for (int i = n - 1; i >= 0; --i) {
                if (next_at[i] > next_at[i + 1]) {
                    next_at[i] = next_at[i + 1];
                }
            }
            for (int x = 1; x <= n; ++x) {
                int start = next_at[0];
                while (start < n) {
                    ++big[x];
                    int after = start + x + 1;
                    if (after >= n) {
                        break;
                    }
                    start = next_at[after];
                }
            }
        }
    }

    long long small = 0;
    for (int x = 1; x <= n; ++x) {
        small += change[x];
        std::printf("%lld\n", small + big[x]);
    }
    return 0;
}
```

`threshold` 是不小于 √N 的最小整数。多标签的 `next_at` 每次重新填一遍，O(N)，至多做 N / B 次。`change` 是差分数组，最后从左往右累加，加上 `big` 就是答案。

跑一下样例。N = 9，界线是 3。标签 1 出现 6 次，算多的；标签 2 和 9 算少的。x = 1 时，标签 1 的位置是 0、1、2、5、7、8，分成 {0, 1}、{2}、{5}、{7, 8} 四组；标签 2 的两头牛隔了 2，要两组；标签 9 一组。共 7 组。标签 2 的组数是 x = 1 时为 2、x ≥ 2 时为 1，两段。

慢程序对每个 x、每个标签直接贪心。N 不超过 40、标签种数随机，这样两类标签都会出现，对拍 300 组，输出全部相同。

## 时间也能成为一维

有修改又有询问时，每个询问只看它之前的修改。把“发生的先后”也当作一个坐标，问题就多了一项条件，也就可以照[第 2 章](02-换一张坐标纸看顺序.md)的办法先固定一项。

看一个三项条件的例子：每个点有三个数 (a, b, c)，问每个点有几个点三项都比它小。按 a 排好以后，a 就像时间。把点分成前一半和后一半：两点都在前一半、都在后一半的，交给两半各自去数；一点在前、一点在后的，前一半的 a 都更小，只剩 b、c 两项，正是第 2 章 §2.1 的扫描。每一层合起来 O(n log n)，一共 log n 层，总共 O(n log² n)。这种按时间对半分的做法叫**CDQ 分治**。

四个点 (1, 3, 2)、(2, 1, 1)、(3, 2, 3)、(4, 4, 4)。前一半是前两个点，后一半是后两个。前一半里，(2, 1, 1) 的 b 不比 3 大，0 个。后一半里，(4, 4, 4) 比 (3, 2, 3) 大，1 个。跨两半：(3, 2, 3) 只比得过 (2, 1, 1)，1 个；(4, 4, 4) 两个都比得过，2 个。合起来，四个点依次是 0、0、1、3。

时间当一维还有别的样子：一条边只在一段时间里存在，就把这段时间挂到线段树上，深入遍历时加边、回来时撤销；一批询问各自往前走，就把它们按当前位置排在一起，一起向前推。

## 查很多张有序表，也能复用位置

有 k 张排好序的表，每次询问一个数 x，要在每张表里都找到第一个不小于 x 的数。各自二分是 k 次 O(log n)。可是在第一张表里找到的位置，能不能帮第二张表少找一点？

做法是从最后一张表往前，给每张表做一张“加强表”：把它自己，和下一张加强表里每隔一个取出的数合并起来，每个数记下两件事，它在本表里对应的位置，和它在下一张加强表里对应的位置。

两张表举例：第一张 2 5 9，第二张 1 4 6 8。第二张的加强表就是它自己。从中每隔一个取出 4、8，和第一张合并，第一张的加强表是 2 4 5 8 9。查 x = 6：在加强表里二分，第一个不小于 6 的是 8。从 8 记下的位置出发：第一张表里，不小于它的第一个数是 9，这就是答案；第二张加强表里，8 在第 4 个位置，真正的答案至多往前一格，看一眼前一个数 6，它也不小于 6，于是答案是 6。

为什么至多往前一格：取进来的数是每隔一个取一个，两个取进来的数之间，下一张表里只漏掉了一个数。一次二分以后，每往下一张表只要 O(1) 步，总共 O(log n + k)。这种办法叫**分散层叠**。

**停笔 4**　照上面的两张表查 x = 3，两张表的答案各是几？

这一章的例题是“奶牛的相依”：出现得多的标签少，每个 x 跳着算；出现得少的标签小，把 x 分段二分。另外三节是自己的小例子：莫队让询问之间只挪一格，CDQ 分治把时间当一维对半分，分散层叠复用上一张表的位置。下一章《给昨天留一份不会变的记录》让一个结构在每次修改以后，还能回去看以前的样子。

## 核对

1. 右端从 3 挪到 4，加进 a[3] = 3，`distinct` 从 2 变成 3。左端从 0 挪到 2：去掉 a[0] = 1，1 还剩一个，`distinct` 仍是 3；去掉 a[1] = 2，2 没了，`distinct` 变成 2。共挪 3 步，答案 2。
2. 标签 1 分成 {0, 1, 2}、{5, 7}、{8} 三组：第一组从 0 开始装到 2；下一头在 5，装到 7；8 离 5 超过 2，另开一组。标签 2 的两头隔 2，一组；标签 9 一组。共 5 组，和样例第 2 行一样。
3. 1 个，是 (2, 1, 1)。(1, 3, 2) 的 b 是 3，不比 3 小；(3, 2, 3) 的 c 是 3，不比 3 小；(4, 4, 4) 的 b、c 都大。
4. 第一张是 5，第二张是 4。在加强表 2 4 5 8 9 里，第一个不小于 3 的是 4。第一张表里不小于 4 的第一个数是 5；4 来自第二张表的第 2 个位置，前一个数 1 比 3 小，不用往前挪，答案是 4。
