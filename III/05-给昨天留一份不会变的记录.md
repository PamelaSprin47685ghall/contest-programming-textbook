# 05　给昨天留一份不会变的记录

今天登记了新分数，还想问昨天那段记录的第 3 小。把整个数组每天复印一份当然可以，但多数位置根本没变。

## 只复制本次改动经过的路

线段树单点更新只经过根到叶的一条路。新版本复制这条路，未改动的子树仍与旧版本共用。共享节点只读，不能再偷偷修改；一个版本一个根编号，叫**可持久化**。

求静态子数组第 `k` 小，可以按输入顺序建立“前 `i` 项的值域计数树”。两版本计数相减，就是子数组的计数。在值域树上比较左半有多少项，够 `k` 就走左，否则减去左半数量走右。

**完整程序：**输入 `1 <= n <= 100000`、`0 <= q <= 100000` 和 `n` 个 `int`，每次查询 `left right k`，要求 `0 <= left < right <= n`、`1 <= k <= right-left`，输出半开子数组第 `k` 小，重复值占各自位置。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

struct Node {
    int left;
    int right;
    int count;
};

class Versions {
    std::vector<Node> nodes{{0, 0, 0}};
public:
    int insert(int old, int left, int right, int position) {
        int current = static_cast<int>(nodes.size());
        Node copy = nodes[old];
        ++copy.count;
        nodes.emplace_back(copy);
        if (right - left > 1) {
            int middle = left + (right - left) / 2;
            if (position < middle) {
                int child = insert(nodes[old].left, left, middle, position);
                nodes[current].left = child;
            } else {
                int child = insert(nodes[old].right, middle, right, position);
                nodes[current].right = child;
            }
        }
        return current;
    }
    int kth(int before, int after, int left, int right, int k) const {
        if (right - left == 1) {
            return left;
        }
        int amount = nodes[nodes[after].left].count - nodes[nodes[before].left].count;
        int middle = left + (right - left) / 2;
        if (k <= amount) {
            return kth(nodes[before].left, nodes[after].left, left, middle, k);
        }
        return kth(nodes[before].right, nodes[after].right, middle, right, k - amount);
    }
};

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2 || n < 1 || n > 100000 || q < 0 || q > 100000) {
        return 1;
    }
    std::vector<int> values(n);
    for (int& value : values) {
        if (std::scanf("%d", &value) != 1) {
            return 1;
        }
    }
    std::vector<int> keys = values;
    std::sort(keys.begin(), keys.end());
    keys.erase(std::unique(keys.begin(), keys.end()), keys.end());
    Versions versions;
    std::vector<int> roots(n + 1, 0);
    int domain = static_cast<int>(keys.size());
    for (int i = 0; i < n; ++i) {
        int position = static_cast<int>(std::lower_bound(keys.begin(), keys.end(), values[i]) - keys.begin());
        roots[i + 1] = versions.insert(roots[i], 0, domain, position);
    }
    for (int i = 0; i < q; ++i) {
        int left = 0;
        int right = 0;
        int k = 0;
        if (std::scanf("%d%d%d", &left, &right, &k) != 3 || left < 0 || left >= right
            || right > n || k < 1 || k > right - left) {
            return 1;
        }
        int position = versions.kth(roots[left], roots[right], 0, domain, k);
        std::printf("%d\n", keys[position]);
    }
    return 0;
}
```

输入：

```text
5 2
8 2 8 4 1
0 5 3
1 4 2
```

输出：

```text
4
4
```

建版本时间、空间均 `O(n log n)`，每问 `O(log n)`。节点保存编号，不保存 `vector` 元素的引用，避免扩容后引用失效。两版本可以相减，依赖这里确实保存可相减的计数；不是任意历史树都能直接相减。

**停笔 1**　若新旧版本共用一个左孩子，更新新版本时直接改那个孩子，会破坏哪项承诺？只复制根够吗？

## 只想回到刚才，不一定保留所有昨天

可回滚并查集不做路径压缩，只按大小合并。每次成功合并记下哪个根接到谁、原大小是多少；记一个历史栈长度作快照，撤销到该长度即可。树高 `O(log n)`，合并和查询 `O(log n)`，一次撤销 `O(1)`。

与时间线段树组合：进入节点存快照、合并有效边，叶子回答，离开回退。结构负责自己的历史，调度者负责递归区间和何时回退。若做路径压缩却不记每次父亲改变，就无法正确撤销。

## 结构可以变化，记录仍须跟着走

平衡搜索树按键组织左右孩子，节点再存子树大小，就能按排名取第 `k` 项。Treap 另外给每节点随机优先级：键满足二叉搜索树次序，优先级满足堆次序。`split` 按键或排名分两棵，`merge` 选择优先级较高的根并递归合并边界子树，每次回来重算大小，期望树高 `O(log n)`。

把“按键”改成“按左子树大小决定位置”，就能维护可插删、翻转的序列。翻转标记交换左右孩子并延迟传递；分裂前先下传。随机性给期望保证，不是最坏高度承诺，优先级冲突要有一致的打破方式。

按颜色段维护序列，则把相邻同色合成区间。赋值时先在左右边界分裂、删除中间段、放一段新颜色，再合并相邻同色。整段赋值会消灭旧边界，某些工作量可按被删边界收费；若操作不断制造碎段并逐段查询，最坏仍能很慢。这是颜色段均摊的边界，不是“随机数据快”就有通用复杂度保证。

**停笔 3**　按位置维护的 Treap，左子树大小为 3，根是本树第几项？查第 6 项时，转入右子树后应找第几项？

## 核对

1. 旧版本应保持原样；只复制根，下一层共享节点仍会被改坏。整条修改路径都要复制。
2. 压缩绕过了后来被撤销的父子边，留下未回退的新连接。
3. 按 1 开始计是第 4 项；右子树里找第 2 项。
