# 05　给昨天留一份不会变的记录

写日记的人，不会每天把前面所有的日记重抄一遍再加上今天。昨天写的就留在那一页，今天只写今天的事。要知道上个月的某一天发生了什么，翻到那一页就是。改稿子的人不一样：他常常只想退回到刚才那一步，不需要每一天的样子都留着。

数据结构也有这两种要求。这一章讲：修改时只复制这一次改动经过的那条路，每一个旧版本都还能查；只想退回刚才时，记下每一步改了什么，倒着撤回；结构自己会变形时，这份记录也必须跟着变。

## 只复制本次改动经过的路

一列数 a，长 n。q 个询问，每个问：第 left 到第 right − 1 个数里，不超过 x 的有几个。

要是只问整列，用第二卷第 15 章的树状数组，下标是值的名次。问一段 [left, right) 时，想到第二卷第 3 章的前缀和：答案是“前 right 个数里不超过 x 的个数”减去“前 left 个数里的”。要是对每个前缀都有一棵按值建的树，事情就成了。可是 n 棵树各存一份，是 O(n²) 的空间。

看第 i 棵树和第 i + 1 棵树差在哪里：只多放进了一个数。用第二卷第 16 章的线段树，按值的名次建，放进一个数只改从根到一个叶子的一条路，O(log n) 个点。别的点，两棵树完全一样。

于是新版本只复制这条路上的点：每个新点照抄旧点的两个孩子，再把计数加 1；往下走的那一边，换成递归造出来的新孩子。没走到的那一边，新点直接指着旧树的孩子，两个版本共用。每个版本记下自己的根。旧版本的点一个都没改，所以昨天的树还在，查哪个版本就从哪个根往下走。这样的结构叫**可持久化**的，这里是一棵可持久化线段树。

### 一段里不超过 x 的数

输入第一行 n、q（都到 10⁵），第二行 n 个整数（绝对值不超过 10⁹）。接下来 q 行，每行 left、right、x，0 ≤ left ≤ right ≤ n。每个询问输出一行。

样例输入：

```text
6 3
5 1 4 1 5 9
0 6 4
1 4 1
2 6 5
```

样例输出：

```text
3
2
3
```

第一个询问整列里不超过 4 的是 1、4、1；第二个询问在 1 4 1 里数 1，有两个；第三个询问在 4 1 5 9 里，9 不算。

这道题没有 USACO 的出处，是为这一节设计的。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

// 管名次区间 [low, high) 的线段树；0 号点是空树，它的孩子都是自己
struct PersistentTree {
    std::vector<int> left_child;
    std::vector<int> right_child;
    std::vector<int> count;

    PersistentTree() : left_child(1, 0), right_child(1, 0), count(1, 0) {}

    // 在 node 这棵树里放进一个名次 position，返回新树的根；旧树不动
    int insert(int node, int low, int high, int position) {
        int fresh = static_cast<int>(count.size());
        left_child.push_back(left_child[node]);
        right_child.push_back(right_child[node]);
        count.push_back(count[node] + 1);
        if (high - low > 1) {
            int middle = low + (high - low) / 2;
            if (position < middle) {
                int child = insert(left_child[node], low, middle, position);
                left_child[fresh] = child;
            } else {
                int child = insert(right_child[node], middle, high, position);
                right_child[fresh] = child;
            }
        }
        return fresh;
    }

    // node 这棵树里，名次小于 limit 的有几个
    int count_below(int node, int low, int high, int limit) const {
        if (node == 0 || limit <= low) {
            return 0;
        }
        if (high <= limit) {
            return count[node];
        }
        int middle = low + (high - low) / 2;
        return count_below(left_child[node], low, middle, limit) +
               count_below(right_child[node], middle, high, limit);
    }
};

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d %d", &n, &q) != 2) {
        return 1;
    }
    std::vector<int> a(n, 0);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d", &a[i]) != 1) {
            return 1;
        }
    }
    std::vector<int> values = a;
    std::sort(values.begin(), values.end());
    values.erase(std::unique(values.begin(), values.end()), values.end());
    int m = static_cast<int>(values.size());

    // root[r]：放进了 a[0] 到 a[r − 1] 的那个版本
    PersistentTree tree;
    std::vector<int> root(n + 1, 0);
    for (int i = 0; i < n; ++i) {
        int rank = static_cast<int>(std::lower_bound(values.begin(), values.end(), a[i]) -
                                    values.begin());
        root[i + 1] = tree.insert(root[i], 0, m, rank);
    }

    for (int k = 0; k < q; ++k) {
        int left = 0;
        int right = 0;
        int x = 0;
        if (std::scanf("%d %d %d", &left, &right, &x) != 3) {
            return 1;
        }
        // 不超过 x 的值，名次都小于 limit
        int limit = static_cast<int>(std::upper_bound(values.begin(), values.end(), x) -
                                     values.begin());
        int answer = tree.count_below(root[right], 0, m, limit) -
                     tree.count_below(root[left], 0, m, limit);
        std::printf("%d\n", answer);
    }
    return 0;
}
```

值先排序去重，换成名次 0 到 m − 1。`root[r]` 是放进前 r 个数以后的版本，`root[0]` 是 0 号空树。0 号点的两个孩子都是 0、计数是 0，所以“从空树复制”不用另写。

`insert` 里有一处要小心。`left_child[fresh] = insert(...)` 看上去更简洁，可是 `insert` 里会 `push_back`，vector 可能换一块更大的内存，原来的元素都搬了家。C++14 不保证先调用 `insert` 再去找 `left_child[fresh]` 的位置，找早了，写进去的就是已经还回去的旧内存。这样写的程序样例可能照样对，换一组数据就不对；加上 `-fsanitize=address` 跑样例，会直接报 heap-use-after-free。先把结果放进 `child`，再赋值，就没有这个问题。

每次放进一个数新造 O(log m) 个点，总共 O(n log n) 个点；每个询问在两个版本里各走一遍，O(log n)。

这道题也可以离线做：把询问按 x 排好，数从小到大放进树状数组。可持久化的好处是不用事先拿到所有询问，来一个答一个。

慢程序对每个询问把那一段直接数一遍。在 n 不超过 15、值有正有负的数据上和程序 A 对拍 300 组，答案全部相同。

## 只想回到刚才，不一定保留所有昨天

有时不需要每一个旧版本，只需要“退回到刚才做标记的地方”，而且总是先退最近的。这时用不着复制：每做一次修改，把它改了什么记到一个栈上；要退回，就从栈顶一条条撤销。这叫**可撤销**的结构。

第二卷第 13 章的并查集可以这样做。路径压缩会一下改很多点，撤销时改不回来，所以不用它，只用按大小合并：树高不超过 log₂ n，查找仍是 O(log n)。每次真正的合并只改两处：被挂上去的代表的 `leader`，和新代表的 `group_size`。栈上记下被挂上去的那个代表就够了，撤销时从它找到新代表，把两处改回去。

下面是**片段**。

```cpp
// 位于 main 内；leader[v] 起初是 v，group_size[v] 起初是 1
auto find = [&](int v) {
    while (leader[v] != v) {
        v = leader[v];  // 不做路径压缩，撤销时才改得回来
    }
    return v;
};
std::vector<int> undo_stack;  // 每次真正的合并，记下被挂上去的那个代表
auto unite = [&](int a, int b) {
    a = find(a);
    b = find(b);
    if (a == b) {
        return;
    }
    if (group_size[a] < group_size[b]) {
        std::swap(a, b);
    }
    leader[b] = a;
    group_size[a] += group_size[b];
    undo_stack.push_back(b);
};
auto undo_to = [&](int mark) {
    while (static_cast<int>(undo_stack.size()) > mark) {
        int b = undo_stack.back();
        undo_stack.pop_back();
        int a = leader[b];
        group_size[a] -= group_size[b];
        leader[b] = b;
    }
};
```

做标记就是记下此刻栈的高度，`undo_to` 把栈退回这个高度。合并时两个代表已经相同，什么也不改，也就不进栈，撤销时不会多撤一步。

在纸上跑一遍。4 个点 0 到 3。合并 0、1：两组一样大，1 挂到 0 上，栈是 [1]。合并 2、3：3 挂到 2 上，栈是 [1, 3]。做标记，高度 2。合并 1、2：两个代表 0 和 2 一样大，2 挂到 0 上，0 那组有 4 个，栈是 [1, 3, 2]。问 1 和 3：3 先到 2 再到 0，同组。退回标记：弹出 2，0 那组减回 2 个，2 重新当自己的代表。再问 1 和 3，不同组了。

慢程序记下全部合并的历史，退回时把历史截短，每次询问从头建图搜一遍。随机混着合并、做标记、退回、询问，至多 7 个点，对拍 300 组，输出全部相同。

这种结构常和第四章的“时间也能成为一维”一起用：一条边只在一段时间里存在，把它挂到时间的线段树上，往下走时合并，回来时撤销。

## 结构可以变化，记录仍须跟着走

可持久化的线段树形状不变，每次只改一条路。有的结构会变形：平衡树为了保持平衡要旋转、分裂、合并，带懒标记的树在往下走时要把标记推给孩子。这些动作都会改点，而被改的点可能正被别的版本共用。

规则只有一条：任何一个要改的点，先复制一份再改。推懒标记时，孩子也要改，所以连两个孩子一起复制；旋转改了三个点的指针，这三个点都要复制。只要守住这一条，每个旧版本的根往下看到的，仍是当时的样子。代价是每次多复制几个点，每次操作仍是 O(log n) 个。

不要求旧版本时，也可以只用一份会变形的结构，但要记得：结构变了，题目里的量有没有跟着它一起变对。下面这道题就是这样，排队的牛一头头加进来，一张“位置与时间”的表整体平移，又要插进新的一项。

## 核对

1. m = 4，不同的值是 1、4、5、9。名次区间 [0, 4) 从根到叶子经过 3 个点，每放一个数新造 3 个点，6 个数共 18 个，加上 0 号，一共 19 个点。
2. 结果仍然对：0 号点的计数是 0，孩子也是 0，往下走得到的都是 0。但查询会在空树里一直走到叶子，白白多走；`node == 0` 让它在空的地方立刻停下。
3. 栈是 [1, 3, 0]。`unite(3, 1)` 里 a 是 3 的代表 2，b 是 1 的代表 0，两组都是 2 个，不交换，于是 0 挂到 2 上，2 成了代表，那组 4 个点。和退回之前相比，组是一样的，代表却换了：撤销并不保证再做一遍会得到同样的树。
4. 那个孩子还被别的版本共用，比如版本 2 也指着它。把标记推进去，等于改了版本 2 的数据，以后在版本 2 上查询，会看到版本 3 才有的修改。
