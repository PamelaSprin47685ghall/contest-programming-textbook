# 06　别把每个旧答案都问一遍

动态规划已经省掉许多重复子问题，却可能每个状态仍要问一遍全部过去。优化之前，先写原式，确认省掉的是哪些候选，而不是把答案换成另一个问题。

## 先从算式里拆出只属于现在的部分

位置 `x[0]=0`，随后不下降。把路分成若干跳，每跳代价为距离平方加固定费用 C。令 `dp[i]` 为到第 `i` 站最低代价：

$$dp[i]=\min_{j<i}\{dp[j]+(x[i]-x[j])^2+C\}.$$

展开平方：`x[i]^2+C` 只属于现在；每个旧站提供一条直线 `y=(-2*x[j])*X+dp[j]+x[j]^2`，在 `X=x[i]` 处问最低值即可。这是斜率优化的起点，不是“看见平方就背队列”。

斜率随旧站不增，查询 X 也不减，可维护下包络的双端队列。中间直线若与前线的交点不早于它与后线的交点，就永远无用；交叉相乘比较，避免浮点交点误差。相同斜率只留截距较小的一条。

**完整程序：**输入 `0 <= n <= 100000`、`0 <= C <= 10000` 及 `n` 个不下降的整数坐标，均在 0 到 10000，输出 `dp[n]`。

```cpp
#include <cstdio>
#include <deque>

struct Line {
    long long slope;
    long long intercept;
    long long value(long long x) const { return slope * x + intercept; }
};

bool redundant(const Line& a, const Line& b, const Line& c) {
    return (b.intercept - a.intercept) * (b.slope - c.slope)
        >= (c.intercept - b.intercept) * (a.slope - b.slope);
}

int main() {
    int n = 0;
    long long fee = 0;
    if (std::scanf("%d%lld", &n, &fee) != 2 || n < 0 || n > 100000 || fee < 0 || fee > 10000) {
        return 1;
    }
    std::deque<Line> hull;
    hull.emplace_back(Line{0, 0});
    long long answer = 0;
    int previous = 0;
    for (int i = 1; i <= n; ++i) {
        int x = 0;
        if (std::scanf("%d", &x) != 1 || x < previous || x > 10000) {
            return 1;
        }
        previous = x;
        while (hull.size() > 1 && hull[1].value(x) <= hull[0].value(x)) {
            hull.pop_front();
        }
        answer = hull.front().value(x) + 1LL * x * x + fee;
        Line next{-2LL * x, answer + 1LL * x * x};
        if (!hull.empty() && hull.back().slope == next.slope) {
            if (hull.back().intercept <= next.intercept) {
                continue;
            }
            hull.pop_back();
        }
        while (hull.size() > 1 && redundant(hull[hull.size() - 2], hull.back(), next)) {
            hull.pop_back();
        }
        hull.emplace_back(next);
    }
    std::printf("%lld\n", answer);
    return 0;
}
```

输入：

```text
3 2
1 2 4
```

输出：

```text
12
```

每条线入队、出队至多一次，时间 `O(n)`。本范围 `dp[i] <= x[i]^2+C`，交叉乘积在 `long long` 内。扩大坐标范围必须重算乘积界；不能把这里的类型当作通用保证。斜率或查询不单调时，改用二分凸包或李超线段树等对应结构，而不是继续弹掉前线。

## 不需要直线，也可能有更少决策

转移为一段来源的和，维护前缀和；为一个滑动区间最值，维护单调队列；几路来源独立，可以先各自汇总再组合。贡献可拆到多步时，增加一个中间状态有时反而减少边数。

分段 DP `D[t][i]=min_j(D[t-1][j]+cost(j,i))`，若最优决策位置随 i 不下降，可用分治计算一行：算中点最优 j，左右递归只查受限候选段。一般每行 `O(n log n)` 次候选检查，还要乘单次 cost 代价。四边形不等式等性质可推导单调性，不能拿观察到的几个表项替代证明。

矩阵满足 `A[i,j]+A[i+1,j+1] <= A[i,j+1]+A[i+1,j]` 的一种方向时称 Monge；相应方向下行最小值位置单调。全单调性要求任意子矩阵也保留适合的最小位置关系。SMAWK 利用它：用列栈删掉不可能成为行最小的列，递归求隔行最小值，再在相邻已知决策之间扫描补行；行列总工作为线性次元素访问。先确认方向、平局规则及每个元素能否 `O(1)` 求值，才有线性结论。

例如三行分别为 `0,1,4`、`1,0,1`、`4,1,0`，来自 `(行号-列号)²`，各行最小列为 0、1、2。它不仅碰巧行最小值向右走，还满足上述每个相邻四格的不等式，才有更强的删列依据。

## 让状态少一维，也有条件

恰好选 K 段，给每段加价格 λ，先解“不限段数”的问题。λ 越大，选择的最优段数不会增加；二分 λ，记录费用和段数，并对平局统一选较多或较少。这是带惩罚的参数优化，常叫 WQS 二分。

只有原“段数—最优费用”的离散凸性等条件成立，才可从支撑线恢复恰好 K 的答案。例如一、二、三段的最优费用为 9、5、4，价格 λ=2 时选两段，修改后费用为 9，减去 `2*2` 回到 5。

反过来，若三份费用为 0、10、0，二段点高于两端连线，任何价格都不会选它：价格为正倾向一段，价格为负倾向三段。此时不能用支撑线恢复“恰好两段需 10”。去掉一维不是免费的。

若 DP 保存的是凸分段线性函数，可用两个堆保存斜率改变位置，加上平移偏置：加 `|x-a|` 插入断点，限制最优位置或整体平移则移动断点或偏置。这叫 slope trick。对 `|x-2|+|x-6|`，最小值为 4，在 `[2,6]` 全部取得；只保存一个最优点会丢掉后续约束所需的信息。这也解释为何有时应维护**所有极优位置**，不是一个数。
