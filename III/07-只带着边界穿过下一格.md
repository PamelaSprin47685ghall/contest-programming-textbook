# 07　只带着边界穿过下一格

过河踩石头，每一步只关心脚下这块和下一块，至于已经走过的那些石头是怎么排的，不用记。要是背着一筐东西过河，还得记一件事：筐里还剩多少。可以过河的人很多，每个人记的都只是“我现在站在哪块、筐里还剩多少”。

这一章的 DP 都是这样：一位一位、一格一格往前走，状态里只带着走到这里还必须知道的那一点东西。先把每一位说成人话，看清要带什么；再看“不超过某个上界”怎样成为状态的一部分；最后，对象少到二十个左右时，干脆把“已经用了哪些”整个记成一个集合。

## 先把每一位翻译成人话

逐位处理一个数时，先问：在这一位上，题目的条件说的是什么？要算出这一位，还需要从别的位带来什么？加法从低位往高位进位，所以从低位做起时，要带的是进位；比大小从高位决定，所以从低位做起时，要带的是“低几位比下来谁大”，而高一位一旦分出大小，就把低位的结论盖掉。

### 数奶牛

方格纸上，坐标 (x, y)（x、y ≥ 0）上有一头牛，当且仅当把 x、y 都写成三进制，每一位上两个数字的奇偶相同（1 是奇数，0 和 2 是偶数；位数不够的在前面补 0）。Q 个询问（到 10⁴），每个给出 d、x、y（都到 10¹⁸），问 (x, y)、(x + 1, y + 1)、…、(x + d, y + d) 这 d + 1 个格子上一共有几头牛。

输入第一行 Q，接下来 Q 行，每行 d、x、y。每个询问输出一行。

样例输入：

```text
8
10 0 0
10 0 1
9 0 2
8 0 2
0 1 7
1 1 7
2 1 7
1000000000000000000 1000000000000000000 1000000000000000000
```

样例输出：

```text
11
0
4
3
1
2
2
1000000000000000001
```

这是 USACO 2021 年 2 月金组第三题[“数奶牛”](../USACO/金组/2020_2021/2021.02/P3.md)。

要数的是满足条件的 k，0 ≤ k ≤ d。把 k 也写成三进制，一位一位地定下来。翻译成人话，第 i 位要满足的是：x + k 和 y + k 在第 i 位上的数字奇偶相同。这一位的数字取决于 x、y、k 在第 i 位上的数字，以及从低一位来的进位。所以从低位往高位做，要带着两个进位：x + k 的和 y + k 的，各是 0 或 1（两个三进制数字加上进位至多 2 + 2 + 1 = 5，进位不超过 1）。

还有 k ≤ d 这一条。它也一位一位地带着：低几位组成的数，比 d 的低几位小、相等还是大。新的一位比 d 的这一位小或大，就直接定下关系；相等，就沿用低位的关系。

于是状态是“关系、两个进位”，3 × 2 × 2 = 12 种，每一位试 k 的三种数字。做完所有位以后，关系是小或相等、两个进位都是 0（x + k、y + k 没有多出更高的一位，而那些更高的位上，两边都是 0，奇偶相同），就是一个合格的 k。

下面是**片段**。

```cpp
// 位于 main 内；对一个询问 d、x、y，数 0 ≤ k ≤ d 里有几个 k 让 (x + k, y + k) 上有牛
// way[relation][carry_x][carry_y]：已定下 k 的低几位，有几种定法
// relation：低几位组成的数和 d 的低几位比，0 是小，1 是相等，2 是大
long long way[3][2][2] = {};
way[1][0][0] = 1;
long long power = 1;  // 3 的 digit 次方
for (int digit = 0; digit < 39; ++digit) {
    long long next[3][2][2] = {};
    int dd = static_cast<int>(d / power % 3);
    int xd = static_cast<int>(x / power % 3);
    int yd = static_cast<int>(y / power % 3);
    for (int relation = 0; relation < 3; ++relation) {
        for (int cx = 0; cx < 2; ++cx) {
            for (int cy = 0; cy < 2; ++cy) {
                long long ways = way[relation][cx][cy];
                if (ways == 0) {
                    continue;
                }
                for (int kd = 0; kd < 3; ++kd) {  // k 在这一位取 kd
                    int sx = xd + cx + kd;
                    int sy = yd + cy + kd;
                    if (sx % 3 % 2 != sy % 3 % 2) {
                        continue;  // 这一位上奇偶不同，没有牛
                    }
                    int now = relation;  // 更高的一位一旦不同，就盖过低位的比较
                    if (kd < dd) {
                        now = 0;
                    } else if (kd > dd) {
                        now = 2;
                    }
                    next[now][sx / 3][sy / 3] += ways;
                }
            }
        }
    }
    for (int relation = 0; relation < 3; ++relation) {
        for (int cx = 0; cx < 2; ++cx) {
            for (int cy = 0; cy < 2; ++cy) {
                way[relation][cx][cy] = next[relation][cx][cy];
            }
        }
    }
    if (digit < 38) {
        power *= 3;
    }
}
long long count = way[0][0][0] + way[1][0][0];
```

x + k 不超过 2 × 10¹⁸，3³⁹ 约是 4 × 10¹⁸，39 位够用。`power` 到 3³⁸ 就不再乘，免得最后一次乘出界。每个询问 39 位、每位 12 × 3 次转移，Q = 10⁴ 时只有一千多万步。

慢程序把每个 k 都拿来，直接把 x + k、y + k 转成三进制逐位比较。d、x、y 都不超过 300，对拍 300 组，每组 5 个询问，答案全部相同。

## 上界也是边界

数“不超过 B 的数”，不必把它们一个个列出来。从高位往低位定数字，带着一个标记：到这里为止，和 B 的前几位是否完全一样。一样的，下一位不能超过 B 的那一位；已经小了的，后面随便取。数“在 A 到 B 之间”的，就数“不超过 B”减去“不超过 A − 1”。这样一位位定数字、状态里带着进位或比较关系的 DP，叫**数位 DP**。

数位不是总按次序一个个定下来的。下面这道题的数字可以加在两头，比较关系也要跟着变成两头的规则。

### 堆纸片

一排 N 张纸（N 到 300），每张写一个数字 1 到 9。给定 A ≤ B < 10¹⁸。Q 个询问（到 5 × 10⁴），每个给出 l、r：从第 l 张到第 r 张依次考虑，每张可以放到纸堆顶上、放到底下，或者不用。最后从顶到底读出一个整数（一张不用就是 0）。3 的 (r − l + 1) 次方种做法里，读出的数落在 [A, B] 里的有几种，模 10⁹ + 7。

样例输入：

```text
5 13 327
1 2 3 4 5
3
1 2
1 3
2 5
```

样例输出：

```text
2
18
34
```

这是 USACO 2023 年 2 月金组第三题[“堆纸片”](../USACO/金组/2022_2023/2023.02/P3.md)。

看询问 [1, 2] 的 9 种做法：都不用是 0；只用 1，放顶或放底，都是 1，两种；只用 2，两种；都用，第一张放下去是 1，第二张放顶得 21，放底得 12，而第一张放顶、放底又各算一种，所以 21 和 12 各两种。落在 [13, 327] 里的只有 21 的那两种。

先算“不超过 B”的做法数。纸堆上的数字始终是一个连续的数字串，新的纸放顶，是在左边加一位；放底，是在右边加一位。设 B 有 D 位。把纸堆想象成要对齐到 B 的某一段位置 x 到 y 上：最后读出的数要是有 D 位，就对齐到 B 的全部；比 D 位少，一定比 B 小。

于是状态是“这一叠对齐到 B 的第 x 到第 y 位，和 B 的这一段比是小、等还是大”。放顶时新数字落在第 x − 1 位，它比低位都高，直接定下关系：比 B 的那一位小就是小，大就是大，相等才沿用原来的关系。放底时新数字落在第 y + 1 位，它是最低的一位，只有原来完全相等时才由它决定，原来已经是小或大，就不变。这正是本章开头说的：比大小时，高位盖过低位。

固定左端 l，r 一张张往右加，每加一张把所有 (x, y, 关系) 更新一遍，O(D²)。所有 l、r 共 O(N² D²)，约 300² × 18² ≈ 3 × 10⁷，事先算好每个 [l, r] 的答案，询问时直接查。最后的计数：对齐到第 x 位到最后一位，x 不是第一位的（位数比 B 少）三种关系都算，x 是第一位的只算小和相等。“不超过 A − 1”同样做一遍，两者相减。0 在两次里都算到了，A ≥ 1，减掉正好抵消。

## 只剩少数对象，可以直接记集合

对象不超过二十个左右时，“已经用掉了哪些”可以整个记进状态：用一个整数的二进制位表示一个集合，第二卷第 2 章 §2.4 的位运算就够用。集合有 2ⁿ 个，n = 18 时是 26 万多个，每个再试 n 种下一步，几百万次。状态里含一个集合的 DP 叫**状压 DP**。

### 摩天大楼里的奶牛

N 头牛（N ≤ 18）坐电梯下楼，电梯一趟最多载重 W（到 10⁸），第 i 头重 Cᵢ（不超过 W）。求最少要几趟，并给出一种方案。

输入第一行 N、W，接下来 N 行每行一个 Cᵢ。输出第一行是趟数 R，接下来 R 行，每行先写这一趟几头牛，再按从小到大写出它们的编号。方案不唯一，输出任意一种。

样例输入：

```text
4 10
5
6
3
7
```

样例输出：

```text
3
2 1 3
1 2
1 4
```

5、6、7 两两相加都超过 10，至少 3 趟；3 号可以和任何一头同行。这是 USACO 2012 年 3 月金组第三题[“摩天大楼里的奶牛”](../USACO/金组/2011_2012/2012.03/P3.md)。

按某个次序一头头装进电梯，装不下就另开一趟。对一个集合 mask，记“运走这些牛最少几趟”，趟数一样时，再记“最后这一趟最少已经装了多重”。这两个数就是要带着的边界：以后的牛只关心还剩多少空间，不关心前面每一趟装了谁。

为什么先比趟数：一个状态趟数少一趟，哪怕最后这一趟装得满，另一个状态能接着装的牛，它新开一趟也装得下，趟数不会更多。趟数相同时，装得越轻越好。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    long long capacity = 0;
    if (std::scanf("%d %lld", &n, &capacity) != 2) {
        return 1;
    }
    std::vector<long long> weight(n, 0);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%lld", &weight[i]) != 1) {
            return 1;
        }
    }

    int full = 1 << n;
    // 运走集合 mask 里的牛：rides 是用了几趟（含正在装的这一趟），load 是这一趟已装多重
    std::vector<int> rides(full, n + 1);
    std::vector<long long> load(full, 0);
    std::vector<int> added(full, -1);  // 最后放进来的是哪头牛，用来还原方案
    rides[0] = 1;
    for (int mask = 0; mask < full; ++mask) {
        for (int cow = 0; cow < n; ++cow) {
            if ((mask >> cow) & 1) {
                continue;
            }
            int next = mask | (1 << cow);
            int next_rides = rides[mask];
            long long next_load = load[mask] + weight[cow];
            if (next_load > capacity) {
                next_rides += 1;  // 这一趟装不下，另开一趟
                next_load = weight[cow];
            }
            if (next_rides < rides[next] ||
                (next_rides == rides[next] && next_load < load[next])) {
                rides[next] = next_rides;
                load[next] = next_load;
                added[next] = cow;
            }
        }
    }

    // 从全集往回走，按趟数分组
    int total = rides[full - 1];
    std::vector<std::vector<int>> groups(total);
    int mask = full - 1;
    while (mask != 0) {
        int cow = added[mask];
        groups[rides[mask] - 1].push_back(cow + 1);
        mask ^= 1 << cow;
    }
    std::printf("%d\n", total);
    for (std::vector<int>& group : groups) {
        std::sort(group.begin(), group.end());
        std::printf("%d", static_cast<int>(group.size()));
        for (int cow : group) {
            std::printf(" %d", cow);
        }
        std::printf("\n");
    }
    return 0;
}
```

`rides[0]` 记成 1，表示一开始就有一趟空的电梯在等，这样“装得下”和“另开一趟”可以用同一个式子。从小集合往大集合推，`next` 总比 `mask` 大，推到它时它的所有来路都已经算好。`added` 记下最后放进的牛，从全集往回走，每头牛进的是第 `rides[mask]` 趟。

状态 2¹⁸ 个，每个试 18 头牛，约 470 万次。

慢程序从 1 趟起，把每头牛分到哪一趟的所有分法都试一遍，找到第一个装得下的趟数。答案不唯一，所以另写了一个检查程序：趟数要和慢程序一样，每头牛恰好出现一次，每趟不超重，编号从小到大。N 不超过 7，跑 300 组，全部通过。

## 核对

1. 1 是 01，7 是 21（三进制，高位在前）。最低位都是 1，奇偶同；第二位是 0 和 2，都是偶数。2 是 02，8 是 22：最低位 2 和 2，第二位 0 和 2，都是偶数。两格都有牛。
2. 6 种。读出的数有 0、1（两种）、2（两种）、12（两种）、21（两种）。不超过 20 又不小于 1 的是 1、2、12，各两种，共 6 种。
3. {1 号, 2 号}：5 + 6 超重，要 2 趟；先装 6 再装 5，最后一趟只有 5，先装 5 再装 6，最后一趟是 6，取轻的，记 2 趟、5。{1 号, 3 号}：5 + 3 = 8 装得下，记 1 趟、8。
