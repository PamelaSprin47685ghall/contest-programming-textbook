# 07　只带着边界穿过下一格

用小长方片铺满两行方格，过去铺成什么花纹通常不重要，重要的是哪几格伸到了下一列。把未来仍会问到的信息留下，其余忘掉，才是状态压缩的含义。

## 先把每一位翻译成人话

宽为 w 的棋盘按格扫描，位掩码记录轮廓线上哪几格已被前面的竖片占用。当前位置已占用就清标记前进；未占用，可以放向右或向下的一片，检查边界与目标格是否空。处理完一行要统一轮廓对应的位次。

只有“占没占”时，`2^w` 个掩码可描述边界。若还要让所有片段最终接成一个环，仅记占用不够：须记哪些端点已经相连，并把等价编号归一。这个插头 DP 中，提前封闭一个小环可能让余下格子永远接不上，必须在转移时排除，不能留到最后才发现。

**停笔 1**　两行两列用面积为二的长方片铺满，有几种？如果每片都要求一个全局编号，而题目根本不区分片的身份，保留编号会增加什么无用状态？

## 上界也是边界

数 0 到 N 中，不出现数字 4，也不出现相邻 `62` 的整数。逐位从左到右决定，只需记前一位是不是 6、当前是否仍贴着 N 的上界。

不贴上界的剩余问题可以复用；贴上界时，当前位不能大于 N 的对应位。此处补在前面的零不制造 4 或 62，所以无需单独记“是否已开始”；若题目统计零的出现次数，这个省略就未必成立。

**完整程序：**输入 `0 <= N <= 10^18`，输出上述数量，包含整数 0。

```cpp
#include <cstdio>
#include <string>
#include <vector>

class Counter {
    std::string digits;
    std::vector<std::vector<long long>> memo;
    long long solve(int position, int previous_six, bool tight) {
        if (position == static_cast<int>(digits.size())) {
            return 1;
        }
        if (!tight && memo[position][previous_six] != -1) {
            return memo[position][previous_six];
        }
        int upper = tight ? digits[position] - '0' : 9;
        long long answer = 0;
        for (int digit = 0; digit <= upper; ++digit) {
            if (digit == 4 || (previous_six && digit == 2)) {
                continue;
            }
            answer += solve(position + 1, digit == 6, tight && digit == upper);
        }
        if (!tight) {
            memo[position][previous_six] = answer;
        }
        return answer;
    }
public:
    explicit Counter(long long upper) : digits(std::to_string(upper)),
        memo(digits.size(), std::vector<long long>(2, -1)) {}
    long long count() { return solve(0, 0, true); }
};

int main() {
    long long n = 0;
    if (std::scanf("%lld", &n) != 1 || n < 0 || n > 1000000000000000000LL) {
        return 1;
    }
    Counter counter(n);
    std::printf("%lld\n", counter.count());
    return 0;
}
```

输入：

```text
20
```

输出：

```text
19
```

这是数位 DP，也可看作按字典序走一棵十叉树。数字位数 d 时，状态与转移代价 `O(d*2*10)`，递归深度 `O(d)`；答案不超过 `N+1`，本范围可用 `long long`。求 `[L,R]` 可用 `F(R)-F(L-1)`，但 `L=0` 时不要请求负上界，应直接减零。

## 只剩少数对象，可以直接记集合

旅行经过 n 个不同站点，令 `dp[mask][v]` 为已经访问集合 mask、最后在 v 的最小费用，向未访问点转移。初始只含起点，答案再按是否要求回起点处理。时间 `O(2^n*n²)`，空间 `O(2^n*n)`，n 约二十时已要认真算内存。

区间 DP 则保留两端：例如合并一段相邻石堆，最后一次在 k 分成左右两堆，枚举 k，把两段答案与本段总重量相加。必须按段长由短到长计算。环上复制一份序列，计算长度不超过 n 的段，再枚举断口。

数位、集合、区间、树形 DP 不必背成互不相干的家族：都是问“未来还需要怎样的边界”。有时边界不是几项，而是一条函数或一个自动机状态；第 6 章与字符串章会继续用到。

**停笔 3**　两条访问顺序到达相同 `mask,v`，后续合法边也相同，最短路目标下保留较贵的一条有必要吗？若改成数走法，还能只留较便宜的一条吗？

## 核对

1. 两种：两片横放或两片竖放。给同一铺法换片编号会被重复区别，状态膨胀却不提供未来信息。
2. 4、14。前一位 6 时不能选 2、4；4 任何时候都不能选。数字 602 没有相邻 62，“曾有 6”会误判它。
3. 没必要，较贵方案不会改善未来。计数必须累计所有不同走法，不能套用最优性淘汰。
