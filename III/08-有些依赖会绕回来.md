# 08　有些依赖会绕回来

走到格子 A，下一步可能回到原来的格子。若写“答案等于下一步答案加一”，就不再有一个从小到大的天然顺序。先判断关系是什么，别把任何递推都算一遍就停。

## 不等式与等式，做法不同

`distance[v] <= distance[u]+w` 是一条差分约束。把它画成 `u→v` 权 w 的边，加入一个到所有点的零边超级起点，最短路距离给出一组满足约束的取值。若存在负环，沿环相加得到 `x <= x + 负数`，不可能成立。

求所有满足条件的最小或最大值时，还要检查变量是否有锚点、目标是否有界。超级起点帮助检查可行性，不自动决定原题每个变量的绝对大小。

概率期望是等式。例如一次尝试成功概率为一半，每次花一步，失败回到原状态。平均步数 E 满足 `E=1+E/2`，所以 E 为 2。这里“平均”不是保证每两次一定成功，长时间失败仍有可能。

## 消掉一个未知量，再消掉下一个

联立 `x+y=3`、`x-y=1`，相加得 `2x=4`，于是 x=2、y=1。高斯消元把这种行变换推广到更多方程：换行；给一行乘非零数；从一行减去另一行的倍数。每步都保持解集。

为了把示例做成精确核对，下面在模 17 的世界里算。非零数都有乘法逆元，可以逐个试 1 到 16 找到；不是用普通整数除法。以后第 18、19 章解释更一般的求逆与线性空间。

**完整程序：**输入 `1 <= n <= 50`，接着 n 行，每行 n 个系数和一个右端值，全部在 0 到 16。求 n 个未知数的模 17 解。输出 `NONE`、`MANY`，或唯一解的一行。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int normalize(int x) { return (x % 17 + 17) % 17; }

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 1 || n > 50) {
        return 1;
    }
    std::vector<std::vector<int>> a(n, std::vector<int>(n + 1));
    for (auto& row : a) {
        for (int& value : row) {
            if (std::scanf("%d", &value) != 1 || value < 0 || value >= 17) {
                return 1;
            }
        }
    }
    int rank = 0;
    std::vector<int> where(n, -1);
    for (int column = 0; column < n && rank < n; ++column) {
        int pivot = rank;
        while (pivot < n && a[pivot][column] == 0) { ++pivot; }
        if (pivot == n) { continue; }
        std::swap(a[rank], a[pivot]);
        int inverse = 1;
        while (a[rank][column] * inverse % 17 != 1) { ++inverse; }
        for (int j = 0; j <= n; ++j) {
            a[rank][j] = a[rank][j] * inverse % 17;
        }
        for (int row = 0; row < n; ++row) {
            if (row == rank) { continue; }
            int factor = a[row][column];
            for (int j = 0; j <= n; ++j) {
                a[row][j] = normalize(a[row][j] - factor * a[rank][j]);
            }
        }
        where[column] = rank++;
    }
    for (const auto& row : a) {
        bool zero = true;
        for (int j = 0; j < n; ++j) { zero = zero && row[j] == 0; }
        if (zero && row[n] != 0) {
            std::printf("NONE\n");
            return 0;
        }
    }
    if (rank < n) {
        std::printf("MANY\n");
    } else {
        for (int j = 0; j < n; ++j) {
            std::printf("%d%c", a[where[j]][n], j + 1 == n ? '\n' : ' ');
        }
    }
    return 0;
}
```

输入：

```text
2
1 1 3
1 16 1
```

输出：

```text
2 1
```

时间 `O(n³)`，空间 `O(n²)`。没有主元的列是自由变量；“没有唯一解”还要分无解与多解，不能混成一个失败标志。

## 浮点消元多了一种风险

实数消元通常选绝对值大的主元减小误差；近似零的阈值要与数据尺度、误差要求一起考虑。整数或模数上的精确秩，与浮点近似秩不是一回事。概率转移若有无法到达终点的封闭类，有限期望方程可能没有所需的有限解；先分析可达性，不是消元报出一串数就算完成。

反复松弛或迭代也须给收敛理由。`x=(x+2)/2` 会趋向 2，但“直到两次差很小”不是所有迭代都可靠：有的振荡，有的发散，有的因浮点舍入停在错误位置。最短路的有限轮界、概率过程的吸收条件、数值方法的误差界各自不同。

## 核对

1. 永不成功的平均完成时间不是有限数，不能在有限实数方程里硬解，更不能把矛盾当成零。
2. 原来多解；改成 7 后无解，第二行消去后成为 `0=1`。
3. 不能；相加得到 `x+y<=x+y-2`，产生矛盾，正对应负环。
