# 08　有些依赖会绕回来

三个同学约好排身高照相：甲说“我比乙高不超过 3 厘米”，乙说“我比丙高不超过 2 厘米”，丙说“我至少比甲高 1 厘米”。这几句话，每一句只说两个人，可是绕了一圈又回到了甲。它们能不能同时成立，单看哪一句都看不出来，要沿着这一圈把话串起来。

第二卷第 11 章《等前面的事做完再开始》里的依赖都是单向的，排好先后一个个算就行。这一章的依赖会绕成圈：一组变量互相约束，谁也不能先算。这一章没有 USACO 的题作例题，用的都是能手算的小例子。先看不等式和等式各怎样做；再看一般的等式组怎样一个个消掉未知量；最后看用小数做消元时多出来的风险。

## 不等式与等式，做法不同

每一条约束都形如 x[b] − x[a] ≤ c，叫**差分约束**。把每个变量当作一个点，这条约束画成一条从 a 到 b、长 c 的边。它和最短路的式子一模一样：从某个起点出发的最短路 dist 总满足 dist[b] ≤ dist[a] + c。所以只要最短路存在，dist 就是一组满足所有约束的解。

最短路什么时候不存在？有一圈边长加起来是负的。沿着这一圈把约束加起来，左边的变量一个个抵消成 0，右边是负数，得到 0 ≤ 负数，矛盾。反过来，没有负圈时最短路存在，约束就能同时满足。有负边，所以不能用只适合非负边的 Dijkstra，要用 Bellman-Ford：所有边一轮轮松弛，没有负圈时 n − 1 轮以内就不再变化；第 n 轮还在变，就有负圈。

还有一层意思：从 0 出发到 n − 1 的最短路，正好是 x[n − 1] − x[0] 能取到的最大值。路上每条边各给一个不等式，加起来就是 x[n − 1] − x[0] ≤ 路长，最短的那条路最紧；而 dist 本身这组解恰好取到它。

### 差分约束

n 个变量 x[0] 到 x[n − 1]（n 到 1000），m 条约束（m 到 2000），每条给出 a、b、c，表示 x[b] − x[a] ≤ c（|c| ≤ 10⁶）。约束互相矛盾时输出 NO；否则输出 x[n − 1] − x[0] 的最大值，没有上限时输出 INF。

样例输入：

```text
3 4
0 1 3
1 2 2
0 2 4
2 0 -1
```

样例输出：

```text
4
```

这道题没有 USACO 的出处，是为这一节设计的。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

struct Edge {
    int from;
    int to;
    long long length;
};

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d %d", &n, &m) != 2) {
        return 1;
    }
    // 约束 x[b] − x[a] ≤ c 成为一条从 a 到 b、长 c 的边
    std::vector<Edge> edges;
    for (int i = 0; i < m; ++i) {
        int a = 0;
        int b = 0;
        long long c = 0;
        if (std::scanf("%d %d %lld", &a, &b, &c) != 3) {
            return 1;
        }
        edges.push_back(Edge{a, b, c});
    }

    // 第一步：从一个连向所有点、边长为 0 的虚拟起点出发，看有没有负圈
    std::vector<long long> any(n, 0);
    bool changed = true;
    for (int round = 0; round < n && changed; ++round) {
        changed = false;
        for (const Edge& edge : edges) {
            if (any[edge.from] + edge.length < any[edge.to]) {
                any[edge.to] = any[edge.from] + edge.length;
                changed = true;
            }
        }
    }
    if (changed) {
        std::printf("NO\n");  // 第 n 轮还能变短，有负圈，约束互相矛盾
        return 0;
    }

    // 第二步：没有矛盾时，x[n − 1] − x[0] 最大就是从 0 到 n − 1 的最短路
    const long long unreached = 1LL << 60;
    std::vector<long long> dist(n, unreached);
    dist[0] = 0;
    for (int round = 0; round + 1 < n; ++round) {
        for (const Edge& edge : edges) {
            if (dist[edge.from] != unreached && dist[edge.from] + edge.length < dist[edge.to]) {
                dist[edge.to] = dist[edge.from] + edge.length;
            }
        }
    }
    if (dist[n - 1] == unreached) {
        std::printf("INF\n");  // 没有约束能拦住 x[n − 1] 往上涨
    } else {
        std::printf("%lld\n", dist[n - 1]);
    }
    return 0;
}
```

查矛盾时要从所有点同时出发：不连通的部分里也可能藏着负圈。办法是假想一个虚拟起点，向每个点连一条长 0 的边，这等于把所有 `any` 一开始都设成 0。`changed` 为假时提前结束，否则第 n 轮还在变，就是有负圈。第二步从 0 出发，到不了 n − 1 说明没有任何一串约束管着 x[n − 1] − x[0]，它想多大都行。

两步各至多 n 轮、每轮看 m 条边，O(nm)，n = 1000、m = 2000 时是两百万次。路长至多 1000 × 10⁶，用 `long long`。

慢程序用 Floyd 求出两两最短路：某个点到自己的最短路是负的就是 NO，否则看 0 到 n − 1。n 不超过 6、c 在 −3 到 6 之间、允许自环，对拍 300 组，答案全部相同。

样例的边是 0→1 长 3、1→2 长 2、0→2 长 4、2→0 长 −1。两个圈 0→2→0 长 3，0→1→2→0 长 4，都不是负的。0 到 2 的最短路是 4，所以 x[2] − x[0] 最多是 4。

约束要是等式 x[b] − x[a] = c，当然可以拆成两条不等式，但有更直接的做法：从一个点出发搜一遍（第二卷第 10 章），沿边把每个点的值推出来，碰到已经有值的点就核对一下，对不上就是矛盾。等式没有“松”的余地，推一遍就全定了，不必一轮轮松弛。

## 消掉一个未知量，再消掉下一个

一般的等式组，每个等式里有很多未知量，比如

x + 2y = 5，3x + y = 1。

这样的依赖也绕成了圈：x 要靠 y 算，y 又要靠 x 算。办法是消元：用一个等式把一个未知量表示出来，代进别的等式里，未知量少一个；一直做到只剩一个。写成表格，每个等式是一行，最右一列是常数，这叫增广矩阵。对第 j 列，挑一行这一列不为 0 的数，叫**主元**，把这一行乘一个数让主元变成 1，再从别的行里减去它的若干倍，让别的行这一列都变成 0。每一列做完，左边就成了对角线全是 1 的样子，最右一列就是解。这叫**高斯消元**，n 个未知量 O(n³)。

在整数里做除法会出分数。很多题要的是模一个质数 p 的答案，这时“除以 a”就是“乘以 a 的逆元”，p 是质数、a 不是 p 的倍数时，费马小定理说 a 的 p − 1 次方模 p 余 1，所以 a 的 p − 2 次方就是 a 的逆元。指数很大，就照第二卷第 7 章《把一大步拆成几小步》的想法，把指数拆成二进制一位位乘，这叫快速幂。

下面是**片段**。

```cpp
// 位于 main 内；a 是 n 行 n + 1 列的增广矩阵，元素都在 0 到 mod − 1 之间，mod 是质数
auto power = [mod](long long base, long long exponent) {
    long long result = 1;
    base %= mod;
    while (exponent > 0) {
        if (exponent & 1) {
            result = result * base % mod;
        }
        base = base * base % mod;
        exponent >>= 1;
    }
    return result;
};
bool unique = true;
for (int column = 0; column < n && unique; ++column) {
    int pivot = column;
    while (pivot < n && a[pivot][column] == 0) {
        ++pivot;
    }
    if (pivot == n) {
        unique = false;  // 这一列找不到不为 0 的数，解不唯一或无解
        break;
    }
    std::swap(a[pivot], a[column]);
    long long inverse = power(a[column][column], mod - 2);
    for (int k = column; k <= n; ++k) {
        a[column][k] = a[column][k] * inverse % mod;
    }
    for (int row = 0; row < n; ++row) {
        if (row == column || a[row][column] == 0) {
            continue;
        }
        long long factor = a[row][column];
        for (int k = column; k <= n; ++k) {
            a[row][k] = ((a[row][k] - factor * a[column][k]) % mod + mod) % mod;
        }
    }
}
// unique 为真时，第 i 个未知数是 a[i][n]
```

某一列在剩下的行里全是 0，说明这个未知量消不掉：要么有无穷多组解，要么无解，这里只报告“解不唯一或无解”。要分开这两种，就继续把能消的列都消完，看有没有一行左边全 0、右边不为 0。

在模 7 下跑上面的例子。第 0 列的主元是第 0 行的 1，第 1 行减去第 0 行的 3 倍：[3, 1, 1] − 3 × [1, 2, 5] = [0, −5, −14]，模 7 是 [0, 2, 0]。第 1 列的主元是 2，它的逆元是 4（2 × 4 = 8，模 7 余 1），乘完是 [0, 1, 0]。第 0 行减去它的 2 倍，得 [1, 0, 5]。所以 x = 5、y = 0：5 + 0 = 5，15 模 7 余 1，都对。

慢程序把模 p 下所有可能的取值都试一遍，恰好一组满足时输出它。p 取 2、3、5、7，至多 3 个未知量，对拍 300 组，输出全部相同。

## 浮点消元多了一种风险

不取模、用小数做消元时，片段里的“这一列不为 0”就要换掉：小数运算有误差，本该是 0 的数可能算成 10⁻¹⁵，判成“不为 0”，再拿它当除数，结果全乱。所以要和一个很小的正数比较，比如绝对值小于 10⁻⁹ 就当作 0。

还有一种风险更隐蔽：主元很小但不是 0。看方程组

0.0001x + y = 1，x + y = 2，

准确的解是 x ≈ 1.0001、y ≈ 0.9999。假设每次运算只保留 3 位有效数字。拿第一行的 0.0001 当主元，第二行要减去第一行的 10000 倍：y 的系数是 1 − 10000 = −9999，舍成 −1.00 × 10⁴；右边是 2 − 10000 = −9998，也舍成 −1.00 × 10⁴。于是 y = 1，代回第一行，x = (1 − 1) ÷ 0.0001 = 0。x 错得一塌糊涂。

换一个主元：先交换两行，拿 x + y = 2 里的 1 当主元，第一行减去它的 0.0001 倍：y 的系数是 1 − 0.0001，舍成 1.00；右边是 1 − 0.0002，舍成 1.00。于是 y = 1、x = 2 − 1 = 1，在 3 位有效数字下是对的。

道理是：除以一个很小的主元，会把这一行的误差放大很多倍，再减到别的行里去。所以每一列都在剩下的行里挑绝对值最大的那个当主元，这叫**列主元**。`double` 有十五六位有效数字，比这里的 3 位多得多，但只要系数大小悬殊，同样的事照样会发生。

**停笔 4**　照 3 位有效数字、不换主元，解 0.001x + y = 1、x + y = 3。x 算出来是几？换了主元呢？

这一章的完整程序 A 用 Bellman-Ford 判断差分约束是否矛盾，并求出两个变量之差的最大值；高斯消元的片段在模质数下一列列消掉未知量；浮点消元的例子说明了为什么要挑绝对值最大的主元。下一章《找出地图上不能轻易断的地方》回到图上，看哪些点和边一断，地图就分成了两半。

## 核对

1. 0→2→0 这一圈成了 4 + (−5) = −1，是负的：x[2] − x[0] ≤ 4 和 x[0] − x[2] ≤ −5 加起来是 0 ≤ −1。输出 NO。
2. 3。0 到 1 的路只有 0→1，长 3；绕道 0→2→0→1 更长。dist 这组解里 x[0] = 0、x[1] = 3、x[2] = 4，四条约束都满足：3 ≤ 3，1 ≤ 2，4 ≤ 4，−4 ≤ −1。
3. 在第 1 列停下。第 0 列主元是 2，逆元是 4，第 0 行乘 4 得 [1, 12, 4]，模 7 是 [1, 5, 4]；第 1 行减去它的 4 倍：[4, 6, 2] − 4 × [1, 5, 4] = [0, −14, −14]，模 7 是 [0, 0, 0]。第 1 列找不到不为 0 的数。第二个方程是第一个的 2 倍，等于没说，y 取 0 到 6 的任何一个，x 都能定下来，共 7 组解。
4. 不换主元：第二行减去第一行的 1000 倍，y 的系数 1 − 1000 = −999，舍成 −999；右边 3 − 1000 = −997，舍成 −997。y = −997 ÷ −999，舍成 0.998，x = (1 − 0.998) ÷ 0.001 = 2.00。换主元：第一行减去第二行的 0.001 倍，y 的系数 1 − 0.001 = 0.999；右边 1 − 0.003 = 0.997。y = 0.997 ÷ 0.999，舍成 0.998，x = 3 − 0.998 = 2.002，舍成 2.00。准确解是 x ≈ 2.002、y ≈ 0.998，这一回两种做法都还行，因为 0.001 没有小到让 1000 倍吞掉 1 和 3 这样的差别。
