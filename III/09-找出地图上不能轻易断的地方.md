# 09　找出地图上不能轻易断的地方

某座桥断了，整个区域就分开；另一些道路断了，还有绕路。判断“能不能绕过”，比反复删除每条边再搜索更有结构。

## 搜索树的回头路

DFS 首次访问时记 `tin[u]`。`low[u]` 表示从 u 的子树出发，沿树边向下，再用至多一条返回祖先的非树边，能到的最早访问时间。

对树边 `u→v`，若 `low[v] > tin[u]`，v 的整个子树找不到越过这条边的回路，因此是**桥**。回父亲时只跳过那条原边的编号，不能跳过所有“邻居等于父亲”的边，否则重边会被误判。

**完整程序：**输入 `0 <= n <= 2000`、`0 <= m <= 20000` 和 m 条无向边，按输入从 0 编边号。输出所有桥的编号，一行一个；没有输出 `NONE`。允许重边、自环及不连通图。

```cpp
#include <algorithm>
#include <cstdio>
#include <utility>
#include <vector>

void visit(int u, int parent_edge,
           const std::vector<std::vector<std::pair<int, int>>>& graph,
           std::vector<int>& tin, std::vector<int>& low,
           std::vector<int>& bridges, int& clock) {
    tin[u] = low[u] = ++clock;
    for (const auto& edge : graph[u]) {
        int v = edge.first;
        int id = edge.second;
        if (id == parent_edge) { continue; }
        if (tin[v] == 0) {
            visit(v, id, graph, tin, low, bridges, clock);
            low[u] = std::min(low[u], low[v]);
            if (low[v] > tin[u]) { bridges.emplace_back(id); }
        } else {
            low[u] = std::min(low[u], tin[v]);
        }
    }
}

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2 || n < 0 || n > 2000 || m < 0 || m > 20000) {
        return 1;
    }
    std::vector<std::vector<std::pair<int, int>>> graph(n);
    for (int id = 0; id < m; ++id) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= n || v < 0 || v >= n) {
            return 1;
        }
        graph[u].emplace_back(v, id);
        graph[v].emplace_back(u, id);
    }
    std::vector<int> tin(n, 0), low(n, 0), bridges;
    int clock = 0;
    for (int u = 0; u < n; ++u) {
        if (tin[u] == 0) { visit(u, -1, graph, tin, low, bridges, clock); }
    }
    std::sort(bridges.begin(), bridges.end());
    if (bridges.empty()) { std::printf("NONE\n"); }
    for (int id : bridges) { std::printf("%d\n", id); }
    return 0;
}
```

输入：

```text
4 4
0 1
1 2
2 0
2 3
```

输出：

```text
3
```

搜索部分 `O(n+m)`，排序输出另需 `O(b log b)`，b 为桥数。递归深度限于本页较小的 n；十万点长链应换显式调用帧，保留“进入、孩子返回”的两个阶段。

**停笔 1**　两个点之间有两条平行边，任一条是桥吗？删除所有桥后，每块内部有什么绕路保证？

## 断一个点，与断一条边不同

非根 u 若有孩子 v 满足 `low[v] >= tin[u]`，删除 u 后这支无法绕到上面，u 是割点。根须有至少两个 DFS 孩子才是割点。注意这里含等号，桥的条件不含。

把边放在栈里，遇到这样的分界就弹出直到树边 `(u,v)`，得到一个点双连通块。一个割点可属于多个块。每个块建一个“块节点”，连向它包含的原点，得到块割树，常称圆方树；孤立点也要保留。边双连通分量则先去桥再分块，缩点得到桥森林。两种分解不能混用。

仙人掌中每条边至多属于一个简单圈，块常是单边或单圈，圈内路径只剩两个方向可比，可在块树上处理。一般点双块可能复杂得多，不能当成一个圈。

## 单向地图怎样缩成无圈地图

有向图里互相可达的点组成强连通分量 SCC。Kosaraju 的两遍做法：在原图 DFS 记录完成顺序，再按逆完成顺序在反图搜索，每次得到一个 SCC。Tarjan 则用栈与低链接一遍完成。缩点后一定是 DAG：若块间还绕成圈，那些块本来就互相可达，应合成一个。

传递闭包记录任意两点是否可达，可以把 Floyd 的加法、取小换成逻辑与、或。DAG 可按逆拓扑序合并后继的位集。竞赛图是每对不同点间恰有一个方向的完全图；把新点插入现有有向路径的合适位置，总能得到经过所有点的有向哈密顿路径，但不保证有哈密顿圈。

## 每条边恰好走一次

欧拉路线关心边，不是点。无向连通非孤立部分有零或两个奇度点时存在；有向图则检查入出度差与相应连通条件。Hierholzer 用栈沿未用边走，到无路可走时弹出记答案，最后翻转。无向边两条邻接记录共享一个“已用”编号，否则会走两次。

**停笔 2**　两个三角形只共享一个点，没有桥，是否就没有割点？SCC 缩点能保证原图的每条边仍有独立端点吗？

**停笔 3**　一条三点链有几个奇度点，可否从中点出发走完每边一次而不停笔？有向图 `0→1→2` 有经过所有点的路径，是否就有圈？

## 核对

1. 都不是，另一条可绕过。去桥后的同块任意两点不因删除单条边而断开。
2. 共享点是割点。SCC 内部边会成为块内信息，不再是缩点 DAG 的跨块边。
3. 两个，必须从一端开始到另一端结束，不能从中点完成。路径不保证回到起点，无圈。
