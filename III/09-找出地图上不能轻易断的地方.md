# 09　找出地图上不能轻易断的地方

一座城被一条河分成两半，河上只有一座桥。这座桥一封，两岸就不通了；要是有两座桥，封掉哪一座都还能绕过去。城里的路口也一样：有的路口一堵，整片街区就进不去，有的路口堵了，绕一圈照样到。

这一章找图上的这种地方。先看深度优先搜索留下的那棵树和它的“回头路”；用它找出断一个点、断一条边就会把图分开的地方；再看单向的地图怎样把能互相到达的点缩成一个，变成没有圈的地图；最后看怎样把每条边恰好走一次。

## 搜索树的回头路

在无向图上做第二卷第 10 章的深度优先搜索，每走到一个新的点，就用一条边把它挂在树上。没用上的边，两头一定是一个祖先和一个后代：要是两头在不同的枝上，先搜到的那一头在搜完以前就会顺着这条边走到另一头，它就成了树边。这样的边叫**回边**，它是一条从后代回到祖先的回头路。

给每个点记两个数。`disc` 是它第一次被搜到的次序。`low` 是从它的子树里出发，走若干条树边往下，再走至多一条回边，能到达的最小的 `disc`。`low` 小，说明这棵子树有一条回头路通到很高的地方。

看一个例子：三角形 0-1-2，三角形 3-4-5，再用一条边 1-3 把它们连起来。从 0 开始，邻点按编号从小到大试。搜的次序是 0、1、2、3、4、5，`disc` 就是 0 到 5。2 有一条回边到 0，`low` 是 0；1 的子树里有 2，`low` 也是 0。5 有一条回边到 3，`low` 是 3；4 和 3 的 `low` 也都是 3。

这些数在点搜完时由孩子往上收：一个点的 `low` 是它自己的 `disc`、它的回边另一头的 `disc`、它每个孩子的 `low` 里最小的那个。图有十万个点时，递归可能太深，和下面的程序 A 一样，用一个手写的栈来搜。

## 断一个点，与断一条边不同

有了 `low`，就能说出哪里一断图就分开。

一条树边 u-v（v 是孩子），要是 `low[v] > disc[u]`，v 的子树里没有任何回头路能绕到 u 或更高的地方，断了这条边，子树就和外面断开了。这样的边叫**桥**。

一个不是根的点 u，要是有一个孩子 v 满足 `low[v] ≥ disc[u]`，v 的子树最高只能绕回到 u 本身，u 一去掉，这棵子树就断开了。这样的点叫**割点**。根是特例：它有两个以上的孩子才是割点，因为不同孩子的子树之间没有边，只能经过根。

两个条件只差一个等号，意思却不同。回到上面的例子：边 1-3，`low[3] = 3 > disc[1] = 1`，是桥；点 1 有孩子 3 满足 3 ≥ 1，是割点；点 3 有孩子 4，`low[4] = 3 ≥ disc[3] = 3`，也是割点；边 3-4 的 `low[4] = 3` 不大于 3，不是桥。三角形里的边断了一条，还能从另外两条绕过去。

断点和断边不能互相代替：去掉一个割点会同时去掉它的好几条边，所以有割点不一定有桥。不能被断一个点分开的一块，叫点双连通分量；不能被断一条边分开的一块，叫边双连通分量。

## 单向地图怎样缩成无圈地图

单向的地图里，两点能互相到达，就把它们看作一组。这样的一组叫**强连通分量**。每一组缩成一个点，组和组之间的边就不会绕成圈：要是绕成了圈，圈上的组都能互相到达，本该是同一组。缩完以后是一张没有圈的地图，第二卷第 11 章的做法都能用上。

找强连通分量的一种办法要搜两遍。第一遍在原图上深搜，记下每个点“搜完”的先后。第二遍在反图上（每条边掉个头）搜，按搜完的先后倒着取起点，每次能搜到的、还没分组的点，正好是一个强连通分量。理由的要点是：最后搜完的那个点所在的组，在缩完的图里没有边从别的组指进来；在反图上从它出发，就出不了这一组。把这一组去掉，剩下的照样成立。这叫 Kosaraju 算法，两遍都是 O(N + M)。

### 草场美食家

N 片草地、M 条单向的路（都到 10⁵）。贝茜从 1 号草地出发，最后要回到 1 号草地，一路吃草，同一片草地去几次都只算一次。她可以有一次逆着某条路走。问她最多能吃到几片草地。

输入第一行 N、M，接下来 M 行，每行 u、v，表示一条从 u 到 v 的路。输出一个整数。

样例输入：

```text
7 10
1 2
3 1
2 5
2 4
3 7
3 5
3 6
6 5
7 2
4 7
```

样例输出：

```text
6
```

路线 1 → 2 → 4 → 7 → 2 → 5，逆着 3 → 5 走到 3，再 3 → 1，吃到 1、2、4、7、5、3。这是 USACO 2015 年 1 月金组第三题[“草场美食家”](../USACO/金组/2014_2015/2015.01/P3.md)。

一个强连通分量里，进去了就能把每片草地都走一遍再出来，所以先缩点，每个分量记它有几片草地。不逆行时，从 1 号出发能回来的只有 1 号所在的那个分量。逆行一次，把路线分成两段：先从 1 号所在的分量顺着路走到某个分量 a，再逆着一条路从 a 到 b，最后从 b 顺着路走回来。

于是要两张表：从家出发，走到每个分量最多能经过几片草地；从每个分量出发，走回家最多能经过几片。缩完的图没有圈，两张表都是最长路，按拓扑序一个个推。两段路除了家以外不会经过同一个分量：要是都经过 X，就有家能到 X、X 也能到家，X 就是家所在的分量。所以两段相加，家只多算了一次，减掉就是答案。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d %d", &n, &m) != 2) {
        return 1;
    }
    std::vector<int> from(m, 0);
    std::vector<int> to(m, 0);
    std::vector<std::vector<int>> out(n);
    std::vector<std::vector<int>> in(n);
    for (int i = 0; i < m; ++i) {
        if (std::scanf("%d %d", &from[i], &to[i]) != 2) {
            return 1;
        }
        --from[i];
        --to[i];
        out[from[i]].push_back(to[i]);
        in[to[i]].push_back(from[i]);
    }

    // 第一遍：沿原图深搜，记下每个点搜完的先后
    std::vector<int> finished;
    std::vector<int> next_edge(n, 0);
    std::vector<bool> seen(n, false);
    for (int start = 0; start < n; ++start) {
        if (seen[start]) {
            continue;
        }
        std::vector<int> stack(1, start);
        seen[start] = true;
        while (!stack.empty()) {
            int v = stack.back();
            if (next_edge[v] < static_cast<int>(out[v].size())) {
                int w = out[v][next_edge[v]];
                ++next_edge[v];
                if (!seen[w]) {
                    seen[w] = true;
                    stack.push_back(w);
                }
            } else {
                finished.push_back(v);
                stack.pop_back();
            }
        }
    }

    // 第二遍：按搜完的先后倒着，沿反图搜，每次搜到的就是一个强连通分量
    std::vector<int> group(n, -1);
    int groups = 0;
    for (int i = n - 1; i >= 0; --i) {
        int start = finished[i];
        if (group[start] != -1) {
            continue;
        }
        std::vector<int> stack(1, start);
        group[start] = groups;
        while (!stack.empty()) {
            int v = stack.back();
            stack.pop_back();
            for (int w : in[v]) {
                if (group[w] == -1) {
                    group[w] = groups;
                    stack.push_back(w);
                }
            }
        }
        ++groups;
    }

    // 分量按编号就是缩点后的拓扑序：分量之间的边总从小编号指向大编号
    std::vector<int> size(groups, 0);
    for (int v = 0; v < n; ++v) {
        ++size[group[v]];
    }
    std::vector<std::vector<int>> forward(groups);
    for (int i = 0; i < m; ++i) {
        if (group[from[i]] != group[to[i]]) {
            forward[group[from[i]]].push_back(group[to[i]]);
        }
    }
    int home = group[0];
    // reach_from[c]：从 home 走到 c，一路最多经过几个点；−1 表示走不到
    std::vector<int> reach_from(groups, -1);
    reach_from[home] = size[home];
    for (int c = home; c < groups; ++c) {
        if (reach_from[c] < 0) {
            continue;
        }
        for (int d : forward[c]) {
            reach_from[d] = std::max(reach_from[d], reach_from[c] + size[d]);
        }
    }
    // reach_to[c]：从 c 走回 home，一路最多经过几个点
    std::vector<int> reach_to(groups, -1);
    reach_to[home] = size[home];
    for (int c = home; c >= 0; --c) {
        for (int d : forward[c]) {
            if (reach_to[d] >= 0) {
                reach_to[c] = std::max(reach_to[c], reach_to[d] + size[c]);
            }
        }
    }

    int best = size[home];
    for (int i = 0; i < m; ++i) {
        // 逆着走 from → to 这条边：先从 home 走到 to，逆行到 from，再走回 home
        int a = group[to[i]];
        int b = group[from[i]];
        if (reach_from[a] >= 0 && reach_to[b] >= 0) {
            best = std::max(best, reach_from[a] + reach_to[b] - size[home]);
        }
    }
    std::printf("%d\n", best);
    return 0;
}
```

第二遍按搜完的先后倒着取起点，找到的分量编号恰好是缩完以后的拓扑序：分量之间的边总是从小编号指向大编号。所以“从家出发”的表按编号从小到大推，“走回家”的表按编号从大到小推。走不到的分量记作 −1，不能拿来相加。

两遍深搜都用手写的栈，`next_edge` 记着每个点下一条该试哪条边；十万个点连成一条长链也不会出问题。整个程序 O(N + M)。

慢程序直接在“当前在哪片草地、逆行过没有、吃过哪些草地”这样的状态上搜遍所有可能，回到 1 号时记下吃到的片数。N 不超过 7，对拍 300 组，答案全部相同。

在样例上，2、4、7 绕成一圈，是一个分量，其余各自一组。从家 {1} 出发：到 {2, 4, 7} 经过 4 片，到 {5} 经过 5 片。从 {3} 走回家经过 2 片。逆着 3 → 5，5 + 2 − 1 = 6。

## 每条边恰好走一次

一笔画：在一张连通的无向图上，从某个点出发，每条边恰好走一次。走过一个中间的点，就是进来一次、出去一次，用掉它两条边。所以除了起点和终点，每个点的度数都得是偶数。全是偶数时能走一圈回到起点；恰好两个点是奇数时，能从其中一个走到另一个；奇数点更多就不行。这样的路叫**欧拉路**，回到起点的叫欧拉回路。

条件也够用，而且有一个直接的走法：从起点出发，随便沿着没走过的边走，走到走不动为止。度数都是偶数时，只会在起点走不动。要是还有边没走，路上一定有某个点还连着没走过的边，从它出发再走一圈回到它，把这一圈插进原来的路里。一直插到所有边都用完。用一个栈来做，每条边只看一次，O(M)，叫 Hierholzer 算法。

例子：两个三角形 0-1-2 和 0-3-4 共用 0。度数是 0 为 4，其余为 2，全是偶数。从 0 出发，先走 0-1-2-0，回到 0 走不动了吗？0 还连着 3 和 4，从 0 再走 0-3-4-0，插进去，得到 0-1-2-0-3-4-0。

这一章的完整程序 A 是“草场美食家”：Kosaraju 缩点以后，在没有圈的地图上从家往外、从外往家各求一次最长路。另外几节是手算的小例子：用 `disc` 和 `low` 认出桥和割点，用度数的奇偶判断一笔画。下一章《找不到搭档时让出一条路》讲配对：每个人至多一个搭档，怎样让配上的对数最多。

## 核对

1. 从 3 开始，次序是 3、1、0、2、4、5，`disc` 依次是 0、1、2、3、4、5（按点 3、1、0、2、4、5）。2 有回边到 1，`low[2] = 1`；0 的孩子是 2，`low[0] = 1`；1 的 `low` 是 1。5 有回边到 3，`low[5] = 0`，`low[4] = 0`，`low[3] = 0`。边 3-1 仍是桥：`low[1] = 1 > disc[3] = 0`。
2. 0 是割点，没有桥。从 0 开始搜，它有两个孩子 1 和 3，两个三角形之间只能经过 0。每条边都在一个三角形上，断了能从另外两条绕过去。
3. 逆着 6 → 5，是从 5 走到 6，接下来要从 6 走回家。可是 6 只有一条去 5 的路，5 哪儿也去不了，回不了家，程序里 `reach_to` 是 −1，这条边不算。逆着 1 → 2，是先从家走到 {2, 4, 7}，经过 4 片，再从 2 逆行到 1，已经在家：4 + 1 − 1 = 4 片，路线 1 → 2 → 4 → 7 → 2，再逆行回 1。
4. 能。度数变成 0 为 4、1 为 3、2 为 2、3 为 3、4 为 2，恰好 1 和 3 是奇数，从 1 起笔、在 3 收笔（或反过来）。例如 1-0-2-1-3-0-4-3，七条边各走一次。
