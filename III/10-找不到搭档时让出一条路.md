# 10　找不到搭档时让出一条路

几位同学与几项工作之间，有些配对可以、有些不可以。每人至多一项，每项至多一人。眼前配不成，不一定是真的没位置；可能需要请别人换个搭档。

## 沿着已配、未配交替走

从一个未配的左点出发，走一条未选边到右点。右点空着就成功；已配给别人，就尝试给那位左点找另一个右点。找到空位后，沿路把“选、未选”全部翻转，匹配数恰好加一。这条路叫**增广路**。

若更大的匹配存在，把它与当前匹配重叠比较，交替路径中必有一条比当前多一条边的增广路。因此找不到任何增广路时，才是最大匹配，不是每人贪心试一次就停。

**完整程序：**输入 `0 <= L,R <= 500`、`0 <= m <= 20000`，随后 m 条合法左右编号边，输出二分图最大匹配数。两边各自从 0 编号。

```cpp
#include <cstdio>
#include <vector>

bool augment(int u, const std::vector<std::vector<int>>& graph,
             std::vector<int>& owner, std::vector<char>& seen) {
    for (int v : graph[u]) {
        if (seen[v]) { continue; }
        seen[v] = 1;
        if (owner[v] == -1 || augment(owner[v], graph, owner, seen)) {
            owner[v] = u;
            return true;
        }
    }
    return false;
}

int main() {
    int left = 0;
    int right = 0;
    int m = 0;
    if (std::scanf("%d%d%d", &left, &right, &m) != 3 || left < 0 || left > 500
        || right < 0 || right > 500 || m < 0 || m > 20000) {
        return 1;
    }
    std::vector<std::vector<int>> graph(left);
    for (int i = 0; i < m; ++i) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= left || v < 0 || v >= right) {
            return 1;
        }
        graph[u].emplace_back(v);
    }
    std::vector<int> owner(right, -1);
    int answer = 0;
    for (int u = 0; u < left; ++u) {
        std::vector<char> seen(right, 0);
        if (augment(u, graph, owner, seen)) { ++answer; }
    }
    std::printf("%d\n", answer);
    return 0;
}
```

输入：

```text
2 2 3
0 0
0 1
1 0
```

输出：

```text
2
```

每次增广重置本轮访问表，最坏 `O(L*m+L*R)`，空间 `O(L+R+m)`，递归深度不超过左点数。更大图可用 Hopcroft–Karp：BFS 分层找最短增广距离，DFS 一轮增广一批互不冲突的路，通常写 `O(m*sqrt(L+R))`。

## 匹配背后还有一份覆盖证据

选若干点，使每条边至少有一个端点被选，叫点覆盖。最大二分匹配完成后，从所有未配左点沿“未选边向右、匹配边向左”走，得到可达左集 ZL、右集 ZR。取“未达左点加可达右点”，就是最小点覆盖，大小等于最大匹配数，这是 König 定理。

不在点覆盖里的点组成独立集，内部没有边，因此二分图最大独立集大小为总点数减最大匹配。一般图不能照搬这个公式。把 DAG 的每个点拆成左右两份，以原边连接，最大匹配可把路径段接起来；最小不相交顶点路径覆盖数为 `n-匹配数`。若题意允许用“可达关系”跨过其他点，要重新确定是否应先传递闭包。

## 有得分的配对，不能只数人数

二分图最大权完美匹配可以用 KM 算法。为左右点设顶标，使每边都有 `label[u]+label[v] >= weight[u,v]`；只在等号边找增广路。找不到时，用最小松弛量调整已搜索的两边顶标，仍不违反不等式，却让新边变成等号。完美匹配全用等号边时，权和等于顶标和，达到任何匹配都不可能超过的上界。

缺边、不等大两侧、允许不匹配的负权项，必须先按真实目标建模，不能一律补零就宣称仍是同一个问题。第 12 章的费用流可以直接表达许多这些约束。

## 奇圈使“左右”消失了

一般图的交替树中，若两个同为偶层的点由边相连，会形成一朵奇圈花。找它们在交替树的共同基点，将整个奇圈收缩成一个点，继续找增广路；找到后按进出花的位置展开，花内两条绕行方向恰有一条保持交替。这是 Edmonds 带花算法的核心。

三角形就是最小反例：它不是二分图，却有大小为 1 的匹配；不能硬分左右复制后把副本数当作一般图匹配数。最大权一般图还需要给奇集合维护对偶量，在紧边与花上同时调整，称加权带花；它不是“普通 KM 允许同侧边”。

边染色是给边分色，使同端点的边颜色不同。二分图可补成正则图、反复取完美匹配，每种颜色一份匹配，所需颜色恰为最大度 Δ。一般简单图需要 Δ 或 Δ+1 色；含重边时这个界不能直接照用。顶点染色、最大独立集和一般最小点覆盖则又是更困难的一组问题，别把“都有颜色”当作同一算法。
