# 11　给整张网络量一量瓶颈

几条管道从水源通向水池，每条管道有限流量。选一条最宽路线不够，多条路线可以一起运水；以前的安排也可能需要撤回。

## 撤回不是新增一条真实管道

每条有向边有容量，实际流量不超容量。除源汇外，流入等于流出。剩余网络中，正向边可再送 `容量-流量`，反向边允许撤回已送的流量。反向容量是算法记账，不等于题目真的有一条反管道。

从源到汇有剩余路径，就送路径最小剩余容量；没有时，源在剩余图中可达的点构成 S。跨出 S 的边已满，跨回的边无流，因此当前流量等于这个割的容量。任何流都不可能超过任意割，故这同时给出最优答案与证据：最大流等于最小割。

## 只沿着本轮的层向前

Dinic 先 BFS 给剩余图分层，再沿层数恰加一的边 DFS 送流，直到本层图没有可增广路，再重建层。当前弧指针记住已经试坏的边，不反复从邻接表开头查。

**完整程序：**输入 `2 <= n <= 200`、`0 <= m <= 2000`，随后有向边 `u v capacity`，端点合法、容量 0 到一百万。源为 0、汇为 `n-1`。允许重边和自环，输出最大流。

```cpp
#include <algorithm>
#include <cstdio>
#include <queue>
#include <vector>

struct Edge {
    int to;
    long long capacity;
};

class Network {
    std::vector<std::vector<int>> graph;
    std::vector<Edge> edges;
    std::vector<int> level;
    std::vector<int> next;
    bool build(int source, int sink) {
        std::fill(level.begin(), level.end(), -1);
        std::queue<int> waiting;
        level[source] = 0;
        waiting.emplace(source);
        while (!waiting.empty()) {
            int u = waiting.front();
            waiting.pop();
            for (int id : graph[u]) {
                const Edge& edge = edges[id];
                if (edge.capacity > 0 && level[edge.to] == -1) {
                    level[edge.to] = level[u] + 1;
                    waiting.emplace(edge.to);
                }
            }
        }
        return level[sink] != -1;
    }
    long long send(int u, int sink, long long amount) {
        if (u == sink) { return amount; }
        for (int& index = next[u]; index < static_cast<int>(graph[u].size()); ++index) {
            int id = graph[u][index];
            Edge& edge = edges[id];
            if (edge.capacity <= 0 || level[edge.to] != level[u] + 1) { continue; }
            long long sent = send(edge.to, sink, std::min(amount, edge.capacity));
            if (sent > 0) {
                edge.capacity -= sent;
                edges[id ^ 1].capacity += sent;
                return sent;
            }
        }
        return 0;
    }
public:
    explicit Network(int n) : graph(n), level(n), next(n) {}
    void add(int from, int to, long long capacity) {
        int id = static_cast<int>(edges.size());
        graph[from].emplace_back(id);
        edges.emplace_back(Edge{to, capacity});
        graph[to].emplace_back(id + 1);
        edges.emplace_back(Edge{from, 0});
    }
    long long max_flow(int source, int sink) {
        long long result = 0;
        while (build(source, sink)) {
            std::fill(next.begin(), next.end(), 0);
            while (long long sent = send(source, sink, 1000000000000000000LL)) {
                result += sent;
            }
        }
        return result;
    }
};

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2 || n < 2 || n > 200 || m < 0 || m > 2000) {
        return 1;
    }
    Network network(n);
    for (int i = 0; i < m; ++i) {
        int u = 0;
        int v = 0;
        int capacity = 0;
        if (std::scanf("%d%d%d", &u, &v, &capacity) != 3 || u < 0 || u >= n
            || v < 0 || v >= n || capacity < 0 || capacity > 1000000) {
            return 1;
        }
        network.add(u, v, capacity);
    }
    std::printf("%lld\n", network.max_flow(0, n - 1));
    return 0;
}
```

输入：

```text
4 5
0 1 3
0 2 2
1 2 1
1 3 2
2 3 3
```

输出：

```text
5
```

一般容量下的最坏时间界 `O(n²*m)`，空间 `O(n+m)`；特殊网络可以更好，不能把所有最大流都叫线性。容量为整数时，每次仍送整数，自然得到整数流。

## 边还要求至少送多少

有下界 l、上界 r 的边，先固定送 l，只在剩余边上留 `r-l` 容量。对每点记 `balance=固定流入-固定流出`。正 balance 点需额外流出，连超级源到它；负 balance 点需额外流入，连它到超级汇。所有超级源边都被送满，才有可行环流。

原题有源汇时，可加汇到源的足够大容量边变环流。这个“大”须由总需求算出能装下的界，不能用溢出的随意常量。若还要求最大流，先得到可行流，再移除辅助边、在原剩余网络增广；不能把超级源流量直接当原题答案。

## 没有指定源汇的割

无向全局最小割可用 Stoer–Wagner：每轮从一点开始，反复加入与已选集合连接权总和最大的未选点；最后加入的点给出本轮割，再与倒数第二点合并，保留最小割值。只有非负无向容量满足这套证明。

想回答任意两点最小割，可构造 Gomory–Hu 最小割树：初始都挂一个根，逐点与当前父亲做一次最小割，按割的两侧重接尚未处理的同父点，必要时交换父子并转移旧权。总共 `n-1` 次最大流。最终两点最小割值等于树路径最小边权；树边并不声称是原图道路。

## 核对

1. 正向 4、反向 3；丢掉改配、撤回旧安排的能力。
2. 可行流不能超过割，需查容量、守恒或割计算。下界已让点产生不平衡，必须补足守恒。
3. 净流出 4，超级源向该点连容量 4 的边。
