# 12　每次改配都算清代价

货物要送到目的地，管道有容量，走一单位还要付费用。流量相同的两份方案，价格可能不同。现在的反向边不只撤回容量，也要退回原来的费用。

## 最便宜的下一步，不是原图最便宜的边

正向费用 c，反向费用 −c。每次在剩余网络中找源汇最低费用路，沿路增广。若原来的零流没有负费用圈，最短增广保持“同流量下费用最小”：否则两份流之差可以拆成改配路径和圈，其中会出现还能进一步降低费用的剩余负圈，与当前最优矛盾。

没有源汇路只说明送不进去；存在负费用圈时，还可能原地循环改进费用。下面程序的契约明确排除初始负费用圈，不把不适用输入当成“偶尔慢一点”。

**完整程序：**输入 `2 <= n <= 60`、`0 <= m <= 1000`、需求 `0 <= need <= 10000`。每条有向边给 `u v capacity cost`，容量 0 到 100，单位费用 −1000 到 1000，初始网络没有负费用圈。输出恰好送 need 单位的最低费用，做不到输出 `IMPOSSIBLE`。

```cpp
#include <algorithm>
#include <cstdio>
#include <limits>
#include <vector>

struct Edge {
    int from;
    int to;
    int capacity;
    int cost;
};

int main() {
    int n = 0;
    int m = 0;
    int need = 0;
    if (std::scanf("%d%d%d", &n, &m, &need) != 3 || n < 2 || n > 60
        || m < 0 || m > 1000 || need < 0 || need > 10000) {
        return 1;
    }
    std::vector<Edge> edges;
    edges.reserve(2 * m);
    for (int i = 0; i < m; ++i) {
        int u = 0;
        int v = 0;
        int capacity = 0;
        int cost = 0;
        if (std::scanf("%d%d%d%d", &u, &v, &capacity, &cost) != 4 || u < 0 || u >= n
            || v < 0 || v >= n || capacity < 0 || capacity > 100 || cost < -1000 || cost > 1000) {
            return 1;
        }
        edges.emplace_back(Edge{u, v, capacity, cost});
        edges.emplace_back(Edge{v, u, 0, -cost});
    }
    const long long infinity = std::numeric_limits<long long>::max() / 4;
    int flow = 0;
    long long total = 0;
    while (flow < need) {
        std::vector<long long> distance(n, infinity);
        std::vector<int> previous(n, -1);
        distance[0] = 0;
        for (int round = 1; round < n; ++round) {
            bool changed = false;
            for (int id = 0; id < static_cast<int>(edges.size()); ++id) {
                const Edge& edge = edges[id];
                if (edge.capacity > 0 && distance[edge.from] != infinity
                    && distance[edge.to] > distance[edge.from] + edge.cost) {
                    distance[edge.to] = distance[edge.from] + edge.cost;
                    previous[edge.to] = id;
                    changed = true;
                }
            }
            if (!changed) { break; }
        }
        if (previous[n - 1] == -1) { break; }
        int amount = need - flow;
        for (int v = n - 1; v != 0; v = edges[previous[v]].from) {
            amount = std::min(amount, edges[previous[v]].capacity);
        }
        for (int v = n - 1; v != 0; v = edges[previous[v]].from) {
            int id = previous[v];
            edges[id].capacity -= amount;
            edges[id ^ 1].capacity += amount;
        }
        flow += amount;
        total += distance[n - 1] * amount;
    }
    if (flow != need) { std::printf("IMPOSSIBLE\n"); }
    else { std::printf("%lld\n", total); }
    return 0;
}
```

输入：

```text
3 3 2
0 1 2 1
1 2 2 2
0 2 1 8
```

输出：

```text
6
```

每次 Bellman–Ford `O(nm)`，至多 need 次增广，最坏 `O(need*n*m)`；一次可能送很多单位，但不能保证轮数与需求无关。空间 `O(n+m)`。

## 用势能让负边换一种表示

点势能 h 给边换费用 `c+h[u]-h[v]`。任何源汇路的费用都统一加 `h[source]-h[sink]`，所以最短路不变。若势能令所有可用边的新费用非负，就可用 Dijkstra；每轮用最短距离更新势能，维护这个不变量。

初始有负边时，不能直接把全零势能交给 Dijkstra。先求合法初势能，或利用图原本是 DAG 的次序求最短路。势能避免的是重复慢搜索，不是删除负边。

## 有时不必真的建整张网络

例如依次安排买入卖出，容量与时间构成链。某个“把一个旧安排换成新安排”的反向路，可能只对应堆里的一次替换。把真实流网络的增广过程压成堆或有序表，叫模拟费用流；正确性要由“压缩前后哪些可行改配相同”给出，不能看见优先队列就贴这个名称。

费用流也是线性规划的特殊形式：变量是每边流量，约束是容量与守恒，目标是费用线性和。整数容量下能得到整数最优流，来自这类约束的特殊结构；一般线性规划允许小数解，不能随意四舍五入成合法整数方案。第 25 章再从可行区域认识它。

## 核对

1. −5，退回费用。需先撤销旧搭档、再换新搭档的路径会被挡住。
2. 不是统一加边常数，中间点势能一正一负抵消，整条路只剩源减汇。
3. 本契约下为 0。有负费用圈时可在不改变源汇净流的情况下绕圈降费，零也未必最优。
