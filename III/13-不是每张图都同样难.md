# 13　不是每张图都同样难

学校排期中考试的监考。每场考试占一段时间，两场时间有重叠，就不能派同一位老师。教务处问：最少要几位老师？要是把“不能同一人”画成一张图，点是考试，边连着冲突的两场，问题就成了“给点上色，相邻的点颜色不同，最少几种颜色”。对任意一张图，这个问题至今没有已知的快办法。可是考试是时间轴上的一段段区间，这张图有自己的形状，问题立刻变得容易。

这一章看几种这样的图：区间排成的图、能被一串小“袋子”装下的图、画在纸上边不交叉的图。要练的是：遇到一张图，先问它是不是一般的图。

## 先看一排区间怎样相交

每个点代表一段区间，两段相交就连边，这样的图叫**区间图**。监考问题里，考试 [1, 4)、[2, 6)、[3, 5)、[5, 8)、[7, 9)（时间从 1 点钟算起，左闭右开）。

先找一个下界。时刻 3.5 被 [1, 4)、[2, 6)、[3, 5) 三场同时盖住，这三场两两冲突，至少要三种颜色。一般地，同一时刻被盖住的场数，记为最大重叠数 d，颜色数至少是 d。

再看能不能用 d 种颜色做到。按左端点从早到晚处理每场考试，给它配一个当前空着的、编号最小的老师。假如某场考试拿到了第 k 号老师，那么 1 到 k − 1 号老师在它开始的时刻都在监考别的场次；那些场次的左端点更早，又还没结束，于是它们和这一场一起盖住了这一场的开始时刻，共 k 场。所以 k ≤ d。用到的老师数不超过 d，又不少于 d，恰好是 d。

d 本身也好求：把 2n 个端点从早到晚排好，遇到左端点加 1，遇到右端点减 1，过程中最大的数就是 d。时间相同时先处理右端点，因为区间是左闭右开，[1, 4) 和 [4, 6) 在时刻 4 并不重叠。

一般的图上，“至少要几种颜色”和“最多几个点两两相邻”可以差得很远；区间图上两者相等，而且贪心一遍就能得到。同样，在区间图上挑最多的两两不相交的区间，就是[第二卷第 9 章](../II/09-眼前的选择凭什么放心.md)里按最早结束挑的那个贪心。

**停笔 1**　对上面五场考试，按左端点顺序逐场写出分到几号老师。哪一时刻同时有三场？如果改成按右端点从早到晚处理，同样分配最小编号，试一试 [4, 5)、[4, 7)、[7, 8)、[6, 9)：要几位老师？最大重叠数又是几？

## 每次只忘掉一个边界点

另一类图不是区间画出来的，却可以“一小段一小段地看”。先看一个具体问题：一张 R 行 C 列的方格表，每格有一个非负整数的分数。选出一些格子，任意两个被选的格子不能共边，问分数和最大是多少。

对一般的图，“选出两两不相邻的点使总分最大”同样没有已知的快办法。方格表的特别之处在于它很窄：按列从左到右、列内从上到下一格格处理，任何时候，已处理的格子里还会和后面的格子相邻的，只有每一行最近处理过的那一格，至多 R 个。把这 R 个格子叫作当前的**边界**。后面的格子是否能选，只取决于边界上谁被选了，和更早的格子无关。

于是表格的状态就是边界上每格选或不选，用 R 位二进制数 `mask` 表示，第 r 位是第 r 行最近一格的选择（位运算见[第二卷第 2 章](../II/02-把选择走成一棵树.md)）。处理格子 (r, c) 时，它的左邻居是边界上第 r 位，上邻居是第 r − 1 位（已经换成本列的格子）。处理完以后，第 r 位换成这一格：原来那一格从此不会再和谁相邻，被“忘掉”了。每一步加进一个点、忘掉一个点，边界始终不超过 R 个。

输入第一行 R 和 C（1 ≤ R ≤ 10，1 ≤ C ≤ 1000），接着 R 行，每行 C 个分数（0 到 10⁶）。输出最大分数和。

样例输入：

```text
2 3
1 5 2
4 2 3
```

样例输出：

```text
12
```

选第 1 行的 5、第 2 行的 4 和 3：它们两两只在斜角相对，没有共边，和是 12。想要左上的 1，就得放弃 5 和 4；想要第 2 行中间的 2，就得放弃 5、4、3 中的三个，换来的都更少。这是本章自编的例子。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int rows = 0;
    int cols = 0;
    if (std::scanf("%d%d", &rows, &cols) != 2) {
        return 1;
    }
    std::vector<std::vector<long long>> score(rows, std::vector<long long>(cols, 0));
    for (int r = 0; r < rows; ++r) {
        for (int c = 0; c < cols; ++c) {
            if (std::scanf("%lld", &score[r][c]) != 1) {
                return 1;
            }
        }
    }
    const long long impossible = -1;
    int states = 1 << rows;
    // best[mask]：已处理的格子里，边界的选择恰为 mask 时的最大分数
    std::vector<long long> best(states, impossible);
    best[0] = 0;
    for (int c = 0; c < cols; ++c) {
        for (int r = 0; r < rows; ++r) {
            std::vector<long long> next(states, impossible);
            for (int mask = 0; mask < states; ++mask) {
                if (best[mask] == impossible) {
                    continue;
                }
                bool left_taken = ((mask >> r) & 1) == 1;
                bool up_taken = r > 0 && ((mask >> (r - 1)) & 1) == 1;
                int forget = left_taken ? mask - (1 << r) : mask;   // 第 r 行的旧格子不再有用
                next[forget] = std::max(next[forget], best[mask]);
                if (!left_taken && !up_taken) {
                    int taken = forget + (1 << r);
                    next[taken] = std::max(next[taken], best[mask] + score[r][c]);
                }
            }
            best = next;
        }
    }
    long long answer = 0;
    for (int mask = 0; mask < states; ++mask) {
        answer = std::max(answer, best[mask]);
    }
    std::printf("%lld\n", answer);
    return 0;
}
```

一开始还没有格子，把边界看成 R 个“没选的空位”，所以只有 `best[0]` 是 0。第 0 列的格子查“左邻居”时查到的就是这些空位，不会被误挡。每格要看 2^R 种边界，一共 R × C × 2^R 步，R = 10、C = 1000 时约一千万步。分数和最多 10⁴ × 10⁶，要用 `long long`。

对拍的慢办法把 R × C ≤ 16 的方格表的全部选法列出来，逐个检查是否有两格共边。它不知道边界，也不知道“忘掉”。

把这件事说成一般的话：给一张图准备一串**袋子**，每个袋子装一些点，要求每条边的两端至少同在一个袋子里，而且含同一个点的袋子在串里是连续的一段。方格表的袋子就是“边界加上正在处理的格子”。这样一串袋子叫**路径分解**；把“一串”放宽成“一棵树”，就是**树分解**。最大的袋子装的点数减 1，叫这份分解的**宽度**；一张图所有树分解里最小的宽度，叫它的**树宽**。沿着分解做表，表的大小只按袋子大小的指数增长，和图的总点数成正比。

**停笔 2**　对样例，写出处理完第 1 列两格后 `best` 的四个值（`mask` = 0、1、2、3）。

## 有些图自己带着合适的袋子

求一般图的最小树宽本身就难。好在很多图天生带着一份窄的分解，用不着去找。

树的树宽是 1：每条边做一个袋子，相邻的边共用中间那个点。所以[第二卷第 14 章](../II/14-没有圈的地图多了什么.md)里的树上表格，正是袋子大小为 2 的情形。一个圈多一点：圈上的点 0、1、……、n − 1，袋子取 {0, i, i + 1}，i 从 1 到 n − 2，点 0 留在每个袋子里，宽度是 2。做表时就是先决定点 0 选不选，再沿着链往下走，最后检查 n − 1 和 0。方格表的宽度不超过行数 R。

反过来，同样 100 个点，一张每两点都连边的图，任何分解都得有一个袋子装下全部 100 个点。图的点数一样，形状不一样，难度可以差得天上地下。

下面是**片段**，求圈上两两不相邻的点的最大分数和。

```cpp
// 位于 main 内；value[0] 到 value[n - 1] 是圈上各点的分数，n >= 3
const long long impossible = -1;
long long answer = 0;
for (int first = 0; first < 2; ++first) {           // first：点 0 选不选
    // chosen / skipped：处理到当前点，当前点选了 / 没选时的最大和
    long long chosen = first == 1 ? value[0] : impossible;
    long long skipped = first == 1 ? impossible : 0;
    for (int i = 1; i < n; ++i) {
        long long take = skipped == impossible ? impossible : skipped + value[i];
        if (i == n - 1 && first == 1) {
            take = impossible;                       // 点 n − 1 与点 0 相邻
        }
        skipped = std::max(chosen, skipped);
        chosen = take;
    }
    answer = std::max(answer, std::max(chosen, skipped));
}
std::printf("%lld\n", answer);
```

`first` 这一个数，就是“点 0 留在每个袋子里”：整条链走完，最后一步还要回头看它。

**停笔 3**　五个点围成一圈，分数依次是 3、1、4、1、5（第 5 个点和第 1 个相邻）。用“先定点 0 选不选”的办法，求两两不相邻的点的最大分数和。

找一份最窄的分解难，检查别人给的一份分解却容易：逐条边看两端是否同在某个袋子里，逐个点看含它的袋子是否连成一段。

## 平面上不交叉，换来另一张图

把一张图画在纸上，边与边只在端点相遇，这样的图叫**平面图**。画好以后，边把纸分成若干块，每块叫一个**面**，外面那块无限大的也算一个。设有 V 个点、E 条边、C 个连通的部分、F 个面，则

V − E + F = 1 + C。

这叫**欧拉公式**。对边数归纳：没有边时，F = 1，C = V，两边都是 V + 1。去掉一条边：它若在某个圈上，两侧原是两个面，合成一个，E 与 F 各少 1；它若不在任何圈上，两侧是同一个面，去掉它使一个部分断成两个，E 少 1、C 多 1。两种情况等式都保持。

例子：一个正方形画上两条对角线，交点也算一个点。点是四个角加中心，V = 5；边是四条边加四段半对角线，E = 8；C = 1。F = 1 + C − V + E = 5：四个小三角形加外面一块。

这条公式的用处在于：面不好直接数，点和边好数。题目问“分成几块区域”，常常可以先算出交点和被切开的线段有几条，再用公式换出面数。每个面还对应另一张图的一个点（相邻的面连边），这张图叫原图的**对偶图**；“一块区域有几个连通的同色块”一类问题，就可以在点、边、面之间换着数。

**停笔 5**　在上面那个正方形的旁边，再画一个分开的三角形。新的 V、E、C、F 各是几？用公式算出 F，再直接数一遍。

## 核对

1. 按左端点：[1, 4) 用 1 号，[2, 6) 用 2 号，[3, 5) 用 3 号，[5, 8) 时 1 号和 3 号都空了，用 1 号，[7, 9) 时 3 号空着、2 号也空着，用 2 号。3.5 时有三场。按右端点处理：[4, 5) 用 1 号，[4, 7) 用 2 号，[7, 8) 和它们都不冲突，用 1 号，[6, 9) 和 2 号、1 号都冲突，只好用 3 号。最大重叠数却只有 2。按右端点排序时，“前面的 k − 1 位老师都盖住我的开始时刻”这句话不成立。
2. 第 1 列：第 1 行分数 1，第 2 行分数 4，上下相邻。`best[0]` = 0（都不选），`best[1]` = 1（只选上），`best[2]` = 4（只选下），`best[3]` 不可能，仍是 −1。
3. 点 0 选：点 1、点 4 不能选，剩 2、3 中选一个，最多 4，共 3 + 4 = 7。点 0 不选：在 1、2、3、4 这条链上选，分数 1、4、1、5，最多 4 + 5 = 9。答案 9。
4. 不是。边 4–0 的两端不同在任何一个袋子里。宽度为 2 的一份：{0, 1, 2}、{0, 2, 3}、{0, 3, 4}，点 0 在三个袋子里都有，含点 2、点 3 的袋子各自也是连续的。
5. V = 8，E = 11，C = 2，F = 1 + 2 − 8 + 11 = 6。直接数：四个小三角形、三角形内部一块、外面一块，共 6。
