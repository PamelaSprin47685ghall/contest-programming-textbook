# 14　把所有开头排在一起

图书角要给一本书做索引。老师把书里的每一句话从每个字开始各抄一张卡片，再把卡片按字典顺序排好。以后想查某个词出现在哪里，只要在排好的卡片里二分，开头是这个词的卡片挨在一起。可是一句一百字的话要抄一百张卡片，每张平均五十个字，太费纸了。其实不用抄：每张卡片只要记“从第几个字开始”，比较时回原句去看。

这一章就做这件事：把一个串的所有后缀按字典序排好，但只排它们的开头位置；再看排好以后，相邻两个后缀共有多长的开头，以及它能回答哪些问题。

## 排的是位置，不是复印所有后缀

长度为 n 的串 s，从位置 i 开始到末尾的那一段叫**后缀** i，位置从 0 编号。把 n 个后缀按字典序排好，记下它们的开头位置，得到的那一排数叫**后缀数组**。

以 `banana` 为例，六个后缀是：0 `banana`、1 `anana`、2 `nana`、3 `ana`、4 `na`、5 `a`。按字典序排：`a`、`ana`、`anana`、`banana`、`na`、`nana`，后缀数组是 5 3 1 0 4 2。

照字面做，把 n 个后缀复制出来再排序：复制要 n²/2 个字符，比较一次又可能要 n 步。n 到 20 万时两样都不行。

办法是一次比较多看一倍。先只按每个后缀的第 1 个字符排好，给每个位置一个**名次**：开头相同的名次相同。知道了“前 k 个字符”的名次以后，“前 2k 个字符”的比较可以只看两个数：先比位置 i 的前 k 个字符的名次，相同再比位置 i + k 的前 k 个字符的名次；i + k 越出末尾，就当它最小，因为短的串排在以它为开头的长串前面。两个数比一次就行，不用逐字看。这样排一遍，就得到前 2k 个字符的名次。

`banana` 上走一遍。k = 1 时按（第 1 个字符，第 2 个字符）排：5 是（a，空），1 和 3 都是（a，n），0 是（b，a），2 和 4 都是（n，a）。名次依次是：位置 5 为 0，位置 1、3 为 1，位置 0 为 2，位置 2、4 为 3。k = 2 时按（前 2 个的名次，位置 i + 2 的名次）排：5 是（0，空），3 是（1，0），1 是（1，1），0 是（2，3），4 是（3，空），2 是（3，3）。六个都不同，排完了。

k 每轮翻倍，名次全都不同时停下，至多约 log n 轮。每轮用 `std::sort` 是 O(n log n)，一共 O(n log² n)。

## 同一个结构能回答哪些问题

排好以后，还要一样东西：后缀数组里相邻两个后缀的**最长公共前缀**长度，叫 **LCP 数组**。`banana` 排好的六个后缀里，`a` 与 `ana` 共有 1 个字符，`ana` 与 `anana` 共有 3 个，`anana` 与 `banana` 是 0，`banana` 与 `na` 是 0，`na` 与 `nana` 是 2。

LCP 数组可以在 O(n) 时间里求出，靠的是一个不等式。设后缀 i 在排好的序列里的前一个是后缀 j，二者共有 h 个字符，h > 0。去掉两个后缀的首字符，后缀 i + 1 和后缀 j + 1 共有 h − 1 个字符，并且后缀 j + 1 仍排在后缀 i + 1 的前面。后缀 i + 1 和它真正的前一个之间，夹着的后缀开头都和它至少共有这 h − 1 个字符，所以它的 LCP 至少是 h − 1。于是按原位置 0、1、2、…… 的次序求，每次从上一个 h 减 1 开始往后比。h 一共只减 n 次，又不超过 n，所以总共往后比的次数不超过 2n。

有了这两排数，能回答的问题很多。

一个子串，就是某个后缀的一个开头。所有后缀的开头加起来有 n(n + 1)/2 个，排好以后，相邻两个后缀共有的 h 个开头被重复数了，所以**不同子串的个数**是 n(n + 1)/2 减去 LCP 数组的和。`banana` 是 21 − 6 = 15。

任意两个后缀的最长公共前缀，是后缀数组里夹在它们之间的 LCP 的最小值。出现至少两次的最长子串，就是 LCP 的最大值。查一个词出现在哪些位置，在后缀数组上二分，开头是它的后缀排成连续的一段。

输入一个小写字母串，长度 1 到 2 × 10⁵。输出三行：后缀数组；LCP 数组，第一个数写 0；不同子串的个数。

样例输入：

```text
banana
```

样例输出：

```text
5 3 1 0 4 2
0 1 3 0 0 2
15
```

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <string>
#include <vector>

char buffer[200001];

int main() {
    if (std::scanf("%200000s", buffer) != 1) {
        return 1;
    }
    std::string s = buffer;
    int n = static_cast<int>(s.size());
    std::vector<int> order(n);
    std::vector<int> rank_now(n);
    std::vector<int> rank_next(n);
    for (int i = 0; i < n; ++i) {
        order[i] = i;
        rank_now[i] = s[i] - 'a';
    }
    for (int k = 1; ; k *= 2) {
        // 按“前 k 个字符的名次，再往后 k 个字符的名次”比较；越出末尾的记 -1
        auto before = [&](int a, int b) {
            if (rank_now[a] != rank_now[b]) {
                return rank_now[a] < rank_now[b];
            }
            int second_a = a + k < n ? rank_now[a + k] : -1;
            int second_b = b + k < n ? rank_now[b + k] : -1;
            return second_a < second_b;
        };
        std::sort(order.begin(), order.end(), before);
        rank_next[order[0]] = 0;
        for (int i = 1; i < n; ++i) {
            int step = before(order[i - 1], order[i]) ? 1 : 0;
            rank_next[order[i]] = rank_next[order[i - 1]] + step;
        }
        rank_now = rank_next;
        if (rank_now[order[n - 1]] == n - 1 || k >= n) {
            break;
        }
    }
    // lcp[r]：排在第 r 位与第 r - 1 位的两个后缀共有多长的开头
    std::vector<int> lcp(n, 0);
    int h = 0;
    for (int i = 0; i < n; ++i) {
        int r = rank_now[i];
        if (r == 0) {
            h = 0;
            continue;
        }
        int j = order[r - 1];
        while (i + h < n && j + h < n && s[i + h] == s[j + h]) {
            ++h;
        }
        lcp[r] = h;
        if (h > 0) {
            --h;   // 下一个位置至少还共有 h - 1 个字符
        }
    }
    long long distinct = static_cast<long long>(n) * (n + 1) / 2;
    for (int r = 0; r < n; ++r) {
        distinct -= lcp[r];
    }
    for (int r = 0; r < n; ++r) {
        std::printf("%d%c", order[r], r + 1 < n ? ' ' : '\n');
    }
    for (int r = 0; r < n; ++r) {
        std::printf("%d%c", lcp[r], r + 1 < n ? ' ' : '\n');
    }
    std::printf("%lld\n", distinct);
    return 0;
}
```

`before` 是[第一卷第 19 章](../I/19-把行为当作数据.md)的 lambda，按引用捕获了 `rank_now`、`k`、`n`；每轮 `k` 变了，就重新造一个。它是严格的“排在前面”，同名次时两边都返回假，`std::sort` 要求的正是这种比较。新名次在排好的序列里逐个比较：前一个严格在前，名次加 1，否则不变。

排在第 0 位的后缀前面没有后缀，这时 h 清成 0。清零不影响 2n 的界：它只会让后面多比几次，而每个位置往后比到不同为止，h 增加的总次数仍然被 n 加上减少的总次数限制住。n = 2 × 10⁵ 时 n(n + 1)/2 约 2 × 10¹⁰，超过 `int`，所以用 `long long`。

对拍的慢办法把所有后缀复制出来排序，所有子串放进第一卷第 17 章的 `std::set` 数个数，只适合长度十几的串。

查一个词出现几次，是在后缀数组上做两次[第二卷第 5 章](../II/05-每次划掉一半候选.md)的二分。拿后缀的前 |P| 个字符和词 P 比，结果只有“小于”“等于”“大于”三种，而且沿着排好的序列，先是一段“小于”，再是一段“等于”，最后一段“大于”。“等于”那一段的长度就是出现次数。

下面是**片段**。

```cpp
// 位于 main 外：后缀 start 的前 pattern.size() 个字符与 pattern 比，返回 -1、0、1
int compare_prefix(const std::string& s, int start, const std::string& pattern) {
    for (std::size_t t = 0; t < pattern.size(); ++t) {
        std::size_t at = static_cast<std::size_t>(start) + t;
        if (at >= s.size()) {
            return -1;   // 后缀先用完，它排在前面
        }
        if (s[at] != pattern[t]) {
            return s[at] < pattern[t] ? -1 : 1;
        }
    }
    return 0;
}

// 位于 main 内；order 已照程序 A 排好
auto first_at_least = [&](int want) {   // 第一个比较结果不小于 want 的名次
    int low = 0;
    int high = n;
    while (low < high) {
        int mid = (low + high) / 2;
        if (compare_prefix(s, order[mid], pattern) >= want) {
            high = mid;
        } else {
            low = mid + 1;
        }
    }
    return low;
};
int count = first_at_least(1) - first_at_least(0);
std::printf("%d\n", count);
```

两次二分各比较 log n 次，每次至多看 |P| 个字符。

## 周期、重复段与最小的开头

一个串的**周期**是一个正整数 p：对所有 i，只要 i + p < n，就有 s[i] = s[i + p]。`abcabcab` 有周期 3、6、8。p 是周期，等于说长度 n − p 的前缀和长度 n − p 的后缀相同。这样又是前缀又是后缀的段，[第二卷第 18 章](../II/18-找文字时别总是退回开头.md)的失败函数正好记着最长的那一个，所以最小周期是 n 减去整个串的最长这种段。最小周期 p 能整除 n 时，整个串是同一段重复 n/p 次，例如 `abab` 是 `ab` 重复 2 次。

另一个常问的是：把串首尾相接成一个圈，从哪里剪开，得到的串字典序最小？这叫**最小表示**。可以把 s 接成 s + s，求它的后缀数组；也有一个更短的办法，同时看两个候选起点 i 和 j。

从 i、j 开始逐字比较，前 k 个相同，第 k 个不同，假设 i 那边的字符大。那么对每个 0 ≤ t ≤ k，从 i + t 剪开都比从 j + t 剪开大：前 k − t 个字符相同，下一个字符 i 那边大。所以 i 到 i + k 都不可能是答案，i 直接跳到 i + k + 1。每次比较失败，i 或 j 至少前进 k + 1，比较的总次数不超过约 3n。

**片段：**

```cpp
// 位于 main 内；s 是长度为 n 的串
int i = 0;
int j = 1;
int k = 0;
while (i < n && j < n && k < n) {
    char from_i = s[(i + k) % n];
    char from_j = s[(j + k) % n];
    if (from_i == from_j) {
        ++k;
        continue;
    }
    if (from_i > from_j) {
        i = i + k + 1;
    } else {
        j = j + k + 1;
    }
    if (i == j) {
        ++j;   // 两个候选不能是同一个起点
    }
    k = 0;
}
int start = std::min(i, j);
std::printf("%d\n", start);
```

k 一直加到 n，说明两个起点剪出的串完全一样，串本身有周期，再比也没有用，停下来。这时两个起点都是答案，取较小的。

这一章只做了一件事：不复印后缀，只把开头位置排好。名次倍增让一次比较看完 2k 个字符；LCP 数组用“每次至多少一”的不等式在线性时间里求出；有了它们，不同子串、重复子串、两个后缀的公共前缀都能直接读出来。周期和最小表示是另外两种“看开头”的问题，也只需要一点证明。能对一个短串手写出后缀数组和 LCP，说清为什么不同子串要减去 LCP 的和，再读下一章。下一章看另外两种不白走的办法：镜子一样对称的回文，和很多模式一起的失败路线。

## 核对

1. 后缀是 0 `abab`、1 `bab`、2 `ab`、3 `b`。排好是 `ab`、`abab`、`b`、`bab`，后缀数组 2 0 3 1，LCP 数组 0 2 0 1，不同子串 10 − 3 = 7：`a`、`b`、`ab`、`ba`、`aba`、`bab`、`abab`。
2. 第一轮按“名次全 0”排，第二个关键字也都是 0 或 −1，排出来几乎是任意次序，之后的倍增在错误的名次上进行，`banana` 的后缀数组和 LCP 都会错。程序 A 是靠第一轮的名次等于第一个字符，才能保证“名次相同就是前 k 个字符相同”。
3. 后缀数组 5 3 1 0 4 2 里，`a` 小于 `an`，`ana`、`anana` 的前两个字符等于 `an`，其余大于。所以两个值是 1 和 3，出现 2 次，位置 1 和 3。查 `nab`：`na` 比 `nab` 先用完，算小于；`nana` 的前三个字符 `nan` 大于 `nab`。两个值都是 5，出现 0 次。
4. 开始 i = 0、j = 1、k = 0：`b` 和 `c` 不同，i 那边小，j 跳到 2。比较 s[0] 的 `b` 和 s[2] 的 `a`，i 那边大，i 跳到 1；i ≠ j。比较 s[1] 的 `c` 和 s[2] 的 `a`，i 跳到 2，和 j 相同，j 加 1 成 3。比较 s[2] 的 `a` 和 s[3] 的 `b`，j 跳到 4，循环停。答案 2，剪出 `abbc`。
5. 最小周期 3，因为 `abcab` 是最长的又是前缀又是后缀的段，8 − 5 = 3；3 不整除 8，不是整数次重复。`abcabc` 的最小周期也是 3，3 整除 6，是 `abc` 重复 2 次。
