# 14　把所有开头排在一起

在 `banana` 里，`ana` 出现两次。若把每个位置开始到末尾的部分排在一起，相同开头自然相邻。这样的部分叫后缀。

## 排的是位置，不是复印所有后缀

后缀数组 SA 保存后缀起点的字典序。`banana` 的顺序是 `5,3,1,0,4,2`，对应 `a,ana,anana,banana,na,nana`。

倍增排序先按前一个字节排名，再用“前半排名、后半排名”这对数排长两倍的前缀。超出文本的后半排名设为 −1，比任何真实排名小。前缀足够长以后，各后缀顺序已经完全确定。

相邻后缀的最长公共前缀称 LCP。按文本下标依次计算时，前一对相同 h 字节，删掉第一个字节后至少还相同 h−1 字节；保留这个下界继续比较，全部比较总量是线性。

**完整程序：**输入一个非空、无空白 ASCII 串，长度不超过 100000，输出不同非空子串数。

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <vector>

int main() {
    std::string text;
    if (!(std::cin >> text) || text.empty() || text.size() > 100000) { return 1; }
    int n = static_cast<int>(text.size());
    std::vector<int> sa(n), rank(n), next(n), position(n);
    std::iota(sa.begin(), sa.end(), 0);
    for (int i = 0; i < n; ++i) { rank[i] = static_cast<unsigned char>(text[i]); }
    for (int length = 1; length < n; length *= 2) {
        auto less = [&rank, n, length](int a, int b) {
            if (rank[a] != rank[b]) { return rank[a] < rank[b]; }
            int x = a + length < n ? rank[a + length] : -1;
            int y = b + length < n ? rank[b + length] : -1;
            return x < y;
        };
        std::sort(sa.begin(), sa.end(), less);
        next[sa[0]] = 0;
        for (int i = 1; i < n; ++i) {
            next[sa[i]] = next[sa[i - 1]] + (less(sa[i - 1], sa[i]) ? 1 : 0);
        }
        rank.swap(next);
        if (rank[sa.back()] == n - 1) { break; }
    }
    for (int i = 0; i < n; ++i) { position[sa[i]] = i; }
    long long answer = 1LL * n * (n + 1) / 2;
    int common = 0;
    for (int i = 0; i < n; ++i) {
        if (position[i] == 0) { common = 0; continue; }
        int j = sa[position[i] - 1];
        while (i + common < n && j + common < n && text[i + common] == text[j + common]) {
            ++common;
        }
        answer -= common;
        if (common > 0) { --common; }
    }
    std::cout << answer << '\n';
    return 0;
}
```

输入：

```text
banana
```

输出：

```text
15
```

每个后缀有“后缀长度”个前缀，即候选子串；与前一个后缀共有的那些已经出现过，减掉 LCP 即可。此版每轮使用比较排序，时间 `O(n log² n)`，空间 `O(n)`；用计数排序处理排名对可降到 `O(n log n)`，不把这里冒称线性后缀数组。

## 同一个结构能回答哪些问题

两后缀的 LCP 是它们 SA 位置之间相邻 LCP 的最小值，可用第二卷的静态最值表；搜索一个模式也可在 SA 二分其前缀范围。后缀树把所有后缀的 Trie 中单孩子长链压成带起止下标的边，大小为线性；子串对应根向下的一段路径，不是把全部子串逐个建节点。

后缀自动机 SAM 另一种压缩：结束位置集合相同的子串归同一状态。状态 v 管的长度范围是 `(len[link[v]],len[v]]`，其中 `link` 指向较短的后缀类。追加一个字符时新建当前状态，沿后缀链接补缺失转移；若已有转移的长度不符合紧邻关系，就克隆目标的转移与链接、缩短克隆最大长度，并把相关转移改指克隆，再把两个受影响状态链接到它。

克隆不代表一次真实新出现，计数初值为零。按长度从大到小沿 link 累加结束次数，可以统计每类子串出现次数；不同子串总数为各状态 `len[v]-len[link[v]]` 之和。状态最多约 `2n`，固定小字母表时可线性构建，转移若用平衡树还要算查找代价。

## 周期、重复段与最小的开头

p 是串的周期，指对所有合法 i 有 `s[i]=s[i+p]`。最短周期是 `n-最长边缀长度`；要整串由一个短块反复拼成，还需 n 能被 p 整除。`ababa` 周期为 2，却不是整块 `ab` 的整数次复制。

Z 数组保存“从 i 开始与全串开头相同多长”。维护当前最右匹配区间，区间内先复用对应前缀位置的 Z 值，截在已知右边界，再向外比较，总共 `O(n)`。KMP 的边缀表与 Z 表提供的是不同位置的信息，不能混用下标含义。

run 是长度至少两倍最小周期、又无法向任一侧继续保持该周期的极大重复段。`ababab` 整段是周期 2 的 run，其中 `abab` 不极大。不能枚举所有子串再判断周期声称线性；高效 runs 枚举利用 Lyndon 根及最长公共延伸来一次定位整段。

Lyndon 串严格小于自己的所有非平凡循环旋转，例如 `ab`。每个串可唯一分解为字典序不增的 Lyndon 因子。Duval 的三个指针可以这样手算：

1. 未处理部分从 i 开始，令 j=i+1、k=i。
2. 只要 j 未到末尾且 `s[k]<=s[j]`，继续比较；严格小于时令 k=i，相等时令 k=k+1，然后 j 加一。
3. 停止后令 p=j−k。只要 i<=k，就输出从 i 开始长 p 的一段，令 i 加 p。
4. 若还有未处理字节，从第一步继续。

`abab` 由此分成 `ab,ab`，相等旋转使整串本身不是 Lyndon 串。指针推进与批量输出共同保证线性总工作。这给最小表示、重复结构和线性分解提供了统一入口。
