# 15　把镜子和失败路线用起来

镜子前放一排积木，镜子里那一半不用再搭一遍，看镜子外这一半就知道了。查字时也一样：一个字和第一个模板对不上，不一定要退回原处一个一个重来，前面已经对上的那一段，可能正好是另一个模板的开头。

[第二卷第 18 章](../II/18-找文字时别总是退回开头.md)讲过一个模板的失败函数。这一章把同样的“不白走”用到三个地方：找回文时用镜子对面已经知道的结果；逐字加长一个串时，数新出现的回文；很多模板一起找时，让它们共用失败后的去处。

## 别丢掉已有镜子的范围

正着读和倒着读一样的串叫**回文**。要找出串里每个位置为中心的最长回文。照字面做，每个中心向两边一格格试，最坏要 n²/4 步，比如全是 `a` 的串。

先把奇偶两种回文变成一种：在每两个字符之间和两头各插一个 `#`。`aba` 变成 `#a#b#a#`，`abba` 变成 `#a#b#b#a#`。原串里任何回文在新串里都以一个格子为中心，长度是奇数。记 `radius[i]` 为以新串第 i 格为中心，最多能往两边各伸几格。它恰好等于对应的原串回文的长度。

现在从左往右求 `radius`。手里记着到目前为止右端最靠右的那个回文：中心 `center`，右端 `right`。新的位置 i 若在 `right` 之内，它关于 `center` 的镜像位置是 2 × `center` − i，那里的答案已经求过。大回文是对称的，所以在大回文的范围里，i 周围的样子和镜像周围一模一样：`radius[i]` 至少是镜像的半径，但不能超出 `right`，因为超出部分镜子照不到。从这个起点再往外试，试成功一次，`right` 就往右移一格。

下面是**片段**，数原串一共有几个回文子串（位置不同就算不同）。

```cpp
// 位于 main 内；s 是原串
std::string t = "#";
for (char c : s) {
    t += c;
    t += '#';
}
int m = static_cast<int>(t.size());
std::vector<int> radius(m, 0);
int center = 0;
int right = 0;   // 已知回文里右端最靠右的一个，以 center 为中心，右端在 right
for (int i = 0; i < m; ++i) {
    if (i < right) {
        radius[i] = std::min(right - i, radius[2 * center - i]);
    }
    while (i - radius[i] - 1 >= 0 && i + radius[i] + 1 < m &&
           t[i - radius[i] - 1] == t[i + radius[i] + 1]) {
        ++radius[i];
    }
    if (i + radius[i] > right) {
        center = i;
        right = i + radius[i];
    }
}
long long count = 0;
for (int i = 0; i < m; ++i) {
    count += (radius[i] + 1) / 2;   // 同一中心、长度不超过 radius[i] 的回文个数
}
std::printf("%lld\n", count);
```

为什么快：`while` 每多成功一次，`i + radius[i]` 就超过原来的 `right`，随后 `right` 至少跟着增加这么多；`right` 不超过 m，所以全部成功的次数不超过 m。每个 i 还有一次失败的比较，加起来 O(n)。

以 `#` 为中心、半径 r 时，r 是偶数，同一中心的回文长度是 2、4、……、r，共 r/2 个；以字母为中心时，r 是奇数，长度是 1、3、……、r，共 (r + 1)/2 个。两种都等于 `(radius[i] + 1) / 2`。

这个办法叫 **Manacher 算法**。

## 每次追加，至多新出一种回文

换一个问题：串里有几种**不同的**回文？`abab` 里有 `a`、`b`、`aba`、`bab` 四种。

一个结论让这件事变得简单：在串的末尾追加一个字符，至多新出现一种回文。新出现的回文一定以新字符结尾，是新串的后缀。设 P 是最长的回文后缀，Q 是更短的另一个回文后缀。Q 是 P 的后缀；把 P 倒过来读还是 P，把 Q 倒过来读还是 Q，所以 Q 也是 P 的前缀。P 的前缀在新字符之前就结束了，Q 早就出现过。只有 P 可能是新的。

于是长度为 n 的串，不同的回文至多 n 种。要知道每次追加时 P 是不是新的、P 是哪一个，可以把出现过的回文记成节点：每个节点记它的长度、它两头各加一个字母得到的节点，以及它最长的回文真后缀。这个结构叫**回文树**。追加字符 c 时，从上一个最长回文后缀出发，沿“最长回文真后缀”往短里走，直到它前面那个字符恰好是 c，两头加上 c 就是新的 P。为了让“走到最短”也有落脚处，回文树有两个根：长度 0 的空串，和一个长度记作 −1 的虚根，在虚根两头加 c 就得到单个字母 c。每次追加，最长回文后缀的长度至多加 2，所以往短里走的总步数是 O(n)。

## 多个模式，也能共用失败后的去处

### 电子游戏连招

一个游戏只有 `A`、`B`、`C` 三个键，有 N 个连招（N ≤ 20），每个是长度 1 到 15 的键串。按键时，每当刚按下的若干个键恰好组成某个连招，就得 1 分；连招可以重叠，可以在同一键上同时完成，一个连招完成几次就得几分。恰好按 K 个键（K ≤ 1000），最多得几分？

输入第一行 N 和 K，之后 N 行每行一个连招。输出最大分数。

样例输入：

```text
3 7
ABA
CB
ABACB
```

样例输出：

```text
4
```

按 `ABACBCB`：第 3 键完成 `ABA`；第 5 键同时完成 `CB` 和 `ABACB`；第 7 键又完成一次 `CB`。一共 4 分。这是 USACO 2012 年 1 月金组第一题[“电子游戏连招”](../USACO/金组/2011_2012/2012.01/P1.md)。

先问：按下一个键时得几分，取决于已经按过的键里的哪一部分？只取决于最近的十几个键，而且只取决于其中“还可能是某个连招开头”的那一段。把所有连招放进一棵**字典树**：从根出发，每个节点代表一个“是某个连招开头”的串，往下一层就是在后面添一个字母。按键过程中，手里只记一个节点：已按的键里，最长的、又是某个连招开头的后缀。

再按一个键 c，要是这个节点有标着 c 的孩子，就走下去；没有，就要退到“当前串最长的、又是某个连招开头的**真**后缀”所在的节点，再试 c。这个退路叫节点的**失败指针**，和第二卷第 18 章一个模板时的失败函数是同一回事，只是现在退到的可能是别的连招。失败指针按深度从浅到深求：深度小的节点的退路已经定好，孩子的退路就是“父亲的退路再按同一个字母”。

两样东西可以一次算好。一是每个节点按每个键到哪里，记成表 `next`，缺的孩子直接填成“退路按这个键到哪里”，以后按键只查一次表。二是停在每个节点时这一键完成几个连招：本节点是连招结尾算一个，它的失败指针那里完成的也同时完成，所以分数沿失败指针加过来。字典树加上失败指针，叫 **AC 自动机**。

于是问题成了[第二卷第 8 章](../II/08-给已经解决的小问题留个位置.md)的表格：记“按了 i 个键、停在节点 v 时最多几分”，每一格往后按三种键转移。节点不超过 20 × 15 + 1 = 301 个，一共 1000 × 301 × 3 次转移，不到一百万。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <queue>
#include <vector>

struct Node {
    int next[3];   // 补全以后：停在这里再按一个键，到哪个节点
    int fail;      // 最长的、又是某个连招开头的真后缀，在哪个节点
    int score;     // 停在这里时，这一键完成的连招个数
};

int main() {
    int n = 0;
    int k = 0;
    if (std::scanf("%d%d", &n, &k) != 2) {
        return 1;
    }
    std::vector<Node> trie(1, Node{{-1, -1, -1}, 0, 0});
    for (int i = 0; i < n; ++i) {
        char combo[16];
        if (std::scanf("%15s", combo) != 1) {
            return 1;
        }
        int v = 0;
        for (int j = 0; combo[j] != '\0'; ++j) {
            int key = combo[j] - 'A';
            if (trie[v].next[key] < 0) {
                trie[v].next[key] = static_cast<int>(trie.size());
                trie.push_back(Node{{-1, -1, -1}, 0, 0});
            }
            v = trie[v].next[key];
        }
        ++trie[v].score;
    }
    std::queue<int> waiting;   // 按深度从浅到深处理
    for (int key = 0; key < 3; ++key) {
        int child = trie[0].next[key];
        if (child < 0) {
            trie[0].next[key] = 0;
        } else {
            waiting.push(child);   // 第一层的退路是根，fail 已是 0
        }
    }
    while (!waiting.empty()) {
        int v = waiting.front();
        waiting.pop();
        int back = trie[v].fail;
        trie[v].score += trie[back].score;   // 退路上完成的连招，这一键也完成
        for (int key = 0; key < 3; ++key) {
            int child = trie[v].next[key];
            if (child < 0) {
                trie[v].next[key] = trie[back].next[key];
            } else {
                trie[child].fail = trie[back].next[key];
                waiting.push(child);
            }
        }
    }
    int nodes = static_cast<int>(trie.size());
    const int impossible = -1;
    std::vector<int> best(nodes, impossible);   // 按了 i 个键、停在 v 时的最高分
    best[0] = 0;
    for (int i = 0; i < k; ++i) {
        std::vector<int> later(nodes, impossible);
        for (int v = 0; v < nodes; ++v) {
            if (best[v] == impossible) {
                continue;
            }
            for (int key = 0; key < 3; ++key) {
                int to = trie[v].next[key];
                later[to] = std::max(later[to], best[v] + trie[to].score);
            }
        }
        best = later;
    }
    std::printf("%d\n", *std::max_element(best.begin(), best.end()));
    return 0;
}
```

`back` 比 v 浅，处理 v 时它的 `next` 和 `score` 都已经补全了，这正是要按深度处理的原因。`trie[back].next[key]` 永远不是 −1：根的三个键在一开始就补好，其余节点在出队时补好。

分数最多是 K × N = 20000，`int` 够用。对拍的慢办法把 3^K 种按法全部列出来（K ≤ 7），每种按法逐个位置、逐个连招比较。它和程序 A 没有共用的想法。

这一章三次用到“已经知道的不再算”。Manacher 算法借镜子对面的半径，让右端只往前走；回文树靠“至多新出一种”的结论，把所有不同回文装进 n 个节点；AC 自动机让很多模板共用失败后的去处，“电子游戏连招”就在它的节点上做表。能对一组小模板画出字典树和失败指针，说清分数为什么要沿失败指针加过来，再读下一章。下一章允许程序碰运气，但要把碰错的机会算出来。

## 核对

1. 新串是 `#a#b#a#a#b#`，11 格。`radius` 依次是 0 1 0 3 0 1 4 1 0 1 0。各项 (r + 1)/2 加起来：0 + 1 + 0 + 2 + 0 + 1 + 2 + 1 + 0 + 1 + 0 = 8。逐个列出：五个单字母，`aa`、`aba`、`baab`。
2. 追加 `a`：`a`，新。`ab`：`b`，新。`abc`：`c`，新。`abca`：最长回文后缀是 `a`，不新。`abcab`：是 `b`，不新。一共 3 种。
3. 节点：根、`A`、`AB`、`ABA`、`ABAC`、`ABACB`、`C`、`CB`。失败指针：`A`、`C` 指向根；`AB` 指向根（`B` 不是任何连招开头）；`ABA` 指向 `A`；`ABAC` 指向 `C`；`ABACB` 指向 `CB`；`CB` 指向根。`ABACB` 的 `score` 是 2：自己是连招结尾，它的退路 `CB` 也是。
4. 最高 3 分，按 `AAAA`，第 2、3、4 键各完成一次。节点只有根、`A`、`AA`。第 1 步能到根（按 B 或 C）和 `A`；第 2 步起，根、`A`、`AA` 都能到。
