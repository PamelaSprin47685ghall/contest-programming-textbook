# 15　把镜子和失败路线用起来

回文正读反读相同，例如 `level`。一个很长的回文里面藏着许多小回文，若每个中心都从头向外比，会反复比较同一对字节。

## 别丢掉已有镜子的范围

奇回文中心落在字节上，偶回文中心落在两个字节之间。Manacher 分别保存半径。若新中心在已知最右回文内部，它的镜像位置给出一个保证成立的半径，但不能超过当前右边界；越过边界的部分再实际比较。

只在右边界向外推进时花新的比较，整体为 `O(n)`。分别处理奇偶，避免引入一个可能与真实文本冲突的分隔字符。

**完整程序：**输入非空、无空白 ASCII 串，长度不超过一百万，输出回文出现总数与最长长度。相同内容出现在不同位置分别计数。

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::string text;
    if (!(std::cin >> text) || text.empty() || text.size() > 1000000) { return 1; }
    int n = static_cast<int>(text.size());
    std::vector<int> odd(n), even(n);
    long long count = 0;
    int longest = 0;
    int left = 0;
    int right = -1;
    for (int i = 0; i < n; ++i) {
        int radius = i > right ? 1 : std::min(odd[left + right - i], right - i + 1);
        while (i - radius >= 0 && i + radius < n && text[i - radius] == text[i + radius]) {
            ++radius;
        }
        odd[i] = radius;
        count += radius;
        longest = std::max(longest, 2 * radius - 1);
        if (i + radius - 1 > right) {
            left = i - radius + 1;
            right = i + radius - 1;
        }
    }
    left = 0;
    right = -1;
    for (int i = 0; i < n; ++i) {
        int radius = i > right ? 0 : std::min(even[left + right - i + 1], right - i + 1);
        while (i - radius - 1 >= 0 && i + radius < n && text[i - radius - 1] == text[i + radius]) {
            ++radius;
        }
        even[i] = radius;
        count += radius;
        longest = std::max(longest, 2 * radius);
        if (i + radius - 1 > right) {
            left = i - radius;
            right = i + radius - 1;
        }
    }
    std::cout << count << ' ' << longest << '\n';
    return 0;
}
```

输入：

```text
abba
```

输出：

```text
6 4
```

奇半径为 r 的中心贡献 r 个回文，偶半径为 r 同样贡献 r 个。空间 `O(n)`，总数最多 `n*(n+1)/2`，所以用 `long long`。

## 每次追加，至多新出一种回文

回文树有两个特殊根，长度分别为 −1、0；普通节点代表一种不同回文，边表示两头同时加一个相同字节，链接指向最长真回文后缀。

追加字符时，从上一次最长回文后缀沿链接找能被新字符包住的节点；对应边不存在就新建，并沿链接寻找它的新后缀链接。为什么至多新增一个？新回文都必须以最后一位结束；除最长新回文外，它们是这个回文的真后缀，也因回文对称性在更早的前缀位置出现过。

最长后缀节点的出现数加一；整串完成后按长度递减沿链接汇总，得到每种回文的总出现次数。特殊根不算真实回文。与 Manacher 相比，它按**不同内容**组织，不是按中心组织。

## 多个模式，也能共用失败后的去处

把模式 `he,she,hers,his` 建 Trie。失败链接指向“当前串最长的、仍在 Trie 里的真后缀”。按 BFS 深度顺序建链接，缺边时沿失败链接找转移，或预先补全小字母表转移，这就是 AC 自动机。

扫描文本每字节走一步，当前节点及其失败祖先上的结束标记都表示匹配。若只求每个模式出现数，扫描时给当前节点计数，结束后按 BFS 逆序沿失败链接累加；不必每字节走完整条失败链。输出所有出现本身可能有平方量，不能把输出数量藏在“线性时间”里。

自动机状态还可以作为 DP 的边界。例如数长度为 L、避开全部禁词的串：`dp[length][state]` 沿字母转移，进入任何含禁词后缀的状态就丢弃。禁词标记也必须沿失败链接继承，不然 `she` 的末尾 `he` 会漏检。固定小字母表时建表 `O(总模式长*字母数)`，DP 为 `O(L*状态数*字母数)`。

## 核对

1. 六次出现，三种内容 `a,aa,aaa`；出现位置与不同内容是两个计数对象。
2. 两个都报告；`he` 是当前路径 `she` 的后缀，通过失败链接得到。
3. 能。节点按内容共用，出现次数放在计数里，不重复造节点。
