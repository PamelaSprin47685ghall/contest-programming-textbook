# 17　数清的是作品还是做法

美术课上，老师发给每人两枚印章，一红一蓝，让大家在一条三格的纸条上盖章，每次盖满相邻两格。下课时老师问：一共能盖出几种不同的纸条？有个同学数了半天，说有几十种。他数的是“先盖哪里、再盖哪里”的盖法；老师问的是贴在墙上的纸条，盖法不同、纸条一样的，只算一种。

计数题最容易错在这一步：数之前没说清，哪些差别算不同。这一章先练“说清”，再练三种常用的分类办法：按最后一个对象去了哪里分，先数全部再扣掉不合格的，以及“转一下算同一个”时按对称性数。

## 先确认哪些差别算不同

一个对象可能有很多种“做法”，我们要数的却常常是“作品”。办法是给每件作品挑一个唯一的**代表**（这里的代表是计数用的，和并查集里一组的代表无关）：一种只看作品本身就能定下来的东西，让作品和代表一一对应，再去数代表。

### 自助

数轴上有 N 条线段（N ≤ 10⁵），第 i 条是闭区间 [l_i, r_i]，l_i < r_i，2N 个端点两两不同，都在 1 到 2N 之间。一组线段的并集分成几段连着的部分，这个段数叫这组线段的复杂度。对全部 2^N 组（包括空组，复杂度 0）求复杂度之和，对 10⁹ + 7 取余。

输入第一行 N，之后 N 行每行 l_i 和 r_i。输出一个整数。

样例输入：

```text
3
1 6
2 3
4 5
```

样例输出：

```text
8
```

七个非空的组里，只有 {[2, 3], [4, 5]} 的并集分成两段，其余都是一段，和是 6 × 1 + 2 = 8。这是 USACO 2020 年 2 月金组第二题[“自助”](../USACO/金组/2019_2020/2020.02/P2.md)。

复杂度是“段数”，一段可以由很多条线段盖成，按线段去数会重复。给每一段挑一个代表：它最左边的那个点。这个点一定是某条线段的左端点，而且端点两两不同，这条线段是唯一的。于是“段数之和”换成：数有多少对（组，线段 i），使得线段 i 在组里，并且 l_i 是一段的最左点。

l_i 是一段的最左点，当且仅当组里没有别的线段盖住 l_i 左边紧挨着的地方，也就是没有 l_j < l_i < r_j 的线段 j。设这样的 j 有 c_i 条。线段 i 必须选，这 c_i 条必须不选，其余 N − 1 − c_i 条随意，共 2^(N − 1 − c_i) 组。答案是这些数的和。

样例里，[1, 6] 没有被谁盖住左端，贡献 2² = 4；[2, 3] 和 [4, 5] 的左端都被 [1, 6] 盖住，各贡献 2¹ = 2。4 + 2 + 2 = 8。

c_i 可以用[第二卷第 3 章](../II/03-先把重复的加法收起来.md)的差分求：每条线段在 l 处加 1、在 r 处减 1，前缀和在位置 x 上的值就是盖住 (x, x + 1) 的线段数，c_i 是它在 l_i − 1 处的值。

**片段：**

```cpp
// 位于 main 内；left_end、right_end 已读入，mod 是 1000000007
std::vector<int> cover(2 * n + 2, 0);
for (int i = 0; i < n; ++i) {
    ++cover[left_end[i]];
    --cover[right_end[i]];
}
for (int x = 1; x <= 2 * n; ++x) {
    cover[x] += cover[x - 1];   // cover[x]：盖住 (x, x + 1) 的线段数
}
std::vector<long long> two_power(n, 1);
for (int i = 1; i < n; ++i) {
    two_power[i] = two_power[i - 1] * 2 % mod;
}
long long total = 0;
for (int i = 0; i < n; ++i) {
    int blocked = cover[left_end[i] - 1];
    total = (total + two_power[n - 1 - blocked]) % mod;
}
std::printf("%lld\n", total);
```

l_i − 1 至少是 0，`cover[0]` 是 0，因为没有端点在 0。盖住 l_i − 1 到 l_i 之间的线段不包括 i 自己，所以 `blocked` 不超过 N − 1，指数不会是负数。

**停笔 1**　四条线段 [1, 4]、[2, 7]、[3, 5]、[6, 8]。写出每条线段的 c_i 和贡献，求答案。

## 按最后一个对象去了哪里分类

要数的对象一件件排好，可以只看最后一件：它去了哪里，就把全部情况分成几类，每一类都是一个更小的同类问题。分类要做到两件事：每种情况恰好落进一类，每一类的个数能用更小的问题表示。

例子：把编号 1 到 n 的 n 个同学分成 k 个小组，每组至少一人，组没有名字，只看谁和谁一组。记这个数为 S(n, k)。看第 n 号同学：要么他一个人一组，其余 n − 1 人分成 k − 1 组，有 S(n − 1, k − 1) 种；要么他加入其余 n − 1 人分好的 k 组中的一组，组虽然没有名字，但这时各组已经由组员区分开了，所以有 k × S(n − 1, k) 种。于是

S(n, k) = S(n − 1, k − 1) + k × S(n − 1, k)，S(0, 0) = 1。

S(3, 2) = S(2, 1) + 2 × S(2, 2) = 1 + 2 = 3：{1, 2}{3}、{1, 3}{2}、{2, 3}{1}。这个数叫**第二类斯特林数**。如果组有名字（第一组、第二组），每种分法再乘以 k!，因为 k 个组可以任意贴名字。“作品”在这里是没有名字的分组，“做法”多了一份贴名字的选择。

下面是**片段**，按行填出 S(i, j)，i 从 0 到 n。

```cpp
// 位于 main 内；求 S(n, k) 对 mod 取余，0 <= k <= n
std::vector<std::vector<long long>> ways(n + 1, std::vector<long long>(n + 1, 0));
ways[0][0] = 1;
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= i; ++j) {
        // 第 i 个人自成一组，或加入前面已经分好的 j 组之一
        ways[i][j] = (ways[i - 1][j - 1] + j * ways[i - 1][j]) % mod;
    }
}
std::printf("%lld\n", ways[n][k]);
```

第 0 列除了 `ways[0][0]` 都是 0：有人却没有组，不可能。表有 (n + 1)² 格，每格一次加法。对拍时，慢办法给每个人在 1 到 k 中挑一个组号，共 k^n 种，留下 k 个组都不空的，再除以 k!，因为没有名字的分组，每一种恰好对应 k! 种组号。两种办法一个按最后一人分类，一个先贴名字再除掉，想法不同，结果应当相同。

## 不好数合法，就先数全部再扣

有时合法的情况长得很杂，不合法的反而整齐。那就先数全部，再扣掉不合法的。不合法的情况若由几条“坏事”组成，彼此又有重叠，就要用**容斥原理**：对坏事 A₁、A₂、……、A_k，

至少发生一件的个数 = 各件之和 − 每两件同时发生之和 + 每三件同时发生之和 − ……

例子：1 到 100 里，不被 2、3、5 中任何一个整除的数。被 2、3、5 整除的各有 50、33、20 个；被 6、10、15 整除的各有 16、10、6 个；被 30 整除的有 3 个。至少被一个整除的是 50 + 33 + 20 − 16 − 10 − 6 + 3 = 74，剩下 100 − 74 = 26 个。为什么对：一个恰好被其中 t 个整除的数（t ≥ 1），在上式里被算了 t − C(t, 2) + C(t, 3) − …… 次，这个数等于 1 − (1 − 1)^t = 1，恰好一次。

### 印章涂色

纸条有 N 格（N ≤ 10⁶），有 M 种颜色的印章（M ≤ 10⁶），每个印章正好盖住相邻的 K 格（1 ≤ K ≤ N），不能伸出纸条。每次盖章把那 K 格涂成印章的颜色，后盖的会盖住先盖的。最后每格都至少被盖过一次。问能得到几种不同的纸条，对 10⁹ + 7 取余。盖的次序、次数不同，纸条相同就算一种。

输入一行 N、M、K。输出一个整数。

样例输入：

```text
3 2 2
```

样例输出：

```text
6
```

两种颜色 A、B，能盖出 AAA、AAB、ABB、BAA、BBA、BBB。ABA 和 BAB 盖不出来：最后一次盖下的两格一定同色，而这两种纸条没有相邻的同色格。这是 USACO 2018 年 1 月金组第三题[“印章涂色”](../USACO/金组/2017_2018/2018.01/P3.md)。

先把作品说清。最后一次盖章留下连续 K 格同色，所以能盖出的纸条一定有某处连续 K 格同色。反过来，设第 i 格起的 K 格同色。从左端起，依次在第 1、2、……、i 格起盖章，每次用这一次起点那格的目标颜色；再从右端往左同样盖到第 i 格起。每一次盖章都把它起点那格定成了目标色，后面的章只会盖到更靠里的格子，而最后盖下的第 i 格起的那一章同时完成了中间的 K 格。所以能盖出的纸条，恰好是“某处有连续 K 格同色”的纸条。

“某处有”不好数，换成全部减去“处处没有”：每一段同色都短于 K 的纸条。这种纸条按最后一段同色有多长分类，正是上一节的办法。记 `valid[i]` 为长度 i、每段同色都短于 K 的纸条数。最后一段长 j（1 ≤ j ≤ K − 1）：若 j = i，整条一种颜色，M 种；否则前 i − j 格是一张合格的纸条，最后一段的颜色要和它最后一格不同，M − 1 种。于是 `valid[i]` 等于“i ≤ K − 1 时的 M”加上 (M − 1) 乘以 `valid[i − 1]` 到 `valid[i − K + 1]` 之和（只取下标 ≥ 1 的）。

样例 K = 2：`valid[1]` = 2，`valid[2]` = 1 × 2 = 2，`valid[3]` = 1 × 2 = 2。2³ − 2 = 6。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

const long long mod = 1000000007LL;

int main() {
    int n = 0;
    long long m = 0;
    int k = 0;
    if (std::scanf("%d%lld%d", &n, &m, &k) != 3) {
        return 1;
    }
    // valid[i]：长度 i、每一段同色都短于 k 的纸条数
    std::vector<long long> valid(n + 1, 0);
    long long window = 0;   // valid[i - k + 1] 到 valid[i - 1] 之和，只算下标 >= 1 的
    for (int i = 1; i <= n; ++i) {
        long long whole = i <= k - 1 ? m % mod : 0;   // 整条一种颜色
        valid[i] = (whole + (m - 1) % mod * window) % mod;
        window = (window + valid[i]) % mod;
        if (i - k + 1 >= 1) {
            window = (window - valid[i - k + 1] + mod) % mod;   // 移出窗口
        }
    }
    long long all = 1;
    for (int i = 0; i < n; ++i) {
        all = all * (m % mod) % mod;
    }
    std::printf("%lld\n", (all - valid[n] + mod) % mod);
    return 0;
}
```

`window` 是一个长 K − 1 的滑动和，每步加进新算的一项、移出最旧的一项，整件事 O(N)。K = 1 时，“短于 1 的段”不存在：`whole` 总是 0，`window` 每步加进又立刻移出，`valid` 全是 0，答案是 M^N，确实每张纸条都能一格一格盖出来。取余以后的乘积小于 (10⁹ + 7)²，在 `long long` 里。

对拍的慢办法不用上面的刻画，直接模拟盖章：从一张全空的纸条出发，对每个能到的状态试每个位置、每种颜色，把能到的状态全部找出来，最后数没有空格的状态。N ≤ 6、M ≤ 3 时状态不超过 4⁶ 个。它数的是作品，因为同一张纸条只算一次。

## 转一下仍算同一个，要按对称性数

用两种颜色的珠子串一个四颗珠子的手链，转一下能重合的算同一条。四颗珠子各两种，共 2⁴ = 16 种涂法，可手链不是 16 ÷ 4 = 4 种：全黑的涂法转四下都是自己，算一种；黑白相间的转两下就回来，只有两种涂法属于它。不同的手链有不同多的“化身”，不能一律除以 4。

办法是换个方向数。把“转 g 下”记为 g（g = 0、1、2、3），数有多少对（g，涂法 x），使得转 g 下以后 x 不变。

先按 g 数：转 0 下，16 种都不变；转 1 下或 3 下，四颗必须同色，2 种；转 2 下，第 1 颗与第 3 颗同色、第 2 颗与第 4 颗同色，2² = 4 种。合计 16 + 2 + 4 + 2 = 24。

再按 x 数：一条手链有 t 种涂法，每种涂法被 4/t 个 g 保持不变。比如黑白相间那条，t = 2，每种涂法被“转 0 下”和“转 2 下”保持不变，正好 4/2 = 2 个。所以每条手链贡献 t × 4/t = 4 对。手链数等于 24 ÷ 4 = 6。

这就是 **Burnside 引理**：不同的作品数，等于每种对称操作保持不变的涂法数的平均值。“每种涂法被 |G|/t 个操作保持不变”这一步，在一般情形叫轨道—稳定子关系，它的证明是：把保持 x 不变的操作记为一组 H，那么“转 g 下以后得到哪种涂法”只取决于 g 落在 H 的哪个“平移”里，平移有 t 个，每个大小 |H|，所以 t × |H| = |G|。

## 核对

1. [1, 4] 的左端 1 没人盖住，c = 0，贡献 2³ = 8；[2, 7] 左端 2 被 [1, 4] 盖住，c = 1，贡献 4；[3, 5] 左端 3 被前两条盖住，c = 2，贡献 2；[6, 8] 左端 6 被 [2, 7] 盖住，c = 1，贡献 4。答案 18。
2. S(4, 1) = 1，S(4, 2) = S(3, 1) + 2 × S(3, 2) = 1 + 6 = 7，S(4, 3) = S(3, 2) + 3 × S(3, 3) = 3 + 3 = 6，S(4, 4) = 1。有名字的两组：7 × 2! = 14 = 2⁴ − 2，减去的是全进第一组和全进第二组。
3. `valid[1]` = 2，`valid[2]` = 2 + 1 × 2 = 4，`valid[3]` = 1 × (2 + 4) = 6，`valid[4]` = 1 × (4 + 6) = 10。答案 16 − 10 = 6：AAAA、AAAB、BAAA、BBBB、BBBA、ABBB。
4. g = 0 到 5 时，gcd 依次是 6、1、2、3、2、1，不变的涂法是 729、3、9、27、9、3，和是 780，除以 6 得 130 条。
