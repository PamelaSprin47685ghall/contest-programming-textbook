# 17　数清的是作品还是做法

三张不同贴纸放进两只不同盒子，两只都不能为空。先把贴纸分两组再给盒子命名，与逐张选盒子，应该得到相同数量；若把中间步骤的不同也重复算上，就会多算。

## 先确认哪些差别算不同

有先后、无先后；允许重复、不允许重复；对象有名字、没有名字；这些条件决定计数对象。一个作品若有多种合法证明，不能把证明数当作品数。

例如“能由一些卡片拼成 10 的子集有几个”，若同一子集有多种拼装顺序，不能每种顺序都加一。可选唯一代表元，例如总按原下标递增处理；或者设计状态直接数子集。去重依据要写进递推。

## 按最后一个对象去了哪里分类

`S(n,k)` 表示 n 个有名字对象分成 k 个无名字、非空组的数。最后一个对象单独一组，有 `S(n-1,k-1)` 种；加入已有 k 组之一，有 `k*S(n-1,k)` 种。因此两项相加。这是第二类 Stirling 数。

组再分给 k 个有名字盒子，有 `k!` 种命名，答案为 `k!*S(n,k)`。阶乘是 `1*2*...*k`，并约定 `0!=1`。

**完整程序：**输入 `0 <= n,k <= 2000`，输出 n 个有名字对象放入 k 个有名字非空盒子的方案数，模 1000000007。零个对象放零个盒子算一种。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    int k = 0;
    if (std::scanf("%d%d", &n, &k) != 2 || n < 0 || n > 2000 || k < 0 || k > 2000) {
        return 1;
    }
    const long long modulus = 1000000007;
    std::vector<long long> ways(k + 1, 0);
    ways[0] = 1;
    for (int count = 1; count <= n; ++count) {
        for (int groups = std::min(count, k); groups >= 1; --groups) {
            ways[groups] = (ways[groups - 1] + groups * ways[groups]) % modulus;
        }
        ways[0] = 0;
    }
    long long answer = ways[k];
    for (int i = 1; i <= k; ++i) { answer = answer * i % modulus; }
    std::printf("%lld\n", answer);
    return 0;
}
```

输入：

```text
3 2
```

输出：

```text
6
```

时间 `O(nk+k)`，空间 `O(k)`。倒序使两项都来自上一轮；这里倒序的理由与 0/1 背包相同，但保存的意义完全不同。

## 不好数合法，就先数全部再扣

两盒任意放有 `2^3=8` 种，扣掉一个盒子空的两种，得 6。一般多个禁事件会重叠：先减每个坏事件，再加两两交集，减三重交集……这是容斥。

固定一个作品，若它落在 t 个坏事件里，其总系数是 `sum((-1)^j*C(t,j))`：t=0 留 1，t>0 为 0。这比只背加减顺序更能检查容斥有没有针对正确事件。

贡献拆分则从另一边数。例如所有子数组的总和，不逐段相加，而看位置 i 被多少段包含：0 下标时为 `(i+1)*(n-i)`，乘上该位置的值后累加。统计对子、边、最小元素也常能这样换主角。

排列无固定点的错排数满足 `D(n)=(n-1)*(D(n-1)+D(n-2))`，边界 `D(0)=1,D(1)=0`：看第一个对象去向，与目标对象是互换还是进入更长的圈两类。括号合法串按首个左括号匹配的右括号分割，得到 Catalan 递推 `C[n]=sum(C[i]*C[n-1-i])`。分类必须互斥且覆盖，不能只凭式子长得像。

## 转一下仍算同一个，要按对称性数

四颗二色珠围成项链，只允许旋转、不允许翻面。16 份带起点涂色不是 16 条项链。四种旋转各固定 16、2、4、2 份涂色，平均为 6，是 Burnside 引理。

理由：数“涂色与固定它的旋转”这类配对。每个旋转等价类，类大小乘上每份被固定的旋转数，恰好等于旋转总数；因此求和再除，得到类数。若加入翻面，允许动作变多，固定数也要重新计算，不能继续除以 4。

群作用、生成函数、卷积反演是在更大范围管理这些重复与分类的方法，后面的代数章会把名字逐一落到运算上。本章不要求先学抽象代数才能数珠子。

## 核对

1. 一只盒子为空，不合要求；不命名盒子为三种。
2. 四个。长度限制改变了可选左右端点，不能再独立随意选。
