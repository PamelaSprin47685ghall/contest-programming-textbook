# 18　让不同的余数说同一件事

体育课排队。老师说：“三个一排多两个，五个一排多三个。”一位同学马上说：“那我们有 8 个人，或者 23 个，或者 38 个……”另一位同学问：“要是四个一排多一个、六个一排多两个呢？”大家试了半天，发现怎么也凑不出来：四个一排多一个，人数是奇数；六个一排多两个，人数是偶数。

两句关于余数的话，有时能接成一句，有时互相矛盾。这一章看清楚是谁决定了这一点：公因数。再看两件相关的事：把一个整数看成一组质因子的坐标，以及一大段整数除出来的商是相同的。

余数的基本算法见[第二卷第 19 章](../II/19-整数身上也有线索.md)。写 a ≡ b (mod m) 表示 a 和 b 除以 m 的余数相同，也就是 m 整除 a − b。

## 公因数决定能不能约

在模 m 的世界里解 a × x ≡ b。普通算术里除以 a 就好，这里能不能“除”，要看 a 和 m 的最大公因数 g = gcd(a, m)。

先看必要条件。a × x − b 是 m 的倍数，而 a 和 m 都是 g 的倍数，所以 b 也必须是 g 的倍数。2 × x ≡ 3 (mod 4) 无解：2x 是偶数，偶数减 3 是奇数，不可能被 4 整除。

再看充分性，靠**扩展欧几里得算法**：它在求 gcd(a, m) 的同时，给出一对整数 x、y，使 a × x + m × y = g。辗转相除的每一步把 (a, m) 换成 (m, a mod m)；若已知 m × x′ + (a mod m) × y′ = g，把 a mod m 写成 a − ⌊a/m⌋ × m 代进去，就得到 a × y′ + m × (x′ − ⌊a/m⌋ × y′) = g。最后一步 m = 0 时，a × 1 + 0 × 0 = a = g。

**片段：**

```cpp
// 返回 gcd(a, m)，并让 a * x + m * y 等于它；a、m 不为负
long long extended_gcd(long long a, long long m, long long& x, long long& y) {
    if (m == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long inner_x = 0;
    long long inner_y = 0;
    long long g = extended_gcd(m, a % m, inner_x, inner_y);
    x = inner_y;
    y = inner_x - (a / m) * inner_y;
    return g;
}
```

有了 a × x₀ + m × y₀ = g，b 是 g 的倍数时，两边乘以 b/g，得到 a × (x₀ × b/g) ≡ b (mod m)，这就是一个解。所有解相差 m/g 的倍数，所以模 m 共有 g 个解。特别地，g = 1 时 a 有唯一的逆元 x₀（[第 8 章](08-有些依赖会绕回来.md)用过模质数的逆元，这里 m 不必是质数）：a × x₀ ≡ 1。逆元存在，当且仅当 a 与 m 互素。

**停笔 1**　用片段的递推，手算 extended_gcd(30, 21) 每一层的返回值和 x、y。再解 30 × x ≡ 12 (mod 21)，写出模 21 的全部解。

## 一次把两个约束接起来

回到排队。x ≡ a₁ (mod m₁)，x ≡ a₂ (mod m₂)。前一句说 x = a₁ + m₁ × t。代进后一句：m₁ × t ≡ a₂ − a₁ (mod m₂)。这正是上一节的方程。设 g = gcd(m₁, m₂)：a₂ − a₁ 不是 g 的倍数就无解；是的话，t 在模 m₂/g 下唯一确定，x 在模 lcm(m₁, m₂) 下唯一确定。m₁、m₂ 互素时这就是**中国剩余定理**：任意两个余数都能接上，答案在模 m₁ × m₂ 下唯一。

三个一排多两个、五个一排多三个：x = 2 + 3t，3t ≡ 1 (mod 5)，3 的逆元是 2，t ≡ 2，x = 8，模 15。四个一排多一个、六个一排多两个：g = 2，2 − 1 = 1 不是 2 的倍数，无解，和开头的奇偶论证一致。

**片段：**

```cpp
// 用到 extended_gcd。把 x ≡ a1 (mod m1) 与 x ≡ a2 (mod m2) 合成 x ≡ a1 (mod m1)；
// 无解返回 false。要求 0 <= a1 < m1、0 <= a2 < m2，m1、m2 不超过 10^6
bool merge(long long& a1, long long& m1, long long a2, long long m2) {
    long long x = 0;
    long long y = 0;
    long long g = extended_gcd(m1, m2, x, y);   // m1 * x + m2 * y = g
    long long diff = a2 - a1;
    if (diff % g != 0) {
        return false;
    }
    long long step = m2 / g;                     // t 只在模 step 下有意义
    long long t = (diff / g) % step * (x % step) % step;
    if (t < 0) {
        t += step;
    }
    a1 = a1 + m1 * t;
    m1 = m1 * step;                              // 这就是 lcm(m1, m2)
    return true;
}
```

`x` 可能是负数，`diff` 也可能是负数，C++ 的 `%` 对负数给出负的余数，所以最后把 `t` 调回 0 到 step − 1。两个因数都小于 step ≤ 10⁶，乘积不超过 10¹²；新的 a1 小于 m1 × step，也不超过 10¹²。模数更大时，乘法要先想好怎样不溢出。

## 因子也能作为一组坐标

每个正整数唯一地写成质数的乘积：360 = 2³ × 3² × 5。把指数排成一行 (3, 2, 1, 0, ……)，一个数就成了一组坐标。很多关系在坐标里变得简单：a 整除 b，当且仅当 a 的每个坐标都不超过 b 的；gcd 取每个坐标的较小者，lcm 取较大者；约数的个数是 (3 + 1)(2 + 1)(1 + 1) = 24。

“和 w 互素”在坐标里是：在 w 有的每个质因子 p 上，坐标都是 0。数 1 到 n 里和 w 互素的数，就是对 w 的质因子 p₁、……、p_r 做第 17 章《数清的是作品还是做法》的容斥：

Σ 符号(d) × ⌊n/d⌋，d 取遍 p₁、……、p_r 中若干个（可以不取）的乘积，符号是 (−1) 的“取了几个”次方。

这个符号叫**默比乌斯函数** μ(d)：d 有平方因子时记 0，否则是 (−1) 的质因子个数次方。n = w 时得到 1 到 w 里和 w 互素的数的个数，叫**欧拉函数** φ(w)，等于 w × (1 − 1/p₁) × …… × (1 − 1/p_r)。φ(12) = 12 × 1/2 × 2/3 = 4：1、5、7、11。

### 大横幅

一块草地的整点 (x, y)，0 ≤ x ≤ M、0 ≤ y ≤ N，每个整点上有一根柱子（M、N ≤ 10⁵）。挑两根柱子挂一条笔直的横幅，要求两根柱子之间的线段上没有别的柱子，长度在 L 到 H 之间（1 ≤ L ≤ H ≤ 1.5 × 10⁵）。两端对调算同一种。求挂法数对 B 取余（B ≤ 10⁹）。

输入一行 M、N、L、H、B。输出一个整数。

样例输入：

```text
2 2 1 3 100
```

样例输出：

```text
28
```

3 × 3 共 9 根柱子，任取两根是 36 对。其中 8 对中间夹着柱子：三条横线和三条竖线上的两端，两条对角线上的两端。长度都在 1 到 3 之间。36 − 8 = 28。这是 USACO 2012 年 3 月金组第一题[“大横幅”](../USACO/金组/2011_2012/2012.03/P1.md)。

两端的坐标差是 (dx, dy)。线段上有别的整点，当且仅当 gcd(|dx|, |dy|) > 1：设 g 是公因数，(dx/g, dy/g) 那一点就在线段上；g = 1 时，线段上的整点必须是 t × (dx, dy)，t 在 0 和 1 之间，又要坐标都是整数，只能 t = 0 或 1。长度限制写成 L² ≤ dx² + dy² ≤ H²，不用小数。

先数坐标差为 (dx, dy) 的横幅能放几处：(M + 1 − |dx|) × (N + 1 − |dy|)。为了让两端对调只算一次，规定 dy > 0，或者 dy = 0 且 dx > 0。dy = 0 时只有 dx = 1 满足互素，长度是 1；dx = 0 时只有 dy = 1。其余情况 dx、dy 都不为 0，dx 取正、取负各一半，算一遍正的再乘 2。

对每个 dy = w ≥ 1，dx 的范围是一段 [low, high]：low 是满足 dx² ≥ L² − w² 的最小正整数，high 是满足 dx² ≤ H² − w² 的最大整数，再不超过 M。要求的是这段里和 w 互素的 dx 的 (M + 1 − dx) 之和。用容斥：对 w 的每个由不同质因子乘成的 d，求这段里 d 的倍数的 (M + 1 − dx) 之和，按 μ(d) 加减。倍数是 k × d，k 从 ⌈low/d⌉ 到 ⌊high/d⌋，和是 个数 × (M + 1) − d × (k 的和)，一步算完。

下面是**完整程序 A**。

```cpp
#include <cmath>
#include <cstdio>
#include <vector>

long long m = 0;

// dx 在 [low, high] 里、是 d 的倍数时，(m + 1 - dx) 的和
long long multiples_sum(long long low, long long high, long long d) {
    long long k_low = (low + d - 1) / d;
    long long k_high = high / d;
    if (k_low > k_high) {
        return 0;
    }
    long long count = k_high - k_low + 1;
    long long k_total = (k_low + k_high) * count / 2;
    return count * (m + 1) - d * k_total;
}

// 不超过 value 的最大整数平方根；value >= 0
long long floor_sqrt(long long value) {
    long long root = static_cast<long long>(std::sqrt(static_cast<double>(value)));
    while (root * root > value) {
        --root;
    }
    while ((root + 1) * (root + 1) <= value) {
        ++root;
    }
    return root;
}

int main() {
    long long n = 0;
    long long low_len = 0;
    long long high_len = 0;
    long long b = 0;
    if (std::scanf("%lld%lld%lld%lld%lld", &m, &n, &low_len, &high_len, &b) != 5) {
        return 1;
    }
    long long answer = 0;
    if (low_len <= 1) {   // 长度为 1 的横线和竖线
        answer = (m % b * ((n + 1) % b) + (m + 1) % b * (n % b)) % b;
    }
    long long top = n < high_len ? n : high_len;
    std::vector<std::vector<int>> primes(top + 1);   // primes[w]：w 的不同质因子
    for (int p = 2; p <= top; ++p) {
        if (primes[p].empty()) {                     // 没有更小的质数整除它
            for (long long j = p; j <= top; j += p) {
                primes[j].push_back(p);
            }
        }
    }
    for (long long w = 1; w <= top; ++w) {
        long long room = high_len * high_len - w * w;
        long long high = floor_sqrt(room);
        if (high > m) {
            high = m;
        }
        long long need = low_len * low_len - w * w;   // dx * dx 至少是 need
        long long low = 1;
        if (need > 1) {
            low = floor_sqrt(need - 1) + 1;
        }
        if (low > high) {
            continue;
        }
        int r = static_cast<int>(primes[w].size());
        long long coprime = 0;   // 精确值，不取余：不超过 1.5e5 * 1e5
        for (int mask = 0; mask < (1 << r); ++mask) {
            long long d = 1;
            int chosen = 0;
            for (int j = 0; j < r; ++j) {
                if ((mask >> j) & 1) {
                    d *= primes[w][j];
                    ++chosen;
                }
            }
            long long part = multiples_sum(low, high, d);
            coprime += chosen % 2 == 0 ? part : -part;
        }
        long long ways = coprime % b * ((n + 1 - w) % b) % b;
        answer = (answer + 2 * ways) % b;
    }
    std::printf("%lld\n", answer);
    return 0;
}
```

`floor_sqrt` 先用 `std::sqrt` 估一个数，再用整数乘法修正。`double` 的平方根可能差一点，直接截断会把 24.999…… 截成 24；两个 `while` 保证结果的平方不超过 value、下一个整数的平方超过它。`room` 一定不为负，因为 w ≤ H。`need − 1` 的平方根加 1，是平方不小于 need 的最小整数。

w 不超过 1.5 × 10⁵ 时，一个数至多 6 个不同质因子（2 × 3 × 5 × 7 × 11 × 13 = 30030，再乘 17 就超过了），每个 w 至多 64 项。这里用到的位运算见第二卷第 2 章。`coprime` 是精确的整数，每项不超过约 10¹⁰，64 项加减也放得下，最后才取余，免得负数取余出错。

## 一大段商相同，不必逐项做

求 ⌊n/1⌋ + ⌊n/2⌋ + …… + ⌊n/n⌋。n = 10¹² 时一项项加做不完。可是商只有不多几种：i ≤ √n 时最多 √n 种 i；i > √n 时商小于 √n，最多 √n 种值。一共不超过 2√n 种。

商相同的 i 连成一段。从 i 开始，商是 q = ⌊n/i⌋，这一段最右到 j = ⌊n/q⌋：j 是满足 j × q ≤ n 的最大整数，而对 i 到 j 之间的数，⌊n/·⌋ 都是 q。

**片段：**

```cpp
// 位于 main 内；n 已读入，n <= 10^12
long long total = 0;
for (long long i = 1; i <= n; ) {
    long long q = n / i;
    long long j = n / q;   // 商为 q 的最后一个 i
    total += q * (j - i + 1);
    i = j + 1;
}
std::printf("%lld\n", total);
```

n = 10 时，段是 [1, 1] 商 10、[2, 2] 商 5、[3, 3] 商 3、[4, 5] 商 2、[6, 10] 商 1，和是 10 + 5 + 3 + 4 + 5 = 27。循环只转了 5 次。n = 10¹² 时约 2 × 10⁶ 次。total 约 n ln n ≈ 2.8 × 10¹³，`long long` 放得下。

第二卷第 5 章的银组题“偿还贷款”里，判定时每天还的数也是这样一段段相同的，可以照这个办法一段一段跳。

**停笔 4**　n = 20，写出所有商相同的段。和是多少？

这一章的主角是公因数。它决定一个方程能不能“约”，决定两个余数能不能接上；把整数看成质因子的坐标，整除、gcd、互素都变成了逐个坐标的比较，容斥就有了 μ 和 φ；“大横幅”把三样都用上了：互素是没有中间柱子，容斥按质因子加减，长度用整数平方比较。商相同的一大段，则让 n 到 10¹² 的和只需几百万步。能对一组同余式说出有没有解、解在模几下唯一，再读下一章。下一章把很多关系放进一张数表。

## 核对

1. 递推依次是 (30, 21) → (21, 9) → (9, 3) → (3, 0)。最底层返回 3，x = 1、y = 0；(9, 3) 层 x = 0、y = 1；(21, 9) 层 x = 1、y = 0 − 2 × 1 = −2；(30, 21) 层 x = −2、y = 1 − 1 × (−2) = 3。核对 30 × (−2) + 21 × 3 = 3。12 是 3 的倍数，乘以 4：x₀ = −8 ≡ 13，所有解相差 7：模 21 下是 6、13、20。核对 30 × 6 = 180 = 8 × 21 + 12。
2. 第一步：extended_gcd(4, 6) 给出 4 × (−1) + 6 × 1 = 2，差 2 是 2 的倍数，step = 3，t = 1 × (−1) 调成 2，得 a1 = 1 + 4 × 2 = 9、m1 = 12。第二步：extended_gcd(12, 9) 给出 12 × 1 + 9 × (−1) = 3，差 6 − 9 = −3 是 3 的倍数，step = 3，t = (−1) × 1 调成 2，得 a1 = 9 + 12 × 2 = 33、m1 = 36。核对：33 除以 4、6、9 余 1、3、6。
3. dy = 0：dx = 1 长 1，不合格；dx = 0、dy = 1 也长 1，不合格。dy = 1：dx 要满足 dx² ≥ 3、dx² ≤ 8，只有 dx = 2，互素，放 (3 + 1 − 2) × (1 + 1 − 1) = 2 处，正负各一，共 4。答案 4。
4. 段：[1] 20、[2] 10、[3] 6、[4] 5、[5] 4、[6] 3、[7, 10] 2、[11, 20] 1。和是 20 + 10 + 6 + 5 + 4 + 3 + 8 + 10 = 66。
