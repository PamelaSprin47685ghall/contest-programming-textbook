# 18　让不同的余数说同一件事

一个数除以 4 余 1，除以 6 余 3。试出 9 以后，还要问：别的答案隔多远出现？条件会不会彼此矛盾？

## 公因数决定能不能约

欧几里得每一步不仅保存公因数，也能保存 `a*x+b*y=gcd(a,b)` 的系数。由下一层 `b*x1+(a%b)*y1=g` 代回，得到 `x=y1,y=x1-(a/b)*y1`，这就是扩展欧几里得。

当 gcd 为 1，x 就是 a 模 b 的逆元。模素数 p 且 a 不被 p 整除时，也可由 `a^(p-2)` 求逆；素数条件不能删。模合数时，用扩展欧几里得最直接。

## 一次把两个约束接起来

已知 `X≡answer (mod M)`，新约束为 `X≡r (mod m)`，代入 `X=answer+M*t`。要求 `M*t≡r-answer (mod m)`。令 `g=gcd(M,m)`，右边须被 g 整除，否则无解；约掉 g 后才能求逆。新周期是 `M*(m/g)`，即最小公倍数。

**完整程序：**输入 `0 <= k <= 20`，随后每行 `m r`，`1 <= m <= 1000000`、`0 <= r < m`，保证所有模数的最小公倍数不超过 `10^12`。输出最小非负解与周期，无解输出 `NONE`。没有约束时输出 `0 1`。

```cpp
#include <cstdio>

long long extended(long long a, long long b, long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long next_x = 0;
    long long next_y = 0;
    long long g = extended(b, a % b, next_x, next_y);
    x = next_y;
    y = next_x - (a / b) * next_y;
    return g;
}

long long normalize(long long x, long long modulus) {
    return (x % modulus + modulus) % modulus;
}

int main() {
    int k = 0;
    if (std::scanf("%d", &k) != 1 || k < 0 || k > 20) { return 1; }
    long long answer = 0;
    long long period = 1;
    for (int i = 0; i < k; ++i) {
        long long modulus = 0;
        long long remainder = 0;
        if (std::scanf("%lld%lld", &modulus, &remainder) != 2 || modulus < 1
            || modulus > 1000000 || remainder < 0 || remainder >= modulus) { return 1; }
        long long x = 0;
        long long y = 0;
        long long g = extended(period, modulus, x, y);
        long long difference = remainder - answer;
        if (difference % g != 0) { std::printf("NONE\n"); return 0; }
        long long step = modulus / g;
        long long t = normalize(difference / g, step) * normalize(x, step) % step;
        if (period > 1000000000000LL / step) { return 1; }
        answer += period * t;
        period *= step;
        answer = normalize(answer, period);
    }
    std::printf("%lld %lld\n", answer, period);
    return 0;
}
```

输入：

```text
2
4 1
6 3
```

输出：

```text
9 12
```

这是广义中国剩余定理。每步先约分与归一，把求 t 的乘积压在 `10^12` 内；合并周期也受契约限制。时间约为每个约束一次欧几里得的对数代价，不依赖最小解有多大。

## 因子也能作为一组坐标

欧拉函数 φ(n) 数 1 到 n 中与 n 互质的整数。按素因子排除倍数，得到 `φ(n)=n*prod(1-1/p)`。莫比乌斯函数 μ(n)：有平方素因子时为 0，否则按不同素因子个数奇偶取 −1 或 1，`μ(1)=1`。

关键恒等式是 `sum_{d|n} μ(d)` 在 n=1 为 1，其余为 0。因此若 `F(n)=sum_{d|n} f(d)`，交换求和得到 `f(n)=sum_{d|n} μ(d)*F(n/d)`，叫莫比乌斯反演。可用于数互质对：枚举公因子 d，以 μ(d) 加减同时被 d 整除的数对。

这里的卷积按因子相乘分解，叫 Dirichlet 卷积，与第 20 章按下标相加的卷积不同。线性筛可同时求 μ、φ：新素数 p 有 μ=-1、φ=p−1；扩展 i*p，若 p 整除 i，则 μ=0、φ=φ(i)*p，否则 μ 取反、φ 乘 p−1。

## 一大段商相同，不必逐项做

`floor(N/i)` 在连续区间不变。当前左端 l，商 q=N/l，该段右端为 `r=N/q`。一次处理 l 到 r，再从 r+1 继续，总共只有 `O(sqrt N)` 个不同商。

例如 N=10，商依次分为：i=1 得 10；2 得 5；3 得 3；4—5 得 2；6—10 得 1。于是 `sum floor(N/i)` 可按五段计算，不用十次除法。若还乘 f(i)，需要 f 的前缀和，不能只乘段长。

求积性函数前缀和时，可从卷积恒等式把未知前缀留一项，余项按这些商分块，并记忆化重复的 `N/i`；杜教筛属于这一组织。按小素数逐层筛除的求和方法则在这些商位置维护“尚未排除小素因子的数”的计数或幂和，再按最小素因子分类恢复，常用于素数和及更一般积性函数求和。正确性来自精确的分类恒等式，不来自用几组值拟合一条曲线。

离散对数 `a^x≡b mod m` 可在互质条件下用 baby-step giant-step 把指数分成 `x=i*s+j`，存一侧、枚举另一侧，约 `O(sqrt m)` 空间时间；不互质需先处理 gcd 障碍。它求指数，不是求普通实数对数。整除块、素因子分解、筛与快速幂应按问题组合，不是逐个轮流试模板。
