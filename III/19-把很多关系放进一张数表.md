# 19　把很多关系放进一张数表

班上互相写信。老师在黑板上画一张表：第 i 行第 j 列写 1，表示 i 号同学给 j 号写过信，否则写 0。有人问：一封信经过两次转交，从 1 号到 3 号，有几种走法？把第 1 行和第 3 列对着看，同一个位置上都是 1 的，就是一个可以转交的中间人。这一步对每一对 (i, j) 做一遍，正好是两张表的乘法。

这一章把关系放进数表，也就是**矩阵**，再用矩阵的运算回答问题。先要选好“加”和“乘”是什么意思，再看在模 2 的世界里怎样解方程，最后看行列式，以及它在图上能数出什么。

## 先选允许怎样算

n × n 的矩阵 A、B 相乘，结果的第 i 行第 j 列是 Σ A[i][t] × B[t][j]，t 取遍 0 到 n − 1。A 是图的邻接矩阵时（A[i][j] 是 i 到 j 的边数），A² 的 (i, j) 项就是从 i 走两步到 j 的走法数：先走到 t，再从 t 走到 j，对每个 t 相乘再相加。归纳下去，A^k 的 (i, j) 项是走 k 步的走法数。

例子：三个点，边 0→1、1→0、1→2、2→0。从 0 出发走回 0：走 3 步只有 0→1→2→0 一种；走 5 步有 0→1→0→1→2→0 和 0→1→2→0→1→0 两种。A⁵ 的第 0 行是 2、1、1，左上角正是 2。

把“相乘再相加”换成别的运算，同样的表格能回答别的问题。换成“相加再取最小”，A^k 的 (i, j) 项就是恰好走 k 步的最短路长；换成“且”和“或”，就是能不能恰好 k 步走到。能这样换，靠的是两种运算满足几条规则：“加”可以交换、可以结合，“乘”可以结合，“乘”对“加”能分配。有了这几条，(AB)C = A(BC)，于是 A^k 可以用[第二卷第 7 章](../II/07-把一大步拆成几小步.md)的平方法求出，只要 log k 次矩阵乘法。

**片段：**

```cpp
typedef std::vector<std::vector<long long>> Matrix;
const long long mod = 1000000007LL;

Matrix multiply(const Matrix& a, const Matrix& b) {
    int n = static_cast<int>(a.size());
    Matrix c(n, std::vector<long long>(n, 0));
    for (int i = 0; i < n; ++i) {
        for (int t = 0; t < n; ++t) {
            for (int j = 0; j < n; ++j) {
                c[i][j] = (c[i][j] + a[i][t] * b[t][j]) % mod;
            }
        }
    }
    return c;
}

// 位于 main 内；adjacency 是 n × n 的邻接矩阵，steps 是步数，可以到 10^18
Matrix result(n, std::vector<long long>(n, 0));
for (int i = 0; i < n; ++i) {
    result[i][i] = 1;   // 走 0 步：只能待在原地
}
Matrix power = adjacency;
while (steps > 0) {
    if (steps % 2 == 1) {
        result = multiply(result, power);
    }
    power = multiply(power, power);
    steps /= 2;
}
```

每次乘法 n³ 步，一共约 2 log k 次。循环把 t 放在中间，内层沿着 `b` 的一行走，比把 t 放在最里面读内存更顺；结果一样。

## 异或其实在每一位模 2 计算

两个二进制位相加，只留个位：0 + 0 = 0，0 + 1 = 1，1 + 1 = 0。这就是模 2 的加法，也是异或（`^`）。乘法是“且”（`&`）。一个数的异或，就是每一位各自做模 2 加法。所以“只关心奇偶”的问题，常常可以搬进一张只有 0 和 1 的矩阵，在模 2 下算。

### 航班路线

N 座城市（2 ≤ N ≤ 750），对每一对 i < j，要么有一班从 i 直飞 j 的航班，要么没有。从 a 到 b 的一条路线是 a = c₁ < c₂ < …… < c_k = b，每一段都是直飞（直飞本身也算一条路线）。现在只告诉你每一对 i < j 之间路线条数的奇偶，请算出有几对城市之间有直飞。可以证明答案唯一。

输入第一行 N；之后 N − 1 行，第 i 行是一个长 N − i 的 0、1 串，第 j 个字符是 i 到 i + j 的路线数的奇偶。输出直飞的对数。

样例输入：

```text
3
11
1
```

样例输出：

```text
2
```

1→2、2→3 有直飞，1→3 没有。1→2、2→3 各一条路线；1→3 只有一条 1→2→3，奇数。和输入一致。这是 USACO 2023 年 12 月金组第一题[“航班路线”](../USACO/金组/2023_2024/2023.12/P1.md)。

记 R[i][j] 为路线数的奇偶，D[i][j] 为有没有直飞。一条从 i 到 j 的路线，按它的第一班航班飞到哪里分类：直接飞到 j，算一条；先飞到 k（i < k < j），后面是 k 到 j 的任何一条路线。于是在模 2 下

R[i][j] = D[i][j] + Σ D[i][k] × R[k][j]，k 从 i + 1 到 j − 1。

这样分类里，要求的 D 和已知的 R 搅在一起。换成按最后一班航班从哪里起飞分类：

R[i][j] = D[i][j] + Σ R[i][k] × D[k][j]，k 从 i + 1 到 j − 1。

现在可以解出 D[i][j] = R[i][j] + Σ R[i][k] × D[k][j]。右边的 D[k][j] 都有 k > i。所以 i 从大往小算：轮到第 i 行时，下面各行的 D 都已经算好。在矩阵的语言里，这是 R = D + R × D，也就是 D = (I + R)⁻¹ × R；I + R 的对角线全是 1、下方全是 0，在模 2 下一定可逆，答案唯一正来自这里。

算第 i 行时，Σ R[i][k] × D[k][j] 对所有 j 一起做：对每个 R[i][k] = 1 的 k，把第 k 行的 D 异或到一行累加器上。这正是“把某几行加起来”的行运算。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <string>
#include <vector>

char line[760];

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    // routes[i][j]、direct[i][j]：只用 i < j 的部分，城市从 0 编号
    std::vector<std::vector<char>> routes(n, std::vector<char>(n, 0));
    std::vector<std::vector<char>> direct(n, std::vector<char>(n, 0));
    for (int i = 0; i + 1 < n; ++i) {
        if (std::scanf("%759s", line) != 1) {
            return 1;
        }
        for (int j = i + 1; j < n; ++j) {
            routes[i][j] = static_cast<char>(line[j - i - 1] - '0');
        }
    }
    int answer = 0;
    std::vector<char> through(n, 0);   // through[j]：经过中间某城再到 j 的路线数的奇偶
    for (int i = n - 2; i >= 0; --i) {
        for (int j = 0; j < n; ++j) {
            through[j] = 0;
        }
        for (int k = i + 1; k < n; ++k) {
            if (routes[i][k] == 1) {        // 先有一条 i 到 k 的路线，最后一班从 k 起飞
                for (int j = k + 1; j < n; ++j) {
                    through[j] ^= direct[k][j];
                }
            }
        }
        for (int j = i + 1; j < n; ++j) {
            direct[i][j] = routes[i][j] ^ through[j];
            answer += direct[i][j];
        }
    }
    std::printf("%d\n", answer);
    return 0;
}
```

处理第 i 行时，用到的 `direct[k][j]` 都有 k > i，已经在前面的轮次算好。三层循环约 N³/6 次，N = 750 时约 7 × 10⁷ 次异或。

对拍的慢办法反过来做：随机造一张航班表，按定义数出每一对的路线数并取奇偶，交给程序 A，看能否还原出原来的直飞对数。它从不解方程，只数路线。

## 行列式不是随便把每行相乘

n × n 矩阵的**行列式**是这样一个数：从每行挑一个数，要求挑的数分在不同的列，把它们乘起来；挑法对应一个排列，排列里逆序对个数为奇数时乘积前面加负号；对全部 n! 种挑法求和。

2 × 2 时，是 a × d − b × c。3 × 3 的例子：

| 2 | 1 | 3 |
|---|---|---|
| 1 | 0 | 2 |
| 4 | 1 | 1 |

六种挑法：2 × 0 × 1 = 0，− 2 × 2 × 1 = −4，− 1 × 1 × 1 = −1，1 × 2 × 4 = 8，3 × 1 × 1 = 3，− 3 × 0 × 4 = 0。和是 6。

n! 项不能逐个算。行列式有三条性质：两行交换，变号；一行乘 c，乘 c；一行加上另一行的倍数，不变。于是可以像解方程那样消元，把矩阵变成上三角，行列式就是对角线的乘积。在模素数 p 下，“除以一个数”就是乘以它的逆元，逆元可以用上一章的扩展欧几里得求，也可以用费马小定理求 a^(p − 2)。

**片段：**

```cpp
// 位于 main 外；a 的元素都在 0 到 mod − 1 之间，mod 是素数
long long power_mod(long long base, long long exponent) {
    long long result = 1;
    base %= mod;
    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result = result * base % mod;
        }
        base = base * base % mod;
        exponent /= 2;
    }
    return result;
}

long long determinant(Matrix a) {
    int n = static_cast<int>(a.size());
    long long det = 1;
    for (int col = 0; col < n; ++col) {
        int pivot = col;
        while (pivot < n && a[pivot][col] == 0) {
            ++pivot;
        }
        if (pivot == n) {
            return 0;            // 这一列下面全是 0
        }
        if (pivot != col) {
            std::swap(a[pivot], a[col]);
            det = (mod - det) % mod;   // 交换两行，变号
        }
        det = det * a[col][col] % mod;
        long long inverse = power_mod(a[col][col], mod - 2);
        for (int row = col + 1; row < n; ++row) {
            long long factor = a[row][col] * inverse % mod;
            for (int j = col; j < n; ++j) {
                a[row][j] = (a[row][j] - factor * a[col][j] % mod + mod) % mod;
            }
        }
    }
    return det;
}
```

消元是 O(n³)，比 n! 少得多。用浮点数消元会有误差，模素数下没有误差，代价是只知道余数。

## 图也有一组线性坐标

一张无向图有 m 条边。一组边可以写成 m 位的 0、1 串，两组边的“和”是异或：同时出现的边抵消。每个点度数都是偶数的边组叫**圈空间**里的元素，它们关于异或封闭。连通的图上，先取一棵生成树，剩下的 m − n + 1 条边，每条和树上的路合成一个圈；任何一个“每点度数为偶”的边组，都恰好是其中若干个圈的异或。所以圈空间有 m − n + 1 个坐标。

用处之一：边上有权，一条路的权是所经过的边权的异或，求 1 到 n 的最大权。任取一条 1 到 n 的路，任何别的路和它异或，得到的是圈空间里的元素。所以答案是“这条路的权”异或上“若干个基本圈的权”，在每一位上模 2 计算，就是选一组向量让结果最大，用消元求出这组圈权的一组**基**，从高位往低位贪心。

## 三个把计数变成行列式的窗口

行列式按定义是带符号的、对排列求和。有三类计数，恰好能整理成这个样子，于是用 O(n³) 的消元就能数出来。这里把它们说准确，只给 LGV 的抵消办法写出一句理由；完整的证明篇幅较长，不在这里展开。

**矩阵树定理**：一张无向图，作矩阵 L，对角线上是各点的度数，i ≠ j 处是 i 与 j 之间边数的相反数。删去任意一行和同号的一列，剩下的行列式等于这张图的生成树个数。例子：四个点，边 0–1、0–2、1–2、1–3、2–3。L 删去第 0 行第 0 列后是

| 3 | −1 | −1 |
|---|---|---|
| −1 | 3 | −1 |
| −1 | −1 | 2 |

行列式是 8，这张图恰有 8 棵生成树。

**LGV 引理**：无圈的有向图上，起点 a₁、……、a_k，终点 b₁、……、b_k。作 k × k 矩阵 M，M[i][j] 是 a_i 到 b_j 的路数。det M 等于对所有“k 条两两没有公共点的路，把每个 a_i 送到某个 b_σ(i)”的方案，按排列 σ 的正负号求和。有公共点的方案在带符号的和里两两抵消：在第一个碰面的点上交换两条路的后半段，正负号恰好相反。要是图的形状保证不碰面的方案只能让 σ 是恒等排列（比如起点、终点都沿着一条边界依次排开），det M 就恰好是不碰面方案的个数。

**BEST 定理**：一张每点入度等于出度、连通的有向图，每条边恰好走一次的回路（只看边的循环顺序，不管从哪里起步）的个数，等于 t × Π (d_v − 1)!，乘积取遍所有点 v，d_v 是 v 的出度，t 是“所有边都指向同一个点 w 的生成树”的个数，取哪个 w 结果都一样。t 又能用矩阵树定理的有向版本求出。

**停笔 5**　四个点两两相连（6 条边）。写出删掉一行一列后的 3 × 3 矩阵，求生成树个数。和 4^(4 − 2) 对得上吗？

这一章把关系放进数表：选好“加”和“乘”，矩阵乘法就数路、求最短路或判断能否到达；在模 2 下，异或是加法，“航班路线”按最后一班航班分类，变成一次自上而下的消元；行列式用消元代替 n! 项，图的生成树、不碰面的路也都能变成行列式。能对一个小图写出它的邻接矩阵和 L，说清每一项的意思，再读下一章。下一章看另一种“一批一起算”：多项式的系数怎样一次全乘出来。

## 核对

1. A² 的第 0 行是 1、0、1，A³ 是 1、1、0。走 6 步回到 0 有 2 种：0→1→0→1→0→1→0 和 0→1→2→0→1→2→0。用 A⁶ 的左上角 2 核对。
2. 路线数：1→2 是 1，1→3 是 2（直飞、经 2），1→4 是 2（1→2→3→4、1→3→4），2→3 是 1，2→4 是 1，3→4 是 1。奇偶串：第 1 行 `100`，第 2 行 `11`，第 3 行 `1`。从下往上：3→4 是 1；第 2 行：2→3 是 1，2→4 是 1 + R[2][3] × D[3][4] = 1 + 1 = 0；第 1 行：1→2 是 1，1→3 是 0 + R[1][2] × D[2][3] = 1，1→4 是 0 + R[1][2] × D[2][4] + R[1][3] × D[3][4] = 0 + 0 + 0 = 0。还原出 4 班直飞。
3. 第 1 列取 2 作主元，第 2 行减 1/2 × 第 1 行，第 3 行减 2 × 第 1 行，得到第 2 行 (0, −1/2, 1/2)、第 3 行 (0, −1, −5)。第 3 行再减 2 × 第 2 行，得 (0, 0, −6)。对角线 2 × (−1/2) × (−6) = 6。没有交换行。
4. m − n + 1 = 4 − 4 + 1 = 1 个，圈 1–2–3–1 的权是 5 ^ 3 ^ 6 = 0。1 到 4 的路 1–3–4 权 6 ^ 1 = 7，异或上 0 不变，最大是 7。
5. 矩阵是对角线 3、其余 −1 的 3 × 3 矩阵，行列式 16，等于 4² = 16。
