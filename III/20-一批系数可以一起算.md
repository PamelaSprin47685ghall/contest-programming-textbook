# 20　一批系数可以一起算

掷两颗骰子，点数和是 7 的方法有几种？列一张 6 × 6 的表，数对角线，6 种。要是问点数和为 2 到 12 的每一种各有几种，就是把整张表沿着对角线一条条加起来。骰子有一百万个面的时候，这张表有 10¹² 格，就不能一格格加了。

这一章把“一排数”看成多项式的系数，“沿对角线加”就是多项式乘法。要说明三件事：系数的乘法到底在算什么；下标按别的规则合并时，该用什么样的变换；以及快的乘法到底快在哪里。

## 多项式不是额外的一门暗号

一颗骰子写成 x + x² + x³ + x⁴ + x⁵ + x⁶：x 的指数是点数，系数是“有几种方法得到这个点数”。两颗骰子相乘，x^i 乘 x^j 得 x^(i + j)，指数正好相加，系数正好相乘再相加。所以乘积里 x⁷ 的系数，就是点数和为 7 的方法数。

一般地，a = (a₀, a₁, ……) 与 b = (b₀, b₁, ……) 的乘积 c 是

c_k = Σ a_i × b_(k − i)，i 从 0 到 k。

这种“下标相加”的乘法叫**卷积**。多项式只是让这个算式好记：x 在这里不代表某个数，只是一个记号，提醒我们乘的时候指数相加。

照式子算，长度 n 和 m 的两排数要做 n × m 次乘法。另一种看法：次数小于 n 的多项式，由它在 n 个不同点上的值唯一确定，因为两个这样的多项式要是在 n 个点上相等，差是一个次数小于 n、却有 n 个根的多项式，只能是 0。于是乘法可以换一种做：先在足够多的点上求出两个多项式的值，逐点相乘，再从这些值还原系数。逐点相乘只要 n 次乘法。麻烦在“求值”和“还原”两步，它们照直做都要 n² 次。第三节就是要让这两步变快。

## 下标怎样合并，决定用什么变换

卷积是“下标相加”。也有题要的是别的合并方式。比如下标是 k 位二进制数，代表一个集合，题目要的是

h(U) = Σ f(A) × g(B)，对所有 A ∪ B = U 求和。

这叫**或卷积**，下标按位“或”合并。办法同样是“换一种表示，逐点相乘，再换回来”，只是换的方式不同。把每个 f 换成 F(S) = Σ f(T)，T 取遍 S 的所有子集。这一步叫**子集和变换**。

为什么它适合或卷积：F(S) × G(S) 是所有 A ⊆ S、B ⊆ S 的 f(A) × g(B) 之和；A、B 都是 S 的子集，等于 A ∪ B 是 S 的子集。所以 F × G 正好是 h 的子集和。逐点相乘以后，把子集和换回原来的数就是 h。

子集和可以一位一位地做：处理第 b 位时，把每个含第 b 位的 S 加上“S 去掉第 b 位”的值。做完第 b 位以后，F(S) 是“只在前 b + 1 位上可以比 S 少”的子集之和；全部位做完，就是所有子集之和。换回去是同样的循环，加改成减。

**片段：**

```cpp
// 位于 main 外；f 的长度是 2 的 k 次方，sign 为 1 时求子集和，为 -1 时换回去
void subset_sum(std::vector<long long>& f, int k, int sign) {
    int size = 1 << k;
    for (int bit = 0; bit < k; ++bit) {
        for (int mask = 0; mask < size; ++mask) {
            if ((mask >> bit) & 1) {
                f[mask] = (f[mask] + sign * f[mask - (1 << bit)] + mod) % mod;
            }
        }
    }
}

// 位于 main 内；f、g 已读入，长度都是 2 的 k 次方
subset_sum(f, k, 1);
subset_sum(g, k, 1);
std::vector<long long> h(1 << k, 0);
for (int mask = 0; mask < (1 << k); ++mask) {
    h[mask] = f[mask] * g[mask] % mod;
}
subset_sum(h, k, -1);
```

照定义算或卷积要 4^k 次，这里是 k × 2^k 次。k = 20 时，前者约 10¹²，后者约 2 × 10⁷。

两个集合时的例子：k = 1，下标 0 表示空集、1 表示 {0}。f = (1, 2)，g = (3, 4)。h(空) = 1 × 3 = 3；h({0}) = 1 × 4 + 2 × 3 + 2 × 4 = 18。子集和：F = (1, 3)，G = (3, 7)，逐点相乘 (3, 21)，换回去 (3, 21 − 3) = (3, 18)。

其他合并方式各有自己的变换。下标按位异或合并，用**沃尔什–阿达马变换**：每一位上把一对数 (u, v) 换成 (u + v, u − v)。按 gcd 或 lcm 合并，用约数上的和与第 18 章《让不同的余数说同一件事》的默比乌斯函数。下标相加，就是下一节的数论变换。共同的模式是：找一种表示，让“合并下标”变成“逐点相乘”。

## 快乘的收益来自怎样分解

先看一个不用复数、不用余数的例子。两个两位数 12 × 34。写成 (1 × 10 + 2)(3 × 10 + 4)，照直要算 1 × 3、1 × 4、2 × 3、2 × 4 四次乘法。可是中间两项只要它们的和：(1 + 2) × (3 + 4) = 21，减去 1 × 3 = 3 和 2 × 4 = 8，得到 10。三次乘法：3 × 100 + 10 × 10 + 8 = 408。把多项式分成前后两半，递归地这样做，每层把一次大乘法换成三次一半大小的乘法，总工作量约 n^1.585，比 n² 少。这个办法叫 **Karatsuba 算法**。

快乘的收益，来自怎样把一次大问题分成几个小问题。更好的分法是：把多项式 A 按指数的奇偶分成两半，A(x) = E(x²) + x × O(x²)。要在 n 个点上求 A 的值，若这 n 个点两两互为相反数，比如 w 和 −w，那么 w² = (−w)²，E 和 O 只要在 n/2 个点上求值。再要这 n/2 个平方也两两互为相反数，一直分到 1 个点。

满足这个要求的点，是 n 次**单位根**：一个数 w，它的 n 次方是 1，而且更小的正次方都不是 1。取 w⁰、w¹、……、w^(n − 1)，n 是 2 的幂时，w^(k + n/2) = −w^k，它们的平方是 n/2 次单位根的全部方幂。复数里有这样的 w，模某些素数也有。模 998244353 = 119 × 2²³ + 1 时，3 是它的一个**原根**：3 的方幂取遍 1 到 p − 1 的全部余数，于是 3^((p − 1)/n) 就是一个 n 次单位根，n 可以是不超过 2²³ 的任何 2 的幂。在模素数下做的这种变换叫**数论变换**，在复数上做的叫快速傅里叶变换。

还原也用同一个变换：用 w 的逆元代替 w 做一遍，再把每个数除以 n。理由是 Σ w^(jk) 对 k 求和，j 不是 n 的倍数时是 0（一圈单位根加起来抵消），j = 0 时是 n。

两步各 O(n log n)：每层把问题分成两个一半大小的问题，再花 O(n) 合起来。

输入第一行两个数 la、lb（1 到 10⁵），第二行 la 个系数，第三行 lb 个系数，都在 0 到 998244352 之间。输出乘积的 la + lb − 1 个系数，对 998244353 取余。

样例是两颗骰子。

样例输入：

```text
7 7
0 1 1 1 1 1 1
0 1 1 1 1 1 1
```

样例输出：

```text
0 0 1 2 3 4 5 6 5 4 3 2 1
```

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

const long long mod = 998244353LL;

long long power_mod(long long base, long long exponent) {
    long long result = 1;
    base %= mod;
    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result = result * base % mod;
        }
        base = base * base % mod;
        exponent /= 2;
    }
    return result;
}

// a 的长度 n 是 2 的幂，root 是 n 次单位根；把系数换成在 root 的各次方上的值
void transform(std::vector<long long>& a, long long root) {
    int n = static_cast<int>(a.size());
    if (n == 1) {
        return;
    }
    std::vector<long long> even(n / 2);
    std::vector<long long> odd(n / 2);
    for (int i = 0; i < n / 2; ++i) {
        even[i] = a[2 * i];
        odd[i] = a[2 * i + 1];
    }
    long long square = root * root % mod;   // n/2 次单位根
    transform(even, square);
    transform(odd, square);
    long long w = 1;
    for (int k = 0; k < n / 2; ++k) {
        long long part = w * odd[k] % mod;
        a[k] = (even[k] + part) % mod;           // 在 w^k 处
        a[k + n / 2] = (even[k] - part + mod) % mod;   // 在 w^(k + n/2) = −w^k 处
        w = w * root % mod;
    }
}

int main() {
    int la = 0;
    int lb = 0;
    if (std::scanf("%d%d", &la, &lb) != 2) {
        return 1;
    }
    int n = 1;
    while (n < la + lb - 1) {
        n *= 2;
    }
    std::vector<long long> a(n, 0);
    std::vector<long long> b(n, 0);
    for (int i = 0; i < la; ++i) {
        if (std::scanf("%lld", &a[i]) != 1) {
            return 1;
        }
    }
    for (int i = 0; i < lb; ++i) {
        if (std::scanf("%lld", &b[i]) != 1) {
            return 1;
        }
    }
    long long root = power_mod(3, (mod - 1) / n);
    transform(a, root);
    transform(b, root);
    for (int i = 0; i < n; ++i) {
        a[i] = a[i] * b[i] % mod;
    }
    transform(a, power_mod(root, mod - 2));   // 用逆元做一遍，就是换回去
    long long inverse_n = power_mod(n, mod - 2);
    for (int i = 0; i < la + lb - 1; ++i) {
        std::printf("%lld%c", a[i] * inverse_n % mod, i + 2 < la + lb ? ' ' : '\n');
    }
    return 0;
}
```

n 取不小于 la + lb − 1 的最小的 2 的幂，乘积的系数个数不超过 n，在 n 个点上求值才够还原。la、lb 都是 10⁵ 时 n = 2¹⁸，小于 2²³，单位根存在。所有乘法的两个因数都小于 p，乘积小于 10¹⁸。

递归每层都新建两个数组，总共多用 O(n log n) 的内存搬动；不用递归、原地交换的写法更快，但想法相同。

对拍的慢办法照卷积的定义双重循环。两份程序共用的只有输入格式。
