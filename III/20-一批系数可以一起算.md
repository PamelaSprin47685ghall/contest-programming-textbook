# 20　一批系数可以一起算

两只转盘分别可能停在 0、1、2。第一只各位置有 `a[i]` 种涂法，第二只有 `b[j]` 种。总和为 k 的组合数，是所有 `i+j=k` 的 `a[i]*b[j]` 之和。

## 多项式不是额外的一门暗号

把序列写成 `A(x)=a[0]+a[1]x+a[2]x²+...`。相乘后 x 的 k 次项系数正是刚才的和，叫卷积。最直接两层循环要 `O(nm)`。

若知道多项式在足够多不同点的值，就可从“系数表示”换到“点值表示”：每个点分别相乘，再插值回来。快速傅里叶变换 FFT 选单位根作点，利用偶项、奇项递归合并，工作量 `O(L log L)`。复数版本有舍入误差，不能无条件把任意大的整数系数四舍五入后声称精确。

NTT 在模素数的域里选择单位根，没有浮点误差。998244353 的原根可取 3，支持长度为 2 的幂且不超过 `2^23` 的变换。长度至少为 `n+m-1`，否则得到环卷积，尾部会绕回开头。

**完整程序：**输入 `1 <= n,m <= 100000`，再输入两组各 0 到 998244352 的系数，输出模 998244353 的普通卷积。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

const int modulus = 998244353;

int power(int base, int exponent) {
    long long answer = 1;
    long long current = base;
    while (exponent > 0) {
        if (exponent & 1) { answer = answer * current % modulus; }
        current = current * current % modulus;
        exponent >>= 1;
    }
    return static_cast<int>(answer);
}

void transform(std::vector<int>& a, bool inverse) {
    int n = static_cast<int>(a.size());
    for (int i = 1, j = 0; i < n; ++i) {
        int bit = n >> 1;
        while (j & bit) { j ^= bit; bit >>= 1; }
        j ^= bit;
        if (i < j) { std::swap(a[i], a[j]); }
    }
    for (int length = 2; length <= n; length *= 2) {
        int root = power(3, (modulus - 1) / length);
        if (inverse) { root = power(root, modulus - 2); }
        for (int start = 0; start < n; start += length) {
            long long factor = 1;
            for (int j = 0; j < length / 2; ++j) {
                int x = a[start + j];
                int y = static_cast<int>(a[start + j + length / 2] * factor % modulus);
                int sum = x + y;
                if (sum >= modulus) { sum -= modulus; }
                int difference = x - y;
                if (difference < 0) { difference += modulus; }
                a[start + j] = sum;
                a[start + j + length / 2] = difference;
                factor = factor * root % modulus;
            }
        }
    }
    if (inverse) {
        int scale = power(n, modulus - 2);
        for (int& value : a) { value = static_cast<int>(1LL * value * scale % modulus); }
    }
}

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2 || n < 1 || n > 100000 || m < 1 || m > 100000) { return 1; }
    int length = 1;
    while (length < n + m - 1) { length *= 2; }
    std::vector<int> a(length, 0), b(length, 0);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d", &a[i]) != 1 || a[i] < 0 || a[i] >= modulus) { return 1; }
    }
    for (int i = 0; i < m; ++i) {
        if (std::scanf("%d", &b[i]) != 1 || b[i] < 0 || b[i] >= modulus) { return 1; }
    }
    transform(a, false);
    transform(b, false);
    for (int i = 0; i < length; ++i) { a[i] = static_cast<int>(1LL * a[i] * b[i] % modulus); }
    transform(a, true);
    for (int i = 0; i < n + m - 1; ++i) { std::printf("%d%c", a[i], i + 1 == n + m - 1 ? '\n' : ' '); }
    return 0;
}
```

输入：

```text
3 2
1 2 3
4 5
```

输出：

```text
4 13 22 15
```

空间 `O(L)`。这里系数结果在指定模数下精确；要还原普通整数卷积，需证明系数上界，并用足够模数的 CRT 或安全分块，不是改一下输出格式。

## 下标怎样合并，决定用什么变换

XOR 卷积把 `i XOR j=k` 的乘积相加，蝶形为 `(u+v,u-v)`，逆变换除以长度，叫 FWT 的一种。OR 卷积可做子集和变换：每位把不含该位的值加到含该位的值，点乘后逐位减回；AND 方向相反。模 2 时不能直接除以 2，所以 XOR 的这份逆变换不适用。

真正的子集卷积要求 `A∩B` 为空且 `A∪B=S`。普通 OR 卷积会把重叠也算进去；按集合大小分层做子集和变换，再按层数相加点乘、逆变换并取大小 `|S|` 的那层，排除重叠，时间 `O(w²*2^w)`。

半在线卷积中一边系数已知、另一边逐项产生，要按依赖把已知贡献分块。CDQ 先算左半，用卷积把左半贡献推到右半，再算右半；不能先算右半再补它需要的旧项。常见总时间 `O(n log² n)`，仍取决于每层卷积组织。

## 快乘的收益来自怎样分解

四个子乘积可重写成三个，是 Karatsuba 的来源：中间项用 `(a0+a1)*(b0+b1)-a0*b0-a1*b1`。递归时间约 `O(n^log2(3))`，但大整数进位与常数不能忽略。

张量把多组下标的双线性系数放在一起，张量分解寻找少量“先做线性组合、再相乘、最后线性组合”的表达。上面的三乘法就是一例。它不是增加维数就自动变快，分解秩和组合代价都要有真实收益。

最值卷积 `c[k]=min(a[i]+b[k-i])` 通常不能直接用 FFT，因为 min 没有普通加法的逆。若额外有凸性或 Monge 结构，再用相应的优化，不能把所有叫卷积的东西都交给 NTT。

## 核对

1. 两种有序来源：左选 x 或右选 x；长度 2 时 x² 回到常数项。
2. OR 可以，不交卷积不行，因为两侧共享元素。
3. 浮点舍入及误差；普通答案也可能是 `3+模数` 等，需范围保证才能还原。
