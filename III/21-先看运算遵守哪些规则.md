# 21　先看运算遵守哪些规则

小卖部只收 1 元、2 元、5 元的硬币。买一支 10 元的笔，有几种付法？可以列表：只用 1 元，用一些 2 元，再加 5 元……数着数着就乱了。上一章把骰子写成了多项式，这里也可以：1 元硬币写成 1 + x + x² + ……（x 的指数是付了几元），2 元写成 1 + x² + x⁴ + ……，5 元写成 1 + x⁵ + x¹⁰ + ……。三个相乘，x¹⁰ 的系数就是付法数。

可这些“多项式”没有尽头。无穷多项能不能相乘？能不能相除？这一章要先说清：在一条系数序列上，哪些运算是允许的，它们遵守哪些规则，再用它们计数。

## 把计数装进一条系数序列

一列数 a₀、a₁、a₂、…… 写成 a₀ + a₁x + a₂x² + ……，叫它的**生成函数**。它不是一个要代入数求值的函数，只是把整列数放在一起的记号。两个生成函数相加，系数逐项相加；相乘，用上一章的卷积。

这样定义的乘法，即使两列都无穷长，乘积的每一项也只用到有限项：xⁿ 的系数是 Σ a_i × b_(n − i)，i 从 0 到 n。所以无穷长的序列照样能乘。

硬币的例子：x¹⁰ 的系数要从三个因子里各挑一项，指数加起来是 10。比如 1 元那一项挑 x³、2 元挑 x²、5 元挑 x⁵，就是付三个 1 元、一个 2 元、一个 5 元。逐项展开太慢，但乘积可以一个因子一个因子地乘：乘上 1 + x^c + x^(2c) + …… 时，新的第 v 项等于旧的第 v 项加上新的第 v − c 项。这正是[第二卷第 8 章](../II/08-给已经解决的小问题留个位置.md)的“完全背包”表格。0 到 10 元的付法数依次是 1、1、2、2、3、4、5、6、7、8、10，付 10 元有 10 种。

生成函数的用处在于，它把“表格的递推”和“序列的乘法”说成同一件事，于是可以借用代数的规则：乘法可以交换次序、可以结合，对加法可以分配。表格不必记住硬币的先后，就是因为乘法可以交换。

## 在截断范围内做代数

很多题只要前 n 项。规定只看 x⁰ 到 x^(n − 1) 的系数，把更高的项一律扔掉，叫“模 xⁿ”。这样做是安全的：乘积的第 k 项只依赖两个因子的前 k 项，先扔掉高次项再乘，和乘完再扔，结果一样。于是加、减、乘都可以在截断范围里做。

除法是乘以倒数。A 的倒数是满足 A × B ≡ 1（模 xⁿ）的 B。看常数项：a₀ × b₀ = 1，所以 a₀ 必须可逆，在模素数时就是 a₀ 不为 0。a₀ 可逆时，B 存在而且唯一：比较 x^k 的系数，a₀ × b_k + a₁ × b_(k − 1) + …… + a_k × b₀ = 0（k ≥ 1），于是

b_k = −(a₁ × b_(k − 1) + …… + a_k × b₀) ÷ a₀。

例子：1 ÷ (1 − x) = 1 + x + x² + ……，因为 (1 − x)(1 + x + x² + ……) 的每个 x^k（k ≥ 1）系数都是 1 − 1 = 0。1 元硬币那个无穷的因子，就是 1 ÷ (1 − x)。再如 1 ÷ (1 − x − x²)：b₀ = 1，b₁ = b₀ = 1，b_k = b_(k − 1) + b_(k − 2)，正是斐波那契数。

输入第一行 n（1 到 5000），第二行 a₀ 到 a_(n − 1)，都在 0 到 998244352 之间，a₀ 不为 0。输出倒数的前 n 项，对 998244353 取余。

样例输入是 1 − x − x²，−1 写成 998244352。

```text
8
1 998244352 998244352 0 0 0 0 0
```

样例输出：

```text
1 1 2 3 5 8 13 21
```

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

const long long mod = 998244353LL;

long long power_mod(long long base, long long exponent) {
    long long result = 1;
    base %= mod;
    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result = result * base % mod;
        }
        base = base * base % mod;
        exponent /= 2;
    }
    return result;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<long long> a(n, 0);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%lld", &a[i]) != 1) {
            return 1;
        }
    }
    if (a[0] == 0) {
        return 1;   // 常数项不可逆，倒数不存在
    }
    long long inverse_head = power_mod(a[0], mod - 2);
    std::vector<long long> b(n, 0);
    b[0] = inverse_head;
    for (int k = 1; k < n; ++k) {
        long long sum = 0;   // a[1] b[k-1] + ... + a[k] b[0]
        for (int i = 1; i <= k; ++i) {
            sum = (sum + a[i] * b[k - i]) % mod;
        }
        b[k] = (mod - sum) % mod * inverse_head % mod;
    }
    for (int k = 0; k < n; ++k) {
        std::printf("%lld%c", b[k], k + 1 < n ? ' ' : '\n');
    }
    return 0;
}
```

a₀ 的逆元用费马小定理 a^(p − 2) 求，见第 19 章《把很多关系放进一张数表》。两层循环约 n²/2 次，n = 5000 时约 1.25 × 10⁷ 次。n 再大时，可以用第 20 章《一批系数可以一起算》的快乘配合“每次把已知的项数翻倍”的牛顿迭代，降到 O(n log n)；那是一个改进，规则还是这里的规则。

对拍的慢办法就用牛顿迭代：已知前 m 项的倒数 B，那么 B × (2 − A × B) 是前 2m 项的倒数，乘法照定义双重循环。它和程序 A 的递推不同，结果应当一样。

## 由点值还原，必须先知道次数

1² + 2² + …… + n² 对 n = 0、1、2、3、4、5 依次是 0、1、5、14、30、55。它是 n 的三次多项式：n(n + 1)(2n + 1)/6。一般地，1^k + 2^k + …… + n^k 是 n 的 k + 1 次多项式：它每往后一项增加 (n + 1)^k，是 k 次多项式，而“相邻两项之差是 d 次多项式”的序列本身是 d + 1 次多项式。

知道次数是 d，就可以用 d + 1 个点的值还原：

P(t) = Σ P(j) × Π (t − m)/(j − m)，j 取遍 0 到 d，乘积取遍 m ≠ j。

对每个 j，右边的乘积在 t = j 时是 1，在其他取样点是 0，所以两边在 d + 1 个点上都相等；两个次数不超过 d 的多项式在 d + 1 个点相等，就完全相同。这叫**拉格朗日插值**。

次数必须先知道，而且要有证明。三个点 (0, 0)、(1, 1)、(2, 2) 可以由 P(t) = t 给出，也可以由 t + t(t − 1)(t − 2) 给出，后者在 t = 3 时是 9。只看前几个值就说“这是一个二次式”，可能说错。

**片段：**

```cpp
// 位于 main 内；用到程序 A 的 mod 和 power_mod；求 1^k + ... + big^k 对 mod 取余
int points = k + 2;                         // 次数是 k + 1，要 k + 2 个点
std::vector<long long> value(points, 0);    // value[x] = 1^k + ... + x^k
for (int x = 1; x < points; ++x) {
    value[x] = (value[x - 1] + power_mod(x, k)) % mod;
}
long long answer = 0;
if (big < points) {
    answer = value[big];
} else {
    long long t = big % mod;
    for (int j = 0; j < points; ++j) {
        long long top = 1;
        long long bottom = 1;
        for (int m = 0; m < points; ++m) {
            if (m != j) {
                top = top * ((t - m + mod) % mod) % mod;
                bottom = bottom * ((j - m + mod) % mod) % mod;
            }
        }
        answer = (answer + value[j] * top % mod * power_mod(bottom, mod - 2)) % mod;
    }
}
std::printf("%lld\n", answer);
```

k ≤ 1000 时约 10⁶ 次乘法，big 可以到 10¹⁸。模 p 下插值要求 j − m 都可逆，k + 1 小于 p 时成立。

## 集合、偏序与排列也有代数

生成函数的乘法对应“把两份东西拼在一起”。拼法不同，乘法也不同。

物品有编号时，把 n 个有编号的物品分成前后两份，要挑哪些编号进第一份，有 C(n, i) 种。这时用 a_n / n! 作系数，叫**指数生成函数**。两个指数生成函数相乘，xⁿ/n! 的系数正好是 Σ C(n, i) × a_i × b_(n − i)。例子：每份可以是任意集合，a_n = 1，生成函数是 1 + x + x²/2! + ……，记作 eˣ。两份相乘是 e^(2x)，xⁿ/n! 的系数是 2ⁿ：每个物品去第一份或第二份。

错排（没有一个人拿到自己的卡片）的指数生成函数是 e^(−x) ÷ (1 − x)：一个排列是“不动点的集合”拼上“一个错排”，所以 eˣ × D(x) = 1 ÷ (1 − x)。展开得 D₄ = 4! × (1 − 1 + 1/2 − 1/6 + 1/24) = 9。

在集合上，第 20 章的子集和与它的逆，第 17 章的容斥，第 18 章对约数的默比乌斯函数，都是同一个模式：在一个**偏序**（某些对象之间有“在下面”的关系）上，对“下面所有的”求和，再用一个带正负号的函数反过来。不同的偏序有不同的反演函数。

## 整数坐标不是实数坐标缩小版

付 n 元、只有 2 元和 3 元硬币，就是数 2x + 3y = n 的非负整数解。直线 2x + 3y = n 在第一象限的那一段，长度和 n 成正比，于是有人以为解的个数大约是 n/6，而且是个一次多项式。停笔 1 算出的却是 1、0、1、1、1、1、2、1、2、2、2、2、3：它确实大约是 n/6，可是每 6 个一组有起伏，不是任何一个多项式。它是一个**拟多项式**：按 n 除以 6 的余数分成六类，每一类各是一个一次多项式。

另一个例子：x + y ≤ n 的非负整数点，个数是 (n + 1)(n + 2)/2，而那个三角形的面积是 n²/2。领头的一项对上了，后面的 3n/2 + 1 是边上和角上的格点带来的。实数的面积只告诉我们“大约多少”，整数点的个数还和边界、和斜率的分母有关。

所以，用插值求一个格点计数之前，要先证明它是多项式，或者知道它的周期，按余数分开插值。顶点都是整点的多边形放大 n 倍，内部和边上的整点个数确实是 n 的多项式；顶点只是有理点时，就只能保证拟多项式。前一句的二维情形，第 24 章《图形的方向也能算出来》会用一份“面积账”说明。

**停笔 6**　数 x + 2y ≤ n 的非负整数点，n = 0 到 5。它是不是 n 的多项式？按 n 的奇偶分开看呢？

这一章先问“允许怎样算”。生成函数的乘法是卷积，无穷长也只用到有限项；截断到 xⁿ 以后，加减乘仍然一致，常数项可逆时还能除；点值还原要先知道次数；有编号的物品、偏序上的反演，各有自己的乘法；整数点的个数可能只是拟多项式。能对一个计数问题写出它的生成函数，并说清每一步运算为什么允许，再读下一章。下一章算的是平均：每种情况发生的机会不一样时，平均该怎样算。
