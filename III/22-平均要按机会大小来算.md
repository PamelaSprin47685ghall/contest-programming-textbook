# 22　平均要按机会大小来算

一枚公平硬币正面得 2 分，反面得 0 分，平均每次 1 分。换成正面机会只有四分之一，平均就变为半分，不是两个可能值简单相加除二。

## 先列事件，再给机会

概率在 0 到 1 之间，互斥且覆盖全部可能的结果，其概率和为 1。随机变量给每个结果一个数，期望是“数值乘机会”的和。

A、B 独立指 `P(A且B)=P(A)*P(B)`。条件概率 `P(A|B)=P(A且B)/P(B)`，要求 B 概率非零。已经知道抽到红球后，再谈原来所有球等可能，就换错了样本空间。

期望有线性：`E(X+Y)=E(X)+E(Y)`，**不要求独立**。令每个满足条件的位置贡献 0 或 1，期望总数就是各位置成立概率之和，常比枚举全部作品方便。方差衡量波动，`Var(X)=E(X²)-E(X)²`；相加时能不能直接加方差，则需要不相关等额外条件。

**停笔 1**　X 是公平硬币正面指示，Y=X。X、Y 独立吗？`E(X+Y)` 仍等于两份期望之和吗？

## 沿无圈地图往回算

每个非终点等概率选一条出边走一步，没有出边就停止。DAG 上从后往前算：终点期望为零，其他点为 `1+所有后继期望的平均`。重边代表两张不同的等概率选择票，即使去同一点也各占一次机会。

**完整程序：**输入 `1 <= n <= 2000`、`0 <= m <= 10000` 和 m 条有向边，点从 0 编号。DAG 时输出从 0 到停止的期望步数，十位小数；存在圈输出 `CYCLE`，不把含圈问题冒充本算法可解。输入通常保证 DAG，圈输出用于识别不适用情况。

```cpp
#include <cstdio>
#include <queue>
#include <vector>

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2 || n < 1 || n > 2000 || m < 0 || m > 10000) { return 1; }
    std::vector<std::vector<int>> graph(n);
    std::vector<int> indegree(n, 0), order;
    for (int i = 0; i < m; ++i) {
        int u = 0;
        int v = 0;
        if (std::scanf("%d%d", &u, &v) != 2 || u < 0 || u >= n || v < 0 || v >= n) { return 1; }
        graph[u].emplace_back(v);
        ++indegree[v];
    }
    std::queue<int> ready;
    for (int u = 0; u < n; ++u) { if (indegree[u] == 0) { ready.emplace(u); } }
    while (!ready.empty()) {
        int u = ready.front();
        ready.pop();
        order.emplace_back(u);
        for (int v : graph[u]) { if (--indegree[v] == 0) { ready.emplace(v); } }
    }
    if (static_cast<int>(order.size()) != n) { std::printf("CYCLE\n"); return 0; }
    std::vector<long double> expected(n, 0);
    for (int i = n - 1; i >= 0; --i) {
        int u = order[i];
        if (!graph[u].empty()) {
            long double sum = 0;
            for (int v : graph[u]) { sum += expected[v]; }
            expected[u] = 1 + sum / graph[u].size();
        }
    }
    std::printf("%.10Lf\n", expected[0]);
    return 0;
}
```

输入：

```text
3 3
0 1
0 2
1 2
```

输出：

```text
1.5000000000
```

时间、空间 `O(n+m)`。最长走 n−1 步，期望也在此范围，浮点输出仍是近似值。含圈时应先分析能否以概率 1 停止及期望是否有限，再用第 8 章方程或适合的迭代，不是把程序多跑几遍就会自动补上循环贡献。

## 从数据推测时，别忘掉波动

样本平均估计真实均值，样本量增加通常减小随机波动，但需要合适抽样条件。Chebyshev 不等式用方差控制偏离均值的概率；Markov 不等式只需变量非负，就有 `P(X>=t) <= E(X)/t`。这给上界，不是说真实分布正好等于上界。

也可先用期望证明某作品存在：随机涂色平均满足多少条件，至少有一份不低于平均。要真找出作品，再用随机尝试及成功概率，或条件期望法。证明“有”与实际构造“哪一个”，是两项工作。
