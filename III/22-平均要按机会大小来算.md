# 22　平均要按机会大小来算

抽奖箱里有 9 张写着 1 元的券和 1 张写着 100 元的券。有人说：“只有两种奖，平均 (1 + 100) ÷ 2，五十多元。”可是十个人抽，九个人拿 1 元，一个人拿 100 元，平均每人 (9 × 1 + 1 × 100) ÷ 10 = 10.9 元。平均不能按“有几种结果”来算，要按“每种结果的机会有多大”来算。

这一章先把“列出事件、给出机会”说清，再看一种常见的算法：沿着一张没有圈的状态图，从结尾往回算平均值。最后一节离开计算，说说从实验数据推测概率时，结果会有多大的波动。

## 先列事件，再给机会

做一次随机试验，所有可能的结果放在一起叫**样本空间**；其中的一部分结果叫一个**事件**（概率里的事件，和扫描线停下来处理的“事件”不是一回事）；每个结果有一个非负的**概率**，全部加起来是 1。掷一颗均匀的骰子，样本空间是 1 到 6，每个结果的概率是 1/6；“掷出偶数”是事件 {2, 4, 6}，概率 1/2。

给每个结果一个数，比如抽到的钱数，这个数叫**随机变量**。它的**期望**是“每个结果的数乘以它的概率”之和，也就是开头的 10.9 元。

期望最有用的一条性质是**期望的线性**：两个随机变量之和的期望，等于各自期望之和。这一条不要求两者独立。例子：n 个人各写一张名字卡，打乱后每人随机拿一张，平均有几个人拿到自己的卡？第 i 个人拿到自己的卡的概率是 1/n。记“第 i 人拿到自己的”为 1、否则为 0，总人数是这 n 个 0、1 之和，期望是 n × 1/n = 1。这些事件互相牵连（前面的人拿走了谁的卡，会影响后面的人），可期望的线性照样成立，所以不用管它们怎样牵连。

## 沿无圈地图往回算

很多随机过程是一步步走的：每走一步，处在某个状态；下一步去哪个状态，只看当前状态和这一步的随机结果。要是状态之间的箭头不会绕回来，就可以从最后的状态开始，往回算“从这个状态出发，最终的期望是多少”，就像[第二卷第 11 章](../II/11-等前面的事做完再开始.md)那样，按依赖的反方向排好次序。

### 奶牛训练营

一道题有 T 个测试点（2 ≤ T ≤ 1000），第 1 个是样例。最终得分是最后一次提交通过的测试点数。Bessie 反复提交同一个程序：样例一定通过；其余每个测试点，每次提交时各自独立地以 1/2 的概率通过。她最多提交 K 次（1 ≤ K ≤ 10⁹），每次看到得分以后，可以决定停下或者再交。问按最好的策略，最终得分的期望最大是多少。

输入一行 T 和 K。输出期望值，与正确答案的误差不超过 10⁻⁶ 即可。

样例输入：

```text
2 3
```

样例输出：

```text
1.875
```

除样例外只有 1 个测试点。只要还没拿到 2 分就再交：三次都没过的概率是 1/8，得 1 分；否则得 2 分。期望 1/8 × 1 + 7/8 × 2 = 1.875。这是 USACO 2022 年 2 月金组第二题[“奶牛训练营”](../USACO/金组/2021_2022/2022.02/P2.md)。

样例那一分总能拿到，先放到一边。设 n = T − 1，一次提交恰好通过 i 个测试点的概率是 p_i = C(n, i) ÷ 2ⁿ。状态是“还剩几次提交机会”。记 E_x 为还剩 x 次机会、按最好的策略时的期望得分（不含样例），E₁ = n/2。还剩 x + 1 次时，先交一次，看到得分 i：停下拿 i，或者继续，期望 E_x。最好的选择是两者中大的那个，所以

E_(x + 1) = Σ p_i × max(i, E_x)，i 从 0 到 n。

答案是 1 + E_K。状态图是 E₁ → E₂ → …… → E_K 一条链，没有圈。

样例里 n = 1，p₀ = p₁ = 1/2。E₁ = 0.5，E₂ = ½ × 0.5 + ½ × 1 = 0.75，E₃ = ½ × 0.75 + ½ × 1 = 0.875，加 1 得 1.875。

K 到 10⁹，一步步算来不及。看 max(i, E_x)：设 f 是 E_x 的整数部分，i ≤ f 时取 E_x，i > f 时取 i。f 不变时，这一步是一个固定的一次函数：

E_(x + 1) = (1 − D) × E_x + G，D 是 i > f 的 p_i 之和（看到这些分数就停下），G 是 i > f 的 i × p_i 之和。

E_x 不会超过 n，所以 f 至多变化 n 次。f 不变的那一段，要连着做很多次同一个一次函数。两个这样的函数接起来还是这样的函数：先 (D₁, G₁) 再 (D₂, G₂)，得到 (1 − (1 − D₁)(1 − D₂), (1 − D₂) × G₁ + G₂)。于是可以照[第二卷第 7 章](../II/07-把一大步拆成几小步.md)“连走很多次，也能提前准备”的办法，先准备走 1、2、4、8、…… 步的函数，再从大到小试：走这么多步以后 E 仍然小于 f + 1，又没超过剩下的次数，就走；最后再走一步，E 跨过 f + 1，进入下一段。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

int main() {
    int t = 0;
    long long k = 0;
    if (std::scanf("%d%lld", &t, &k) != 2) {
        return 1;
    }
    int n = t - 1;   // 样例那一分最后再加
    // chance[i]：一次提交恰好通过 i 个测试点的概率，逐个测试点按“过或不过各一半”加进来
    std::vector<double> chance(n + 1, 0.0);
    chance[0] = 1.0;
    for (int test = 1; test <= n; ++test) {
        for (int i = test; i >= 1; --i) {
            chance[i] = (chance[i] + chance[i - 1]) / 2;
        }
        chance[0] /= 2;
    }
    double expected = n / 2.0;   // 还剩 1 次机会
    long long left = k - 1;
    while (left > 0) {
        int f = static_cast<int>(expected);
        if (f >= n) {
            break;               // 已经是满分，再交也不会更多
        }
        // 一步：E 变成 E - leave * E + gain。leave 是得分超过 f、选择停下的概率，
        // gain 是这部分的期望得分。leave 可能极小，直接存它，不存 1 - leave
        double leave = 0.0;
        double gain = 0.0;
        for (int i = f + 1; i <= n; ++i) {
            leave += chance[i];
            gain += i * chance[i];
        }
        // jump_leave[j]、jump_gain[j]：连走 2^j 步合成的一步
        std::vector<double> jump_leave(1, leave);
        std::vector<double> jump_gain(1, gain);
        while ((1LL << jump_leave.size()) <= left) {
            double d = jump_leave.back();
            double g = jump_gain.back();
            jump_leave.push_back(d + d - d * d);   // 1 - (1 - d)(1 - d)
            jump_gain.push_back(g - d * g + g);    // (1 - d) g + g
        }
        for (int j = static_cast<int>(jump_leave.size()) - 1; j >= 0; --j) {
            double next = expected - jump_leave[j] * expected + jump_gain[j];
            if ((1LL << j) <= left && next < f + 1) {
                expected = next;
                left -= 1LL << j;
            }
        }
        if (left > 0) {          // 再走一步，跨进下一段
            expected = expected - leave * expected + gain;
            --left;
        }
    }
    std::printf("%.12g\n", expected + 1);
    return 0;
}
```

二进制位的写法 `1LL << j`（2 的 j 次方）见[第二卷第 2 章](../II/02-把选择走成一棵树.md)，`1LL` 让它按 `long long` 算，j 到 30 也不溢出。

p_i 不用阶乘：每加进一个测试点，“恰好过 i 个”要么是前面过了 i 个、这个没过，要么是前面过了 i − 1 个、这个过了，各占一半。这样所有数都在 0 和 1 之间，不会溢出。

程序存的是 D，不是 1 − D。f 接近 n 时，D 小到 10⁻³⁰⁰ 这样的量级，1 − D 在 `double` 里就是 1，信息全丢了；可 D 自己是能存下的。合成时写成 D₁ + D₂ − D₁ × D₂，每一项都是小数之间的运算，不会把它们和 1 相减。要是改存 1 − D，T = 1000、K = 10⁹ 时第四位小数就会错，相对误差约 3 × 10⁻⁷，虽然还在题目允许的范围里，但离边界不远。

为什么从大到小试就对：在一段里，E 随步数增加而增加（每步至少不变，因为 max(i, E) ≥ E），所以“走 s 步后仍小于 f + 1”的 s 是从 0 开始的一段。从大到小试，就是在这一段里二分找最长的 s，和第二卷第 7 章的倍增找法一样。最后一步把 E 推到不小于 f + 1。段数不超过 n，每段 O(n + log K)。

对拍的慢办法照递推式一步步算，K 不超过 60，用分数精确计算，再和程序 A 的输出比较前 6 位小数。

## 从数据推测时，别忘掉波动

有时我们不会算概率，就做实验：让程序随机模拟一万次，数事件发生了几次。得到的频率不是概率本身，它会上下波动。

一次试验成功的概率是 p，独立做 m 次，成功次数的期望是 m × p，**方差**（离期望的平方距离的平均）是 m × p × (1 − p)。频率 = 次数 ÷ m，它的方差是 p(1 − p)/m，**标准差**是它的平方根。p = 1/2、m = 10000 时，标准差是 0.005。**切比雪夫不等式**说：离期望超过 c 个标准差的机会不超过 1/c²。所以频率和真实的 p 差 0.02（4 个标准差）以上的机会不超过 1/16；实际上远比这小，但切比雪夫不需要任何别的假设。

这对检查程序也有用。用模拟去核对“奶牛训练营”的答案，模拟一万次，平均得分和程序 A 的输出差了 0.003，不能说明程序 A 错了；差了 0.3，就该怀疑。

**片段：**

```cpp
// 位于 main 内；n、k 已读入，threshold[x] 是“还剩 x 次机会时，得分不超过它就再交”的界
std::mt19937 engine(12345);
std::uniform_int_distribution<int> coin(0, 1);
const int rounds = 10000;
double total = 0.0;
for (int r = 0; r < rounds; ++r) {
    int score = 0;
    for (long long x = k; x >= 1; --x) {
        score = 0;
        for (int test = 0; test < n; ++test) {
            score += coin(engine);
        }
        if (x == 1 || score > threshold[x - 1]) {
            break;   // 停下，保留这次的分数
        }
    }
    total += score + 1;
}
std::printf("%.4f\n", total / rounds);
```

种子固定成 12345，每次运行结果相同，方便复查；`<random>` 的这些工具在第 16 章《允许碰运气也要算清风险》介绍过。`threshold[x − 1]` 是 E_(x − 1) 的整数部分：还剩 x − 1 次时，得分不超过它就值得再交。

**停笔 4**　T = 101、K = 1 时，一次提交的得分是 1 加上 100 个各一半机会的 0 或 1。模拟一万次求平均，标准差大约是多少？平均值落在 50.9 到 51.1 之外的机会，切比雪夫不等式能保证不超过多少？

这一章的平均都按机会大小来算。期望的线性让互相牵连的事件也能直接相加；“奶牛训练营”沿着一条链从后往前算，阈值不变的一大段用一次函数的倍增跳过；实验得到的频率有波动，标准差告诉我们差多少才值得怀疑。能对一个随机过程列出状态、写出“从这里出发的期望”的递推，并说清状态图里没有圈，再读下一章。下一章换一种对手：不是随机的硬币，而是会动脑筋的另一位玩家。

## 核对

1. 六种拿法里，拿到自己卡的人数依次是 3（全对）、1、1、1、0、0，和是 6，平均 1。恰好 0 人的有 2 种，概率 1/3。
2. p 依次是 1/8、3/8、3/8、1/8。E₁ = 1.5。E₂ = 1/8 × 1.5 + 3/8 × 1.5 + 3/8 × 2 + 1/8 × 3 = 1.875，答案 2.875。第一次得分（不含样例）是 0 或 1 时再交，因为它们小于 E₁ = 1.5。
3. E 超过 f + 1 以后，得分恰好是 f + 1（以及更高、但仍不超过新 E 的整数）时，旧的 `leave` 和 `gain` 仍让她停下拿这个分数，可这时继续交的期望 E 更大。每一步都把 max(i, E) 换成了较小的 i，算出的期望偏小。
4. 得分的方差是 100 × 1/4 = 25，平均值的方差是 25/10000，标准差 0.05。50.9 到 51.1 是期望 51 两边各 2 个标准差，切比雪夫保证落在外面的机会不超过 1/4。
