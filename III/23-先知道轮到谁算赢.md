# 23　先知道轮到谁算赢

小时候常玩“抢三十”：两人轮流报数，从 1 开始往上数，每次报一个或两个连着的数，谁报到 30 谁赢。玩过几回就会发现，后手只要每次都让自己报到 3 的倍数，先手就怎么也赢不了。这里没有运气，也不靠对手犯错：胜负在第一步之前就定了，只是要先弄清“轮到谁时，哪种局面算赢”。

这一章把这种推理写成算法。先给每个局面标上胜负，再看几个游戏摆在一起时怎样合起来算，最后用一道题说明：从小数据里找到的规律，要证明它不会在大数据里变样。

## 状态先分胜负

这一章的游戏都是两人轮流走，局面全公开，没有运气，总步数有上限。把局面连同“轮到谁”叫作一个状态。没有合法走法的状态叫**终止状态**；在本章的游戏里，轮到的人在终止状态就输。

一个状态叫**必胜状态**，是说轮到的人有办法保证赢；叫**必败状态**，是说不论他怎么走，对手都有办法赢。判定只有两句：

- 能走到某个必败状态，就是必胜状态；
- 所有走法都走到必胜状态（包括无路可走），就是必败状态。

总步数有上限，所以状态之间的箭头不会绕回来，可以从终止状态往回推，每个状态恰好得到一个标签。“抢三十”换成“还差几个数到 30”：差 0 个时对手刚报到 30，轮到的人已经输了，是必败；差 1、2 个时能一口报完，是必胜；差 3 个时，报一个剩 2，报两个剩 1，都把必胜留给对手，是必败。往上推，差的个数是 3 的倍数时必败，否则必胜。开局差 30 个，所以先手输。

两人的目标不同时，也可以用同样的办法：一方需要“存在一种走法”行得通，另一方需要“所有走法”都行得通。下面这道题就是这样。

### 例题　奶牛跑步

圆形跑道一圈长 M，奶牛从起点出发，总路程记为 R，开始时 R = 0。游戏有 N 轮，每轮有 8 张写着数的牌。约翰先在上面 4 张和下面 4 张里选一半，贝茜再从这 4 张里选上面 2 张或下面 2 张。设这两张自上而下是 t 和 b：奶牛先跑 R × t，再跑 b，R 也跟着加上这两段。N 轮以后，奶牛离起点（沿跑道两个方向中较近的那一个）不超过 K 才回得了家。题目保证约翰应对得当时，不论贝茜怎么选都回得了家。

输入第一行是 N、M、K（N ≤ 14，M ≤ 10⁹，K ≤ ⌊M/2⌋）；第二行是一个长 N 的串，第 i 个字符是贝茜第 i 轮实际选的一半，`T` 表示上面，`B` 表示下面；接下来 N 行，每行自上而下 8 个小于 M 的数。输出一个长 N 的串：每一轮约翰该选哪一半，要求选了以后，不论贝茜从这一轮起怎么选，他都还能让奶牛回家；有几种都可以时，输出字典序最小的串。

样例输入：

```text
2 2 0
TT
1 0 0 0 0 0 0 1
0 1 1 1 0 0 1 0
```

样例输出：

```text
TB
```

只关心位置，把 R 对 M 取余记作 x，一轮之后它变成 (x × (t + 1) + b) mod M。样例 M = 2、K = 0，要正好回到起点。第一轮约翰要是选下面一半 0 0 0 1，贝茜选“0 1”，x 变成 1。第二轮从 x = 1 出发，上面一半有“1 1”，x 变成 (1 × 2 + 1) mod 2 = 1；下面一半有“0 0”，x 还是 1；两种选法都会被贝茜拖住。所以第一轮只能选 `T`：这一半是 1 0 0 0，两种“2 张”都让 x 仍为 0。贝茜实际选了 `T`，x = 0。第二轮选下面一半 0 0 1 0，“0 0”和“1 0”都让 x 留在 0，可以选 `B`，答案是 `TB`。

这是 USACO 2012 年 1 月金组第二题[“奶牛跑步”](../USACO/金组/2011_2012/2012.01/P2.md)。

状态是“第几轮开始、位置 x、轮到约翰”。约翰的状态可行，要求他的两种选择**至少一种**可行；他选定一半以后，轮到贝茜，这个状态可行要求贝茜的两种选择**都**可行。第 N 轮结束时，看 x ≤ K 或 x ≥ M − K。按字典序，`B` 比 `T` 小：每一轮先问“选下面一半以后还可行吗”，可行就选 `B`，否则选 `T`；再按贝茜实际的选择算出新的 x，进入下一轮。

x 可以取到 10⁹ 种值，没法照[第二卷第 8 章](../II/08-给已经解决的小问题留个位置.md)的办法给每个状态留一个格子，只能沿着游戏树往下搜。整棵树每轮分叉 4 次，最后一层有 4¹⁴ ≈ 2.7 × 10⁸ 个叶子。好在“至少一种”遇到一个可行就不必再试另一种，“都可行”遇到一个不可行也不必再试，这就是[第一卷第 3 章](../I/03-让规则决定下一步.md)讲过的短路。数据要是专门让先试的那一支总派不上用场，短路就省不了多少；每个节点用随机数决定先试哪一支，这种布置就失效了。随机只改变先后，不改变答案，参看[第 16 章](16-允许碰运气也要算清风险.md)。

**片段：**

```cpp
// 位于 main 之前；n、m、k 和 card[i][j]（第 i 轮自上而下第 j 张牌）是读入的全局变量
std::mt19937 coin(20120102);

// 第 round 轮从位置 x 出发，约翰选 half（0 上 1 下），贝茜选 pair（0 上 1 下）
long long step(int round, long long x, int half, int pair) {
    long long t = card[round][half * 4 + pair * 2];
    long long b = card[round][half * 4 + pair * 2 + 1];
    return (x * (t + 1) + b) % m;
}

bool john_ok(int round, long long x);

// 约翰已选 half，轮到贝茜：她的两种选择都要可行
bool bessie_ok(int round, long long x, int half) {
    int first = static_cast<int>(coin() & 1);
    for (int j = 0; j < 2; ++j) {
        int pair = first ^ j;
        if (!john_ok(round + 1, step(round, x, half, pair))) {
            return false;
        }
    }
    return true;
}

// 轮到约翰：两种选择至少一种可行
bool john_ok(int round, long long x) {
    if (round == n) {
        return x <= k || x >= m - k;
    }
    int first = static_cast<int>(coin() & 1);
    for (int j = 0; j < 2; ++j) {
        if (bessie_ok(round, x, first ^ j)) {
            return true;
        }
    }
    return false;
}
```

`first ^ j` 依次取 first 和另一个数，异或见[第二卷第 2 章](../II/02-把选择走成一棵树.md)；`std::mt19937` 要 `#include <random>`。`main` 从 x = 0 开始，每轮 `bessie_ok(i, x, 1)` 成立就输出 `B`，否则输出 `T`，再按贝茜实际的选择用 `step` 更新 x。乘积不超过 10⁹ × 10⁹ = 10¹⁸，`long long` 放得下。

## 最小没出现的数

很多游戏是几个小游戏摆在一起：每一步挑其中一个小游戏走一步，轮到时所有小游戏都走不动的人输。这叫小游戏的**和**。两堆一样多的石子，每次从一堆里取走任意颗：每堆单独看都是必胜，合起来后手却能照着先手在另一堆取同样多，先手必败。只知道胜败合不起来，要给每个状态一个更细的数。

一组非负整数里，最小的、没出现的非负整数记作 **mex**。mex{0, 1, 3} = 2，mex{1, 2} = 0，mex{} = 0。给每个状态定一个 **SG 值**：终止状态的 SG 值是 0；其他状态的 SG 值，是它一步能到的所有状态的 SG 值的 mex。

SG 值是 0 的状态，一步走不到 SG 值为 0 的状态；SG 值不是 0 的状态，一步能走到 SG 值为 0 的状态。这正是必败、必胜的两句判定，所以 SG 值为 0 恰好就是必败。

**片段：**

```cpp
// 位于 main 内：一堆 v 颗石子，每次取走 1、3 或 4 颗，sg[v] 是它的 SG 值
const int limit = 20;
const int take[3] = {1, 3, 4};
std::vector<int> sg(limit + 1, 0);
for (int v = 1; v <= limit; ++v) {
    std::vector<char> seen(5, 0);      // 至多 3 种走法，mex 不超过 3
    for (int j = 0; j < 3; ++j) {
        if (take[j] <= v) {
            seen[sg[v - take[j]]] = 1;
        }
    }
    int mex = 0;
    while (seen[mex] != 0) {
        ++mex;
    }
    sg[v] = mex;
}
```

至多 3 种走法，mex 不超过 3，`seen` 开 5 格不会越界。v 从 0 到 13 的 SG 值是 0、1、0、1、2、3、2、0、1、0、1、2、3、2，从 v = 7 起重复前 7 个。

## Nim 的石子数恰好就是 SG

**Nim** 是这样的游戏：几堆石子，每次从一堆里取走任意正数颗，轮到时没有石子的人输。只有一堆 a 颗时，一步能走到 0 到 a − 1 颗，按归纳，它们的 SG 值就是 0 到 a − 1，mex 是 a。一堆石子的 SG 值恰好就是它的石子数。

几堆合起来的规律是：Nim 的状态必败，当且仅当各堆石子数的**异或**是 0。证明分两步，对应两句判定。

- 异或是 0 时，任取一堆，把 a 改成更小的 a′，a′ 和 a 在二进制下至少有一位不同，总的异或这一位就从 0 变成 1，不再是 0。所以从异或为 0 的状态出发，走不到异或为 0 的状态。
- 异或 s 不是 0 时，看 s 的最高位，总有一堆在这一位是 1，设它有 a 颗。a ^ s 在这一位变成 0，更高的位和 a 一样，所以 a ^ s < a，可以把这一堆取到 a ^ s 颗。取完以后总的异或是 s ^ a ^ (a ^ s) = 0。

无路可走的状态各堆都是 0，异或是 0。于是“异或为 0”这一族状态满足必败状态的两句判定。

把 Nim 的证明里“一堆的石子数”换成“一个小游戏的 SG 值”，几乎一字不改，就得到更一般的结论：一个状态的 SG 值是 g，就能走到 SG 值为 0 到 g − 1 的任何一个，像一堆 g 颗的石子；它也许还能走到 SG 值比 g 大的状态，但对手总能再走回 SG 值为 g 的状态，这种走法不会改变胜负。所以若干小游戏的和，SG 值是各个小游戏 SG 值的异或，这叫 **Sprague–Grundy 定理**。照这个定理，两堆“取 1、3、4 颗”的石子合成的游戏，必败当且仅当两堆的 SG 值相等。

**片段：**

```cpp
// 位于 main 内：pile 里是 Nim 各堆的石子数，找出一步必胜的走法
int total = 0;
for (int a : pile) {
    total ^= a;
}
if (total == 0) {
    std::printf("lose\n");
} else {
    for (std::size_t i = 0; i < pile.size(); ++i) {
        int target = pile[i] ^ total;
        if (target < pile[i]) {
            std::printf("take %d from pile %zu\n", pile[i] - target, i + 1);
            break;
        }
    }
}
```

`for (int a : pile)` 依次取出 `pile` 的每个元素；`%zu` 打印 `std::size_t`。证明里说过，总有一堆满足 `target < pile[i]`，所以异或不为 0 时一定会打印一步。

## 找规律以后，还要证明不会换样

SG 值常常有周期，“取 1、3、4 颗”就是每 7 个一循环。可是前几十项看出的规律只是猜，尤其可取的数和素数有关时，猜完一定要证明。

### 例题　环形谷仓

N 个房间围成一圈，第 i 个房间有 a_i 头牛。约翰和 Nhoj 一起从 1 号房间开始，每进一个房间，约翰先走一步，Nhoj 再走一步，然后两人一起走到下一个房间，N 号房间之后回到 1 号。轮到某人时，房间里没有牛，他就输了；否则他从这个房间赶走 P 头牛，P 是 1，或者是不超过当前牛数的一个素数。双方都走最好的一步，问谁赢。

输入第一行是数据组数 T（T ≤ 1000）。每组先是 N，再是 a_1 到 a_N（N ≤ 10⁵，所有组的 N 之和不超过 2 × 10⁵，1 ≤ a_i ≤ 5 × 10⁶）。每组输出一行 `Farmer John` 或 `Farmer Nhoj`。

样例输入：

```text
5
1
4
1
9
2
2 3
2
7 10
3
4 9 4
```

样例输出：

```text
Farmer Nhoj
Farmer John
Farmer John
Farmer John
Farmer Nhoj
```

第一组只有 4 头牛。约翰赶走 1、2 或 3 头，Nhoj 都能一口赶完剩下的，下一轮约翰面对空房间。第二组 9 头牛，约翰赶走 5 头，剩下 4 头，轮到 Nhoj 面对第一组的局面，约翰赢。

这是 USACO 2022 年 12 月银组第二题[“环形谷仓”](../USACO/银组/2022_2023/2022.12/P2.md)。

先只看一个房间，问轮到的人胜还是败。用小数据推：0 头败；1、2、3 头一口赶完，胜；4 头只能留下 3、2、1 头，败；5 头赶走 1 头，胜。往下排，前几十项里败的恰好是 4 的倍数。这是猜，下面证明它不会换样。可取的数是 1、2 和奇素数，没有一个是 4 的倍数，所以从 4 的倍数出发，一步走不到 4 的倍数。牛数 v 除以 4 余 1、2、3 时，分别赶走 1、2、3 头（都不超过 v），就留下 4 的倍数。两句判定都满足，规律对一切 v 成立。

可是这些房间是交替走的，一个房间的胜负还不是全局的胜负。每个房间都由约翰先走，所以对每个房间，赢家早已确定：牛数是 4 的倍数时，约翰终将在这里面对空房间；否则 Nhoj 终将如此。游戏在第一次有人面对空房间时结束。赢家想让自己赢的房间早点空，输家想让它晚点空，于是要算清：双方都这样较劲时，这个房间要走多少步才空，记作 f(v)。

- 从 4 的倍数开始、轮到输家：他每次只赶走 2 头，留下除以 4 余 2 的数；赢家要再留下 4 的倍数，只能赶走除以 4 余 2 的可取数，这样的数只有 2。于是每步 2 头，房间拖到最长；输家赶走别的数，只会给赢家一口赶走更多的机会。剩 w 头时还要走 w ÷ 2 步。
- v 是偶数：是 4 的倍数时就是上一条；余 2 时轮到的是赢家，他只能赶走 2 头，接着又是上一条。f(v) = v ÷ 2。
- v 是奇数：轮到的人是赢家，第一步赶走一个和 v 除以 4 余数相同的可取数 p，剩下 v − p 是 4 的倍数，以后按第一条再走 (v − p) ÷ 2 步。赢家想快，p 取满足条件的最大可取数。f(v) = 1 + (v − p) ÷ 2。

f 是奇数时，最后一步是约翰走的，Nhoj 在同一次进门时面对空房间；f 是偶数时，约翰在下一次进门时面对空房间。两种情况都在第 ⌊f/2⌋ + 1 次进这个房间时结束。

最先结束的房间决定胜负：每个房间的赢家能保证对手最迟在第 ⌊f/2⌋ + 1 次进门时在这里面对空房间，输家能保证自己不会更早在这里面对空房间。所以取 ⌊f/2⌋ 最小的房间，一样小时取编号最小的，因为同一圈里编号小的先进门。它的 f 是奇数，约翰赢，否则 Nhoj 赢。

样例第五组，三个房间 4、9、4 的 f 是 2、3、2，⌊f/2⌋ 都是 1，取 1 号房间，f = 2 是偶数，Nhoj 赢。

f(v) 要用到“不超过 v、除以 4 余数和 v 相同的最大可取数”。按[第二卷第 19 章](../II/19-整数身上也有线索.md)的筛法从小到大找素数，同时记下余 1、余 3 两类里最近见到的那一个，就能边筛边算出所有 f(v)。余 1 那一类把 1 也算进去：v = 1 时只能取 1，f(1) = 1。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

int main() {
    const int max_cows = 5000000;
    // moves[v]：一个有 v 头牛的房间，双方较劲时走几步才空
    std::vector<int> moves(max_cows + 1, 0);
    std::vector<char> composite(max_cows + 1, 0);
    // biggest[r]：已经见过的、除以 4 余 r 的最大可取数，1 也算可取数
    int biggest[4] = {0, 1, 0, 0};
    moves[1] = 1;
    for (int v = 2; v <= max_cows; ++v) {
        if (composite[v] == 0) {           // 比 v 小的素数都已划过，v 是素数
            biggest[v % 4] = v;
            for (long long j = 1LL * v * v; j <= max_cows; j += v) {
                composite[j] = 1;
            }
        }
        if (v % 2 == 0) {
            moves[v] = v / 2;
        } else {
            moves[v] = 1 + (v - biggest[v % 4]) / 2;
        }
    }

    int t = 0;
    if (std::scanf("%d", &t) != 1) {
        return 1;
    }
    for (int c = 0; c < t; ++c) {
        int n = 0;
        if (std::scanf("%d", &n) != 1) {
            return 1;
        }
        int best_visit = -1;
        int best_moves = 0;
        for (int i = 0; i < n; ++i) {
            int a = 0;
            if (std::scanf("%d", &a) != 1) {
                return 1;
            }
            int visit = moves[a] / 2;
            if (best_visit < 0 || visit < best_visit) {
                best_visit = visit;
                best_moves = moves[a];
            }
        }
        if (best_moves % 2 == 1) {
            std::printf("Farmer John\n");
        } else {
            std::printf("Farmer Nhoj\n");
        }
    }
    return 0;
}
```

筛到 v 时，比 v 小的素数都已经把自己的倍数划过，v 没被划过就是素数，所以一遍循环就能边筛边填。余 3 的一类第一次用到是 v = 3，那时 3 刚被记下。f(v) ≤ v ÷ 2 + 1，`int` 放得下。`moves` 和 `composite` 一共约 25 MB，用 `std::vector` 放在堆上，不会撑破栈。

对拍用的慢程序不用任何规律，直接对“各房间牛数、当前房间、轮到谁”按两句判定递归求胜负。
