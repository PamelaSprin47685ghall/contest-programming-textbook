# 24　图形的方向也能算出来

一条橡皮筋围住所有图钉，绷紧后只碰到外侧一些点，形成凸包。程序看不到橡皮筋，需要把“左转、右转、在里面”变成可检查的数。

## 两个乘积告诉我们方向

向量 `(x1,y1)`、`(x2,y2)` 的叉积是 `x1*y2-y1*x2`。从 A 到 B、从 A 到 C 的叉积为正表示 C 在有向直线 AB 左侧，负为右侧，零为共线。点积 `x1*x2+y1*y2` 则帮助判断夹角、投影与平方距离。

整数坐标可做精确方向判断，但乘法范围要先算。浮点坐标要按题目尺度设计容差；同一个随意 `epsilon` 不能包治大小相差十亿倍的数据，尤其不能让排序比较器因“差不多相等”而不传递。

## 把会凹进去的中间点弹掉

按 x、再按 y 排序并去重。沿左到右构造下壳，新点令最后两段不是左转，就弹掉中间点；上壳反向同理。这是 Andrew 凸包。下面不保留边上多余共线点，全部共线时只留两端。

**完整程序：**输入 `0 <= n <= 100000` 及 n 个整数点，各坐标绝对值不超过十亿，输出凸包顶点数和面积的两倍。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

struct Point {
    long long x;
    long long y;
    bool operator<(const Point& other) const {
        return x != other.x ? x < other.x : y < other.y;
    }
    bool operator==(const Point& other) const { return x == other.x && y == other.y; }
};

long long cross(const Point& a, const Point& b, const Point& c) {
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 0 || n > 100000) { return 1; }
    std::vector<Point> points(n);
    for (Point& point : points) {
        if (std::scanf("%lld%lld", &point.x, &point.y) != 2
            || point.x < -1000000000 || point.x > 1000000000
            || point.y < -1000000000 || point.y > 1000000000) { return 1; }
    }
    std::sort(points.begin(), points.end());
    points.erase(std::unique(points.begin(), points.end()), points.end());
    n = static_cast<int>(points.size());
    if (n <= 1) { std::printf("%d 0\n", n); return 0; }
    std::vector<Point> hull(2 * n);
    int size = 0;
    for (const Point& point : points) {
        while (size >= 2 && cross(hull[size - 2], hull[size - 1], point) <= 0) { --size; }
        hull[size++] = point;
    }
    int upper_start = size + 1;
    for (int i = n - 2; i >= 0; --i) {
        while (size >= upper_start && cross(hull[size - 2], hull[size - 1], points[i]) <= 0) { --size; }
        hull[size++] = points[i];
    }
    --size;
    long long twice_area = 0;
    for (int i = 1; i + 1 < size; ++i) { twice_area += cross(hull[0], hull[i], hull[i + 1]); }
    std::printf("%d %lld\n", size, twice_area);
    return 0;
}
```

输入：

```text
5
0 0
2 0
2 2
0 2
1 1
```

输出：

```text
4 8
```

排序 `O(n log n)`，扫描 `O(n)`。用凸多边形同向三角扇累计面积，所有项非负，总面积两倍不超过包围正方形的 `8*10^18`，仍在本环境 `long long` 内；坐标范围扩大就不再安全。

## 平移一条线，答案会有顺序

凸包最远点对可用旋转卡壳：沿凸包边旋转，另一端支持点只向前走，不从头扫描；整体线性次推进。最近点对则可按 x 分治，合并时只在宽度由当前最短距离限制的条带内比较，按 y 排序并利用平面装箱界控制近邻数，达到 `O(n log n)`。不能把卡壳用到任意非凸点序。

矩形并面积用扫描线：按 x 处理进入、离开，纵向线段树维护被覆盖总长度；相邻 x 差乘覆盖长就是条带面积。离散化的是坐标边界，叶子代表相邻坐标间的真实长度，不是一个长度为 1 的编号。几何不必都用小数。

判两线段相交要检查方向跨立与共线投影重叠；把“叉积乘积 <=0”直接相乘，可能使两个本来安全的叉积再乘溢出，应比较符号。求交点是另一步，要处理平行、重合，并决定用有理数还是浮点。

## 整数格点还有一份面积账

顶点都在整数格点的简单多边形，Pick 定理为 `面积=内部格点数+边界格点数/2-1`。一条整数边的分段数为 `gcd(|dx|,|dy|)`，沿所有边累加得到边界点数，避免顶点重复。

凸性也能从几何走回优化：凸集合中两点连线全在集合内；凸函数在两点间不高于弦。支持线把函数换成斜率及截距的约束，Fenchel–Legendre 凸共轭定义为 `f*(p)=sup_x(p*x-f(x))`。它把“斜率为 p 的最低支撑信息”记录下来，是第 6 章斜率、参数价格与第 25 章对偶视角的共同来源，不要求先把每条直线都叫成新算法。
