# 24　图形的方向也能算出来

手机导航说“前方路口左转”。程序看不见地图，只知道几个点的坐标，却算出了左和右：两个方向的坐标交叉相乘，再看差的正负。这一章的几何全靠这样的整数乘法，不用角度和除法，也就不怕浮点误差。

## 两个乘积告诉我们方向

平面上的向量 u = (a, b)、v = (c, d) 有两种乘积。**点积** u · v = ac + bd，**叉积** u × v = ad − bc。点积为正，两个方向夹角小于 90°；为 0，互相垂直；为负，大于 90°。叉积为正，从 u 转到 v 是逆时针，也就是 v 在 u 的左边；为 0，两者共线；为负，v 在 u 的右边。

三个点 o、a、b，取 u = a − o、v = b − o，叉积的正负就回答“从 o 走到 a，b 在左边还是右边”。叉积的绝对值是 u、v 张成的平行四边形面积，所以三角形 oab 的面积是它的一半。多边形顶点按顺序是 p₀ 到 p_(m−1)，把每条边 (p_i, p_(i+1)) 的 x_i × y_(i+1) − x_(i+1) × y_i 加起来，得到多边形面积的 2 倍，逆时针排列时为正、顺时针时为负，这叫**鞋带公式**。坐标都是整数时，这些量全是整数，比较时不会有误差。

### 例题　对称

平面上有 N 头奶牛，各占一个不同的整点（2 ≤ N ≤ 1000，坐标绝对值不超过 10⁴）。一条直线叫对称轴，是说把每个点关于它翻过去，落点仍是某头奶牛。问一共有几条对称轴。输入第一行是 N，接着 N 行坐标；输出一个整数。

样例输入：

```text
4
0 0
0 1
1 0
1 1
```

样例输出：

```text
4
```

四个点是一个正方形，对称轴是一条竖线、一条横线和两条对角线。

这是 USACO 2012 年 2 月金组第二题[“对称”](../USACO/金组/2011_2012/2012.02/P2.md)。

直线有无穷多条，先缩小候选。取两个点 a、b。对称轴要么不过 a，那么 a 翻到另一个点 p，轴就是 a、p 连线的中垂线；要么过 a，再看 b：b 也在轴上，轴就是直线 ab；b 不在轴上，b 翻到另一个点 q，轴是 b、q 的中垂线，而且还要过 a。三类候选共不到 2N 条，各不相同，逐条检查即可。

直线写成 n · X = c 的样子，n = (nx, ny) 是垂直于直线的向量。点 P 翻过去得到 P′ = P − 2(n · P − c) ÷ |n|² × n。a、p 的中垂线取 n = p − a，2c = n · (a + p)；直线 ab 取 n = (a_y − b_y, b_x − a_x)，它和 b − a 的点积是 0。程序把 2c 记作 c2，把 P′ 乘上 |n|² 再算，整除不了就说明落点不是整点；|n|² ≤ 8 × 10⁸，乘上坐标不超过 10¹³。

**片段：**

```cpp
// 位于 main 之前；pts 是全部点，cows 是同样的点，放进 std::set 便于查找
struct Point {
    long long x;
    long long y;
};
std::vector<Point> pts;
std::set<std::pair<long long, long long>> cows;

// 直线 nx × X + ny × Y = c2 ÷ 2 是不是对称轴：每个点的镜像都得还是一个点
bool is_axis(long long nx, long long ny, long long c2) {
    long long len2 = nx * nx + ny * ny;
    for (const Point& p : pts) {
        long long t = 2 * (nx * p.x + ny * p.y) - c2;
        long long qx = len2 * p.x - t * nx;      // 镜像的横坐标乘了 len2
        long long qy = len2 * p.y - t * ny;
        if (qx % len2 != 0 || qy % len2 != 0) {
            return false;
        }
        if (cows.count(std::make_pair(qx / len2, qy / len2)) == 0) {
            return false;
        }
    }
    return true;
}

int count_axes() {
    int n = static_cast<int>(pts.size());
    const Point& a = pts[0];
    const Point& b = pts[1];
    int axes = 0;
    // 第一类：a 不在轴上，镜像是 pts[j]，轴是两点连线的中垂线
    for (int j = 1; j < n; ++j) {
        long long nx = pts[j].x - a.x;
        long long ny = pts[j].y - a.y;
        long long c2 = nx * (a.x + pts[j].x) + ny * (a.y + pts[j].y);
        if (is_axis(nx, ny, c2)) {
            ++axes;
        }
    }
    // 第二类：a、b 都在轴上，轴就是直线 ab
    long long nx = a.y - b.y;
    long long ny = b.x - a.x;
    if (is_axis(nx, ny, 2 * (nx * a.x + ny * a.y))) {
        ++axes;
    }
    // 第三类：a 在轴上，b 的镜像是 pts[k]，轴是 b、pts[k] 的中垂线且过 a
    for (int k = 2; k < n; ++k) {
        nx = pts[k].x - b.x;
        ny = pts[k].y - b.y;
        long long c2 = nx * (b.x + pts[k].x) + ny * (b.y + pts[k].y);
        if (2 * (nx * a.x + ny * a.y) == c2 && is_axis(nx, ny, c2)) {
            ++axes;
        }
    }
    return axes;
}
```

`std::set` 见[第一卷第 17 章](../I/17-集合、顺序与自己设计的键.md)。`main` 把点放进 `pts` 和 `cows`，输出 `count_axes()`，总共约 2N² log N 步。

## 把会凹进去的中间点弹掉

包住一组点的最小凸多边形叫这组点的**凸包**。“凸”是说图形里任意两点的连线都在图形里。

求凸包的一种办法：把点按 x 从小到大排好（x 相同按 y），从左往右走，分别做下半边和上半边。做下半边时，依次放进新点 q；只要最后两个点 a、b 和 q 不是左转，即叉积 (b − a) × (q − a) ≤ 0，b 就是凹进去或者夹在中间的点，弹掉它，再看新的最后两个点。上半边相反，不是右转就弹。每个点进出各至多一次，排序以后只要 O(N) 步。这两条边叫**下链**和**上链**，各自从最左的点走到最右的点。

### 例题　奶牛冰壶

两队各有 N 颗石子，2N 颗石子在不同的整点上（3 ≤ N ≤ 50000，坐标绝对值不超过 40000）。一颗石子落在对方某三颗石子围成的三角形里（含边界），就被对方俘获。输入第一行是 N，接着 N 行是 A 队的坐标，再 N 行是 B 队的。输出 A 队、B 队各俘获对方几颗。

样例输入：

```text
4
0 0
0 2
2 0
2 2
1 1
1 10
-10 3
10 3
```

样例输出：

```text
1 2
```

A 队的正方形盖住了 B 队的 (1, 1)。B 队的 (1, 1)、(−10, 3)、(10, 3) 围成一个三角形，盖住 A 队的 (0, 2) 和 (2, 2)。

这是 USACO 2014 年 1 月金组第一题[“奶牛冰壶”](../USACO/金组/2013_2014/2014.01/P1.md)。

三颗石子的组合有 N³ 量级，不能一一试。换个说法：被某个三角形盖住，等于落在对方凸包里（含边界）。一方面，每个三角形都在凸包里。另一方面，从凸包的一个顶点向其余顶点连线，凸包被切成若干三角形，顶点都是石子，凸包里的点总落在其中一个里。三颗石子共线时，“三角形”是一条线段，所有石子共线时凸包也是一条线段，说法仍然成立。

于是对每队求一次凸包，再逐颗检查对方的石子。石子 q 的 x 在最左、最右之间时，在下链上二分找出跨过 q.x 的那条边，q 不能在它右侧（叉积 ≥ 0）；上链同理，q 不能在它左侧。q 恰好在最左或最右那条竖线上时，直接比较那条竖线上石子的最低、最高 y。

下面是**完整程序 A**。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

struct Point {
    long long x;
    long long y;
};

// 从 o 走到 a 再看 b：正数表示向左转，负数表示向右转，0 表示三点共线
long long cross(const Point& o, const Point& a, const Point& b) {
    return (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x);
}

bool left_lower(const Point& a, const Point& b) {
    if (a.x != b.x) {
        return a.x < b.x;
    }
    return a.y < b.y;
}

// 一队石子围成的范围：下链、上链，以及最左、最右两条竖线上的 y 范围
struct Region {
    std::vector<Point> lower;
    std::vector<Point> upper;
    long long left_x = 0;
    long long right_x = 0;
    long long left_low = 0;
    long long left_high = 0;
    long long right_low = 0;
    long long right_high = 0;
};

Region build(std::vector<Point> p) {
    std::sort(p.begin(), p.end(), left_lower);
    Region r;
    for (const Point& q : p) {
        while (r.lower.size() >= 2 &&
               cross(r.lower[r.lower.size() - 2], r.lower.back(), q) <= 0) {
            r.lower.pop_back();
        }
        r.lower.push_back(q);
        while (r.upper.size() >= 2 &&
               cross(r.upper[r.upper.size() - 2], r.upper.back(), q) >= 0) {
            r.upper.pop_back();
        }
        r.upper.push_back(q);
    }
    r.left_x = p.front().x;
    r.right_x = p.back().x;
    r.left_low = p.front().y;
    r.left_high = p.front().y;
    r.right_low = p.back().y;
    r.right_high = p.back().y;
    for (const Point& q : p) {
        if (q.x == r.left_x) {
            r.left_high = q.y;               // 同一个 x 按 y 从小到大排过
        }
        if (q.x == r.right_x && q.y < r.right_low) {
            r.right_low = q.y;
        }
    }
    return r;
}

// 链上找一条边 (chain[j - 1], chain[j])，使 chain[j - 1].x <= x < chain[j].x
int edge_after(const std::vector<Point>& chain, long long x) {
    int lo = 1;
    int hi = static_cast<int>(chain.size()) - 1;
    while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (chain[mid].x > x) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }
    return lo;
}

bool covered(const Region& r, const Point& q) {
    if (q.x < r.left_x || q.x > r.right_x) {
        return false;
    }
    if (q.x == r.left_x) {
        return r.left_low <= q.y && q.y <= r.left_high;
    }
    if (q.x == r.right_x) {
        return r.right_low <= q.y && q.y <= r.right_high;
    }
    int j = edge_after(r.lower, q.x);
    if (cross(r.lower[j - 1], r.lower[j], q) < 0) {
        return false;                        // 在下链下方
    }
    j = edge_after(r.upper, q.x);
    return cross(r.upper[j - 1], r.upper[j], q) <= 0;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<Point> team[2];
    for (int t = 0; t < 2; ++t) {
        for (int i = 0; i < n; ++i) {
            Point q = {0, 0};
            if (std::scanf("%lld%lld", &q.x, &q.y) != 2) {
                return 1;
            }
            team[t].push_back(q);
        }
    }
    int score[2] = {0, 0};
    for (int t = 0; t < 2; ++t) {
        Region r = build(team[t]);
        for (const Point& q : team[1 - t]) {
            if (covered(r, q)) {
                ++score[t];
            }
        }
    }
    std::printf("%d %d\n", score[0], score[1]);
    return 0;
}
```

`edge_after` 找链上第一个 x 大于 q.x 的点 j。竖边只可能出现在下链最右端或上链最左端，q.x 严格在两端之间，所以边 (j − 1, j) 横跨 q.x。叉积的量级是 (8 × 10⁴)² ≈ 6.4 × 10⁹，超过 `int`，坐标存成 `long long`。

## 平移一条线，答案会有顺序

一条竖线从左往右扫过平面，叫**扫描线**。线段的端点就是[第二卷第 20 章](../II/20-让几种工具接成一件事.md)说的事件，把扫描线的移动分成若干段：扫到一条线段的左端，它开始和扫描线相交；扫到右端，它离开。只要线段互不相交，同时和扫描线相交的线段就有固定的上下次序，次序只在事件处变化。于是可以把“当前和扫描线相交的线段”放进按上下排好的 `std::set`，每个事件只插入或删除一条。

### 例题　山丘漫步

有 N 座山丘（N ≤ 10⁵），每座是一条从 (x₁, y₁) 到 (x₂, y₂) 的线段，x₁ < x₂，y₁ < y₂，坐标在 0 到 10⁹ 之间。线段互不相交也不相碰，第一座从 (0, 0) 出发。贝茜从 (0, 0) 起沿山丘往上走到右端，然后竖直往下掉：落到别的山丘上就接着走，否则掉到最底下结束。山丘含左端点、不含右端点，所以在 x = x₁ 处落下会落到它上面，在 x = x₂ 处不会。问她一共走过几座山丘。

样例输入：

```text
4
0 0 5 6
1 0 2 1
7 2 8 5
3 0 7 7
```

样例输出：

```text
3
```

第 1 座走到 (5, 6) 落下。x = 5 处只有第 4 座在下面，高度 3.5，落到它上面，走到 (7, 7)。x = 7 处第 3 座刚开始，左端 (7, 2) 在下面，落上去，走到 (8, 5)，下面再没有山丘。共 3 座。

这是 USACO 2013 年 3 月金组第二题[“山丘漫步”](../USACO/金组/2012_2013/2013.03/P2.md)。

贝茜每次落下的 x 都比上一次大，扫描线只往右走。落在 x 处，要找的是“和 x 相交的山丘里，落点正下方最高的那座”。两座山丘的上下次序，在左端靠右的那座的左端点处比较：那一点在另一座所在直线的上方还是下方，用一个叉积判断。查询时把落点本身当成一座左右端点重合的山丘，用 `lower_bound` 找到第一座不在它下面的，前一座就是答案。

同一个 x 上先删结束的，再插入开始的。这样集合里的山丘都横跨当前的 x，两两可比；x₂ = x 的也已离开，符合“不含右端点”。

**片段：**

```cpp
// 位于 main 之前；hill[0..n-1] 是读入的山丘，hill[n] 留给查询点
struct Hill {
    long long x1;
    long long y1;
    long long x2;
    long long y2;
};
int n = 0;
std::vector<Hill> hill;

// 点 (x, y) 在山丘 h 所在直线的上方为正，下方为负
long long side(const Hill& h, long long x, long long y) {
    return (h.x2 - h.x1) * (y - h.y1) - (h.y2 - h.y1) * (x - h.x1);
}

// 两座山丘在共同的横坐标范围里，a 是不是在 b 下面
struct Below {
    bool operator()(int a, int b) const {
        const Hill& p = hill[a];
        const Hill& q = hill[b];
        if (p.x1 == q.x1) {
            return p.y1 < q.y1;
        }
        if (p.x1 > q.x1) {
            return side(q, p.x1, p.y1) < 0;    // p 的左端在 q 下方
        }
        return side(p, q.x1, q.y1) > 0;        // q 的左端在 p 上方
    }
};

int walk() {
    std::vector<int> by_start(n, 0);
    std::vector<int> by_end(n, 0);
    for (int i = 0; i < n; ++i) {
        by_start[i] = i;
        by_end[i] = i;
    }
    std::sort(by_start.begin(), by_start.end(),
              [](int a, int b) { return hill[a].x1 < hill[b].x1; });
    std::sort(by_end.begin(), by_end.end(),
              [](int a, int b) { return hill[a].x2 < hill[b].x2; });
    std::set<int, Below> active;
    int next_in = 0;
    int next_out = 0;
    int cur = 0;
    int touched = 1;
    while (true) {
        long long x = hill[cur].x2;
        long long y = hill[cur].y2;
        // 把扫描线推到 x：同一横坐标先拿走结束的，再放进开始的
        while (true) {
            bool can_out = next_out < n && hill[by_end[next_out]].x2 <= x;
            bool can_in = next_in < n && hill[by_start[next_in]].x1 <= x;
            if (can_out && (!can_in || hill[by_end[next_out]].x2 <= hill[by_start[next_in]].x1)) {
                active.erase(by_end[next_out]);
                ++next_out;
            } else if (can_in) {
                active.insert(by_start[next_in]);
                ++next_in;
            } else {
                break;
            }
        }
        hill[n] = {x, y, x, y};                // 把落点当成一座退化的山丘
        auto it = active.lower_bound(n);
        if (it == active.begin()) {
            return touched;
        }
        --it;
        cur = *it;
        ++touched;
    }
}
```

比较规则 `Below` 见[第一卷第 17 章](../I/17-集合、顺序与自己设计的键.md)，传给 `std::sort` 的小函数写法见[第一卷第 19 章](../I/19-把行为当作数据.md)。`main` 让 `hill` 有 N + 1 格，读入后输出 `walk()`。叉积的两项各不超过 10¹⁸，差不超过 2 × 10¹⁸，`long long` 放得下。总共 O(N log N)。

## 整数格点还有一份面积账

顶点都是整点的多边形，叫**格点多边形**。它的面积 A、内部的整点数 I、边上的整点数 B 之间有一个关系，叫**皮克定理**：

A = I + B ÷ 2 − 1。

证明的思路是：先对长方形和直角三角形直接数出来验证，再说明两块沿一条边拼起来时等式仍然成立，而任何格点多边形都能这样拼出来。

一条边从 (x₁, y₁) 到 (x₂, y₂)，除起点外，上面的整点数是 gcd(|x₂ − x₁|, |y₂ − y₁|)。所以 B 用最大公约数求，A 用鞋带公式求，I 就是 A − B ÷ 2 + 1。

**片段：**

```cpp
// 位于 main 内；x[i]、y[i] 是多边形按顺序排好的 m 个整点顶点
long long twice_area = 0;     // 鞋带公式：有向面积的 2 倍
long long on_edge = 0;        // 边上的整点数
for (int i = 0; i < m; ++i) {
    int j = (i + 1) % m;
    twice_area += x[i] * y[j] - x[j] * y[i];
    long long dx = x[j] - x[i];
    long long dy = y[j] - y[i];
    on_edge += gcd_of(dx < 0 ? -dx : dx, dy < 0 ? -dy : dy);
}
if (twice_area < 0) {
    twice_area = -twice_area;
}
long long inside = (twice_area - on_edge + 2) / 2;
std::printf("%lld %lld\n", inside, on_edge);
```

`gcd_of` 用辗转相除求最大公约数，见[第二卷第 19 章](../II/19-整数身上也有线索.md)。对拍时，慢程序逐个检查包围盒里的每个整点在边上、内部还是外部。

[第 21 章](21-先看运算遵守哪些规则.md)说过，格点多边形放大 n 倍以后，整点个数是 n 的多项式。现在可以算出来：面积变成 A × n²，边上的整点变成 B × n，于是内部加边上一共 I + B = A × n² + B × n ÷ 2 + 1，是 n 的二次多项式。
