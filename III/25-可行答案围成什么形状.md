# 25　可行答案围成什么形状

春天分菜地：一共 4 亩地，种白菜每亩要 1 份水、2 个工，种萝卜每亩要 3 份水、1 个工；水只有 9 份，人工只有 7 个；白菜每亩赚 3 百元，萝卜每亩赚 2 百元。地可以分成零头，不必是整亩。各种分法有无穷多种，可它们在纸上围成一块多边形，最好的分法就在这块多边形的某个角上。

这一章先看这种“连续”的问题：可行答案围成什么形状，最优答案在哪里，又怎样证明找到的答案不能再好。然后回到离散的选择，看贪心在什么样的结构上一定对，结构不够好时又要怎样补。

## 连续问题先看角点

设白菜种 x 亩、萝卜种 y 亩。条件写成不等式：x + y ≤ 4，x + 3y ≤ 9，2x + y ≤ 7，x ≥ 0，y ≥ 0；要让 3x + 2y 最大。变量可以取实数，条件和目标都是一次式，这样的问题叫**线性规划**。满足全部条件的点叫可行解，它们合起来叫**可行区域**。

每个不等式 a × x + b × y ≤ c 都是一条直线一侧的半个平面，可行区域是这些半平面的公共部分。两点都在一个半平面里，连线也在，所以可行区域是凸的，在平面上就是一个凸多边形，它的顶点叫**角点**。上面的菜地，角点是 (0, 0)、(3.5, 0)、(3, 1)、(1.5, 2.5)、(0, 3)，目标值依次是 0、10.5、11、9.5、6，最好是 (3, 1)：白菜 3 亩，萝卜 1 亩，赚 11 百元。

为什么只看角点就够了？在可行区域的一条边上走，目标值随走过的距离一次地变化，不是一直变大，就是一直变小，或者不变；所以边上的最好值总在端点取到。区域里面的点也一样：沿目标增大的方向走，总会碰到边界，在边界上再走到角点。只要区域非空、目标有上限，最优值就在某个角点上取到。

两个变量时，角点就是两条边界直线的交点。把每两条直线都交一下，留下满足全部条件的交点，比较目标值即可。交点用两行两列的方程组求：分母 d 和分子都是整数，比较时乘上分母，不用除法。

**片段：**

```cpp
// 位于 main 内；第 i 个约束是 a[i] × x + b[i] × y <= c[i]，共 m 个（含 x >= 0、y >= 0），
// 目标是让 p × x + q × y 最大。可行区域非空且有界
bool found = false;
long long best_num = 0;      // 目前最大的目标值 = best_num / best_den
long long best_den = 1;
for (int i = 0; i < m; ++i) {
    for (int j = i + 1; j < m; ++j) {
        long long d = a[i] * b[j] - a[j] * b[i];
        if (d == 0) {
            continue;                         // 两条线平行，没有交点
        }
        long long dx = c[i] * b[j] - c[j] * b[i];
        long long dy = a[i] * c[j] - a[j] * c[i];
        if (d < 0) {
            d = -d;
            dx = -dx;
            dy = -dy;
        }
        // 交点 (dx / d, dy / d)，检查它满足全部约束
        bool ok = true;
        for (int k = 0; k < m; ++k) {
            if (a[k] * dx + b[k] * dy > c[k] * d) {
                ok = false;
            }
        }
        long long value = p * dx + q * dy;    // 目标值乘了 d
        if (ok && (!found || value * best_den > best_num * d)) {
            found = true;
            best_num = value;
            best_den = d;
        }
    }
}
```

m 条直线两两相交，每个交点再检查 m 个条件，共 O(m³) 步，只适合很小的 m。变量更多时，常用的**单纯形法**从一个角点出发，每次沿一条边走到相邻的、目标更好的角点，走不动了就是最优；它在实际数据上通常很快。[第 11 章](11-给整张网络量一量瓶颈.md)的流和[第 12 章](12-每次改配都算清代价.md)的费用流，都可以写成线性规划，只是有专门的、更快的算法。

## 一份上界也能证明最优

找到 (3, 1)，目标值 11。怎样让别人相信不可能超过 11，而不必把所有角点给他看？

把 x + y ≤ 4 和 2x + y ≤ 7 相加，得到 3x + 2y ≤ 11。左边正好是目标，所以任何可行解的目标都不超过 11；(3, 1) 达到了 11，它就是最优的。这两个系数 1、1 是一份**证书**。

一般地，给每个条件 a_i × x + b_i × y ≤ c_i 配一个非负的系数 u_i，加起来得到 (Σ u_i a_i) x + (Σ u_i b_i) y ≤ Σ u_i c_i。只要左边每个系数都不小于目标里对应的系数，而且 x、y ≥ 0，目标就不超过 Σ u_i c_i。系数必须非负，否则不等号会反过来。

在所有这样的系数里找让 Σ u_i c_i 最小的，又是一个线性规划，叫原问题的**对偶**。上面的推导说明：对偶的任何可行解都给出原问题的上界，这叫**弱对偶**。更进一步的结论是**强对偶**：原问题有最优解时，对偶的最优值和它相等，所以总能找到一份恰好卡住最优值的证书。[第 11 章](11-给整张网络量一量瓶颈.md)的“最大流等于最小割”，就是这句话在网络上的样子：割是流量的一份上界，最小割恰好卡住最大流。

证书还告诉我们哪些条件在起作用。u 不为 0 的条件，在最优解处一定取等号：(3, 1) 让土地和人工都用完，水只用了 6 份，水的系数是 0。这叫**互补松弛**。系数还有一个读法：人工多 1 个，最多能多赚多少。

## 哪些“独立选择”真的适合贪心

回到离散的问题。有一批作业，每份做一天，第 i 份要在第 d_i 天或之前做完，做完得 p_i 分；一天只能做一份。怎样选、怎样排，总分最高？

先说清“一组作业排得下”是什么意思。按截止日从早到晚依次放进第 1、2、3、…… 天，就知道：一组作业排得下，当且仅当对每个 t，截止日不晚于 t 的作业不超过 t 份。

直接的贪心是：按分数从高到低看，加进来以后还排得下就收下。它对吗？要说清这件事，先看排得下的作业组有什么共同性质。

一个集合族叫**拟阵**，里面的集合叫（拟阵的）**独立集**，要满足三条（和[第 10 章](10-找不到搭档时让出一条路.md)图上的独立集不是一回事，一张图的独立集一般不构成拟阵）：空集独立；独立集的子集也独立；两个独立集 A、B，|A| < |B| 时，B 里总有一个不在 A 里的元素 x，使 A 加上 x 仍独立。最后一条叫**交换性质**。

排得下的作业组满足交换性质。设 A、B 都排得下，|A| < |B|，x 是 B 里不在 A 里、截止日最晚的那一份，截止日是 D。假设 A 加上 x 排不下，那么有某个 t ≥ D，A 里截止日不晚于 t 的作业恰好 t 份。B 里不在 A 里的作业截止日都不晚于 D ≤ t，所以 B 里截止日不晚于 t 的作业，至少是“A、B 共有的那部分里不晚于 t 的”再加上“B 独有的全部”。B 排得下，这个数不超过 t；A 的同一个数正好是 t，等于“共有部分里不晚于 t 的”加上“A 独有部分里不晚于 t 的”。比较两边，B 独有的份数不超过 A 独有的份数，与 |A| < |B| 矛盾。

在拟阵上，按权从大到小的贪心一定得到权和最大的独立集（权都非负）。设贪心选出 g₁、g₂、……，按权从大到小；任取一个独立集 o₁、o₂、……，也从大到小排。假如第一次出现 o_i 的权比 g_i 大，对 {g₁, ……, g_(i−1)} 和 {o₁, ……, o_i} 用交换性质，能找到某个 o_j 加进前者仍独立，而它的权不小于 o_i，比 g_i 大。贪心看到 o_j 时，手里的集合是 {g₁, ……, g_(i−1)} 的子集，加上 o_j 仍独立，它应当已经收下 o_j，矛盾。所以贪心的第 i 个总不比别人的第 i 个差。贪心在反方向上也成立：要是一个集合族满足前两条却不满足交换性质，总能配一组权，让贪心出错。最小生成树的克鲁斯卡尔算法就是图上“无圈边集”这个拟阵上的贪心。

“还排得下吗”每次重查所有 t 太慢。程序 A 把收下的作业放在“截止日或之前、还空着的最晚一天”，用[第二卷第 13 章](../II/13-只记住谁和谁是一组.md)的办法把用掉的日子接到前一天。找不到空日子，说明从第 1 天起连续若干天全满，而且放在这些天里的作业截止日都不晚于这一段的最后一天，否则它会被放到更晚的空日子去；新作业加进来就排不下。

下面是**完整程序 A**。输入第一行是 n（n ≤ 2 × 10⁵），接着 n 行，每行是截止日 d_i（1 ≤ d_i ≤ n）和分数 p_i（p_i ≤ 10⁹），输出最高总分。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

struct Job {
    int deadline;
    long long profit;
};

bool more_profit(const Job& a, const Job& b) {
    return a.profit > b.profit;
}

// free_day[d]：第 d 天或更早、还空着的最晚一天，0 表示一天都不剩
int latest_free(std::vector<int>& free_day, int d) {
    int root = d;
    while (free_day[root] != root) {
        root = free_day[root];
    }
    while (free_day[d] != root) {          // 把走过的路直接接到终点
        int next = free_day[d];
        free_day[d] = root;
        d = next;
    }
    return root;
}

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<Job> jobs(n);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%d%lld", &jobs[i].deadline, &jobs[i].profit) != 2) {
            return 1;
        }
    }
    std::sort(jobs.begin(), jobs.end(), more_profit);
    std::vector<int> free_day(n + 1, 0);
    for (int d = 0; d <= n; ++d) {
        free_day[d] = d;
    }
    long long total = 0;
    for (const Job& job : jobs) {
        int day = latest_free(free_day, job.deadline);
        if (day > 0) {
            total += job.profit;
            free_day[day] = day - 1;       // 这一天用掉了，以后往前找
        }
    }
    std::printf("%lld\n", total);
    return 0;
}
```

样例输入：

```text
5
2 50
1 10
2 20
1 30
3 15
```

样例输出：

```text
95
```

按分数从高到低：50 分放第 2 天，30 分放第 1 天，20 分截止第 2 天，第 1、2 天都满了，不收；15 分放第 3 天；10 分不收。共 95 分。对拍的慢程序枚举所有子集，按“每个 t 截止不晚于 t 的不超过 t 份”判断能否排下。

## 两套独立要求一起用，得重新安排

有时一组选择要同时满足两套要求。左边是几个人，右边是几项工作，一条边表示“这个人能做这项工作”。选一组边作为分配，要求每个人至多一项，每项工作至多一人。只看“每个人至多一条边”，是一个拟阵；只看“每项工作至多一条边”，也是一个拟阵。分配就是同时在两个拟阵里独立的边集，这叫两个拟阵的**交**。

交通常不再是拟阵，贪心就会出错。人 a₁ 做工作 b₁ 值 3 分，a₁ 做 b₂ 值 2 分，a₂ 做 b₁ 值 2 分。贪心先拿 3 分，a₁ 和 b₁ 都被占了，另外两条边都放不进去，总分 3；分给 a₁ 做 b₂、a₂ 做 b₁，总分 4。

补救的办法是允许改配：已经选了的边可以换出去，只要换完以后两套要求都还满足、结果更好。在分配问题里，这就是[第 10 章](10-找不到搭档时让出一条路.md)那种沿着一条交替的路线改配，[第 12 章](12-每次改配都算清代价.md)再把每次改配的代价算清。一般的两个拟阵，也有类似的“交换图”，在图上找改配的路线，叫**拟阵交**算法。三个拟阵的交就难得多，一般情形属于下一章要说的“NP 困难”。

**停笔 4**　用上面的人和工作说明：“所有分配”组成的集合族，不满足交换性质。

这一章先看连续问题：可行区域是凸多边形，最优解在角点上，对偶的系数给出一份证书。离散问题里，拟阵正是贪心一定对的结构，作业排期的交换性质可以直接证出来；两个拟阵的交不再是拟阵，要允许改配。能对一个贪心说清“它选的集合族是不是拟阵”，或者对一个最优答案拿出一份上界，再读下一章。下一章问的是另一件事：什么时候可以断定，某个问题不能指望又快又准的办法。

## 核对

1. 五个角点的 x + 3y 依次是 0、3.5、6、9、9。(1.5, 2.5) 和 (0, 3) 一样好，两点之间那条边（x + 3y = 9 这条线上的一段）上的点都是最优解，最优解不唯一，最优值是 9。
2. 角点的 2x + 3y 依次是 0、7、9、10.5、9，最优是 (1.5, 2.5)，值 10.5。给 x + y ≤ 4 配 1.5，给 x + 3y ≤ 9 配 0.5：1.5(x + y) + 0.5(x + 3y) = 2x + 3y ≤ 1.5 × 4 + 0.5 × 9 = 10.5。
3. 按分数：7 分放第 1 天；6 分放第 2 天；5 分截止第 2 天，第 2、1 天都满，不收；1 分放第 3 天。总分 14。n = 4，最后 `free_day[0]` 到 `free_day[4]` 是 0、0、0、2、4：给 5 分那份找日子时，路径 2 → 1 → 0 被直接接到 0；第 3 天刚用掉，指向 2，还没有被查找压缩过；第 4 天空着。
4. A = {a₁b₁}，B = {a₁b₂, a₂b₁}，都是分配，|A| < |B|。把 a₁b₂ 加进 A，a₁ 有两项工作；把 a₂b₁ 加进 A，b₁ 有两个人。B 里没有一条边能加进 A，交换性质不成立。
