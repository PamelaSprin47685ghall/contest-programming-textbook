# 28　一排数里面还藏着树

排队拍集体照时，摄影师常说“最矮的站中间”。要是再让左边一半里最矮的站左边一半的中间，右边一半也一样，一直分下去，队伍还是原来的左右次序，却已经排成了一棵树：每个人的位置，由“谁是这一段里最矮的”决定。这一章就讲一排数里藏着的这种树，以及几种和“一段数”有关的结构。

## 最小值当根，原顺序不动

一排数 a₀ 到 a_(n−1)，取最小的那个当根（几个一样小时取最左边的），它左边的数照同样的规则建成左子树，右边的建成右子树。这样得到的二叉树叫**笛卡尔树**。它同时满足两件事：按中序（左子树、根、右子树）读出来，正好是原来的次序；每个点都不大于它的孩子，这一点和堆一样。

笛卡尔树里，以 v 为根的子树正好是原数组的一段 [low_v, high_v]，a_v 是这一段的最小值。任取一段 [l, r]，它的最小值（最左的那个）就是 l、r 在树里的最近公共祖先。

照定义递归建树，最坏要 O(n²) 步。从左往右加数可以做到 O(n)：只有树最右边的一条链会变。新来的 a_i 是整个数组最右的，它一定在这条链的末端。从链的底部往上看，比 a_i 大的点都要变成 a_i 的左子树，把它们弹掉；剩下的链底如果还有点，a_i 就是它的右孩子。链用一个栈存，每个点进栈、出栈各一次。

### 例题　所有子数组的最小值之和

给一排正整数 a₀ 到 a_(n−1)（n ≤ 10⁵，a_i ≤ 10⁹），求所有 n(n + 1)/2 个连续子数组的最小值之和。

样例输入：

```text
5
3 1 4 1 5
```

样例输出：

```text
24
```

笛卡尔树的根是下标 1 的 1（两个 1 取左边的）。它的左孩子是 3；右孩子是下标 3 的 1，下面再挂 4 和 5。

一个子数组的最小值（取最左的）是 a_v，当且仅当它在 v 的子树那一段里，而且包含 v。左端有 v − low_v + 1 种取法，右端有 high_v − v + 1 种，所以 a_v 被算了这两个数之积那么多次。样例里，根管的是整段 [0, 4]，有 2 × 4 = 8 个子数组以它为最小；下标 3 的 1 管 [2, 4]，有 2 × 2 = 4 个；其余三个叶子各管自己。总和 8 × 1 + 4 × 1 + 3 + 4 + 5 = 24。

这道题是自编的，USACO 里用到同一结构的两道白金题放在本节的练习表里。

下面是**完整程序 A**。

```cpp
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1) {
        return 1;
    }
    std::vector<long long> a(n, 0);
    for (int i = 0; i < n; ++i) {
        if (std::scanf("%lld", &a[i]) != 1) {
            return 1;
        }
    }
    // 用栈从左往右建笛卡尔树：栈里是当前最右一条链，从根往下
    std::vector<int> left_child(n, -1);
    std::vector<int> right_child(n, -1);
    std::vector<int> chain;
    for (int i = 0; i < n; ++i) {
        int last = -1;                    // 最后弹出的点，成为 i 的左孩子
        while (!chain.empty() && a[chain.back()] > a[i]) {
            last = chain.back();
            chain.pop_back();
        }
        left_child[i] = last;
        if (!chain.empty()) {
            right_child[chain.back()] = i;
        }
        chain.push_back(i);
    }
    int root = chain.front();
    // 子树对应原数组里的一段 [low, high]，按“先孩子后自己”的顺序求出
    std::vector<int> low(n, 0);
    std::vector<int> high(n, 0);
    std::vector<int> order;               // 先序：根先进
    std::vector<int> todo(1, root);
    while (!todo.empty()) {
        int v = todo.back();
        todo.pop_back();
        order.push_back(v);
        if (left_child[v] >= 0) {
            todo.push_back(left_child[v]);
        }
        if (right_child[v] >= 0) {
            todo.push_back(right_child[v]);
        }
    }
    long long total = 0;
    for (int k = n - 1; k >= 0; --k) {    // 倒着走先序，孩子总在父亲之前
        int v = order[k];
        low[v] = left_child[v] >= 0 ? low[left_child[v]] : v;
        high[v] = right_child[v] >= 0 ? high[right_child[v]] : v;
        // 最小值是 a[v] 的子数组：在 [low, high] 里且包含 v
        long long count = 1LL * (v - low[v] + 1) * (high[v] - v + 1);
        total += count * a[v];
    }
    std::printf("%lld\n", total);
    return 0;
}
```

建树时栈 `chain` 从底到顶依次是根到链底，所以最后 `chain.front()` 就是根。弹栈用 `>`：相等的数不弹，左边的那个留在上面当祖先，符合“取最左”的约定。求子树的段时，不写递归，免得 n = 10⁵ 时一条长链把调用栈撑破：先用一个栈求出先序，再倒着走，孩子一定先于父亲处理完。答案最大约 (10⁵)² ÷ 2 × 10⁹ = 5 × 10¹⁸，还在 `long long` 里。对拍的慢程序枚举左端点，右端点往右走时维护当前最小值。

## 一段值恰好填满一段整数

在 1 到 n 的一个排列里，如果一段 [l, r] 里的值恰好是若干个连续整数，就叫它一个**连续段**。比如 3 1 2 5 4 里，“3 1 2”的值是 1、2、3，是连续段；“2 5”不是。

判断很简单：值互不相同，这一段有 r − l + 1 个值，所以它们恰好连续，当且仅当最大值减最小值等于 r − l。固定左端点，右端点往右走时维护最大、最小值，就能 O(n²) 数出所有连续段。

**片段：**

```cpp
// 位于 main 内；p[0..n-1] 是 1 到 n 的一个排列
long long intervals = 0;
for (int l = 0; l < n; ++l) {
    int low = p[l];
    int high = p[l];
    for (int r = l; r < n; ++r) {
        if (p[r] < low) {
            low = p[r];
        }
        if (p[r] > high) {
            high = p[r];
        }
        if (high - low == r - l) {      // 这一段的值恰好是 low 到 high
            ++intervals;
        }
    }
}
std::printf("%lld\n", intervals);
```

这个片段适合 n 在几千以内。更快的办法是从右往左扫左端点 l，同时对每个右端点 r 维护 (max − min) − (r − l)：它总不小于 0，等于 0 的个数就是以 l 开头的连续段数，需要一种能整段加减、查询最小值及其个数的线段树，参看[第二卷第 16 章](../II/16-整段的工作先记一张便条.md)。连续段之间也能组织成一棵树，叫**析合树**，每个点代表一个连续段，孩子是它分成的更小的连续段。

## 一组元素必须挨在一起，不等于次序固定

有时题目给的约束是：“这几个元素在排列里必须挨在一起”，比如几个人必须站成相邻的一排，但谁先谁后不管。这样的约束只限制“谁和谁挨着”，不限制次序。

举个例子：元素 0、1、2、3，要求 {0, 1} 挨着，{1, 2} 也挨着。那么 1 夹在 0 和 2 中间，0、1、2 只能排成 0 1 2 或 2 1 0；这个整块和 3 谁在左边都行。一共 2 × 2 = 4 种。这里出现了两种组合方式：0 1 2 这一块只能整体翻转，3 和这一块的次序可以任意调换。

描述所有满足这类约束的排列，有一种结构叫 **PQ 树**：叶子是元素，P 节点的孩子可以任意排列，Q 节点的孩子只能按给定顺序或整体反过来。上面的例子，根是 P 节点，孩子是 3 和一个 Q 节点；Q 节点的孩子是 0、1、2。所有满足约束的排列，正好是这棵树允许的读法。把约束一条条加进去，每次调整树的形状，可以在接近线性的时间里建好它；细节很多，这里不展开。小数据可以直接枚举：

**片段：**

```cpp
// 位于 main 内；要排 n 个元素 0 到 n − 1，group[g] 是第 g 组“必须挨在一起”的元素
std::vector<int> order(n, 0);
for (int i = 0; i < n; ++i) {
    order[i] = i;
}
long long ways = 0;
do {
    std::vector<int> where(n, 0);         // where[x]：元素 x 排在第几个
    for (int i = 0; i < n; ++i) {
        where[order[i]] = i;
    }
    bool ok = true;
    for (const std::vector<int>& g : group) {
        int first = n;
        int last = -1;
        for (int x : g) {
            first = std::min(first, where[x]);
            last = std::max(last, where[x]);
        }
        if (last - first + 1 != static_cast<int>(g.size())) {
            ok = false;
        }
    }
    if (ok) {
        ++ways;
    }
} while (std::next_permutation(order.begin(), order.end()));
std::printf("%lld\n", ways);
```

`group` 是 `std::vector<std::vector<int>>`，读入时已经填好。一组元素挨在一起，就是它们的位置最大减最小等于个数减 1，和上一节的连续段是同一个判断。对拍时换用另一种写法：直接检查排列的某个连续窗口恰好等于这一组。

## 极值、选择与查询还可以继续分工

只问“[l, r] 里最小的是多少”，叫**区间最小值查询**。数组不变时，可以先花 O(n log n) 准备，然后每问 O(1)。办法是记下每个位置开始、长 2^j 的一段的最小值，长度翻倍时由两段长度减半的拼出来；查询 [l, r] 时取不超过长度的最大 2^j，从左端往右、从右端往左各取一段，两段可能重叠，但重叠不影响最小值。这叫**稀疏表**。

**片段：**

```cpp
// 位于 main 内；a[0..n-1] 已读入。best[j][i] 是从 i 起 2^j 个数里最小的
std::vector<std::vector<long long>> best(1, a);
for (int j = 1; (1 << j) <= n; ++j) {
    const std::vector<long long>& half = best[j - 1];
    std::vector<long long> row(n - (1 << j) + 1, 0);
    for (int i = 0; i + (1 << j) <= n; ++i) {
        row[i] = std::min(half[i], half[i + (1 << (j - 1))]);
    }
    best.push_back(row);
}
// 查询 [l, r]：取不超过长度的最大 2^j，两段从两头盖住整段
for (int t = 0; t < q; ++t) {
    int l = 0;
    int r = 0;
    if (std::scanf("%d%d", &l, &r) != 2) {
        return 1;
    }
    int j = 0;
    while ((2 << j) <= r - l + 1) {
        ++j;
    }
    std::printf("%lld\n", std::min(best[j][l], best[j][r - (1 << j) + 1]));
}
```

`2 << j` 是 2^(j+1)，移位见[第二卷第 2 章](../II/02-把选择走成一棵树.md)。`while` 找到满足 2^j ≤ 长度 < 2^(j+1) 的 j，也可以预先算好每个长度对应的 j。这个片段直接在 `main` 里读询问，读失败时 `return 1`。

三个问题可以互相转化：区间最小值就是笛卡尔树上的最近公共祖先；反过来，树上的最近公共祖先，沿着欧拉序（深度优先走一遍，每经过一个点记一次）可以变成相邻两次出现之间深度的区间最小值。要问“[l, r] 里第 k 小的是多少”，就不能只靠极值了，要用能按值分段的结构，参看[第 5 章](05-给昨天留一份不会变的记录.md)。按问题要的东西选工具，不要用一种结构硬扛所有询问。

**停笔 4**　n = 10，查询 [2, 8]，j 是多少？用到的两段是哪两段，重叠了几个位置？

这一章看到一排数里藏着的结构：以最小值为根的笛卡尔树，用栈 O(n) 建出，每个点管一段，子数组最小值之和由此直接算出；连续段用最大值减最小值来判断；“必须挨在一起”的约束不固定次序，由 PQ 树描述；区间最小值可以由稀疏表 O(1) 回答，和最近公共祖先互相转化。能对一排数说出它的笛卡尔树长什么样，并用每个点管的段数清楚和极值有关的计数，再读下一章。下一章的输入不再一次给全，答案要通过和评测程序一问一答才能拿到。

## 核对

1. 根是下标 4 的 1，管 [0, 4]；它的左孩子是下标 1 的 2，管 [0, 3]；2 的左孩子是 5（下标 0），右孩子是下标 3 的 3，管 [2, 3]；3 的左孩子是 4。最小值之和：1 × (5 × 1) + 2 × (2 × 3) + 5 × 1 + 3 × (2 × 1) + 4 × 1 = 5 + 12 + 5 + 6 + 4 = 32。
