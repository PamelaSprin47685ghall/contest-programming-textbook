# 28　一排数里面还藏着树

一排柱子高度为 `2 1 4 3`，求它们撑起的最大矩形面积。选一段后，高度由最矮柱决定。于是可以先找最矮柱，把左右两侧分别交给小问题。

## 最小值当根，原顺序不动

笛卡尔树中，中序遍历仍是原下标顺序，父亲高度不大于孩子。相同高度按下标打破平局。任何区间的最小值，对应两端节点的 LCA；静态 RMQ 因此能转成树问题。

向右扫描，单调栈保存右侧祖先链。新柱比栈顶低，就弹出；最后弹出的一棵树成为新柱的左孩子，未弹出的栈顶把新柱接为右孩子。每项进出一次，线性建树。

柱 u 的子树覆盖一个连续段，段内最小高度是 `height[u]`。让矩形在这一段铺满，面积是高度乘子树大小；取所有 u 的最大值就是答案。任何最优矩形有一根最矮柱，向它的整段子树扩展不会降低面积，所以不会漏。

**完整程序：**输入 `0 <= n <= 100000` 和 n 个 0 到十亿的柱高，输出最大矩形面积，空输入为零。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    int n = 0;
    if (std::scanf("%d", &n) != 1 || n < 0 || n > 100000) { return 1; }
    std::vector<int> height(n), left(n, -1), right(n, -1), stack;
    for (int& value : height) {
        if (std::scanf("%d", &value) != 1 || value < 0 || value > 1000000000) { return 1; }
    }
    if (n == 0) { std::printf("0\n"); return 0; }
    stack.reserve(n);
    for (int i = 0; i < n; ++i) {
        int last = -1;
        while (!stack.empty() && height[stack.back()] > height[i]) {
            last = stack.back();
            stack.pop_back();
        }
        left[i] = last;
        if (!stack.empty()) { right[stack.back()] = i; }
        stack.emplace_back(i);
    }
    int root = stack.front();
    std::vector<int> order{root};
    order.reserve(n);
    for (int i = 0; i < n; ++i) {
        int u = order[i];
        if (left[u] != -1) { order.emplace_back(left[u]); }
        if (right[u] != -1) { order.emplace_back(right[u]); }
    }
    std::vector<int> size(n, 1);
    long long answer = 0;
    for (int i = n - 1; i >= 0; --i) {
        int u = order[i];
        if (left[u] != -1) { size[u] += size[left[u]]; }
        if (right[u] != -1) { size[u] += size[right[u]]; }
        answer = std::max(answer, 1LL * height[u] * size[u]);
    }
    std::printf("%lld\n", answer);
    return 0;
}
```

输入：

```text
4
2 1 4 3
```

输出：

```text
6
```

时间空间均 `O(n)`，遍历不用递归，因此全递增柱高形成的长链也不耗尽调用栈。二维最大全一矩形可逐行把连续向上的 1 数成柱高，再用本算法；按每格向左右延伸限制宽度的悬线法，是另一种组织这份限制的方式。

## 一段值恰好填满一段整数

排列里没有重复值。子段 `[l,r]` 的值构成连续整数，当且仅当 `max-min=r-l`。没有重复是关键：`1,1,3` 也满足这个等式，却缺 2。

把位置段映成值域段 `[min,max]`，或者反过来查这些值的最小、最大位置，可以寻找“位置与值域同时闭合”的段。相邻值间的蕴含关系也能表达闭合性。

所有共同区间可能交叉，不能一律直接连成包含树。挑出不与任何共同区间交叉的强区间，它们两两嵌套或不交，形成析合树的骨架；内部孩子有时能按同向或反向顺序连续合并，有时只能把整个节点当不可再简化的素块。必须保留节点类型，不能只存一棵普通子树树就代表全部连续段。

若给每位置连向左、向右第一个更大值，会得到另一种有序骨架。添加两个足够大且规定好优先级的边界，可把它画成多边形三角剖分，面间邻接又形成树；这说明“最近更大”的单调栈与平面对偶并非互不相关的技巧。

## 一组元素必须挨在一起，不等于次序固定

PQ 树表示允许的叶子排列。P 节点的孩子可任意换序，Q 节点的孩子只可整体正向或反向。每加入一组“必须连续”的约束，就缩减允许的叶子顺序族；若族为空，约束无解。

四个符号 A、B、C、D，要求 A、B 连续，B、C 也连续。只能把 ABC 或 CBA 当成一段，D 在两端任选：`ABCD,DABC,CBAD,DCBA`。可用一个 P 根，孩子为 Q(A,B,C) 与 D 表示，恰好四种。再要求 A、C 也相邻，三者两两相邻在线性排列里做不到，允许族变空。

一般约束更新把叶标为在集合内、外，向上区分全满、全空、部分节点，在相关子树按 P/Q 的局部形状归约，保持**全部且仅有**合法前沿。不能简单把约束集合“打包成一个新节点”，因为新旧集合可交叉；上例 B 同时属于两组，恰须转成可翻转的共同顺序。PQ 树不是析合树的别名，前者维护允许的排列族，后者描述一份排列已有的共同区间。

## 极值、选择与查询还可以继续分工

找第 k 小的确定性线性选择，可每五项一组取中位数，再递归选这些中位数的中位数作轴。至少约三成元素在轴两侧各一边，递归规模满足 `T(n)<=T(n/5)+T(7n/10+O(1))+O(n)`，总为 `O(n)`。它比随机快选更有最坏保证，却不必总在工程上更快。

区间 mex 是最小没出现的非负整数，长度 L 的区间 mex 不超过 L。可按右端离线，记录每个值最近出现位置，在值域线段树存最小最近位置，找第一个最近位置小于左端的值。区间众数没有相同的可减前缀结构，常用分块或莫队；不能从两个前缀众数推回区间众数。
