# 30　把完整的证明带到终点

一棵带长度的树，有多次维修任务。每次给几个地点，想知道连接这些地点的最小子树总长度。不是从根去每点的距离和，也不是必须走回起点的路程。

这道题把树的唯一道路、DFS 顺序和 LCA 接起来。先用纸笔做一次，再看程序。

## 一条边该不该保留

删掉一条树边，原树分成两侧。若两侧各有本次关键点，这条边必选；否则可删。这给出完整、唯一的最小连接子树，也给出一个朴素检查器：逐边检查两侧是否都有关键点。

关键点按 DFS 首次进入序排成 `v0,v1,...`，再首尾相接。把相邻关键点的距离全加起来，每条应保留的边恰好被走过两次：其孩子子树内的关键点在 DFS 序中连续，环形访问只进入、离开各一次。不应保留的边一次也不走。因此答案是这份距离和的一半。

与“随便给点排序后也除二”不同，连续性是证明的关键。重复关键点先去重；零或一个关键点，答案为零。

**停笔 1**　链 `0—1—2—3`，每边长度 1，关键点 1、3。最小连接长度与从根去两点的距离和分别多少？

## 预处理负责树，查询负责这次任务

倍增表回答 LCA；根距离给 `dist(u,v)=dist[u]+dist[v]-2*dist[lca]`。第一次遍历必须是真正的深度优先进入序，不是第二卷 LCA 示例里仅保证父先子的队列式 order。

**完整程序：**输入 `1 <= n <= 100000`、`0 <= q <= 100000`，随后 `n-1` 条 `u v length`，保证为树、边长 0 到一百万。每次先给 `0 <= k <= n`，再给 k 个合法关键点，可重复；全部查询给出的 k 总和不超过 200000。逐行输出最小连接子树长度。

```cpp
#include <algorithm>
#include <cstdio>
#include <utility>
#include <vector>

int main() {
    int n = 0;
    int q = 0;
    if (std::scanf("%d%d", &n, &q) != 2 || n < 1 || n > 100000 || q < 0 || q > 100000) { return 1; }
    std::vector<std::vector<std::pair<int, int>>> tree(n);
    for (int i = 1; i < n; ++i) {
        int u = 0;
        int v = 0;
        int length = 0;
        if (std::scanf("%d%d%d", &u, &v, &length) != 3 || u < 0 || u >= n || v < 0 || v >= n
            || length < 0 || length > 1000000) { return 1; }
        tree[u].emplace_back(v, length);
        tree[v].emplace_back(u, length);
    }
    int levels = 1;
    while ((1 << levels) <= n) { ++levels; }
    std::vector<std::vector<int>> up(levels, std::vector<int>(n, 0));
    std::vector<int> depth(n, 0), tin(n, 0), stack{0};
    std::vector<long long> distance(n, 0);
    int clock = 0;
    while (!stack.empty()) {
        int u = stack.back();
        stack.pop_back();
        tin[u] = clock++;
        for (const auto& edge : tree[u]) {
            int v = edge.first;
            if (v == up[0][u]) { continue; }
            up[0][v] = u;
            depth[v] = depth[u] + 1;
            distance[v] = distance[u] + edge.second;
            for (int p = 1; p < levels; ++p) { up[p][v] = up[p - 1][up[p - 1][v]]; }
            stack.emplace_back(v);
        }
    }
    auto lca = [&](int u, int v) {
        if (depth[u] < depth[v]) { std::swap(u, v); }
        int difference = depth[u] - depth[v];
        for (int p = 0; p < levels; ++p) { if (difference & (1 << p)) { u = up[p][u]; } }
        if (u == v) { return u; }
        for (int p = levels - 1; p >= 0; --p) {
            if (up[p][u] != up[p][v]) { u = up[p][u]; v = up[p][v]; }
        }
        return up[0][u];
    };
    for (int query = 0; query < q; ++query) {
        int k = 0;
        if (std::scanf("%d", &k) != 1 || k < 0 || k > n) { return 1; }
        std::vector<int> keys(k);
        for (int& v : keys) { if (std::scanf("%d", &v) != 1 || v < 0 || v >= n) { return 1; } }
        std::sort(keys.begin(), keys.end(), [&](int u, int v) { return tin[u] < tin[v]; });
        keys.erase(std::unique(keys.begin(), keys.end()), keys.end());
        long long twice = 0;
        k = static_cast<int>(keys.size());
        for (int i = 0; i < k; ++i) {
            int u = keys[i];
            int v = keys[(i + 1) % k];
            twice += distance[u] + distance[v] - 2 * distance[lca(u, v)];
        }
        std::printf("%lld\n", twice / 2);
    }
    return 0;
}
```

输入：

```text
4 3
0 1 2
1 2 3
1 3 5
2 2 3
3 0 2 3
0
```

输出：

```text
8
10
0
```

预处理时间空间 `O(n log n)`；一次 k 点查询 `O(k log k+k log n)`，空查询 `O(1)`。总查询规模的约定不能漏掉，否则即使每题都快，总输入仍可能大得无法保存或读完。

## 还可以完成两份不同作品

**再试一题 A：**一排颜色，依次发生单点改色与区间不同数查询。先写每问重新建集合的完整朴素版，再选择带修改莫队或其他适合范围的方法。带修改莫队把查询记作 `(left,right,time)`，移动时间时先撤掉窗口内旧颜色、改数组、加上新颜色；记录修改前后两值才能回退。复杂度由三维移动与块长重新计算，不能沿用静态莫队的原界。

**再试一题 B：**任务分两组，各有容量与配对收益，要分配恰好 K 次且每个具体任务最多一次。连源到左组、允许配对边、右组到汇，容量按题意设，配对边费用为收益的负数。恰好送 K 单位最小费用，取反就是最大收益；送不满要报告不可行。零流原图是分层 DAG，符合第 12 章示例前提。若同一任务允许多份，不是改收益，而是改相应容量。

这两题的核对分别看“每次操作后的真实数组”与“枚举所有小配对”，不能让快程序与朴素版共用一份已经可能出错的窗口或剩余流状态。
