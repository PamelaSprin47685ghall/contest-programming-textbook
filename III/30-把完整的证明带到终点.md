# 30　把完整的证明带到终点

村里要修路，把几个村子连起来。每条可以修的路都有造价，要让任意两个村子之间都能走通，总造价最低。办法很多人都想得到：先修最便宜的，修到成圈的就跳过。可是如果有人问“为什么这样就是最便宜的”“再加一条新路，要不要拆一条旧的”“有没有第二便宜的方案”，就得有一份从头到尾说得通的证明，而不是一句“看起来对”。

这一章用最小生成树把整卷的做法再走一遍：先证明，再设计预处理和查询，最后算出第二份方案。最后一节离开本书：先独立做一道题，再回头看这一卷，最后说说接下来往哪里走。

## 一条边该不该保留

连通的无向图里，包含所有点、没有圈的边集是[第二卷第 13 章](../II/13-只记住谁和谁是一组.md)的生成树，n 个点的生成树恰好有 n − 1 条边；边权之和最小的是最小生成树。

那一章的 Kruskal 算法（克鲁斯卡尔算法）把边从轻到重排好，依次看每条边：两端已经连通就跳过，否则收下。判断连通用[第二卷第 13 章](../II/13-只记住谁和谁是一组.md)的并查集。要证明它对，靠两条性质。

**割的性质**：把点分成两组，横跨两组的边里最轻的那条 e，一定在某棵最小生成树里。证明：任取一棵最小生成树 T。若 e 不在 T 里，把 e 加进 T，就成了一个圈；圈从一组走到另一组再回来，除 e 之外至少还有一条横跨的边 f。f 不比 e 轻，把 f 换成 e，得到的仍是生成树，权和不变大，所以也是最小生成树，而且含 e。

**圈的性质**：一个圈上严格最重的边，不在任何最小生成树里。证明：设 T 含有这条边 f，把 f 删掉，T 分成两块；圈上除 f 之外的边连起了 f 的两端，所以其中某条边 g 横跨这两块。用 g 换 f，权和严格变小，与 T 最小矛盾。

用割的性质，可以对克鲁斯卡尔做归纳：每收下一条边之前，已收的边都包含在某棵最小生成树里。要收下的边 e 连接两个还不连通的块，取 e 一端所在的块当一组，其余的点当另一组，已经看过的更轻的边都没有横跨这两组，否则这两块早就连通了，所以 e 是横跨的边里最轻的。把割的性质的证明照做一遍，并且选的 f 不在已收的边里（已收的边都不横跨这个割），就得到一棵同时含有已收边和 e 的最小生成树。看完所有边，收下的 n − 1 条边就是一棵最小生成树。

把两条性质合起来，能回答“一条边该不该保留”：边 e = (u, v)，权 w。只用比 w 轻的边已经能把 u、v 连通，e 就是那个圈上严格最重的，不在任何最小生成树里；否则 e 在某棵最小生成树里。

## 预处理负责树，查询负责这次任务

现在问：在原图里再加一条边 (a, b)，权 w，新的最小生成树权和是多少？每次询问都重做克鲁斯卡尔，要 O(m log m)；询问有十万次就太慢。

先证明新的最小生成树只需要在 T 加上新边里找。原图里不在 T 上的每条边 f，和 T 上连接它两端的路成一个圈，f 在圈上不比别的边轻；按圈的性质的证明，可以把 f 拿掉而最小生成树的权和不变（f 和别的边一样重时，也存在一棵不含 f 的最小生成树）。这些圈只用到 T 的边，加上新边以后仍在，所以可以一条条拿掉。剩下的是 T 加上新边，只有一个圈：新边和 T 上 a 到 b 的路。去掉圈上最重的一条，就是答案：

新权和 = T 的权和 − max(路上最重的边, w) + w。

于是预处理负责树，查询负责这一次的任务：把 T 以 1 为根，用[第二卷第 14 章](../II/14-没有圈的地图多了什么.md)的倍增祖先表（想法来自[第二卷第 7 章](../II/07-把一大步拆成几小步.md)），记下每个点往上 2^j 步到达哪里、这 2^j 条边里最重的是多少。查询时先把较深的点提到一样深，再一起往上跳，停在最近共同祖先下面，一路取最大值。

下面是**完整程序 A**。输入第一行是 n、m（n ≤ 10⁵，m ≤ 2 × 10⁵），接着 m 行，每行一条边 u v w（1 ≤ w ≤ 10⁹），保证图连通；再一行 q（q ≤ 10⁵），接着 q 行，每行一个询问 a b w。先输出原图最小生成树的权和，再对每个询问输出一行。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

struct Edge {
    int u;
    int v;
    long long w;
};

bool lighter(const Edge& a, const Edge& b) {
    return a.w < b.w;
}

int find_root(std::vector<int>& boss, int x) {
    while (boss[x] != x) {
        boss[x] = boss[boss[x]];          // 顺手让路径减半
        x = boss[x];
    }
    return x;
}

const int levels = 17;                    // 2^17 > 10^5

// up[j][v]：v 往上 2^j 步到达的点；heavy[j][v]：这 2^j 条边里最重的
std::vector<std::vector<int>> up;
std::vector<std::vector<long long>> heavy;
std::vector<int> depth;

long long path_max(int a, int b) {
    long long best = 0;
    if (depth[a] < depth[b]) {
        std::swap(a, b);
    }
    for (int j = levels - 1; j >= 0; --j) {      // 先把 a 提到和 b 一样深
        if (depth[a] - (1 << j) >= depth[b]) {
            best = std::max(best, heavy[j][a]);
            a = up[j][a];
        }
    }
    if (a == b) {
        return best;
    }
    for (int j = levels - 1; j >= 0; --j) {      // 再一起往上，停在公共祖先下面
        if (up[j][a] != up[j][b]) {
            best = std::max(best, std::max(heavy[j][a], heavy[j][b]));
            a = up[j][a];
            b = up[j][b];
        }
    }
    return std::max(best, std::max(heavy[0][a], heavy[0][b]));
}

int main() {
    int n = 0;
    int m = 0;
    if (std::scanf("%d%d", &n, &m) != 2) {
        return 1;
    }
    std::vector<Edge> edges(m);
    for (int i = 0; i < m; ++i) {
        if (std::scanf("%d%d%lld", &edges[i].u, &edges[i].v, &edges[i].w) != 3) {
            return 1;
        }
    }
    // 克鲁斯卡尔：从轻到重，不成圈就收下
    std::sort(edges.begin(), edges.end(), lighter);
    std::vector<int> boss(n + 1, 0);
    for (int v = 1; v <= n; ++v) {
        boss[v] = v;
    }
    std::vector<char> in_tree(m, 0);
    std::vector<std::vector<int>> near(n + 1);    // near[v]：树上和 v 相连的边的编号
    long long total = 0;
    for (int i = 0; i < m; ++i) {
        int a = find_root(boss, edges[i].u);
        int b = find_root(boss, edges[i].v);
        if (a != b) {
            boss[a] = b;
            in_tree[i] = 1;
            total += edges[i].w;
            near[edges[i].u].push_back(i);
            near[edges[i].v].push_back(i);
        }
    }
    // 以 1 为根，求每个点的父亲、深度和连向父亲的边权
    up.assign(levels, std::vector<int>(n + 1, 1));
    heavy.assign(levels, std::vector<long long>(n + 1, 0));
    depth.assign(n + 1, 0);
    std::vector<char> seen(n + 1, 0);
    std::vector<int> todo(1, 1);
    seen[1] = 1;
    while (!todo.empty()) {
        int v = todo.back();
        todo.pop_back();
        for (int id : near[v]) {
            int other = edges[id].u == v ? edges[id].v : edges[id].u;
            if (seen[other] == 0) {
                seen[other] = 1;
                up[0][other] = v;
                heavy[0][other] = edges[id].w;
                depth[other] = depth[v] + 1;
                todo.push_back(other);
            }
        }
    }
    for (int j = 1; j < levels; ++j) {
        for (int v = 1; v <= n; ++v) {
            int mid = up[j - 1][v];
            up[j][v] = up[j - 1][mid];
            heavy[j][v] = std::max(heavy[j - 1][v], heavy[j - 1][mid]);
        }
    }
    std::printf("%lld\n", total);

    int q = 0;
    if (std::scanf("%d", &q) != 1) {
        return 1;
    }
    for (int t = 0; t < q; ++t) {
        int a = 0;
        int b = 0;
        long long w = 0;
        if (std::scanf("%d%d%lld", &a, &b, &w) != 3) {
            return 1;
        }
        // 新边和树上 a 到 b 的路成一个圈，去掉圈上最重的一条
        long long drop = a == b ? w : std::max(path_max(a, b), w);
        std::printf("%lld\n", total - drop + w);
    }
    return 0;
}
```

样例输入：

```text
4 5
1 2 3
2 3 1
3 4 4
1 4 2
1 3 5
2
2 4 1
1 3 6
```

样例输出：

```text
6
4
6
```

树是 2−3、1−4、1−2，权和 6。加 2−4 权 1：树上 2 到 4 的路是 2−1−4，最重的是 1−2 权 3，换掉它，6 − 3 + 1 = 4。加 1−3 权 6：路 1−2−3 最重是 3，比 6 轻，不换，仍是 6。

建树用一个栈，不用递归，n = 10⁵ 的长链也不会撑破调用栈。`up` 的初值都是 1：根往上跳仍停在根，连向根的“边权”是 0，不影响最大值。权和最大约 10⁵ × 10⁹ = 10¹⁴，用 `long long`。预处理 O(m log m + n log n)，每次询问 O(log n)。对拍的慢程序对每个询问把新边加进去，重做一遍克鲁斯卡尔。

## 还可以完成两份不同作品

再问：边集和最小生成树不完全一样的生成树里，权和最小是多少？这叫**次小生成树**。它的权和可以和最小生成树相等，那时最小生成树不唯一。

可以证明，总有一棵次小生成树和 T 只差一条边：换进一条不在 T 上的边 f，换出 T 上 f 两端之间路上的某条边。证明的想法和割的性质一样：任取一棵次小生成树 T′，在 T′ 和 T 不同的边之间反复做交换，每次权和不增，直到只差一条边。既然只换一条，换出的当然应该是路上最重的那条，所以只要对每条不在 T 上的边，算一次 T 的权和 − 路上最重 + f 的权，取最小。这正好用上程序 A 的预处理。

**片段：**

```cpp
// 位于 main 内，程序 A 建好倍增表以后：次小生成树的权和
// 换进一条不在树上的边，换出它和树上路径成圈时最重的那条
bool has_other = false;
long long second = 0;
for (int i = 0; i < m; ++i) {
    if (in_tree[i] == 1 || edges[i].u == edges[i].v) {
        continue;
    }
    long long candidate = total - path_max(edges[i].u, edges[i].v) + edges[i].w;
    if (!has_other || candidate < second) {
        has_other = true;
        second = candidate;
    }
}
if (has_other) {
    std::printf("%lld\n", second);
} else {
    std::printf("-1\n");                  // 这张图只有一棵生成树
}
```

这个片段放在程序 A 输出 `total` 的那一行之后。自环换进来不成生成树，跳过。没有任何可以换进来的边时，图本身就是一棵树，只有一棵生成树，输出 −1。样例的图里，不在树上的是 3−4 权 4 和 1−3 权 5：前者的路 3−2−1−4 最重是 3，得 6 − 3 + 4 = 7；后者得 6 − 3 + 5 = 8。次小生成树权和是 7。对拍的慢程序枚举所有 n − 1 条边的组合，挑出生成树，排序取第二个。

## 核对与继续学习

### 先不翻书，试着独立做一次

给一张连通的无向图，n ≤ 10⁵ 个点，m ≤ 2 × 10⁵ 条边，边权是正整数，没有自环。对每条边，按输入顺序回答它属于下面哪一种：在每一棵最小生成树里（输出 `all`）；在某些但不是全部最小生成树里（输出 `some`）；不在任何最小生成树里（输出 `none`）。

例如输入

```text
4 5
1 2 1
2 3 1
1 3 1
3 4 2
2 4 3
```

应输出

```text
some
some
some
all
none
```

先用纸笔做，不急着写程序。**停笔 4**　先回答三个小问题：边 2−4 为什么是 `none`？三条权 1 的边为什么都不是 `all`？要是把权相同的边放在一起处理，处理权为 w 的这一批时，比 w 轻的边已经把哪些点连在一起了，这些信息该怎样用？

做完再核对。按权从小到大，一批一批处理权相同的边。处理权为 w 的一批之前，并查集里已经并好了所有更轻的边。一条边两端已经在同一块里，就是 `none`。其余的边至少是 `some`；要判断是不是 `all`，把每一块缩成一个点，只看这一批边组成的小图：一条边在这张小图里是桥，就是 `all`，否则它在一个圈上，换成圈上另一条同样重的边也行，是 `some`。找桥参看[第 9 章](09-找出地图上不能轻易断的地方.md)《找出地图上不能轻易断的地方》。缩点以后的小图常有重边，搜索时只跳过来时走的那一条边（按边的编号认），不能跳过整个父亲点，否则两条一样重的平行边会被误判成桥；小图要按这一批的边重新编号，避免每批都扫一遍所有点。最后把这一批边全部并进并查集，处理下一批。

再给自己找三个反例：所有边权都相同；所有边权都不同；两点之间有两条一样重的边。能说出每种情况下答案是什么、程序会怎样走，就比“样例刚好对”多了一层把握。

## 核对

1. 收下 2−3（权 1）、1−4（权 2）、1−2（权 3），权和 6；3−4 和 1−3 两端已经连通，跳过。边 3−4 和圈 3−2−1−4−3 上的另外三条边权是 1、3、2，它是这个圈上严格最重的，按圈的性质不在任何最小生成树里。
2. 新边 3−4 权 2，树上 3 到 4 的路是 3−2−1−4，最重的是 1−2 权 3，比 2 重，换掉它：6 − 3 + 2 = 5。
3. 最小生成树任取两条边，权和 2。另外两棵生成树权和也是 2，所以次小生成树权和是 2。片段里唯一不在树上的边换进来，换出路上权 1 的边，得 2 − 1 + 1 = 2，输出 2。
4. 2−4 权 3，比它轻的边已经把 1、2、3、4 全部连通（2−3、3−4 就连起了 2 和 4），所以它是某个圈上严格最重的，是 `none`。三条权 1 的边组成一个圈，每条都能被另外两条之一替换，所以都是 `some`。处理权为 w 的一批时，比 w 轻的边已经并好了若干块；同一块里的点之间不需要权为 w 的边，跨块的边才有用，把每块缩成一个点，就只剩这一批边组成的小图要判断。
