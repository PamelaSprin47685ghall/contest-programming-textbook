# 把难题拆到能检查

这是《彻底颠覆版学生手册》第三卷。读完第二卷，你已经有一组能独立使用的办法。接下来不是把模板越背越长，而是看看：几项条件碰在一起，原来的办法还能保留多少，应该怎样改变。

读者仍是从小学高年级开始学的你；这不表示所有高级内容都必须在小学学完。会 C++ 不等于已学过概率、矩阵或凸性。遇到新对象先画两三个具体例子，公式读不顺就查[把记号读成一句话](查阅-把记号读成一句话.md)。没有时间要求，也没有“到某章才算聪明”的分界。

## 先选一条短路线

**继续做题的路线：**1、2、3、4、5、7、9、14、15、28，最后做第 30 章。它们主要接着第二卷的序列、树、搜索与字符串。

**慢慢补数学的路线：**17、18、19、20、21、22、23、24。概率第一次出现时可先读 22 的前两节，再看其他章用到的“期望”。线性方程初次接触先读 8 的纸笔例子，再读 19。

**带读的深入路线：**6、8、10—13、16、25—27、29。先复习对应的基础问题，再用一节时间只读一个推导。SMAWK、带花、PQ 树、形式幂级数与实时维护等节更适合已经能解释前面例子的读者；不是读到标题就必须独立写出工业级实现。

全卷有 30 章、90 组停笔练习，另有 6 组数学记号练习，均有核对。23 份完整程序覆盖各条主线；没有程序的章节用完整的小例子推导、计算并检查，不以省略号冒充实现。正文讲清问题、条件、核心步骤和保证，不为每个理论名词重复铺一份长模板。

## 怎样检查，而不是怎样背

代码继续用 C++14、标准头文件、`std::`，约定与[第二卷](../II/README.md)一致。树图点号及序列从 0 开始，区间默认半开。一个算法的输入保证，尤其非负权、单调性、无负圈、模数和乘积范围，是程序契约的一部分。

完整程序可以单独编译；交互程序必须由真正一问一答的本地裁判驱动。构造检查条件而非固定输出；近似检查合法性与界；概率保证检查模型与误差；不要让一种核对冒充另一种。

本卷先解释动机，再给可以复核的核心理由。没有声称这些练习已经证明所有推广，也没有声称每一位小学读者都经过试读。遇到推导卡住，停在那个具体问题上，比继续背后面的名词有用。

## 继续读原始讲义

完成某个主题后，可对照 Jeff Erickson 在伊利诺伊大学公开的 [Algorithms 与课程讲义](https://jeffe.cs.illinois.edu/teaching/algorithms/)。其中明确列出前置要求，适合在本册之后按主题选读，不是把整本英文书当作孩子的新起点。递归、DP、流与归约可查主书；拟阵、费用流、线性规划、近似与均摊可查扩展讲义。

那里的 [Proof by Induction](https://jeffe.cs.illinois.edu/teaching/algorithms/notes/98-induction.pdf) 与 [Solving Recurrences](https://jeffe.cs.illinois.edu/teaching/algorithms/notes/99-recurrences.pdf) 可供带读者核对证明方式。这些是继续阅读的来源入口，本卷的情境、练习与组织另行写作，没有搬用其中习题或以改名替代重写。

## 这次实际核对了什么

23 个完整程序使用 GCC 16.2.1，按 `-std=c++14 -O1 -g -Wall -Wextra -Werror -pedantic -fsanitize=undefined -fno-sanitize-recover=all` 编译通过，并完成 623 组运行场景：22 组印出的普通样例、528 组固定种子独立小数据对照、22 组普通程序缺失输入、24 组上限或退化场景，以及 27 组真实交互会话。

对照包括原始平方级 DP、排序取第 k 小、删边重算连通、枚举配对、枚举割、枚举可行流、逐子串判等与回文、逐项卷积、分数期望、博弈状态搜索、独立凸包算法和逐边检查关键点连通。大数据实际覆盖持久化节点扩展、百万字节回文、十万项卷积、十万点树及坐标极值下的整数面积。

交互会话由本地裁判启动正文原程序，读取问题后实时回复；24 个秘密均正确结束，最多 20 问，另验证 `-1`、无效回复和 EOF 后停止。不是用预置回复文件代替对话。

纸笔部分另枚举核对了 Lyndon 分解、Prüfer 编解码、杨表形状、PQ 小例子、旋转涂色和点覆盖近似等局部结论。96 组停笔与核对编号匹配，本卷 32 个本地文档链接可解析。没有据此声称全部理论推广均经机械证明，也没有真实小学生试读或其他平台兼容性的验证记录。
