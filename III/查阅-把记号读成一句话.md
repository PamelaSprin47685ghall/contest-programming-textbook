# 查阅　把记号读成一句话

这页像工具箱，不必一次背完。第三卷的证明里会出现不少数学记号，它们只是把一句话写短了。读到一个记号时，先把它念成一句中文，再往下看；念不出来，就回到这页查。每节先列记号和读法，再说一两个容易出错的地方。

## 求和与连乘

| 记号 | 读成一句话 | 例子 |
|---|---|---|
| Σ_{i=1}^{n} f(i) | 让 i 从 1 走到 n，把每个 f(i) 加起来 | Σ_{i=1}^{3} i² = 1 + 4 + 9 = 14 |
| ∏_{i=1}^{n} f(i) | 让 i 从 1 走到 n，把每个 f(i) 乘起来 | ∏_{i=1}^{4} i = 24 |
| Σ_{x∈S} f(x) | 对集合 S 里的每个 x，把 f(x) 加起来 | S = {2, 5} 时 Σ x = 7 |
| n! | 1 × 2 × …… × n，0! = 1 | 5! = 120 |

求和就是一个循环。下标的范围是空的（比如 n = 0）时，和是 0，积是 1，循环一次也不做，变量保持初值，正好对上。

**片段：**

```cpp
// 位于 main 内：Σ 就是一个循环，∏ 也是
long long sum = 0;                       // 空的和是 0
long long product = 1;                   // 空的积是 1
for (int i = 1; i <= n; ++i) {
    sum += 1LL * i * i;
    product *= i;
}
std::printf("%lld %lld %lld\n", sum, 1LL * n * (n + 1) * (2 * n + 1) / 6, product);
```

第二个数是公式 n(n + 1)(2n + 1)/6，和第一个数应当相等。n ≤ 20 时 n! 还放得进 `long long`，20! ≈ 2.4 × 10¹⁸，21! 就放不下了。

**停笔 1**　Σ_{i=1}^{n} Σ_{j=1}^{i} 1 等于多少？把它写成两层循环，里层一共执行几次？

## 取整、整除与余数

| 记号 | 读成一句话 | 例子 |
|---|---|---|
| ⌊x⌋ | 不超过 x 的最大整数，向下取整 | ⌊3.7⌋ = 3，⌊−3.5⌋ = −4 |
| ⌈x⌉ | 不小于 x 的最小整数，向上取整 | ⌈3.2⌉ = 4，⌈−3.5⌉ = −3 |
| a mod b | a 除以 b 的余数，本卷总取 0 到 b − 1 | 17 mod 5 = 2，−7 mod 2 = 1 |
| a ≡ b (mod m) | a 和 b 除以 m 余数相同，即 m 整除 a − b | 17 ≡ 2 (mod 5) |
| a ∣ b | a 整除 b，b 是 a 的倍数 | 3 ∣ 12 |
| gcd(a, b) | a 和 b 的最大公约数 | gcd(12, 18) = 6 |

最容易出错的是负数。C++ 的 `a / b` 向 0 截断，`-7 / 2` 是 −3，而 ⌊−7/2⌋ = −4；`a % b` 的符号跟着 a，`-7 % 2` 是 −1，而 −7 mod 2 = 1。数学上的写法要求 a = ⌊a/b⌋ × b + (a mod b)，余数在 0 到 b − 1 之间。

**片段：**

```cpp
// 位于 main 之前：b > 0 时的 ⌊a / b⌋ 和 a mod b（结果在 0 到 b − 1 之间）
long long floor_div(long long a, long long b) {
    long long q = a / b;                 // C++ 的除法向 0 截断
    if (a % b != 0 && a < 0) {
        --q;                             // 负数时多减 1，才是向下取整
    }
    return q;
}

long long mod_of(long long a, long long b) {
    long long r = a % b;                 // 余数的符号跟着 a
    if (r < 0) {
        r += b;
    }
    return r;
}
```

对 a 从 −50 到 50、b 从 1 到 12 的每一对，都满足 `floor_div(a, b) * b + mod_of(a, b) == a`，余数在 0 到 b − 1 之间。

**停笔 2**　⌊−1/3⌋、⌈−1/3⌉、−1 mod 3 各是多少？C++ 里的 `-1 / 3` 和 `-1 % 3` 呢？

## 集合与计数

| 记号 | 读成一句话 |
|---|---|
| x ∈ S、x ∉ S | x 是（不是）S 里的元素 |
| A ⊆ B | A 里的每个元素都在 B 里，A 可以等于 B |
| A ∪ B、A ∩ B、A \ B | 在 A 或 B 里；同时在 A 和 B 里；在 A 里但不在 B 里 |
| ∅ | 空集合 |
| \|S\| | S 里元素的个数 |
| C(n, k) | 从 n 个不同的东西里挑出 k 个、不管次序的挑法数 |
| a ⊕ b | 两个数逐位异或；用在集合上，是“恰好在一个里”的元素 |

C(n, k) = n! ÷ (k! × (n − k)!)，k < 0 或 k > n 时规定为 0。C(n, 0) = C(n, n) = 1。算 C(n, k) 时不要先算 n! 再除，n 稍大就会溢出；可以用杨辉三角一行行加，或者在取模时乘上逆元。

**停笔 3**　A = {1, 2, 3}，B = {2, 3, 4}。写出 A ∪ B、A ∩ B、A \ B 和 |A ∪ B|。C(5, 2) 和 C(5, 3) 为什么相等？

## 增长的快慢

| 记号 | 读成一句话 |
|---|---|
| f(n) = O(g(n)) | n 足够大以后，f(n) 不超过 g(n) 的某个常数倍 |
| f(n) = Ω(g(n)) | n 足够大以后，f(n) 不小于 g(n) 的某个正常数倍 |
| f(n) = Θ(g(n)) | 两者都成立，f 和 g 是同一个量级 |
| log n | 本卷不写底数时指以 2 为底；在 O 里底数不影响，只差一个常数倍 |

O 只是上界：说一个算法是 O(n²)，它也可能其实是 O(n)。要说“不会更快”，得用 Ω。量级比较时，常数和低次项都不算：3n² + 100n = Θ(n²)。可是数步数时它们仍然存在，n 不大时，常数可能比量级更要紧。

**停笔 4**　n log n、n²、2ⁿ、n、√n，从慢到快排一排（n 很大时）。100n 是不是 O(n²)？是不是 Θ(n²)？

## 机会与平均

| 记号 | 读成一句话 |
|---|---|
| Pr[A] | 事件 A 发生的概率 |
| Pr[A ∣ B] | 已知 B 发生时，A 发生的概率，等于 Pr[A 和 B 都发生] ÷ Pr[B] |
| E[X] | 随机变量 X 的期望，每个取值乘以它的概率再相加 |
| Var[X] | X 的方差，E[(X − E[X])²]，衡量离平均有多远 |

E[X + Y] = E[X] + E[Y] 总成立，不要求 X、Y 互不影响；E[XY] = E[X] E[Y] 却要求两者独立。条件概率里的竖线和整除的竖线长得一样，看上下文区分：方括号里的是概率。

## 逻辑与方向

| 记号 | 读成一句话 |
|---|---|
| ∀x | 对每一个 x |
| ∃x | 存在某个 x |
| P ⇒ Q | 如果 P 成立，那么 Q 成立 |
| P ⇔ Q | P 成立当且仅当 Q 成立，两个方向都要证 |
| u · v | 点积 ac + bd，看两个方向的夹角 |
| u × v | 叉积 ad − bc，看 v 在 u 的左边还是右边 |

“∀x ∃y”和“∃y ∀x”不一样：前者说每个 x 都能找到自己的 y，后者说有一个 y 对所有 x 都行。证明“当且仅当”时，两个方向要分开写，常见的错是只证了一边。

**停笔 5**　把“∀ 正整数 n，∃ 素数 p，p > n”念成一句话。把 ∀ 和 ∃ 的次序交换以后，意思变成什么？它还对吗？

## 核对

1. 等于 1 + 2 + …… + n = n(n + 1)/2。外层 i 从 1 到 n，里层 j 从 1 到 i，里层一共执行 n(n + 1)/2 次。
2. ⌊−1/3⌋ = −1，⌈−1/3⌉ = 0，−1 mod 3 = 2。C++ 里 `-1 / 3` 是 0，`-1 % 3` 是 −1。
3. A ∪ B = {1, 2, 3, 4}，A ∩ B = {2, 3}，A \ B = {1}，|A ∪ B| = 4。挑出 2 个，就是同时决定了留下的 3 个，两种挑法一一对应，都是 10。
4. √n、n、n log n、n²、2ⁿ。100n 是 O(n²)，因为 n ≥ 100 时 100n ≤ n²；但不是 Θ(n²)：不论正常数 c 多小，n 足够大时 100n 都小于 c × n²。
5. “对每个正整数 n，都存在一个比 n 大的素数”，这是对的，素数有无穷多个。交换以后是“存在一个素数 p，它比每个正整数都大”，这不对，任何素数都不比它自己大。
