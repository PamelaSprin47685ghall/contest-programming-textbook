# 查阅　把记号读成一句话

公式太挤时，不必一口气读。先找每个字母代表什么，再把一个具体数字代进去。本页只为读本卷服务，不要求提前学完中学数学。

## 一次把一串加法写完

`sum` 或 `∑` 都表示求和。例如 `sum_{i=1}^4 i` 就是 `1+2+3+4=10`。下面的 i 是依次变化的编号，不是另一个输入。

`prod` 或 `∏` 表示连乘，例如 `prod_{i=1}^4 i=24`。没有项的和规定为 0，没有项的积规定为 1，便于把边界放进同一规则。

`n!` 读作 n 的阶乘，为 1 到 n 的连乘。`C(n,k)` 是从 n 个不同对象选 k 个、不看先后。`2^n` 在数学公式里是次方；C++ 的 `^` 却是异或，不能照抄。

**停笔 1**　`sum_{i=0}^2 (2*i+1)` 是几？`C(3,1)` 与 `3!` 各是几？

## 最小值与在哪里最小，是两种答案

`min{7,3,5}=3`，是最小的数值；`argmin` 问哪个位置达到最小，例如这排数从 0 编号，答案是位置 1。若多处相同，题目要说取哪一个，或返回全部位置。

`max` 类似。`sup` 是最小上界：正数 x 严格小于 1 时，没有最大 x，却有上确界 1。算法里用一个很大的整数当“不可达”是实现约定，不是真的把数学无穷大塞进变量。

**停笔 2**　`5,2,2` 的最小值与所有取到最小值的位置分别是什么？不可达哨兵能否直接加边权而不检查溢出？

## 一段范围、一组配对

`[l,r)` 包含左端，不包含右端。整数下标 `[1,4)` 是 1、2、3；实数范围则还包含 1.5 等许多值。看清讨论的是整数位置还是连续数轴。

集合 `{1,3}` 没有重复也不靠顺序定义。`A∪B` 是并集，`A∩B` 是交集，`A\B` 是 A 中不在 B 的元素。`A⊆B` 表示 A 每个元素都在 B。

`A×B` 是所有有序配对，不是把两集合做数值乘法。例如 `{1,2}×{R,B}` 有 `(1,R),(1,B),(2,R),(2,B)` 四对。

**停笔 3**　A={1,2}、B={2,3}，并集、交集、A\B 各是什么？

## 函数只是说清怎样从输入得到结果

`f(x)=x²+1`，给 3 得 10。`f(g(x))` 表示先做 g，再把结果交给 f；顺序可能影响答案。向量 `(x,y)` 就是按顺序放好的两个数，矩阵先当成规则整齐的数表，乘法会在正文从“连续做两次变换”解释。

`a≡b (mod m)` 表示两数相差 m 的整数倍，不是普通相等。9 与 1 模 4 同余，实际仍是不同整数。除以一个数前，必须知道它在当前运算规则里可逆。

`[x^k]F(x)` 在生成函数里是“取 x 的 k 次项系数”。例如 `[x²](1+3x+5x²)=5`。它不是求 x，也不是把 x 取成 k。

**停笔 4**　f(x)=x+1，g(x)=2x，f(g(3)) 与 g(f(3)) 各多少？

## 用“次数”衡量增长

`log2 n` 问“2 的多少次方是 n”。2 的 10 次方为 1024，所以 `log2 1024=10`。非整幂时对数可以是小数；二分实际执行次数则要按边界向上取整。

`O(f(n))` 说有一个固定倍数，上界最终不超过该增长量级；`Ω` 给相应下界；`Θ` 表示两边都有。不是说 n 小时就一定谁快，固定成本和内存访问仍重要。

ε 通常读作 epsilon，表示给定误差要求；λ 读作 lambda，正文常用作价格参数。它们只是名字，不会自动很小、很大或拥有某条性质。概率 p=1/4 表示同样模型下四份机会中的一份，不能把一次试验结果当作概率本身。

**停笔 5**　每次剩下一半，从 64 到 1 要缩几次？如果误差要求从 0.1 改成 0.001，能不检查代价就说“反正都是一个 ε”吗？

## 说明“总是如此”，不能只列三项

归纳法先证明最小规模成立，再说明：若较小规模都成立，当前规模也成立。归并排序正确性就这样证明：两半已排好，合并每次取较小开头，最终整排有序。归纳假设不是“想当然”，必须严格请求更小规模，才能从已证明的起点逐层推出。

反证法先假设结论失败，再由约束推出矛盾。交换论证则把一份最优解合法改成另一份同样好的解。写证明时允许画图、列小表、用自然语言；关键是没有遗漏的情况，不是符号数量。

**停笔 6**　“n=1、2、3 都对，所以所有 n 都对”缺少哪一步？递归函数若又请求相同规模，为什么不能用普通的规模归纳为它结束作证明？

1. `1+3+5=9`；3 与 6。
2. 最小值 2，位置 1、2；哨兵加法也可能溢出，须按范围设计并检查来源。
3. `{1,2,3}`、`{2}`、`{1}`。
4. 7 与 8，复合不能随意交换。
5. 六次；误差变严会改变采样量、迭代轮数或状态规模，要重新计账。
6. 缺少从小规模推到下一规模的一般理由。相同规模没有朝已知起点前进，可能陷入循环。
