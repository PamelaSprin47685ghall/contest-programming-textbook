# P3　吃草路线（Grazing Patterns）

## 题目

农夫约翰把农场缩小成一块 $5 \times 5$ 的方格草地，左上角是 $(1,1)$，右下角是 $(5,5)$。除了 $K$ 块不长草的荒地，每格都有草。$K$ 是偶数，且 $(1,1)$ 和 $(5,5)$ 一定有草。

Bessie 从 $(1,1)$ 开始吃草，Mildred 从 $(5,5)$ 开始吃草。每半小时，她们吃完当前格的草后，各自走到相邻（上下左右）的**有草**格子上。

她们想吃完所有有草的格子，并且最终停在**同一个**格子。请算出有多少种不同的走法。她们总是走到有草的格子上，而且除非那是最后一块有草的格子，否则她们不会同时走到同一格。

## 输入

- 第一行一个整数 $K$（$0 \le K \le 22$，偶数）。
- 接下来 $K$ 行，每行两个整数 $i$ $j$，表示一块荒地的位置。

## 输出

一个整数：Bessie 和 Mildred 吃完所有草并停在同一点的不同走法数。

## 样例

输入：

```text
4
3 2
3 3
3 4
3 1
```

输出：

```text
1
```

解释：唯一一种方案是她们在 $(3,5)$ 相遇。

## 思路

草地只有 $5\times5=25$ 格，很小，可以直接**搜索**（深度优先遍历）枚举所有走法。

关键约束：两人要吃完**所有**有草的格子，且最后停在同一点。可以这样想：两人走过的格子合起来必须覆盖全部可走的格子，而且不能重复走。这等价于找一条从 $(1,1)$ 到 $(5,5)$ 的“哈密顿路”——一条经过每个可走格子恰好一次、从左上角到右下角的路。因为两人从两端相向走、最终汇合，正好对应这样一条覆盖全部格子的路。

实现时用递归搜索：从起点出发，每次向四个方向走一步，标记已访问，走到终点时检查走过的格数是否等于全部可走格数，相等就计数。荒地直接跳过。
