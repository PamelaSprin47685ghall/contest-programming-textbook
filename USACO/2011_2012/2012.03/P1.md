# P1　乘以 17（Times 17）

## 题目

农夫约翰开了个写小程序的小生意。他的第一个任务看起来很简单：输入一个数 $N$，输出 $17$ 倍 $N$。

但客户突然打电话说：输入和输出都必须是**二进制**表示，而且这个数可能非常大。$N$ 的二进制表示最多有 1000 位。

请帮约翰完成：输入 $N$ 的二进制表示，输出 $17 \times N$ 的二进制表示。

## 输入

一行：$N$ 的二进制表示（最多 1000 位，没有前导零）。

## 输出

一行：$17 \times N$ 的二进制表示。

## 样例

输入：

```text
10110111
```

输出：

```text
110000100111
```

解释：二进制 `10110111` 是十进制 $183$，$183 \times 17 = 3111$，其二进制是 `110000100111`。

## 思路

1000 位的二进制数远超普通整数范围，要用字符串模拟大数。关键技巧：$17 = 16 + 1$，所以 $N \times 17 = N \times 16 + N$。而二进制里乘以 16 就是在末尾补 4 个 0（$2^4=16$）。

于是：把 $N$ 后面补上 4 个 0 得到 $N\times16$，再和 $N$ 做二进制加法即可。二进制加法就是逐位相加并处理进位。

实现时为了方便进位，把二进制字符串**低位放在前面**（反转存储），逐位相加、处理进位；最高位若有进位就多出一位。最后再反转回来输出。

## 复杂度

二进制数最多 1000 位，逐位相加是 $O(L)$（$L$ 是位数）。时间与空间都是 $O(L)$，$L \le 1000$。
