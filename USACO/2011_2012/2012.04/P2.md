# P2　三条直线（Three Lines）

## 题目

农夫约翰想用新买的监控系统监视他的 $N$ 头奶牛。第 $i$ 头奶牛在坐标 $(x_i, y_i)$，坐标是整数，且没有两头牛在同一个位置。

监控系统有三台特殊摄像机，每台能观察**一整条竖线或横线**上的所有奶牛。请判断：约翰能否布置这三台摄像机，使所有 $N$ 头牛都被覆盖。也就是说，能否用三条直线（每条要么水平、要么竖直）同时覆盖全部 $N$ 个位置。

## 输入

- 第一行一个整数 $N$（$1 \le N \le 50000$）。
- 接下来 $N$ 行，每行两个整数 $x_i$ 和 $y_i$（范围 $0$ 到 $1000000000$），表示第 $i$ 头牛的位置。

## 输出

一个整数：如果能用三条摄像机覆盖所有牛输出 `1`，否则输出 `0`。

## 样例

输入：

```text
6
1 7
0 0
1 2
2 0
1 4
3 4
```

输出：

```text
1
```

解释：三条线 $y=0$、$x=1$、$y=4$ 都是水平或竖直的，合起来覆盖了全部 6 个位置。

## 思路

只有三条线，每条要么竖（固定 $x$）要么横（固定 $y$）。可以逐个点处理：从左到右看每个点，如果它已经被某条已选的线覆盖，就跳过；如果还没被覆盖，就必须为它新开一条线（竖线取它的 $x$，或横线取它的 $y$）。

用递归搜索：维护已选的线集合，逐个处理点。对未覆盖的点，分别尝试加一条竖线或一条横线，然后继续处理后面的点。如果已选线数达到 3 还有未覆盖的点，就失败。只要找到一种方案覆盖全部点就成功。

因为每条线都取某个点的坐标，且只有横/竖两种选择，搜索空间很小。

## 复杂度

每个未覆盖点尝试两种线，线数最多 3，搜索分支有限；检查覆盖时对每条已选线 $O(1)$。实际运行很快，时间 $O(N)$ 量级，空间 $O(N)$。
