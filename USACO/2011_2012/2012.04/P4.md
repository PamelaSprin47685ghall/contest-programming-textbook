# P4　解锁积木（Unlocking Blocks）

## 题目

奶牛们喜欢解谜！Bessie 过生日，农夫约翰送她一个机械谜题。谜题由三个实心物体组成，每个物体由若干 $1\times1$ 的单位方格粘在一起构成。每个物体都是“连通”的：从它上面任意一个方格出发，可以沿上下左右走到它上面任意其他方格。

物体可以通过反复沿北、南、东、西方向**滑动一格**来移动。谜题的目标是让三个物体**分离**——即它们的外接矩形两两不相交。给定三个物体的形状和位置，请判断它们能否被分开。无法分离的布局称为“锁死”。

## 输入

- 第一行三个整数 $N_1$、$N_2$、$N_3$，分别表示三个物体各由多少个单位方格构成。
- 接下来 $N_1$ 行：每行两个整数 $(x,y)$，表示物体 1 中一个方格的左下角坐标（范围 $0$ 到 $9$）。
- 接下来 $N_2$ 行：物体 2 的方格坐标。
- 接下来 $N_3$ 行：物体 3 的方格坐标。

## 输出

一个整数：如果能分开输出 `1`，否则输出 `0`（锁死）。

## 样例

输入：

```text
12 3 5
0 0
1 0
2 0
3 0
3 1
0 1
0 2
0 3
0 4
1 4
2 4
3 4
2 1
2 2
1 2
2 3
3 3
4 3
4 4
4 2
```

输出：

```text
1
```

## 思路

这是典型的**状态搜索**问题。三个物体在平面上滑动，物体 1 固定不动（相对运动），只需记录物体 2 和物体 3 相对物体 1 的偏移，状态用 $(dx_1,dy_1,dx_2,dy_2)$ 表示。

每一步有三种移动方式：把物体 2 沿一个方向平移一格、把物体 3 平移一格，或把物体 1 平移一格（等价于物体 2、3 同时反向平移一格）。每一步都要保证三个物体两两不重叠。

目标：把物体 2 推到右上角 $(20,20)$、物体 3 推到左下角 $(-20,-20)$，此时三者必然分离。用 BFS 从初始状态出发逐层扩展，用四维数组记录已访问的偏移状态避免重复。

为了快速判断两个物体在某个偏移下是否重叠，先**预计算**每对物体在 $[-20,20]$ 所有偏移下的两两关系，搜索时 $O(1)$ 查表，避免每次移动都重新逐格检查。

只要 BFS 能到达目标状态就输出 1，否则输出 0。

## 复杂度

偏移范围是 $[-20,20]$，每个偏移分量有 $41$ 种取值，状态空间是 $41^4$ 量级。预计算两两关系 $O(3^2 \cdot 41^2 \cdot 100)$，BFS 每个状态尝试常数种移动。时间与空间均为 $O(41^4)$ 量级。
