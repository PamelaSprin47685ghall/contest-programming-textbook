# P1　寻找奶牛（Find the Cow!）

## 题目

Bessie 逃走了，躲在一片长满高草的山脊上。农夫约翰想悄悄爬过去抓住她，但他趴在地上时看不清前面的草。

他面前的草看起来是一串由 `(` 和 `)` 组成的括号串，长度 $N$（$1 \le N \le 50000$）。

Bessie 的后腿看起来就像一对相邻的左括号 `((`，前腿看起来就像一对相邻的右括号 `))`。所以 Bessie 站的位置可以描述成一对下标 $x < y$：在位置 $x$ 处出现 `((`，在位置 $y$ 处出现 `))`。

请你数一数一共有多少种不同的可能位置（也就是有多少对下标 $x < y$ 满足：$x$ 处是 `((`，$y$ 处是 `))`）。

## 输入

一行，一个长度为 $N$ 的括号串。

## 输出

一行，一个整数：Bessie 可能站的位置总数，即满足条件的 $(x, y)$ 对数。

## 样例

输入：

```text
)((()())())
```

输出：

```text
4
```

解释：有 4 个位置，分别是 `((` 在第 2、3 位时，与后面出现的 `))` 组合成的 4 种情况。

## 思路

我们要数的是：每一对相邻的 `))` 能和它**之前**出现过的每一对 `((` 各组成一个位置。

所以从左往右扫一遍：

- 用一个计数器 `left` 记录到目前为止已经出现过多少对 `((`；
- 每遇到一对 `))`，它都能和之前的所有 `((` 配对，所以把 `left` 加到答案里。

这样每对 `((` 只会和它**后面**的 `))` 配对，正好满足 $x < y$ 的要求。一次扫描就能数完。
