# P2　闪烁（Blink）

## 题目

农夫约翰嫌谷仓灯光太暗，刚装了一个新吊灯，由 $N$（$3 \le N \le 16$）个灯泡围成一圈组成。

牛们很喜欢这个新灯，爱玩这个游戏：在时间 $T$，如果某盏灯左边的邻居在时间 $T-1$ 是亮着的，就翻转（切换）这盏灯的状态。它们会玩 $B$（$1 \le B \le 10^{15}$）个单位时间。注意 $B$ 可能大到放不进 32 位整数。

给你灯泡的初始状态，请算出经过 $B$ 个单位时间后每盏灯的最终状态。

## 输入

- 第一行：两个整数 $N$ 和 $B$；
- 接下来 $N$ 行：第 $i+1$ 行是灯泡 $i$ 的初始状态，0（灭）或 1（亮）。

## 输出

$N$ 行，第 $i$ 行输出灯泡 $i$ 的最终状态，0（灭）或 1（亮）。

## 样例

输入：

```text
5 6
1
0
0
0
0
```

输出：

```text
1
1
1
0
1
```

解释：灯泡状态依次变化，时间 $T=6$ 时是 `1 1 1 0 1`。

## 思路

$B$ 可以大到 $10^{15}$，直接模拟 $B$ 步不可能。但灯泡只有 $N$ 个，状态总数最多 $2^N$（$N \le 16$ 时最多 65536 种），所以状态序列**必然会在有限步内进入循环**。

做法：

- 把每盏灯的状态压缩成一个整数（第 $i$ 位表示第 $i$ 盏灯）；
- 用哈希表记录每个状态第一次出现的步数；
- 每走一步，检查当前状态是否出现过：如果出现过，就说明找到了循环，可以用取模跳过循环的整数倍，只走剩余的部分；
- 继续模拟到第 $B$ 步，输出最终状态。

这样即使 $B$ 很大，也只需模拟最多 $2^N + 1$ 步。

## 复杂度

最多模拟 $2^N$ 步，每步 $O(N)$ 或 $O(1)$（用位运算）。时间 $O(2^N \cdot N)$，空间 $O(2^N)$。
