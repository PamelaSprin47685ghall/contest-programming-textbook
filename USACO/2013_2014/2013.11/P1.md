# P1　组合锁（Combination Lock）

## 题目

农夫约翰的奶牛总想逃出农场，于是他在牧场大门上装了一把高级组合锁。这把锁有三个转盘，每个转盘都标着 $1$ 到 $N$ 的数字（$1 \le N \le 100$），因为转盘是圆形的，所以 $1$ 和 $N$ 相邻。

这把锁有两把"正确"的密码：一把是农夫约翰自己设的，另一把是锁匠设的"主密码"。锁有一定的容错：只要三个转盘上的数字各自离某个正确密码对应位置的数字不超过 $2$，锁就能打开。例如约翰的密码是 $(1,2,3)$，主密码是 $(4,5,6)$，那么转盘调到 $(1,N,5)$ 或 $(2,4,8)$ 都能打开锁，而 $(1,5,6)$ 打不开（它离任何一把密码都不够近）。

请计算一共有多少种不同的转盘设置能打开锁。顺序是有意义的，所以 $(1,2,3)$ 和 $(3,2,1)$ 算两种。

## 输入

- 第一行：整数 $N$。
- 第二行：三个空格隔开的整数，表示约翰的密码。
- 第三行：三个空格隔开的整数，表示主密码（可能和约翰的密码相同）。

## 输出

- 一行：能打开锁的不同转盘设置的数量。

## 样例

输入：

```text
50
1 2 3
5 6 7
```

输出：

```text
249
```

## 思路

每个转盘允许的数字只有 5 个：正确数字本身以及它左右各两个。因为转盘是圆形的，所以要用取模来处理"越界"的情况（比如 $N$ 和 $1$ 相邻）。

对两把锁分别枚举三个位置各自允许的 5 种取值，一共得到 $5^3 = 125$ 种候选设置。两把锁加起来最多 $250$ 种，但其中可能有重复（两把锁允许的范围重叠）。我们用哈希集合（`unordered_set`）把所有候选设置存起来，集合里元素的个数就是能打开锁的不同设置数。

这里用集合去重是关键：直接数 $250$ 会算重，而集合天然保证每个设置只出现一次。

## 复杂度

每把锁枚举 $5^3 = 125$ 种组合，两把共 $250$ 种。时间复杂度 $O(N)$（实际是常数 $250$），空间复杂度 $O(250)$。
