# P1　记录整理（Record Keeping）

## 题目

农夫约翰一直详细记录奶牛进谷仓挤奶的情况。每个小时会有一组 3 头牛进入谷仓，约翰记下它们的名字。例如 5 个小时的记录可能是：

```
BESSIE ELSIE MATILDA
FRAN BESSIE INGRID
BESSIE ELSIE MATILDA
MATILDA INGRID FRAN
ELSIE BESSIE MATILDA
```

约翰发现同一组牛可能多次出现。在上面的例子里，{BESSIE, ELSIE, MATILDA} 这一组出现了 3 次（即使约翰每次记名字的顺序可能不一样）。

请帮约翰数一数：出现次数最多的那一组牛一共出现了多少次。

## 输入

- 第一行：记录的小时数 $N$（$1 \le N \le 1000$）。
- 接下来 $N$ 行：每行三个空格隔开的奶牛名字，每个名字 1 到 10 个字符，只含大写字母 A–Z。

## 输出

- 一行：出现次数最多的那组牛出现的次数。

## 样例

输入：

```text
5
BESSIE ELSIE MATILDA
FRAN BESSIE INGRID
BESSIE ELSIE MATILDA
MATILDA INGRID FRAN
ELSIE BESSIE MATILDA
```

输出：

```text
3
```

样例解释：{BESSIE, ELSIE, MATILDA} 这一组在三次不同场合进入谷仓。

## 思路

题目要求统计"同一组牛"出现的次数，而"同一组"指的是三个名字相同，与顺序无关。所以关键是先把每组里的三个名字排序，这样无论约翰按什么顺序写名字，排序后都得到同一个键。

用哈希表（`unordered_map`）以"排序后的三个名字"为键，统计每种三人组出现的次数。读完所有记录后，遍历哈希表找出最大的计数就是答案。

这里用哈希表把"名字组合"直接映射到"出现次数"，省去了手动比较的麻烦，是这类统计问题最自然的做法。
