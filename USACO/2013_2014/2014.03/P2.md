# P2　懒牛（The Lazy Cow）

## 题目

一个炎热的夏天，贝茜觉得很懒。她想在田地里选一个位置，让它在短距离内能吃到尽可能多的美味青草。

贝茜的田地里长着 $N$ 块青草（$1 \le N \le 100{,}000$），可以把田地看成一条很长的数轴。第 $i$ 块草含有 $g_i$ 单位草（$1 \le g_i \le 10{,}000$），位于数轴上不同的点 $x_i$（$0 \le x_i \le 1{,}000{,}000$）。贝茜想选一个初始位置（可以正好在某块草的位置），使得距离这个位置不超过 $K$ 步（$1 \le K \le 2{,}000{,}000$）的草量总和最大。

请帮贝茜算出，选最优位置时她能吃到的最多草量。

## 输入

- 第一行：两个整数 $N$ 和 $K$。
- 接下来 $N$ 行：每行两个整数 $g_i$ 和 $x_i$，描述一块草。

## 输出

- 一行：贝茜在最优位置时，距离 $K$ 步内能吃到的最多草量。

## 样例

输入：

```text
4 3
4 7
10 15
2 2
5 1
```

输出：

```text
11
```

样例解释：贝茜应站在位置 $x=4$，这样位置 $x=1$、$x=2$ 和 $x=7$ 的草都在她够得着的范围内，共 $5+2+4=11$。

## 思路

贝茜站在某个位置 $p$ 时，能吃到位置在 $[p-K, p+K]$ 内的所有草。所以问题变成：找一个长度 $2K$ 的区间，使区间内的草量总和最大。

因为位置范围只有 $0 \sim 1{,}000{,}000$，我们可以用一个数组记录每个位置上的草量（多个位置可能重合，直接累加），然后做前缀和，这样就能 $O(1)$ 求出任意区间的草量总和。

最后枚举所有长度为 $2K+1$ 的区间（即左端 $left$ 从 0 到最大位置，右端 $left + 2K$），用前缀和算出区间草量，取最大值。这就是"滑动窗口 + 前缀和"的思路，避免了每次重新累加。

## 复杂度

位置范围 $M = 10^6$。构建数组和前缀和 $O(M)$，枚举区间 $O(M)$。总时间复杂度 $O(M + N)$，空间复杂度 $O(M)$。
