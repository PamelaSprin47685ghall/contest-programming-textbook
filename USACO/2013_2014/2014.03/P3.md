# P3　奶牛艺术（Cow Art）

## 题目

奶牛有一个鲜为人知的特点：它们是红绿色盲，也就是说红色和绿色在它们眼里看起来一样。这让设计既让奶牛又让人类满意的画作变得很困难。

考虑一幅用 $N \times N$ 字符网格描述的正方形画作（$1 \le N \le 100$），每个字符是 R（红）、G（绿）或 B（蓝）。一幅画如果有很多可以区分的"颜色区域"就算有趣。两个字符属于同一个区域，当且仅当它们直接相邻（上下左右）且颜色无法区分。

例如画作：

```
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

人类看有 4 个区域（2 红、1 蓝、1 绿），但奶牛看只有 3 个区域（2 个红绿、1 个蓝）。

给定一幅画，请分别计算人类视角和奶牛视角下的区域数量。

## 输入

- 第一行：整数 $N$。
- 接下来 $N$ 行：每行一个长度为 $N$ 的字符串，描述画作的一行。

## 输出

- 一行：两个空格隔开的整数，分别表示人类视角和奶牛视角下的区域数量。

## 样例

输入：

```text
5
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

输出：

```text
4 3
```

## 思路

"区域"就是颜色相同的连通块，所以问题本质是统计连通分量个数，用深度优先搜索（DFS）或广度优先搜索（BFS）遍历网格即可。

关键在"颜色相同"的定义有两种视角：

- 人类视角：两个格子颜色必须完全相同（R=R、G=G、B=B）才算连通；
- 奶牛视角：G 和 R 视为同一种颜色，所以 R=G、G=R、B=B 都算连通，只有 B 是单独一类。

实现时写一个通用的统计函数 `CountRegions`，它接收一个"判断两个颜色是否相同"的函数。分别用"完全相等"和"把 G 看成 R"两个判断函数调用它，就得到两个答案。

遍历时用栈模拟 DFS：从每个未访问的格子出发，向四个方向扩展，把颜色相同且未访问的格子都标记并压栈，这样一个连通块就统计完了。

## 复杂度

网格有 $N^2$ 个格子，每个格子最多被访问一次，每次检查四个方向。总时间复杂度 $O(N^2)$，空间复杂度 $O(N^2)$。
