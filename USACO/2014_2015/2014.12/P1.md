# P1　马拉松（Marathon）

## 题目

贝茜报名了一个跑步班，老师让她跑一场马拉松。马拉松路线由 $N$ 个检查点组成，必须按顺序依次经过：第 1 个检查点是起点，第 $N$ 个是终点。但贝茜很懒，她想跳过最多一个检查点来缩短总路程。她不能跳过第 1 个和第 $N$ 个检查点（那样太明显了）。

请你帮贝茜算出：如果最多能跳过一个检查点，她最少要跑多远。

注意：城市是网格状街道，所以两个检查点 $(x_1,y_1)$ 与 $(x_2,y_2)$ 之间的距离是曼哈顿距离 $|x_1-x_2|+|y_1-y_2|$（只能沿横竖方向走，不能走直线）。

## 输入

第一行一个整数 $N$（$3 \le N \le 100000$）。

接下来 $N$ 行，每行两个整数 $x,y$，表示一个检查点的坐标（$-1000 \le x,y \le 1000$）。检查点按必须经过的顺序给出。路线可能多次交叉，也可能多个检查点在同一位置；跳过某个检查点只跳过那一个实例。

## 输出

输出一个整数：跳过最多一个检查点后，贝茜最少要跑的总距离。

## 样例

输入：

```text
4
0 0
8 3
11 -1
10 0
```

输出：

```text
14
```

跳过位于 $(8,3)$ 的检查点后总距离最小，为 14。

## 思路

先想清楚：不跳过任何检查点时，总距离就是所有相邻检查点之间曼哈顿距离的和。跳过第 $i$ 个检查点（$2 \le i \le N-1$）后，原本"$i-1 \to i$"和"$i \to i+1$"两段距离，会被"$i-1 \to i+1$"这一段直连距离替代。所以对每个可跳过的 $i$，我们都要算一次新的总距离，再取最小值。

直接对每个 $i$ 从头累加一遍是 $O(N^2)$，会超时。我们用两个辅助量来避免重复计算：

- 前缀和 `prefix`：第 $1$ 个到第 $i-1$ 个检查点之间所有相邻距离之和（即 $i$ 之前的距离）。
- 后缀和 `suffix[i]`：第 $i$ 个到第 $N$ 个检查点之间所有相邻距离之和（即 $i$ 及之后的距离），从右往左递推得到。

这样跳过 $i$ 的新总距离 = `prefix` +（$i-1$ 与 $i+1$ 的直连距离）+ `suffix[i+1]`，一次就能算出来。枚举所有可跳过的 $i$ 取最小即可。
