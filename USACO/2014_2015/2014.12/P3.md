# P3　奶牛慢跑（Cow Jog）

## 题目

有 $N$ 头奶牛在一条无限长的单车道跑道上慢跑。每头奶牛从不同的位置出发，速度也可能不同。由于只有一条车道，奶牛不能互相超越：当一头较快的奶牛追上另一头时，它必须减速以避免撞上去，从而和前面的奶牛组成同一群。最终，不会再有任何奶牛相撞。

请问最终会剩下多少群奶牛？

## 输入

第一行一个整数 $N$（$1 \le N \le 100000$）。

接下来 $N$ 行，每行两个整数：一头奶牛出发时的位置和速度。位置是非负整数，速度是正整数，两者都不超过 $10^9$。所有奶牛的起始位置互不相同，且输入按位置从小到大给出。

## 输出

输出一个整数：最终剩下的奶牛群数。

## 样例

输入：

```text
5
0 1
1 2
2 3
3 2
6 1
```

输出：

```text
2
```

## 思路

先想：什么情况下两头奶牛最终会变成同一群？如果前面的奶牛跑得比后面的慢（或一样慢），后面的迟早会追上它，于是它们合并成一群。反过来，如果前面的奶牛跑得比后面的快，那么后面的永远追不上，它们会一直保持分开。

关键观察是：**最终分群的边界，只取决于速度，与位置无关**。因为位置已经按从小到大排好了，我们只需要从右往左看每头奶牛的速度。从最右边（最后面出发）那头开始，维护"当前这群里最慢的速度"：

- 如果当前这头奶牛的速度**不大于**右边已形成的那群的最慢速度，那么它追不上右边那群，于是它自己单独成为新的一群。
- 否则（它更快），它最终会追上右边那群，被并入同一群。

从右往左扫一遍，每遇到一个"自成新群"的奶牛就答案加 1。因为位置无关紧要，读入时直接丢弃位置、只保留速度即可。
