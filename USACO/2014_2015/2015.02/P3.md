# P3　奶牛跳房子（Cow Hopscotch）

## 题目

像人类喜欢玩跳房子一样，农夫约翰的奶牛发明了自己的跳房子玩法。游戏在一个 $R \times C$ 的网格上进行（$2 \le R, C \le 15$），每个格子是红色（R）或蓝色（B）。奶牛从左上角格子出发，通过一系列跳跃到达右下角格子。一次跳跃合法，当且仅当：

1. 跳到**不同颜色**的格子；
2. 目标格子至少在**当前格子下方一行**；
3. 目标格子至少在**当前格子右方一列**。

请帮奶牛算出：从左上角到右下角，一共有多少种不同的合法跳跃序列。

## 输入

第一行两个整数 $R$ 和 $C$。接下来 $R$ 行，每行 $C$ 个字符，是 `R`（红色）或 `B`（蓝色）。

## 输出

输出从左上角跳到右下角的不同方式数。

## 样例

输入：

```text
4 4
RRRR
RRBR
RBBR
RRRR
```

输出：

```text
3
```

## 思路

这是一个计数问题，适合用动态规划（DP）。设 `ways[i][j]` 表示从格子 $(i,j)$ 出发到右下角的跳法数。我们想知道的是 `ways[0][0]`。

从右下角向左上递推：右下角本身是终点，`ways[R-1][C-1] = 1`。对其它格子 $(i,j)$，从它可以跳到任何"在右下方、且颜色不同"的格子 $(i0,j0)$，所以

$$\text{ways}[i][j] = \sum_{\substack{i0>i,\ j0>j\\ \text{颜色不同}}} \text{ways}[i0][j0]$$

因为网格很小（最多 $15 \times 15$），对每个格子枚举所有右下方的格子求和即可，不需要更复杂的优化。递推顺序从右下往左上，保证算 $(i,j)$ 时它依赖的 $(i0,j0)$ 都已经算好。
