# P2　蹄子、纸、剪刀（Hoof, Paper, Scissors）

## 题目

你大概听说过“石头、剪刀、布”游戏。奶牛们玩一种类似的游戏，叫“蹄子、纸、剪刀”。

规则很简单：两头牛同时做出一个手势，代表“蹄子”、“纸”或“剪刀”之一。胜负关系是：蹄子赢剪刀（蹄子能砸碎剪刀）、剪刀赢纸（剪刀能剪纸）、纸赢蹄子（蹄子会被纸划伤）。如果手势相同则平局。

约翰看着两头牛玩了 $N$ 局。他能看出奶牛做了三种不同的手势，但分不清哪个手势代表“蹄子”、哪个代表“纸”、哪个代表“剪刀”。于是他把三种手势编号为 1、2、3。

给定每局两头牛出的编号，请你帮约翰算出：在合适的编号与手势的对应关系下，第一头牛**最多**能赢多少局。

## 输入

第一行一个整数 $N$（$1 \le N \le 100$）。

接下来 $N$ 行，每行两个整数（每个都是 1、2 或 3），表示一局中第一头牛和第二头牛出的编号。

## 输出

一个整数：第一头牛可能赢的最大局数。

## 样例

输入：

```text
5
1 2
2 2
1 3
1 1
3 2
```

输出：

```text
2
```

解释：一种对应是 1 代表“剪刀”、2 代表“蹄子”、3 代表“纸”。这样第一头牛在 `1 3` 和 `3 2` 两局中获胜，共 2 局。没有别的对应能让它赢得更多。

## 思路

关键点：编号和手势的对应关系是固定的，但我们可以任意选。三种手势的胜负关系是“循环”的：A 赢 B、B 赢 C、C 赢 A。

先看每局两头牛编号的差（按模 3 处理）。因为对应关系可以任意旋转，所以“第一头牛赢”只取决于两局编号的相对关系，而不是具体编号。具体说：

- 若两牛编号相同，这局一定平局，无论怎么对应；
- 若编号差为 1（模 3 意义下），在某种对应下第一头牛赢；
- 若编号差为 2（模 3 意义下），在另一种对应下第一头牛赢。

由于我们可以自由选择对应关系，只能让“差为 1”的所有局都算第一头牛赢，或者让“差为 2”的所有局都算它赢，二者取其一。所以答案就是：差为 1 的局数 与 差为 2 的局数 中较大的那个。
