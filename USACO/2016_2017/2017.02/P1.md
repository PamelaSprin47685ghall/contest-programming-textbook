# P1　奶牛为什么过马路（Why Did the Cow Cross the Road）

## 题目

农夫约翰有 10 头奶牛（编号 1 到 10）。他记录了一整天里奶牛们的位置，共 $N$ 次观察。每次观察记录了一头奶牛的编号，以及它当时在路的哪一边（用 0 或 1 表示，0 是路的一边，1 是另一边）。

请你数出：总共发生了多少次**确认的过马路**。当同一头奶牛**连续两次**被观察到时，它所在的路边不同，就算它过了一次马路。

## 输入

第一行一个整数 $N$（$1 \le N \le 100$）。

接下来 $N$ 行，每行两个整数：奶牛编号（1 到 10）和它所在的位置（0 或 1）。

## 输出

一个整数：确认过马路的次数。

## 样例

输入：

```text
8
3 1
3 0
6 0
2 1
4 1
3 0
4 0
3 1
```

输出：

```text
3
```

解释：奶牛 3 先出现在 1 侧，后来出现在 0 侧，再后来又回到 1 侧，所以它过了两次马路。奶牛 4 从 1 侧到 0 侧，过了一次。奶牛 2 和 6 都没有过马路。

## 思路

对每一头奶牛，我们只需要记住它**最近一次**被观察到时在哪一侧。当读到一条新记录时：

- 如果这头奶牛之前出现过，并且上次所在侧和这次不同，就说明它过了一次马路，计数加一；
- 如果相同，或者它之前没出现过，就不算过马路。

然后用这次的所在侧更新它最近的位置，继续处理下一条记录。

用一个数组 `side` 存每头牛最近的位置，初值设为“还没出现”（例如 -1），这样能区分“第一次出现”和“确实换了侧”。

每条记录做常数次运算，总时间 $O(N)$；空间 $O(1)$（固定 10 头牛）。
