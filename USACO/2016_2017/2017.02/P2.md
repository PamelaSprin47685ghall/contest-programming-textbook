# P2　奶牛为什么过马路 II（Why Did the Cow Cross the Road II）

## 题目

农夫约翰的农场有一圈圆形道路，奶牛们每天早晨从各自的路口进入中间的草地，傍晚又从另一个路口离开。约翰有 26 头奶牛，命名为 A 到 Z。

每头牛进入和离开的路口都互不相同，所以圆形道路上一共有 52 个路口。约翰沿着圆顺时针走一圈，把每个路口对应的奶牛名字写下来，得到一个长度为 52 的字符串，其中每个大写字母恰好出现两次（一次是进入点，一次是离开点）。约翰不区分哪个是进入点、哪个是离开点。

如果两头牛 $a$ 和 $b$ 从进入点到离开点的路径必然相交，约翰就称它们是一对“交叉对”。请你数出：一共有多少对交叉的奶牛。

## 输入

一行，一个长度为 52 的字符串，只含大写字母 A 到 Z，每个字母恰好出现两次。

## 输出

一个整数：交叉对的总数。

## 样例

输入：

```text
ABCCABDDEEFFGGHHIIJJKKLLMMNNOOPPQQRRSSTTUUVVWWXXYYZZ
```

输出：

```text
1
```

解释：这个例子里只有奶牛 A 和 B 是一对交叉对。

## 思路

把 52 个路口看成圆上按顺时针排列的 52 个位置，每头牛占据其中两个位置。两头牛 $a$ 和 $b$ 的路径相交，当且仅当：在圆上，$a$ 的两个端点把 $b$ 的两个端点**隔开**——也就是 $b$ 的一个端点落在 $a$ 的两个端点之间，而另一个端点落在外面。

用数学语言：设 $a$ 的两个位置为 $a_1 < a_2$，$b$ 的两个位置为 $b_1 < b_2$（按在字符串中的下标排序）。两头牛交叉，当且仅当：

$$a_1 < b_1 < a_2 < b_2$$

（即 $b$ 的一个端点插在 $a$ 的两个端点之间，另一个在 $a_2$ 之后）。

做法：

1. 遍历字符串，记录每头牛的两个位置下标；
2. 枚举所有奶牛对 $(a,b)$，用上面的条件判断它们是否交叉，计数即可。
