# P2　蹄球（Hoofball）

## 题目

Farmer John 在训练 $N$ 头奶牛传球。奶牛站在一条很长的直线上，第 $i$ 头牛站在离谷仓 $x_i$ 远的位置，所有位置互不相同。

训练开始时，John 会把几个球分别发给不同的奶牛。任何一头牛接到球（不管是 John 发的还是别的牛传的），都会把球传给**离自己最近**的那头牛；如果左右两边距离一样，就传给**最左边**的那头。

John 想让**每一头牛**都至少拿到一次球。请你算出：他一开始最少需要发几个球？

## 输入

第一行一个整数 $N$（$1 \le N \le 100$）。

第二行 $N$ 个空格隔开的整数 $x_i$（$1 \le x_i \le 1000$），是每头牛的位置。

## 输出

一个整数：John 一开始最少要发的球数。

## 样例

输入：

```text
5
7 1 3 11 4
```

输出：

```text
2
```

解释：John 把球发给位置 1 和 11 的两头牛。位置 1 的牛把球传给位置 3，之后球会在位置 3 和 4 之间来回；位置 11 的牛传给位置 7，7 传给 4，之后也在这两头之间循环。这样所有牛都拿到过球。

## 思路

先想：把每头牛“会把球传给谁”看成一个**图**：每头牛有一条出边，指向它传球的目标。这样从某个球出发，会沿着这些边一直传下去，最终进入一个环（两头牛互相传球就是最简单的环）。

要覆盖所有牛，可以这样想：

- 一头牛如果**没有人把球传给它**（入度为 0），那它永远不可能从别人那里拿到球，必须由 John 直接发一个球给它；
- 处理完所有入度为 0 的牛后，剩下的每个连通分支一定是一个环，每个环还需要一个球才能让环上的牛都拿到球。

所以做法是：先排序位置，对每头牛判断它传球给左边还是右边（比较左右邻居的距离，平局传左边），建出“传给谁”的数组；然后统计入度，给所有入度为 0 的牛发球并沿传球链标记已处理，最后每个剩下的环再补一个球。代码用一个 `Graph` 结构体管理这些操作。
