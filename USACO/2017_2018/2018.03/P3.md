# P3　家族树（Family Tree）

## 题目

Farmer John 的农场是家族传承下来的，牛群也有几代的血缘关系。给你一些“某牛是某牛的母亲”的记录，请你判断给定的两头牛之间是什么关系。

可能的关系类型有：

- **SIBLINGS**（同胞）：两头牛有同一个母亲；
- **直系祖先**：一头牛是另一头的母亲、祖母、曾祖母……输出形如 `ELSIE is the great-grand-mother of BESSIE`；
- **姨/姑（aunt）**：一头牛是另一头牛祖母的女儿（但不是对方的祖先或同胞），按辈分叫 aunt、great-aunt、great-great-aunt……；
- **COUSINS**（表亲）：两头牛有共同祖先但不符合上面几种；
- **NOT RELATED**（无血缘）：两头牛没有共同祖先，也不是直系后代关系。

## 输入

第一行一个整数 $N$（$1 \le N \le 100$），后面跟着两头牛的名字（每个名字是最多 10 个大写字母的字符串），就是你要判断关系的两头牛。

接下来 $N$ 行，每行两个名字 `X Y`，表示 X 是 Y 的母亲。

## 输出

一行，表示两头牛的关系，格式见题目说明。

## 样例

输入：

```text
7 AA BB
MOTHER AA
GGMOTHER BB
MOTHER SISTER
GMOTHER MOTHER
GMOTHER AUNT
AUNT COUSIN
GGMOTHER GMOTHER
```

输出：

```text
BB is the great-aunt of AA
```

## 思路

先想：母亲关系可以看成一棵**家族树**，每头牛有一条指向母亲的边。要判断关系，关键是找出两头牛的**最近公共祖先（LCA）**，以及各自到它的距离。

先把牛名映射成整数编号，用 `Parent` 数组存“每头牛的母亲是谁”。然后：

- 如果两头牛到根（没有母亲的牛）都走不到同一个祖先，说明没有共同祖先，输出 NOT RELATED；
- 如果两头牛到 LCA 的距离都是 1，说明同一个母亲，是 SIBLINGS；
- 如果两头牛到 LCA 的距离都大于 1，是 COUSINS；
- 否则其中一头是另一头的长辈：如果长辈是对方的直系祖先（距离为 0），输出 mother / grand-mother / great-…-mother；否则是 aunt / great-aunt / …。

求 LCA 用朴素方法：先让较深的那头牛沿着母亲链向上走到和另一头同一层，再两头一起向上走，直到相遇。这里用递归算每头牛到根的深度，再按深度对齐。输出时按辈分在前面加对应数量的 `great-`。
