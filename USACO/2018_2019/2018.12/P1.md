# P1　混合牛奶（Mixing Milk）

## 题目

农夫约翰有三只容积各不相同的桶，分别装有一定量的牛奶。

他按照固定顺序连续进行 $100$ 次倒牛奶操作：
- 第 1 次将桶 1 倒入桶 2；
- 第 2 次将桶 2 倒入桶 3；
- 第 3 次将桶 3 倒入桶 1；
- 第 4 次将桶 1 倒入桶 2；
- 依此类推，循环进行。

每次倒牛奶时，约翰会倒出尽可能多的牛奶，直到源桶变空，或者目标桶装满为止。

请计算完成全部 $100$ 次倒水后，每只桶中最终剩余的牛奶量。

## 输入

输入共三行，每行两个整数：
- 第 1 行：桶 1 的容量 $c_1$ 与初始牛奶量 $m_1$；
- 第 2 行：桶 2 的容量 $c_2$ 与初始牛奶量 $m_2$；
- 第 3 行：桶 3 的容量 $c_3$ 与初始牛奶量 $m_3$。

保证容量满足 $1 \le c_i \le 10^9$，初始牛奶量满足 $0 \le m_i \le c_i$。

## 输出

输出共三行，每行一个整数，分别表示最终桶 1、桶 2 和桶 3 中的牛奶量。

## 样例

输入：

```text
10 3
11 4
12 5
```

输出：

```text
0
10
2
```

## 思路

题目要求严格按照固定规则模拟 $100$ 次倒牛奶操作。

因为只有 3 只桶，且操作步数仅为 100 步，可以直接进行模拟：
1. 用数组 `capacity` 和 `milk` 记录各桶的容量和当前奶量。
2. 第 `step` 步时，源桶编号为 `step % 3`，目标桶编号为 `(step + 1) % 3`。
3. 每次倒牛奶的实际量为源桶剩余奶量与目标桶剩余空间的较小值，即 $\min(milk[source], capacity[target] - milk[target])$。
4. 从源桶扣除该牛奶量，并加到目标桶中。循环 100 轮后输出结果即可。

## 复杂度

循环固定进行 $100$ 次，每次操作时间为 $O(1)$。时间复杂度为 $O(1)$，空间复杂度为 $O(1)$。
