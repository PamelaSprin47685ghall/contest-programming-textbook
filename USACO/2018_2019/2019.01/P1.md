# P1　猜贝壳游戏（Shell Game）

## 题目

贝茜和她的奶牛朋友们正在玩经典的“猜贝壳游戏”。桌上扣着三只贝壳，编号分别为 1、2、3。最初，贝茜会在其中一只贝壳下面悄悄藏入一颗小坚果。

游戏一共进行 $N$ 回合。在每一回合中，埃尔希会先交换其中两只贝壳的位置（例如交换 $a$ 和 $b$ 处的贝壳），随后贝茜会猜测坚果在哪一只贝壳下面（猜 $g$）。如果猜对了，贝茜就得一分。

埃尔希已经记录下了全部 $N$ 回合交换的贝壳编号以及贝茜每次猜测的编号。但是她忘记了最初坚果放在哪只贝壳下面。

请帮助埃尔希计算，在坚果初始位置未知的情况下，贝茜最高可能得到多少分。

## 输入

第一行包含一个整数 $N$（$1 \le N \le 100$），表示回合数。
接下来 $N$ 行，每行包含三个整数 $a, b, g$，表示该回合交换了位置 $a$ 与 $b$ 处的贝壳，且贝茜猜测坚果在位置 $g$（$1 \le a, b, g \le 3$ 且 $a \neq b$）。

## 输出

一个整数，表示贝茜最高可能获得的分数。

## 样例

输入：

```text
3
1 2 1
3 2 1
1 3 1
```

输出：

```text
2
```

## 思路

坚果一开始只有 3 种可能的位置：位置 1、位置 2 或位置 3。

我们可以分别枚举这 3 种初始位置：
1. 假设初始位置为 $p$；
2. 逐一模拟这 $N$ 轮操作：如果本轮交换的两个位置之一等于当前坚果位置，坚果的位置就变为另一个位置；
3. 如果本轮猜测的位置正好等于坚果当前位置，得分加一；
4. 统计 3 种假设下的最终得分，取最大值输出。

## 复杂度

枚举 3 种初始位置，每次模拟 $N$ 步。时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。在 $N \le 100$ 的数据范围内可以瞬间完成。
