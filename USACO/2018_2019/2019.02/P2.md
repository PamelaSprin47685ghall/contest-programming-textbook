# P2　植被重建（The Great Revegetation）

## 题目

农夫约翰有 $N$ 个牧场（编号 $1 \dots N$）和 $M$ 头奶牛（$1 \le N \le 100, 1 \le M \le 150$）。每头奶牛喜欢两处不同的牧场。

约翰计划在每个牧场种植 4 种草料之一（编号 1、2、3、4）。为了满足奶牛们的口味多样性，对于每头牛喜欢的两个牧场，这两个牧场所种植的草种**不能相同**。
此外，题目保证每处牧场至多只会被 3 头奶牛喜爱（即度数不超过 3）。

请给每个牧场分配草种 1..4，并使得输出的分配方案构成的字符串在字典序上尽可能小。

## 输入

第一行两个整数 $N$ 和 $M$。
接下来 $M$ 行，每行两个整数 $u$ 和 $v$（$1 \le u, v \le N, u \neq v$），表示某头奶牛喜欢的两块牧场。

## 输出

一个长为 $N$ 的数字字符串，第 $i$ 位表示牧场 $i$ 种植的草种编号（1..4）。如果有多种方案，输出字典序最小的方案。

## 样例

输入：

```text
5 6
4 1
4 2
4 3
2 5
1 2
1 5
```

输出：

```text
12134
```

## 思路

这是一个典型的图染色问题：每个节点代表一个牧场，每头奶牛连起一条无向边，要求相邻节点的颜色互不相同。颜色总数为 4，且每个节点的度数不超过 3。
因为每个节点的度数最多为 3，所以在为某个节点选择颜色时，它的邻居最多只占用了 3 种颜色，这意味着集合 $\{1, 2, 3, 4\}$ 中必然至少有 1 种颜色未被占用！

要求字典序最小，我们可以采用从编号 $1$ 到编号 $N$ 的贪心策略：
1. 依次处理牧场 $1, 2, \dots, N$；
2. 对于牧场 $i$，检查与其相邻的所有已经染色的邻居占用了哪些颜色；
3. 在 $\{1, 2, 3, 4\}$ 中，选取满足不与邻居冲突的最小数字作为牧场 $i$ 的草种；
4. 因为前面的牧场尽量选了较小的数字，得到的整体序列天然具备最小字典序。

## 复杂度

节点数 $N \le 100$，边数 $M \le 150$。遍历所有节点及其邻居边，总操作次数 $O(N + M)$。时间复杂度为 $O(N + M)$，空间复杂度为 $O(N + M)$。
