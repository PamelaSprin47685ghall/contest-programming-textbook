# P2　牛奶工厂（Milk Factory）

## 题目

农夫约翰的牛奶加工厂有 $N$ 个处理站（编号 $1 \dots N$）和 $N-1$ 条单向传送带（$1 \le N \le 100$）。
原本无向的通道使得任何两个站点之间都是连通的（即底层是一棵包含 $N$ 个节点的树）。安装了传送带后，每条走道只能单向通行。

约翰希望找到这样一个加工站 $i$：从**任意其他加工站**出发，都能顺着传送带最终抵达加工站 $i$（中途可以经过若干其他站）。

请帮助约翰寻找是否存在这样的站点 $i$。如果存在，输出它的编号；如果不存在，输出 `-1`。若存在多个，输出编号最小的一个。

## 输入

第一行包含一个整数 $N$。
接下来 $N-1$ 行，每行两个空格隔开的整数 $a_i$ 和 $b_i$（$1 \le a_i, b_i \le N, a_i \neq b_i$），表示存在一条从 $a_i$ 流向 $b_i$ 的单向传送带。

## 输出

输出满足条件的站点编号。如果不存在，输出 `-1`。

## 样例

输入：

```text
3
1 2
3 2
```

输出：

```text
2
```

## 思路

底层的无向图是一棵包含 $N$ 个节点、$N-1$ 条边的树。
现在将所有边定向，形成一个有向无环图（DAG）。

如果某个节点能够被**所有**其他节点到达：
1. 这个节点自身不能有流向其他节点的出边（如果有出边，顺着出边离开后无法再回到该树上节点，产生矛盾）。因此，目标汇点的**出度必须为 0**。
2. 此外，如果全图存在两个或更多出度为 0 的节点，那么这两个节点之间必然谁也无法到达谁，此时不存在合法的全能汇点。
3. 反之，因为总边数为 $N-1$ 且无环，若恰好只有一个节点的出度为 0，则其余 $N-1$ 个节点的出度必定恰好都为 1。沿着唯一的出边前行，任何节点最终都会汇流到该唯一的出度为 0 的节点。

因此，只需统计每个节点的出度，若出度为 0 的节点恰好只有 1 个，输出该节点编号；否则输出 -1。

只需读取 $N-1$ 条边并统计出度，时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。
