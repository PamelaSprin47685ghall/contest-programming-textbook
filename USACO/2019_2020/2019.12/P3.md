# P3　牲畜排队（Livestock Lineup）

## 题目

农夫约翰有 8 头奶牛，它们的名字分别是：Bessie、Buttercup、Belinda、Beatrice、Bella、Blue、Betsy 和 Sue。

约翰要把它们排成一列去挤奶。但是奶牛们有一些要求，包含 $N$ 条约束限制（$1 \le N \le 7$）。每条约束形如“奶牛 $X$ 必须站在奶牛 $Y$ 的身旁”（即在最终排列中，它们的位置必须紧挨着相邻）。

请帮助约翰安排队伍，满足所有的相邻要求。如果有多种合法的排列方式，请输出**按名字字典序最小**的排队方案。

## 输入

第一行一个整数 $N$。
接下来 $N$ 行，每行描述一条约束，固定格式为：
`X must be milked beside Y`
其中 `X` 和 `Y` 是两头不同的奶牛的名字。

## 输出

输出共 8 行，每行一个奶牛的名字，表示满足所有限制条件的字典序最小的排队方案。

## 样例

输入：

```text
3
Buttercup must be milked beside Bella
Blue must be milked beside Bella
Sue must be milked beside Beatrice
```

输出：

```text
Beatrice
Sue
Belinda
Bessie
Betsy
Blue
Bella
Buttercup
```

## 思路

奶牛总数固定为 8 头。8 头牛的所有可能排列总数仅为 $8! = 40320$ 种，完全可以通过全排列进行暴力检验：

1. 将 8 个奶牛的名字存入数组，并先进行一次升序排序，使数组初始状态就是字典序最小的排列；
2. 使用标准库函数 `std::next_permutation` 依次枚举所有排列；
3. 对于每个排列，检查输入的 $N$ 条约束：对于每条约束，两头牛在排列中的下标之差的绝对值是否恰好等于 1；
4. 一旦找到第一个能够同时满足所有 $N$ 条约束的排列，由于我们是从字典序最小的排列开始遍历的，该排列必定就是答案，直接输出并终止程序即可。

## 复杂度

总排列数 $8! = 40320$。对每个排列检验 $N$ 条约束（$N \le 7$），耗时极其微小。时间复杂度为 $O(N \cdot 8!)$，空间复杂度为 $O(1)$。
