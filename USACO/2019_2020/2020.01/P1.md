# P1　文字处理器（Word Processor）

## 题目

奶牛贝茜正在用文字处理器给作文排版。作文一共有 $N$ 个单词（$1 \le N \le 100$），单词之间用空格隔开。每个单词的长度在 1 到 15 个字符之间。

排版规则如下：
- 每行容纳的**字母字符总数**（不包含空格）不得超过 $K$（$1 \le K \le 80$）；
- 如果当前行还能容纳下一个单词，就把它放在当前行，与前一个单词之间用一个空格隔开；
- 如果放不下，就另起一行放置该单词；
- 行尾不得包含多余的空格。

请帮助贝茜完成文章的排版输出。

## 输入

第一行包含两个整数 $N$ 和 $K$。
第二行包含 $N$ 个由空格隔开的单词。

## 输出

输出排版好的文章。

## 样例

输入：

```text
10 7
hello my name is Bessie and this is my essay
```

输出：

```text
hello my
name is
Bessie
and this
is my
essay
```

## 思路

直接按照贪心规则逐个单词处理：
1. 用一个变量 `currentLineChars` 记录当前行已经放置的字母总数；
2. 读入一个新单词，检查 `currentLineChars + word.length()` 是否不超过 $K$；
3. 若不超过，说明当前行能放下：若当前行已有单词，先输出一个空格，然后输出该单词，并更新 `currentLineChars`；
4. 若超过，说明必须换行：输出一个换行符，然后输出该单词，并将 `currentLineChars` 重置为当前单词长度。

每个单词处理一次，时间复杂度为 $O(N)$，空间复杂度为 $O(1)$。
