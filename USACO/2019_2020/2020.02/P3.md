# P3　翻转再翻转（Swapity Swap）

## 题目

农夫约翰的 $N$ 头奶牛（$1 \le N \le 100$）排成一列，初始时从左到右编号依次为 $1, 2, \dots, N$。

约翰为奶牛们设计了晨练程序，要求将以下两步过程重复执行恰好 $K$ 次（$1 \le K \le 10^9$）：
1. 队伍中当前处于位置 $A_1 \dots A_2$ 的这一段奶牛反转顺序（$1 \le A_1 < A_2 \le N$）；
2. 随后，队伍中处于位置 $B_1 \dots B_2$ 的这一段奶牛反转顺序（$1 \le B_1 < B_2 \le N$）。

请输出在重复执行了 $K$ 次上述两步操作后，从左到右各个位置上的奶牛编号。

## 输入

第一行包含两个整数 $N$ 和 $K$。
第二行包含两个整数 $A_1$ 和 $A_2$。
第三行包含两个整数 $B_1$ 和 $B_2$。

## 输出

输出共 $N$ 行，第 $i$ 行输出最终位于位置 $i$ 的奶牛编号。

## 样例

输入：

```text
7 2
2 5
3 7
```

输出：

```text
1
2
4
3
5
7
6
```

## 思路

虽然重复次数 $K$ 高达 $10^9$，不能暴力循环 $K$ 次，但是整个过程具有固定的**置换规律**与**周期性**：

1. 我们先对初始序列 $[1, 2, \dots, N]$ 单独模拟执行一次两步翻转，得到经过一次完整操作后每个位置的元素变动关系；
2. 任何一个有限集合的置换都可以分解为若干个不相交的**置换环（Cycle）**；
3. 对于长度为 $L$ 的某个环，在这个环上的元素每经过 $L$ 次操作就会完全回到原本的位置。因此，执行 $K$ 次操作的效果等价于在该环上移动 $K \bmod L$ 步；
4. 找出所有的置换环，直接计算移动 $K \bmod L$ 步后的位置，即可在 $O(N)$ 时间内直接得出最终排布。

## 复杂度

单次置换模拟耗时 $O(N)$，置换环分解与定位耗时 $O(N)$。由于 $K$ 取模后直接定位，时间复杂度为 $O(N)$，与 $K$ 的大小无关。空间复杂度为 $O(N)$。
