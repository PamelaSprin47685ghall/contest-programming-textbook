# P1　社交距离 I（Social Distancing I）

## 题目

农夫约翰的牛棚是一排紧挨着的 $N$ 个牛栏（$2 \le N \le 10^5$），编号为 $0 \dots N-1$。每个牛栏要么有牛占据（`1`），要么是空的（`0`）。

定义 $D$ 为**任意两头被占据的牛栏之间的最小距离**（例如，如果距离最近的两头牛位于牛栏 3 和 8，则 $D = 5$）。

现在有 2 头新牛加入牛棚，约翰需要把它们分别安置在两个原本空置的牛栏中。约翰不能移动任何原有的牛。

请帮助约翰安排这两头新牛的位置，使得安置后所有牛之间的最小距离 $D$ **尽可能大**。

## 输入

第一行一个整数 $N$。
第二行一个长度为 $N$ 的 01 字符串，表示牛棚当前的占用情况。

## 输出

一个整数，表示在最佳放置方案下，$D$ 的最大可能值。

## 样例

输入：

```text
14
10001001000010
```

输出：

```text
2
```

## 思路

如果原本完全没有牛（全 0 串），将两头牛放在 0 和 $N-1$ 即可得到最大距离 $N-1$。

如果已经有若干头牛，显然最终的最小距离 $D$ 不可能超过原本已有牛之间的最小间隙（$D \le \minExistingDist$）。
同时，目标是最大化最小距离，非常适合采用**二分答案**：

对于给定的候选距离 $d$（$1 \le d \le \minExistingDist$），检查是否能放入至少 2 头牛：
1. **最左侧空白区间** $[0, p_{\text{first}}]$：第一头牛在 $p_{\text{first}}$，左端边界不受约束，最多可放 $\lfloor p_{\text{first}} / d \rfloor$ 头牛；
2. **中间空白区间** $[p_i, p_{i+1}]$：两端都已有牛，要在内部放置新牛且距离至少为 $d$，最多可放 $\max(0, \lfloor (p_{i+1} - p_i) / d \rfloor - 1)$ 头牛；
3. **最右侧空白区间** $[p_{\text{last}}, N-1]$：右端边界不受约束，最多可放 $\lfloor (N - 1 - p_{\text{last}}) / d \rfloor$ 头牛。

将各区间可容纳的新牛数相加，若总和 $\ge 2$，则说明距离 $d$ 可行。单调二分即可找到最大的合法 $D$。

## 复杂度

单次可行性检验只需遍历一遍已有牛的下标，耗时 $O(N)$。二分范围在 $[1, N]$，循环 $\log_2 N \approx 17$ 次。总时间复杂度为 $O(N \log N)$，空间复杂度为 $O(N)$。在 $N = 10^5$ 下耗时约 0.02 秒。
