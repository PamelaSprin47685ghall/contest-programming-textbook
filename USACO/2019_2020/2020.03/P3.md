# P3　密切接触追踪（Cowntact Tracing）

## 题目

农夫约翰的 $N$ 头奶牛（$1 \le N \le 100$）编号为 $1 \dots N$。农场里暴发了 COWVID-19 疫情，约翰通过检测测出了每头牛当前的患病状态（01 字符串表示）。

通过监控录像，约翰整理出了握手记录列表，每条记录形如 $(t, x, y)$，表示在时间 $t$，奶牛 $x$ 与奶牛 $y$ 互相握手（碰撞蹄子）。所有握手时刻 $t$ 互不相同（$1 \le T \le 250$）。

已知传染机制如下：
1. 整个农场最初只有**恰好一头**奶牛染病（称为“0 号病人”）；
2. 任何奶牛一旦被感染，她在接下来的**恰好 $K$ 次**握手过程中会将病毒传染给对方；
3. 完成 $K$ 次握手后，该奶牛失去传染力，后续的握手不再导致新的传染（但她自己仍处于染病状态）。

约翰并不知道谁是 0 号病人，也不知道参数 $K$ 的确切数值。
请根据最终的患病状态与全部握手记录，推断：
- 有多少头奶牛可能是初始的“0 号病人”；
- 满足条件的 $K$ 的最小可能值与最大可能值（若最大值可以任意大，输出 `Infinity`）。

## 输入

第一行包含两个整数 $N$ 和 $T$。
第二行包含一个长为 $N$ 的 01 字符串，第 $i$ 个字符表示奶牛 $i$ 最终是否患病。
接下来 $T$ 行，每行三个整数 $t, x, y$（$1 \le t \le 250, 1 \le x, y \le N, x \neq y$），描述一次握手事件。

## 输出

一行输出三个值，由空格隔开：
- 可能成为“0 号病人”的奶牛数量；
- $K$ 的最小可能值；
- $K$ 的最大可能值（如果 $K$ 没有上限，输出 `Infinity`）。

## 样例

输入：

```text
4 3
1100
7 1 2
5 2 3
6 2 4
```

输出：

```text
1 1 Infinity
```

## 思路

奶牛数量 $N \le 100$，握手事件 $T \le 250$。
因为总握手次数只有 $T$ 次，所以哪怕 $K > T$，效果也与 $K = T+1$ 完全等价（即每头牛可以永远传染下去）。
因此，$K$ 的有效取值范围只需在 $0 \dots T+1$ 之间枚举。

我们可以进行全量暴力枚举：
1. 枚举哪头牛 $P$ 是最初的 0 号病人（共 $N$ 种可能）；
2. 枚举常数 $K$（共 $T+2$ 种可能）；
3. 将握手记录按时间 $t$ 升序排序，从时间 0 开始模拟传染：
   - 维护每头牛是否被感染，以及感染后参与握手的次数；
   - 每次握手 $(x, y)$：若 $x$ 已感染且握手次数尚未超过 $K$，则 $y$ 被感染；若 $y$ 已感染且握手次数未超过 $K$，则 $x$ 被感染。注意双方的握手计数器都要增加；
4. 模拟结束后，对比所有牛的最终感染状态是否与题目给出的字符串完全一致；
5. 若一致，则该对 $(P, K)$ 是合法的。据此统计可能的 0 号病人总数以及合法的 $K_{\min}$ 和 $K_{\max}$。若 $K_{\max} = T+1$，输出 `Infinity`。

## 复杂度

枚举 0 号病人耗时 $O(N)$，枚举 $K$ 耗时 $O(T)$，单次模拟遍历 $T$ 条边耗时 $O(T)$。总时间复杂度为 $O(N \cdot T^2)$。当 $N = 100, T = 250$ 时，总运算量约 $100 \times 250^2 \approx 6 \times 10^6$ 次，在 0.05 秒内即可完成。空间复杂度为 $O(N + T)$。
