# P2　奇数和偶数照片（Even More Odd Photos）

## 题目

农夫约翰想给他的 $N$ 头奶牛（$2 \le N \le 1000$）拍照。每头奶牛有一个整数 ID。

约翰要求将所有奶牛划分为若干个不相交的非空组，并排成一列拍照。照片从左到右各组中奶牛的 ID 总和必须**奇偶交替**：
- 第 1 组的和必须是**偶数**；
- 第 2 组的和必须是**奇数**；
- 第 3 组的和必须是**偶数**；
- 依此类推……

请问约翰最多能将这 $N$ 头奶牛划分为多少个组？题目保证至少存在一种合法分组。

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个整数，表示各头奶牛的 ID。

## 输出

一个整数，表示最多能划分出的合法组数。

## 样例

输入：

```text
7
1 3 5 7 9 11 13
```

输出：

```text
3
```

## 思路

数的大小并不重要，我们只关心每个数是奇数还是偶数。统计奇数总数 `odd` 与偶数总数 `even`。
根据和的奇偶性：
- 偶数 + 偶数 = 偶数，奇数 + 奇数 = 偶数；
- 奇数 + 偶数 = 奇数。

我们需要构建交替序列：偶, 奇, 偶, 奇, 偶……
1. 如果奇数过多（`odd > even`），我们可以将每两个奇数捆绑在一起，当作一个偶数使用（`odd -= 2; even += 1`），直到 `odd <= even`；
2. 如果此时 `even > odd + 1`，由于偶数组最多比奇数组多 1 组（首尾都是偶数组），多出来的所有多余偶数只能合并到已有的某个偶数组中，而不能独立成组，因此有效偶数组最多为 `odd + 1`；
3. 最终最多能划分的组数即为调整后的 `even + odd`。

## 复杂度

只需一次遍历统计奇偶性，随后执行常数级基本运算。时间复杂度为 $O(N)$，空间复杂度为 $O(1)$。
