# P2　舒适的奶牛（Comfortable Cows）

## 题目

农场是一个由网格单元组成的大平面。约翰将 $N$ 头奶牛（$1 \le N \le 10^5$）逐一放入农场。第 $i$ 头奶牛被安置在网格坐标 $(x_i, y_i)$ 处（$0 \le x_i, y_i \le 1000$）。所有奶牛的坐标互不相同。

如果某头奶牛在上下左右四个相邻格子中**恰好有 3 个格子**被其他奶牛占据，这头奶牛就感到“舒适（comfortable）”。

请在每加入一头奶牛后，输出当前农场中感到舒适的奶牛总数。

## 输入

第一行一个整数 $N$。
接下来 $N$ 行，每行两个空格隔开的整数 $x_i, y_i$。

## 输出

输出共 $N$ 行，第 $i$ 行表示放入前 $i$ 头奶牛后感到舒适的奶牛总数。

## 样例

输入：

```text
8
0 1
1 0
1 1
1 2
2 1
2 2
3 1
3 2
```

输出：

```text
0
0
0
1
0
0
1
2
```

## 思路

坐标范围在 $[0, 1000]$ 之内，我们可以直接开一个 $1001 \times 1001$ 的二维数组记录每个格子是否有牛（`hasCow`）以及该格周围现存的相邻牛数（`adjCows`）。

维护一个全局计数器 `comfortableCount`：
每当在 $(x, y)$ 放入一头新牛时：
1. 统计自身 4 个相邻方向中已经有牛的格子数，如果刚好是 3，则 `comfortableCount++`；
2. 随后，新牛的加入会使其 4 个相邻的已有邻居牛的度数均增加 1：
   - 如果邻居牛原本度数为 3，增加到 4 后失去舒适状态，`comfortableCount--`；
   - 更新邻居牛度数加 1；
   - 如果邻居牛增加后的度数刚好达到 3，获得舒适状态，`comfortableCount++`；
3. 每次只需常数次检查和更新即可输出当前的 `comfortableCount`。

## 复杂度

每次插入只检查新牛自身及其 4 个邻接格子，单次操作时间复杂度为 $O(1)$。处理全部 $N$ 头牛的总时间复杂度为 $O(N)$。空间复杂度为 $O(1000^2) = O(1)$。
