# P2　学术牛 II（Acowdemia II）

## 题目

实验室有 $N$ 名研究员（$1 \le N \le 100$），所有人的资历各不相同。实验室发表了 $K$ 篇学术论文（$1 \le K \le 100$），每篇论文包含所有 $N$ 名成员的署名排序。

署名排序规则如下：
1. 论文作者按照为论文付出的贡献大小从大到小降序排列；
2. 如果多位成员付出的贡献完全相同，他们之间会按照**名字的字典序**升序排列；
3. 资历更深的研究员承担更多行政职务，因此**资历深的研究员付出的贡献永远不会严格大于资历浅的研究员**（即资历深的贡献 $\le$ 资历浅的贡献）。

请根据这 $K$ 篇论文的署名顺序，推导每对研究员之间确定的资历深浅关系。

## 输入

第一行包含两个整数 $K$ 和 $N$。
第二行包含 $N$ 个空格隔开的字符串，表示研究员的姓名。
接下来 $K$ 行，每行包含 $N$ 个字符串，表示某篇论文的作者列表。

## 输出

输出一个 $N \times N$ 的字符矩阵：
- 第 $i$ 行第 $j$ 列表示研究员 $i$ 与研究员 $j$ 的关系；
- 如果确定 $i$ 比 $j$ 资历深，输出 `1`；
- 如果确定 $i$ 比 $j$ 资历浅，输出 `0`；
- 如果关系无法确定，输出 `?`；
- 对角线（$i=j$）输出 `B`。

## 样例

输入：

```text
2 3
bessie elsie mildred
elsie bessie mildred
bessie elsie mildred
```

输出：

```text
B1?
0B?
?1B
```

## 思路

在一篇论文的作者序列中，考察排在前面的作者 $X$ 和排在后面的作者 $Y$（即 $X$ 的下标小于 $Y$ 的下标）：
- 如果从 $X$ 到 $Y$ 之间的名字并非完全按字典序升序排列，说明中途必定存在相邻两个人不满足字典序；
- 这意味着中途发生了一次**贡献的严格下降**；
- 也就是说，$X$ 为论文做出的实际贡献严格大于 $Y$ 做出的实际贡献；
- 根据规则，“资历深的研究员贡献永远不会严格大于资历浅的研究员”，因此做出更多贡献的 $X$ 的资历必定**严格低于** $Y$ 的资历（即 $X$ 资历浅于 $Y$）。

我们只需对每篇论文，检查所有下标对 $(i, j)$（$i < j$）。如果子串 $\text{authors}[i \dots j]$ 不符合字典序升序，则确凿得知 $\text{authors}[i]$ 资历浅于 $\text{authors}[j]$。在矩阵中分别填入 `0` 与 `1`。

## 复杂度

处理 $K$ 篇论文，每篇论文检查所有对 $(i, j)$，耗时 $O(K \cdot N^2)$。当 $K = 100, N = 100$ 时，$KN^2 = 10^6$，在 0.02 秒内即可完成。空间复杂度为 $O(N^2)$。
