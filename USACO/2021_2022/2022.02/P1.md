# P1　课上打瞌睡（Sleeping in Class）

## 题目

贝茜在课上经常打瞌睡。在 $N$ 节课中（$1 \le N \le 10^5$），贝茜在第 $i$ 节课上睡着了 $a_i$ 次（$0 \le a_i \le 10^6$），所有课的瞌睡总次数不超过 $10^6$。

埃尔希想修改记录，让贝茜看起来在每节课上打瞌睡的次数完全一样。
埃尔希修改记录的唯一方式是：**合并两节相邻的课**，合并后新课的打瞌睡次数等于原本两节课打瞌睡次数之和。

请帮助埃尔希计算：最少需要进行多少次合并操作，才能使数组中的所有元素完全相等？

## 输入

第一行一个整数 $T$（$1 \le T \le 10$），表示测试用例的数量。
每个测试用例第一行包含一个整数 $N$，第二行包含 $N$ 个整数 $a_1, \dots, a_N$。
保证所有测试用例的 $N$ 之和不超过 $10^5$，$a_i$ 之和不超过 $10^6$。

## 输出

对每个测试用例输出一行：达成目标所需的最少合并次数。

## 样例

输入：

```text
3
6
1 2 3 1 1 1
3
2 2 3
5
0 0 0 0 0
```

输出：

```text
3
2
0
```

## 思路

任何合并操作都不会改变整个数组所有元素之和 $S = \sum a_i$。
假设最终合并成了 $K$ 个相等的块（$1 \le K \le N$），每个块的和必定为 $T = S / K$。
因此：
- $S$ 必须能被 $K$ 整除；
- 合并次数等于 $N - K$。为了使合并次数最少，我们应该让最终保留的块数 $K$ **尽可能大**！

算法步骤：
1. 计算数组总和 $S$。若 $S = 0$，本来就全部为 0，所需操作数为 0；
2. 从大到小枚举最终块数 $K = N, N-1, \dots, 1$；
3. 如果 $S \bmod K == 0$，目标块和为 $target = S / K$：
   - 线性遍历数组累加前缀和，如果累加到 $target$ 就清零开启下一个块；如果中途超过了 $target$，说明无法恰好划分出目标块；
   - 如果能顺利将整个数组分割为和均为 $target$ 的块，则找到了最大的合法 $K$，输出 $N - K$ 即可。

## 复杂度

$S \le 10^6$，其因数个数很少。枚举所有因数并进行线性检验，时间复杂度为 $O(N + \text{因数个数} \times N)$。在总和限制下耗时极少，约为 0.01 秒。空间复杂度为 $O(N)$。
