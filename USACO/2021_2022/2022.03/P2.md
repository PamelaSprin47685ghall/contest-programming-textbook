# P2　统计说谎者（Counting Liars）

## 题目

奶牛贝茜躲藏在数轴上的某个整数坐标处。其余 $N$ 头奶牛（$1 \le N \le 1000$）各自提供了一条线索：
- 第 $i$ 头奶牛声称贝茜藏在大于等于 $p_i$ 的位置（记为 `G pi`）；
- 或者声称贝茜藏在小于等于 $p_i$ 的位置（记为 `L pi`）。

所有牛的线索可能互相矛盾，意味着其中某些牛在说谎。
请计算在最佳的真实位置假定下，**最少有多少头奶牛在说谎**？

## 输入

第一行一个整数 $N$。
接下来 $N$ 行，每行包含一个字符（`G` 或 `L`）和一个整数 $p_i$（$0 \le p_i \le 10^9$）。

## 输出

一个整数，表示说谎奶牛的最少可能数量。

## 样例

输入：

```text
2
G 3
L 5
```

输出：

```text
0
```

## 思路

数轴上的任意位置都会被各头牛划分为“真话区间”与“假话区间”：
- `G pi`：在 $[p_i, +\infty)$ 上为真话，在 $(-\infty, p_i)$ 上为假话；
- `L pi`：在 $(-\infty, p_i]$ 上为真话，在 $(p_i, +\infty)$ 上为假话。

因为所有断点边界都是某头牛给出的坐标 $p_i$，在任意两个相邻断点之间的开区间内部，各头牛的真伪判断是完全不变的常数。
因此，能够取得最少说谎牛数的极值点，**必定可以在某个 $p_i$ 处取得**！

由于 $N \le 1000$ 规模较小：
我们只需直接枚举所有 $p_i$ 作为贝茜假想的藏身坐标，对每一个坐标遍历全部 $N$ 条陈述统计说谎总人数，取最小值即可。

## 复杂度

外层枚举 $N$ 个候选位置，内层检查 $N$ 条线索。总时间复杂度为 $O(N^2)$。当 $N = 1000$ 时，$N^2 = 10^6$，耗时小于 0.01 秒。空间复杂度为 $O(N)$。
