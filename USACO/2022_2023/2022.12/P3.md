# P3　逆向工程（Reverse Engineering）

## 题目

埃尔希写了一个程序，输入由 $N$ 个二进制变量 $b[0], \dots, b[N-1]$（每个为 0 或 1）组成的数组，通过一系列 `if / else if / else` 语句返回 0 或 1。
每条语句仅检查至多一个变量的值，例如：
```text
if (b[1] == 1) return 1;
else if (b[0] == 0) return 0;
else return 1;
```

埃尔希给出了 $M$ 组不同的输入字符串以及程序对应的输出值。贝茜怀疑埃尔希在说谎（即可能不存在任何具有上述结构的程序能与给定的 $M$ 组输入输出全部匹配）。

请针对每个测试用例，判断埃尔希是否必定在说谎（输出 `LIE`）或可能没有说谎（输出 `OK`）。

## 输入

第一行一个整数 $T$（$1 \le T \le 10$），表示测试用例的数量。
每个测试用例第一行包含两个整数 $N$ 和 $M$（$1 \le N, M \le 100$）。
接下来 $M$ 行，每行包含一个长为 $N$ 的 01 字符串和一个整数（0 或 1）。

## 输出

对每个测试用例输出一行：若不存在合法程序输出 `LIE`，否则输出 `OK`。

## 样例

输入：

```text
4

1 3
0 0
0 0
1 1

2 4
00 0
01 1
10 1
11 0

1 2
0 1
0 0

2 4
00 0
01 1
10 1
11 1
```

输出：

```text
OK
LIE
LIE
OK
```

## 思路

注意程序结构是严格顺序执行的 `if / else if / ...` 链：
第一条命中的 `if (b[var] == val) return res;` 会将所有满足条件 $b[var] == val$ 的输入直接截流返回。
因此，能够作为当前最外层分支条件的变量检查 $(var, val)$，必须满足：**在当前所有剩余未被处理的样本中，所有满足 $b[var] == val$ 的样本的输出结果必须完全相同（全为 0 或全为 1）！**

反向贪心消元法：
1. 维护尚未被已有规则分类的剩余样本集合；
2. 枚举所有可能的单变量条件 $(var, val)$（共 $N \times 2$ 种）：
   - 检查在剩余样本中，满足该条件的样本是否存在矛盾（即输出既有 0 又有 1）；
   - 若不存在矛盾且至少匹配了一个样本，则这一条分支规则可以安全成立，将匹配到的样本全部从剩余集合中剔除；
3. 重复执行该过程，直到所有样本都被成功分类（说明存在合法程序，输出 `OK`）；
4. 如果在某一轮中找不到任何一个无矛盾的有效分支条件，说明不可能写出符合要求的 `if-else` 程序，埃尔希必定说谎（输出 `LIE`）。

## 复杂度

每次消元至少消除 1 个样本，至多进行 $M$ 轮消元。每轮枚举 $2N$ 种条件并扫描 $M$ 个样本，单用例时间复杂度为 $O(M^2 N)$。在 $N, M \le 100$ 时，$M^2 N = 10^6$，耗时约 0.01 秒。空间复杂度为 $O(MN)$。
