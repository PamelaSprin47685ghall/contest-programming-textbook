# P1　饥饿的牛（Hungry Cow）

## 题目

贝茜是一头饥饿的奶牛。每天晚餐时间，如果牛棚里有干草堆，她就会吃掉 1 捆干草。

农夫约翰在某些天的早晨（晚餐前）会送来一批干草：第 $i$ 次送草在第 $d_i$ 天送来 $b_i$ 捆干草（$1 \le d_1 < d_2 < \dots < d_N \le T \le 10^{14}$，$1 \le b_i \le 10^9$）。

请计算在第 1 天到第 $T$ 天期间（包含第 $T$ 天），贝茜一共吃掉了多少捆干草。注意数值可能很大，请使用 64 位整数。

## 输入

第一行包含两个整数 $N$ 和 $T$（$1 \le N \le 10^5, 1 \le T \le 10^{14}$）。
接下来 $N$ 行，每行包含两个整数 $d_i$ 和 $b_i$。

## 输出

一个整数，表示贝茜在前 $T$ 天内吃掉的干草总数。

## 样例

输入：

```text
2 5
1 2
5 10
```

输出：

```text
3
```

## 思路

因为总天数 $T$ 高达 $10^{14}$，不能按天循环模拟。但是送草的事件只有 $N \le 10^5$ 次。
在两次送草事件之间的平静期，吃草速率固定为每天 1 捆。

我们可以进行**事件跳跃模拟**：
1. 维护当前牛棚库存的干草数 `currentHay` 以及上一次处理的日期 `lastDay`；
2. 遇到第 $i$ 次送草（第 $d_i$ 天）：
   - 在区间 $[lastDay, d_i - 1]$ 共有 $d_i - lastDay$ 天，贝茜最多能吃掉 $\min(currentHay, d_i - lastDay)$ 捆草；
   - 累加吃草数，扣除库存，并加入当天新送到的 $b_i$ 捆草；
   - 更新 `lastDay = d_i`；
3. 循环结束后，处理从最后一次送草日到截止日 $T$ 的区间 $[lastDay, T]$（共 $T - lastDay + 1$ 天），同理吃掉 $\min(currentHay, T - lastDay + 1)$ 捆草。

## 复杂度

只需一次遍历处理 $N$ 次送草事件，时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。在 $N = 10^5$ 时耗时约 0.01 秒。
