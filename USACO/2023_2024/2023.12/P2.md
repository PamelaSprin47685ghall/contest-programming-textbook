# P2　密切接触追踪 II（Cowntact Tracing 2）

## 题目

一排 $N$ 头奶牛（$1 \le N \le 3 \times 10^5$）中部分患病。每天早晨，每头患病奶牛会将疾病传染给与它相邻的健康奶牛。

给定经过若干天传播后的最终患病状态（01 字符串）。
请计算最初最少有多少头奶牛患病？

## 输入

第一行一个整数 $N$。
第二行一个长度为 $N$ 的 01 字符串。

## 输出

一个整数，表示最少初始病牛数。

## 样例

输入：

```text
5
11111
```

输出：

```text
1
```

## 思路

连续的 `1` 构成若干个独立的染病区间（块）。
设疾病传播了 $D$ 天：
- 一头初始染病的牛向左右各扩散 $D$ 天，覆盖的区间最大长度为 $2D + 1$；
- 如果某个染病块处于两端边界（例如从下标 0 开始），它向外侧扩散受边界截断，长度至少为 $D + 1$，由此可得 $D \le L - 1$；
- 如果染病块处于中间，两端都是 0，说明向两侧扩散都没有触及更远的牛，由此可得每个染病块必须能由若干个单点扩散产生，即 $D \le \lfloor (L - 1) / 2 \rfloor$。

在所有块中求出最大的合法天数 $D$。
在此天数下，每头初始病牛最多能覆盖 $W = 2D + 1$ 头连续的牛。对于长度为 $L$ 的块，最少需要 $\lceil L / W \rceil$ 头初始病牛。累加各块所需牛数即为答案。
