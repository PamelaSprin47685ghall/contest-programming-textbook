# P3　平衡细菌（Balancing Bacteria）

## 题目

一排 $N$ 块土地（$1 \le N \le 10^5$），第 $i$ 块土地上有细菌水平 $a_i$（正数表示过多，负数表示过少）。

约翰可以使用喷雾器进行调整：
在任意土地 $i$ 喷洒一次喷雾（可选择增加或减少），将导致：
- 土地 $i$ 的细菌水平改变 1；
- 土地 $i+1$ 的细菌水平改变 2；
- 土地 $i+2$ 的细菌水平改变 3；
- ……土地 $i+k$ 的细菌水平改变 $k+1$（直到最右端 $N$）。

请计算将所有土地的细菌水平全部调整为 0 所需的最少喷雾操作次数。

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个整数 $a_1, \dots, a_N$。

## 输出

一个整数，表示最少所需的操作总次数。

## 样例

输入：

```text
2
-1 3
```

输出：

```text
3
```

## 思路

从左到右贪心求解：
由于在位置 $i$ 施加的喷雾只能影响到下标 $\ge i$ 的土地，位置 0 的细菌水平**只能**由位置 0 自身执行的操作来消除！
因此：
1. 观察位置 0 当前的实际数值，必须在位置 0 施加 $\Delta_0 = -a[0]$ 次操作；
2. 随后位置 0 被成功清零，继续向右移动到位置 1；
3. 位置 1 当前的数值受到了来自位置 0 的影响（增加量为 $2 \cdot \Delta_0$），算出当前实际值后，由于后续的操作再也影响不到位置 1，位置 1 也必须在自身位置施加唯一的补偿操作清零；
4. 依次类推。我们在遍历过程中动态维护已施加操作对当前位置的值增量 `currentValue` 与斜率 `currentSlope`，即可在 $O(N)$ 时间内完成。
