# P3　最大化生产力（Maximizing Productivity）

## 题目

农场有 $N$ 个区域（$1 \le N \le 2 \times 10^5$）。第 $i$ 个区域在时刻 $c_i$ 关门，从起点走到第 $i$ 个区域需要耗时 $t_i$。

假设约翰在时刻 $S$ 从起点出发：
他在时刻 $S + t_i$ 到达第 $i$ 个区域。只有在 $S + t_i < c_i$（严格在关门之前到达）时，他才能访问该区域。

现有 $Q$ 次独立询问（$1 \le Q \le 2 \times 10^5$），每次询问给出 $V$ 和 $S$：
请问如果约翰在时刻 $S$ 出发，他是否能够访问**至少 $V$ 个**不同的区域？

## 输入

第一行两个整数 $N$ 和 $Q$。
第二行包含 $N$ 个整数 $c_1, \dots, c_N$。
第三行包含 $N$ 个整数 $t_1, \dots, t_N$。
接下来 $Q$ 行，每行两个整数 $V$ 和 $S$。

## 输出

对每次询问输出一行：若能访问至少 $V$ 个区域输出 `YES`，否则输出 `NO`。

## 样例

输入：

```text
5 5
3 5 7 9 11
1 2 3 4 5
1 3
2 3
3 3
4 3
5 3
```

输出：

```text
YES
YES
YES
YES
NO
```

## 思路

能在时刻 $S$ 出发并成功访问第 $i$ 个区域的条件为：
$$S + t_i < c_i \iff c_i - t_i > S$$

定义每个区域的余裕裕量 $d_i = c_i - t_i$。
则无论何时出发，能够访问的区域数量，就等于满足 $d_i > S$ 的区域总数！

离线预处理：
1. 将所有 $d_i$ 升序排序；
2. 每次查询给出 $S$，我们在有序数组 $d$ 中通过二分查找（`std::upper_bound`）快速定位第一个严格大于 $S$ 的位置；
3. 其右侧所有元素的数量即为满足条件的区域数；
4. 只要该数量 $\ge V$，输出 `YES`，否则输出 `NO`。

## 复杂度

排序数组耗时 $O(N \log N)$，每次询问二分查找耗时 $O(\log N)$。总时间复杂度为 $O((N + Q) \log N)$，空间复杂度为 $O(N)$。在 $N, Q = 2 \times 10^5$ 时耗时约 0.08 秒。
