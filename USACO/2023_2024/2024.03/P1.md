# P1　逻辑哞（Logical Moos）

## 题目

给出一个由布尔值（`true`、`false`）以及逻辑运算符 `and`、`or` 构成的有效布尔表达式，长度为 $N$。
运算优先级满足标准逻辑：`and` 的优先级高于 `or`。

现有 $Q$ 次独立询问，每次询问给出区间 $[l, r]$（$l$ 和 $r$ 必定对应某个布尔值，且区间内包含完整的表达式）以及目标布尔值 $target$（`true` 或 `false`）：
请问是否可以将子表达式 $[l, r]$ 整体替换为单个布尔值（`true` 或 `false`），使得整个完整表达式的最终求值结果恰好等于 $target$？

## 输入

第一行两个整数 $N$ 和 $Q$（$1 \le N, Q \le 2 \times 10^5$）。
第二行包含 $N$ 个字符串，交替为布尔值与运算符。
接下来 $Q$ 行，每行包含两个整数 $l, r$ 和一个字符串 `true` 或 `false`。

## 输出

输出一个长度为 $Q$ 的由 `Y` 和 `N` 组成的字符串。

## 样例

输入：

```text
5 7
false and true or true
1 1 false
1 3 true
1 5 false
3 3 true
3 3 false
5 5 false
5 5 true
```

输出：

```text
NYYYNYY
```

## 思路

任何一个布尔表达式由若干个由 `or` 分隔开的“`and` 块”构成。整个表达式为 `true` 当且仅当至少有一个 `and` 块为 `true`。

通过前缀与后缀预处理：
- `prefixOr[i]`：前缀区间是否已经包含为 `true` 的 `and` 块；
- `suffixOr[i]`：后缀区间是否已经包含为 `true` 的 `and` 块；
- 找到区间 $[l, r]$ 左侧最近的 `or` 与右侧最近的 `or`：
  - 如果区间外侧（前缀或后缀）已经存在为 `true` 的 `and` 块，则无论当前区间填什么，整式必定恒为 `true`（不可能为 `false`）；
  - 否则，若要整式为 `true`，当前区间所在的 `and` 块必须能够为 `true`（这要求该块内处于 $[l, r]$ 外侧的其余固定元素全为 `true`）；
  - 若要整式为 `false`，则要求外侧全不为 `true`，且当前区间填 `false` 可以将当前块变为 `false`。

## 复杂度

前缀预处理耗时 $O(N)$，每次询问查找最近 `or` 并做常数次判断耗时 $O(1)$。总时间复杂度为 $O(N + Q)$，空间复杂度为 $O(N)$。
