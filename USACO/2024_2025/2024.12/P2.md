# P2　奶酪立方体（Farmer John's Cheese Block）

## 题目

农夫约翰有一块 $N \times N \times N$ 的实心奶酪立方体（$1 \le N \le 1000$）。
奶酪内部由 $N^3$ 个单位小方块组成，每个小方块用坐标 $(x, y, z)$ 表示（$0 \le x, y, z < N$）。

老鼠们会陆续挖空 $Q$ 个小方块（$1 \le Q \le 2 \times 10^5$）。如果整条平行于坐标轴的长条（长度为 $N$）内部的所有小方块全都被挖空，就形成了一条能透光的完整隧道。

请在每次挖空一个小方块后，输出当前已形成的完整贯穿隧道的总数量。

## 输入

第一行两个整数 $N$ 和 $Q$。
接下来 $Q$ 行，每行三个整数 $x, y, z$（保证方块不重复被挖）。

## 输出

输出共 $Q$ 行，每行一个整数，表示挖空该方块后整个奶酪中的完整隧道数量。

## 样例

输入：

```text
2 5
0 0 0
1 1 1
0 1 0
1 0 0
1 1 0
```

输出：

```text
0
0
1
2
5
```

## 思路

立方体中有且仅有三类隧道：
1. 沿着 $z$ 轴贯穿：要求固定的 $(x, y)$ 处，所有 $z \in [0, N-1]$ 的小方块全被挖空；
2. 沿着 $y$ 轴贯穿：要求固定的 $(x, z)$ 处，所有 $y \in [0, N-1]$ 的小方块全被挖空；
3. 沿着 $x$ 轴贯穿：要求固定的 $(y, z)$ 处，所有 $x \in [0, N-1]$ 的小方块全被挖空。

维护三个 $N \times N$ 的二维数组分别记录这三组截面上的已挖方块数：
每当挖空一个方块 $(x, y, z)$：
- `xy[x][y]++`，若恰好达到 $N$，隧道总数加 1；
- `xz[x][z]++`，若恰好达到 $N$，隧道总数加 1；
- `yz[y][z]++`，若恰好达到 $N$，隧道总数加 1；
- 每次更新只需 $O(1)$ 常数时间。

## 复杂度

每次询问 $O(1)$，总时间复杂度为 $O(N^2 + Q)$，空间复杂度为 $O(N^2)$。在 $N = 1000, Q = 2 \times 10^5$ 时耗时约 0.05 秒。
