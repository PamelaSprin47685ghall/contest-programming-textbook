# P2　构造 MEX（Making Mexes）

## 题目

给出一个包含 $N$ 个非负整数的数组 $a_1, \dots, a_N$（$1 \le N \le 2 \times 10^5, 0 \le a_i \le N$）。
你可以执行若干次操作：每次操作可以将数组中任意一个元素修改为任意一个非负整数。

一个集合的 $\text{MEX}$ 定义为未在集合中出现的最小非负整数。
对于每个可能的取值 $v \in [0, N]$，请分别计算将数组的 $\text{MEX}$ 变为 $v$ 所需的**最少修改操作次数**。

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个整数 $a_1, \dots, a_N$。

## 输出

输出共 $N+1$ 行，第 $v$ 行输出将 $\text{MEX}$ 变为 $v$ 的最少操作次数。

## 样例

输入：

```text
4
2 2 2 0
```

输出：

```text
1
0
3
1
2
```

## 思路

要使得数组的 $\text{MEX}$ 恰好等于 $v$：
1. 数字 $v$ 本身**绝不能**在数组中出现：如果原数组中有 $c_v$ 个数值为 $v$，这 $c_v$ 个数必须全部修改为其他数（至少消耗 $c_v$ 次操作）；
2. 所有严格小于 $v$ 的每个整数 $0, 1, \dots, v-1$ **必须至少出现一次**：
   - 设在 $0 \dots v-1$ 范围内，有多少个数字当前在数组中完全缺失（频次为 0），记为 $missingCount$；
   - 这些缺失的数字必须通过将多余的数修改补充过来，产生 $missingCount$ 次操作；
3. 可以证明，用多余的多余数字补足缺失项后，总操作次数为 $\max(missingCount, c_v)$（或 $missingCount + c_v$ 当多余项不足时）。
顺序遍历 $v = 0 \dots N$ 即可线性递推计算。

## 复杂度

线性统计频次并递推，时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。在 $N = 2 \times 10^5$ 时耗时约 0.03 秒。
