# P1　蹄剪布减一（Hoof Paper Scissors Minus One）

## 题目

有 $N$ 头奶牛（$1 \le N \le 1000$）在玩“蹄子、剪刀、布”游戏的拓展版。
每轮比赛两头牛出招对决。现在某头牛在比赛中漏记了某一位选手的一次出招。

请根据给出的胜负历史记录矩阵，分析在各种可能的补全出招下，谁能够取得最终的优胜。

## 输入

第一行两个整数 $N$ 和 $M$。
接下来输入矩阵描述各轮出招与胜负关系。

## 输出

输出满足条件的可能优胜者信息。

## 样例

输入：

```text
3 3
D
WD
LWD
1 2
2 3
1 1
```

输出：

```text
0
0
5
```

## 思路

利用传递闭包与成对胜负关系图分析：
将各牛之间的胜负关系看作有向图上的有向边。
缺损的一条出招只会影响两头牛之间的单次胜负判定，枚举可能的缺损取值，在常数时间内更新拓扑关系并重新判定强连通分量与入度出度即可。
