# P3　熄灯（Lights Out）

## 题目

农夫约翰给谷仓装了一台新式挤奶机，它太费电，时不时让谷仓停电。停电太频繁，Bessie 已经把谷仓的地图背了下来，好在黑暗中也能找到出口。

谷仓是一个简单多边形（不自交），顶点为整数点 $(x_1, y_1) \ldots (x_n, y_n)$（$4 \le n \le 200$），按顺时针给出，相邻两条边一横一竖交替。出口在第 1 个顶点，Bessie 一开始站在某个不是出口的顶点上。她只能沿着谷仓的边界走，可以顺时针也可以逆时针，走到顶点时可以随时改变方向。

灯亮时，她当然只挑顺、逆两个方向中较短的那条走到出口。灯灭时她慌了神，忘了自己站在哪个顶点，好在还记得整张地图：站在一个顶点上（包括出发点）时，她能摸出这个角朝里凹还是朝外凸，也能认出这里是不是出口；沿一条边走到头，她能知道这条边有多长。于是她可以一边摸索一边收集信息，等到能确定自己的位置，就能算出余下到出口的最短路。

请你求出：在她的黑暗策略最优的前提下，最坏情况（起点取遍所有可能的顶点）下，黑暗中走的总路程比灯亮时的最短路多出多少。

## 输入

第一行一个整数 `N`（$4 \le N \le 200$）。

接下来 `N` 行，每行两个整数，按顺时针依次给出各个顶点坐标（绝对值不超过 100000）。

## 输出

一个整数：最坏情况下多走的最小距离。

## 样例

输入：

```text
4
0 0
0 10
1 10
1 0
```

输出：

```text
2
```

解释：这是一条 $1 \times 10$ 的长条，四个角摸起来一模一样，所以刚开始的信息几乎没用。一种最优策略是一路顺时针走：从 3、4 号顶点出发都不必多走，从 2 号顶点出发也只多走 2。

## 思路

她能观察到的东西只有三种：某个顶点朝里凹还是朝外凸、这条边有多长、这个顶点是不是出口。把整座谷仓编码成一条"观测串"：偶数位放拐角（出口记成 0，凸、凹各用一个不同的字符），奇数位放边长。那么无论她顺时针还是逆时针摸索，摸出的一段信息就是这个串的某个子串（反向摸时顺序相反）。

**状态压缩。** 她真正掌握的信息是"哪些窗口（连续的一段顶点）与我的观察完全吻合"。两个窗口只要字符串相同，她就绝不可能区分，因此可以把每个子串归到它的等价类——取"最早出现的位置"作代表元（预处理 `canon[i][len]`），状态数从 $O(N^2)$ 种窗口变成 $O(N^2)$ 个等价类，恰好和窗口数同阶。

**状态定义。** `dp[start][ln][strt][side]`：她已知的窗口是代表元从 `start` 开始、共 `ln` 个顶点，她是从窗口内第 `strt` 个顶点出发的，此刻人站在窗口的 `side` 端（0 左端、1 右端）。值 = 从这一刻起算，"比灯亮时多走的距离"在最坏情况下的最小值。整个过程中走过的路程一直被累加进来，直到能确定位置；所以一旦窗口里露出出口（窗口包含顶点 0），她就能完全定位，余下的路按灯亮时的最短路 `opt[strt]` 走完，于是这个状态的值直接记成 $-opt$——累加的路程减去灯亮时的最短路，正是"多走的距离"。

**转移。** 从窗口 $(i, ln)$ 出发只有两种选择：往左多摸一条边，或往右多摸一条边。摸之前要站到窗口对应的那一端去，若此刻人在另一端，就得先横穿整个窗口（距离 = 窗口两端沿墙的弧长）。摸到新边后，她看到的字符串属于哪个等价类是她控制不了的：`nextLeft[i][ln]`、`nextRight[i][ln]` 预先算好了所有可能出现的代表元（把当前窗口向一端扩展一个顶点后，可能的规范窗口 = "去掉那一端顶点后与当前窗口同类"的那些窗口），转移时对这些可能取最坏（`max`），再对"往左 / 往右"两种选择取最优（`min`）。

**求解顺序。** 窗口越大信息越多，所以按窗口大小从大到小填表；大小为 1 的状态就是她的初始处境（只知道出发顶点长什么样），把所有 `ln == 1` 的状态取最大值就是答案。

一个细节：为了区分"两种拐角"和"出口"、"边长"，串里用一个正数存边长，两个不同的负数存拐角，0 存出口；比对时只关心字符是否相同，所以代表元之间的相等恰好等价于子串相等。
