# P1　升职计数（Promotion Counting）

## 题目

奶牛们又一次尝试创业，可惜它们忘了自己实在是糟糕的管理者！

公司里的奶牛编号 $1 \ldots N$（$1 \le N \le 100000$），组织成一棵树：1 号奶牛是总裁（树的根），除总裁外每头奶牛都有一个直属上司（树上的父亲）。每头奶牛 $i$ 有一个互不相同的熟练度 $p(i)$，表示它干得有多好。如果 $i$ 是 $j$ 的祖先（上司的上司的上司……），就说 $j$ 是 $i$ 的下属。

遗憾的是，奶牛们发现经常出现“上司比好几个下属还差”的情况，这时上司就该考虑提拔一些下属。请对每头奶牛 $i$，统计满足 $p(j) > p(i)$ 的下属 $j$ 的个数。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，依次给出 $p(1) \ldots p(N)$，每个是 $1 \ldots 10^9$ 之间互不相同的整数。

接下来 $N-1$ 行，依次给出 $2 \ldots N$ 号奶牛的上司编号。

## 输出

输出 $N$ 行，第 $i$ 行是熟练度高于奶牛 $i$ 的下属数量。

## 样例

输入：

```text
5
804289384
846930887
681692778
714636916
957747794
1
1
2
3
```

输出：

```text
2
0
1
0
0
```

解释：树是 1 的两个儿子 2、3，其中 2 的儿子是 4，3 的儿子是 5。1 号奶牛的下属里 2 号和 5 号比它强，共 2 个；2 号奶牛的下属 4 号比它弱，0 个；3 号奶牛的下属 5 号比它强，1 个；4、5 号没有下属，都是 0。

## 思路

对每头奶牛分别枚举它的所有下属会太慢（链状树上是 $O(N^2)$）。换个角度：我们只需要判断“谁是自己的下属”，而不需要真的沿着树爬。

先对树做一次**前序遍历**。前序遍历有一个关键性质：一棵子树里的所有点在遍历序列中恰好排成**连续的一段**，而且子树的根就排在这一段的最前面。于是“$j$ 是 $i$ 的下属”就等价于“$j$ 在前序序列里的位置落在以 $i$ 的位置为起点的、长度为 $i$ 子树大小的那段区间里”，树上的问题就变成了序列上的区间问题。

再注意到我们要数的是熟练度**高于** $i$ 的下属。把奶牛按熟练度从高到低排序，依次处理：处理到 $i$ 时，已经处理过的奶牛恰好就是所有熟练度比 $i$ 高的奶牛。用树状数组记录“已经处理过的奶牛各自在前序序列中的位置”，那么 $i$ 的答案就是它子树对应区间内已插入位置的个数，一次区间求和即可；随后把 $i$ 自己的位置插入树状数组。

前序遍历与子树大小都用迭代方式实现：树可能退化成一条长度 $10^5$ 的链，递归会爆栈。

## 复杂度

前序遍历与子树大小统计是 $O(N)$，排序 $O(N\log N)$，之后每个点做一次树状数组区间查询和一次单点插入，各 $O(\log N)$。总时间 $O(N\log N)$，空间 $O(N)$。
