# P3　奶牛为什么要过马路 III（Why Did the Cow Cross the Road III）

## 题目

FJ 继续琢磨奶牛过马路的问题，这次他意识到"友好"的门槛更微妙：品种 $a$ 与品种 $b$ 友好当且仅当 $|a-b| \le K$，否则不友好。

给出马路两侧各 $N$ 块田地的品种顺序（$1 \le N \le 100000$，每侧都是 $1 \ldots N$ 的一个排列），其中 $0 \le K < N$。交叉品种对的定义与前两题相同：不同品种 $a,b$ 的过马路路线必定相交时就称 $(a,b)$ 交叉。请统计**不友好的交叉品种对**数量。

## 输入

第一行两个整数 $N$ 和 $K$。

接下来 $N$ 行，依次给出路一侧各田地的品种编号。

再接下来 $N$ 行，依次给出路另一侧各田地的品种编号。

## 输出

输出一个整数：不友好的交叉品种对数量。

## 样例

输入：

```text
4 1
4
3
2
1
1
4
2
3
```

输出：

```text
2
```

解释：共有 $4$ 个交叉品种对，其中品种 $1,4$（$|1-4|=3>1$）与品种 $1,3$（$|1-3|=2>1$）是不友好的交叉对，所以答案是 $2$。

## 思路

用"全部交叉对数量"减去"友好的交叉对数量"。

**全部交叉对**：设路一侧第 $i$ 块田地的品种在另一侧的位置是 $p_i$。对同侧位置 $i<j$ 的两头奶牛，她们交叉当且仅当 $p_i > p_j$，因此全部交叉对数就是 $p_1 \ldots p_N$ 的逆序对数，用树状数组 $O(N \log N)$ 求出。

**友好交叉对**：把每个品种 $c$ 看成平面上的点 $(\mathrm{posA}(c), \mathrm{posB}(c))$，其中 $\mathrm{posA}(c)$、$\mathrm{posB}(c)$ 分别是品种 $c$ 在两侧的位置。品种 $a$ 的路线与品种 $c$ 的路线交叉，当且仅当两个点在"横坐标与纵坐标的大小关系相反"这一意义上构成逆序；于是每个交叉对恰好有一个方向满足：$a$ 的横坐标更小、纵坐标更大（即 $a$ 落在 $c$ 的左上角，两支路线的顺序在一次比较中是相反的）。

因此友好交叉对数可以写成对每个品种 $c$ 的求和：

$$\#\{a : a \le c+K,\ \mathrm{posA}(a) < \mathrm{posA}(c),\ \mathrm{posB}(a) > \mathrm{posB}(c)\} - \#\{a : a \le c-K-1,\ \text{同样两个不等式}\}.$$

第一项统计品种编号不超过 $c+K$ 的左上角点数，第二项扣掉编号不超过 $c-K-1$ 的部分，两者之差正是满足 $|a-c| \le K$ 的那些 $a$（品种 $c$ 自身因为横坐标不满足严格小于，不会被计入）。

于是问题变成：按品种编号从小到大"激活"点（品种 $v$ 的点在时刻 $v$ 出现），并回答若干形如"已激活的点里落在给定点左上角的个数"的询问——询问挂在时刻 $c+K$（超过 $N$ 就截断到 $N$）与时刻 $c-K-1$ 上。这是一个二维计数问题：外层用按下标（横坐标）分段的树状数组，每个节点存下这一段里所有纵坐标的有序表，再配一个内层树状数组记录其中已激活的个数。激活与查询各花 $O(\log^2 N)$。

注意答案最大约为 $\frac{N(N-1)}{2}$，需要用 `long long`。
