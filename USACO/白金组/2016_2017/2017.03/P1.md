# P1　现代艺术（Modern Art）

## 题目

画家 Picowso 在一张 $N \times N$ 的画布上作画，画布最初全是 $0$。她一共画 $N^2$ 个矩形，分别使用颜色 $1 \ldots N^2$，每种颜色恰好用一次。每个矩形的边与画布平行，可以大到整张画布，也可以小到单个格子；后画的矩形会盖住先画的，所以最后画的那个矩形一定完整地露在外面。

给定画布最终的样子，请统计有多少种颜色**可能是最先画上去的**。

## 输入

第一行一个整数 $N$（$1 \le N \le 1000$）。

接下来 $N$ 行，每行 $N$ 个整数（取值范围 $0 \ldots N^2$），描述画布的最终状态。输入保证这张画布确实能按题目规则画出来。

## 输出

一个整数：可能是最先画上去的颜色种数。

## 样例

输入：

```text
4
2 2 3 0
2 7 3 7
2 7 7 7
0 0 0 0
```

输出：

```text
14
```

解释：颜色 $2$ 可以最先画；颜色 $3$ 一定画在 $7$ 之后，颜色 $7$ 一定画在 $2$ 之后，所以它俩不行；没露过面的 $13$ 种颜色都可以最先画，因此答案是 $14$。

## 思路

为了让"可能最先画"的颜色尽量多，我们应当假设每个矩形都尽可能小——一种颜色的矩形最小就是它所有格子的**最小外接矩形**（最上面那一行、最左边那一列等等）。矩形画得越大，只会和更多矩形重叠、否定掉更多颜色，所以取最小矩形不会让答案变小。

现在有两种颜色的矩形 $R$（颜色 $c$）和 $S$（颜色 $d$）。如果 $S$ 盖住了 $R$ 的某个格子 $(i,j)$，而 $(i,j)$ 最终显示的是 $c$，那么 $S$ 一定画在 $c$ 之前（否则 $(i,j)$ 上就不会是 $c$ 了），于是 $c$ 不可能是最先画的。反过来，如果 $c$ 的所有格子都没有被别的矩形盖住，就可以把 $c$ 的矩形最先画上，再按合适的顺序画其余颜色。所以：

> 露过面的颜色 $c$ 可能最先画 $\iff$ $c$ 的每个格子都只被 $c$ 自己的矩形盖住（覆盖数为 1）。

统计覆盖数用**二维差分**：给每种颜色的最小矩形在四个角打上 $+1/-1$，再求一次二维前缀和，每个格子的前缀和就是盖住它的矩形个数。逐格检查，若某格颜色为 $c$ 而覆盖数 $\ge 2$，就把 $c$ 淘汰。

没露过面的颜色一定可以最先画：把它先画在某个会显示别的颜色的格子上，之后自然被盖住。于是答案 = $N^2$ − 被淘汰的颜色数。

只有一个例外：如果画布上只露出一种颜色，它必然是**最后**画的（最后画的矩形一定完整可见），因此答案要减掉它，即 $N^2-1$。特别地当 $N=1$ 时整幅画只画了一次，那种颜色既最先也最后，答案是 $1$。

## 复杂度

读入与差分前缀和都是 $O(N^2)$，遍历颜色是 $O(N^2)$；时间 $O(N^2)$，空间 $O(N^2)$（画布、差分数组以及每种颜色的四个边界值）。
