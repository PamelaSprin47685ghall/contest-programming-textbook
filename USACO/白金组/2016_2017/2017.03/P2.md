# P2　更换牧草（Switch Grass）

## 题目

FJ 的农场有 $N$ 块田地（$1 \le N \le 200000$），由 $M$ 条双向道路相连（$1 \le M \le 200000$，图保证连通，任意两块田地之间至多一条直路，路的长度在 $1 \ldots 10^6$ 之间）。每块田地里种着 $K$ 种草之一（$1 \le K \le N$）。

之后 FJ 会做 $Q$ 次"更新"（$1 \le Q \le 200000$）：把某块田地的草换成另一种。每次更新后，他想知道**草种不同的两块田地之间的最短路径长度**（在所有草种不同的田地对里取最近的一对）。题目保证任何时刻至少有两块田地的草种不同。

## 输入

第一行四个整数 $N, M, K, Q$。

接下来 $M$ 行，每行三个整数 $A, B, L$，表示田地 $A$ 与 $B$ 之间有一条长度为 $L$ 的路。

接下来一行 $N$ 个整数，表示各块田地初始的草种。

最后 $Q$ 行，每行两个整数 $A, B$，表示把田地 $A$ 的草种换成 $B$。

## 输出

对每次更新输出一行，表示更新后草种不同的两块田地之间的最短路径长度。

## 样例

输入：

```text
3 2 3 4
1 2 3
2 3 1
1 1 2
3 3
2 3
1 2
2 2
```

输出：

```text
1
3
3
1
```

解释：初始草种为 $1,1,2$，边 $2\text{-}3$ 的两端不同种，长度为 $1$。第一次更新把 $3$ 号田改成 $3$ 号草，仍是这条边，答案为 $1$；第二次把 $2$ 号田改成 $3$ 号草，此时只有边 $1\text{-}2$ 两端不同种，长度 $3$；第三次把 $1$ 号田改成 $2$ 号草，仍是边 $1\text{-}2$，长度 $3$；第四次把 $2$ 号田改成 $2$ 号草，变成边 $2\text{-}3$ 两端不同种，答案回到 $1$。

## 思路

**第一步：答案一定是一条边。** 设 $u,v$ 草种不同，它们最短路径上长度为 $1 \ldots$ 的若干条边中，必有一条边两端草种不同（否则整条路径同种，与 $u,v$ 不同种矛盾）；单独取这条边也是一条合法路径，而且更短（边长都是正数）。所以每次要求的就是：**所有"两端草种不同的边"中的最小边权**。

**第二步：只看最小生成树。** 设边 $e=(u,v,w)$ 不在最小生成树上，树上 $u$ 到 $v$ 的路径上每条边权都不超过 $w$（否则把 $e$ 换进去能得到更小的生成树）。这条路径的两端草种不同，所以路径上必有一条两端草种不同的边，它的权不超过 $w$。因此非树边永远不可能比树上某条"颜色不同"的边更优，只需要考虑最小生成树的边。

**第三步：把树在 1 号田地处生根。** 每条树边都恰好是"父亲—孩子"的关系。对每个点 $u$ 维护它的孩子，并按颜色分组：

- `groups[u][c]`：孩子中颜色为 $c$ 的那些孩子与 $u$ 之间的边权集合（用 `multiset` 维护，因为要随时取最小值、还要支持删除）；
- `best[u]`：每个颜色组的当前最小边权，键为 `(边权, 颜色)`。

由于 `best[u]` 里每种颜色只出现一次，$u$ 的答案（从 $u$ 连到草种不同的孩子的最短边）就是 `best[u]` 中第一条颜色不等于 `color[u]` 的记录——先看的头元素，颜色相同就往后跳一条即可。

把所有点的答案放进一个全局 `multiset`，它的最小值就是本题答案。

**第四步：一次更新只影响两个点。** 把点 $a$ 的颜色从旧色改成新色后：

- $a$ 在父亲 $parent[a]$ 的分组里要"搬家"（从旧颜色组挪到新颜色组），顺便更新 `best[parent[a]]`；
- $a$ 自己的颜色变了，它自己的答案要重新算；
- 其余任何点的分组内容都没变。

每个操作都是若干个 `map` / `multiset` 操作，单次更新 $O(\log N)$。

## 复杂度

读入并排序 $M$ 条边、跑 Kruskal 与建树是 $O(M \log M)$（并查集近似 $O(M\alpha)$）；每次更新只会改动两个点上的 `map`/`multiset`，外加全局集合的一次删除插入，共 $O(\log N)$。总时间 $O\big((N+M)\log M + Q \log N\big)$，空间 $O(N+M)$。
