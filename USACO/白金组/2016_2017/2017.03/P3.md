# P3　奶牛 BASIC（COWBASIC）

## 题目

Bessie 发明了一门语言 COWBASIC，它只有两种运算：加法和 MOO 循环，所有加法都在模 $10^9+7$ 意义下进行。程序不超过 100 行，每行不超过 350 个字符，由下面三类语句组成：

- 赋值：`<变量> = <表达式>`；
- 循环：`<整数> MOO { <若干语句> }`，把块里的代码原样执行该整数次，可以嵌套；
- `RETURN <变量>`，保证恰好出现一次且是最后一行。

表达式只有三种形式：整数、变量、`( <表达式> ) + ( <表达式> )`。整数是正数且不超过 $100000$，变量名是不超过 10 个小写字母的字符串。保证任何变量都不会在定义之前被使用。请算出程序返回的数。

## 输入

一个符合上述语法的 COWBASIC 程序，`RETURN` 语句一定在最后一行。

## 输出

一个整数：被 `RETURN` 的变量的值。

## 样例

输入：

```text
x = 1
10 MOO {
 x = ( x ) + ( x )
}
RETURN x
```

输出：

```text
1024
```

解释：循环体每次让 $x$ 翻倍，循环执行 10 次，于是 $x = 2^{10} = 1024$。

## 思路

表达式里只有加法，所以每个表达式的值都是各变量的线性函数；一段顺序执行的语句，合起来也是"每个新变量 = 若干个旧变量的线性组合 + 常数"。

把状态写成一个列向量 $V = (1, v_1, v_2, \ldots, v_m)^{\mathsf T}$：第 0 维固定为常量 $1$，用来承载常数项，后面每一维是一个变量。于是：

- **一条赋值语句** $v = a_0 + a_1 v_1 + \cdots$ 就是一个矩阵：单位矩阵的第 $v$ 行换成系数行 $(a_0, a_1, \ldots)$；
- **两条语句接起来**（先 $A$ 后 $B$）对应矩阵相乘 $B \cdot A$；
- **循环执行 $n$ 次**对应矩阵的 $n$ 次幂，用快速幂在 $O(\log n)$ 次矩阵乘法内完成；
- 整个程序最终也对应一个矩阵 $M$，答案是 $M \cdot (1,0,\ldots,0)^{\mathsf T}$ 中 `RETURN` 变量对应的那一项（也就是 $M$ 那一行的第 0 列）。变量的初始值无关紧要，因为题目保证变量都先定义、后使用。

实现上，语句按**前序**编号：遇到循环时先给循环语句自己占一个下标，再解析它的循环体，于是每个循环体都是连续的一段下标。用一条显式的矩阵栈模拟"一层层拼装语句列表"：进入循环就压入一个单位矩阵，扫描到循环体结束（下标到达 `bodyEnd`）就把它求 $n$ 次幂再乘到外层的累积矩阵上。这样既不用递归遍历语法树，深度也只有嵌套层数。

矩阵乘法里每累加 8 项才取一次模：每项都是 $(10^9+6)^2 < 2^{60}$ 量级，8 项相加仍在 64 位整数范围内，省掉了大量取模。

## 复杂度

设程序里的变量数为 $m$（$m \le 99$），矩阵大小是 $m+1$。每个 MOO 循环需要 $O(\log n)$ 次 $O(m^3)$ 的矩阵乘法，即 $O(m^3 \log n)$；而 100 行的程序里"每定义一个变量至少占一行、每层循环至少占两行"，二者互相挤占行数，所以实际总运算量远小于按 50 个循环估出的上界（官方分析给出的紧致上界约 $8.8 \times 10^7$ 次乘法）。

空间方面：矩阵栈的大小是嵌套层数 $d$（$\le 50$）乘 $(m+1)^2$，即 $O(d\,m^2)$，约几 MB。
