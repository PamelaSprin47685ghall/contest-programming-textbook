# P1　从牛群中脱颖而出（Standing Out from the Herd）

## 题目

$N$ 头奶牛（$1 \le N \le 10^5$）各有一个只含小写字母的名字，所有名字的总长度不超过 $10^5$。一头奶牛的"独特性"等于她的名字中只属于她一个（不出现于任何其他奶牛名字里）的子串个数，同一个子串即便在她自己的名字里出现多次也只算一次。例如 `amy` 与 `tommy` 待在一起时，`amy` 的独特性是 3（`a`、`am`、`amy`；而 `m`、`y`、`my` 被 `tommy` 共享），`tommy` 是 11。求每头奶牛的独特性。

## 输入

第一行一个整数 `N`。

接下来 `N` 行，每行一个只含小写字母的字符串，表示一头奶牛的名字。

## 输出

共 `N` 行，每行一个整数，依次表示每头奶牛的独特性。

## 样例

输入：

```text
3
amy
tommy
bessie
```

输出：

```text
3
11
19
```

## 思路

把所有名字拼成一个长串，名字之间插入分隔符 `'\1'`（它比 `'a'` 小，于是所有从分隔符开始的后缀都排在全部真实后缀之前），对这个长串求**后缀数组**（倍增 + 计数排序）与相邻后缀的 **LCP 数组**（Kasai 算法）。任意两个后缀的最长公共前缀等于它们在 SA 中下标之间所有相邻 LCP 的最小值，于是可以用稀疏表 $O(1)$ 求任意两个后缀的 LCP。

对某头奶牛的一个后缀 $S$，记：

- `prevSame(S)`：同一头奶牛在 SA 序中紧挨在 $S$ 前面那个后缀与 $S$ 的 LCP；
- `f(S)`：$S$ 与**别的奶牛**的任意后缀的 LCP 的最大值。由于后缀按字典序排列，$f(S)$ 一定取在 SA 里 $S$ 左右两侧最近的"别人的后缀"上（区间越长最小值越小），所以只要这两个值就够了。

那么 $S$ 的前缀中只属于这头牛的个数为

$$\max\bigl(0,\ |S| - \max\{prevSame(S),\ f(S)\}\bigr).$$

理由：长度超过 $f(S)$ 的前缀不可能出现在别的名字里（否则有别的后缀与 $S$ 的公共前缀更长）；而在同一头奶牛内部，长度不超过 `prevSame(S)` 的前缀已经由 SA 序里更靠前的同名词缀负责计数，超过它的前缀恰好在这里被数一次。把一头牛所有后缀的贡献相加即得她的独特性。

实现上把 SA 中连续的同名后缀看成"块"（块极大，所以块两端紧邻的后缀都来自别的牛）：块内前扫一遍得到每个后缀与左侧最近异名后缀的 LCP，后扫一遍得到右侧的，块首再用稀疏表求它与同一头牛上一段块尾之间的 LCP。注意答案可能远超 `int`（单个名字长 $10^5$ 时可达 $5 \times 10^9$），要用 `long long`。

## 复杂度

后缀数组与 LCP 数组均为 $O(L \log L)$，稀疏表预处理 $O(L \log L)$、查询 $O(1)$，逐块统计 $O(L)$。总时间 $O(L \log L)$，空间 $O(L \log L)$，其中 $L$ 为所有名字加上分隔符后的总长度（$\le 2 \times 10^5$）。
