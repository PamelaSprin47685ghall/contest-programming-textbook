# P3　贪心的收礼者（Greedy Gift Takers）

## 题目

农夫 Nhoj 的 $N$ 头牛（$1 \le N \le 10^5$）排成一队领礼物，牛 1 在队首、牛 $N$ 在队尾。农夫 John 本想每轮让队首的牛领走礼物后站到队尾，可牛 $i$ 拿到礼物后会"插队"：她总是恰好切到 $c_i$ 头牛的**前面**（$0 \le c_i \le N-1$），也就是说她会插到队尾那 $c_i$ 头牛之前。

礼物无限供应，同一头牛可以领很多次。请求出有多少头牛**无论如何都领不到**礼物。

## 输入

第一行一个整数 `N`。

第二行 $N$ 个整数 `c_1 c_2 ... c_N`。

## 输出

一个整数：永远领不到礼物的牛的数量。

## 样例

输入：

```text
3
1 2 0
```

输出：

```text
1
```

## 思路

关键观察：一次插队不会改变任何两头牛之间的先后顺序。队首的牛 $i$ 从名次 1 插到名次 $N - c_i$（记作她的**跳跃号码** $N-c_i$）：原来排在她前面（名次 $2 \sim N-c_i$）的牛仍然在她前面，原来在她后面的牛仍然在她后面。所以：

- 领不到礼物的牛一定是初始队列的一个**后缀**：若某头牛领不到礼物，她始终在某头牛后面，而排在更后面的牛永远排不到队首；
- 任一头牛的跳跃号码就是它插回队列后所处的名次。

再看队伍里第一个领不到礼物的牛（她前面有 $k$ 头牛）。她的名次只会减小、不会增大，最终稳定下来，此时挡在她前面的 $k$ 头牛永远挡着她，而她们每头都会轮到队首（否则"第一个领不到礼物的牛"就不是她），且每次插入后名次都 $\le k$，即跳跃号码 $\le k$。反过来，若某头牛前面存在 $i$ 头跳跃号码 $\le i$ 的牛，则每轮过后这 $i$ 头牛仍然都在她前面（插队者只能插到名次 $\le i$ 的地方），她永远到不了队首。

于是"第 $m$ 头牛（前面有 $m-1$ 头牛）永远领不到礼物"等价于：存在 $i$，使得前 $m-1$ 头牛中跳跃号码 $\le i$ 的牛至少有 $i$ 头。用桶 + 前缀和可以 $O(N)$ 判定一头牛，而该条件关于 $m$ 单调，直接二分第一个领不到礼物的牛即可。
