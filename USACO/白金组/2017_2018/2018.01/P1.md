# P1　救生员（Lifeguards）

## 题目

Farmer John 给奶牛们开了一个游泳池，雇了 $N$ 头奶牛当救生员，每头救生员值班一段连续的时间区间。为简单起见，游泳池每天从时刻 $0$ 开到时刻 $10^9$，所以每头奶牛的值班时间可以用两个整数（开始时刻、结束时刻）描述。例如一头从 $t=4$ 值班到 $t=7$ 的救生员覆盖了 3 个单位时间（注意端点是“时刻点”）。

不幸的是，John 多雇了 $K$ 头救生员。既然他必须**正好开除 $K$ 头**救生员，那么剩下的救生员最多还能覆盖多少时间？只要至少有一头救生员在，这段时间就算被覆盖。

## 输入

第一行两个整数 $N$ 和 $K$（$K \le N \le 100000$，$1 \le K \le 100$）。

接下来 $N$ 行，每行两个整数，表示一头救生员值班的起点与终点，范围是 $0 \ldots 10^9$。所有端点互不相同，不同救生员的值班区间可能重叠。

## 输出

一个整数：开除 $K$ 头救生员后，剩下的人还能覆盖的最长时间。

## 样例

输入：

```text
3 2
1 8
7 15
2 14
```

输出：

```text
12
```

解释：开除 $1\ldots 8$ 和 $7\ldots 15$ 这两头，只剩 $2\ldots 14$，覆盖 $14-2=12$ 个单位时间。

## 思路

**第一步：把“正好开除 $K$ 个”换成“至少开除 $K$ 个”。** 如果某个方案开除了超过 $K$ 头奶牛，我们可以把多开除的那些再叫回来（保留它们），覆盖时间只会变多，不会变少。所以“至少开除 $K$ 个”的最优值和“正好开除 $K$ 个”相同。这样处理起来方便很多，因为可以放心地“随手多开除”。

**第二步：剔除被包含的区间。** 若区间 $A$ 被区间 $B$ 完全包含（$A$ 的左右端点都夹在 $B$ 里面），那么开除 $A$ 不会损失任何覆盖。由第一步，最优解中不妨认为这些被包含的区间**全都被开除**——它们正好帮我们消耗开除名额。实现上把区间按左端点排序，同时记录“前面出现过的最大右端点”；只要当前区间的右端点比它小，就一定是被某个更早的区间包含（端点互不相同，不会取等），直接开除并计数。剔除后剩下的区间按左端点排序时，右端点也严格递增，我们称这样的区间为**单调区间**。

**第三步：动态规划。** 记剩下的（单调）区间依次为 $1..M$。定义

$$f(i,r)=\text{只看前 } i \text{ 个区间、保留第 } i \text{ 个、且至少开除 } r \text{ 个时的最大覆盖长度}$$

转移只有三种情况（设 $j_0$ 是 $1..i-1$ 中最左边那个与第 $i$ 个区间相交的下标）：

1. **前 $i$ 个里只保留第 $i$ 个**：覆盖 $e_i-s_i$，可行当且仅当 $r\le i-1$。
2. **保留 $j_0$**：若某方案保留了 $j_0$ 之后的、与 $i$ 相交的区间 $x$，那么 $s_x\ge s_{j_0}$、$e_x\le e_i$，且 $j_0$ 与 $i$ 相交意味着 $[s_{j_0},e_{j_0}]\cup[s_i,e_i]$ 是连续的一段，它包含 $[s_x,e_x]$——所以这些区间删掉也不损失覆盖。于是可以认为 $j_0$ 之后到 $i$ 之间（除 $i$ 外）全部开除，再用 $f(j_0,\cdot)$ 处理前 $j_0$ 个：$f\big(j_0,\max(0,r-(i-j_0-1))\big)+(e_i-e_{j_0})$。
3. **与 $i$ 相交的区间一个都不保留**：保留下来的区间全部落在前 $j_0-1$ 个里，它们与 $i$ 不相交（右端点都小于 $s_i$），贡献可以直接相加。记 $P(x,s)$ 为“在前 $x$ 个区间里至少开除 $s$ 个”的最大覆盖（不要求保留第 $x$ 个），则这一类是 $P\big(j_0-1,\max(0,r-(i-j_0))\big)+(e_i-s_i)$。$P$ 有简单递推 $P(x,s)=\max\big(f(x,s),\,P(x-1,s-1)\big)$：要么保留第 $x$ 个，要么开除第 $x$ 个（它占掉一个开除名额）。

三种情况覆盖了所有可能：保留 $i$ 的方案里，若与 $i$ 相交的区间一个都没保留就是情况 3，否则取最左边的那个相交区间，套用上面的“删掉后面相交区间”论证就归到情况 2，而一个都没保留就是情况 1。

**实现细节：** $e$ 单调递增，所以 $j_0$ 随着 $i$ 增大只会右移，用双指针维护；$P$ 只需要 $P(j_0-1,\cdot)$ 这一行，随 $j_0$ 前进时用上面的递推式就地（从大到小枚举 $s$）更新即可。最后枚举“最后一个被保留的区间”$i$：它后面 $M-i$ 个区间全部开除，前面至少还要开除 $\max(0,\text{need}-(M-i))$ 个，其中 $\text{need}=\max(0,K-\text{第二步开除的个数})$；答案取这些 $f(i,\cdot)$ 与 $0$（一个区间都不留）的最大值。

## 复杂度

排序 $O(N\log N)$；DP 状态数 $O(MK)=O(NK)$，每个状态 $O(1)$ 转移，双指针与 $P$ 的推进总代价 $O(MK)$。总时间 $O(N\log N+NK)$，空间 $O(NK)$。
