# P2　逃亡的奶牛（Cow at Large）

## 题目

走投无路的贝茜终于躲进了偏僻的农场。农场由 $N$ 个谷仓（$2\le N\le 7\cdot 10^4$）和 $N-1$ 条双向隧道组成，任意两个谷仓之间恰有一条路径，也就是一棵树。只连出一条隧道的谷仓就是**出口**。

天亮时，贝茜会在某个谷仓冒头，然后试图跑到出口。她一冒头，农夫们就知道了她的位置，于是各自从某些出口出发去抓她。农夫和贝茜速度相同（每单位时间可以沿一条隧道走到相邻谷仓），双方始终都知道对方的位置。只要农夫在**任意时刻**和贝茜处在同一个谷仓、或者正穿过同一条隧道，贝茜就算被抓到；反之，如果贝茜**严格早于**任何农夫到达出口谷仓，她就逃掉了。

贝茜不确定该从哪个谷仓冒头。对每个谷仓，请算出：如果她从那里冒头，并且农夫们可以在各出口之间最优分配，最少需要多少农夫才能抓到她。

## 输入

第一行一个整数 $N$。

接下来 $N-1$ 行，每行两个整数（$1\ldots N$），描述一条隧道连接的两个谷仓。

## 输出

输出 $N$ 行，第 $i$ 行表示贝茜从第 $i$ 个谷仓冒头时最少需要的农夫数。

## 样例

输入：

```text
7
1 2
1 3
3 4
3 5
4 6
5 7
```

输出：

```text
3
1
3
3
3
1
1
```

## 思路

记 $L(v)$ 为谷仓 $v$ 到最近出口的距离（多源 BFS / 两次树形 DP 都可以求）。对某个固定的起点 $u$，把树以 $u$ 为根，那么：

- 若 $v$ 满足 $L(v)\le \operatorname{dist}(u,v)$，说明某个农夫能**不晚于**贝茜到达 $v$，这类点组成集合 $S_u$；
- $S_u$ 的连通块恰好是若干棵完整的子树，每棵子树需要且只需要一个农夫去“封口”，所以需要的农夫数就是 $S_u$ 的连通块个数。

**怎么把连通块个数变成好求和的形式？** 对任意一棵“只通过一条边与外界相连”的子树，内部有 $k$ 个点时，度数和为 $2k-1$（内部边算两次、出去的那条边算一次），于是

$$\sum_{v\in\text{子树}}(2-\deg v)=2k-(2k-1)=1 .$$

所以对非出口的 $u$：$S_u$ 的连通块个数 $=\sum_{v\in S_u}(2-\deg v)$。又因为整棵树满足 $\sum_v(2-\deg v)=2N-2(N-1)=2$，于是

$$\text{答案}(u)=2-\sum_{v:\ \operatorname{dist}(u,v)<L(v)}(2-\deg v),\qquad \deg u\ge 2 .$$

（$u$ 本身是出口时答案固定为 1，这也和 $S_u$ 恰好是整棵树、连通块只有 1 个相符。）

**问题转化成：给每个点 $v$ 赋权 $w(v)=2-\deg v$，对每个 $u$ 求“与 $u$ 距离不超过 $L(v)-1$ 的所有 $v$ 的权值和”。** 这是树上经典的“球加、点查”，用**点分治**做：对每个点 $v$，沿它的重心祖先链，在每个重心 $C$ 处把 $w(v)$ 记到“阈值 $L(v)-1-\operatorname{dist}(v,C)$”上；查询 $u$ 时就累加 $u$ 的每个重心祖先 $C$ 处“阈值 $\ge\operatorname{dist}(u,C)$”的权值和，再减去与 $u$ 处在同一个儿子子树里的那部分（那部分的路径不经过 $C$，要留给下一层递归）。

实现上不必用树套树：在每一层，重心 $C$ 固定后，先把它的整个连通块 BFS 一遍，按 key $=L(v)-1-\operatorname{dist}(v,C)$ 把权值打进桶里做**后缀和**（key 一定落在 $[0,N]$，负数直接忽略），这样对块内每个点 $x$ 就得到 $O(1)$ 的“块内全部点”的贡献；再对 $C$ 的每个儿子子树单独做一次同样的桶统计并从这些点里减掉。每层的工作量与连通块大小成正比，总复杂度 $O(N\log N)$。

## 复杂度

求 $L$ 是 $O(N)$；点分治共 $O(\log N)$ 层，每层总工作量与当前连通块大小成正比，总时间 $O(N\log N)$，空间 $O(N)$。
