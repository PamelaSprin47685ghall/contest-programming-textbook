# P2　新牛棚（New Barns）

## 题目

FJ 发现奶牛挤得太近会吵架，于是想新建一批牛棚把它们分散开。

每当 FJ 建一座新牛棚，他最多用一条双向小路把它和一座已有的牛棚连起来。为了确认奶牛之间是否够分散，他有时想知道：从某座牛棚出发，能走到的**最远**牛棚有多远（两座牛棚的距离是它们之间要走过的小路条数）。

FJ 会给出 $Q$ 条指令（$1 \le Q \le 10^5$），每条要么是"建棚"，要么是"询问距离"。建棚指令会新建一座牛棚并与至多一座已有牛棚相连；询问指令保证问的牛棚已经建好。

## 输入

第一行一个整数 `Q`。

接下来 `Q` 行，每行形如 `B p` 或 `Q k`：`B p` 表示新建一座牛棚并与牛棚 `p` 相连，若 `p = -1` 则不连任何牛棚；`Q k` 表示询问牛棚 `k` 能走到的最远距离。牛棚从 1 开始编号，第 $i$ 次建棚得到的牛棚编号就是 $i$。

## 输出

对每条 `Q` 指令输出一行：该牛棚到最远牛棚的距离。没有任何连接的孤立牛棚，最远距离是 0。

## 样例

输入：

```text
7
B -1
Q 1
B 1
B 2
Q 3
B 2
Q 2
```

输出：

```text
0
2
1
```

解释：依次建出 1、2、3、4 号牛棚，小路是 $2-1$、$3-2$、$4-2$。第一次询问时 1 号牛棚孤立，答案是 0；第二次询问时最远的是 1 号，距离 2；第三次询问时 2 号到 1、3、4 的距离都是 1，答案是 1。

## 思路

虽然牛棚是一边输入一边建的，但整棵森林的**最终形状**在读完输入后就完全确定了（每条建棚指令只给新牛棚接了一个父亲）。于是把"活着的牛棚"看成"已经激活的点"，先离线地把最终森林搭出来。

要紧的是：若按建棚顺序编号，新牛棚连到的旧牛棚编号一定更小，所以同一棵树里，父牛棚总是先建。于是

- 每次询问时，一棵树里"已建的牛棚"恰好是编号不超过当前已建总数的那些；
- 这些点在最终树里**连成一片**（每个点的父亲都已建好），而且两点之间在"已建部分"里的路径就是它们在最终树里的路径；
- 每棵树里用最早建的那座牛棚当"树根"，一座棚属于哪棵树在建棚时就能记录下来。

所以只要知道每棵树当前已建部分的**直径两端**，询问就解决了：树上离任意一点最远的点，一定是直径的某一端。这个经典结论保证了答案就是"该点到两个端点的距离中较大的那个"。

直径也被边建边维护。往树里接一片新叶子 $v$ 时，新的直径只可能是三者之一：原直径、$v$ 连到原直径端点 $U$、$v$ 连到原直径端点 $V$——因为离新叶子最远的点必是原直径的某一端。比较这三个长度取最大即可。

两点距离用**最近公共祖先**算：$dist(u,v)=depth_u+depth_v-2\cdot depth_{lca}$。倍增表 $jumpUp[v][j]$ 表示 $v$ 向上跳 $2^j$ 步到达的牛棚，先把较深的一点提到同深度，再一起从小步到大步往上跳，停在最近公共祖先的两个不同儿子上。

几个细节：

1. 独立建棚时父亲记作虚拟点 0，它的深度更小，倍增表自然会停在 0 上，不影响其它树；
2. 直径两端与长度的数组用"树的代表牛棚"作下标，所以只对被问到的那棵树读写；
3. 新叶子的候选距离等于原直径长度时，保留原来的端点即可——旧端点仍是新树的一组直径端点。

## 复杂度

读入、建表、维护直径与询问都是 $O(Q)$ 次 $O(\log Q)$ 的操作。总时间 $O(Q\log Q)$，空间 $O(Q\log Q)$。
