# P1　失序（Out of Sorts）

## 题目

Bessie 把"冒泡排序"和"快速排序"记混了，实现了一版奇怪的混合排序。她管数组 $A$ 中"元素 $i$ 与 $i+1$ 之间"的位置叫**划分点**，当且仅当

$$A[0..i] \text{ 的最大值} \le A[i+1..N-1] \text{ 的最小值}.$$

她的做法是：先对整段数组反复做冒泡排序的一趟扫描，直到数组里出现划分点为止；每做一趟扫描就把当前段的长度累加进 `work_counter`（她把主循环的每次迭代看成线性时间）；然后按所有划分点把数组切开，对每一段递归重复上述过程。用伪代码描述就是

```text
quickish_sort(A) {
    if (A 的长度 = 1) return
    do {                    // 主循环，至少执行一次
        work_counter += A 的长度
        bubble_sort_pass(A) // 一趟冒泡：从前往后，相邻逆序就交换
    } while (A 中没有划分点)
    在所有划分点处切分 A，对每一段递归 quickish_sort
}
```

注意主循环是 `do-while`：即使一开始就到处是划分点，也要先白做一趟。

给定数组 $A$（$1 \le N \le 10^5$，$0 \le A_i \le 10^9$，元素**不保证互不相同**），预测算法结束时 `work_counter` 的值。

## 输入

第一行一个整数 `N`。

接下来 `N` 行，每行一个整数，依次是 $A[0], A[1], \dots, A[N-1]$。

## 输出

一个整数：`work_counter` 的最终值。

## 样例

输入：

```text
7
20
2
3
4
9
8
7
```

输出：

```text
12
```

解释：初始数组是 20 2 3 4 9 8 7。做一趟冒泡（记账 7）后变成

```text
2 | 3 | 4 | 9 8 7 | 20
```

`|` 处都是划分点，于是切成若干段：`2`、`3`、`4`、`9 8 7`、`20`。前四个长度为 1 的段直接返回，只有 `9 8 7` 这一段的长度大于 1：对它再做一趟主循环（记账 3）得到 `8 7 | 9`，出现划分点后切成 `8 7` 和 `9`；`8 7` 再做一趟（记账 2）完成后有序。总计 $7+3+2=12$。

## 思路

先想办法不真的模拟递归。若把若干已经互相分开的段放在一起、各做一趟冒泡扫描，与对整段数组做一趟冒泡相比：元素不会跨段移动，比较与交换的模式逐段相同，总长度也恰好是各段长度之和，所以**效果和记账完全相同**——唯一的区别是长度 1 的段会直接返回、不贡献长度。

于是可以把整个过程压平成一句话：每个元素从第一趟扫描起，每趟贡献 1，直到它**左右两条缝都变成划分点**为止（这时它单独成段，不再被计入任何大于 1 的段）。所以只要分别求出每条缝最晚在第几趟成为划分点，这个元素的贡献就是左右两条缝的较大值。

接下来数缝。设某条缝 $i$（前 $i$ 个位置与后 $n-i$ 个位置之间，$1 \le i \le n-1$）要成立，需要"前 $i$ 小的元素"恰好都落在前 $i$ 个位置上。值可能有重复，取"按值排序、值相同按下标排"的前 $i$ 个作为一组合法的"前 $i$ 小"。设这组元素里原始下标的**最大值**为 $mx$：这个元素必须向左挪 $mx-(i-1)$ 格，而一趟冒泡里每个元素最多左移一格，所以至少要 $mx+1-i$ 趟；另一方面，经过 $mx+1-i$ 趟后它已进入前 $i$ 个位置，缝 $i$ 一定已经成立。因此

$$\texttt{needPass}[i] = mx_i + 1 - i .$$

把所有下标按 $(\text{值}, \text{下标})$ 排序，前缀最大值一边扫一边维护，就能在 $O(N\log N)$ 内算出所有 `needPass`。

最后，元素 $i$ 的贡献是它左右两条缝 `needPass` 的较大值（越界的那侧按 0 算）；`do-while` 保证主循环至少跑一趟，所以**一开始就被两侧隔开的元素**（$N>1$ 时该值为 0）也要按 1 记账；$N=1$ 时 `quickish_sort` 直接返回，答案为 0。

两个细节：

1. 排序时值相同必须按原始下标排——否则"前 $i$ 小"里会混进本来可以由更靠前的相同值顶替的元素，`mx` 不再是那组元素的正确最大值；
2. 逆序数组的答案在 $N=10^5$ 时约为 $N^2/2 \approx 5\times10^9$，超过 `int`，累加要用 `long long`。
