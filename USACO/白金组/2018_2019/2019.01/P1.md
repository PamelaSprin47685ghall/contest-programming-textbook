# P1　选区重划（Redistricting）

## 题目

Bovinopolis 由一排 $N$ 个牧场组成（$1 \le N \le 3 \cdot 10^5$），每个牧场里恰好有一头牛，品种是 Holstein（记作 `H`）或 Guernsey（记作 `G`）。

政府要把这一排牧场划分成若干连续的选区，每个选区最多包含 $K$ 个牧场（$1 \le K \le N$），每个牧场恰好属于一个选区。Holstein 占多数的政府想让"Guernsey 占多数或者双方平局"的选区尽可能少（平局指选区里两种牛的个数相同）。请求出这个最少数量。

## 输入

第一行包含两个用空格隔开的整数 `N K`。

第二行是一个长度为 $N$ 的字符串，每个字符是 `H` 或 `G`，依次表示每个牧场里牛的品种。

## 输出

一个整数：最少有多少个选区是"Guernsey 占多数或双方平局"。

## 样例

输入：

```text
7 2
HGHGGHG
```

输出：

```text
3
```

解释：可以划分为 `HG|HG|GH|G`：前两个选区里两种牛各有一头（平局），最后一个选区只有一头 Guernsey，一共 3 个；中间的 `GH` 是 Holstein 占多数，不计入答案。答案不可能是 2：不计入答案的选区必须 Holstein 占多数，而字符串里没有相邻的 `H`，所以这样的选区只能是单个 `H`，最多 3 个。7 个牧场每区最多 2 个，所以至少要有 4 个选区；若选区数为 4，只有 2 个计入答案时另外 2 个选区要装下 5 个牧场，装不下；若选区数为 5，3 个单个 `H` 把剩下 4 个 `G` 隔成 3 段，仍要占 3 个选区，计入答案的选区同样是 3 个；选区数更多时只会更多。所以最少是 3。

## 思路

设 `dp[j]` 表示前 $j$ 个牧场的最少代价，则 `dp[0] = 0`，并且

$$dp[j] = \min_{\max(0, j-K) \le i \le j-1}\big(dp[i] + cost(i, j)\big)$$

其中 $cost(i, j)$ 表示把区间 $[i, j)$ 单独划成一个选区时它是否"Guernsey 占多数或平局"（是则 1，否则 0）。直接按这个式子做是 $O(NK)$，需要优化。

用前缀差判断区间的归属：令 `balance[i]` 为前 $i$ 个牧场中 `H` 比 `G` 多的个数。区间 $[i, j)$ 中 `G` 的个数不少于 `H`，等价于 `balance[j] - balance[i] <= 0`，也就是 `balance[i] >= balance[j]`；反过来，$cost(i, j) = 0$ 等价于 `balance[i] < balance[j]`。这样每个 $cost$ 都能 $O(1)$ 算出。

注意到 $cost$ 只能取 0 或 1，所以若记窗口内 `dp` 的最小值为 $m$，则 $dp[j]$ 只可能是 $m$ 或 $m + 1$：

- 窗口里任意一个 $i$ 都给出 $dp[i] + cost(i, j) \le m + 1$，所以 $dp[j] \le m + 1$；
- 而 $dp[j] \ge m$，所以只有两种可能。

想要取到下界 $m$，就必须存在一个 $i$ 同时满足 `dp[i] == m` 和 $cost(i, j) == 0$，也就是 `balance[i] < balance[j]`。于是只要知道"窗口内 `dp` 值等于 $m$ 的那些 $i$ 中，最小的 `balance[i]` 是多少"：

- 若这个最小值小于 `balance[j]`，就取 $dp[j] = m$；
- 否则窗口内所有 `dp[i] == m` 的 $i$ 都给出代价 1，只能取 $dp[j] = m + 1$。

把窗口内所有 `(dp[i], balance[i])` 存进一个按字典序排序的 `multiset`，首元素恰好给出"最小的 `dp` 值，以及这个 `dp` 值下最小的 `balance`"，正是需要的信息。窗口滑动时先插入 `(dp[j], balance[j])`，若 $j \ge K$ 再把下标 $j - K$ 的那一项删掉（选区长度不超过 $K$，所以 $i$ 最小只能到 $j - K$）。答案就是 `dp[N]`。

## 复杂度

每个下标做 $O(1)$ 次 `multiset` 操作，每次 $O(\log N)$，所以时间 $O(N \log N)$；数组与窗口各存 $O(N)$ 个元素，空间 $O(N)$。
