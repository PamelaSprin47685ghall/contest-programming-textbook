# P3　追踪火车 2（Train Tracking 2）

## 题目

每天都有特快列车经过农场。列车有 $N$ 节车厢（$1 \le N \le 10^5$），每节车厢贴着一个 $1$ 到 $10^9$ 之间的正整数标签，不同车厢的标签可以相同。

今天雾太大，Bessie 看不清任何一节车厢的标签，但她从可靠渠道拿到了窗口长度为 $K$ 的滑动窗口最小值：$N-K+1$ 个正整数 $c_1, \dots, c_{N+1-K}$，其中 $c_i$ 是第 $i, i+1, \dots, i+K-1$ 节车厢标签的最小值。请求出与这些滑动窗口最小值一致的标签方案数，对 $10^9 + 7$ 取模。输入保证至少存在一种方案。

## 输入

第一行包含两个用空格隔开的整数 `N K`。

接下来 $N-K+1$ 行，每行一个整数，依次是 $c_1, \dots, c_{N+1-K}$。

## 输出

一个整数：给每节车厢分配一个不超过 $10^9$ 的正整数、使得第 $i$ 到第 $i+K-1$ 节车厢的最小值恰为 $c_i$ 的方案数，对 $10^9+7$ 取模。

## 样例

输入：

```text
4 2
999999998
999999999
999999998
```

输出：

```text
3
```

解释：$c_1 < c_2$ 迫使第 1 节车厢等于 $999999998$，$c_2 > c_3$ 迫使第 4 节车厢等于 $999999998$。第 2、3 节车厢都必须不小于 $999999999$，且其中至少有一个等于 $999999999$（否则第二个窗口的最小值就变成 $10^9$），共有 $3$ 种：$(999999999, 999999999)$、$(999999999, 10^9)$、$(10^9, 999999999)$。

## 思路

**第一步：从窗口最小值反推出被定死的车厢。** 如果相邻两个窗口最小值不同，就能立刻确定某节车厢的标签。

- 若 $c_i < c_{i+1}$：因为 $c_i = \min(a_i, \min(a_{i+1}, \dots, a_{i+K-1}))$，而 $\min(a_{i+1}, \dots, a_{i+K-1}) \ge c_{i+1} > c_i$，所以只能是 $a_i = c_i$。
- 若 $c_i > c_{i+1}$：同理 $c_{i+1}$ 只能由新进入窗口的第 $i+K$ 节车厢提供，即 $a_{i+K} = c_{i+1}$。

**第二步：把序列切成互不影响的段。** 把 $c$ 压缩成"连续相同取值"的段（run）。上面的规则说明：每一处相邻段取值的变化都会定死一节车厢，这些被定死的车厢把整条车厢序列切成若干段，每段对应一个 run。段内的元素只需不小于该 run 的取值，并且段内每个完整窗口的最小值恰好等于它；不同段之间没有共同约束，所以答案是各段方案数之积。

直观上，这些定死车厢的位置是可以算出来的：在 $c$ 的相邻两段之间，如果取值是**上升**的（$c_i < c_{i+1}$），被定死的是第 $i$ 节车厢；如果是**下降**的（$c_i > c_{i+1}$），被定死的是第 $i + K$ 节车厢。于是每段的长度就是夹着它的两个定死位置之间的距离（首段从第 1 节开始算，末段算到第 $N$ 节为止）。记 run 长度为 $L$，逐种情况写出就是：

- 中间段，左右两侧的变化方向相同时（取值一路上升，或者一路下降，即"单调穿过"）：段长 $L - 1$；
- 中间段，run 是局部最大（前后两段取值都比它小）：段长 $L + K - 1$；
- 中间段，run 是局部最小（前后两段取值都比它大）：段长 $\max(0, L - K - 1)$，两侧的定死车厢有时会重合，此时段长为 0；
- 首段（左侧没有相邻 run，从第 1 节车厢开始）：右侧取值上升时段长 $L - 1$，下降时段长 $L + K - 1$；
- 末段（右侧没有相邻 run，算到第 $N$ 节车厢为止）：左侧取值下降时段长 $L - 1$，上升时段长 $L + K - 1$。

**第三步：数出一段有多少种填法。** 记 $f(v, K, \text{len})$ 为长度 $\text{len}$、每个元素都不小于 $v$、且每个长度为 $K$ 的窗口最小值恰好为 $v$ 的序列数，并记 $x = 10^9 - v$（严格大于 $v$ 的取值个数）。

- 若 $\text{len} < K$，段内没有完整窗口，只需每个元素不小于 $v$，方案数 $(x+1)^{\text{len}}$。
- 否则，设 $\text{seqDp}[u]$ 为长度 $u$、每个窗口最小值都是 $v$、且**末尾元素恰好等于 $v$** 的序列数。按"最后一个等于 $v$ 的位置距离末尾多远"分类：若距离为 $d$（$1 \le d \le K$），则末尾 $d-1$ 个元素都严格大于 $v$（$x^{d-1}$ 种），前面长度为 $u-d$ 的部分仍要满足同样条件且末尾为 $v$，于是

$$\text{seqDp}[u] = \sum_{d=1}^{K} x^{d-1} \cdot \text{seqDp}[u-d]$$

  直接按这个式子算是 $O(NK)$。把 $u$ 换成 $u+1$ 后与自身相减，中间项全部抵消，得到只含三项的线性递推：

$$\text{seqDp}[u+1] = \text{seqDp}[u] + x\big(\text{seqDp}[u] - x^{K-1}\text{seqDp}[u-K]\big)$$

  初值 $\text{seqDp}[0] = \text{seqDp}[1] = 1$，且 $u \le K$ 时 $\text{seqDp}[u] = (x+1)^{u-1}$。
- 段长 $\text{len} \ge K$ 时的答案是 $\text{seqDp}[\text{len}+1]$：在长度 $\text{len}$ 的合法段末尾补一节标签为 $v$ 的车厢，就与"长度 $\text{len}+1$、末尾为 $v$"的序列一一对应（补上去的那节车厢只会让最后一个窗口也含有 $v$）。

$x^{K-1}$ 用一次快速幂求出即可，各段递推的总长度不超过 $N$。

## 复杂度

压缩取值段与各段递推合计 $O(N)$，另外每段用一次快速幂求 $x^{K-1}$，共 $O(R \log K)$（$R$ 是连续相同取值的段数，$R \le N$）。总时间 $O(N + R\log K)$，空间 $O(N)$。
