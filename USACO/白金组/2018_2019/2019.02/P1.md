# P1　奶牛约会（Cow Dating）

## 题目

Bessie 拿到了一份 $N$ 头公牛的名单，第 $i$ 头公牛接受舞会邀请的概率是 $p_i$（$0 < p_i < 1$）。她会给名单上一个**连续区间**内的每头公牛都发一封邀请，希望恰好有一头公牛接受。求这个概率的最大值。

## 输入

第一行一个整数 $N$（$1 \le N \le 10^6$）。

接下来 $N$ 行，每行一个整数，是 $10^6$ 倍的 $p_i$。

## 输出

一个整数：$10^6$ 倍的最大概率向下取整。

## 样例

输入：

```text
3
300000
400000
350000
```

输出：

```text
470000
```

解释：选择第 2 到第 3 头公牛，恰好一头接受的来源是"2 接受 3 拒绝"或"2 拒绝 3 接受"，概率为 $0.4 \times 0.65 + 0.6 \times 0.35 = 0.47$。

## 思路

记区间 $[l, r]$ 恰好一封接受的概率为

$$P\sum_{l \le i \le r}\frac{p_i}{1-p_i},\qquad P=\prod_{l\le j\le r}(1-p_j).$$

这是把"恰好一封"按是哪一封展开：$p_i\prod_{j\ne i}(1-p_j)$，再提出公因子 $P$ 得到的。于是记 `prod` $=P$、`sum` $=\sum p_i/(1-p_i)$，区间概率就是两者之积。

关键结论：**往区间的一端加进概率 $p'$ 后概率变大，当且仅当加之前的 $sum < 1$**。把新区间的概率 $P(1-p')\big(\tfrac{p'}{1-p'}+sum\big)$ 与原概率 $P\cdot sum$ 相比，两边约掉 $P$ 后等价于
$$p'+(1-p')sum > sum \iff p'(1-sum) > 0 \iff sum < 1 .$$
每个 $p_i/(1-p_i)$ 都是正数，扩展只会让 `sum` 变大，所以对固定的左端点 $l$，概率随右端点先增后减，最优右端点就是**第一个使 `sum ≥ 1` 的位置**（或右端到底）。这正是双指针：右指针一直往右推，直到 `sum ≥ 1`；此时算一次答案，再把左端点右移一格考察下一个 $l$。

双指针的正确性来自 $p_i > 0$ 带来的单调性：$l$ 变大时，区间里少一个正数，能让 `sum` 重新回到 $1$ 以下的右端点不会比之前更靠左，因此右指针无需回退，总复杂度 $O(N)$。

实现上用一个 `double` 的 `prod` 和 `sum` 逐步加减即可（注意不能用 `float`，精度不够）。一次扩展/收缩的误差量级约为 $10^{-16}$ 乘以量级，但"$10^6$ 倍后向下取整"可能恰好落在整数边界上（例如最优区间只含一头公牛时，真值就是整数 $10^6 p_i$），因此输出时先加一点点 $\varepsilon$ 再取整，避免浮点误差把整数答案压成少 1。
