# P2　山羊卡丁车（Moorio Kart）

## 题目

农场由 $N$ 块草地和 $M$ 条双向道路组成，第 $i$ 条道路连接 $A_i, B_i$，长 $D_i$。道路之间没有环，所以整张图是一片森林：把"至少两块草地、内部任意两块草地之间恰有一条道路链"的草地集合叫作一个**农场**，森林里每棵树就是一个农场。设农场数为 $K$。

Bessie 要修一条赛道：在 $K$ 个农场之间新增 $K$ 条长度为 $X$ 的道路，把所有农场串成一个环；每个农场恰好被访问一次，并且在每个农场内部至少要走一条路。赛道长度就是所用道路的长度之和。

两条赛道不同，当且仅当选取的道路集合（含新增道路的端点）不同。

求所有**长度至少为 $Y$** 的赛道的长度之和，模 $10^9+7$。

## 输入

第一行四个整数 $N, M, X, Y$（$1 \le N \le 1500$，$1 \le M \le N-1$，$0 \le X, Y \le 2500$）。

接下来 $M$ 行，每行三个整数 $A_i, B_i, D_i$（$1 \le A_i, B_i \le N$，$0 \le D_i \le 2500$），表示一条长 $D_i$ 的道路。保证无环，且每块草地至少和一条道路相连。

## 输出

一个整数：所有长度至少为 $Y$ 的赛道的长度之和模 $10^9+7$。

## 样例

输入：

```text
5 3 1 12
1 2 3
2 3 4
4 5 6
```

输出：

```text
54
```

解释：图分成两个农场——$\{1,2,3\}$（内部路径长度 $3,4,7$）和 $\{4,5\}$（内部路径长度 $6$）。$K=2$，每条赛道总长为"两条内部路径长度之和 $+\,2X$"，三种取法分别得到 $11$、$12$、$15$。只有 $12$ 与 $15$ 达标，各对应 $2$ 条赛道（顺序与端点接法不同），故答案为 $12+12+15+15=54$。

## 思路

**模型。** 森林的每棵树就是一个农场，"每个农场内部至少走一条路、且每个农场只走一次"意味着：在每个农场里选一条**路径**（树内两点路径唯一，至少含一条边），再按某个顺序用 $K$ 条长 $X$ 的新路把它们首尾相接成一个环。于是总长度 $=KX+\sum(\text{各农场内选中的路径长度})$，我们只需要把所有满足"总长度 $\ge Y$"的组合的长度和求出来。

**每个农场的路径信息。** 一棵大小为 $s$ 的树里，任意两块草地之间的路径唯一，从每个点出发各做一遍 DFS 就能得到全部 $s(s-1)/2$ 个**无序**点对的距离（只记录编号较大的那端，保证每个点对只被记一次），所有农场合计 $O(N^2)$。接着按长度分桶：长度 $<Y$ 的记在对应下标上；长度 $\ge Y$ 的路径全部并进关键字 $Y$ 这一桶。之所以能并桶，是因为**一旦总长度已经 $\ge Y$，之后再叠加任何非负长度，"是否达标"这件事都不会改变**，这些路径在"是否达标"上完全等价；但答案要的是长度之和，所以桶里除条数 `cnt` 之外还要存这些路径的**真实长度之和** `sum`。

**合并（计数与长度和的卷积）。** 用一个下标封顶在 $Y$ 的 DP 表示"已经处理过的农场里各选一条路径"的汇总信息：`res[j] = (cnt, sum)` 表示封顶总长度为 $j$ 的选法有 `cnt` 种、它们的真实总长度之和为 `sum`，其中下标 $Y$ 表示"长度 $\ge Y$"。初始只有 $K$ 条连接路：`res[min(KX, Y)] = (1, KX)`——注意即使下标被压到 $Y$，`sum` 里记的仍是真实的 $KX$，这一点是后面答案正确的前提。

合并两条汇总信息 $A=(\text{cntA},\text{sumA})$ 与 $B=(\text{cntB},\text{sumB})$（后者是某棵树的一个长度桶）时：方案数相乘 $\text{cntA}\cdot\text{cntB}$；而所有配对的长度和是 $\sum_{a,b}(a+b)=\text{sumA}\cdot\text{cntB}+\text{cntA}\cdot\text{sumB}$。这就是把"求和的分配律"拆开后得到的卷积形式，$(\text{cnt},\text{sum})$ 在它下面封闭，因此只需存这两个量（都按模 $10^9+7$ 运算）就足够。把每个农场的每个长度桶都这样并进去，新下标取 $\min(j+k,Y)$；由于封顶后的 `sum` 保存真实长度，最终 `res[Y].sum` 恰好就是所有"总长度 $\ge Y$"选法的长度和，不需要额外信息。

合并时内层只遍历"当前存在方案的下标"（用一张可达下标表维护），外层只遍历该树真实出现过的长度桶，避免对每个 $j$ 都从 $0$ 扫到 $Y$；每轮结束需要清空新用的下标，用"时间戳"（`seenToken`）做惰性清零即可。若最终 `res[Y]` 一个方案也没有（例如 $K=1$ 且所有路径加上 $X$ 仍不到 $Y$），答案按 $0$ 输出。

**赛道计数。** 上面求和的是"每农场一条路径"的组合，还没算这些路径能拼成几条不同的赛道。给定 $K$ 条路径，一种拼法是：把这 $K$ 个农场排成一个线性顺序（$K!$ 种），再为每个农场指定它的路径哪一端接前一条新路、哪一端接后一条新路（$2^K$ 种），共 $K!\cdot 2^K$ 种"带标号的拼法"。每条真实赛道恰好被这样数了 $2K$ 次：可以任选 $K$ 个农场之一作为起点，还可以沿环的两个方向之一走。反过来，从赛道的道路集合能唯一还原出每个农场内选的是哪条路径（路径的边集在树里唯一确定一条路径），也能还原环上的顺序与各端点的接法，所以这个 $2K$ 倍的重复是均匀的。于是赛道条数 $=\dfrac{K!\cdot 2^K}{2K}=(K-1)!\cdot 2^{K-1}$，答案就是 $\text{res}[Y].\text{sum}\times (K-1)!\times 2^{K-1}$。$K=1$ 时因子为 $1$，此时 $KX=X$ 也要计入，与公式一致，无需特判。

## 复杂度

枚举点对时间 $O(N^2)$。合并的代价是 $O(Y\cdot S)$，其中 $S$ 为各农场"封顶后不同路径长度个数"之和：一棵大小为 $s$ 的树最多贡献 $\min\big(s(s-1)/2,\ Y+1\big)$ 个桶，在 $s\approx\sqrt Y$ 时 $S$ 最大，约为 $O(N\sqrt Y)$，故最坏时间 $O(N^2+NY^{1.5})$；可达下标数不超过 $Y+1$，内层循环因此有界。空间上，点对距离表在最坏情况（一整棵树）要存 $O(N^2)$ 个距离，加上 $O(Y)$ 的 DP 数组和 $O(N+M)$ 的图，总空间 $O(N^2+Y)$。
