# P1　树形箱子（Tree Boxes）

## 题目

农夫约翰要建 $N$ 个农场（$N \le 10^5$），用 $N-1$ 条路连成一棵树。他不满足于只被告知"出问题的农场在 $A$ 到 $B$ 的路径上"，而希望被告知一个**轴对齐矩形**（的农场集合）。Bessie 告诉他最多用**两个**矩形：两矩形的农场集合交集为空、并集恰好是路径上所有农场。请你决定农场该建在哪些 2D 点上，使得任何路径都能这样用至多两个矩形通知。

**这是一道交互题**（原题在 USACO 上通过交互评测，没有普通输入输出文件）。裁判按下面的顺序调用你的程序：

1. `addRoad(a, b)` 共调用 $N-1$ 次，告知每条路；
2. 调用一次 `buildFarms()`，你必须在其中对每个农场 $v$ 调用 `setFarmLocation(v, x, y)` 定下位置（$1 \le x, y \le N$，各农场坐标互不相同）；
3. 调用 $Q$ 次 `notifyFJ(a, b)`（$1 \le Q \le 10^5$），每次你调用 1 或 2 次 `addBox(X1, Y1, X2, Y2)`（$1 \le X1 \le X2 \le N$，$1 \le Y1 \le Y2 \le N$）。

每次 `notifyFJ(a, b)` 结束后，裁判取所有已加入的矩形，检查它们覆盖的农场集合**互不相交且并集恰好是树上 $a$ 到 $b$ 的路径**。

函数原型：

```text
int getN();                              // 农场数
int getQ();                              // 询问次数
void setFarmLocation(int ID, int X, int Y);   // 只能在 buildFarms 里调用
void addBox(int X1, int Y1, int X2, int Y2);  // 只能在 notifyFJ 里调用
```

## 输入

没有标准输入；输入由交互协议给出：先是 $N-1$ 次 `addRoad`，再调用 `buildFarms()`，随后 $Q$ 次 `notifyFJ(a, b)`，其中 $0 \le a, b \le N-1$。

## 输出

没有标准输出；$N$ 次 `setFarmLocation` 定下各农场坐标，每次 `notifyFJ` 里 1 到 2 次 `addBox` 给出覆盖路径的两个矩形。

## 样例

题目给出的样例交互（树的边为 $0-1$、$1-2$，$Q = 2$）：

输入（裁判的调用序列）：

```text
addRoad(0, 1)
addRoad(1, 2)
buildFarms()
notifyFJ(0, 0)
notifyFJ(0, 2)
```

输出（选手程序的合法回答之一；本解法会把三个农场摆在 $(1,3),(2,3),(3,3)$）：

```text
setFarmLocation(0, 1, 3)
setFarmLocation(1, 2, 3)
setFarmLocation(2, 3, 3)
addBox(1, 3, 1, 3)
addBox(1, 3, 3, 3)
```

第一个询问只覆盖农场 0；第二个询问用矩形 $[1,3] \times \{3\}$ 覆盖全部三个农场，恰是路径 $0 \to 1 \to 2$。

## 思路

**摆放：先序编号 + 子树末号。** 随意定根（解法里取农场 0），做一遍 DFS 求出每个农场 $v$ 的先序编号 $\mathrm{tin}_v$ 与子树里最大的先序编号 $\mathrm{tout}_v$，然后把农场 $v$ 摆在点 $(x,y) = (\mathrm{tin}_v, \mathrm{tout}_v)$。这些点两两不同且都在 $[1,N]^2$ 内。

**关键性质：** 先序区间 $[\mathrm{tin}_v, \mathrm{tout}_v]$ 要么互相包含、要么不相交，且 $u$ 是 $v$ 的祖先 $\iff \mathrm{tin}_u \le \mathrm{tin}_v$ 且 $\mathrm{tout}_u \ge \mathrm{tout}_v$。

于是"某条祖先链截掉一部分"可以写成矩形：

- $v$ 的全体祖先恰是矩形 $\{x \le \mathrm{tin}_v\} \times \{y \ge \mathrm{tout}_v\}$ 里的农场（不满足的就是区间不相交、被 $y$ 的条件筛掉）；
- $b$ 到祖先 $a$ 的链（$a$ 是 $b$ 的祖先）恰是矩形 $\{\mathrm{tin}_a \le x \le \mathrm{tin}_b\} \times \{y \ge \mathrm{tout}_b\}$ 里的农场。这里 $x$ 从 $\mathrm{tin}_a$ 起就天然把链截到 $a$ 为止，不需要再压 $y$ 的上界——注意 $y$ 的上界不能用来截链，因为一条"一路走最后一个孩子"的祖先链上 $\mathrm{tout}$ 会全部相等。

**回答询问。** 设 $l = \mathrm{LCA}(a,b)$，路径由 $a$ 到 $l$、$b$ 到 $l$ 两条链拼成（用倍增法求 LCA，$O(\log N)$）：

- 若 $l = a$（或对称为 $b$）：路径就是一条链，用一个矩形即可：$\{\mathrm{tin}_a \le x \le \mathrm{tin}_b\} \times \{y \ge \mathrm{tout}_b\}$（对称情形把 $a,b$ 互换）。
- 否则用两个矩形：
  $$\text{Box}_1 = [\mathrm{tin}_l, \mathrm{tin}_a] \times [\mathrm{tout}_a, N],\qquad
    \text{Box}_2 = [\mathrm{tin}_l + 1, \mathrm{tin}_b] \times [\mathrm{tout}_b, N].$$
  $\text{Box}_1$ 恰好是 $a$ 到 $l$ 的链；$\text{Box}_2$ 把 $x$ 下界抬到 $\mathrm{tin}_l + 1$，恰好是 $b$ 到 $l$ 的链去掉 $l$。两盒交集为空：落在两个盒里的农场既要 $\mathrm{tin} \le \mathrm{tin}_a$、$\mathrm{tin} \le \mathrm{tin}_b$，又要 $\mathrm{tout} \ge \mathrm{tout}_a$、$\ge \mathrm{tout}_b$，那它就是 $a$ 与 $b$ 的公共祖先；而 $x \ge \mathrm{tin}_l+1$ 又排除了 $l$ 本身，和 $l$ 是最深公共祖先矛盾。

实现细节：树可能退化成 $10^5$ 深的链，DFS 用手写栈；`addRoad` 阶段只把边记下来，`buildFarms` 里再建邻接表、跑 DFS、摆农场、建倍增祖先表（$O(N \log N)$）。

**本地验证方式（本仓库用）**：自建一个 grader——它提供 `getN`/`getQ`/`setFarmLocation`/`addBox` 与 `main`，随机生成树（链、星、随机、偏深随机），按协议调用三个函数，再对每次 `notifyFJ` 独立重建树上路径，逐题检查：1~2 个矩形、矩形坐标合法、矩形内的农场都在路径上、两矩形农场集合不相交、路径上每个农场都被覆盖、各农场坐标互不重复。小树（$n \le 20$）全量校验；另外用 $n = 1000$、$Q = 10^5$（全部逐题校验）与 $n = 10^5$、$Q = 10^5$（抽前 300 条逐题校验）做规模与性能检查。
