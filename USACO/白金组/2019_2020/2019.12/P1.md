# P1　贪吃的奶牛（Greedy Pie Eaters）

## 题目

农夫约翰烤了 $N$ 个派（$1 \le N \le 300$），编号 $1 \ldots N$，另外养着 $M$ 头奶牛。第 $i$ 头奶牛只吃编号落在区间 $[l_i, r_i]$ 内的派，任意两头奶牛对应的区间都不相同，她的体重是整数 $w_i$（$1 \le w_i \le 10^6$）。

约翰可以挑一串奶牛 $c_1, c_2, \ldots, c_K$，让它们按这个顺序轮流吃派。轮到 $c_j$ 时，她会吃光区间 $[l_{c_j}, r_{c_j}]$ 里**剩下的**所有派。约翰不想看到"轮到某头奶牛，她感兴趣的派却已经被吃光"的场面，所以要求序列里每一头奶牛轮到自己时都至少还能吃到一块派。

请求出合法序列的体重总和 $w_{c_1} + w_{c_2} + \cdots + w_{c_K}$ 的最大值。

## 输入

第一行两个整数 `N M`（$1 \le M \le \frac{N(N+1)}{2}$）。

接下来 `M` 行，每行三个整数 `w_i l_i r_i`，描述一头奶牛。

## 输出

一个整数：合法序列的最大总体重。

## 样例

输入：

```text
2 2
100 1 2
100 1 1
```

输出：

```text
200
```

解释：若区间 $[1,2]$ 的奶牛先吃，它会把两块派都吃掉，$[1,1]$ 的奶牛就没得吃了；若 $[1,1]$ 的奶牛先吃走第 1 块派，$[1,2]$ 的奶牛再吃剩下的第 2 块派，两头奶牛都吃到了派，总体重为 $100 + 100 = 200$。

## 思路

**关键观察：盯住序列的最后一头奶牛。** 她既然有派可吃，就至少吃到某一块派，挑她吃到的一块派记作 $i$。在她之前被吃的派都不可能是 $i$（否则 $i$ 早就没了），也就是说前面每一头奶牛的区间都不含 $i$。于是一串奶牛被 $i$ 分成互不相干的两拨：区间落在 $[l, i-1]$ 里的和落在 $[i+1, r]$ 里的。这两拨吃的是不同的派，各自合法就能拼在一起，顺序怎么接都行。

**区间 DP。** 设 $best[l][r]$ 表示只允许使用完整包含在 $[l,r]$ 内的奶牛时，合法序列的最大总体重。按上面的观察写出两类转移：

1. **切两半**：$best[l][r] = \max_{l \le t < r}\left(best[l][t] + best[t+1][r]\right)$。
2. **让某头奶牛收尾**，并指定她吃到的派是 $i$：
   $$best[l][r] = \max_{l \le i \le r}\left(best[l][i-1] + best[i+1][r] + cover[i][l][r]\right),$$
   其中 $cover[i][l][r]$ 是所有"区间完整落在 $[l,r]$ 内、且覆盖派 $i$"的奶牛里体重的最大值。把取到最大值的这头奶牛放到末尾即可：她吃 $i$ 之前，前面的奶牛都没碰过 $i$。若没有这样的奶牛，$cover[i][l][r] = 0$，而体重都是正数，这个转移自然不会生效。

两类转移都只依赖更小的区间，因此按区间长度从小到大递推，答案是 $best[0][N-1]$（下标从 0 开始）。

**$cover$ 怎么算。** 先把每头奶牛 $(w,[l,r])$ 写进 $cover[i][l][r]$（$i$ 取遍 $[l,r]$）。接着注意到区间向外扩只会允许更多奶牛，所以 $cover[i][l][r]$ 可以沿 $l-1$ 与 $r+1$ 两个方向往外扩散。按 $l$ 从大到小、$r$ 从小到大的顺序扫一遍，每格把自己的值推给 $(l-1,r)$ 和 $(l,r+1)$：轮到某格时，它的两个来源 $(l+1,r)$ 与 $(l,r-1)$ 都已经推完，扫完这一遍就得到所有区间上的最值。

## 复杂度

$cover$ 的写入是 $O(MN)$，向外扩散是 $O(N^3)$；区间 DP 的两类转移各是 $O(N)$ 乘上 $O(N^2)$ 个区间，也是 $O(N^3)$。总时间复杂度 $O(N^3)$。空间复杂度 $O(N^3)$：三维表在 $N = 300$ 时约 $2.7 \times 10^7$ 个 `int`，约 103 MB（限制为 256 MB）。
