# P3　树的深度（Tree Depth）

## 题目

为了迎接新年，农夫约翰决定送奶牛们一棵节日二叉搜索树。他先取一个 $1 \ldots N$ 的排列 $a = \{a_1, a_2, \ldots, a_N\}$（$N \le 300$），再按下面的伪代码调用 `generate(1, N)` 生成这棵树：

```text
generate(l, r):
    if l > r, return 空子树;
    x = argmin_{l ≤ i ≤ r} a_i;   // 区间里最小值所在的下标
    return 以 x 为根、generate(l, x-1) 为左子树、generate(x+1, r) 为右子树的 BST;
```

树的节点就用下标 $i$ 标记。$d_i(a)$ 表示节点 $i$ 的深度，即从根到节点 $i$ 路径上的节点个数。排列 $a$ 的逆序数是满足 $i < j$ 且 $a_i > a_j$ 的数对个数。

已知约翰将要使用的排列恰好有 $K$ 个逆序（$0 \le K \le \frac{N(N-1)}{2}$）。对所有满足条件的排列 $a$，请对每个 $1 \le i \le N$ 输出 $\sum_a d_i(a) \bmod M$。其中 $M$ 是 $[10^8, 10^9+9]$ 内的质数。

## 输入

一行三个整数 `N K M`。

## 输出

一行 $N$ 个整数，第 $i$ 个是 $\sum_a d_i(a) \bmod M$。

## 样例

输入：

```text
3 0 192603497
```

输出：

```text
1 2 3
```

解释：$K=0$ 时只有排列 $\{1,2,3\}$，它每次递归的最小值都在最左端，建出的树是一条 $1 \to 2 \to 3$ 的链，三个节点的深度分别是 1、2、3。

## 思路

**第一步：把"深度"换成一对对祖先关系。** 这棵树是按区间最小值递归建出来的，所以用值的大小就能判断祖先：对位置 $i < j$，位置 $j$ 是位置 $i$ 的祖先，当且仅当 $a_j = \min(a_i, \ldots, a_j)$。理由是：区间 $[i,j]$ 的最小值若落在最右端，递归到这一段时 $j$ 就是根，$i$ 落在它的左子树里，$j$ 当然是 $i$ 的祖先；若最小值落在别处，$i$、$j$ 会分到根的两侧，不再有祖先关系。于是

$$d_i(a) = 1 + \#\{j < i : a_j = \min(a_j, \ldots, a_i)\} + \#\{j > i : a_j = \min(a_i, \ldots, a_j)\},$$

括号里的两个条件其实都是"另一个位置是位置 $i$ 的祖先"，只是它站在左边还是右边。

**第二步：统计固定一对位置的排列数。** 先写出所有排列按逆序数的计数。把排列看成逐个插入：插入第 $t$ 个数时，它相对前面 $t-1$ 个数可以带来 $0$ 到 $t-1$ 个新逆序，因此恰好有 $d$ 个逆序的 $n$ 元排列数，正是多项式

$$P(x) = \prod_{t=1}^{n}\left(1 + x + \cdots + x^{t-1}\right)$$

中 $x^d$ 的系数。

现在固定一对位置 $i < j$，记 $d = j - i$，要数的是所有满足 $a_j = \min(a_i, \ldots, a_j)$ 的排列里，逆序数恰为 $K$ 的那些。把 $a_i, \ldots, a_j$ 这 $d+1$ 个数看成一个整体：它们内部完全自由的相对顺序对应因子 $\prod_{t=1}^{d+1}(1 + \cdots + x^{t-1}) = (1 + x + \cdots + x^{d}) \cdot \prod_{t=1}^{d}(1 + \cdots + x^{t-1})$，而 $P(x)$ 里其余的因子描述的是"别的数如何与这一段交错"。所以用 $P(x)$ 除掉 $1 + x + \cdots + x^{d}$，就消掉了这一段内部的自由度；再乘上 $x^{d}$，表示 $a_j$ 是段内最小值（它比左边的 $d$ 个数都小，固定多出 $d$ 个逆序）。记

$$Q_d(x) = P(x) \big/ (1 + x + \cdots + x^{d}),$$

则对固定的一对位置：

- **右边那个位置是祖先**（$a_j = \min(a_i, \ldots, a_j)$）：排列数等于 $Q_d(x)$ 中 $x^{K-d}$ 的系数；
- **左边那个位置是祖先**（$a_i = \min(a_i, \ldots, a_j)$）：最小值落在最左端，不强迫任何逆序，排列数等于 $Q_d(x)$ 中 $x^{K}$ 的系数。

**第三步：把贡献累加到答案上。** 每个位置的深度里都先有"自己"这一层，即 $[x^K]P(x)$；然后对每个 $d = 1 \ldots N-1$ 和每一对 $(i, i+d)$，把上面两个系数分别加到位置 $i$ 与位置 $i+d$ 的答案里。

**第四步：多项式的乘除要够快。** $P$ 的度数最大是 $\frac{N(N-1)}{2} \approx 4.5 \times 10^4$。乘上 $(1 + x + \cdots + x^{b-1})$ 本质是"每个系数向后摊到 $b$ 个位置"的滑动窗口求和，朴素做法要 $O(\text{长度} \times b)$；改成先把系数记成差分（$i$ 处 $+c_i$、$i+b$ 处 $-c_i$）再整体做前缀和，就只要 $O(\text{长度})$。除以 $(1 + x + \cdots + x^{b-1})$ 就是这两步的逆运算（一定能整除），代价同样是 $O(\text{长度})$。于是每处理一个 $d$ 只做一次"除 + 乘回去"，共 $N$ 次。

## 复杂度

多项式长度为 $\frac{N(N-1)}{2} + 1$。构造 $P(x)$ 是逐个乘因子，每次 $O(\text{长度})$；随后每个 $d$ 做一次除法和一次乘法，共 $N$ 次。总时间复杂度 $O(N^3)$，空间复杂度 $O(N^2)$。
