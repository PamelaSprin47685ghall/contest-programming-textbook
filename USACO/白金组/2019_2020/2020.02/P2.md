# P2　等边三角形（Equilateral Triangles）

## 题目

农夫约翰的牧场是一个 $N\times N$ 的方格棋盘（$1\le N\le 300$），每个格子 $(i,j)$ 上的字符是 `*` 表示那里有一头奶牛，是 `.` 表示没有。因为所有奶牛都在整数坐标上，欧氏距离下不可能出现等边三角形，于是 FJ 改用**曼哈顿距离** $|x_0-x_1|+|y_0-y_1|$ 来衡量。求有多少个三元组奶牛，使得两两之间的曼哈顿距离都相等（即构成曼哈顿意义下的等边三角形）。答案保证在 32 位有符号整数范围内。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行一个长度为 $N$ 的、仅由 `*` 和 `.` 组成的字符串，第 $i$ 行第 $j$ 个字符描述位置 $(i,j)$。

## 输出

一个整数，即曼哈顿等边三元组的个数。

## 样例

输入：

```text
3
*..
.*.
*..
```

输出：

```text
1
```

三头奶牛两两马距都为 $2$，构成唯一的一个三元组。

## 思路

**先看结构。** 设三角形三顶点为 $a,b,c$，取包含它们的、边与坐标轴平行的最小包围矩形。可以证明：三个顶点中至少有一个落在包围矩形的角上（且至多两个顶点落在角上）。于是只需统计"某个顶点恰好是包围矩形左下角"的三角形，再把网格顺时针旋转 $90^\circ$ 重复做四次，就能把落在任意一个角上的情况都覆盖到。

**固定左下角后另外两个顶点的位置。** 不妨设 $a=(a_0,a_1)$ 满足 $a_0\le\min(b_0,c_0)$、$a_1\le\min(b_1,c_1)$，且三边长度都是 $r$。此时 $b,c$ 必同在某条副对角线 $x+y=(a_0+a_1)+r$ 上，并且 $b-c=\pm\left(\frac{r}{2},-\frac{r}{2}\right)$。也就是说：**先挑出同一条副对角线 $b$ 上坐标差为 $(d,-d)$（$d=\frac r2$）的两个点对 $(b,c)$，再让 $a$ 沿副对角线 $a$ 滑动**，只要 $a$ 处有奶牛就累加当前的"点对数"。

**O(1) 转移。** 直接枚举 $a$ 需要 $O(N)$ 找点对、$O(N)$ 滑动，共 $O(N^4)$。注意副对角线 $a$ 上相邻两点 $(i,a-i)$ 与 $(i+1,a-i-1)$ 对应的合法点对集合几乎重合：滑动一格只会让一对新点对进入、一对旧点对离开（因为 $b,c$ 的坐标整体加 $1$）。所以先用 $O(N)$ 求出起点 $(st,a-st)$ 的点对数 $cur$，之后每一步只做常数次 `+=` / `-=`，滑动过程就降为 $O(N)$。

**计数不重不漏。** 对每一条副对角线 $a$、每一条副对角线 $b$（$b\ge a+2$、同奇偶），把 $cur$ 累加到副对角线 $a$ 上所有有奶牛的位置；每种朝向下"左下角 + 另两顶点同对角线"的三角形被数到恰好一次，四个朝向下每个三角形也只被数到它在包围矩形角上的顶点个数那么多——而这样的顶点个数恰好与上述统计方式自洽（曼哈顿等边三角形的两个"侧"顶点无法同时落在包围矩形的两条对角角上）。因此答案正确。
