# P3　马戏团（Circus）

## 题目

农夫约翰的马戏团有 $N$ 头奶牛（$1 \le N \le 10^5$），表演都在一棵 $N$ 个结点（标号 $1 \ldots N$）的树上进行。一个"起始状态"由整数 $K$（$1 \le K \le N$）和把奶牛 $1 \dots K$ 放到 $K$ 个互不相同的结点上的方案组成。

表演过程中奶牛会进行任意多次"移动"：一次移动是让一头奶牛从当前结点走到一个相邻且没有被占用的结点。两个起始状态等价，当且仅当可以通过若干次移动从其中一个变成另一个。

对每个 $K=1,2,\dots,N$，求出起始状态的等价类个数（即最多能选出多少个两两不等价的起始状态），答案对 $10^9+7$ 取模。

## 输入

第一行一个整数 $N$。

接下来 $N-1$ 行，每行两个整数 $a_i,b_i$，表示树上的一条边。

## 输出

共 $N$ 行，第 $i$ 行是 $K=i$ 时的答案对 $10^9+7$ 取模的结果。

## 样例

输入：

```text
5
1 2
2 3
3 4
3 5
```

输出：

```text
1
1
3
24
120
```

解释：$K=1,2$ 时任意两个状态都等价；$K=3$ 时状态 $(1,2,3)$ 与 $(1,2,5)$、$(1,3,2)$ 等价，但与 $(2,1,3)$ 不等价。$K=5$ 时每个状态都是单独的等价类，共 $5!=120$ 个。

## 思路

$K=N$ 时没有任何空位，一步也走不了，$N!$ 个状态各自成为一个等价类，答案是 $N!$。下面设 $K<N$。

**归一化与类的大小。** 任意状态都能通过移动让奶牛恰好占据结点 $1..K$（依次把奶牛推进空位即可）；把这样的状态称为"规范的"。两个规范状态能互相到达的话称为"朋友"。每个状态的"朋友"数量都一样，所以只要算出某个规范状态的朋友数 $f$，答案就是 $K!/f$。

**哪些牛可以互换。** 想让两头奶牛 $x,y$ 互换而其它牛回到原位，只需把局面变成"$x$ 与 $y$ 之间隔着一个空位"，即树里出现 $x-*-y$ 这种形状，换完再把之前的移动倒着走回去。可以证明（官方分析）：把树按"度数不为 2 的点 + 中间全为 2 度点的极大链"压缩。如果某条链两侧的牛被卡住无法互相穿过，这条链就称为**饱和**的；删除所有饱和链后，树被切成若干连通块，同一块内的奶牛可以任意置换，不同块的奶牛无法交换。进一步可以证明长度为 $L$ 的链恰好在 $K \le N-2-L$ 时饱和。

**块的计数。** 对一个连通块 $c$，记

- $x_c$ = 块内所有树边的条数（也就是被并入块内部的那些链的长度之和），
- $y_c$ = 与块相邻的饱和链条数，

则在这一步就"卡"在块外的牛有 $(N-1-x_c)+(K-N+1)y_c$ 头（$N-1-x_c$ 是块外的树边数，每条相邻饱和链还会再拉走 $K-N+1$ 头），于是块内的牛数为

$$s_c=K-\bigl[(N-1-x_c)+(K-N+1)y_c\bigr]=(N-1-K)(y_c-1)+x_c .$$

（$y_c=0$ 时整棵树就是一块，$s_c=K$，符合直觉。）"朋友"的数目就是把每个块内的牛任意置换：

$$f=\prod_c s_c!,\qquad \text{答案}_K=\frac{K!}{\prod_c s_c!}.$$

**从大到小枚举 $K$。** $K$ 从 $N$ 递减到 $1$ 时，链会按长度从短到长依次饱和，用并查集把饱和链两侧的块合并，同时更新 $x,y$（合并一条长度为 $L$ 的链：$y\leftarrow y_1+y_2-2$，$x\leftarrow x_1+x_2+L$）。每轮对当前所有活跃块累乘 $\mathrm{invFact}[s_c]$ 再乘 $K!$ 即可。由于所有 $K$ 下活跃块数之和是 $O(N)$（把每轮的块数与合并过程对应起来即可得出：总和 $=(N-1)\cdot(\text{非二度点数})-\sum_L (\text{长度} \ge L \text{ 的链数})\cdot(N-2-L)=O(N)$），整体复杂度由排序决定。

实现细节：树先以某个"度数不为 2"的点为根做一次 BFS（树中一定有这样的点，否则度数之和矛盾），之后每条链只会从它最靠上的那个端点被"向下走"一次，不会重复计数；链端点一定是度数不为 2 的点。

## 复杂度

时间复杂度 $O(N\log N)$：链排序 $O(N\log N)$，并查集（按大小合并 + 路径压缩）与所有 $K$ 下累乘逆阶乘的总量均为 $O(N\alpha(N))$。空间复杂度 $O(N)$。
