# P2　最小化边数（Minimizing Edges）

## 题目

贝茜有一张连通的、无向的图 $G$，包含 $N$ 个编号为 $1 \ldots N$ 的顶点和 $M$ 条边（$2 \le N \le 10^5$，$N-1 \le M \le \frac{N^2+N}{2}$）。图里允许自环（顶点连向自己），但没有重边。

记 $f_G(a,b)$ 为：从顶点 $1$ 出发，是否有一条恰好走过 $b$ 条边的行走能到达顶点 $a$（一条边重复走会重复计数）。$1 \le a \le N$，$b \ge 0$。

埃尔希想造一张新图 $G'$，使得对所有 $a,b$ 都有 $f_{G'}(a,b) = f_G(a,b)$。她希望工作尽量少，所以 $G'$ 的边数要尽可能少。求最少的边数。$G'$ 同样允许自环、不允许重边。

每个输入含 $T$ 个独立测试点（$1 \le T \le 5 \cdot 10^4$），保证所有测试点的 $N$ 之和不超过 $10^5$、$M$ 之和不超过 $2 \cdot 10^5$。

## 输入

第一行一个整数 $T$。

每个测试点第一行两个整数 `N M`，接下来 $M$ 行每行两个整数 `x y`（$x \le y$），表示一条边。相邻测试点之间有空行，对读入没有影响。

## 输出

每个测试点输出一行，为最少边数。

## 样例

输入：

```text
2

5 5
1 2
2 3
2 5
1 4
4 5

5 5
1 2
2 3
3 4
4 5
1 5
```

输出：

```text
4
5
```

解释：第一个测试点是一张二分图，等价图必须是连通图，最少是一棵生成树（4 条边），删掉边 $(2,5)$ 后剩下的树就保持了所有 $f$ 不变；第二个测试点是一张五元环，删掉任意一条边都会把奇数长度的行走全部消掉，所以最少仍是 5 条边。

## 思路

### 顶点只由两个数决定

因为一条边走过一次会翻转长度的奇偶性，一个顶点的信息其实就是两个最短长度：

- $e_i$：从顶点 $1$ 走到 $i$、长度为**偶数**的最短行走长度；
- $o_i$：从顶点 $1$ 走到 $i$、长度为**奇数**的最短行走长度。

把它们当成状态 $(i, \text{奇偶})$，在一个"顶点 + 奇偶"的状态图上做 BFS 就能求出：从状态 $(1,\text{偶})$ 出发，走一条边恰好换到另一个奇偶，所以每个状态第一次被访问时就是最短长度。记

$$h(i) = (a_i, b_i) = (\min(e_i, o_i), \max(e_i, o_i)), \qquad s(a, b) = \{ i : h(i) = (a,b) \}.$$

如果 $o_1$ 不存在（图是二分图），那么每个顶点只有一种奇偶可到，最小的等价图就是一棵生成树，答案是 $N-1$。否则每个顶点两种奇偶都能到，下面都假定这一点。

### 每条边只能是三种类型

对每个顶点 $i \ne 1$，它在 $G'$ 里的边必须让两个最短长度都不变大、也不变小，于是只剩三类可能：

- **type A**：$i$ 连向 $s(a_i - 1, b_i - 1)$ 中某个顶点（一条边同时推进两个最短长度）；
- **type B**（当 $a_i + 1 < b_i$）：$i$ 连向 $s(a_i - 1, b_i + 1)$ 中某个顶点，**并且**连向 $s(a_i + 1, b_i - 1)$ 中某个顶点（两条边，一条保持 $a_i$ 不变，一条把两个值互换）；
- **type C**（当 $a_i + 1 = b_i$）：$i$ 连向 $s(a_i - 1, b_i + 1)$ 中某个顶点，**并且**连向 $s(a_i, b_i)$ 中某个顶点（可以是自己，即自环）。

顶点 $1$ 是特例：它的 $a_1 = 0$，不存在 $s(-1, \cdot)$。$b_1 = 1$ 时它需要一条自环，否则需要连向 $s(1, b_1 - 1)$ 的顶点。

四种情况的共同点是：**type A 边只影响本层的顶点**（$a_i + b_i$ 比它小 2，已经被处理过），而 **type B、type C 边只连同一层（$a + b$ 相同）里的顶点**。所以按层号 $a + b$ 分组，各层可以独立求最优，层内按 $a$ 从小到大处理。

### 贪心

处理组 $s(a,b)$ 时，记 `previous` 为**已经有了**的条数：它是前一组 $s(a-1, b+1)$ 在构造自己的向下边时，连到 $s(a,b)$ 上的边数。这些边可以安排成落在 $s(a,b)$ 中互不相同的顶点上，所以有 `min(previous, |s(a,b)|)` 个顶点已经拿到了"向上边"。

**$b > a+1$**：本组顶点可以有两条出路——用一条 type A 边，或用 type B 的两条边。我们总是先给每个顶点各连一条向下的边到 $s(a+1, b-1)$（它们会成为下一组的"向上边"）：

- 若 type A 可用：已有向上边的顶点就顺手把这条向下边当作自己第二条 type B 边（花费同样是 1），其余顶点各花 1 条 type A 边。总共 $|s(a,b)|$ 条，并把 $\min(previous, |s(a,b)|)$ 条向下边留给下一组。
- 若 type A 不可用：每个顶点都必须有向上边，缺的 $|s(a,b)| - previous$ 条要补上，再花 $|s(a,b)|$ 条向下边。

**$b = a+1$**：此时 $s(a+1, b-1)$ 的坐标是 $(a+1, a)$，不存在这样的集合，所以第二条边只能落在本组内部——它们可以两两配对共用一条边，剩下单个顶点用自环，即 $\lceil m/2 \rceil$ 条组内边解决 $m$ 个顶点。设改用组内边的顶点数为 $m$，总花费是

$$(|s(a,b)| - m) + \left\lceil \frac{m}{2} \right\rceil + \max(m - previous, 0),$$

其中第一项是没改的顶点各用一条 type A 边，第三项是补齐的向上边。这个函数在 $previous \ge |s(a,b)|$ 时于 $m = |s(a,b)|$ 取最小 $\lceil |s(a,b)|/2 \rceil$，否则于 $m = previous$ 取小，两种情况正好能用

$$\max\left((|s(a,b)| - previous) + \left\lceil \frac{previous}{2} \right\rceil,\ \left\lceil \frac{|s(a,b)|}{2} \right\rceil\right)$$

一次写完。若 type A 不可用，则全组都必须改用组内边，花费 $\lceil |s(a,b)|/2 \rceil$ 再加上补的向上边。

顶点 $1$ 出现在 $a = 0$ 的组里：$b_1 = 1$ 时费用 $\lceil 1/2 \rceil = 1$（一条自环）；否则花 1 条边连向 $s(1, b_1 - 1)$，正好当下一组的"向上边"。

## 复杂度

状态图 BFS 是 $O(N + M)$，把顶点按层排序是 $O(N \log N)$，贪心是 $O(N \log N)$（查组是否存在用二分）。总时间 $O(\sum (N \log N + M))$，空间 $O(N + M)$。
