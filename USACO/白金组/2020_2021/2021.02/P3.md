# P3　统计图的数量（Counting Graphs）

## 题目

贝茜有一张连通的、无向的图 $G$，包含 $N$ 个编号为 $1 \ldots N$ 的顶点和 $M$ 条边（$2 \le N \le 100$，$N-1 \le M \le \frac{N^2+N}{2}$）。图里允许自环（顶点连向自己），但没有重边。

记 $f_G(a,b)$ 为：从顶点 $1$ 出发，是否有一条恰好走过 $b$ 条边的行走能到达顶点 $a$（一条边重复走会重复计数）。$1 \le a \le N$，$b \ge 0$。

埃尔希想造一张新图 $G'$，使得对所有 $a, b$ 都有 $f_{G'}(a,b) = f_G(a,b)$。$G'$ 同样允许自环、不允许重边。请数出所有可能的 $G'$ 的个数，模 $10^9+7$。

每个输入含 $T$ 个独立测试点（$1 \le T \le \frac{10^5}{4}$），保证所有测试点的 $N^2$ 之和不超过 $10^5$。

## 输入

第一行一个整数 $T$。

每个测试点第一行两个整数 `N M`，接下来 $M$ 行每行两个整数 `x y`（$x \le y$），表示一条边。相邻测试点之间有空行，对读入没有影响。

## 输出

每个测试点输出一行，为方案数模 $10^9+7$。

## 样例

输入：

```text
1

5 4
1 2
2 3
1 4
3 5
```

输出：

```text
3
```

解释：$G'$ 可以是 $G$ 本身，也可以是下面两张图之一：

```text
5 4
1 2
1 4
3 4
3 5
```

```text
5 5
1 2
2 3
1 4
3 4
3 5
```

## 思路

### 顶点只由两个数决定

一条边走过一次会翻转长度的奇偶性，所以一个顶点的全部信息就是两个最短长度：

- $e_i$：从顶点 $1$ 走到 $i$、长度为**偶数**的最短行走长度；
- $o_i$：从顶点 $1$ 走到 $i$、长度为**奇数**的最短行走长度。

在"顶点 + 长度奇偶"的状态图上 BFS 即可求出（走一条边恰好换一个奇偶，每个状态第一次入队就是最短）。记

$$h(i) = (a_i, b_i) = (\min(e_i, o_i), \max(e_i, o_i)), \qquad s(a, b) = \{ i : h(i) = (a,b) \}.$$

**二分图的情况**：$o_i$ 不存在，距离 $d$（即 $\min(e_i,o_i)$）为唯一的层号。等价图里不能有任何自环、同行边或跳层边，否则会出现奇环或让距离变小；于是每个距离为 $d$ 的顶点必须连向距离 $d-1$ 的顶点，且不能一条都不连。若距离 $d$ 的顶点有 $f_d$ 个，方案数是

$$\prod_{d \ge 1} \left(2^{f_{d-1}} - 1\right)^{f_d}.$$

### 非二分图只能有三类边

非二分图里每个顶点的两个最短长度都有限。对每个顶点 $i \ne 1$，它的边只能来自三类：

- **type A**：$i$ 连向 $s(a_i - 1, b_i - 1)$ 中某个顶点；
- **type B**（当 $a_i + 1 < b_i$）：$i$ 连向 $s(a_i - 1, b_i + 1)$ 的某个顶点，**并且**连向 $s(a_i + 1, b_i - 1)$ 的某个顶点；
- **type C**（当 $a_i + 1 = b_i$）：$i$ 连向 $s(a_i - 1, b_i + 1)$ 的某个顶点，**并且**连向 $s(a_i, b_i)$ 的某个顶点（可以是自己）。

顶点 $1$ 是特例（$a_1 = 0$，没有 $s(-1, \cdot)$）：$b_1 = 1$ 时它需要一条自环，否则需要连向 $s(1, b_1 - 1)$。

type A 边只关系到本层的顶点（另一端的层号小 2），type B、type C 边只连同一层（$a+b$ 相同）里的顶点，所以各层互不影响，答案是把每层的方案数乘起来。层内按 $a$ 从小到大决定。

### 每层的 DP

设 $dp$ 表示"已经决定完本层中 $a$ 更小的那些组"之后，当前组 $s(a,b)$ 里还有多少个顶点**一条边都还没有**的方案数。处理一组要分三步：

**第一步：连 type B 边。** 上一组 $s(a-1,b+1)$ 留下了 $y$ 个"还需要一条向下边"的顶点（它们的 $dp$ 值），本组 $|s(a,b)|$ 个顶点里选出 $x$ 个暂时一条边都不连，其余每个顶点都至少连一条边到 $s(a-1,b+1)$；同时那 $y$ 个顶点也必须至少被连到一条边。用容斥处理"某几个顶点没被连到"：

$$\binom{|s(a,b)|}{x}\sum_{y} dp[y]\sum_{k=0}^{y}(-1)^k\binom{y}{k}\left(2^{|s(a-1,b+1)|-k}-1\right)^{|s(a,b)|-x}.$$

**第二步：连 type A 边。** 第一步里"一条边都没有"的 $y$ 个顶点必须靠 type A 边补救。先从已有 type B 边的 $|s(a,b)| - y$ 个顶点里选出 $x$ 个，它们是最后仍然没被满足、留给第三步的顶点；其余 $|s(a,b)| - x$ 个顶点（含那 $y$ 个）每个都要连至少一条 type A 边到 $s(a-1,b-1)$：

$$\binom{|s(a,b)|-y}{x}\left(2^{|s(a-1,b-1)|}-1\right)^{|s(a,b)|-x}.$$

**第三步：只有本层最高的组（$b = a+1$）需要。** 这类组的 $s(a_i+1, b_i-1) = s(a+1,a)$ 不存在，所以剩下没被满足的顶点只能在本组内部连边（连自己就是自环），而一条内部边能同时满足两个顶点。候选边数是 $|s(a,b)|$ 个顶点之间所有可连的边，共 $\frac{|s(a,b)|(|s(a,b)|+1)}{2}$ 条（含自环）；对 $y$ 个待满足顶点再容斥一次：

$$\sum_{k=0}^{y}(-1)^k\binom{y}{k}2^{\frac{(|s(a,b)|-k)(|s(a,b)|-k+1)}{2}}.$$

$a = 0$ 的组只有顶点 $1$ 一个成员，它作为每层的起点：初始 $dp$ 认为它"还没有边"，随后被第一组的**第一步**处理掉——容斥保证它至少收到一条来自 $s(1,b-1)$ 的边，正好对应顶点 $1$ 的特殊条件；$b_1 = 1$ 时它所在层只有 $s(0,1)$ 一组，第三步的自环把它解决，方案数为 $2^1 - 1 = 1$。

## 复杂度

每个测试点时间 $O(N^3)$（第一步的容斥是三重循环，取模乘方用快速幂），空间 $O(N^2)$；题目保证 $\sum N^2 \le 10^5$。
