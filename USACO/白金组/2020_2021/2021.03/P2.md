# P2　路由方案（Routing Schemes）

## 题目

有一个 $N$ 个节点（$2 \le N \le 100$）的有向网络，节点编号 $1 \ldots N$。每个节点要么是发送者（`S`）、要么是接收者（`R`）、要么都不是（`.`），发送者与接收者数量相同且至少各有一个。

边用 $i \to j$ 表示，其中 $i \ne j$；所有边都满足 $i < j$，只有 $K$ 条例外满足 $i > j$（$0 \le K \le 2$）。

一个"路由方案"由 $S$ 条从发送者到接收者的有向路径组成，要求不同的路径端点互不相同（互不相同的发送者对应互不相同的接收者）。路径可以重复经过同一个节点。

求"每条有向边恰好被经过一次"的**不同路由方案数**，对 $10^9+7$ 取模；保证至少存在一个合法方案。输入含 $T$（$1 \le T \le 20$）组测试数据，所有数据的 $N^2$ 之和不超过 $2 \cdot 10^4$。

## 输入

第一行一个整数 $T$。

每组数据：第一行两个整数 $N$ 和 $K$；第二行一个长度为 $N$ 的字符串（第 $i$ 个字符表示第 $i$ 个节点的类型）；接下来 $N$ 行，每行一个长度为 $N$ 的 01 串，第 $i$ 行第 $j$ 位为 `1` 表示存在边 $i \to j$。相邻测试数据之间有空行。

## 输出

对每组数据输出一行，为方案数模 $10^9+7$。

解释：第一组数据的边为 $1\to 3, 2\to 3, 3\to 4, 3\to 5, 4\to 6, 5\to 6, 6\to 7, 6\to 8$，把 $3$ 的两条出边与两条入边配对、$6$ 的两条出边与两条入边配对，共 $2 \times 2 = 4$ 种合法方案（每一种都把两组 $1,2$ 到 $7,8$ 的对应关系确定下来）。第二组数据中节点 $4$ 的度数（连上虚拟边后）为 $3$、节点 $10$ 为 $2$，各自任意配对，答案 $3! \cdot 2! = 12$。

## 思路

**第一步：把问题变成"配对"。**

新增一个虚拟起点 $\sigma$ 连向每个发送者，再新增一个虚拟终点 $\tau$，每个接收者都连向 $\tau$。由于每个有向边恰好被经过一次、且路径都从发送者出发到接收者结束，新图里每个原节点的入度都等于出度，记这个公共值为 $deg(i)$。

一个方案等价于：对每个节点 $i$，把它的**入边**和**出边**一一配对（进入 $i$ 的边后面接上从 $i$ 出发的哪条边），使得这样连出来的图**没有环**。原因很直接：路径分解完全由每个节点上的配对决定，反之亦然；而且只要没有环，每条边必然落在某条从 $\sigma$ 到 $\tau$ 的路径上，于是所有边都被覆盖、端点也自动互不相同。

每个节点独立地有 $deg(i)!$ 种配对方式，所以总配对数

$$\texttt{prod} = \prod_{i=1}^{N} deg(i)!.$$

**第二步：环的"比例"。**

所有正向边都从小标号指向大标号，因此任何环都必须经过回边（$i > j$ 的那 $K \le 2$ 条）。先数"强制某个环出现"的配对数：环 $e_{start} \to e_{end} \to \cdots \to e_{start}$ 上每个顶点都被迫把环的入边接到环的出边，原来 $deg(v)!$ 种配法只剩 $(deg(v)-1)!$ 种；不在环上的顶点随便配。于是

$$\#\{\text{含该环的配对}\} = \texttt{prod} \times \prod_{v \in \text{环}} \frac{1}{deg(v)}.$$

（环上每个顶点 $deg(v) \ge 1$，逆元总存在。）

**第三步：路径上的比例之和。**

$$\texttt{pathSum}(st, en) = \sum_{\text{从 } en \text{ 正向走到 } st \text{ 的路径}} \ \prod_{v \in \text{路径}} \frac{1}{deg(v)},$$

其中路径经过的顶点包含首尾两个端点（端点也各要强制配一次）。它可以在 $O(N^2)$ 内用 DP 求出：按标号从小到大扫，$dp[en]=1$，处理到 $i$ 时先除以 $deg(i)$（于是每次经过 $i$ 就乘上 $1/deg(i)$），再沿正向边把值传给更大的标号，最后 $dp[st]$ 就是答案。若 $st = 0$、$en = 0$ 或 $en > st$ 则返回 $0$（回边要求起点标号更大）。

**第四步：容斥。**

把两条回边记作 $0, 1$，各自对应环 $e_{start}[x] \to e_{end}[x] \to \cdots$，答案就是

$$\texttt{prod} \times \Bigl(1 - \texttt{pathSum}(s_0,e_0) - \texttt{pathSum}(s_1,e_1) + \texttt{pathSum}(s_0,e_0)\,\texttt{pathSum}(s_1,e_1) - \texttt{pathSum}(s_1,e_0)\,\texttt{pathSum}(s_0,e_1)\Bigr).$$

前两项减去"出现某个环"，第三项加回"两个环同时出现"（此时两个环互不干扰，比例相乘）。最后一项减去"只用两条回边串成一个大环"的情形——如果用 Inclusion–Exclusion 的字面意思去数，这种配置会被前面的项多算或少算，正好用最后一项配平；若某个方案让一个顶点落在两个环里、或让同一个环重复出现，它在第三、四项中的贡献相互抵消，净贡献为 $0$。

当 $K = 1$ 时把缺失的回边补成 $(0, 0)$，所有含它的项都因 $\texttt{pathSum}$ 返回 $0$ 而消失，公式退化成 $1 - \texttt{pathSum}(s_0, e_0)$；当 $K = 0$ 时退化为 $1$，即所有配对都合法——和前面"不可能形成环"的结论一致。

除法在模意义下用费马小定理（$deg(v) < 10^9+7$，逆元 $\text{deg}(v)^{p-2}$）。

## 复杂度

每组数据求 4 次 $\texttt{pathSum}$，每次 $O(N^2)$（求逆元的 $O(\log p)$ 可以忽略），总时间 $O\!\left(\sum N^2\right)$，空间 $O(N^2)$。
