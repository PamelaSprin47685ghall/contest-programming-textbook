# P3　平衡子集（Balanced Subsets）

## 题目

农夫约翰的牧场是一个 $N \times N$ 的方格棋盘（$1 \le N \le 150$），格子用 $(i, j)$ 表示（$1 \le i, j \le N$），其中一些格子长草（`G`），其余是空地（`.`）。

一个非空的格子集合称为"平衡的"，如果满足：

1. 集合中所有格子都长草；
2. 集合是 4-连通的：任意两个格子之间都有一条由集合内格子组成的路径，路径上相邻两格水平或竖直相邻；
3. 若第 $y$ 列中的格子 $(x_1, y)$ 与 $(x_2, y)$（$x_1 \le x_2$）都在集合中，则所有 $(x, y)$（$x_1 \le x \le x_2$）也都在集合中；
4. 若第 $x$ 行中的格子 $(x, y_1)$ 与 $(x, y_2)$（$y_1 \le y_2$）都在集合中，则所有 $(x, y)$（$y_1 \le y \le y_2$）也都在集合中。

求平衡子集的数量，对 $10^9+7$ 取模。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行一个长度为 $N$ 的字符串，第 $i$ 行第 $j$ 个字符是 `G` 表示 $(i, j)$ 长草，`.` 表示不长草。

## 输出

一行，一个整数，表示平衡子集的个数模 $10^9+7$。

## 样例

输入：

```text
2
GG
GG
```

输出：

```text
13
```

解释：$2 \times 2$ 的全草棋盘上，所有 4-连通的子集都同时满足第 3、4 条限制，而它的 4-连通子集共有 $13$ 个（$4$ 个单格、$4$ 条相邻的格对、$4$ 个三格、$1$ 个四格）。

## 思路

**第一步：把条件翻译成行区间序列。**

设集合占据的行是若干连续的行（否则不连通），第 $i$ 行占据的列区间是 $[L_i, R_i]$。

- 条件 4（列连续）等价于**每行一个区间**：这是它的直接改写。
- 条件 3（行连续）等价于：$L$ 序列"先不增后不减"（谷形），且 $R$ 序列"先不减后不增"（峰形）。
- 条件 2（4-连通）等价于相邻两个行区间有公共列：$L_{i+1} \le R_i$ 且 $R_{i+1} \ge L_i$。

为什么 $L$ 谷形、$R$ 峰形就保证了列连续？取任意一列 $y$ 和行 $i < j < k$，设 $y$ 在第 $i$ 行与第 $k$ 行出现。若第 $j$ 行不含 $y$，则要么 $y < L_j$（此时 $L_j > L_i$，说明 $L$ 的严格上升已经发生在 $j$ 或更早，由后半段非递减知 $L_k \ge L_j > y$，与 $y$ 出现在第 $k$ 行矛盾），要么 $y > R_j$（同理，$R$ 的严格下降已经发生在 $j$ 或更早，由后半段非递增知 $R_k \le R_j < y$，同样矛盾）。所以 $y$ 必然出现在第 $j$ 行，列连续成立。反过来，若 $L$ 不是谷形（先升后降），中间那一行会"塌"下去，把某一列撕成两段，列连续被破坏；$R$ 同理。判据因此是**充分必要**的。

**第二步：DP 状态与相位。**

逐行自上而下 DP。状态 $(a, b, L, R)$ 表示：当前处理的行是这个子集的**最后一行**，该行取 $[L, R]$，而

- $a = 0$：$L$ 还没有出现过"严格上升"，仍处于非递增阶段；$a = 1$：已经出现过严格上升，此后 $L$ 必须非递减；
- $b = 0$：$R$ 还没有出现过"严格下降"，仍处于非递减阶段；$b = 1$：已经出现过严格下降，此后 $R$ 必须非递增。

用"**第一次**严格上升（下降）"作为相位切换点，每个合法形状的 $(a,b)$ 取值唯一，因此不会重复计数；答案就是把所有相位的 DP 值加总（每个子集在它的最后一行被计入一次）。

**第三步：转移。**

设上一行的区间是 $[l, r]$，本行要取 $[L, R]$（要求 $[L,R]$ 全是草）。转移必须满足：

- 相交条件：$l \le R$ 且 $r \ge L$；
- $a$ 方向：若上一行 $a = 0$，则要么 $l \ge L$（留在非递增阶段），要么 $l < L$（发生严格上升，转入 $a = 1$）；若 $a = 1$，则必须 $l \le L$；
- $b$ 方向：若上一行 $b = 0$，则要么 $r \le R$（留在非递减阶段），要么 $r > R$（发生严格下降，转入 $b = 1$）；若 $b = 1$，则必须 $r \ge R$。

把"上一行区间 $[l,r]$ 与各种相位组合"的合法取值并起来，正好是 $dp$ 上的一块矩形区域，例如 $a' = 0, b' = 0$ 对应 $l \in [L, R]$、$r \in [L, R]$ 的整块矩形（$l > r$ 的位置本来就是 $0$）。于是对上一行的 $dp$ 做二维前缀和，每个状态的四种转移都能 $O(1)$ 求出，一行内再做一遍 $O(N^2)$ 的前缀和即可。

另外，只由本行这一段构成的子集要额外记 $1$（对应状态 $a = 0, b = 0$）。
