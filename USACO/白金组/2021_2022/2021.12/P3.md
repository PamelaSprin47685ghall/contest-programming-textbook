# P3　高低猜数（HILO）

## 题目

贝茜心里有一个数 $x + 0.5$，其中 $x$ 是 $0$ 到 $N$ 之间的整数（$1 \le N \le 5000$）。

埃尔希要猜这个数。她可以问"$i$ 是偏高还是偏低？"（$1 \le i \le N$）：如果 $i$ 大于 $x + 0.5$，贝茜回答 "HI!"；如果 $i$ 小于 $x + 0.5$，回答 "LO!"。

埃尔希的策略是：动手之前先写一个 $1$ 到 $N$ 的排列，然后按排列中的顺序逐个猜数，但会跳过没有必要的猜测——如果她准备猜 $i$，而之前猜过某个 $j < i$ 得到过 "HI!"，就跳过 $i$；如果之前猜过某个 $j > i$ 得到过 "LO!"，也跳过 $i$。可以证明，无论排列怎么选，这个策略最终都能唯一确定 $x$。

把贝茜所有的回答依次连成字符串 $S$，"说了多少次 HILO"就是 $S$ 中等于 "HILO" 的长度 $4$ 子串个数。求：埃尔希所有可能的排列上，"HILO" 个数之和，对 $10^9 + 7$ 取模。

## 输入

一行两个整数 $N$ 和 $x$。

## 输出

一个整数：所有排列的 "HILO" 个数之和模 $10^9 + 7$。

## 样例

输入：

```text
4 2
```

输出：

```text
17
```

输入：

```text
60 10
```

输出：

```text
508859913
```

## 思路

被跳过的猜测根本不会写进 $S$，所以它们怎么排列都不影响答案。真正有意义的只有"有用的取值"：目前还有可能是下一个回答来源的那些数。把它们按出现顺序看成一个随机序列，每一步都等概率地取"还没出现过的有用取值"中的任意一个——这就是下面递推里 $1/(j+k)$ 的来源。

设贝茜的数是 $x + 0.5$，那么小于它的有用取值有 $x$ 个，大于它的有 $N - x$ 个。

用期望来做。令 `dp[0][j][k]` 表示：还剩 $j$ 个更小的有用取值、$k$ 个更大的有用取值，且贝茜**最近一次**回答是 "LO" 时，之后还会说出的 "HILO" 个数的期望；`dp[1][j][k]` 是最近一次回答为 "HI" 时的期望。

从 $(j, k)$ 出发，下一个出现的有用取值在这 $j + k$ 个里均匀分布，所以：

- 取到更小的取值（概率 $j/(j+k)$）：贝茜回答 "LO"；如果它在 $j$ 个更小取值里按从大到小排第 $j_2$ 位，那么比它更小的有用取值还剩 $j_2$ 个，之后的状态是 $dp[0][j_2][k]$。
- 取到更大的取值（概率 $k/(j+k)$）：贝茜回答 "HI"，之后的状态是 $dp[1][j][k_2]$（$k_2$ 是它按从小到大排的位置）。

于是

$$dp[0][j][k] = \frac{\sum_{j_2 < j} dp[0][j_2][k] + \sum_{k_2 < k} dp[1][j][k_2]}{j+k},$$

而 $dp[1][j][k]$ 只比它多一项：刚说完 "HI" 之后如果下一个回答是 "LO"，就当场多出一个 "HILO"，这种情况的概率是 $j/(j+k)$，所以

$$dp[1][j][k] = dp[0][j][k] + \frac{j}{j+k}.$$

两个和式没法每次重算，但可以边推边维护：把 `sumHiInRow[j]` 当作"固定 $j$、$k$ 更小的那些 $dp[1][j][k_2]$ 之和"，把 `sumLoInColumn[k]` 当作"固定 $k$、$j$ 更小的那些 $dp[0][j_2][k]$ 之和"。按 $j$ 从小到大、$k$ 从小到大推的时候，轮到 $(j,k)$ 时这两个前缀和刚好就是需要的两个和，算完再把新的 $dp$ 值加进去。因为递推只用到这两个前缀和与当前状态，整张 $O(N^2)$ 的表都不必存下来。

模意义下的除法用逆元：$j + k \le N \le 5000 < 10^9+7$，所以 $1/(j+k)$ 总是存在，乘上 $(j+k)^{-1}$ 即可。$j = k = 0$ 时已经没有可取的值，期望为 $0$。

最后，所有 $N!$ 个排列等可能，所以答案 $= dp[0][x][N-x] \times N!$。初始时应收敛到"最近一次回答是 LO"：一开始还没有说过 "HI"，不可能立刻凑出 "HILO"，这与递推中说的"只有刚回答过 HI 才可能马上多出一个 HILO"一致。

## 复杂度

状态数 $O(N^2)$，每个状态 $O(1)$ 转移，时间 $O(N^2)$；递推只需要两个长度为 $N$ 的前缀和数组，空间 $O(N)$。
