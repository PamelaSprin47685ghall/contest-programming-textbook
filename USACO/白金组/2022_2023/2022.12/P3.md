# P3　回文串（Palindromes）

## 题目

UCFJ 的 $N$ 头牛（$1 \le N \le 7500$）排成一排参加颁奖典礼，第 $i$ 头牛的位置从左到右记为 $1 \ldots N$。每头牛的品种是 Guernsey（记作 `G`）或 Holstein（记作 `H`）。

FJ 要为**每一个连续子段**拍一张合照，但他只肯拍重排后能成为回文串的子段。对每个连续子段，统计把它重新排列成回文串所需的最少**相邻交换**次数（也就是每次只能交换子段里相邻的两头牛），无法做到则记 $-1$。

注意每个子段都独立计算（拍完一张照片，牛会回到原来的位置）。请输出全部 $\frac{N(N+1)}{2}$ 个子段的这些数字之和。

## 输入

一行，一个长度为 $N$ 的、只由 `G` 和 `H` 组成的字符串。

## 输出

一行一个整数：所有连续子段的答案之和。

## 样例

输入：

```text
GHHGGHHGH
```

输出：

```text
12
```

解释：前四个子段是 `G`、`GH`、`GHH`、`GHHG`。`G` 和 `GHHG` 本身就是回文串，贡献 $0$；`GHH` 用一次交换就能变成回文串，贡献 $1$；`GH` 无论怎么交换都不行，贡献 $-1$。另一个有贡献的子段是 `HHGG`，需要两次交换。

## 思路

**先看单个子段。** 交换两头相同品种的牛没有任何意义，所以子段里所有 `G` 之间的相对顺序、所有 `H` 之间的相对顺序都不会改变。于是第 $j$ 个 `G` 只能和倒数第 $j$ 个 `G` 配对。设第 $j$ 个 `G` 左边有 $x_j$ 个 `H`、倒数第 $j$ 个 `G` 右边有 $y_j$ 个 `H`，为了让这两处对称，至少需要 $|x_j - y_j|$ 次交换，各对之间可以独立完成、下界可以同时取到；如果 `G` 有奇数个，还要额外把正中的那个 `G` 挪到子段正中，代价是它到中点的距离。另外，`G` 的个数的奇偶性必须和子段长度的奇偶性一致（否则"最多一种字符出现奇数次"这一条件不满足），不满足就输出 $-1$。

**O(N³) 的做法。** 枚举所有 $O(N^2)$ 个子段，对每个子段从左、右两端同时向内，每次找出最左、最右的两个 `G` 作为一对，累加它们到各自端点的距离之差即可。

**优化到 O(N²)。** 关键在于固定"中间"的 `G`：`G` 有奇数个时中点就是正中那一个，有偶数个时中点是最中间的两个。中点一固定，**每个 `G` 配谁就与左右端点无关了**——中点左边第 $j$ 个 `G` 永远配中点右边第 $j$ 个 `G`。用整串下标看，若这一对是 $(u, v)$，子段是 $[l, r]$，那么这一对的代价是

$$\big|(u-l)-(r-v)\big|=\big|(u+v)-(l+r)\big|,$$

只依赖于 $s = l + r$。于是定义 $F(s) = \sum_j |u_j + v_j - s|$：维护差分 $d(s) = F(s+1) - F(s)$，$s$ 每增大 $1$，$F$ 只要加上 $d$；而每跨过一对的 $u_j + v_j$，$d$ 就增加 $2$，用一个数组 $e$ 记下每个 $s$ 上有多少对（贡献 $2$），$d$ 也能 $O(1)$ 更新。

对固定的中点，配对是一层一层向外扩的：第 $k$ 层的配对是 $(\text{gpos}[lc-k], \text{gpos}[rc+k])$（$lc = rc$ 表示中间是单独一个 `G`，$rc = lc+1$ 表示中间是两个 `G`；$k = 0$ 时若 $lc = rc$，中间那个 `G` 不参与配对）。第 $k$ 层里合法的左右端点 $l \in (\text{gpos}[lc-k-1],\ \text{gpos}[lc-k]]$、$r \in [\text{gpos}[rc+k],\ \text{gpos}[rc+k+1])$ 构成一个小矩形，把矩形里的 $(l, r)$ 全部枚举一遍：固定 $l$ 从小到大扫 $r$，每得到一格的 $F$ 就加进总答案（$lc = rc$ 时还要加上正中 `G` 到中点的距离；若长度与 `G` 的个数奇偶性不匹配就记 $-1$）。每扫完一行把 $F, d$ 退回行首，进入下一层时再把状态推到新矩形的起点，这些"前进/回溯"都是常数次加减。

每个子段恰好被枚举一次，所有的前进与回溯次数也与枚举次数同阶，因此总时间是 $O(N^2)$。
