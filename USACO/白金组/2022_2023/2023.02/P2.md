# P2　出题（Problem Setting）

## 题目

农夫约翰创作了 $N$ 道题（$1 \le N \le 10^5$），并请了 $M$ 名测试员（$1 \le M \le 20$），每名测试员对每道题都给出了"简单"或"困难"的评价。

约翰想要从中选出若干道题排成一个难度递增的题集：题集中的题可以按任意顺序排列，但要求不存在一对题——排在前面的题被某位测试员评为"困难"，而排在后面的题被同一位测试员评为"简单"。

请统计约翰能组成的不同非空题集的数量，答案对 $10^9+7$ 取模。题集中题目的顺序不同视为不同题集。

## 输入

第一行两个整数 $N$ 和 $M$。

接下来 $M$ 行，每行一个长度为 $N$ 的字符串，第 $i$ 个字符为 `E` 表示这名测试员认为第 $i$ 道题简单，为 `H` 表示困难。

## 输出

一个整数，表示不同非空题集的数量对 $10^9+7$ 取模的结果。

## 样例

输入：

```text
3 1
EHE
```

输出：

```text
9
```

## 思路

对每道题 $p$，记掩码 $b_p$：第 $i$ 位为 1 当且仅当第 $i$ 名测试员认为它困难。题集 $[p_1,p_2,\dots,p_k]$ 合法当且仅当相邻两题满足 $b_{p_i}\ \&\ b_{p_{i+1}}=b_{p_{i+1}}$，即掩码沿题集**单调不减**（后一题的困难集合包含于前一题）。于是顺序只由掩码决定。

设 $f[b]$ 表示最后一题掩码恰为 $b$ 的非空题集数量，$g[b]$ 表示掩码恰好为 $b$ 的题目数量。若题集有多道题，则去掉最后一题后，倒数第二道题的掩码 $b'$ 是 $b$ 的子掩码（$b' \subseteq b$，允许 $b'=b$）：

$$f[b]=\Bigl(1+\sum_{b'\subsetneq b}f[b']\Bigr)\cdot\bigl(\mathrm{ord}(g[b])-1\bigr),$$

其中 $\mathrm{ord}(x)=1+x\cdot \mathrm{ord}(x-1)$ 表示从 $x$ 道题中随便选出一个子集并任意排列的方案数（含空集），减去 1 是因为掩码为 $b$ 的题目至少要选一道；括号里的 $1$ 表示题集只有一道题（掩码为 $b$）的情形。

朴素枚举子掩码需要 $O(3^M)$。使用子集和（SOS）预处理：令 $\mathrm{sdp}[b][j]$ 表示只允许改动 $b$ 的前 $j$ 位时，所有子掩码的 $f$ 之和。由于计算 $f[b]$ 时需要的是严格子掩码，而在按数值从小到大枚举 $b$ 时，用 $b$ 的最高不同位拆开即可避免重复与自身：

- 求 $\sum_{b'\subsetneq b} f[b']$：枚举 $b$ 中每个为 1 的第 $j$ 位，累加 $\mathrm{sdp}[b\oplus 2^j][j]$；
- $\mathrm{sdp}[b][j+1]=\mathrm{sdp}[b][j]$，若 $b$ 的第 $j$ 位为 1，再加上 $\mathrm{sdp}[b\oplus 2^j][j]$。

由于 $b\oplus 2^j<b$，递推天然按正确顺序完成。

## 复杂度

时间复杂度为 $O(NM+2^M\cdot M)$，空间复杂度为 $O(2^M\cdot M)$。取 $M=20$ 时约为 $2\cdot 10^7$ 次运算与 80MB 的 DP 表。
