# P1　空想性错觉（Pareidolia）

## 题目

"空想性错觉"指人在本来没有图案的地方看出熟悉图案的现象。农夫约翰整天和奶牛打交道，于是经常把日常物品看成与牛有关的东西：例如看到字符串 `bqessiyexbesszieb` 时，他的眼睛会忽略掉一些字母，只看到 `bessiebessie`。

给定一个字符串 $s$，令 $B(s)$ 表示从 $s$ 中删掉零个或多个字符后，最多能拼出多少个连续的 `bessie`。例如 $B($`bqessiyexbesszieb`$) = 2$。再给定字符串 $t$，令 $A(t)$ 表示 $t$ 的**所有连续子串** $s$ 的 $B(s)$ 之和。

$t$ 的长度 $N \le 2\cdot 10^5$，只含小写字母。请先求出初始的 $A(t)$，再依次处理 $U$（$1 \le U \le 2\cdot 10^5$）次修改：每次把 $t$ 的第 $p$ 个字符改成 $c$（修改**累积**生效），并输出修改后的 $A(t)$。

（本题时限 4 秒、空间 512 MB，都是默认值的两倍。）

## 输入

第一行一个字符串 $t$。

第二行一个整数 $U$，接下来 $U$ 行每行一个位置 $p$（$1 \le p \le N$）和一个字符 $c$，表示把第 $p$ 个字符改成 $c$。

## 输出

共 $U+1$ 行：初始的 $A(t)$，以及每次修改后的 $A(t)$。

## 样例

输入：

```text
bessiebessie
3
3 l
7 s
3 s
```

输出：

```text
14
7
1
7
```

解释：初始时恰有 12 个子串含 1 个 `bessie`、1 个子串（整串）含 2 个，故 $12\cdot 1 + 1\cdot 2 = 14$；第一次修改后 $t = $ `belsiebessie`，有 7 个子串含 1 个 `bessie`；第二次修改后 $t = $ `belsiesessie`，只有整串含 1 个；第三次改回来后又是 7 个。

## 思路

**先看不带修改的 $O(N)$ 做法。** 扫描 $t$，维护 `cnt[0..5]`：`cnt[j]` 表示"当前已匹配到模式 `bessie` 前 $j$ 个字符"的待续批次有多少。扫到下标 $k$ 的字符时：

- 先给 `cnt[0] += 1`（这个字符本身可以作为某一批的起点）；
- 若字符等于 `bessie[j]`，就把 `cnt[j]` 整批推进到 `cnt[j+1]`，否则原地保留；
- 若推进的是最后一格（$j = 5$，字符 `e`），说明这些批次此刻都能完成一份 `bessie`：以 $k$ 为结尾、起点在它们各自的起点之前的所有子串都能得到一个 `bessie`，所以答案加上 $(N - k + 1)\cdot \texttt{cnt}[5]$。

注意每个下标在扫描中是"新老分离"的：新加的那个 1 也要跟着当前字符一起前移，所以上面的顺序不能反。

**带修改怎么做。** 把每个字符变成"转移"，用线段树合并相邻区间。一段子串的转移只需要记四组信息就能完全描述它：

- `endsUpAt[d]`：扫描之前位于下标 $d$ 的那批计数，扫描之后落在哪个下标（一批计数在扫描过程中始终整批一起走）；
- `coefficients[d]`：这批计数在这段子串里对答案的线性贡献系数（因为"完成匹配"时的系数 $(N-k+1)$ 只与位置有关，与是哪一批无关）；
- `fixedEndsUpAt[d]`、`fixedContribution`：每个字符都会凭空给下标 0 加一个 1，这些"新来的"量与外部状态无关，所以单独记它们的去向与贡献。

于是每段子串的转移形如

$$v'_j = \sum_{d:\ endsUpAt[d]=j} v_d + fixedEndsUpAt[j],\qquad
\Delta = \sum_{d} coefficients[d]\cdot v_d + fixedContribution .$$

合并相邻两段 $L,R$ 时逐项代入即可：$d$ 先被 $L$ 送到 `L.endsUpAt[d]` 再被 $R$ 送往 `R.endsUpAt[L.endsUpAt[d]]`；系数是两段的系数之和；$L$ 内部新加的量要穿过 $R$，于是既贡献 `R.coefficients[·] * L.fixedEndsUpAt[·]`，又改变最终落点。

单个字符的转移可以直接写出：`endsUpAt[d] = (c == "bessie"[d] ? d+1 : d)`；`fixedEndsUpAt[endsUpAt[0]] = 1`；若 `endsUpAt[5] == 0`（即字符是 `e`，匹配收尾），则 `coefficients[5] = N - k`（$k$ 为 0 基下标，对应 $(N-k+1)$）。

线段树叶子数补齐到 2 的幂，多出来的叶子用单位元（`endsUpAt[d] = d`，其余全 0），自底向上建树；每次修改重算 $O(\log N)$ 个结点，根结点的 `fixedContribution` 就是答案（因为根代表的整段子串一开始没有任何待续批次）。
