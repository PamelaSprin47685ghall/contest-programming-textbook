# P2　好比特串（Good Bitstrings）

## 题目

对任意正整数 $a,b$，按题面给出的代码定义 $\texttt{gen_string}(a,b)$：从 `ia = ib = 0` 开始，每一步比较 $ia\cdot b$ 与 $ib\cdot a$，若 $ia\cdot b \le ib\cdot a$ 就输出一个 `0` 并让 `ia` 加一，否则输出一个 `1` 并让 `ib` 加一，直到输出 $a+b$ 个字符。循环结束时恰好 `ia = a`、`ib = b`，所以结果是一个长度 $a+b$、恰含 $a$ 个 `0` 与 $b$ 个 `1` 的比特串。例如 $\texttt{gen_string}(4,10) = \texttt{01110110111011}$。

称比特串 $s$ 是**好的**，如果存在正整数 $x,y$ 使 $s = \texttt{gen_string}(x,y)$。

给定 $A,B$（$1 \le A,B \le 10^{18}$），求 $\texttt{gen_string}(A,B)$ 有多少个前缀是好的。

## 输入

第一行一个整数 $T$（$1 \le T \le 10$）。

接下来 $T$ 行，每行两个整数 $A,B$。

## 输出

对每个测试用例输出一行一个整数，表示答案。

## 样例

输入：

```text
6
1 1
3 5
4 7
8 20
4 10
27 21
```

输出：

```text
1
5
7
10
6
13
```

解释：$\texttt{gen_string}(4,10)$ 的 6 个好前缀分别是 $\texttt{gen_string}(1,1)$、$(1,2)$、$(1,3)$、$(2,5)$、$(3,7)$、$(4,10)$。

## 思路

把比特串看成从 $(0,0)$ 走向 $(a,b)$ 的格路：第 $t$ 步向右（输出 `0`）当且仅当当前点 $(ia,ib)$ 满足 $ia\cdot b \le ib\cdot a$，也就是当前点在直线 $y = \frac{b}{a}x$ 上或上方。于是这条路永远"贴着"这条直线走。

设 $s = \texttt{gen_string}(a,b)$。前缀与点一一对应：走了 $x$ 次向右、$y$ 次向上，对应点 $(x,y)$。称 $0 < x \le a$、$0 < y \le b$ 的点是**好点**，如果 $\texttt{gen_string}(x,y)$ 是 $s$ 的前缀；答案就是好点个数。

**判定一个点是不是好点。** 把 $\texttt{gen_string}(x,y)$ 的每一步与 $s$ 的前 $x+y$ 步对齐，两者必须步步同向。可以证明 $(x,y)$ 是好点当且仅当：矩形 $0 \le x_p \le x$、$0 \le y_p \le y$ 内除 $(x,y)$ 以外的**每个格点**都落在过原点、斜率分别为 $\frac{y}{x}$ 与 $\frac{b}{a}$ 的两条直线的同一侧（用叉积 $x_1y_2 - x_2y_1$ 判正负）。直观上就是：从 $(0,0)$ 到 $(x,y)$ 的这段路上，不能有任何格点"跨"到两条直线之间去。

**按位置分成两类来数。**

- **在过 $(a,b)$ 的射线下方**的点：对每个 $y$，最多只有一个候选，即该 $y$ 上最靠左的射线下方的点 $(x,y) = (\lfloor ya/b\rfloor + 1,\ y)$。从 $y=1$ 递增枚举，若这个候选与上一个好点的叉积 $> 0$（说明它没有被别的点卡住），它就是好点。
- **在射线上或其上方**的点：对每个 $x$，最低的候选是 $(x,\ \lceil xb/a\rceil)$，从 $x=1$ 递增枚举，若叉积 $\ge 0$ 则它也是好点。

直接把这两轮枚举做出来是 $O(a+b)$，对 $10^{18}$ 的 $a,b$ 不可行。改成下面这种"一次跳一整段"的连分数式循环即可（这正是欧几里得算法）：

设 $f_1,f_2$ 是夹住 $f' = (a,b)$ 的两条射线上的相邻格点，初始 $f_1 = (1,0)$、$f_2 = (0,1)$。只维护两个数

$$\texttt{crsBelow} = \text{cross}(f_1,f'),\qquad \texttt{crsAbove} = \text{cross}(f',f_2),$$

它们都 $>0$ 且每次只改一个。每轮令 $f_3 = f_1 + f_2$，由双线性性 $\text{cross}(f_1,f_3) = \text{cross}(f_3,f_2) = 1$：

- 若 $\texttt{crsBelow} > \texttt{crsAbove}$，说明 $f_3$ 在 $f'$ 下方，把 $f_1$ 换成 $f_3$：$\texttt{crsBelow} \mathrel{-}= \texttt{crsAbove}$。这一步 $f_3$ 本身是好点；若 $f_2$ 已经不在 $y$ 轴上，则 $f_2$ 的"下一个整数倍"也被确认为好点，所以一次加 2（否则只加 1）。
- 否则把 $f_2$ 换成 $f_3$：$\texttt{crsAbove} \mathrel{-}= \texttt{crsBelow}$，只加 1，并标记 $f_2$ 已离开 $y$ 轴。

同一分支可以连续走很多步，用 `mul = (crsBelow - 1) / crsAbove` 或 `mul = crsAbove / crsBelow` 一次乘过去，答案加上 `mul` 份贡献即可；每轮至少让其中一个数减少一半以上，所以总轮数是欧几里得算法的步数。

当 $\texttt{crsAbove} = 0$ 时终止：此时 $(a,b)$ 正好落在 $f_2$ 射线上，$f_1$ 与 $(0,0)$ 之间还夹着 $\texttt{crsBelow}$ 个 $f_2$ 的整数倍，其中最后一共孪生出 $f_1 + m$ 与 $m$ 两个好点，贡献 $2(\texttt{crsBelow}-1)$。
