# P3　奶牛三元组（Triples of Cows）

## 题目

农夫约翰有 $N$（$2 \le N \le 2\cdot 10^5$）头奶牛，标号 $1\dots N$，初始时有 $N-1$ 对朋友关系，构成一棵树。奶牛们要一头一头地去度假：第 $i$ 天第 $i$ 头牛离开农场，**然后**它的所有还留在农场的朋友之间两两成为朋友。

请对每个 $i = 1\dots N$，求出第 $i$ 头牛离开**之前**，有多少个互不相同的奶牛有序三元组 $(a,b,c)$，满足 $a,b,c$ 都没去度假、$a$ 与 $b$ 是朋友、$b$ 与 $c$ 是朋友。

## 输入

第一行一个整数 $N$。

接下来 $N-1$ 行，每行两个整数 $u_i,v_i$，表示初始时 $u_i$ 与 $v_i$ 是朋友。

## 输出

共 $N$ 行：第 $i$ 行的答案是第 $i$ 头牛离开之前的三元组个数。

## 样例

输入：

```text
3
1 2
2 3
```

输出：

```text
2
0
0
```

解释：牛 1 离开前只有 $(1,2,3)$ 与 $(3,2,1)$ 两个三元组；牛 1 离开后只剩 2 头牛，凑不出三元组。

（题面另有两组样例：$N=4$、边为 `1 2 / 1 3 / 1 4` 时答案为 `6 6 0 0`；$N=5$、边为 `3 5 / 5 1 / 1 4 / 1 2` 时答案为 `8 10 2 0 0`。）

## 思路

**换一种方式记录"朋友关系"。** 每条初始的朋友关系 $(\texttt{par}[u], u)$ 建成一个**白点** $u$，每头奶牛建成一个**黑点**。以黑点 $N$ 为根，白点 $u$ 接在黑点 $\texttt{par}[u]$ 与黑点 $u$ 之间，得到的是一棵 $2N-1$ 个结点的树（每条边 $(\texttt{par}[u],u)$ 变成 黑$(\texttt{par}[u])$ — 白$(u)$ — 黑$(u)$）。

这样，**两头牛是朋友当且仅当它们的黑点同时与某个白点相邻**。牛 $x$ 离开时，它当前的所有邻居两两成为朋友，正好对应"把 $x$ 的所有白邻居合并成一个白点"：新白点的黑邻居就是 $x$ 当前的全部邻居，它们两两共享这个白点。于是树结构永远保持，而且朋友关系就是"黑点—白点—黑点"。

**答案的树意义。** 有序三元组 $(a,b,c)$（$a,b,c$ 互不相同、$a\!-\!b$、$b\!-\!c$）恰好对应树中的五元路径 $(a',b,c',d,e')$：$a',c',e'$ 是黑点且互不相同，$b,d$ 是白点。把路径按**中间黑点 $c'$** 的位置分成三类。记

$$\texttt{mass}[w] = \text{白点 } w \text{正下方相邻的黑点数（即 } w \text{ 的黑邻居数减一）},$$

则三类分别是

1. $b = d$：$a',c',e'$ 是同一个白点 $w$ 的黑邻居里三个不同的点，中间那个当 $c'$，共 $\sum_w (\texttt{mass}[w]+1)\,\texttt{mass}[w]\,(\texttt{mass}[w]-1)$ 个。
2. $b \ne d$ 且 $c'$ 同时在 $b,d$ 上方：$b,d$ 是黑点 $c'$ 的两个不同的孩子白点，$a'$ 与 $e'$ 各从它们下面挑一个黑孩子，共 $2\sum_{c'}\sum_{b<d \text{ 是 } c' \text{ 孩子白点}} \texttt{mass}[b]\,\texttt{mass}[d]$ 个。
3. $b,d$ 一上一下：$c'$ 的白邻居里一个是它的父亲、一个是它的孩子。等价地枚举"白点 $a$ 与它下方距离 2 的白点 $u$"这一对，$a'$ 从 $a$ 的黑孩子里挑、$e'$ 从 $u$ 的黑孩子里挑，共 $2\sum_{a} \texttt{mass}[a]\cdot\texttt{combinedCombinedMass}[a]$ 个，其中 $\texttt{combinedCombinedMass}[a] = \sum_{u \text{ 在 } a \text{ 下方距离 } 2} \texttt{mass}[u]$。

乘 2 是因为 $(a,b,c)$ 与反向的 $(e,d,c)$ 是两个不同的有序三元组。

**增量维护。** 再记 $\texttt{combinedMass}[x]$ 为黑点 $x$ 所有孩子白点的 $\texttt{mass}$ 之和。初始时每个白点 $u$ 正下方只有黑点 $u$ 自己，所以 $\texttt{mass}[u] = 1$；把白点逐个"加进来"就得到初始答案。之后每次操作只影响常数个白点：

- `update(u, delta)`：白点 $u$ 的 $\texttt{mass}$ 增加 `delta`。此时二类里 $u$ 与父亲黑点其它孩子白点的配对、三类里 $u$ 与上方距离 2 的白点 $a = \texttt{find}(\texttt{par}[u])$ 的配对、以及一类中 $u$ 自己的多项式都要按增量公式修正（代码里逐项加减，全是 $O(1)$）。
- `mergeNode(u)`：把白点 $u$ 合并进它上方的白点 $a = \texttt{find}(\texttt{par}[u])$。先把 $u$ 相关的三类贡献从答案里摘掉，再把 $\texttt{mass}[u]$ 与 $\texttt{combinedCombinedMass}[u]$ 交给 $a$（调用 `update(a, mass[u])`），最后并查集里 $u$ 指向 $a$。

并查集的代表元取"合并集合里位置最高的那头牛"的编号，于是 $\texttt{find}(p)$ 恰好给出黑点 $p$ **当前**上方的白点（这也是白点合并必须朝上合并的原因）。每个白点一生只被合并有限次，所以总复杂度是均摊的。

牛 $a$ 离开时：先 `mergeNode` 它的每个孩子白点（这些白点原本是它与孩子们的友谊），再 `update(find(a), -1)` 删掉它自己这个黑点，输出答案。
