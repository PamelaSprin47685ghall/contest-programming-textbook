# P3　列车调度（Train Scheduling）

## 题目

Bessie 要调度一条连接 A、B 两个车站的单轨铁路。一列车在时刻 $t$ 从某站出发，会在 $t+T$ 到达另一站（$1 \le T \le 10^{12}$）。

有 $N$ 班列车（$1 \le N \le 5000$）需要排时刻表：第 $i$ 班必须在 $s_i$ 站（$s_i \in \{A,B\}$）于 $t_i$ 或之后出发（$0 \le t_i \le 10^{12}$）。轨道上不允许同时有相向而行的列车（会相撞），但同向的列车可以同时在轨（列车尺寸忽略不计）。

若第 $i$ 班实际在 $a_i \ge t_i$ 时刻出发，总延误定义为 $\sum_i (a_i - t_i)$，求最小的总延误。

## 输入

第一行两个整数 $N$ 和 $T$。

接下来 $N$ 行，第 $i$ 行是车站 $s_i$（字符 `A` 或 `B`）和时刻 $t_i$。

## 输出

一个整数：最小的总延误。

## 样例

输入：

```text
1 95
B 63
```

输出：

```text
0
```

只有一班列车，准点发出即可。

## 思路

把每班列车的占轨时间看成区间 $[a_i, a_i+T]$。相向而行的一对列车区间不能有正长度交集，而刚好一列车到站、对面同时发车是允许的：于是约束可以写成——**任意两班相向而行的列车，出发时刻之差至少为 $T$；同向列车之间没有任何限制**。

于是把方案想象成"锚点"序列。所谓锚点，就是"当前最后发出、且按原始时刻准点发出的一班车"。设锚点在 $s$ 侧、时刻为 $t_0$，那么：

- 可以继续在 $s$ 侧发车，下一班（按原始时刻排序的下一班）准点发出也不产生任何延误，成为新的锚点；
- 也可以换向：对向所有"已经就绪"（$t_i \le t_0 + T$）的列车就在 $t_0+T$ 就地发出——这是它们最早能出发的时刻，代价是 $\sum (t_0+T-t_i)$；再往后每隔 $T$ 都有一次换向机会，每次把当时那一侧所有已就绪的列车就地发出；中途可以停在其中某一侧，让它的下一班车准点发出，成为新的锚点。

据此设计 DP：`dp[s][a][b]` 表示两侧分别已经发出 $a$、$b$ 班列车，最后一次发出的是 $s$ 侧第 $a$ 班（且它准点发出，即锚点）时的最小总延误（另有隐含约束：锚点的原始时刻大于另一侧已发出列车的原始时刻，保证不会重复统计）。转移分两类：

1. **同侧续发**：$s$ 侧第 $a+1$ 班准点发出，转入 `dp[s][a+1][b]`，延误不变，$O(1)$；
2. **换向**：先算出 `dp2[s][a]`——从 `dp[s][a][b]` 换向、并把对向所有就绪列车就地发掉后的最小代价（对每个 $b$ 汇总取最小）。从 `dp2` 出发，枚举继续换向的次数 $k=1,2,\dots$：第 $k$ 次换向的时刻是 $t_0 + kT$，方向两侧交替，每一轮把该侧所有 $t_i \le t_0+kT$ 的列车就地发出并累加延误；若某一轮两侧都发完了就更新答案，否则可以停在当前侧、让它的下一班车准点发出（写入某个 `dp` 状态）。换向次数不会超过 $N$。

处理顺序是：两个指针分别指向两侧下一班未当锚点的列车，每次处理原始时刻更小的那一侧，这样能保证写入的 `dp` 状态在被读取之前已经就绪。

两点说明：

- 为什么只把"准点发车"的状态当作锚点：任何被推迟的列车，其出发时刻一定落在某次换向的就地清车里；而已就绪的列车越早发越好（延误最小，且同向发车互不干扰），所以把它们立即发掉不会更差。
- 代码里给代价设了封顶 `CAP = 2e18`：总是存在总延误不超过 $N \cdot (\max t_i + T) \le 10^{13}$ 的可行方案（先把一侧的列车全部准点发完，另一侧的列车都推迟到 $\max t_i + T$ 之后），所以代价超过 $2 \times 10^{18}$ 的方案绝不可能最优，封顶不会影响答案，还能避免 64 位整数相加溢出。

## 复杂度

`dp` 状态数为 $O(N^2)$，每个状态 $O(1)$ 转移；`dp2` 状态数为 $O(N)$，每个要枚举 $O(N)$ 次换向。总时间 $O(N^2)$。空间为 $O(N^2)$（按两侧实际列车数分配，最坏约 $N^2/4$ 个 64 位整数）。
