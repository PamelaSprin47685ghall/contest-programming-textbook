# P1　岛屿度假（Island Vacation）

## 题目

有 $N$ 座岛（$2 \le N \le 10^4$）与 $M$ 条双向桥（$N-1 \le M \le \frac{3}{2}(N-1)$），图连通、无重边自环，且**每条边至多属于一个简单环**（这样的图称为仙人掌 cactus）。

Bessie 从 $1$ 号岛出发，重复下面的过程：

- 若当前岛 $i$ 没有尚未走过的相邻桥，度假结束；
- 否则，以 $\bmod 10^9+7$ 意义下等于 $p_i$ 的概率结束度假；
- 否则，在所有尚未走过的相邻桥中**等概率**随机选一条走过去。

对每座岛，求出她在该岛结束度假的概率 $\bmod 10^9+7$。

## 输入

第一行整数 $T$（$1 \le T \le 10$），相邻两个测试点之间有一个空行。

每个测试点第一行 $N,M$，第二行 $N$ 个整数 $p_1,\dots,p_N$（$0 \le p_i < 10^9+7$），随后 $M$ 行每行一条桥 $u_i\ v_i$。所有测试点 $N$ 之和不超过 $10^4$。

## 输出

对每个测试点输出一行 $N$ 个整数，表示 $1 \dots N$ 号岛上结束度假的概率。

## 样例

输入：

```text
2

3 2
0 10 111111112
1 3
2 3

6 5
500000004 0 0 0 0 0
1 5
1 3
4 5
5 6
1 2
```

输出：

```text
0 888888896 111111112
500000004 166666668 166666668 83333334 0 83333334
```

## 思路

以 $1$ 为根做 DFS，得到 DFS 树。无向图 DFS 的非树边一定连接祖先与后代，因此每个环都可以写成"环顶 $v$（深度最小的点）→ 沿父子链一路向下到 $u$ → 非树边 $(u,v)$"的形式。

对顶点 $i$，把"父边"分成两类：

- 父边是**桥**：唯一进入 $i$ 的方式就是走过这条桥，之后只能呆在 $i$ 的子仙人掌 $T_i$ 里，永不返回；
- 父边在**环**上：进入 $i$ 时，环的另一条边还没有走过，它是 $T_i$ 唯一的出口。一旦走它就再也回不到 $T_i$ ——称它为 $i$ 的**逃逸边**。

于是每个点首次被访问时的状态完全确定：未走过的边 = $T_i$ 内部的边 + 可能还有一条逃逸边，记这个数目为 $d_i$。

定义两个量：

- $z_i$（逃逸概率）：从 $i$ 出发（此时状态如上），最终用掉逃逸边（若没有逃逸边则 $z_i=0$）的概率；
- $v_{i,j}$（访问概率）：从 $i$ 出发，最终访问到后继 $j$ 的概率。"后继"指：父边是桥的儿子，以及以 $i$ 为环顶的环上其余全部顶点。

再把"从 $i$ 走完整整一圈环 $C$ 又回到 $i$"的概率记作 $z_C=\prod_{j\in C,\,j\ne i} z_j$（两个方向概率相同，因为路径上要依次逃逸的点集恰好都是 $C\setminus\{i\}$）。

**为什么要用生成函数。** 在 $i$ 处，只要还没结束，Bessie 会一直重复"要么选中环（两个方向各一条边，概率 $2/(d_i-2h)$，并以 $z_C$ 绕回来），要么选中那条指定的边"。完整走完 $k$ 个环后选边与绕回的顺序可以任意，所以

$$p_{\text{edge}}=\sum_{k=0}^{K} k!\,2^k\,(1-p_i)^{k+1}\Big(\prod_{h=0}^{k}\frac{1}{d_i-2h}\Big)e_k,$$

其中 $K$ 是以 $i$ 为环顶的环数，$e_k=\sum_{|S|=k}\prod_{C\in S}z_C$ 是 $z_C$ 的初等对称多项式。把 $\prod_C(1+z_Cx)$ 展开就得到全部 $e_k$（$O(K^2)$）。而"选中**指定环 $C$ 的两条边之一**"的概率，只需把生成函数除以 $(1+z_Cx)$（$O(K)$ 倒着做一次乘法即可还原），再代入同一个权重公式即可。于是：

- $z_i$ 与"父边是桥的儿子 $j$ 的 $v_{i,j}$"都等于 $p_{\text{edge}}$；
- 环上后继由两个方向分别累乘：从 $i$ 沿环一个方向走到 $j$，路上经过的每个点都要用掉自己的逃逸边，故 $v_{i,j}=y\cdot\prod z_k$（$y$ 为"选中该环指定一条边"的概率，$k$ 取路径上严格在 $i,j$ 之间的点）。

**最后统计答案。** 自顶向下传递 $P_i$（走到 $i$ 的概率，$P_1=1$，$P_j=P_i\cdot v_{i,j}$）。Bessie 恰好停在 $i$，当且仅当她走到了 $i$，且：

- 没有用掉 $i$ 的逃逸边；并且
- 没有"走到某个后继 $j$ 后就永远困在 $T_j$ 里"（该事件概率为 $v_{i,j}(1-z_j)$）。

这些事件互不相交，故

$$\text{ans}_i=P_i\Big(1-z_i-\sum_{j\ \text{是}\ i\ \text{的后继}}v_{i,j}(1-z_j)\Big).$$

对桥儿子有 $z_j=0$，公式自动包含"进去就出不来"的情形。两次 DP 都只需按深度顺序扫描，环上链的总长度是 $O(N)$。

## 复杂度

设 $K_i$ 为以 $i$ 为环顶的环数，则时间为 $O\!\left(N+\sum_i K_i^2\right)\le O(N^2)$（取模运算下 $N\le 10^4$ 时约 $10^7$ 次），空间为 $O(N+M)$。
