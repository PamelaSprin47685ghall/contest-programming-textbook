# P2　最大值之和最小化（Minimum Sum of Maximums）

## 题目

Bessie 有 $N$（$2 \le N \le 300$）块瓷砖排成一排，gugliness 值依次为 $a_1, a_2, \dots, a_N$（$1 \le a_i \le 10^6$）。其中 $K$（$0 \le K \le \min(N, 6)$）块瓷砖被固定住不能移动，位置为 $x_1 < x_2 < \dots < x_K$。

她可以做任意多次操作：选两块**都未被固定**的瓷砖交换。定义总 ugliness 为
$$\sum_{i=1}^{N-1} \max(a_i, a_{i+1}),$$
求操作后能取到的最小值。

## 输入

第一行两个整数 $N$ 和 $K$。

第二行 $N$ 个整数 $a_1, \dots, a_N$。

第三行 $K$ 个整数 $x_1, \dots, x_K$（$K = 0$ 时这一行为空）。

## 输出

一个整数，表示最小的总 ugliness。

## 样例

样例 1（$K = 0$）：

输入：

```text
3 0
1 100 10
```

输出：

```text
110
```

样例 2（$K = 1$）：

输入：

```text
3 1
1 100 10
3
```

输出：

```text
110
```

样例 3（$K = 1$）：

输入：

```text
3 1
1 100 10
2
```

输出：

```text
200
```

样例 4（$K = 2$）：

输入：

```text
4 2
1 3 2 4
2 3
```

输出：

```text
9
```

## 思路

**补哨兵。** 在位置 $0$ 和 $N+1$ 各补一块值为 $10^6$ 的"固定瓷砖"（$10^6$ 不小于任何 $a_i$，故不影响相邻的 $\max$）。这样每个未固定瓷砖都夹在两块固定瓷砖之间，代价 $\sum_{i=1}^{N-1}\max(a_i,a_{i+1})$ 就等于"含哨兵的全部相邻对之和"减去 $2 \cdot 10^6$。

**分段。** 相邻两块固定瓷砖之间称为一个**段**：段由端点值 $m_i = \min(a_l, a_r)$、$M_i = \max(a_l, a_r)$ 与长度 $len_i$（段内未固定瓷砖数）描述，$\sum len_i = N - K$。段内未固定值记为 $b_{i,1}, \dots, b_{i,len_i}$，并记 $b_{i,0} = m_i$、$b_{i,len_i+1} = M_i$。

**段内升序最优。** 用 0-1 原理：把每个值换成"是否 $> v$"的 0/1 串后，每个 $v$ 上是排序更优，故原问题也排序更优。又因为一段的代价在整体反转下不变，所以"从 $m$ 升序到 $M$"的模型与真实摆放一一对应。此时该段的代价为
$$\max(m_i, b_{i,1}) + b_{i,2} + \dots + b_{i,len_i} + \max(b_{i,len_i}, M_i).$$

**拆分常数项。** 所有段的这类和加起来后，
$$\text{总值} = \underbrace{\sum_{\text{未固定值}} c + \sum_i M_i + \sum_{len_i = 0}\max(a_l,a_r)}_{\text{固定}} + \sum_i \Big[\max(m_i, b_{i,1}) - b_{i,1} + \max(b_{i,len_i}, M_i) - M_i\Big].$$
所以只需最小化"修正量"之和，而修正量只取决于每段分到的**最小值与最大值**。

**结构引理。** 存在最优解，使任意两段的取值区间要么互相包含、要么不相交。证明思路：把两段合起来的值按大小列出，若出现"交错"（后面的值分给了另一段且能交换），交换后大的段的最小值变大、小的段的最大值变小，而修正量关于前者递减、关于后者递减，故不会变差；反复消去逆序即可。

**区间 DP。** 把所有未固定值升序排成 $c_1 \le c_2 \le \dots \le c_{N-K}$（下标从 $1$ 开始）。设 $dp[L][R][mask]$ 为：把 $c_L, \dots, c_R$ 中的值分配给 $mask$ 里的**所有**段（可以剩下一些值不用）所需的最小修正量，要求这些段恰好被填满。转移有三类：

1. 两端不用：$dp[L][R][mask] \leftarrow dp[L+1][R][mask]$、$dp[L][R-1][mask]$（仅在 $mask$ 需要的值数 $< R-L+1$ 时成立）。
2. 两端属于同一段 $k$：该段的最小值就是 $c_L$、最大值就是 $c_R$（长度 $1$ 的段要求 $L = R$），修正量立刻算出，再递归到 $dp[L+1][R-1][mask \setminus \{k\}]$。
3. 拆成两个不相交的非空段集 $sub_1, sub_2$：由结构引理，最优时 $sub_1$ 恰好用掉前缀 $c_L, \dots, c_{L+len(sub_1)-1}$，于是 $dp[L][M][sub_1] + dp[M+1][R][sub_2]$，其中 $M$ 由 $sub_1$ 的总长度唯一确定。

答案是 $dp[1][N-K][\text{全部段}]$ 加上前面的固定项，再减去 $2 \cdot 10^6$。

**细节。** $K = N$（全部瓷砖被固定）时不存在任何长度为正的段，此时 $dp$ 值为 $0$，答案就是原数组直接算出的 $\sum \max(a_i,a_{i+1})$（实现中长度 $0$ 的段由 `addon` 累加相邻固定值的 $\max$，恰好覆盖这种情况）。$K=1$ 时则是官解中的特例。

## 复杂度

状态数 $O(N^2 2^K)$，每个状态枚举子掩码与段 $O(3^K)$，总时间 $O(N^2 3^K)$，空间 $O(N^2 2^K)$；由于 $K \le 6$（段数 $\le 7$），$N = 300$ 时约 $10^8$ 次简单运算，实测远小于时限。
