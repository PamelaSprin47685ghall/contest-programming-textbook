# P1　身份盗用（Identity Theft）

## 题目

农夫约翰有 $N$（$1 \le N \le 10^5$）头奶牛，每头牛有一个由 `0`、`1` 组成的**农场编号**位串。最年长的奶牛 Bessie 记住了所有编号，喜欢到处问奶牛它们的编号。

被问到时，奶牛会开始念出正确的编号，但可能犯糊涂而**提前停下**。Bessie 听到这个位串后：如果它不是农场上任何一头奶牛的编号，她就耸耸肩走开；但如果它是另一头奶牛的编号，她就会认为发生了**身份盗用**并封锁农场。注意：一头牛即使念完自己的完整编号也可能引发这种情况。

农夫约翰想避免封锁，愿意通过给编号**末尾**追加 bit 来修改奶牛们的编号：一秒可以把任意一头奶牛的编号末尾追加一个 bit。求他最少需要多少秒才能让封锁永远不会发生。

（原题时限与空间分别为 3s 和 512MB，是平时的 1.5 倍与 2 倍。）

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行一个非空的位串，表示一头奶牛的编号。所有编号的总长度不超过 $10^6$。

## 输出

一行一个整数，表示最少的秒数。

## 样例

输入：

```text
3
1
1
1
```

输出：

```text
5
```

样例解释：给分别补上 `0`、`10`、`11`，编号变成 `10`、`110`、`111`，共花 5 秒；可以证明 4 秒内做不到。

## 思路

**问题转化。** 不会封锁等价于：任意两头奶牛的编号**互不为前缀**（若 $x$ 是 $y$ 的前缀，念 $y$ 的牛就可能停在 $x$，Bessie 便听到了另一头牛的编号）。因为补位只能加在末尾，一个串的"活动范围"就是它的所有**延伸**，所以我们要给每个串选一个延伸，使选出的串两两无前缀关系（即对应一棵二叉树的叶子），并让追加的 bit 总数最少。

**trie 模型。** 把原串插入一棵二叉 trie：根代表空串，往左/右走一位相当于补一个 `0`/`1`。每个结点有三种状态：

- `FREE`：空闲，某个串可以直接落在这里（花费 = 落点深度 - 原串长度）；
- `IN_USE`：已被某个串占用，必是叶子；
- `BLOCKED`：是某个已占用串的祖先，串落在这里会和后代冲突，必须继续往下走。

**贪心。** 按原串长度**从大到小**处理：长串可选的位置最窄，应先安排。处理一个串（长度 $l$，当前位于深度 $l$ 的结点）时，最便宜的两种做法是：

1. 从它的结点出发按深度递增找到**第一个空闲结点**，深度 $d$，花费 $d - l$；
2. 把一个**已占用的叶子**（深度 $d$）往下推一格：它的串补 1 位，新串补到另一个儿子上（深度 $d+1$），花费 $1 + (d + 1 - l) = d - l + 2$。

这样做是安全的：用掉一个空闲叶子后它变成"占用叶子"，以后（面对更短的串）下推它反而要贵 2；下推占用叶子则换来两个更深 1 的占用叶子，也只会更贵。也就是说**现在最便宜的选择，将来仍然最便宜**，所以每次直接取当前最小值即可。

**实现。** 对每个不同的编号做一次扫描（重复出现的编号用计数累计）。扫描用两个按深度递增的队列：第一队列像 BFS 一样在后代里找结点，碰到空闲结点就立刻使用（并把它计入第二队列），碰到占用叶子则放进第二队列；第二队列存放可下推的占用叶子。每次比较两个队头的深度：如果第二队头深度 $+2$ 不超过第一队头深度，就下推更划算，下推它，否则继续从第一队列取结点。

由于下推次数等于编号数、给阻塞结点补出的兄弟结点数不超过总长度，整棵树的规模是 $O(\sum |s|)$，配合"每个不同编号只扫一次"，总复杂度为线性。
