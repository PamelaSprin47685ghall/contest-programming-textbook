# P2　拆分干草堆（Splitting Haybales）

## 题目

Farmer John 想在他最喜欢的两头奶牛 Bessie 和 Elsie 之间公平地分干草。他有 $N$（$1 \le N \le 2\cdot 10^5$）个干草堆，按**不增**顺序排好，第 $i$ 堆有 $a_i$ 单位干草（$2\cdot 10^5 \ge a_1 \ge a_2 \ge \dots \ge a_N \ge 1$）。

Farmer John 考虑把一段连续的干草堆 $a_l, \dots, a_r$ 分给两头牛。他按从 $l$ 到 $r$ 的顺序处理，每次把当前这一堆给**当前干草较少**的那头牛（若持平就给 Bessie）。

给出 $Q$（$1 \le Q \le 2\cdot 10^5$）个询问，每个询问含 $l, r, x$（$1 \le l \le r \le N$，$|x| \le 10^9$）。若一开始 Bessie 比 Elsie 多 $x$ 单位干草，求处理完 $a_l, \dots, a_r$ 之后 Bessie 比 Elsie 多多少（为负表示 Elsie 更多）。

## 输入

第一行一个整数 $N$。

第二行 $N$ 个整数 $a_1 \dots a_N$。

第三行一个整数 $Q$。

接下来 $Q$ 行，每行三个整数 $l, r, x$。

## 输出

$Q$ 行，每行一个整数表示对应询问的答案。

## 样例

输入：

```text
2
3 1
15
1 1 -2
1 1 -1
1 1 0
1 1 1
1 1 2
1 2 -2
1 2 -1
1 2 0
1 2 1
1 2 2
2 2 -2
2 2 -1
2 2 0
2 2 1
2 2 2
```

输出：

```text
1
2
3
-2
-1
0
1
2
-1
0
-1
0
1
0
1
```

样例解释：第 1 个询问中 Elsie 一开始多 2，第 1 堆（3 单位）给 Bessie，于是 Bessie 反而多 1；第 3 个询问中两人一开始持平，第 1 堆给 Bessie 后 Bessie 多 3；第 9 个询问中 Bessie 一开始多 1，第 1 堆给 Elsie 后 Bessie 少 2，第 2 堆又给 Elsie 后 Bessie 少 1。

## 思路

**状态量。** 记 $d$ 为 Bessie 比 Elsie 多的干草数，则处理第 $i$ 堆时：$d \le 0$ 就把 $a_i$ 给 Bessie（$d \mathrel{+}= a_i$），$d > 0$ 就给 Elsie（$d \mathrel{-}= a_i$）。每个询问就是问：从初值 $x$ 出发，经过 $a_l, \dots, a_r$ 后 $d$ 变成多少。

**离线扫描。** 把询问按左端点、右端点分别挂链，从左到右扫描 $a$，同时维护所有"已进入但还没回答"的询问当前的 $d$。若直接模拟是 $O(NQ)$，需要找一种能对同类询问**整体更新**的表示。

**变换去掉 0。** 令 $t = 2d - 1$、$a_i \leftarrow 2a_i$。这样所有 $t$ 都是奇数（永远不会等于 0），更新规则统一成：

$$t > 0 \Rightarrow t \mathrel{-}= a_i, \qquad t < 0 \Rightarrow t \mathrel{+}= a_i .$$

最后把 $t$ 还原成 $d = (t+1)/2$ 即可（$t$ 为奇数，所以整除无歧义）。

**四类松弛集合。** 处理完 $a_i$ 后，把所有 $t$ 按 $|t|$ 与 $a_i$ 的大小关系分成 4 类：

- `posSmall`：$0 < t < a_i$，`posBig`：$t > a_i$；
- `negSmall`：$-a_i < t < 0$，`negBig`：$t < -a_i$。

每一类用一个"懒标记有序集合"维护：`map` 里存**相对值**（实际值减去该集合的 `lazy`），对这一类整体加同一个常数只需改 `lazy`，是 $O(1)$ 的。因为 $a$ 单调不增，类别之间的搬动只发生在相邻两类之间：

1. $a_{i-1}$ 变成 $a_i$ 时阈值下降，`small` 里绝对值超过 $a_i$ 的**极端值**要升格成 `big`（两个集合各自从排序的一端弹出即可）；新进入的询问也先放进对应的 `small`，随后被同一轮搬动归位。
2. 执行第 $i$ 堆：`small` 里的值必定换号，而两类 `small` 的更新方向恰好相反（一个 $+a_i$ 一个 $-a_i$），所以只需各自改好 `lazy`、再**交换两个集合的指针**，就一次性完成了所有 `small` 的更新；`big` 里的值保持原符号，整体靠近或远离 0，直接改它们的 `lazy`。
3. 更新之后，绝对值掉到 $a_i$ 以下的 `big` 极端值又要降格回 `small`。

**合并等值询问。** 上面第 1、3 步都是"从一端弹出若干元素"，要让它们的总次数足够小，就必须保证同一集合内每个值只出现一次：从 `small` 升格进 `big` 的**互不相同**的值都落在长度只有 $a_{i-1}-a_i$ 的开区间内，于是总搬动次数是 $O(a_1 + Q)$。为此用**并查集**把当前取值相同的询问合并成一个结点（它们此后每一刻的值都相同），集合里每个值只保留一个代表；回答询问时先 `find` 到代表，答案就是"代表所在集合的 `lazy` + 代表的相对值"。
