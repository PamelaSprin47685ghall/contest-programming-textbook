# P3　激活机器人（Activating Robots）

## 题目

周长为 $L$（$1 \le L \le 10^9$）的圆周上，你和**一台**机器人初始都在位置 $0$。你可以沿圆周以每秒 $1$ 单位的速度顺时针或逆时针移动，所有移动都是连续的。

你的目标是总共放置 $R-1$ 台新机器人（$2 \le R \le 20$，且 $R$ 整除 $L$），使得最终**任意两台相邻机器人**沿圆周相距恰好 $L/R$。圆周上有 $N$（$1 \le N \le 10^5$）个激活点，第 $i$ 个激活点位于从 $0$ 起逆时针 $a_i$ 处（$0 \le a_i < L$）。当你**正好**位于某个激活点时，可以瞬间在该处放置一台机器人。

所有机器人（包括最初那台）都以每秒 $1/K$ 单位的速度逆时针移动（$1 \le K \le 10^6$）。求达成目标所需的最少时间。

## 输入

第一行四个整数 $L$、$R$、$N$、$K$。

第二行 $N$ 个整数 $a_1, a_2, \dots, a_N$。

## 输出

一行一个整数，表示最少时间。

## 样例

输入：

```text
10 2 1 2
6
```

输出：

```text
22
```

样例解释：逆时针方向无法快速到达激活点 $6$，改走顺时针 $4$ 秒到达。此时原机器人位于 $2$；再等 $18$ 秒，原机器人到达 $1 = L/2$ 处，我们立刻在 $6$ 放置机器人，两台机器人相距 $10/2 = 5$，目标达成。

## 思路

**转化为"机器人静止"的参考系。** 把所有机器人（包括我们自己的位移基准）一起扣掉它们的逆时针位移，即让参考系随机器人以 $1/K$ 的速度逆时针自转。于是各机器人在参考系里固定不动，激活点则以 $1/K$ 的速度顺时针移动；我们的逆时针速度为 $1 - 1/K = (K-1)/K$，顺时针速度为 $1 + 1/K = (K+1)/K$。注意 $K \ge 1$ 这一点很关键：$K = 1$ 时逆时针速度为 $0$，只能顺时针走或原地等。

**从"走到激活点等机器人"改成"走到机器人位置等激活点"。** 原问题里常见做法是走到某个激活点、再等机器人转过来；转化之后应当反过来：站到目标机器人的位置上，等激活点经过。这样做状态只与"站在哪台机器人的位置"有关，而与激活点无关，状态数从 $O(2^R R N)$ 降到了 $O(2^R R)$。

**两点间行走时间。** 在参考系里从 $y$ 顺时针走到 $x$ 的弧长为 $d = (x - y + L) \bmod L$，则顺时针耗时 $\lceil Kd/(K+1) \rceil$；逆时针耗时 $\lceil K(L-d)/(K-1) \rceil$（$K=1$ 时不存在，忽略）。两者取较小值即可（方向由我们自己选）。

**对齐（等待）时间。** 激活点 $a$ 在时刻 $t'$ 位于 $a - t'/K$。要让它恰好经过位置 $pos$，需要 $t' = K m$ 且 $m \equiv a - pos \pmod L$。因此取 $m_0 = \lceil t/K \rceil$，算出 $\text{residue} = (pos + m_0) \bmod L$，再在**排序后**的激活点数组里二分出环上顺时针第一个 $\ge \text{residue}$ 的激活点（越界则绕回 $L + a_1$），多走的距离 $d$ 就是需要多等的 $Kd$ 时间，即对齐时刻为 $K(m_0 + d)$。

**DP。** 要放置的 $R-1$ 台机器人必须落在位置 $L/R, 2L/R, \dots, (R-1)L/R$（原机器人已经在 $0$，共 $R$ 台等距）。设第 $i$ 台待放置机器人的位置为 $L/R \cdot (i+1)$，$i = 0, \dots, R-2$。定义 $dp[S][i]$：已经从 $0$ 号位置出发、把集合 $S$（其中 $i \in S$）中的机器人"走到并放好"所需的最少时间——这里存的是**到达第 $i$ 个机器人位置的时间上界**，还没有等待对齐。初始 $dp[\{i\}][i] = \text{hop}[i+1]$（从位置 $0$ 走到位置 $L/R \cdot (i+1)$ 的行走时间），答案就是对所有 $i$ 把 $dp[\text{full}][i]$ 对齐后取最小值。

转移时先取出状态 $(S, i)$，把它对齐成"激活点正好经过"的时刻 $t$，再走到下一个未放置机器人的位置 $j$：$dp[S \cup \{j\}][j] = \min(dp[S \cup \{j\}][j],\ t + \text{hop}[(j-i) \bmod R])$，其中 $\text{hop}$ 在程序里展开成 $2R$ 长度以省掉取模。

**为什么能把"等待"推迟到状态上做（本题相对于 $R \le 16$ 做法的关键一步）。** 官方的次优做法是在每条转移边里"走完立刻二分对齐"，多了一个 $\log N$ 因子。而等待函数关于到达时间单调不减，因此"先取最小值再对齐"与"先各自对齐再取最小值"结果相同：完全可以把每条边只做加法，等真正取出状态 $(S,i)$ 时统一对齐一次。这样每个状态只做一次二分，复杂度从 $O(2^R R^2 \log N)$ 降为 $O(N \log N + 2^R R (R + \log N))$。
