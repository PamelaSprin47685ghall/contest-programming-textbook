# P2　哞叫时刻（It's Mooin' Time）

## 题目

Bessie 有一个长为 $N$（$1 \le N \le 3\times 10^5$）、只由字符 `M` 和 `O` 组成的字符串。把第 $i$ 个字符改成另一个字符需要花费 $c_i$（$1 \le c_i \le 10^8$）。

Bessie 希望字符串里出现更多长度为 $L$（$1 \le L \le \min(N,3)$）的 moo：一个长度为 $L$ 的 moo 就是一个 `M` 后面紧跟 $L-1$ 个 `O`。

对每个正整数 $k=1,2,\dots,\lfloor N/L\rfloor$，求出让字符串**至少包含 $k$ 个**等于长为 $L$ 的 moo 的子串所需的最小代价。

## 输入

第一行两个整数 $L$ 与 $N$。

第二行是长为 $N$ 的字符串，只含 `M` 和 `O`。

第三行是 $N$ 个用空格分隔的整数 $c_1,\dots,c_N$。

## 输出

输出 $\lfloor N/L\rfloor$ 行，依次给出 $k$ 从小到大每个 $k$ 的答案。

## 思路

先注意一个重要性质：同一个字符串里，两个长度相同的 moo 出现位置**不可能重叠**。因为 moo 只有第一位是 `M`、其余全是 `O`；若两次出现相距 $d<L$，则第 $d$ 个字符既要当第一次出现里非首位的 `O`，又要当第二次出现的首位 `M`，矛盾。因此"至少 $k$ 个 moo"等价于"选出 $k$ 个互不重叠的 moo 出现位置使其总花费最小"，问题变成在候选出现位置里选 $k$ 个互不相交的区间。

预先算出以每个位置 $i$ 为起点做出一个 moo 的代价 $a_i$（$i \le N-L$）。

**$L=1$.** 每个 moo 只占一个字符，各位互相独立：把已经是 `M` 的位置代价记 0，其余记 $c_i$，升序排序后求前缀和，第 $k$ 个前缀和就是答案。样例 1 即 $0,20,30,40$ 的前缀和。

**$L=2$.** 要选 $k$ 个**互不相邻**的起点。记相邻哨兵 $a_0=a_N=\infty$。经典做法是贪心：

- 每次取出当前代价最小的位置 $i$，把它计入答案；
- 然后把 $a_{i-1},a_i,a_{i+1}$ 从链表里删掉，在同一位置放回 $a_{i-1}+a_{i+1}-a_i$。

放回值的含义是"反悔"：以后如果又选中了它，相当于撤销刚才的选择，改成同时选 $i-1$ 和 $i+1$。小根堆保存候选代价、双向链表保存相邻关系（堆里用惰性删除丢掉失效记录），每次操作 $O(\log N)$。

这个贪心之所以能**依次**给出每个 $k$ 的答案，是因为答案序列关于 $k$ 凸（第 $k$ 个增量随 $k$ 不减），贪心每次取出的恰好是下一个增量：第一次取出的最小值就是 $k=1$ 的答案；若后面取到与最小位置 $i$ 相连的新值，说明 $k$ 增大时最优解在 $i$ 附近发生了"换一个选法"的调整。于是每步输出当前累计和即可。

**$L=3$.** 直接沿用 $L=2$ 的"合并邻居"技巧不再成立，改用分治 + 凸序列归并：

- 记 $g(i,j)$ 为"某段区间在左端去掉 $i$ 个字符、右端去掉 $j$ 个字符（$0\le i,j\le L-1$）后，放 $t$ 个 moo 的最小代价序列"（下标 $t$ 从 0 取到区间长度整除 $L$）。
- 可以证明（见官方题解）每个 $g$ 都是关于 $t$ 的凸序列，即差分非降；两个凸序列的最小卷积可以用"谁的下一个差分小就走谁"的贪心在线性时间内归并。
- 分治时把区间 $[l,r)$ 从中点 $mid$ 拆成两半。跨中点至多放一个 moo：它在左半占 $p$ 个字符、右半占 $L-p$ 个字符（$p=1,\dots,L-1$），代价为 $a_{mid-p}$，于是把左半的 $g(i,p)$、右半的 $g(L-p,j)$ 与"那个 moo"的最小卷积并进去；不跨中点则把 $g(i,0)$ 与 $g(0,j)$ 归并。区间短到放不下 moo 时序列就是 $\{0\}$。

因为 $L\le 3$，每个区间只需记录 $O(L^2)$ 条序列，每条序列长度是区间长 $/L$，每层归并总代价 $O(N)$，共 $O(\log N)$ 层。

用样例 2（$L=3,N=4$，串为 `OOOO`）体会 $a_i$：只有 $k=1$，把位置 $2$ 改成 `M` 得到 `OMOO` 要花 $c_2=40$，所以答案是 $40$；这里 $a_1=50+40+30$（改三位）、$a_2=40$（只改一位）。

## 复杂度

$L=1$：排序 $O(N\log N)$。$L=2$：堆与链表 $O(N\log N)$。$L=3$：分治归并 $O(N\log N)$（实际运行远快于上界）。空间复杂度均为 $O(N)$。
