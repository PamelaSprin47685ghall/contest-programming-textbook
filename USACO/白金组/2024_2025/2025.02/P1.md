# P1　最小最大子数组（Min Max Subarrays）

## 题目

给定长度为 $N$（$2 \le N \le 10^6$，$1 \le a_i \le N$）的整数数组 $a_1, a_2, \dots, a_N$。

对任意一个非空整数列表，依次交替进行以下操作（从第一个操作开始），直到列表大小恰好为 1：

- 把列表中两个相邻的整数替换为它们的**最小值**；
- 把列表中两个相邻的整数替换为它们的**最大值**。

问最后剩下的整数最大可能是多少。输出**所有** $N(N+1)/2$ 个连续子数组这一子问题答案之和。

例如：

```text

[4, 10, 3] -> [4, 3] -> [4]
[3, 4, 10] -> [3, 10] -> [10]

```

## 输入

第一行一个整数 $N$。

第二行 $N$ 个整数 $a_1, a_2, \dots, a_N$。

## 输出

输出一行一个整数，表示所有子数组答案之和。

## 样例

输入：

```text
2
2 1
```

输出：

```text
4
```

解释：$[2]$ 的答案是 2，$[1]$ 的答案是 1，$[2,1]$ 的答案是 1，故总和为 $2+1+1=4$。

## 思路

**第一步：先搞清楚单个数组的答案长什么样。**

记长度（元素个数）为 $L$：

- 最后一次操作是第 $L-1$ 次操作。$L$ 为偶数时第 $L-1$ 次是 max，$L$ 为奇数时是 min。
- 由 0-1 原理（把每个数与阈值比较变成 0/1 再游戏，结果不变），可以只考虑 0/1 数组；对 $L \ge 5$ 的奇数长度用归纳可以证明：**答案几乎总是最大值**；对 $L \ge 8$ 的偶数长度同理可证：**答案几乎总是次大值**（偶数长度最后一次操作必为 min，所以取不到最大值）。
- 更精确地说：
  - $L = 1$：答案就是该元素（也是最大值）；
  - $L = 2$：第一次就是 min，答案是较小值（也是次大值）；
  - $L$ 为奇数且 $L \ge 5$：答案为最大值；
  - $L$ 为偶数且 $L \ge 8$：答案为次大值；
  - 只有 $L = 3, 4, 6$ 会偏离上述规律，需要单独修正。

**第二步：对"奇数取最大值、偶数取次大值"这个规律求和。**

把每个下标 $i$ 看作"打破平局后的更大者"：定义全序：先比值，值相同再比下标（值大的优先，值相同下标大的优先）。处理所有下标，按 $(a_i, i)$ 升序做：

- 把 $a_i$ 从小到大处理，把处理过的下标从"活跃集合"里删掉，用**双向链表**维护每个下标的左、右最近活跃邻居 $l_i, r_i$。这样 $l_i$、$r_i$ 就是 $a_i$ 的左、右两侧首个"排位更高"的元素。
- 一个子数组把 $a_i$ 记为答案（作为最大值）当且仅当它包含 $i$、且不含其它活跃元素：即左端点 $lo \in [l_i+1, i]$，右端点 $hi \in [i, r_i-1]$。奇数长度要求 $hi - lo$ 为偶数（$lo, hi$ 同奇偶）。用前缀奇偶计数相乘即可 $O(1)$ 统计。
- 一个子数组把 $a_i$ 记为答案（作为次大值）当且仅当它包含 $i$、且恰含另一个活跃元素，且这个活跃元素只能是 $l_i$ 或 $r_i$（否则中间还夹着别的活跃元素）。偶数长度要求 $lo, hi$ 奇偶不同。同样 $O(1)$ 统计这两种情况。

每个下标被处理一次、C++ 中删除是 $O(1)$，于是"规律和"整体 $O(N)$ 算出。

**第三步：修正长度 3、4、6。**

对 $L \in \{3, 4, 6\}$：

- 先用上面的 DP（对全部 $2^L$ 个 0-1 数组做"可达状态集合"搜索）预处理出每个 0-1 数组的真实答案 `pre[mask]`。
- 再对数组内的每个长度为 $L$ 的窗口求真实答案：把窗口内元素按值从大到小逐个加入集合，第一个使 0-1 数组 `pre[mask] = 1` 的值就是真实答案（这正是 0-1 原理的"阈值翻转"表述：答案等于满足"把不小于它的元素标记为 1 后游戏结果为 1"的最大值）。
- 从总答案中减去规律值（奇数长度取最大值、偶数长度取次大值），再加上真实答案。

## 复杂度

"规律和"统计是 $O(N)$；长度 3、4、6 的修正每窗口 $O(L \log L)$ 但 $L \le 6$，总计 $O(N)$；预处理 $O(2^L \cdot 2^L \cdot L)$ 是常数。总时间复杂度 $O(N)$，空间复杂度 $O(N)$（数组、双向链表与计数排序桶）。
