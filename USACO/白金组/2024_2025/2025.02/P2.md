# P2　变换数对（Transforming Pairs）

## 题目

回答 $Q$（$1 \le Q \le 10^5$）组独立询问，每组给出四个整数 $a,b,c,d$（绝对值不超过 $10^{18}$）。

一次操作可以执行 $a \mathrel{+}= b$ 或 $b \mathrel{+}= a$。求把 $(a,b)$ 变成 $(c,d)$ 所需的**最少操作次数**，若不可能则输出 $-1$。

## 输入

第一行一个整数 $Q$。

接下来 $Q$ 行，每行四个整数 $a, b, c, d$。

## 输出

每组询问输出一行，表示最少操作次数或 $-1$。

## 样例

输入：

```text
4
5 -3 -1 -3
5 3 5 2
5 3 8 19
5 3 5 3
```

输出：

```text
2
-1
3
0
```

第一组：$(5,-3) \to (2,-3) \to (-1,-3)$；第二组不可能；第三组：$(5,3) \to (8,3) \to (8,11) \to (8,19)$；第四组不需要操作。

## 思路

操作是可逆的：倒着看，每一步是把一个坐标**减去**另一个坐标。问题变成"从 $(c,d)$ 出发做减法，最少几步到 $(a,b)$"。关键观察：

**一、先把 0 处理掉。**

- 起点有 0 坐标时（如 $a=0$）：$a \mathrel{+}= b$ 与 $b \mathrel{+}= a$ 里只有一个是有效操作（加 0 是空操作），所以第一步是确定的；两个坐标都是 0 则只要目标不是 $(0,0)$ 就永远停在原地。
- 终点有 0 坐标时同理倒推：$c=0$ 说明最后一步必然是把 $d$ 加到了 $c$ 上，倒推一步 $(0,d) \leftarrow (-d,d)$。

**二、符号模式。**

两个坐标的符号组合只有有限几种，路径一旦进入"两个坐标同号"，就会永远保持同号（正数加正数、负数加负数），进入"两个坐标异号"后则可能在某个时刻翻转。逐类讨论（可通过取反全部坐标、交换两个坐标把情形归一）：

- **起点同号**：终点必须同号同向，否则 $-1$。之后（取绝对值）两个正数对之间只能"大减小"——每一步选择唯一，用类欧几里得的整除跳跃 $O(\log)$ 模拟即可。
- **起点、终点都是 $(正,负)$**：符号不变，同样取绝对值后"大减小"，模拟判断能否恰好到达。
- **起点 $(正,负)$，终点 $(负,正)$**：从 $(正,负)$ 出发永远只会到达 $(正,负)$、$(正,正)$、$(负,负)$，所以不可能，$-1$。
- **起点 $(正,负)$，终点 $(正,正)$**：路径分为两段——前缀里第二坐标始终 $\le 0$（第一坐标必须保持为正，否则无法回头），到某一步 $b \mathrel{+}= a$ 使第二坐标变正，此后两个坐标全正，"大减小"的走法唯一。

**三、压缩枚举 + 相遇。**

最后一种情形是唯一有选择的：在"第一坐标的绝对值 > 第二坐标的绝对值"的状态上，既可以继续 $a \mathrel{+}= b$，也可以 $b \mathrel{+}= a$ 跳进正数区。这些决策点连成若干等差数列（每一步两个坐标同减 $|b|$），共 $O(\log)$ 段；另一边，从终点倒推的正数链也是 $O(\log)$ 段等差数列（每段是"一个坐标连续减另一个坐标"）。

于是答案 = 两族段的公共状态中 $\min(\text{前缀步数} + \text{后缀步数})$。两族段按坐标和严格有序，用双指针只比较"坐标和区间重叠"的段对，段内解一个二元一次方程组即可 $O(1)$ 判断是否有交点。

## 复杂度

每组询问 $O(\log(\max|a|,|b|,|c|,|d|))$：两条链各 $O(\log)$ 段，双指针后实际比较的段对数是 $O(\log)$。总时间复杂度 $O(Q \log 10^{18})$，空间复杂度 $O(1)$（每段的常数个信息，$Q$ 组询问互不影响）。
