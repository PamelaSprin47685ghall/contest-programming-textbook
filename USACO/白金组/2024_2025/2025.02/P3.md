# P3　真假测试（True or False Test）

## 题目

Bessie 要参加一场有 $N$（$1 \le N \le 2 \times 10^5$）道判断题的考试。第 $i$ 题答对得 $a_i$ 分，答错扣 $b_i$ 分，不答不得分也不扣分（$0 < a_i, b_i \le 10^9$）。

Bessie 知道所有答案，但担心 Elsie 会在考试后把最多 $k$ 道她**答对**的题目改掉，使那些题不得分（即她在那道题上不仅拿不到 $a_i$，还要被扣 $b_i$）。

给定 $Q$（$1 \le Q \le N+1$）个互不相同的 $k$（$0 \le k \le N$），对每个 $k$ 求：在"必须至少作答 $k$ 道题"的前提下，Bessie 能**保证**得到的最多分数。

## 输入

第一行两个整数 $N$ 和 $Q$。

接下来 $N$ 行，每行两个整数 $a_i, b_i$。

接下来 $Q$ 行，每行一个 $k$。所有 $k$ 互不相同。

## 输出

对每个 $k$ 输出一行，表示对应的最优保证分数。

## 样例

输入：

```text
2 3
3 1
4 2
2
1
0
```

输出：

```text
-3
1
7
```

## 思路

Elsie 会改掉 Bessie 作答的题目中 $a_i + b_i$ 最大的 $k$ 道（改一道题让 Bessie 净损失 $a_i + b_i$）。

**观察 1（最优作答的结构）。** 把题目按 $a_i + b_i$ 升序排序。若被改的题集是 $C$、其余作答的是 $U$，则排名靠后的题只可能进入 $C$。由于 $a_i > 0$，凡是留在 $U$ 里的题都应尽量取"排名更小"的题——最终最优结构是：

- 取排序后的一个前缀 $1..p$：它们永远不会被改，纯赚 $\sum_{i \le p} a_i$；
- 再从后缀 $p+1..N$ 里选 $k$ 道作答：它们恰好就是被改掉的 $k$ 道，净收益 $-b_i$，因此应选后缀中 $b$ 最小的 $k$ 道。

于是对固定 $k$：

$$\text{ans}[k] = \max_{0 \le p \le N-k}\Big(\text{prefA}[p] - S_k(p)\Big),\qquad S_k(p)=\sum_{\text{后缀 } p+1..N \text{ 中最小的 } k \text{ 个 } b}.$$

**观察 2（最优 $p$ 的单调性）。** 设 $p^*(k)$ 为最优前缀长度（平局取更大的 $p$），可以证明 $p^*(k+1) \le p^*(k)$：若 $k+1$ 的最优方案多答了一题而 $k$ 的没有，则把该题的收益代入 $k$ 或 $k+1$ 的方案会立即改进，三种大小关系各自导出矛盾（详见官方题解）。

**算法。**

- 用**分治**处理 $k$：先求区间中点 $k_{\text{mid}}$ 的最优 $p$（在合法范围内线性扫描），再按单调性把 $k < k_{\text{mid}}$ 的 $p$ 下界、$k > k_{\text{mid}}$ 的 $p$ 上界收窄，递归两侧。总扫描量 $O(N \log N)$。
- 扫描过程中需要快速计算 $S_k(p)$：即"给定后缀中最小的 $k$ 个 $b$ 之和"。把问题按 $a+b$ 排序后，对每个前缀建一棵**可持久化线段树**（按 $b$ 的排名为值域），版本差 `versionN - versionP` 就表示后缀 $p+1..N$；在线段树上从根往下走，左侧个数 $\ge k$ 就往左，否则整块取走再往右，单次 $O(\log N)$。

查询的 $k$ 直接输出 `ans[k]` 即可（$k$ 互不相同，但把全部 $k$ 都算出来更省事）。

## 复杂度

时间 $O(N \log^2 N)$（分治扫描 $O(N\log N)$ 次、每次求"最小 $k$ 个之和" $O(\log N)$）；空间 $O(N \log N)$（可持久化线段树，约 $N(\log_2 N + 1)$ 个节点）。
