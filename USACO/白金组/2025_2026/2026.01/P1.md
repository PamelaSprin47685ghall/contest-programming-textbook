# P1　蹄子、布、剪刀三元组（Hoof, Paper, Scissors Triples）

## 题目

你可能听说过"石头剪刀布"，奶牛们则玩一个类似的游戏："蹄子、布、剪刀"。蹄子砸碎剪刀，剪刀剪纸，纸割破蹄子，同种手势则打平。

现在有 $N$ 头奶牛互相比赛。第 $i$ 头奶牛的策略是按固定的分布出手，它出蹄子、布、剪刀的概率分别是

$$\left(\frac{h_i}{h_i+p_i+s_i},\ \frac{p_i}{h_i+p_i+s_i},\ \frac{s_i}{h_i+p_i+s_i}\right)。$$

问有多少个互不相同的奶牛三元组 $(A,B,C)$，使得 $A$ **平均意义上**胜过 $B$、$B$ 胜过 $C$、$C$ 胜过 $A$？两个三元组只要循环移位后相同就算同一个。

## 输入

第一行一个整数 `T`（$1 \le T \le 5\cdot 10^4$），表示独立的测试组数。

每组测试第一行一个整数 `N`（$3 \le N \le 2\cdot 10^5$）。

接下来 `N` 行，每行三个非负整数 `h_i p_i s_i`（$0 \le h_i,p_i,s_i \le 10^9$，且 $h_i+p_i+s_i>0$）。

保证所有测试的 $N$ 之和不超过 $3\cdot 10^5$。

## 输出

对每组测试输出一行：满足条件的三元组个数。注意答案可能超出 32 位整数范围。

## 样例

输入：

```text

4

1 0 0
0 1 0
0 0 1
10
20410069 21445597 257862632

```

解释：第一组里只有 $(1,3,4)$ 和 $(2,3,4)$ 两个三元组（第 3 头牛总出布、第 4 头牛总出剪刀，两头总出蹄子的牛轮着当第一个）。

## 思路

**把胜负化成平面的方向比较。** 奶牛 $i$ 平均胜过 $j$，即它赢的概率大于输的概率：

$$h_is_j+p_ih_j+s_ip_j > h_js_i+p_jh_i+s_jp_i.$$

令 $x_i=h_i-s_i$，$y_i=p_i-s_i$（三个数同时加同一个常数不改变分布，所以这样化简不丢信息），把上式移项整理后，左式减右式恰好等于 $-(x_iy_j-y_ix_j)$。也就是说：

- $i$ 胜过 $j$ 等价于叉积 $x_iy_j-y_ix_j<0$，即把 $(x_i,y_i)$ 看成方向向量时，$j$ 的方向落在 $i$ 的方向**逆时针 $180^\circ$ 之内**；
- 两者打平等价于叉积为 $0$，即两个方向**共线**（同向或反向都可以：反向正是两手势互补的一对）。

概率均匀分布（$x=y=0$）的奶牛与所有奶牛打平，不可能出现在任何循环三元组里，直接删掉即可。

**循环三元组的几何刻画。** 设三个方向逆时针排列，相邻方向之间的三段"圆角"之和恒为 $360^\circ$。三者两两分出胜负，等价于没有共线对（没有圆角为 $0^\circ$ 或 $180^\circ$）；再要求首尾相接地互相取胜，等价于三段圆角全部**严格小于** $180^\circ$。所以

$$\text{答案}=\underbrace{\text{三对关系全部分出胜负的三元组数}}_{U}-\underbrace{\text{三个方向落在某个开半平面内的三元组数}}_{OPEN}.$$

落在开半平面内的三元组一定是"传递"型（一头牛胜另外两头），必然不是循环型，所以上式的减法正好剔掉它们。

**求 $U$。** 先把同方向的奶牛合并成方向类（按极角排序后相同方向必然相邻），设共有 $d$ 个方向类，第 $i$ 类有 $w_i$ 头牛、总牛数 $T$。

- $S_3$：三个方向互不相同的三元组数，用初等对称和滚动累加，$O(d)$：依次加入每个类，累加 $w_i\times$（已加入的类里选两类的方案数）。
- $S_{anti}$：含有一对相反方向（这对奶牛互相打平）的三元组数。每对相反方向 $\{a,b\}$ 贡献 $w_aw_b(T-w_a-w_b)$；遍历每个方向去查它的反方向，成对会被统计两次，最后除以 2。查反方向用极角序上的二分。
- $U=S_3-S_{anti}$。

**求 $OPEN$。** 一个落在开半平面内的三元组有唯一的一条"最顺时针"方向，所以只需对每个方向类 $i$ 统计它逆时针 $180^\circ$ 开区间内所有方向类的两两配对：若窗口内奶牛数之和为 $P$、奶牛数平方和为 $Q$，则配对数 $\frac{P^2-Q}{2}$。窗口内不允许出现相反方向（恰在 $180^\circ$ 处），而这正由"叉积 $>0$"的严格判断保证。

把方向类数组复制一份接在后面，用前缀和一次求出窗口的 $P$ 与 $Q$；再用单调指针定位每个 $i$ 对应的窗口右边界（$i$ 增大时右边界只会向右移），整个过程 $O(d)$。

**实现细节。** 方向要精确比较，不能用 `atan2`（坐标可达 $10^9$，浮点会把相邻方向判反）。这里先把 $(x,y)$ 用 $\gcd$ 约分成最简整数向量，于是"方向相同"就是"向量完全相等"；排序时按"上半平面（含正 $x$ 轴）在前、然后叉积 $>0$ 在前"的规则，全整数运算不会溢出（最简坐标绝对值不超过 $10^9$，叉积不超过 $2\cdot 10^{18}$）。另外注意 $(h_i-s_i,p_i-s_i)$ 与它的反向量代表**不同**的方向，合并方向类时不能把反方向也并进去。

## 复杂度

每个测试组的时间复杂度为 $O(N\log N)$（瓶颈是方向排序），空间复杂度 $O(N)$；总时间 $O\left(\sum N\log N\right)$。
