# P1　圆圈上的奶牛（Circle of Cows）

## 题目

农夫约翰有 $N$（$2\le N\le 1000$）头奶牛，它们位于周长 $C$（$N\le C\le 10^9$）的圆周上的互不相同的位置 $l_1<l_2<\dots<l_N$（$0\le l_1$，$l_N<C$）。

约翰要选出 $k$（$1\le k\le \lfloor N/2\rfloor$）对奶牛，每头奶牛至多出现在一对中。他想让"每一对奶牛之间沿圆周的最短距离"的最小值尽可能大。

对每个 $k$，求出这个最大可能的最小距离。

## 输入

第一行两个整数 $N$ 和 $C$。

第二行 $N$ 个整数 $l_1\dots l_N$，均匀分布在 $[0,C)$ 内且单调递增。

## 输出

输出一行 $\lfloor N/2\rfloor$ 个用空格分隔的整数，第 $i$ 个是 $k=i$ 时的答案。

## 样例

输入：

```text
4 100
0 25 50 75
```

输出：

```text
50 50
```

$k=1$ 时把 $0$ 和 $50$ 配对，距离为 $50$；$k=2$ 时把 $0$ 与 $50$、$25$ 与 $75$ 分别配对，最小距离仍是 $50$。（题面另给一组样例 `4 100 / 0 1 2 99`，答案为 `3 2`。）

## 思路

记两头牛 $a,b$ 的圆周距离为 $\text{cd}(a,b)=\min(|l_a-l_b|,\ C-|l_a-l_b|)$。若 $k$ 对奶牛的最小距离能取到 $d$，那么任意 $k'\le k$ 对也能取到 $d$（扔掉几对即可），所以答案关于 $k$ 单调不增，下面的做法对每个"最小距离"只需求出它最多能配出多少对。

**关键结论：对每个 $k$，都存在一组最优解使得任意两条被选中的弦（配对线段）在圆内相交。** 证明用交换论证：设两条不相交的弦是 $(p_1,p_2)$ 与 $(p_3,p_4)$（端点满足 $0\le p_1<p_2<p_3<p_4<C$），把它们换成 $(p_1,p_3)$ 与 $(p_2,p_4)$ 后，四条弦长分别变成 $p_3-p_1$ 与 $p_4-p_2$ 及其补弧。新弦正向长度变大（$p_3-p_1>p_2-p_1$，$p_4-p_2>p_4-p_3$），补弧长度要么不小于正向长度（不必担心），要么回落到 $C-(p_4-p_1)+(p_4-p_3)\ge p_4-p_3$，总之两条新弦的圆周距离都不小于原来的最小值；并且原本与 $(p_1,p_2)$ 相交的弦，交换后必定与 $(p_1,p_3)$ 或 $(p_2,p_4)$ 之一相交，相交对数不会减少。于是反复做这种交换即可把最优解变成"两两相交"的解。

两两相交意味着：沿圆周走一圈，$k$ 条弦的 $2k$ 个端点交替出现——每条弦的两个端点之间恰好隔着其余每条弦的一个端点。因此，**固定一条"基准弦"后，其余弦都夹在它的两个端点之间**：设基准弦为 $(i,j)$（$i<j$），则其他弦可以写成 $(i_2,j_2)$，其中 $i<i_2\le j$、$j<j_2<i+N$（把位置复制一份接到后面，$L_{t+N}=L_t+C$，避免取模），且这些弦两两相交。

设基准弦的圆周距离为 $d$，我们要在所有长度不小于 $d$ 的"夹层"弦中贪心地取最多条。用两根指针 $i_2\ (i+1\le i_2<j)$、$j_2\ (j+1\le j_2<i+N)$ 沿同一方向扫描，记 $\text{cur}=L_{j_2}-L_{i_2}$（正向弧长，恒有 $0<\text{cur}<C$，于是圆周距离为 $\min(\text{cur},C-\text{cur})$）：

1. $\text{cur}<d$：距离太小，把 $j_2$ 右移让 $\text{cur}$ 变大；
2. $C-\text{cur}<d$（即 $\text{cur}>C-d$）：走过头了，把 $i_2$ 右移让 $\text{cur}$ 变小；
3. 否则 $\text{cur}$ 与 $C-\text{cur}$ 都不小于 $d$，即这条弦的圆周距离合格，收下它，两根指针同时右移。

（交换论证同样保证：若存在一种用 $c$ 条夹层弦的方案，贪心至少也能收下 $c$ 条，所以对固定的基准弦贪心取到的条数 $cnt$ 是最大的。）循环在 $i_2=j$ 或 $j_2=i+N$ 时结束，因为此时所有端点的相对顺序已经绕完一圈。

于是枚举全部 $N(N-1)/2$ 条基准弦，每次得到 $(cnt,d)$，执行 `ans[cnt] = max(ans[cnt], d)`：含义是"用 $cnt$ 条弦可以把最小距离做到 $d$"。最后从大到小做后缀最大值 `ans[k] = max(ans[k], ans[k+1])`（$k=\lfloor N/2\rfloor$ 往下到 $1$），把"用更多弦也能达到的距离"传给更小的 $k$，即得每个 $k$ 的答案。

## 复杂度

时间 $O(N^3)$：枚举 $O(N^2)$ 条基准弦，每次双指针的指针总位移不超过 $N-2$，故内部是 $O(N)$。空间 $O(N)$。$N\le 1000$ 时约 $5\times 10^8$ 次极简操作，实测远快于时限。
