# P2　奶牛圆圈（Cow Circle）

## 题目

农夫约翰有 $N$（$1\le N\le 5000$）头奶牛，站在一条被等分为 $M$（$1\le M\le 10^6$）个位置的环形跑道上，位置编号 $0$ 到 $M-1$。奶牛 $i$ 初始位于 $x_i$，且 $0=x_1<x_2<\dots<x_N<M$。

每头奶牛 $i$ 独立地以概率 $p_i$ 选择顺时针出发、否则逆时针出发，方向一旦选定便以每分钟一个位置的速度匀速前进。任意两头奶牛相遇（占据同一空间）时立刻反弹，各自反向但速度不变。

对每个 $0\le i<M$，求 $K$（$1\le K\le 10^{18}$）分钟后奶牛 $1$ 恰好在位置 $i$ 的概率。

## 输入

第一行一个整数 $T$（$1\le T\le 100$），表示测试数据组数。

每组数据第一行三个整数 $N,M,K$；第二行 $N$ 个整数 $p_1,\dots,p_N$（若奶牛 $i$ 顺时针的概率为 $\frac{a_i}{b_i}$，则 $p_i\cdot b_i\equiv a_i\pmod{10^9+7}$）；第三行 $N$ 个整数 $x_1,\dots,x_N$。

保证所有测试数据的 $\sum N^2\le 5000^2$，$\sum M\le 10^6$。

## 输出

每组数据输出一行 $M$ 个用空格分隔的整数：第 $i$ 个是奶牛 $1$ 最终位于位置 $i$ 的概率，其中的分母取模 $10^9+7$ 的逆元。

## 样例

输入：

```text
3
2 2 1
500000004 500000004
0 1
3 3 1
500000004 500000004 500000004
0 1 2
5 10 13
500000004 1 500000004 0 500000004
0 3 4 7 9
```

输出：

```text
500000004 500000004
500000004 250000002 250000002
0 0 0 125000001 375000003 0 125000001 375000003 0 0
```

## 思路

**把弹开看成穿过。** 两牛相遇反弹，等价于两牛互不干扰地擦肩而过、只是**交换了标号**。于是可以把问题拆成 $2N$ 条固定轨迹：奶牛 $i$ 的顺时针轨迹是一条以 $x_i$ 为起点、每分钟前进一个位置的射线（模 $M$ 的匀速圆周运动），逆时针轨迹同理。我们要的是"标号 $0$（奶牛 $1$）最终落在哪条轨迹的终点"。

**顺序不变，所以只和相邻标号交换。** 牛的环形相对次序在运动过程中始终不变，因此每次相撞的两条轨迹承载的标号必然相邻：顺时针轨迹的标号 $+1$，逆时针轨迹的标号 $-1$。于是顺时针轨迹 $i$ 初始带标号 $i$，撞过 $T$ 次后带标号 $i+T$，它承载标号 $0$ 当且仅当

$$T\equiv -i \pmod N,$$

此时终点位置为 $(x_i+K)\bmod M$。（逆时针轨迹 $i$ 撞 $T'$ 次后带标号 $i-T'$，这一点通过镜像统一处理，见下。）

**数清碰撞次数。** 顺时针轨迹 $i$ 会与所有"起点落在它顺时针方向 $2K$ 弧内"的逆时针轨迹相撞，绕圈时重复计数。令 $L=\lfloor 2K/M\rfloor$、$E=2K\bmod M$，$A$ 为走逆时针的奶牛总数，$B$ 为落在弧 $[x_i,x_i+E]$（顺时针方向，含 $x_i$ 自身但自身此时定为顺时针故不计）内的逆时针牛数，则满圈部分贡献 $LA$、余弧贡献 $B$：

$$T=LA+B.$$

于是要求 $B\equiv -i-LA\pmod N$；又由 $A=B+C$（$C$ 为弧外的逆时针牛数）得到 $C=A-B$，所以只需要枚举 $A=0,\dots,N-1$，对每对合法的 $(B,C)$ 累加概率。

**用生成函数维护两个弧的概率分布。** 每头奶牛对应一次因式 $(1-p_j)x+p_j$：乘进"逆时针条数"的生成函数时，$x$ 的指数恰好表示区间内走逆时针的牛数。两个分布 $F_{in},F_{out}$ 分别对应弧内、弧外。弧的右端 $r_i$ 关于 $i$ 单调，用两指针滑动：每次把新进弧的牛乘进 $F_{in}$ 并从 $F_{out}$ 中除掉，两头指针总共只走 $O(N)$ 步；由于两个多项式都是可整除的一次因式乘积，除法就是对因式做一次 $O(N)$ 的带余除法（除以 $(1-p)x+p$）。路径主人自己不进统计，单独乘 $p_i$。

**逆时针分支。** 把环沿位置 $0$ 所在直径做镜像：位置变成 $(M-x)\bmod M$，每头牛"顺时针"的概率变成 $1-p_i$，此时原来的逆时针运动在镜像里是顺时针运动，而且在镜像里绕行方向相反、标号次序也反转，因此判定条件依旧写成 $T\equiv -i\pmod N$（代码里就是直接复用同一个函数）。镜像中的位置 $q$ 对应原位置 $M-q$，把两半答案按位置相加即可。

**实现细节。** 位置数组复制一份（$x_{i+N}=x_i+M$）把环形弧变成普通区间；$L$ 只需对 $N$ 取模；当某头牛概率恰为 $1$ 时因式退化成常数 $1$，乘除都跳过即可。

## 复杂度

时间 $O(N^2)$：两指针总位移 $O(N)$，每次乘/除一次因式 $O(N)$；对每头牛枚举 $A$ 求和 $O(N)$；顺时针、镜像两遍常数加倍。空间 $O(N+M)$。本题时限 6s，$\sum N^2\le 5000^2$ 时余量充足。
