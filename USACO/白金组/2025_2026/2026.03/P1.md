# P1　全源最短路（All Pairs Shortest Paths）

## 题目

平面被若干三角形区域铺满，铺法如下：

- 在复平面上，对所有整数 $x,y$ 在 $x+y\exp(\pi i/3)$ 处画一个顶点。
- 对每一组能构成边长为 $1$ 的等边三角形的三个顶点，画出该三角形边界的三条边；再在三角形中心画一个顶点，并从中心向三个外部顶点连边。

给定 $N$ 个输入点，每个点都严格位于某个区域内部（不在任何顶点或边上）。对任意两个输入点，定义它们的距离为：从一点走到另一点、且路径不经过任何顶点时，最少需要穿过的边数。请输出全部 $N(N-1)/2$ 对点的距离之和。

## 输入

第一行一个整数 $T$，表示独立的测试组数。

每组测试：

- 第一行一个整数 $N$。
- 接下来 $N$ 行，每行三个整数 $x,y,z$（$0\le x,y<10^6$，$0\le z<12$），表示复平面上位于 $x+y\exp(\pi i/3)+\epsilon\cdot\exp((1+2z)\pi i/12)$ 的点，其中 $\epsilon$ 是一个很小的正数。

保证所有测试的 $N$ 之和不超过 $2\cdot 10^5$。

## 输出

对每组测试，输出一行，表示该组全部 $N(N-1)/2$ 对点距离之和。

## 样例

输入：

```text
6
2
0 0 0
0 0 0
2
0 0 0
1 1 7
2
0 0 0
0 0 6
3
0 0 1
0 0 5
0 0 9
2
0 2 11
1 1 1
2
2 0 11
1 1 1
```

输出：

```text
0
3
6
12
2
6
```

## 思路

两类边各自构成一张网格：整数顶点之间构成**等边三角形网格**，而连向三角形中心的边构成**菱形网格**。原图中两点的最短距离恰好等于在这两张子网格中距离之和，因此可以分开统计后相加。

**一、三角形网格**（三个方向的平行直线族）

只需把每个点定位到三条平行线族上的坐标 $(a,b,c)$。两点之间的最短距离等于三个方向上的坐标差之和，于是问题化为：给定 $N$ 个点在某方向上的坐标，求所有点对坐标差之和。把坐标排序，相邻坐标之间的"缝隙"会被 $b\cdot(N-b)$ 条点对路径跨过，其中 $b$ 是坐标小于该缝隙的点数；三个方向分别统计再相加。

**二、两张六边形网格**

把菱形网格按"连向上方三角形"与"连向下方三角形"拆成两张正六边形网格。对位于同一张六边形网格中的两点，其距离等于对应的内接等边三角形网格中距离的**一半**（跨一条六边形边可看成进入一个反向三角形再出来，故恰好是两倍代价）。因此对每张六边形网格套用上面的三角形网格统计法，再除以 $2$ 即可。

**三、菱形链修正**

两张六边形网格并不独立：以 $(0,0,0)$ 与 $(0,0,5)$ 为例，两张六边形网格各自只要 $1$ 步，但真实距离为 $1+2=3$。可以证明这是唯一的例外——**长对角线水平的菱形**按共享顶点排成无限多条"链"，位于同一条链的**不同**菱形中的两点，其真实距离恰比两张六边形网格距离之和多 $1$（走到链上第 $r$ 个菱形需要 $2r+1$，而两张网格各自只需 $r$）。

于是对三个方向的链分别统计：每条链中有 $a_1,\dots,a_m$ 个点分布在各个菱形里，需要加上

$$\binom{a_1+\dots+a_m}{2}-\sum_{i=1}^m\binom{a_i}{2},$$

即该链内所有点对数减去落在同一菱形内的点对数。

总复杂度 $O(N\log N)$（对每个测试排序）。
