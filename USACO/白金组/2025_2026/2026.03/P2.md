# P2　爆炸伤害（Blast Damage）

## 题目

贝西要击败一列 $N$ 个敌人，第 $i$ 个敌人的初始血量为 $v_i$（$1\le N\le 2\cdot 10^5$，$0\le v_i\le 10^9$）。一次攻击的规则是：

- 选择一个仍然活着的敌人 $i$（即 $v_i>0$）；
- 对 $i$ 造成一点伤害，并对所有**仍然活着**的相邻敌人（$i-1$ 与 $i+1$）各造成一点伤害。

求击败所有敌人的最少攻击次数。

此外给定参数 $M$（$0\le M\le 2$）。若 $M>0$，还要输出一个达到最少攻击次数的构造。一次“连续攻击同一个敌人”称为一个 run，记构造中共有 $R$ 个 run，要求：

- $M=1$ 时 $R\le 2N$；
- $M=2$ 时 $R\le f(N)$，其中 $f(N)$ 是长度为 $N$ 的所有血量序列中“最少 run 数”的最大值。

## 输入

第一行两个整数 $T,M$（$1\le T\le 10^5$，$0\le M\le 2$），表示独立的测试组数。

每组测试两行：第一行一个整数 $N$；第二行 $N$ 个整数 $v_1\dots v_N$。

保证所有测试的 $N$ 之和不超过 $10^6$。

## 输出

对每组测试，第一行输出最少攻击次数。若 $M>0$，再输出一行 $R$，随后 $R$ 行每行两个整数 $i$ 与 $r$（$1\le i\le N$，$0\le r\le 10^9$），表示连续攻击第 $i$ 个敌人 $r$ 次。$M>0$ 时输出任意一个合法构造即可。

## 样例

输入：

```text
2 0
1
10
3
6 1 7
```

输出：

```text
10
12
```

## 思路

记 $a_i$ 为“攻击第 $i$ 个敌人的次数”，则总攻击次数为 $\sum a_i$，且对每个敌人必须有 $a_{i-1}+a_i+a_{i+1}\ge v_i$（$a_0=a_{N+1}=0$），同时显然 $a_i\le v_i$——因为把 $a_i$ 增大超过 $v_i$ 之后敌人 $i$ 已经死了，后面的攻击根本无法执行。

**一、下界与最优次数。** 先全部取 $a_i=0$，从左到右依次满足每个敌人的需求：处理 $i$ 时，$a_{i-1},a_i$ 已经确定，还差 $\text{need}=\max(0,\ v_i-a_{i-1}-a_i)$ 点伤害。此时把 $\text{need}$ 尽量加到 $a_{i+1}$ 上是最好的：$i+1$ 的贡献同时被 $i+1$ 与 $i+2$ 两个（尚未处理的）约束使用，而 $a_i$ 只被 $i+1$ 使用，而且 $a_{i-1}$ 对应的约束早就满足了，所以

$$a_{i+1}\leftarrow\min(\text{need},\ v_{i+1}),\qquad a_i\leftarrow a_i+(\text{need}-a_{i+1}).$$

这一步仍然满足 $a_i\le v_i$。该贪心给出的 $\sum a_i$ 就是答案：任何合法解在处理到第 $i$ 步时都至少有这么多“必须落在 $i$ 与 $i+1$ 上”的攻击次数，归纳可知它是最优解，而且下面会给出达到该值的构造。

**二、构造 run 的顺序。** $a_i$ 的每个非零值恰好对应一个 run，所以 run 数为非零 $a_i$ 的个数（$\le N\le 2N$）。取基准顺序“下标从大到小”。若某个 run 的执行过程中目标敌人先死了，后面的攻击就无从进行，因此顺序必须保证：轮到 $a_q$ 这个 run 时，敌人 $q$ 的剩余血量不少于 $a_q$。

基准顺序里紧挨着的两个 run 若下标为 $p=q+1$，则先打的 $p$ 会顺带扣掉 $q$ 的 $v_q$ 中被浪费掉的那部分血量：敌人 $q$ 在轮到自己时只剩 $v_q-a_p$ 点血。于是只需检查 $a_p>v_q-a_q$ 是否成立（相等时恰好打完，不必交换）：若成立就交换这两个 run 的先后，否则保持原序。每次交换都只影响这一对相邻下标，去掉多余攻击后**所有非零 $a_i$ 都恰好只贡献一个 run**，并且可以证明“相邻敏感下标不会同时出现”这一性质保证了这些交换互不冲突；按上面的规则从大到小扫描一遍即得合法构造。由 $M=1$ 的要求 $R\le 2N$ 自动满足（实际有 $R\le N$）。

**三、$M=2$ 与 $f(N)$。** 当 $N$ 为奇数时 $f(N)=N$：取交替序列 $3,1,3,1,\dots,3$，小值只能通过攻击自己才能在一次攻击中同时削弱两侧的大值，所以每个敌人至少贡献一个 run，上面的构造已经达到 $N$ 个 run。当 $N$ 为偶数时 $f(N)=f(N-1)=N-1$，而 $N$ 为偶数且每个 $a_i>0$ 时（此时 run 数恰为 $N$）一定有某个敌人被浪费的攻击打中，把血量序列反转后再跑一遍上述构造，run 数就会严格小于 $N$；把输出的下标 $i$ 换成 $N-i$ 即可（实现里记录是否反转）。因为不可能原序列与逆序列同时满足“$v_1>v_2<v_3>v_4<\dots>v_N$”，所以反转总能少一个 run。

## 复杂度

每组测试 $O(N)$ 时间（贪心、扫描求顺序、必要时反转重算各一遍），空间 $O(N)$；总计 $O(\sum N)$ 时间、$O(\max N)$ 空间。
