# P1　中位数之上（Above the Median）

## 题目

农夫约翰把 $N$ 头奶牛排成一排测量身高，第 $i$ 头奶牛的身高为 $H_i$ 纳米。他想选出一段**连续**的奶牛拍照片，提交给县集市上的奶牛摄影比赛。

比赛有一条奇怪的规则：照片只有在"所拍牛群身高的中位数不小于阈值 $X$"时才算有效。

本题中数组 $A[0 \dots K]$ 的中位数定义为：把 $A$ 排序后取 $A[\lceil K/2 \rceil]$，即下标向上取整的那个元素（$K/2$ 为整数时就是它本身）。例如 $\{7,3,2,6\}$ 的中位数是 $6$，$\{5,4,8\}$ 的中位数是 $5$。

请统计有多少个不同的连续子序列可以作为有效照片提交。

## 输入

- 第一行两个整数 $N$ 与 $X$（$1 \le N \le 100000$，$1 \le X \le 10^9$）。
- 接下来 $N$ 行，每行一个整数 $H_i$（$1 \le H_i \le 10^9$）。

## 输出

一行一个整数，表示中位数不小于 $X$ 的连续子序列个数。该数可能超过 32 位整数范围。

## 样例

输入：

```text
4 6
10
5
6
2
```

输出：

```text
7
```

解释：四头牛身高为 $10,5,6,2$，共 10 个连续子序列，其中 7 个的中位数不小于 $6$，分别是 $\{10\}$、$\{6\}$、$\{10,5\}$、$\{5,6\}$、$\{6,2\}$、$\{10,5,6\}$、$\{10,5,6,2\}$。

## 思路

中位数不小于 $X$，等价于"这段数里不小于 $X$ 的个数至少占一半"，因为向上取整的中位数落在第 $\lceil K/2 \rceil$ 小的位置上。于是把每个数替换成符号：$H_i \ge X$ 记作 $+1$，否则记作 $-1$，一个区间合法就等价于该区间的和 $\ge 0$。

设前缀和 $P[0] = 0$，$P[j] = A[1] + \dots + A[j]$，那么区间 $(i, j]$ 的和是 $P[j] - P[i]$，条件 $P[j] - P[i] \ge 0$ 即 $P[i] \le P[j]$。问题转化为统计满足 $0 \le i < j \le n$ 且 $P[i] \le P[j]$ 的二元组个数。

按 $j$ 从小到大扫描，边扫边把已经出现过的 $P[j]$ 插入树状数组（下标加上偏移量使其非负），每次查询"已插入元素中 $\le P[j]$ 的个数"并累加即可，这样每个合法的 $(i, j)$ 恰好在扫描到 $j$ 时被计入一次。
