# P2　简化农场（Simplifying the Farm）

## 题目

农夫约翰的农场可以看成一个带权无向图：顶点是田地，边是田地之间的小路，每条路有一个长度。他想拆掉一些小路，让剩下的图变成一棵树：任意两块田地之间恰好有一条路径，并且这棵树要是**最小**生成树，即所有边的总长度尽可能小。

请你帮他算出最小生成树的总长度，以及不同的最小生成树一共有多少棵（结果对 $10^9+7$ 取模）。

题目保证：每一种长度最多只有 3 条路具有这个长度。

## 输入

- 第一行两个整数 $N$ 和 $M$（$1 \le N \le 40000$，$1 \le M \le 100000$），顶点数与边数。
- 接下来 $M$ 行，每行三个整数 $a_i, b_i, n_i$（$1 \le a_i, b_i \le N$，$1 \le n_i \le 10^6$），表示一条连接 $a_i$ 与 $b_i$、长度为 $n_i$ 的路。

## 输出

一行两个整数：最小生成树的总长度，以及最小生成树的棵数对 $10^9+7$ 取模的结果。

## 样例

输入：

```text
4 5
1 2 1
3 4 1
1 3 2
1 4 2
2 3 2
```

输出：

```text
4 3
```

解释：两条长度 1 的边都必须选，再任选一条长度 2 的边，就得到总长度 $2+2=4$ 的生成树，共 3 棵。

## 思路

用 Kruskal 的思路按长度从小到大处理，把所有长度相同的边分成一组。

关键观察：同一组内的边**无论怎么选**，这组处理完之后图的连通分量划分都完全一样。因为组内一条边若在组处理前两端就已经属于同一分量，那它在任何方案里都用不上；否则在按长度递增处理的意义下，这两个分量总会被（直接或间接地）合并，区别只在于用哪些边合并。既然不同组的选择互不影响后续的分量划分，最小生成树的总数就是**各组候选取法数的乘积**，而总长度就是 Kruskal 贪心得到的那一条（各组能合并的次数乘以该组长度之和）。

那么一组内部怎么数？把组内每条边的两个端点替换成它们当前所在的分量，得到一张至多 6 个顶点、至多 3 条边的小图。合法的取法就是这张小图的一棵生成森林：选出的边不能成环，并且要恰好用满"这组边能实现的最大合并次数"。由于组内至多 3 条边，直接枚举全部 $2^3$ 个子集，用局部并查集判环、数选中的边数即可。

## 复杂度

排序 $O(M \log M)$；每组枚举子集 $O(2^3)$，并查集操作近似常数。总时间 $O(M \log M)$，空间 $O(N + M)$。
