# P1　电子游戏连招（Video Game Combos）

## 题目

Bessie 在玩一个电子游戏，游戏中只有 `A`、`B`、`C` 三个按键。游戏里有 $N$ 个「连招」$S_1 \dots S_N$（每个长度 $1$ 到 $15$，只含 `A`、`B`、`C`）。每当 Bessie 按出的一串字母与某个连招匹配时，她就得到一分；连招之间可以互相重叠，也可以在同一时刻结束，同一个连招出现多次就多次得分。

如果 Bessie 恰好按 $K$ 个键，她最多能得多少分？

## 输入

- 第一行两个整数 $N$、$K$（$1 \le N \le 20$，$1 \le K \le 1000$）。
- 接下来 $N$ 行，每行一个字符串 $S_i$，只含 `A`、`B`、`C`，长度 $1$ 到 $15$。

## 输出

一行一个整数，表示恰好按 $K$ 个键能获得的最大分数。

## 样例

输入：

```text
3 7
ABA
CB
ABACB
```

输出：

```text
4
```

解释：最优按键序列是 `ABACBCB`，共得 4 分——`ABA` 一次、`ABACB` 一次、`CB` 两次。

## 思路

按顺序按键时，"现在能得到多少分"只取决于当前按键序列的一段后缀：能匹配的连招必须在这一刻结束。因此把 $N$ 个连招建成 AC 自动机，用节点表示"当前序列最长的、是某个连招前缀的后缀"。

预处理 `score[u]`：AC 自动机走到节点 $u$ 时这一刻新增的分数。一个连招在 $u$ 结束当且仅当它是 `u` 或 `u` 失败链上某个节点的结尾，所以按广搜顺序令 `score[u] += score[fail[u]]` 即可把整条失败链的贡献累加进来。注意有重叠或同时结束的连招，例如 `ABA` 和 `ABACB` 会在同一个位置一起结算。

之后就是普通 DP：$dp[k][u]$ 表示按了 $k$ 个键、自动机停在状态 $u$ 时的最大得分。转移时枚举补上的字符 $c$，新状态 $v = go(u, c)$，则

$$dp[k+1][v] = \max\big(dp[k+1][v],\; dp[k][u] + score[v]\big)$$

由于分数只增不减、也不受状态限制，直接取最大值即可；答案为所有状态下 $dp[K][u]$ 的最大值。

## 复杂度

AC 自动机节点数 $O(NL)$（$L \le 15$ 为连招最大长度）。建自动机与预处理耗时 $O(3NL)$；DP 时间 $O(K \cdot NL \cdot 3)$，在 $N \le 20$、$K \le 1000$ 时约 $1.8 \times 10^6$ 次转移。空间为 DP 表 $O(K \cdot NL)$，约 1.2 MB。
