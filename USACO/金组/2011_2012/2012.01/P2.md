# P2　奶牛跑步（Cow Run）

## 题目

农夫约翰和 Bessie 发明了一个新的锻炼游戏。奶牛们在一个长度为 $M$ 的圆形跑道上从同一个位置出发，游戏共 $N$ 轮，每轮用 8 张写有数字 $X_i$（$0 \le X_i < M$）的牌。

每轮 FJ 先取出最上面的 8 张牌，选择其中上面 4 张或下面 4 张；Bessie 再从这 4 张中选上面 2 张或下面 2 张。然后 FJ 报出这 2 张中最上面那张牌的数字 $X_{top}$，奶牛们跑 $R \cdot X_{top}$ 的距离（$R$ 是到目前为止跑过的总距离）；接着 Bessie 报出最下面那张牌的数字 $X_{bottom}$，奶牛们再跑 $X_{bottom}$ 的距离。

如果结束时奶牛们距起点超过 $K$（$0 \le K \le \lfloor M/2 \rfloor$）就回不了家。题目保证只要 FJ 应对正确，无论 Bessie 怎么选都能让奶牛回家。请为每一轮输出 FJ 应该选哪一半（`T` 表示上面 4 张，`B` 表示下面 4 张），使得无论从这一轮起 Bessie 如何选择，FJ 都能把奶牛送回家；多个答案取字典序最小的。Bessie 每轮实际的选择会额外给出，供你推进游戏。

## 输入

- 第一行三个整数 $N$、$M$、$K$（$1 \le N \le 14$，$2 \le M \le 10^9$，$0 \le K \le \lfloor M/2 \rfloor$）。
- 第二行一个长度为 $N$ 的字符串，第 $i$ 个字符是 `T` 表示 Bessie 第 $i$ 轮选上面 2 张，是 `B` 表示选下面 2 张。
- 接下来 $N$ 行，每行 8 个整数，表示该轮自上而下的 8 张牌。

## 输出

一行长度为 $N$ 的字符串，第 $i$ 个字符是 FJ 第 $i$ 轮的选择（`T` 或 `B`），要求字典序最小。

## 样例

输入：

```text
2 2 0
TT
1 0 0 0 0 0 0 1
0 1 1 1 0 0 1 0
```

输出：

```text
TB
```

解释：$K = 0$ 时奶牛们必须恰好回到起点。第一轮 FJ 若选下面 4 张，Bessie 选下面 2 张就会走到距离 1，之后无法回到起点，所以第一轮只能选 `T`；第二轮选 `B` 对 Bessie 的两种选择都能回到起点。

## 思路

把游戏展开成一棵**交替的 AND/OR 树**：FJ 的每一轮是 OR 节点（两种选择有一种可行即可），Bessie 的每一次选择是 AND 节点（两种应对都必须可行）。叶子判断当前位置 $x$ 是否满足 $\min(x, M-x) \le K$，即 $x \le K$ 或 $x + K \ge M$。求每个 OR 子树的值就是「FJ 能否从此保证把牛送回家」。

求字典序最小的策略：每轮先试着选 `B`（字典序更小），若该 AND 子树求值为真就输出 `B`，否则输出 `T`；然后按输入中 Bessie 的实际选择算出新位置，进入下一轮。

直接完整展开整棵树有 $4^N$ 个叶子（$4^{14} \approx 2.7 \times 10^8$），但 AND/OR 的短路（Bessie 一假即假、FJ 一真即真）能砍掉大量分支。官方题解指出测试数据被刻意构造过，会卡掉固定的访问顺序，因此**每个节点用 xorshift 随机数决定先访问哪个孩子**：这样求值的期望节点数约为 $(1.686\ldots)^{2N} \approx 2.84^N$，$N = 14$ 时约 200 万，远快于展开整棵树；随机化只改变访问顺序、不改变 AND/OR 的语义，结果始终正确。
