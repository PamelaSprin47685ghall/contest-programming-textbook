# P1　奶牛优惠券（Cow Coupons）

## 题目

Farmer John 要买新奶牛。一共有 $N$ 头奶牛待售（$1 \le N \le 50000$），他的预算是 $M$ 元钱（$1 \le M \le 10^{14}$）。第 $i$ 头奶牛的原价是 $P_i$（$1 \le P_i \le 10^9$），不过 FJ 手上还有 $K$ 张优惠券（$1 \le K \le N$），对第 $i$ 头奶牛用一张券之后它只要 $C_i$ 元（$1 \le C_i \le P_i$）。每头奶牛最多只能用一张券。

问 FJ 最多能买下多少头奶牛。

## 输入

第一行三个空格分隔的整数 `N K M`。

接下来 $N$ 行，第 $i$ 行是两个整数 `P_i C_i`。

## 输出

一行一个整数：最多能买的奶牛数。

## 样例

输入：

```text
4 1 7
3 2
2 2
8 1
4 3
```

输出：

```text
3
```

FJ 把唯一的券用在第 3 头奶牛上，再全价买下第 1、2 头，共花 $3+2+1=6$ 元。

## 思路

一个自然的贪心是：用券买下优惠价最低的 $K$ 头，再全价买剩下奶牛里最便宜的。它是错的——如果有些奶牛用券很便宜、不用券却很贵，而另一些奶牛本来就很便宜，那么券应该留给前者。

正确的贪心把每一步都变成「**在当前局面下，多买一头奶牛的最小代价是多少**」。把已经用券买下的奶牛的 $P_i - C_i$ 放进一个小根堆，它表示「把这头奶牛改回全价、从而**撤回**一张券」的代价。于是多买一头奶牛只有两种方式：

1. **全价买**：花掉当前原价最小的那头奶牛的 $P_j$；
2. **用券买**：先从最便宜的地方撤回一张券（代价 `recover.top()`），再花掉当前优惠价最小的那头奶牛的 $C_j$。

两者取小者，买下它，再更新手头券的分布：

- 走方式 2 之后，这头奶牛占用了新到手的券，于是把它的 $P_j - C_j$ 压入 `recover`；
- 走方式 1 不改变券的分布。

每买的这一头都是当前能买到的最便宜的一头，所以贪心是安全的：如果最优解里下一头买的不是它，把它换过来只会更省。重复到预算不够为止，买到的头数就是答案。
