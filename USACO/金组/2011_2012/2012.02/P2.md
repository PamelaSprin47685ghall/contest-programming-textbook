# P2　对称（Symmetry）

## 题目

上完现代艺术课后，Farmer John 迷上了在农场里找几何图案。他在平面上标记了 $N$ 头奶牛的位置（$2 \le N \le 1000$），每头奶牛占一个互不相同的整点。他想知道这 $N$ 个点一共构成多少条对称轴——也就是关于它左右（上下）两侧的点互为镜像的直线。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个空格分隔的整数，表示第 $i$ 头奶牛的坐标，坐标范围 $-10000 \ldots 10000$。

## 输出

一行一个整数：这个点集的对称轴条数。

## 样例

输入：

```text
4
0 0
0 1
1 0
1 1
```

输出：

```text
4
```

四个点组成一个正方形，它有 $4$ 条对称轴：一条竖直、一条水平、两条对角。

## 思路

平面上的直线有无穷多条，不能一条条试；但对称轴只可能是少数几条候选，先把候选缩小。

任取两个给定的点 $p$、$q$（比如编号 $0$ 与 $1$ 的点），任何一条对称轴必属于下面三类之一：

1. **不过 $p$**：$p$ 的镜像 $x$ 一定不是 $p$ 自己，而这条轴恰好是线段 $px$ 的中垂线；
2. **过 $p$ 但不过 $q$**：同理，$q$ 的镜像 $x$ 一定不是 $q$，这条轴是线段 $qx$ 的中垂线；
3. **同时过 $p$ 和 $q$**：两点确定一条直线，这条轴就是直线 $pq$。

于是候选轴一共只有 $2N-1$ 条：$p$ 与其余各点的中垂线、$q$ 与其余各点的中垂线，再加上直线 $pq$。逐条验证即可，而**验证一条候选轴**只要看每个点的镜像点是否也是给定点。

为了让镜像点的判断精确无误，直线写成整系数的 $Ax+By+C=0$。点 $(x,y)$ 沿法向量反射后的位置是

$$\left(x - \frac{2At}{A^2+B^2},\ y - \frac{2Bt}{A^2+B^2}\right), \qquad t = Ax+By+C .$$

- 若 $2At$ 或 $2Bt$ 不能被 $A^2+B^2$ 整除，镜像点就不是整点，这条轴立刻不可能对称；
- 否则镜像点也是一个整点，坐标范围只有 $20001^2$ 种，把它和原坐标一起编码成一个整数放进排序数组，二分查找即可判断它是不是给定点。

同一个点的集合中，三条候选线可能重合（比如 $p$ 与 $q$ 的中垂线只有同一条）。把所有约掉公因数、统一符号后的直线放进一个小数组，确认是同一条时只记一次，最后输出不同对称轴的条数。

## 复杂度

时间 $O(N^2 \log N)$（$2N-1$ 条候选轴，每条最多检查 $N$ 个点，每个点一次二分查找），空间 $O(N)$。
