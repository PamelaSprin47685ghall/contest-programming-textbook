# P3　摩天大楼里的奶牛（Cows in a Skyscraper）

## 题目

奶牛们爬完楼梯比赛后都不愿意再走下楼，只好坐电梯回一楼。电梯的载重上限是 $W$，第 $i$ 头奶牛重 $C_i$。

请帮贝西安排电梯的每一趟，让所有 $N$ 头奶牛都回到一楼，并且用的趟数最少。每一趟里奶牛的总重量不能超过 $W$。

输出最少趟数 $R$，然后输出 $R$ 行，每行描述一趟：先给出这趟的奶牛头数，再按从小到大的顺序给出这些奶牛的编号。最优方案可能有很多种，输出任意一种即可。

## 输入

- 第一行两个整数 $N, W$（$1 \le N \le 18$，$1 \le W \le 10^8$）：奶牛头数与电梯载重上限。
- 接下来 $N$ 行，每行一个整数 $C_i$（$1 \le C_i \le W$），表示第 $i$ 头奶牛的重量。

## 输出

- 第一行一个整数 $R$：最少需要的趟数。
- 接下来 $R$ 行：每行先是这趟的奶牛头数，随后是这些奶牛的编号。

## 样例

输入：

```text
4 10
5
6
3
7
```

输出：

```text
3
2 1 3
1 2
1 4
```

解释：3 号奶牛只有 3 重，可以跟任何一头奶牛同乘一趟，样例里它跟 1 号（重 5）一起走；剩下的 5、6、7 三头奶牛两两相加都超过 10，谁都挤不进别人那一趟，所以至少要 3 趟。本题的最优方案不唯一，例如 `1 1`、`2 2 3`、`1 4` 也是 3 趟的合法方案（2 号与 3 号合起来 $6+3=9 \le 10$）。

## 思路

把重量换成"奶牛能否同乘一趟"，问题就是经典的装箱（bin packing）：把 $N$ 个物品装进尽量少的容量为 $W$ 的箱子。装箱是 NP 难的，但 $N \le 18$ 提示我们用子集上的指数级 DP。

**预处理子集重量。** 用 `subsetSum[mask]` 记录 `mask` 里所有奶牛的重量之和：任取 `mask` 里编号最小的一位 `lowBit`，则 `subsetSum[mask] = subsetSum[mask ^ (1 << lowBit)] + C[lowBit]`，$O(2^N)$ 递推。

**状态只要两个数。** 把安排过程想成"一头一头往电梯里放"：放第 $i$ 头牛时，它要么挤进当前最后一趟，要么因为装不下而另起一趟。于是决定未来只需要知道两个量：

- `rides[mask]`：装完 `mask` 里这些牛，一共用掉了多少趟（含当前正在装的那趟）；
- `lastLoad[mask]`：在趟数最少的前提下，最后一趟已经装了多少重量。

趟数越少越好；趟数相同则最后一趟越轻越好（后面更塞得下）。这两个数按字典序比较，逐个把新牛加进 `mask` 就能递推：

```
if (lastLoad[prev] + C[i] <= W) 放进最后一趟
else                            另起一趟
```

**为什么两个数就够。** 未来的每一步只会问"当前这趟还装得下吗"，所以状态里除了已用趟数，只需要最后一趟的载重；而"趟数更少"永远不会比"趟数更多、但最后一趟更空"更差——多出来的那一趟本身就是一段可以自由使用的余量，接下来无论怎么装，趟数少的一方都不会落后。于是按"先比趟数、再比最后一趟载重"的字典序取最小状态即可。

约定 `rides[0] = 1`、`lastLoad[0] = 0`：把"此刻还是空的、正在装的这一趟"也算进去，这样每加一头牛时都有一趟可以用来装，全部装完时 `rides[full]` 恰好就是答案（最后那趟是真实存在的一趟）。

**还原方案。** 有了所有子集的 `rides` 值，从全集 `full` 倒着拆：每一趟都强制包含当前剩余集合里编号最小的那头牛（否则同一组会被重复考虑），在满足

- `subsetSum[part] <= W`（装得下）、
- `rides[rest ^ part] == rides[rest] - 1`（走完这趟后剩下的牛仍然能用最少趟数装完，`part == rest` 时视为成立）

的候选组里挑 `subsetSum` 最大的那一组，也就是"在保证总趟数不变的前提下尽量装满"。这样挑出来的组一定是合法的：取任意最优方案里含最小编号那牛的那趟作为 `part`，它必然满足上面两个条件。

## 复杂度

子集重量、DP 都是 $O(2^N N)$；还原方案最多拆 $N$ 趟，每趟枚举 $O(2^N)$ 个子集，合计 $O(2^N N)$。空间 $O(2^N)$，三个大小为 $2^N$ 的数组。
