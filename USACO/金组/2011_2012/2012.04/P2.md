# P2　书架（Bookshelf）

## 题目

农夫约翰收集了 $N$ 本书（$1 \le N \le 100000$），打算做一套新书架把它们全部放下。第 $i$ 本书的宽度是 $W_i$、高度是 $H_i$。

书必须**按编号顺序**上架：第一层放第 $1 \ldots k$ 本，第二层从第 $k+1$ 本接着放，依此类推。每层的总宽度不能超过 $L$（$1 \le L \le 10^9$）。一层的高度等于这一层里最高的那本书的高度；整套书架的高度等于所有层的高度之和。

求整套书架的最小可能高度。

## 输入

第一行两个空格分隔的整数 `N L`。

接下来 $N$ 行，第 $i+1$ 行是两个整数 `H_i W_i`（$1 \le H_i \le 10^6$，$1 \le W_i \le L$）。

## 输出

一行一个整数：最小总高度。

## 样例

输入：

```text
5 10
5 7
9 2
8 5
13 2
3 8
```

输出：

```text
21
```

三层分别是：第 1 层只放第 1 本（高 5，宽 7），第 2 层放第 2、3、4 本（高 13，宽 9），第 3 层放第 5 本（高 3，宽 8），总高度 $5+13+3=21$。

## 思路

设 $dp[i]$ 为放好前 $i$ 本书的最小总高度，$dp[0] = 0$。枚举最后一层的起点是第 $j+1$ 本，则

$$dp[i] = \min_j \left\{ dp[j] + \max(H_{j+1}, \dots, H_i) \right\},$$

其中 $j$ 必须满足 $\sum_{k=j+1}^{i} W_k \le L$，即 $j$ 落在窗口 $[lo-1,\ i-1]$ 内；$lo$ 随宽度约束单调右移。$j=i-1$ 永远合法，因为题目保证 $W_i \le L$。

直接枚举 $j$ 是 $O(N^2)$，$N = 10^5$ 过不去。注意 $j$ 从 $i-1$ 往左移动时，$\max(H_{j+1..i})$ 只会变大，所以合法的 $j$ 被切成若干**块**，同一块内最大值相同。用单调栈维护这些块：加入第 $i$ 本书时，若 $H_i$ 不小于下面那块的高度，那么下面那块的最大值也会变成 $H_i$，两块可以并成一块（代码里就是不断把栈顶并入它的下一块）。

每一块只需要记「块内 $j$ 的个数」。关键观察是

> 每一块的高度等于 $H[\text{块内最大的 } j + 1]$。

（顶部那块的最大 $j$ 是 $i-1$，高度 $H_i$ 正好是它右边那本书；其余各块同理。）又因为 $dp$ 单调不减——多放一本书不可能让总高度下降——块内 $dp[j]$ 的最小值一定出现在**最左端**的 $j$。于是每块只需往一个 `multiset` 里放一个候选值 `块高 + dp[块内最左的 j]`，`multiset` 的最小值就是 $dp[i]$；合并两块时，把下面那块 `max` 变高之前的旧候选值删掉、合并完重算即可。

窗口左端右移时只会动到最底下的块：它最左的 $j$ 前移一格，候选值从 `块高 + dp[lo-1]` 改成 `块高 + dp[lo]`；若这一块被掏空就整块删掉（上面各块最左端没变，候选值也不用动）。

## 复杂度

时间 $O(N \log N)$：每本书推动常数次「入栈、合并、出栈」以及常数次 `multiset` 操作。空间 $O(N)$。
