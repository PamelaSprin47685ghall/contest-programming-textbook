# P1　平衡的奶牛品种（Balanced Cow Breeds）

## 题目

Farmer John 有 $N$ 头奶牛站成一排（$1 \le N \le 1000$），每头牛身上的烙印看起来是一个左括号 `(` 或右括号 `)`，于是整排牛构成了一个长度为 $N$ 的括号串 $S$。

FJ 有两种品种的牛：Holstein 和 Guernsey。请统计有多少种把每头牛标成 Holstein 或 Guernsey 的方案，使得：

- 按原顺序只保留 Holstein 的牛时，得到的括号串是平衡的；
- 只保留 Guernsey 的牛时，得到的括号串也是平衡的。

这里"平衡"指：`(` 与 `)` 总数相等，且任意前缀中 `(` 的数量不少于 `)` 的数量。全部牛只属于一个品种也算合法方案。

## 输入

- 第一行：一个长度为 $N$ 的括号串 $S$。

## 输出

- 第一行：方案数对 $2012$ 取模的结果。

## 样例

输入：

```text
(())
```

输出：

```text
6
```

解释：合法的品种分配是 `HHHH`、`GGGG`、`HGGH`、`GHHG`、`HGHG`、`GHGH` 六种。

## 思路

设 $h_i$ 为 $S$ 前 $i$ 个字符中 `(` 比 `)` 多的个数（即前缀高度）。把每头牛分给某个品种，相当于把 $S$ 的字符分成两个子序列。一个子序列合法（前缀中 `(` 不少于 `)`，且结束时归零）当且仅当该子序列的"未匹配 `(` 数"在每一步都非负、最后为 $0$。

关键观察：两个品种的字符合起来正好是前 $i$ 个字符，所以

$$(\text{Holstein 的未匹配数}) + (\text{Guernsey 的未匹配数}) = h_i .$$

因此我们只需要记录其中一个。

设 $dp[a]$ 表示"处理完当前前缀、Holstein 还有 $a$ 个未匹配的 `(`"的方案数，那么 Guernsey 的未匹配数必然是 $b = h_i - a$。逐头牛转移：

- 当前字符是 `(`：分给 Holstein 则未匹配数变为 $a+1$，分给 Guernsey 则 $a$ 不变；两种选择都不会让任何一侧变负。
- 当前字符是 `)`：只有当 Holstein 的未匹配数 $a > 0$ 时才能分给它（$a \to a-1$），只有当 $b > 0$ 时才能分给 Guernsey（$a$ 不变），否则会让该品种的某个前缀中 `)` 多于 `(`，非法。

转移完整个串后，若 $h_N \ne 0$，两个品种的括号总数不可能同时相等（此时 $dp$ 里也不可能给出合法值），答案为 $0$；否则答案就是 $dp[0]$，即两个品种都恰好用完所有 `(`（都平衡）。

由于 $h_i$ 的取值只在 $[-N, N]$ 且实际只需考虑 $0 \le a \le h_i$，用两行滚动数组即可，注意每一步都对 $2012$ 取模。
