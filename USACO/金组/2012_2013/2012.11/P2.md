# P2　并发平衡的括号串（Concurrently Balanced Strings）

## 题目

Farmer John 把奶牛排成了 $K$ 行，每行 $N$ 头（$1 \le K \le 10$，$1 \le N \le 50000$），第 $s$ 行的括号串记为 $S_s$。

对区间 $[i, j]$（$i \le j$），如果每个串 $S_s$ 在区间 $[i, j]$ 上的子串都是平衡的（`(` 与 `)` 数量相等，且任意前缀中 `(` 不少于 `)`），就称这个区间是"并发平衡"的。求有多少个区间是并发平衡的。

## 输入

- 第一行：两个整数 $K$ 和 $N$；
- 接下来 $K$ 行：每行一个长度为 $N$ 的括号串。

## 输出

- 第一行：并发平衡区间的个数。

## 样例

输入：

```text
3 14
)()((())))(())
()(()()()((())
)))(()()))(())

```

输出：

```text
3
```

解释：$[3,8]$、$[10,13]$、$[11,12]$ 这三个区间（下标从 $0$ 开始）是并发平衡的。

## 思路

给每个串定义前缀高度 $pre_s[j] = $ 前 $j$ 个字符中 `(` 比 `)` 多的个数（$pre_s[0]=0$）。用 $p = i-1$ 表示区间左端点的前一位，则

$$S_s[i..j] \text{ 平衡} \iff pre_s[j] = pre_s[p] \ \text{且}\ \forall q \in (p, j]:\ pre_s[q] \ge pre_s[p].$$

在后一条中把 $pre_s[p]$ 换成相等的 $pre_s[j]$，即"$(p,j]$ 内不存在高度严格小于 $pre_s[j]$ 的位置"。设 $low_s[j]$ 为满足 $q \le j$ 且 $pre_s[q] < pre_s[j]$ 的**最大**下标 $q$（不存在时记 $-1$），再设

$$low[j] = \max_s low_s[j],$$

那么区间 $[i, j]$（$p = i-1$）并发平衡等价于两条：

1. 对所有 $s$ 都有 $pre_s[p] = pre_s[j]$，即位置 $p$ 与位置 $j$ 的"高度向量"完全相同；
2. $p \ge low[j]$（若 $low_s[j] > p$，那么 $low_s[j] \in (p, j]$ 就是破坏平衡的那个位置）。

于是问题变成：对每个 $j \in [0, N]$，统计前面有多少个位置 $p$ 与它高度向量相同、且 $p \ge low[j]$。做法：

- $low_s[j]$ 就是"左侧最后一个高度严格更小的位置"，用单调栈在线性时间求出每个串的它，再对 $s$ 取最大值；
- 关键性质是 $low[j]$ 关于 $j$ **单调不减**（$j$ 增大时，"之前出现过的小高度"只会变多，最后一个这样的位置只会往右移）。因此给每个高度向量开一个桶，把出现过的位置按时间顺序存进去，并用一个头指针维护"还没被淘汰的位置"：处理 $j$ 时先把桶里所有小于 $low[j]$ 的位置弹掉，桶中剩余的位置数就是可与 $j$ 配对的数量，最后把 $j$ 自己放进桶里。头指针只前进，总代价均摊线性。
- 高度向量用 `vector<int>` 作为 `map` 的键，比较一次是 $O(K)$。

答案最大约为 $N^2/2 \approx 1.25 \times 10^9$，要用 64 位整数。

## 复杂度

单调栈与指针移动都是 $O(NK)$；`map` 的 $N+1$ 次查找每次比较 $O(K)$ 个整数，共 $O(NK \log N)$。空间 $O(NK)$。
