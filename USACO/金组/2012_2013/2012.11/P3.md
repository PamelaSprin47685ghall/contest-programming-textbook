# P3　平衡树（Balanced Trees）

## 题目

FJ 的农场是一棵 $N$ 个节点的树（$1 \le N \le 40000$），每个节点上写着一个 `(` 或 `)`。树上任意两点之间的唯一路径都会读出一个括号串。

一条路径代表的括号串平衡，当且仅当：`(` 与 `)` 数量相等，且沿路径任意前缀中 `(` 不少于 `)`。平衡串的**嵌套深度**定义为所有前缀中"多余的 `(` 个数"的最大值（例如 `()()()` 深度为 $1$，`((()))()` 深度为 $3$）。

求所有平衡路径中嵌套深度的最大值。

## 输入

- 第一行：一个整数 $N$；
- 第 $2 \sim N$ 行：第 $i+1$ 行给出节点 $i+1$ 的父亲 $p_{i+1}$（$1 \le p_{i+1} \le i$）；
- 第 $N+1 \sim 2N$ 行：节点 $1 \sim N$ 上的字符，每行一个 `(` 或 `)`。

## 输出

- 第一行：最大的嵌套深度。

## 思路

给 `(` 记 $+1$、`)` 记 $-1$，一条路径平衡等价于：路径上的权和为 $0$，并且沿任意一端开始走，前缀权和非负；嵌套深度就是从起点开始走时的最大前缀权和。

**拆边。** 每条长度不小于 $2$ 的路径都会跨过某条边；把树按边 $e=(p,v)$ 分成 $v$ 的子树和"其余部分"两半。若一条平衡路径跨过 $e$，它在这两半里各走一段。设从 $v$ 一侧的端点出发、只在这一半内走所能得到的最大权和为 $A$（允许在此停下的空走，$A \ge 0$），从 $p$ 一侧出发、只在另一半内走能达到的最大**负**权和为 $-B$（即把 `)` 记 $+1$、`(` 记 $-1$ 时的最大权和为 $B \ge 0$），则：

- 深度不可能超过 $A$：路径里所有 `(` 相对 `)` 的净盈余都来自 $v$ 那一半，而 $A$ 正是那一半能提供的最大盈余上界；
- 深度也不可能超过 $B$：路径最终要回到权 $0$，需要 $p$ 那一半提供足够的 `)` 来抵消这些盈余。

所以跨过 $e$ 的平衡路径深度至多 $\min(A, B)$；反过来，把**最高点**（前缀权和取得最大值的位置）当作切分点、以它到其路径上相邻点的那条边为 $e$，"起点的盈余"与"需要抵消的 `)`"恰好各等于真实深度，故该边取到 $\min(A,B)$ 正好等于真实深度。于是

$$\text{答案} = \max_{\text{边 } (p,v)} \max\Big(\min(\text{dPos}[v], \text{upNeg}[v]),\ \min(\text{upPos}[v], \text{dNeg}[v])\Big),$$

其中括号里的第二种组合是把整条路径的方向反过来（在 $p$ 一侧要求 `(` 盈余、在 $v$ 一侧要求 `)` 盈余），两种方向都要试。

**四个量的计算。** 记

- $\text{dPos}[v]$：从 $v$ 出发、只在 $v$ 的子树里走的最大权和（$1$ 为 `(`）；
- $\text{dNeg}[v]$：同样的路径，但把 `)` 当作 $+1$；
- $\text{upPos}[v]$：从父亲 $p$ 出发、不进入 $v$ 的子树的最大权和（$1$ 为 `(`）；
- $\text{upNeg}[v]$：同样路径、把 `)` 当作 $+1$。

它们的递推都是"可以停在这里（$0$），也可以往某个方向再走一步"：

$$\text{dPos}[v] = \max\big(0,\ \text{lab}[v] + \max_{c\ \text{是}\ v\ \text{的儿子}} \max(0, \text{dPos}[c])\big),$$

$$\text{upPos}[v] = \max\big(0,\ \text{lab}[p] + \max\big(0,\ \text{upPos}[p],\ \max_{c \ne v\ \text{是}\ p\ \text{的儿子}} \text{dPos}[c]\big)\big),$$

$\text{dNeg}$、$\text{upNeg}$ 把 $\text{lab}$ 换成 $-\text{lab}$ 即可。由于输入中每个节点的父亲编号都小于它自己，直接按编号从大到小做第一遍（子树信息自底向上），再从小到大做第二遍（父亲信息先于孩子算好）即可，不需要建图 DFS。为了 $O(1)$ 地"排除某个儿子"，对每个节点记录儿子中 $\text{dPos}$（以及 $\text{dNeg}$）的最大值与次大值及其来源儿子。
