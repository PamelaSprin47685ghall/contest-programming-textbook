# P2　谁排第一（First!）

## 题目

Bessie 发现只要把字母表的顺序重新排列，就能让某些字符串变成字典序最小的那一个。给定 $N$ 个互不相同的字符串，问哪些字符串**存在**一种字母表排列，使得它排在所有字符串的最前面。

字典序的定义：比较两个字符串 $X,Y$，找到第一个不同的位置 $j$，谁在这个位置的字符在字母表中更靠前谁就更小；若没有不同位置，则较短的字符串更小。

## 输入

- 第一行：整数 $N$（$1 \le N \le 30000$）；
- 接下来 $N$ 行：每行一个非空字符串，只含小写字母 `a` 到 `z`（所有字符串总长度不超过 $300000$，且互不相同）。

## 输出

- 第一行：能排在最前面的字符串个数 $K$；
- 接下来 $K$ 行：按**输入顺序**输出这些字符串。

## 样例

输入：

```text
4
omm
moo
mom
ommnom
```

输出：

```text
2
omm
mom
```

解释：把字母表排成 `abcdefghijklonmpqrstuvwxyz` 可以让 `omm` 排第一；用标准字母表则 `mom` 排第一（`m` 排在 `o` 前面）。`moo` 与 `ommnom` 无论怎么排列都做不到。

## 思路

对一个候选串 $s$，它要排第一，就必须在每种字母表下都满足：对任意其它串 $t$，$s$ 都小于 $t$。比较 $s$ 和 $t$ 时：

- 若在最前面的第 $i$ 个位置第一次出现 $s_i \ne t_i$，那么必须有约束“$s_i$ 必须排在 $t_i$ 前面”；
- 若某个串是 $s$ 的**真前缀**，那无论字母表怎么排它都排在 $s$ 前面，$s$ 直接出局；
- 若 $s$ 是别的串的前缀，无需约束（短的天然更小）。

把所有得到的约束（形如“字母 $x$ 必须排在字母 $y$ 前面”）建成一张 $26$ 个点的有向图：$x \to y$ 表示 $x$ 在 $y$ 前面。**这张图无环**就等价于存在一种字母表顺序满足全部约束（任一拓扑序即可），也就是 $s$ 能排第一。

暴力对每个串与所有其它串比较是 $O(N \cdot \text{总长})$，太慢。注意到 $s$ 产生的约束只与“字典树上从根到 $s$ 的路径”以及“这些路径节点的儿子字符集合”有关，于是先建字典树：沿 $s$ 的路径走，每到一个节点，$s$ 的下一个字符就必须排在**该节点所有其它儿子字符**的前面；同时若在走到 $s$ 结尾前遇到某个节点是别的串的结尾（即别的串是 $s$ 的真前缀），直接判否。最后做一次拓扑排序判环即可。

因为总字符数不超过 $300000$，字典树儿子用“首儿子 + 兄弟链表”存储，边数等于总字符数，比每个节点开 $26$ 个儿子的数组省内存。

## 复杂度

设字符串总长度为 $S$。建树 $O(S)$；每个串沿路径收集约束需要 $O(26|s|)$，判环 $O(26^2)$。总时间 $O(26S + 26^2N)$，空间 $O(S)$。
