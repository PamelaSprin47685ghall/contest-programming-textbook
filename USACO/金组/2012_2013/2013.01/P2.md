# P2　岛屿旅行（Island Travels）

## 题目

奶牛们来到海上度假。海域是一张 $R \times C$ 的网格（$1 \le R, C \le 50$），'X' 表示岛屿（上下左右相邻的 'X' 属于同一座岛），'S' 表示浅水，'.' 表示深水。海域中一共有 $N$ 座岛（$1 \le N \le 15$）。

贝茜可以乘直升机直接降落在任意一座岛上，然后只能在浅水中沿上下左右方向游动，也可以在岛屿与浅水之间移动，但绝不能进入深水。她游泳的距离按"身体落在浅水格上的不同次数"计算。保证所有岛之间都能靠浅水连通。求你访问完所有岛至少一次所需的最小游泳距离。

## 输入

- 第 1 行：两个整数 $R$ 和 $C$。
- 接下来 $R$ 行：每行 $C$ 个字符，描述海域，字符为 '.'、'X'、'S' 之一。

## 输出

一行，一个整数：访问所有岛屿所需的最小游泳距离。

## 样例

输入：

```text
5 4
XX.S
.S..
SXSS
S.SX
..SX
```

输出：

```text
3
```

解释：从左上角的岛出发，游 1 格到达中间的岛，再从中间的岛游 2 格到达右下角的岛，总共游 3 格。

## 思路

分三步做：

1. **给岛屿编号**：对整张网格做一次洪水填充（四连通的 'X' 归为同一座岛），得到岛屿总数 $N \le 15$，并记下每个格子属于哪座岛。

2. **求两两岛屿之间的最短游泳距离**：从每座岛的所有格子出发做 0-1 BFS。踏入 'S' 的代价记为 $1$（同一块浅水格不会被重复计数，所以"代价"就等价于"踩过的不同浅水格数"）；踏入 'X' 的代价记为 $0$（岛上行走不消耗游泳距离）；'.' 不可通行。边权只有 $0$ 和 $1$，用双端队列即可做到线性时间：代价为 $0$ 的邻居压入队首，代价为 $1$ 的压入队尾。

3. **状压 DP 求访问顺序**：这就是旅行商问题。设 $dp[mask][i]$ 表示"已访问岛屿集合为 $mask$、当前位于岛 $i$"时的最小游泳距离。初始 $dp[2^i][i] = 0$（直升机直达），转移是把 $j \notin mask$ 加进集合：$dp[mask \cup \{j\}][j] \leftarrow \min(dp[mask][i] + \text{swim}[i][j])$，答案是 $\min_i dp[\text{full}][i]$。

把"两两最短距离之和"当作总游泳距离是合理的：一方面，任何一条访问路线的行程可以按"第一次抵达某座新岛"切成若干段，每段的浅水格数不少于两端岛屿间的最短游泳距离，所以 DP 的答案不超过真实最优解；另一方面，按 DP 的最优顺序依次沿着最短路游过去，实际踩过的不同浅水格不会超过这些最短路长度之和，所以真实最优解也不超过 DP 的答案。两者相等。

## 复杂度

洪水填充 $O(RC)$；每座岛的 0-1 BFS 是 $O(RC)$，共 $O(N \cdot RC)$；TSP 状压 DP 是 $O(N^2 \cdot 2^N)$。总时间 $O(N \cdot RC + N^2 \cdot 2^N)$，空间 $O(RC + 2^N \cdot N)$。
