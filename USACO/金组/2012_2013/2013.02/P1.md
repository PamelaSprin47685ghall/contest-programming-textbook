# P1　划分农场（Partitioning the Farm）

## 题目

农夫约翰的农场是一块 $N \times N$ 的正方形牧场网格（$2 \le N \le 15$），每个格子里有若干头奶牛（每格 $0$ 到 $1000$ 头）。农场四周本来就有围栏，但奶牛可以在格子之间自由走动。

约翰想再建一些围栏把奶牛分开。受地方法规限制，每条新围栏必须是一条横贯整个农场的水平线或竖直线，且不能穿过任何格子。他的钱只够建**至多 $K$ 条**围栏（$1 \le K \le 2N-2$）。

两头奶牛属于同一组，当且仅当它们之间不隔着任何围栏就能互相走到。约翰想让**最大的那一组**尽可能小，请你求出这个最小值。

## 输入

- 第 1 行：两个整数 $N$ 和 $K$。
- 接下来 $N$ 行：每行 $N$ 个整数，描述这一行每个牧场里的奶牛数。

## 输出

一行，一个整数：最大组的最小可能奶牛数。

## 样例

输入：

```text
3 2
1 1 2
1 1 2
2 2 4
```

输出：

```text
4
```

解释：在第 2 列与第 3 列之间、第 2 行与第 3 行之间各建一条围栏，农场被切成 4 个 $2 \times 2$ 的组，每组的奶牛数都是 $1+2+2+4$ 分出来的 $4$，最大组为 4，这是 $K=2$ 时能做到的最好结果。

## 思路

$N \le 15$ 说明正解是指数级的，但直接枚举所有围栏位置有 $2^{2N-2}$ 种，$N=15$ 时约 $2.7$ 亿，太多了。突破口在于两类围栏的规模不一样：

- 竖围栏的位置只有 $N-1$ 个候选（第 $0$ 列右边、第 $1$ 列右边……），枚举量只有 $2^{N-1} \le 16384$；
- 竖围栏一旦定下来，切分出的"列组"就固定了，剩下的问题只剩"把行切成若干条横带"，这可以动态规划。

设竖围栏方案为 `mask`（第 $c$ 位为 1 表示第 $c$ 列的右边有围栏），用 $v$ 表示这个方案里竖围栏的条数，则横围栏最多还能建 $K-v$ 条，也就是行最多被切成 $K-v+1$ 条横带。

先预处理

$$band[i][j] = \max_{\text{列组}} \bigl(\text{第 } i \text{ 到 } j-1 \text{ 行在第 } \text{列组} \text{ 中的奶牛总数}\bigr),$$

它表示"横带 $[i, j)$ 自己内部最胖的那个组有多大"。固定 `mask` 后，逐对 $(i,j)$ 累加每一列的列和再扫描一遍列组即可，每个方案 $O(N^3)$。

然后做切分 DP。令 $f[b][j]$ 表示"把前 $j$ 行切成 $b$ 条横带时，最大组的最小可能值"。最后一条横带覆盖 $[i, j)$，它贡献 $band[i][j]$，前面的部分贡献 $f[b-1][i]$，整体取较大者：

$$f[b][j] = \min_{0 \le i < j} \max\bigl(f[b-1][i],\ band[i][j]\bigr),\qquad f[0][0] = 0 .$$

答案为 $\min_{1 \le b \le K-v+1} f[b][n]$。因为题目说的是"至多 $K$ 条"围栏，横带数 $b$ 取得比上限小时也合法，所以枚举所有 $b$ 取最小即可；围栏更多绝不会让最大组变大，故不必担心"没用满预算"。

## 复杂度

枚举 $2^{N-1}$ 种竖围栏方案，每种方案里预处理横带是 $O(N^3)$、切分 DP 也是 $O(N^3)$，总时间 $O(2^{N-1} \cdot N^3)$；空间 $O(N^2)$。
