# P3　路线设计（Route Design）

## 题目

Bessie 在 Amoozon 河两岸开旅行社。左岸有 $N$ 个景点（$1 \le N \le 40000$），第 $i$ 个景点的观赏价值是 $L_i$；右岸有 $M$ 个景点（$1 \le M \le 40000$），第 $j$ 个景点的观赏价值是 $R_j$（$0 \le L_i, R_j \le 40000$）。所有价值都是非负整数。

两岸之间共有 $R$ 条航线（$0 \le R \le 100000$），每条航线连接一个左岸景点和一个右岸景点，可以双向通行；同侧景点之间没有航线。

一条**行程**是一个景点序列，相邻两个景点之间有航线相连，行程的总分是经过的所有景点价值之和。行程可以从任意一个景点开始、到任意一个景点结束。

两条航线 $(a\ x)$ 与 $(b\ y)$ 相交，当且仅当 $a < b$ 且 $y < x$，或 $b < a$ 且 $x < y$，或 $a = b$ 且 $x = y$（即左端点大小关系与右端点大小关系相反，或是同一条航线）。要求行程中任意两条航线都不相交，求最大总分。

## 输入

- 第 1 行：三个整数 $N$、$M$、$R$。
- 接下来 $N$ 行：每行一个整数 $L_i$。
- 接下来 $M$ 行：每行一个整数 $R_j$。
- 接下来 $R$ 行：每行两个整数 $I$、$J$，表示左岸景点 $I$ 与右岸景点 $J$ 之间有一条航线。

## 输出

一行，一个整数：行程能取得的最大总分。

## 样例

输入：

```text
3 2 4
1
1
5
2
2
1 1
2 1
3 1
2 2
```

输出：

```text
8
```

解释：最优行程依次经过左岸 1 号、右岸 1 号、左岸 3 号，价值分别是 $1$、$2$、$5$，总分 $8$。所用的两条航线是 $(1\ 1)$ 和 $(3\ 1)$，它们的右端点相同（不算相交所要求的"大小关系相反"），左端点 $1 < 3$ 与右端点 $1 = 1$ 同向递增，因此不相交。

## 思路

先想清楚"不相交"意味着什么。任意两条相邻接的航线首尾相接，其余航线两两不相交。若两条航线 $(a\ x)$、$(b\ y)$ 都用上了，且 $a < b$，那么必须 $x \le y$（否则它们相交）；把它们推广到整条行程，就得到结论：

**行程在左岸访问的景点编号严格递增，在右岸访问的景点编号也严格递增。**

（若在某一侧的编号回退，例如左岸出现 $a < b$ 之后又回到 $a' < b$ 这种"回头"，那么对应两段航线必然出现大小关系相反，从而相交。）反过来，左岸编号递增、右岸编号递增的景点序列，所用航线一定两两不相交。

于是问题变成：在二分图上选一条路径 $l_1, r_1, l_2, r_2, \dots$（两侧编号各自严格递增，相邻景点有边），使点权和最大。状态数看似 $O(NM)$，其实有用的状态只有"走到某条航线"这 $O(R)$ 种——但直接以 \((u, v)\) 为状态仍需要快速找到下一个状态。

换个角度，不再记"走到哪条航线"，而是记"从某个景点出发最多还能拿多少分"：

- `bestFromLeft[u]`：从左岸景点 $u$ 出发（$u$ 是行程第一个景点）能得到的最大总分；
- `bestFromRight[v]`：从右岸景点 $v$ 出发能得到的最大总分。

一条行程走航线 $(u, v)$ 时，接下来必须从 $v$ 走到一个**编号大于 $u$** 的左岸景点（否则左岸编号会回退），所以

$$\text{bestFromLeft}[u] = \max\Bigl(L_u,\ \max_{\text{航线 } (u,v)} \bigl(L_u + \text{bestFromRight}[v]\bigr)\Bigr),$$

但右边的 `bestFromRight[v]` 必须只统计"从 $v$ 出发、下一站左岸编号 $> u$"的那些延续。做法是把航线按 $(左端点, 右端点)$ **从大到小**排序后依次处理：

- 处理到航线 $(u,v)$ 时，所有左端点 $> u$ 的航线都已经处理过，而 `bestFromRight[v]` 只会被"右端点恰好是 $v$"的航线更新，因此此刻它里面装的恰好是"下一站左岸编号 $> u$"的最优延续，正是我们要的；
- 同一条左端点 $u$ 的多条航线不会互相污染：右端点不同的航线不会更新同一个 `bestFromRight`，而右端点相同时航线本身相同。

实现上处理航线 $(u,v)$ 时只做两条松弛：用 $L_u + \text{bestFromRight}[v]$ 去更新 $\text{bestFromLeft}[u]$，用 $R_v + \text{bestFromLeft}[u]$ 去更新 $\text{bestFromRight}[v]$。两项都用**旧值**算完之后再一起更新，避免同一条航线被当成自己的后继。初始值是"原地结束"：$\text{bestFromLeft}[i] = L_i$、$\text{bestFromRight}[j] = R_j$，对应只有一个景点的行程。最后答案是所有 $\text{bestFromLeft}$、$\text{bestFromRight}$ 中的最大值（行程从哪一侧开始都可以）。

注意点数可达 $40000$、每个价值可达 $40000$，一条行程最多访问 $80000$ 个景点，总分可超过 $2^{31}$，要用 `long long`。

## 复杂度

读入 $O(N + M + R)$，路线排序 $O(R \log R)$，之后每条路线 $O(1)$ 转移；时间 $O(N + M + R \log R)$，空间 $O(N + M + R)$。
