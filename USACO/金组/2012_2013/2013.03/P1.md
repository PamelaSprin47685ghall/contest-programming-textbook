# P1　奶牛狂奔（The Cow Run）

## 题目

农夫约翰忘了修补农场围栏上的一个洞，他的 $N$ 头奶牛（$1 \le N \le 1000$）逃了出来，正在外面撒野。每有一头奶牛待在围栏外，她每分钟就造成 $1$ 美元的损失。约翰必须走到每头奶牛身边给她套上缰绳让她安静下来，损失才会停止。

幸好奶牛们都待在农场外一条公路的直线上，位置互不相同。约翰知道第 $i$ 头奶牛相对于大门（位置 $0$，也是约翰的出发点）的位置 $P_i$（$-500000 \le P_i \le 500000$，$P_i \ne 0$）。

约翰每分钟走一个单位距离，套缰绳不花时间。请你求出约翰按照怎样的顺序拜访奶牛，能使损失总和最小，并输出这个最小损失。

## 输入

- 第 1 行：一个整数 $N$。
- 第 2 到 $N+1$ 行：每行一个整数 $P_i$。

## 输出

一行，一个整数：最小的总损失。

## 样例

输入：

```text
4
-2
-12
3
7
```

输出：

```text
50
```

解释：最优拜访顺序是 $-2, 3, 7, -12$。约翰走 $2$ 分钟到达 $-2$，此时这头奶牛造成 $2$ 美元损失；再走 $5$ 分钟到 $3$，累计损失 $2+5=7$；再走 $4$ 分钟到 $7$，累计 $7+4=11$；最后走 $19$ 分钟到 $-12$，累计 $11+19=30$。总损失 $2+7+11+30=50$。

## 思路

先把所有位置排序，并把起点 $0$ 也当成一个"位置"插进序列里（它上面没有奶牛，只是为了方便确定区间边界），记它在排序后的下标为 $s$。

**关键观察**：任意时刻已经套好缰绳的奶牛，在排序后的序列里一定是连续的一段。因为约翰沿直线移动，要去安抚更远处的奶牛，中途必然经过中间的每一个位置，那些位置上的奶牛早就被顺手安抚了。于是可以用区间 DP：只需要记录"已经安抚的是排序后第 $i$ 到第 $j$ 个位置"以及"约翰此刻站在这个区间的左端还是右端"。

**损失的记法**：在某一次移动所花的每分钟里，所有还没被安抚的奶牛都在继续破坏，所以这一段移动的代价等于

$$\text{移动距离} \times \text{移动开始时尚未安抚的奶牛数}.$$

注意新拜访的那头奶牛是在到达时才被安抚的，所以路上也算在"尚未安抚"里。记区间 $[i,j]$ 里有 $j-i$ 头真奶牛（那段里唯一的非奶牛位置是起点 $0$），则还剩 $N-(j-i)$ 头没安抚。

设 $best[i][j][0]$、$best[i][j][1]$ 分别表示安抚完区间 $[i,j]$ 里的奶牛、约翰站在左端 $pos_i$ 或右端 $pos_j$ 时的最小累计损失，初始 $best[s][s][0]=best[s][s][1]=0$。每次可以向左扩一格或向右扩一格，共 $4$ 种转移：

- 从左端 $pos_i$ 向左走到 $pos_{i-1}$，花费 $(pos_i-pos_{i-1})\cdot(N-(j-i))$；
- 从右端 $pos_j$ 向左走到 $pos_{i-1}$，花费 $(pos_j-pos_{i-1})\cdot(N-(j-i))$；
- 从左端 $pos_i$ 向右走到 $pos_{j+1}$，花费 $(pos_{j+1}-pos_i)\cdot(N-(j-i))$；
- 从右端 $pos_j$ 向右走到 $pos_{j+1}$，花费 $(pos_{j+1}-pos_j)\cdot(N-(j-i))$。

按区间长度递增的顺序（代码里用 $i$ 递减、$j$ 递增的两重循环）递推即可。当区间覆盖全部位置（$i=0,\ j=N$）时奶牛全部安抚完毕，不会再有新损失，答案为 $\min(best[0][N][0], best[0][N][1])$。

累计损失可能超过 $32$ 位整数，需要用 `long long`。
