# P2　山丘漫步（Hill Walk）

## 题目

有 $N$ 座山丘（$1 \le N \le 100000$）。每座山丘是一条从 $(x_1,y_1)$ 连到 $(x_2,y_2)$ 的线段，其中 $x_1 < x_2$ 且 $y_1 < y_2$。所有线段互不相交、也不相碰（连端点都不重合），并且第一条山丘满足 $(x_1,y_1)=(0,0)$。

奶牛贝茜从第一条山丘上的 $(0,0)$ 出发。每当她站在某座山丘上，她就顺着坡往上爬到这条线段的右端，然后从边上跳下去。如果她落到了另一座山丘上，就接着在那座山丘上走；否则她会一直往下掉，最后安全地落在 $y=-\infty$ 处的枕头堆上。每座山丘 $(x_1,y_1)\to(x_2,y_2)$ 都规定为**包含**点 $(x_1,y_1)$ 但**不包含**点 $(x_2,y_2)$，因此贝茜若在 $x=x_1$ 处从上方落下就会落在它上面，而在 $x=x_2$ 处从上方落下则不会。

请求出贝茜整段漫步中一共碰到了多少座山丘。

## 输入

- 第 1 行：一个整数 $N$。
- 第 2 到 $N+1$ 行：每行四个整数 $x_1,y_1,x_2,y_2$，描述一座山丘；每个整数都在 $0$ 到 $10^9$ 之间。

## 输出

一行，一个整数：贝茜碰到的山丘数。

## 样例

输入：

```text
4
0 0 5 6
1 0 2 1
7 2 8 5
3 0 7 7
```

输出：

```text
3
```

解释：贝茜依次走在第 $1$、第 $4$、最后第 $3$ 座山丘上，共碰到 $3$ 座山丘。

## 思路

贝茜始终向右移动，所以每条山丘最多走一次；只要每次都能快速找出"从当前山丘右端跳下去会落到哪一座山丘上"，模拟整个漫步过程就行了。

她跳下时位于 $(p,q)$（$p$ 是当前山丘的 $x_2$），穿过直线 $x=p$ 的山丘有很多座，她会落在其中 $y$ 坐标低于 $q$、且 $y$ 最高的那一座上。换成"按高度排序"，就是**紧挨着当前山丘下方的那一座**。注意 $x=p$ 处的取法必须遵守题目规定的开闭约定：$x_1=p$ 的山丘算在内，$x_2=p$ 的山丘不算——所以判断顺序上，应当先让"即将离开"的山丘出队。

接下来要解决的是"如何在任意 $x$ 处按高度给山丘排序"。由于任意两条山丘既不相交也不相碰，它们之间的上下关系不会随 $x$ 改变（不会换位）。于是可以让比较器固定在某个与 $x$ 无关的位置：取两条线段 $x$ 区间公共部分的右端 $\min(x_2)$，在那里比较两者高度（用交叉相乘避免浮点误差）。因为两条山丘在该处高度必不相等（否则就相碰了），这个比较器构成严格弱序，可以交给 `std::set`。

有了全局比较器，就做一次从左到右的扫描线：把所有山丘的左右端点当作事件，按 $x$ 排序（$x$ 相同时按 $y$ 排序），集合里始终保存"跨过当前 $x$"的那些山丘，并按高度有序。遇到左端点就插入；遇到右端点就删除。当遇到的右端点恰好属于贝茜正踩着的那座山丘时，取它在集合里的**前驱**（高度紧挨着它下方的那座）作为落点，计数加一，并让贝茜继续在那座山丘上走；若它已经是集合中最矮的一条，说明下方没有山丘了，漫步结束。

$x$ 相同时按 $y$ 排序保证了处理顺序正确：高度更低、已经结束的旧山丘先被删除，而高度更高的新山丘还没有插进来，因此取前驱时看到的正是"真实位于她下方且此刻仍跨过该 $x$"的山丘。

## 复杂度

共有 $2N$ 个事件，排序与每次插入、删除、查前驱都是 $O(\log N)$，总时间 $O(N\log N)$；空间 $O(N)$。
