# P1　照片（Photo）

## 题目

FJ 决定给他的 $N$ 头奶牛（$1 \le N \le 200000$）排成一列拍一张全景照片，奶牛按 $1 \dots N$ 编号。他一共拍了 $M$ 张照片（$1 \le M \le 100000$），第 $i$ 张照片覆盖一段连续的奶牛区间 $[a_i, b_i]$。这些照片并不一定覆盖了每一头奶牛。

拍完之后 FJ 发现一个有趣的现象：**每张照片里恰好有一头带斑点的奶牛**。他知道自己养了一些带斑点的奶牛，但从来没数过。请根据照片求出牛群中带斑点奶牛数量的最大值；如果不存在任何与照片结果相符的斑点分配方案，输出 $-1$。

## 输入

- 第 1 行：两个整数 $N$、$M$。
- 第 2 到 $M+1$ 行：每行两个整数 $a_i$、$b_i$，表示第 $i$ 张照片覆盖的区间。

## 输出

一行一个整数：带斑点奶牛数量的最大值；无解时输出 $-1$。

## 样例

输入：

```text
5 3
1 4
2 5
3 4
```

输出：

```text
1
```

解释：由最后一张照片可知 3 号或 4 号中恰有一头带斑点；取其中任意一头都能同时满足另外两张照片，所以最多 1 头。

## 思路

按从左到右的顺序决定哪些奶牛带斑点，把"当前最后一头斑点牛的编号"当作状态。

设上一头斑点牛在 $j$，下一头在 $i$（$j < i$，且 $(j,i)$ 之间没有斑点牛）。要让每张照片恰好含一头斑点牛，需要满足两类条件：

1. **不能有照片同时包含 $j$ 和 $i$。** 区间 $[a,b]$ 同时包含两者当且仅当 $a \le j$ 且 $b \ge i$。记

   $$maxR[j] = \max\{b_k : a_k \le j\}$$

   （没有这样的照片时取 0），则要求 $i > maxR[j]$。

2. **不能有照片被整段跳过。** 若某张照片 $[a,b]$ 里一头斑点牛都没有，那么它一定满足 $a > j$ 且 $b < i$（$a \le j$ 的照片要么含 $j$，要么含更早的斑点牛——这一半由归纳法保证）。反过来，只要所有满足 $a_k > j$ 的照片都有 $b_k \ge i$，这种照片就不会出现。记

   $$minR[j] = \min\{b_k : a_k > j\}$$

   （没有这样的照片时取 $+\infty$），则要求 $i \le minR[j]$。

于是 DP 转移为

$$dp[i] = 1 + \max\{dp[j] : 0 \le j < i,\ maxR[j] \le i-1,\ minR[j] \ge i\}$$

其中 $dp[0] = 0$ 是哨兵，表示"还没放斑点牛"；此时 $maxR[0] = 0$、$minR[0] = \min_k b_k$，恰好表达了"第一头斑点牛不能晚于任何照片的右端点"。

由于 $maxR$ 与 $minR$ 都单调不降，对固定的 $i$ 合法的 $j$ 是一段连续区间，而且区间两端随 $i$ 增大只会右移。用单调队列维护窗口内 $dp$ 的最大值，转移均摊 $O(1)$。

最后，链尾那最后一头斑点牛 $i$ 还必须满足 $i \ge \max_k a_k$（否则有照片的左端点落在它右边的空档里，照片里一头斑点牛也没有）。答案取所有满足该条件的 $dp[i]$ 的最大值；若都不存在则输出 $-1$。
