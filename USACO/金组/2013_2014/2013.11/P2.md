# P2　视线（Line of Sight）

## 题目

Farmer John 的 $N$ 头奶牛（$1 \le N \le 50000$）站在牧场的不同位置上。牧场中央是一个巨大的圆形谷仓，圆心在原点 $(0,0)$，半径 $R$。位于谷仓两侧的奶牛互相看不见，因为谷仓挡住了视线。求能通过一条直线直接互相看见的奶牛对数。

没有奶牛位于谷仓上或谷仓内部，也没有两头奶牛同时落在谷仓的某条切线上。$1 \le R \le 1000000$，每头奶牛坐标都是 $-1000000 \dots 1000000$ 内的整数。

## 输入

- 第 1 行：两个整数 $N$ 和 $R$。
- 接下来 $N$ 行：每行两个整数，表示一头奶牛的坐标 $(x, y)$。

## 输出

- 一行，一个整数：能互相看见的奶牛对数。

## 样例

输入：

```text
4 5
0 10
0 -10
10 0
-10 0
```

输出：

```text
4
```

解释：4 头奶牛分别位于 $(0,10)$、$(0,-10)$、$(10,0)$、$(-10,0)$，谷仓半径 5。6 对奶牛中除了位于谷仓两侧的两对——$(-10,0)$ 与 $(10,0)$、$(0,-10)$ 与 $(0,10)$——看不见彼此，其余 4 对都能互相看见。

## 思路

两头奶牛能互相看见，当且仅当谷仓边缘上存在**同时被她们两个看见**的点（画几个图就能确信）。于是先算出每头奶牛各自能看见的那段圆弧。

设奶牛到原点的距离为 $d$，她到圆的两条切线所夹的角的一半是

$$\alpha = \arccos\frac{R}{d},$$

因为她、切点和圆心构成的直角三角形中，斜边是 $d$、贴着 $\alpha$ 的直角边是 $R$。于是这头奶牛能看见的谷仓边缘就是从 $\theta - \alpha$ 到 $\theta + \alpha$ 的一段圆弧，其中 $\theta = \operatorname{atan2}(y,x)$ 是奶牛所在的方向角；记每头奶牛的区间为 $[\text{from}, \text{to}]$，长度 $2\alpha < \pi$。问题化为：数出多少对区间在圆上相交。

用"转动的切线"来数：把所有奶牛的 `from` 排序，用一条贴着谷仓慢慢转动的切线扫描。切线转到一条奶牛的 `from` 时，凡结束角已经小于这个角度（即已经转到切线背面去）的奶牛就再也看不见了，把它们从小根堆里弹出；剩下的那些奶牛的可见圆弧都覆盖当前位置，其中每一头都和当前这头奶牛互相可见，于是把堆的大小计入答案；最后把这头奶牛自己的结束角压进堆。

每个可见区间长度小于 $\pi$，所以每对互相可见的奶牛恰好被统计一次（圆上两个长度小于 $\pi$ 的相交区间，只有一端的端点会落进另一段里），而看不见的配对永远不同时出现在堆中。为了正确处理跨越 $0$ 度（也就是圆弧回绕）的区间，把整个扫描绕着圆做**两圈**，只在第二圈累加答案：这样在第二圈开始时，那些 `from` 很大、圆弧一直绕到 $2\pi$ 之外的奶牛仍然留在堆里，跨过 $0$ 度的可见关系不会漏掉。
