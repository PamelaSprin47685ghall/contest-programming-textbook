# P1　假期计划（Vacation Planning）

## 题目

Air Bovinia 航空公司在奶牛居住的 $N$ 个农场之间运营航班（$1 \le N \le 20000$）。公司指定了其中 $K$ 个农场作为枢纽（$1 \le K \le 200$，$K \le N$）。

目前公司开设了 $M$ 条单向航班（$1 \le M \le 20000$），第 $i$ 条从农场 $u_i$ 飞往 $v_i$，票价 $d_i$ 美元（$1 \le d_i \le 10000$）。和任何"合理"的航空公司一样，**每条航班至少有一端是枢纽**。两个农场之间同一方向至多有一条直达航班，也没有起点终点相同的航班。

Bessie 负责售票。她收到了 $Q$ 个单程出行请求（$1 \le Q \le 50000$），第 $i$ 个请求要求从农场 $a_i$ 到农场 $b_i$。请帮她判断每个请求能否被满足，以及满足时的最小花费。

为了缩小输出，只需要输出**能被满足的请求个数**和这些请求的**最小总花费**。注意这个总花费可能超过 32 位整数。

## 输入

- 第 1 行：四个整数 $N, M, K, Q$。
- 接下来 $M$ 行：每行三个整数 $u_i, v_i, d_i$，描述一条航班（$1 \le u_i, v_i \le N$，$u_i \ne v_i$）。
- 接下来 $K$ 行：每行一个整数，表示一个枢纽的编号。
- 接下来 $Q$ 行：每行两个整数 $a_i, b_i$，表示一个出行请求（$1 \le a_i, b_i \le N$，$a_i \ne b_i$）。

## 输出

- 第 1 行：能被满足的请求个数。
- 第 2 行：这些请求的最小总花费。

## 样例

输入：

```text
3 3 1 2
1 2 10
2 3 10
2 1 5
2
1 3
3 1
```

输出：

```text
1
20
```

解释：唯一可行的是 $1 \to 2 \to 3$，花费 20。没有任何航班从农场 3 出发，所以可怜的小牛只能困在那里，第二个请求无法满足。

## 思路

这是单源最短路问题，但直接对每个请求跑一遍 Dijkstra 或做 Floyd 都不行（$Q$ 有 50000，$N$ 有 20000）。

关键在题目给出的特殊限制：**每条航班至少有一端是枢纽**。于是任何一条路线的第一段必然连着某个枢纽（起点本身是枢纽时也成立），所以 $a$ 到 $b$ 的最短路一定能写成

$$\text{cost}(a, b) = \min_{h \text{ 是枢纽}} \big(\text{cost}(a, h) + \text{cost}(h, b)\big).$$

因此只需要以每个枢纽为源点做两次 Dijkstra：

- 在**原图**上从 $h$ 出发，得到 $h$ 到所有点的最小花费，记作 `distOut[h][x]`；
- 把每条边反向得到**反向图**，再从 $h$ 出发，得到的就是原图上所有点走到 $h$ 的最小花费，记作 `distIn[h][x]`。

每个请求枚举 $K$ 个枢纽取最小值即可：总时间 $O(K(N+M)\log N + QK)$。注意只有 `distIn` 与 `distOut` 都有限时该请求才可行，把这些请求的最小花费累加（用 `long long`）后输出。
