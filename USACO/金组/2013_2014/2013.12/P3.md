# P3　贝西洗牌（The Bessie Shuffle）

## 题目

Bessie 已经掌握了"贝西洗牌"：对一个 $M$ 张牌的牌堆（$2 \le M \le 100000$）洗牌后，从上往下第 $i$ 张牌会变成从上往下第 $P[i]$ 张。

现在她在一副更大的牌上练习。这副牌共有 $N$ 张（$M \le N \le 10^9$），从上到下编号 $1 \dots N$。她反复做下面的操作：

1. 取出最上面的 $M$ 张牌，对它们做一次贝西洗牌，再放回牌堆顶部；
2. 拿走牌堆最上面的一张牌，面朝下放到一边；
3. 重复上面两步，直到牌堆空了。每次拿出的牌都摞在前一张拿出的牌上面。

如果剩下的牌**不足 $M$ 张**，就不再洗牌，直接拿走最上面的一张。

牌堆一开始是排好序的：$1$ 在最上面，$2$ 其次，$N$ 在最下面。给定贝西洗牌的描述，请回答 $Q$ 个询问（$1 \le Q \le N$，$Q \le 5000$）：最后摞好的牌堆中，从上往下第 $q_i$ 个位置上是几号牌（$1 \le q_i \le N$）。

## 输入

- 第 1 行：三个整数 $N, M, Q$。
- 第 $2 \dots M+1$ 行：第 $i+1$ 行是整数 $P[i]$，表示洗牌前第 $i$ 张牌洗牌后的位置（$1 \le P[i] \le M$）。
- 第 $M+2 \dots M+Q+1$ 行：每行一个整数 $q_i$，表示一个询问。

## 输出

共 $Q$ 行，每行一个整数，表示对应位置上牌的编号。

## 样例

输入：

```text
5 3 5
3
1
2
1
2
3
4
5
```

输出：

```text
4
5
3
1
2
```

解释：这副牌初始是 `[1, 2, 3, 4, 5]`，$M=3$ 的洗牌效果是把最上面一张移到这一段的末尾。过程如下：

```text
[1, 2, 3, 4, 5] -> [2, 3, 1, 4, 5] (拿走 2)
[3, 1, 4, 5]    -> [1, 4, 3, 5]    (拿走 1)
[4, 3, 5]       -> [3, 5, 4]       (拿走 3)
[5, 4]                             (拿走 5)
[4]                                (拿走 4)
```

最后牌堆自上而下是 `[4, 5, 3, 1, 2]`。

## 思路

$N$ 高达 $10^9$，不可能逐步模拟，但询问只有 $Q \le 5000$ 个，所以对每个询问**沿时间倒着追踪这张牌**。

注意最后摞好的牌堆自上而下正好是拿走顺序的倒序，所以"最终第 $q$ 个位置"等价于"第 $t = N-q+1$ 个被拿走的牌"。

设 $A_t$ 是第 $t$ 步操作前（还没洗牌）的牌堆，$p_t$ 是目标牌在 $A_t$ 中的位置。

- 若第 $t$ 步前牌堆不少于 $M$ 张（即 $t \le K = N-M+1$），那么被拿走的是洗牌后最上面那张，它在洗牌前位于 `invP[1]`（`invP` 是 $P$ 的逆）；否则牌不够 $M$ 张，被拿走的就是 $A_t$ 的第 1 张。
- 倒推一步（从 $A_{t}$ 回到 $A_{t-1}$）：洗牌把第 $i$ 张移到第 $P[i]$ 张，随后最上面一张被拿走、其余整体上移一格，所以洗牌后位于 $x$ 的牌，洗牌前位于 `invP[x+1]`；若 $x \ge M$ 说明它在窗口之外没被动过，于是倒退后位置变成 $x+1$。

于是定义窗口内的倒退映射 $f(x) = \text{invP}[x+1]$（$1 \le x \le M-1$）：

- 位置 $x \ge M$ 时，往后（更早的时刻）每一步都只是 $x \to x+1$，可以一步算出答案；
- 位置 $x < M$ 时按 $f$ 迭代；一旦迭代出 $M$，之后就一直是 $+1$；
- 还有 $M-1$ 步是没有洗牌的（第 $K+1 \dots N$ 步），这些步永远是位置 $+1$，也用公式一次性处理。

由于 `invP` 是双射，$f$ 在 $[1, M-1] \cup \{M\}$ 上每个点**至多有一个前驱**，所以它构成的函数图只能由环和"最终落到 $M$ 的链"组成。预处理两件事：

1. 沿前驱链从 $M$ 反向 BFS，求出每个位置"倒退多少步会落到 $M$"（到不了 $M$ 的位置一定在环上）；
2. 对 $f$ 建倍增表，支持 "倒退 $k$ 步后的位置" 查询。

单个询问 $O(\log M)$：算出 $t$ 与被拿走的初始位置后，先把多余的无洗牌步骤用 $+1$ 抹掉，再判断会滑出窗口（用 `escape` 一步算出）还是留在窗口/环上（倍增跳）。总复杂度 $O(M\log M + Q\log M)$。
