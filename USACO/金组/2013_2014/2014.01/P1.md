# P1　奶牛冰壶（Cow Curling）

## 题目

奶牛冰壶是哞运会（Moolympics）上一项很受欢迎的冬季运动。和普通冰壶一样，两队各把 $N$ 颗石子滑到冰面上（$3 \le N \le 50000$），终局时冰面上共有 $2N$ 颗石子，每颗石子位于平面上一个互不相同的点。

计分方式有点特别：一颗石子如果落在对方三颗石子围成的三角形内部（落在三角形边界上也算），就被对方"俘获"了。一队的得分就是它俘获的对方石子数。给定 $2N$ 颗石子的坐标，请计算这场比赛的比分。

## 输入

- 第 1 行：整数 $N$。
- 第 $2 \sim N+1$ 行：每行两个整数 $x, y$，表示 A 队一颗石子的坐标（$-40000 \le x, y \le 40000$）。
- 第 $N+2 \sim 2N+1$ 行：每行两个整数 $x, y$，表示 B 队一颗石子的坐标。

## 输出

- 第 1 行：两个用空格隔开的整数，依次是 A 队和 B 队的得分。

## 样例

输入：

```text
4
0 0
0 2
2 0
2 2
1 1
1 10
-10 3
10 3
```

输出：

```text
1 2
```

解释：A 队的四颗石子是 $(0,0),(0,2),(2,0),(2,2)$，它们围出的正方形俘获了 B 队位于 $(1,1)$ 的石子，A 队得 1 分。B 队用 $(1,1),(10,3),(-10,3)$ 三颗石子围出的三角形盖住了 A 队的 $(0,2)$ 与 $(2,2)$，B 队得 2 分。

## 思路

三角形个数是 $O(N^3)$，逐个枚举显然不行。但注意到一件事：**所有可能的三角形恰好拼满对方石子的凸包**。一方面任何一个由对方石子围成的三角形都在凸包里面；另一方面，平面上凸包内的任意一点，都落在某三颗石子的凸包（即三角形）里——这条结论就是二维的 Carathéodory 定理，把该点所在的最小包围三角形取出来即可。所以：

> 一颗 B 队石子被 A 队俘获 $\iff$ 它落在 A 队石子的凸包内（边界也算）。

于是问题变成"求一堆点，有多少个落在给定凸包内"，两边各做一次即可。

凸包用单调链法求，得到逆时针排列的顶点，并把最下面的顶点旋到最前面。这样其余每个顶点相对于它的极角都在 $[0, \pi)$ 内且单调递增（严格凸保证极角两两不同），于是可以二分：

1. 若目标点在 `hull[0] -> hull[1]` 这条边的右侧，或在 `hull[0] -> hull[最后一个点]` 的左侧，说明它在那两条射线张开的扇形之外，直接判否；
2. 否则二分出极角夹在哪两个相邻顶点 `hull[lo-1]`、`hull[lo]` 之间；
3. 若它与 `hull[0]`、`hull[lo]` 共线，只要它离 `hull[0]` 不比 `hull[lo]` 远，就落在边界上（算被俘获），否则在线段之外；
4. 否则只要它在 `hull[lo-1] -> hull[lo]` 这条边的左侧（或边上）即可。

叉积最大规模约为 $80000 \times 80000 \approx 6.4 \times 10^9$，超出 32 位整数，因此坐标比较全部用 `long long`。另外要防住退化情形：当对方的石子全部共线时凸包退化成一条线段，这时直接判断点是否落在线段上（共线且被两端点"夹住"）。
