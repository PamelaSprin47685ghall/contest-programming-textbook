# P1　懒惰的奶牛（The Lazy Cow）

## 题目

炎热的夏天里，奶牛 Bessie 变得十分懒惰。她打算在牧场中选一个位置站定，这样只要走一小段路就能吃到尽量多的美味青草。

牧场中有 $N$ 片草地（$1 \le N \le 100000$），第 $i$ 片含有 $g_i$ 单位青草（$1 \le g_i \le 10000$），位于互不相同的点 $(x_i, y_i)$（$0 \le x_i, y_i \le 1000000$）。Bessie 可以任选一个位置作为起点（也可以与某片草地重合，甚至坐标不必是整数），使得距离该位置不超过 $K$ 步的草地总草量最大（$1 \le K \le 2000000$）。

Bessie 每走一步就是向东、西、南、北移动 1 个单位，可以走非整数步。例如从 $(0,0)$ 走到 $(3,2)$ 需要 5 步，而 1 步也可以拆成"向北半格、向东半格"。

## 输入

- 第 1 行：两个整数 $N$ 和 $K$。
- 接下来 $N$ 行：每行三个整数 $g_i, x_i, y_i$，描述一片草地。

## 输出

- 一行：Bessie 在最佳位置能吃到的最多草量。

## 样例

输入：

```text
4 3
7 8 6
3 0 0
4 6 0
1 4 2
```

输出：

```text
8
```

样例解释：站在 $(3,0)$ 时，$(0,0)$、$(6,0)$、$(4,2)$ 三片草地的距离都不超过 3，共得到 $3+4+1=8$ 单位青草。

## 思路

Bessie 的行走方式是曼哈顿距离，而"曼哈顿距离不超过 $K$"在一对旋转后的坐标下会变成两个互相独立的一维条件。令

$$u = x + y, \qquad v = x - y,$$

由 $|\Delta x| + |\Delta y| = \max(|\Delta u|, |\Delta v|)$ 可知：位置 $(X, Y)$ 到第 $i$ 片草地的曼哈顿距离不超过 $K$，等价于

$$|u - u_i| \le K \quad \text{且} \quad |v - v_i| \le K.$$

于是每片草地在 $(u, v)$ 平面里对应一个边长 $2K$ 的轴对齐正方形，Bessie 能吃到第 $i$ 片草地的初始位置恰好落在其中。因为 $X = (u+v)/2$、$Y = (u-v)/2$ 对任意实数 $u, v$ 都成立，所以 $(u,v)$ 可以自由选取；并且把实数坐标取整不会丢掉任何一片草地：若实数 $u$ 满足 $u_i - K \le u \le u_i + K$，则 $\lceil u \rceil$ 也满足（$K$ 与 $u_i$ 都是整数），$v$ 方向同理。因此只需考虑整数坐标。

接下来做**按 $u$ 横扫 + 线段树**：每片草地产生两个事件——在 $u_i - K$ 处对 $v$ 区间 $[v_i - K, v_i + K]$ 整体加上 $g_i$，在 $u_i + K + 1$ 处减去 $g_i$（取 $+K+1$ 是为了让 $u = u_i + K$ 上这片草地仍然有效）。把全部 $v$ 端点排序去重后压缩坐标，线段树维护"区间整体加"和全局最大值，那么处理完同一个 $u$ 坐标上的所有事件后，树根的值就是 Bessie 站在该 $u$ 处能吃到的最多草量。对所有事件坐标取最大值即为答案。

由于只查询树根，区间加的懒标记不必下传：结点存的最大值满足"自身标记 $+$ 两个孩子最大值的较大者"即可。
