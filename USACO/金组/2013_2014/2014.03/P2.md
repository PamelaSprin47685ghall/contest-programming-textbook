# P2　破坏（Sabotage）

## 题目

农夫约翰的死对头农夫保罗决定破坏约翰的挤奶设备！

挤奶设备由一排 $N$ 台挤奶机组成（$3 \le N \le 100000$），第 $i$ 台机器产奶 $M_i$ 单位（$1 \le M_i \le 10000$）。保罗打算拆掉一段连续的机器——从第 $i$ 台到第 $j$ 台（$2 \le i \le j \le N-1$）；注意保罗不想拆掉第一台或最后一台机器，否则阴谋太容易被发现。保罗的目标是让剩下机器的**平均**产奶量尽可能低。哪怕拆掉一台会让平均值变高，保罗也一定会至少拆掉一台机器。

约翰已经得知了保罗的阴谋，他非常想知道：如果阴谋得逞，情况会有多糟。请帮约翰算出保罗得手后剩下机器可能达到的最低平均产奶量。

## 输入

- 第 1 行：整数 $N$。
- 接下来 $N$ 行：每行一个整数 $M_i$。

## 输出

- 一行：保罗能达到的最低平均产奶量，保留 3 位小数。

## 样例

输入：

```text
5
5
1
7
8
2
```

输出：

```text
2.667
```

样例解释：最优方案是拆掉 7 和 8，剩下 5、1、2，平均值为 $8/3 \approx 2.667$。

## 思路

设全部机器的产奶总量为 $S$。如果保罗拆掉一段长度为 $L$、和为 $X$ 的机器，剩下机器的平均值就是 $(S - X)/(N - L)$。直接枚举所有连续段需要 $O(N^2)$，所以改为**对答案二分**：猜测一个值 $B$，判断是否存在可拆的连续段，使得剩下的平均值不超过 $B$。

判断条件可以化成只有"和"的形式。剩余平均值 $\le B$ 等价于

$$S - X \le B(N - L) \iff X - B \cdot L \ge S - B \cdot N.$$

也就是说，把每台机器的产奶量都减去 $B$ 之后，"被拆掉那段的和"要不小于"全部机器调整后的总和"。这个条件对被拆段的和是单调的：段的和越大越容易成立，因此只需检查**和最大**的那一段——这正是最大子段和问题，用 Kadane 算法在 $O(N)$ 内解决（注意段的左右端点必须落在 $2 \sim N-1$，且非空）。

判断函数关于 $B$ 单调（$B$ 越大越容易满足），所以从 $B=0$（一定不可行，因为产奶量至少为 1）和 $B=10001$（一定可行）出发二分 100 次，最后取区间中点按 3 位小数输出。
