# P3　数朋友（Counting Friends）

## 题目

农夫约翰的 $N$ 头奶牛（$2 \le N \le 500$）加入了社交网络 "MooBook"。每头奶牛至少有一个朋友。约翰一时兴起，把每头奶牛的朋友个数列成了一张表，但在写的过程中走了神，多写了一个数——表里共有 $N+1$ 个数，而不是他本想要的 $N$ 个。

请帮约翰找出：表中的哪些数有可能是那个多写的数。

## 输入

- 第 1 行：整数 $N$。
- 接下来 $N+1$ 行：每行一个整数，表示一头奶牛的朋友数，或者那个多写出来的数。

## 输出

- 第 1 行：整数 $K$，表示表中可能是多余数字的个数（$K=0$ 表示没有任何一个数删掉后能得到可行的朋友关系）。
- 接下来 $K$ 行：按升序给出每个可能是多余数字的**编号**（$1 \sim N+1$，即它在输入中的位置）。

## 样例

输入：

```text
4
1
2
2
1
3
```

输出：

```text
3
1
4
5
```

样例解释：删掉第 1 个数（值为 1）后剩下 $2,2,1,3$，令奶牛为 A、B、C、D，朋友关系 (A,B)、(A,C)、(A,D)、(B,C) 恰好使 A 有 3 个朋友、B 和 C 各有 2 个、D 有 1 个，可行。删掉另一个 "1"（第 4 个数）同理可行；删掉 "3"（第 5 个数）后剩下 $1,2,2,1$，也可行。而删掉任何一个 "2" 后剩下数字之和为奇数，无法两两配对，所以不可行。

## 思路

把一头奶牛看作图中的一个点，"朋友关系"就是一条无向边，那么问题就是：给定一个度数序列，它能否是某个**简单图**（无重边、无自环）的度数序列？只要对 $N+1$ 个位置各尝试删去一个数、判断剩下的 $N$ 个度数是否"可成图"即可。

仅仅检查度为奇数 / 总和为偶数是不够的（例如一个点度为 0、另一个点度为 $N-1$ 就无法同时成立），需要用 **Erdős–Gallai 定理**：把度数按从大到小排成 $d_1 \ge d_2 \ge \dots \ge d_n$，该序列可成简单图当且仅当总和为偶数，且对每个 $k = 1, 2, \dots, n$ 都有

$$\sum_{i=1}^{k} d_i \le k(k-1) + \sum_{i=k+1}^{n} \min(d_i, k).$$

右式的含义是：前 $k$ 个点的度数之和受限于"这 $k$ 个点内部最多贡献 $k(k-1)$"加上"其余点最多各贡献 $\min(d_i, k)$"。

每次检查需要 $O(n)$：先排序并求出前缀和；对每个 $k$，因为序列递减，满足 $d_i \le k$ 的位置构成一个后缀，随 $k$ 增大只会变长，用一个指针从右往左滑动即可；于是 $\sum_{i>k}\min(d_i,k) = k \cdot(\text{该后缀之前、位置在 } k \text{ 之后的那几个数}) + (\text{后缀的度数之和})$，都可 $O(1)$ 算出。

## 复杂度

每个位置检查一次，单次 $O(N)$，总时间复杂度 $O(N^2)$（$N \le 500$），空间复杂度 $O(N)$。
