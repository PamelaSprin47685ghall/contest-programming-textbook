# P2　奶牛光学（Cow Optics）

## 题目

激光位于 $(0,0)$，朝正北（$+y$ 方向）射出一束光；谷仓在 $(Bx, By)$。平面上还散落着 $N$ 头奶牛（$1 \le N \le 100000$），每头牛举着一面与坐标轴成 $45^\circ$ 的镜子（`/` 或 `\`），镜子位置用整数坐标给出，所有坐标的绝对值不超过 $10^9$。

`/` 镜把 北$\leftrightarrow$东、南$\leftrightarrow$西 互换，`\` 镜把 北$\leftrightarrow$西、南$\leftrightarrow$东 互换。当前配置下激光**打不到**谷仓。Bessie 要再在某个位置举一面 $45^\circ$ 镜子（可以选 `/` 或 `\`），把激光引到谷仓上。

求这样的位置个数。保证：光离开起点后不会回到 $(0,0)$；没有两头牛站在同一点；Bessie 不能站在已有奶牛的位置上；任何可放镜子的位置坐标也都在 $[-10^9, 10^9]$ 内。

## 输入

- 第 1 行：三个整数 $N$、$Bx$、$By$。
- 接下来 $N$ 行：每行两个整数 $x,y$ 和一个字符（`/` 或 `\`），描述一面镜子的位置与朝向。

## 输出

- 一行：Bessie 可以站的位置个数。

## 样例

输入：

```text
4 1 2
-2 1 \
2 1 /
2 2 \
-2 2 /
```

输出：

```text
2
```

样例解释：在 $(0,1)$ 或 $(0,2)$ 放一面镜子（两个朝向之一均可）都能把激光引到谷仓 $(1,2)$。

## 思路

### 关键结论：新镜子一定在两条光路的交点上

设激光在**原配置**（不额外放镜子）下走出的光路为 $L$。

- 新镜子必须落在 $L$ 上。否则激光在碰到它之前的那段轨迹与原来完全一样，自然也就照旧打不到谷仓。
- 反过来看，把谷仓当成光源，朝四个方向各射一束光，得到四条光路 $B_0,B_1,B_2,B_3$（下标为出发方向）。新镜子必须落在其中某一条上：因为把激光引到谷仓的那段"末段"光路，正是从谷仓出发沿相反方向走出来的路径，倒着走就是原光路的一段。
- 两条光路在该点还必须**十字相交**（一横一竖）。若同向或反向相交，激光经过这面镜子后方向不变，仍打不到谷仓；而只要十字相交，把激光朝两个拐弯方向之一拧过去就必然沿着谷仓光路奔谷仓去了。

于是问题化为：统计 $L$ 与 $B_d$ 的交点数（竖直段与水平段的交点），$d$ 取四个方向。

### 细节一：成环的光路要少记一份

如果从谷仓出发的某条光路绕了一圈又回到谷仓，那么这条光路是个**环**。环上的点往环的两个方向走都能回到谷仓，因此该点放 `/` 或 `\` 都行；但同一个环会分别从两个相反的出发方向各被扫描一次，交点数会被重复计入，所以这种情况只按 1 份计，其余情况按 2 份计，最后统一除以 2 得到位置数。

### 细节二：交点的端点归属

两条光路的顶点都是镜子（或起点、出界点），所以"交点落在端点"的情形必须处理干净，否则会把已有奶牛的位置算进去：

- 竖直段 $(x_0; [ylo,yhi])$ 与水平段 $(y_0; [xlo,xhi])$ 计一次交点，当且仅当 $xlo \le x_0 < xhi$ 且 $ylo < y_0 \le yhi$。

扫描线实现：把水平段的两个端点作为事件，按 $x$ 从小到大处理；每条竖直段都在"它右侧第一个事件到达之前"被统计一次，此时树里恰好留下满足 $xlo \le x_0 < xhi$ 的水平段。纵坐标离散化后用树状数组查询区间和，查询区间取 $(ylo, yhi]$。

### 实现要点

- 用 `map<int, vector<...>>` 分别维护"每列的物体（按 $y$ 排序）"和"每行的物体（按 $x$ 排序）"，模拟光束时二分找前进方向上最近的物体，复杂度 $O(\log N)$。
- 起点 `S` 与谷仓 `B` 也登记为物体，撞上它们光束就停止（保证光不会回到起点、也不会中途穿过谷仓）。
- 光路步数用 $4(N+2)$ 作上界（每个"物体 + 方向"状态至多经过一次），避免病态数据下死循环。
