# P3　破译密码（Code Breaking）

## 题目

密码写在一棵 $N$（$1\le N\le 20000$）个节点的有根树上，每个节点是 $0$ 到 $9$ 的数字。给出 $M$（$1\le M\le 50000$）条长度为 5 的禁止模式，每条模式从指定节点起、沿父亲方向不能出现。求被排除的密码数，对 $1234567$ 取模。

## 输入

第一行 $N,M$。接下来 $N-1$ 行，第 $i$ 行是节点 $i$ 的父亲（节点从 0 编号）。再接下来 $M$ 行，每行一个起点和一条 5 位数字串。起点往上至少还有 4 步。

## 输出

一行，被排除的密码数模 $1234567$。

## 样例

输入：

```text
6 2
0
1
2
3
3
4 01234
5 91234
```

输出：

```text
19
```

## 思路

总方案是 $10^N$。合法方案用树形 DP 计数，两者相减就是被排除的方案数。

只保留当前最长匹配后缀。比它更早的数字已经不会影响后面的禁止模式，于是状态数从 $10^4$ 降到与“节点 + 模式后缀”同阶。

`treeDp[u][S]` 是节点 $u$ 的子树在上方后缀为 $S$ 时的合法填法；`assignedDp[u][S']` 是 $u$ 自己也已经填好后的填法。后者等于每个孩子方案数的乘积。用一棵线段树同时维护所有孩子：先替换恰好匹配当前后缀的孩子，递归更长后缀，再把替换撤销。模数不是质数，不能靠除法撤回某个孩子。
