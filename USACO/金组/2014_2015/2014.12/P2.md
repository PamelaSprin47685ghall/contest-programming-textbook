# P2　马拉松（Marathon）

## 题目

贝茜为同伴们设计了一条马拉松路线，路线由 $N$ 个检查点组成（$1 \le N \le 10^5$），必须按给定顺序依次经过。可惜其他奶牛体力可能不够，于是贝茜想考查某些子路线的用时：子路线是路线上连续的一段检查点。更麻烦的是，懒惰的奶牛跑一条子路线时还可能顺手跳过其中一个检查点——取能让总用时最少的那个——但子路线的首尾两个检查点不许跳过。

贝茜还要研究修改检查点位置带来的影响。请你帮她依次处理这些修改与询问，算出每条子路线的最短用时。

城市是网格状的街道，两个检查点 $(x_1,y_1)$ 与 $(x_2,y_2)$ 之间的距离是曼哈顿距离 $|x_1-x_2|+|y_1-y_2|$。

## 输入

第一行两个整数 `N Q`（$1 \le Q \le 10^5$）。

接下来 $N$ 行，每行两个整数，给出 $N$ 个检查点的坐标，按必须经过的顺序排列（坐标范围 $-1000 \sim 1000$）。

接下来 $Q$ 行，每行一条操作，按给出的顺序处理：

- `U I X Y`：把第 $I$ 个检查点的位置改成 $(X,Y)$；
- `Q I J`：询问从第 $I$ 个到第 $J$ 个检查点的子路线（$I \le J$），在允许跳过中间一个检查点时，最少要跑多远。

## 输出

对每条 `Q` 询问输出一行一个整数，表示该子路线的最短用时。

## 样例

输入：

```text
5 5
-4 4
-5 -3
-1 5
-3 4
0 5
Q 1 5
U 4 0 1
U 4 -1 1
Q 2 4
Q 1 4
```

输出：

```text
11
8
8
```

第一次询问中不跳点时总路程为 $8+12+3+4=27$，跳过第 2 个检查点可以省下 $8+12-4=16$，剩下 11。

## 思路

**拆成"整段和"减"最大节省"。** 记 $d_k$ 为第 $k$ 与第 $k+1$ 个检查点的曼哈顿距离。若两点只差一个下标之外没有可跳点，答案就是 $\sum_{k=i}^{j-1} d_k$；若中间有点，跳过第 $k$ 个（$i<k<j$）会把它前后的两段换成一段直连，省下

$$g_k=d_{k-1}+d_k-\operatorname{dist}(k-1,k+1)\ \ge 0 .$$

由三角不等式知 $g_k$ 恒非负，所以"最多跳一个"与"必须跳一个"答案相同，取区间内 $g_k$ 的最大值即可。于是

$$\text{answer}(i,j)=\sum_{k=i}^{j-1} d_k-\max_{i<k<j} g_k .$$

**为什么可以用线段树。** 询问要区间和、区间最值，修改又要立刻生效——正是单点修改 + 区间查询的经典场景。用一棵线段树，每个位置 $k$ 的叶子同时存 $d_k$ 与 $g_k$，内部结点分别维护"区间 $d$ 之和"和"区间 $g$ 的最大值"。

**修改只波及常数个叶子。** 只有 $d_{I-1}$、$d_I$ 和 $g_{I-1}$、$g_I$、$g_{I+1}$ 用到检查点 $I$，所以改一个点只需重写叶子 $k \in [I-1, I+1] \cap [1, N-1]$ 并自底向上刷新它们的祖先。

**边界处理。** 首尾检查点不允许跳过，故 $g_1$ 与 $g_N$ 置为 $-\infty$；询问 $I=J$ 时不用走路，答案为 $0$；$J=I+1$ 时没有中间点，直接输出 $d_I$。

## 复杂度

时间 $O((N+Q)\log N)$：建树 $O(N)$，每次修改或询问都在线段树上走 $O(\log N)$ 个结点。空间 $O(N)$：线段树存两套数组。
