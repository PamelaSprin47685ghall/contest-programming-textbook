# P3　奶牛慢跑（Cow Jog）

## 题目

农夫约翰的 $N$ 头奶牛（$1 \le N \le 10^5$）又在活动蹄子了，它们在一条无限长的跑道上慢跑。每头奶牛从跑道上互不相同的位置出发，速度也可能不同。

跑道被划分成若干条平行的分道，奶牛可以互相超越；但在同一条分道里的两头奶牛任何时刻都不能处于同一位置。约翰不愿让奶牛变道或调速，他想知道：如果奶牛要跑 $T$ 分钟（$1 \le T \le 10^9$），至少需要多少条分道。

## 输入

第一行两个整数 `N T`。

接下来 $N$ 行，每行两个整数，表示一头奶牛的初始位置与速度。位置是非负整数，速度是正整数，都不超过 $10^9$。所有奶牛的初始位置互不相同，且按递增顺序给出。

## 输出

一个整数：使得同一条分道内没有两头奶牛在**任意时刻（含 $T$ 时刻）**占据同一位置所需的最少分道数。

## 样例

输入：

```text
5 3
0 1
1 2
2 3
3 2
6 1
```

输出：

```text
3
```

$T=3$ 时五头奶牛的位置分别是 $3,7,11,9,9$：第 3 头牛会超过第 4、5 头，第 4 头牛会追平第 5 头牛，它们两两都不能同分道，所以至少有 3 条分道的牛相互纠缠（例如第 3、4、5 头），3 条分道也够用。

## 思路

**谁和谁不能同分道。** 初始位置靠前的牛 $i$ 会超过（或正好在 $T$ 时刻追平）初始位置靠后的牛 $j$（$i<j$）当且仅当它们的终点位置满足

$$x_i+v_iT\ \ge\ x_j+v_jT .$$

反过来说，一组奶牛能共用一条分道，当且仅当按初始位置排列时它们的终点位置**严格递增**。要求最少的严格递增子序列把整个序列覆盖，由 Dilworth 定理（或官方题解里"把不被任何牛超过的牛放进同一条分道，再删掉它们重复"的贪心证明），这个数目恰好等于**最长不上升子序列**的长度。

**转成 LIS。** 把终点位置全部取相反数 $y_k=-(x_k+v_kT)$，不上升就变成了不下降，于是只需用经典的贪心 + 二分（`upper_bound`）求最长不下降子序列的长度：维护 `tails[k]` 为长度 $k+1$ 的不下降子序列末尾元素的最小值，依次把 $y_k$ 接到第一个大于 $y_k$ 的元素上、放不下就直接接在末尾。

**细节。** $x,v,T$ 都可达 $10^9$，$vT$ 能到 $10^{18}$，必须用 64 位整数；终点相同时两头牛会在 $T$ 时刻相遇，因此允许相等是一个极限情况，对应的"不下降"判断要带上等号。
