# P3　围住牛群（Fencing the Herd）

## 题目

FJ 想用一条**直线**形状的围栏限制奶牛的活动范围。一条直线围栏可用，当且仅当所有奶牛都位于它的同一侧；只要有一头奶牛正好落在围栏上，这条围栏就不可用。

他会不断询问一些候选围栏，并且时不时把一头新奶牛加进牛群——从那一刻起，之后的所有围栏查询都必须让这头新牛也满足"在同一侧"的条件。

给定 $N$（$1 \le N \le 10^5$）头牛的初始位置和 $Q$（$1 \le Q \le 10^5$）条操作：

- `1 x y`：往牛群里加入位于 $(x,y)$ 的新奶牛；
- `2 A B C`：询问直线 $Ax+By=C$ 是否可用。

所有奶牛的位置互不相同，坐标满足 $-10^9 \le x, y \le 10^9$；查询满足 $-10^9 \le A, B \le 10^9$、$-10^{18} \le C \le 10^{18}$，且 $A$、$B$ 不同时为 $0$。

## 输入

- 第 1 行：两个整数 $N$、$Q$。
- 接下来 $N$ 行：每行两个整数 $x$、$y$，描述初始牛群。
- 接下来 $Q$ 行：每行形如 `1 x y` 或 `2 A B C` 的一条操作。

## 输出

对每条查询，输出一行 `YES`（围栏可用）或 `NO`（围栏不可用）。

## 样例

输入：

```text
3 4
0 0
0 1
1 0
2 2 2 3
1 1 1
2 2 2 3
2 0 1 1
```

输出：

```text
YES
NO
NO
```

解释：记 $f(x,y)=Ax+By$。直线 $2x+2y=3$ 下，三头牛的 $f$ 分别是 $0,2,2$，全都小于 $3$，所以可用；加入 $(1,1)$ 后它的 $f=4>3$，牛群被这条线分成两半，于是不可用；直线 $y=1$ 上有两头牛（$f$ 恰好等于 $C=1$），所以也不可用。

## 思路

把"是否可用"翻译成最值条件。记 $f(p) = A x_p + B y_p$，则

- 所有牛都在直线严格一侧 $\iff$ $\max_p f(p) < C$ 或者 $\min_p f(p) > C$；
- 只要 $\min_p f(p) \le C \le \max_p f(p)$，就说明直线把牛群切开或压到了某头牛，围栏不可用。

于是问题变成：**带插入地维护点集，查询给定方向 $(A,B)$ 上的最大、最小点积**。

线性函数在点集上的最值一定在凸包顶点上取到，所以只需要维护点集的凸包：

- 最初的 $N$ 头牛永远不变，给它们建一个静态凸包 $H_0$；
- 之后加入的牛用**倍增法（二进制分组）动态凸包**维护：第 $i$ 层存一个大小恰好为 $2^i$ 的凸包，新点先自成一团，从小到大逐层合并，遇到空层就把合并结果放进去。一次插入最多触发每层各一次重建，均摊复杂度是 $O(\log^2 n)$；
- 一次查询只需在 $H_0$ 和动态结构的每一层上各求一次最值。最小值由 $"$凸包在 $-pt$ 方向上的最大值$\times (-1)"$ 得到。

在**逆时针**凸包上求方向 $pt=(A,B)$ 对应的最大点积用二分：以 $P_0-P_{n-1}$（即首尾相接的那条边反向）作为极角扫描的起点，把每条"边向量"和 $pt$ 逆时针旋转 $90^\circ$ 后的向量按极角先后比较，二分出最优顶点，单次 $O(\log n)$。

所有几何判定都保持整数：$|x|,|y|,|A|,|B| \le 10^9$ 时，叉积里是两个差向量各分量的乘积之差，绝对值不超过 $2 \times (2\cdot 10^9)^2 = 8 \times 10^{18} < 2^{63}-1$，点积不超过 $2\times 10^{18}$，都在 `long long` 范围内，因此不需要浮点也不需要更宽的类型。

## 复杂度

插入均摊 $O(\log^2 n)$，查询 $O(\log^2 n)$（$O(\log n)$ 层凸包，每层二分 $O(\log n)$）；总时间复杂度 $O(N\log N + Q\log^2 Q)$，空间 $O((N+Q)\log(N+Q))$。
