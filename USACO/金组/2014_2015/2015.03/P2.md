# P2　回文路径（Palindromic Paths）

## 题目

农夫约翰的农场是一个 $N \times N$ 的网格（$1 \le N \le 500$），每个格子里写着字母表里的一个字母。每天贝茜从左上角的格子走到右下角的格子，每步只能向右或向下走一格，她沿途经过的字母按顺序连成一个字符串。

如果这个字符串是**回文**（正着读和倒着读一样），贝茜就会晕头转向，分不清自己走的是哪个方向。请帮贝茜算出有多少条路线形成的字符串是回文。不同路线即使形成同一个回文也分别计数，答案对 $10^9+7$ 取模。

## 输入

第一行一个整数 $N$。接下来 $N$ 行，每行 $N$ 个大写字母（A 到 Z），描述网格。

## 输出

输出回文路线的条数对 $10^9+7$ 取模的结果。

## 样例

输入：

```text
4
ABCD
BXZX
CDXB
WCBA
```

输出：

```text
12
```

样例里 12 条路线分别形成 `ABCDCBA`（1 条）、`ABCWCBA`（1 条）、`ABXZXBA`（6 条）和 `ABXDXBA`（4 条）。

## 思路

每条路线恰好包含 $2N-1$ 个格子，回文意味着第 $k$ 个格子与倒数第 $k$ 个格子的字母必须相同。于是可以**从正中间的格子向外一层层配对**：把中心格和它两侧的格子看成同一条反对角线（`行号 + 列号 = N-1`），每向外扩一层，就从中心左右各加上一对格子，并检查这一对格子上的字母是否相同。

设 $f(a, r_1, r_2)$ 表示已经向外扩了 $a$ 层、左侧端点在第 $r_1$ 行、右侧端点在第 $r_2$ 行时，合法的配对方案数。由于左右端点所在的反对角线完全由 $a$ 决定（左侧满足 `行 + 列 = N-1-a`，右侧满足 `行 + 列 = N-1+a`），列号都能由行号唯一算出，状态里只要存两个行号。

- 初始状态（$a = 0$）：左右端点重合在中心格 $(r, N-1-r)$ 上，长度为 $1$ 的串必是回文，所以 $f(0, r, r) = 1$。
- 转移：左侧端点向外走一步只有两种走法——向左 $(r_1, c_1-1)$ 或向上 $(r_1-1, c_1)$；右侧端点同理只有向右 $(r_2, c_2+1)$ 或向下 $(r_2+1, c_2)$。两两组合最多四种，其中越界要去掉；若新配成的一对字母不同，则这条配对无效，不计入。所有贡献累加并取模即可。

扩到最外层时左侧端点只能是 $(0,0)$、右侧端点只能是 $(N-1,N-1)$，所以答案就是 $f(N-1, 0, N-1)$。实现上枚举 $r_1$ 时限制 $r_1 \le N-1-a$、枚举 $r_2$ 时限制 $r_2 \ge a$（其余位置对应的列号会越界），这样每层只需处理大约 $(N-a)^2$ 个状态。

注意 DP 值是"方案数"而不是"不同回文串个数"，所以同一个回文被多条路线产生时就是被累加多次，这与题目要求一致（样例中 `ABXZXBA` 计了 $6$ 次）。

## 复杂度

时间 $O(N^3)$（第 $a$ 层处理 $O((N-a)^2)$ 个状态，四种转移是常数；$N = 500$ 时约 $4 \times 10^7$ 次运算）；空间 $O(N^2)$（滚动两个 $N \times N$ 的数组）。
