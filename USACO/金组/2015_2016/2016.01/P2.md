# P2　无线电联络（Radio Contact）

## 题目

FJ 的牛铃丢了，他和 Bessie 分头在农场里找，靠无线电保持联系（$1 \le N, M \le 1000$）。

FJ 从 $(f_x, f_y)$ 出发，按给定的 $N$ 步路径走，每步是 `N`、`E`、`S`、`W` 之一；Bessie 从 $(b_x, b_y)$ 出发，按给定的 $M$ 步路径走。每一时刻，两人都可以选择"原地不动"或"沿自己的路径向前走一步"。

从第 1 步之后开始（即起始时刻不计），每个时刻无线电消耗的能量等于两人距离的平方。求两人都到达各自路径终点时，消耗的总能量最小值。

## 输入

- 第 1 行：两个整数 $N$ 和 $M$。
- 第 2 行：两个整数 $f_x, f_y$。
- 第 3 行：两个整数 $b_x, b_y$。
- 第 4 行：长度为 $N$ 的字符串，描述 FJ 的路径。
- 第 5 行：长度为 $M$ 的字符串，描述 Bessie 的路径。

保证两人全程坐标都在 $0 \dots 1000$ 内；`E` 是 $x$ 正方向，`N` 是 $y$ 正方向。

## 输出

一行一个整数：最小总能量。

## 样例

输入：

```text
2 7
3 0
5 0
NN
NWWWWWN
```

输出：

```text
28
```

## 思路

这题本质上是"动态时间规整"（DTW）：两条路径可以各自暂停，代价函数是两人距离的平方，要找出一种对齐方式使总代价最小。

先把两人的路径展开成位置序列：`px[i], py[i]` 是 FJ 走完前 $i$ 步后的位置，`qx[j], qy[j]` 同理，$i$ 取 $0 \dots N$，$j$ 取 $0 \dots M$。

设 `dp[i][j]` 表示"FJ 走到第 $i$ 个位置、Bessie 走到第 $j$ 个位置"时的最小累计能量。一个时刻两人各自至多前进一步，所以这个状态只能由三个更早的状态转移而来：

- 只有 FJ 前进：`dp[i-1][j]`；
- 只有 Bessie 前进：`dp[i][j-1]`；
- 两人同时前进：`dp[i-1][j-1]`。

无论从哪来，新的这个时刻两人的距离就是当前位置 $i$、$j$ 的坐标差，能量按"到达后的距离平方"计入；起点 `dp[0][0] = 0` 不产生能量。于是

`dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + (px[i]-qx[j])^2 + (py[i]-qy[j])^2`。

按 $i$ 从小到大、$j$ 从小到大填表即可（三个前驱都已经算好），答案是 `dp[N][M]`。距离平方最大约 $2 \times 10^6$、时间步最多 $2000$，累计值会超过 `int`，所以要用 `long long`。
