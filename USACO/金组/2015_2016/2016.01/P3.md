# P3　熄灯（Lights Out）

## 题目

FJ 的谷仓是一个简单（不自交）多边形，$N$ 个顶点按顺时针给出（$4 \le N \le 200$，坐标范围 $-100000 \dots 100000$），每条边都平行于坐标轴，且横边和竖边交替出现。出口在第 $1$ 个顶点，Bessie 站在某个非出口的顶点上，只能沿着多边形的周长走。

- 灯亮时：她直接沿周长向两个方向中较短的一侧走到出口。
- 灯灭时：她按如下策略走——沿顺时针方向一直走，每到一个顶点就摸出该顶点处的内角大小，走完一条边就知道这条边的确切长度；一旦根据摸到的角度和边长序列能够唯一确定自己所在的顶点，就停下来，再改走（沿剩余周长的两个方向中）较短的一侧去出口。

求：在最坏的起始顶点上，灯灭时所走路程比灯亮时最多增加多少。

## 输入

- 第 1 行：一个整数 $N$。
- 接下来 $N$ 行：每行两个整数 $x_i, y_i$，按顺时针顺序给出多边形顶点。

## 输出

一行一个整数：最坏情况下的最大增加量。

## 样例

输入：

```text
4
0 0
0 10
1 10
1 0
```

输出：

```text
2
```

解释：这个 $10 \times 1$ 的长方形里，四个顶点的内角都是 $90^\circ$，所以她一开始分不清自己在顶点 2、3、4 中的哪一个。从顶点 2 出发时，她走 1 个单位到顶点 3、摸到边长后就能确定位置，再走 11 个单位到出口，共 12；灯亮时只需 10，增加 2（另外两个起点的增加量分别是 0 和 0，所以答案是 2）。

## 思路

**把多边形抽象成字符串。** 她一路摸到的东西只有两类信息：顶点处的内角（直角多边形里内角只有 $90^\circ$ 和 $270^\circ$ 两种）和边长。把出口单独标成 `0`（一摸到出口她就知道自己到了哪里），两种转角分别标成 `-1`、`-2`（用相邻三点的叉积符号判定是左转还是右转），边用长度表示，就得到一个序列

```
S = 0, 边(0->1), 角(1), 边(1->2), 角(2), ..., 边(n-1->0), 0
```

长度是 $2N+1$：偶数下标是顶点信息（下标 $2n$ 是"出口标记 0"，下标 $0$ 也是），奇数下标是边长。从顶点 $k$ 出发（$k \ge 1$）时，她依次摸到的就是 $S[2k], S[2k+1], S[2k+2], \dots$，也即以 $2k$ 开头、长度为 $1, 3, 5, \dots$ 的子串。

**唯一性判定。** 摸完前 $t$ 条边后，她的"观察串"是以 $2k$ 开头、长度 $2t+1$ 的子串。只有当这个串在所有起点的对应长度子串中只出现一次时，她才能确定自己的位置。于是：

1. 用 `lcp[i][j]`（从 $i$、$j$ 出发的最长公共前缀，倒着递推一次）统计某个观察串的出现次数：出现次数就是满足 $\min(lcp[2k][2j],\ 2N+1-2j) \ge L$ 的起点 $2j$ 的个数。取 $\min$ 是因为某个起点可能走到出口就结束了，那种被截断的串更短，不会和完整的串相等。
2. 对每个起点，从 $L=1$ 开始每次加 $2$，直到出现次数为 $1$，中途走过的边长累加起来就是她在黑暗中走的路程。（最后一个串必然唯一：它以出口标记 $0$ 结尾，而序列里另一个 $0$ 在开头、前面凑不出同样的前缀。）
3. 灯亮时的最短距离 `opt[k]`：先把"沿顺时针一路走到出口"的长度算出来，再从 $k=n-1$ 到 $0$ 用另一侧的长度松弛一遍（顶点 $n$ 与出口重合，`opt[n] = 0`）。

答案为 `max(已走路程 + opt[认出的顶点] - opt[起点])`。

## 复杂度

时间 $O(N^3)$（起点的每个长度都要数一遍出现次数，$N \le 200$ 足够快），空间 $O(N^2)$。
