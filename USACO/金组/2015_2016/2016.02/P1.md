# P1　圆形谷仓（Circular Barn）

## 题目

谷仓呈正圆形，环形排列 $n$ 个房间（$3 \le n \le 100000$），按顺时针编号 $1 \dots n$。每个房间有两扇通往相邻房间的门，另有一扇通往谷仓外的门。

有 $n$ 头牛挤在门外，第 $i$ 个门外排着 $c_i$ 头牛，且 $\sum c_i = n$。Farmer John 要求每头牛从她排队的那扇门进谷仓，然后顺时针沿房间一直走，直到走到一个空房间安顿下来，最终恰好每个房间一头牛。

一头牛走过 $d$ 扇门要消耗 $d^2$ 点能量，求把牛安置好所需的最小总能量。

## 输入

- 第 1 行：一个整数 $n$。
- 接下来 $n$ 行：每行一个整数，依次给出 $c_1 \dots c_n$。

## 输出

一行一个整数：最小总能量。

## 样例

输入：

```text
10
1
0
0
2
0
0
1
2
2
2
```

输出：

```text
33
```

解释：从第 7 个房间处把环切开，各头牛走的门数依次是 $0,0,1,1,1,2,2,2,3,3$，平方和为 $1+1+1+4+4+4+9+9=33$。

## 思路

**第一步：确定每条"房间边界"上必须有几头牛经过。** 记 $x_i$ 为从房间 $i-1$ 走进房间 $i$ 的牛数（下标循环）。房间 $i$ 会等来 $c_i$ 头新牛，并留下恰好一头牛，所以

$$x_{i+1} = x_i + c_i - 1 .$$

在环上这个递推只能把整个序列整体平移：$x$ 的差值是唯一确定的，平移多少则自由。牛数不能是负数，且"多绕一圈"只会让总路程更长，所以最优取平移量使得 $\min x_i = 0$ —— 即存在一段没有任何牛经过的边界，那里就是自然的切点。

求切点只需前缀和：先算 $p_i = \sum_{j < i}(c_j - 1)$（以 $1$ 号门为起点的 $x_i$），取使 $p_i$ 最小的那个位置为起点，则从该处出发 $x = p_i - \min p$ 恒不为负，正是一条合法的切法。这就是经典的"环形加油站"技巧。

**第二步：给定 $x$ 后直接构造分配。** 从切点出发按顺时针顺序处理每个门口：门口 $i$ 进来的 $c_i$ 头牛分别走

$$x_i,\; x_i + 1,\; \dots,\; x_i + c_i - 1$$

步。因为 $x_i + c_i - 1 = x_{i+1}$，这一批牛的落点区间是 $[i + x_i,\; i + x_{i+1}]$，而下一个门口 $i+1$ 的落点区间从 $i + 1 + x_{i+1}$ 开始，恰好紧接在它后面。于是所有落点区间首尾相接、不重不漏，正好铺满 $n$ 个房间——每个房间一头牛，且所有距离都是非负的顺时针距离，构造合法。

**第三步：它为什么是最优的。** 官方分析的交换论证：若牛 $A$ 越过了牛 $B$ 的起点，则 $A$ 的终点可以挪到 $B$ 的终点之前（把两头牛的终点互换不会让答案变差），这说明最优解中"先出发的牛可以先下车"，排序配对的代价不高于任何交叉配对；又因为距离的平方是凸函数，在总距离固定时把距离摊得越平均代价越小，所以上述"按顺序落点"的分配达到下界。于是答案就是

$$\sum_i \Big[\big(x_i + c_i - 1\big)^2 + \dots + x_i^2\Big] = \sum_i \big(S(x_i + c_i - 1) - S(x_i - 1)\big),\qquad S(v) = \frac{v(v+1)(2v+1)}{6}.$$

代码里只需按顺时针扫一遍，用 $S$ 一次算出每批牛的平方和；所有量都可能是 $O(n^2)$ 级别，用 `long long`。
