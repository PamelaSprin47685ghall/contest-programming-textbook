# P2　关闭农场（Closing the Farm）

## 题目

农场由 $N$ 个谷仓（$1 \le N \le 200000$）和 $M$ 条双向道路（$1 \le M \le 200000$）构成。FJ 每次关闭一个谷仓，同时关闭与它相邻的所有道路。他想知道：在最初以及每关闭一个谷仓之后，还开着的谷仓构成的农场是否**完全连通**——任意两个开着的谷仓之间都能沿道路互相到达。农场一开始可能就不完全连通。

## 输入

- 第 1 行：两个整数 $N$ 和 $M$。
- 接下来 $M$ 行：每行两个整数，表示一条道路连接的两个谷仓编号。
- 最后 $N$ 行：$1 \ldots N$ 的一个排列，表示谷仓被关闭的先后顺序。

## 输出

$N$ 行，每行 `YES` 或 `NO`。第 1 行表示初始状态；第 $i+1$ 行（$1 \le i \le N-1$）表示按关闭顺序关掉第 $i$ 个谷仓之后的状态。

## 样例

输入：

```text
4 3
1 2
2 3
3 4
3
4
1
2
```

输出：

```text
YES
NO
YES
YES
```

## 思路

正向"删点删边"很难维护连通性，但**把时间倒过来**就变成了简单的"加点加边"：按关闭顺序的逆序依次让谷仓复活，复活一个谷仓时，把它与所有已经复活的邻点合并。

用并查集（DSU）维护当前开着（已复活）的谷仓形成的连通块个数 `comps`。逆序处理到关闭顺序里第 $t$ 个谷仓时：先让谷仓 $v$ 复活，`comps` 加一；再遍历 $v$ 的所有邻点，只处理已经复活的邻点（尚未复活的谷仓此刻还不存在），若两者不在同一连通块就合并，`comps` 减一。

处理完顺序里第 $t$ 个谷仓后，处于"已复活"状态的谷仓集合恰好就是**关闭前 $t$ 个谷仓之后**剩下的集合，所以此刻 `comps == 1` 就是那一时刻的答案；循环结束时 $t = 0$，得到初始状态的答案。最后按 $t = 0, 1, \ldots, N-1$ 顺序输出。

并查集带路径压缩与按大小合并，单次操作近似常数。
