# P3　合成 248（248）

## 题目

Bessie 在玩一个数字合并游戏。序列长度为 $N$（$2 \le N \le 248$），每个数都在 $1 \ldots 40$ 之间。每次操作可以选两个**相邻且相等**的数 $v, v$，把它们替换成一个 $v+1$。游戏结束时（可以随时停手），求序列中能出现的最大数最大是多少。

## 输入

- 第 1 行：一个整数 $N$。
- 接下来 $N$ 行：每行一个整数，依次给出初始序列。

## 输出

一行一个整数：能生成的最大数。

## 样例

输入：

```text
4
1
1
1
2
```

输出：

```text
3
```

解释：先把第 2、3 个 $1$ 合并成 $2$，得到 $1\ 2\ 2$，再把两个 $2$ 合并成 $3$。

## 思路

区间 DP。设 $dp[i][j]$ 表示区间 $[i, j]$ 能否被**完全合并成一个数**：若能，它就是这个数；若不能，记为 $-1$。

之所以只需存一个值：一个区间能合成的数只由这个区间本身决定（若它能合出 $v$，则它的元素总"势"固定，它不可能还能合出别的数），所以"最大可合成值"与"唯一可合成值"是一回事。

转移：区间长度大于 $1$ 时，最后一次操作必然是把左半截 $[i, k]$ 合出的数与右半截 $[k+1, j]$ 合出的数合并，两者必须相等，于是

$$dp[i][j] = \max\{\, dp[i][k] + 1 \;\big|\; dp[i][k] = dp[k+1][j] > 0 \,\}.$$

长度为 $1$ 时 $dp[i][i] = a_i$。答案取所有 $dp[i][j]$ 的最大值——因为不必把整个序列合完（例如样例中第一个 $1$ 保持原样），任何子区间合出的数都可能成为最终序列里的最大值。

按区间长度从小到大递推，所有被引用的子区间都比当前区间短，递推顺序合法。
