# P2　奶牛清单（Cow Checklist）

## 题目

Farmer John 有两群奶牛：$H$ 头 Holstein（编号 $1 \ldots H$）和 $G$ 头 Guernsey（编号 $1 \ldots G$），其中 $1 \le H \le 1000$，$1 \le G \le 1000$。每头牛都站在平面上的一个点（不同的牛可以重合）。

FJ 从 Holstein 1 出发，最后停在 Holstein $H$，路途中要拜访到每一头牛。为了方便核对清单，他希望同一品种的牛按编号顺序被拜访：也就是整条拜访序列是把 $1 \ldots H$ 和 $1 \ldots G$ 两个序列交错合并得到的。

从一头牛走到另一头牛，走多远就消耗距离平方那么多的能量。求拜访完全部牛所需的最小能量。

## 输入

第一行两个整数 `H G`。

接下来 $H$ 行，每行两个整数 `x y`，依次是 Holstein $1 \ldots H$ 的坐标；再接下来 $G$ 行，每行两个整数，依次是 Guernsey $1 \ldots G$ 的坐标。所有坐标在 $0 \ldots 1000$ 之间。

## 输出

一行一个整数，表示完成这次巡检所需的最小能量。

## 样例

输入：

```text
3 2
0 0
1 0
2 0
0 3
1 3
```

输出：

```text
20
```

解释：最优路线是 H1(0,0) → G1(0,3) → G2(1,3) → H2(1,0) → H3(2,0)，能量为 $9+1+9+1=20$。

## 思路

两种牛的拜访顺序都被编号锁死了，所以"路线"并不自由：任意时刻，有用的历史只有"已经拜访了前 $i$ 头 Holstein、前 $j$ 头 Guernsey"，再加上"此刻站在哪一头牛上"。后面能怎么走只由这三件事决定。

据此设计状态：

- $f(i, j)$：拜访完前 $i$ 头 Holstein 和前 $j$ 头 Guernsey，且此刻停在第 $i$ 头 Holstein，消耗的最小能量；
- $g(i, j)$：拜访数量相同，但此刻停在第 $j$ 头 Guernsey 的最小能量。

转移时只看"上一头牛是谁"：

$$f(i,j) = \min\big(f(i-1,j) + d(H_{i-1}, H_i),\ g(i-1,j) + d(G_j, H_i)\big)$$
$$g(i,j) = \min\big(f(i,j-1) + d(H_i, G_j),\ g(i,j-1) + d(G_{j-1}, G_j)\big)$$

其中 $d$ 是两点距离的平方。初值 $f(1,0)=0$（站在起点 Holstein 1、还没走路），其余状态为无穷大；答案取 $f(H,G)$，因为题目要求最后停在 Holstein $H$。转移全部是"往前走"（$i$ 或 $j$ 增大），所以按 $i$ 递增、$j$ 递增的顺序填表即可。

能量的上界约为 $(H+G) \times 2 \times 1000^2 \approx 4 \times 10^9$，超过了 `int`，要用 `long long`。
