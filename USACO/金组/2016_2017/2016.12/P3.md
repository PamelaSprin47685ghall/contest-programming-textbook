# P3　激光与镜子（Lasers and Mirrors）

## 题目

FJ 的奶牛要办激光表演。激光器固定在平面上的点 $(x_L, y_L)$，谷仓在 $(x_B, y_B)$。奶牛把光束朝水平或竖直方向射出，再用镜子把它引到谷仓：镜子只能斜着装在栅栏柱上，把水平的光折成竖直，或把竖直的光折成水平；也可以不在柱子上装镜子，让光直接掠过。

农场里共有 $N$ 个栅栏柱（$1 \le N \le 100000$），位置互不相同，也不与激光器、谷仓重合。求最少需要几面镜子；做不到就输出 -1。

## 输入

第一行五个整数 `N xL yL xB yB`。

接下来 $N$ 行，每行两个整数 `x y`，表示一根栅栏柱的位置。所有坐标都在 $0 \ldots 1000000000$ 之间。

## 输出

一行一个整数：最少需要的镜子数；如果无法把光引到谷仓，输出 `-1`。

## 样例

输入：

```text
4 0 0 7 2
3 2
0 2
1 6
3 0
```

输出：

```text
1
```

解释：在柱子 $(0,2)$ 上装一面镜子，光从激光器竖直向上射出，到 $(0,2)$ 折成水平，正好经过 $(7,2)$ 的谷仓。

## 思路

镜子数就是转向次数，所以先想清楚光可能走在哪些直线上。如果光在一条直线上走了两段互不相连的区间，我们完全可以只保留其中一段、把绕出去的部分删掉，镜子数只会变少。因此每条直线上的光路都是一段连续区间，需要关心的直线只有：每根柱子所在的横线与竖线，加上激光器和谷仓所在的横线与竖线，一共不超过 $2N+2$ 条。

把"一条直线"当作结点建图：站在水平直线 $y=c$ 上，它可以经过它上面的任意一根柱子 $(x,c)$，在那里装一面镜子就转到竖直直线 $x=x$；反过来同理。这两种转移的代价都是 1 面镜子。

- 起点：激光所在的横线 $y=y_L$ 和竖线 $x=x_L$，代价都是 0，因为奶牛一开始就能把激光朝水平或竖直方向射出；
- 终点：谷仓所在的横线 $y=y_B$ 或竖线 $x=x_B$，光只要沿这条线走，就一定会扫过谷仓。

所有边的代价都是 1，于是用 BFS 求最短路；BFS 把队列搜空还没能碰到终点就说明无解，输出 -1。BFS 出队的镜子数不减，第一次碰到终点直线时得到的就是最小值。

实现时先把所有出现过的 $x$、$y$ 坐标排序去重，用编号表示直线；再把柱子按所属直线计数排序分组，这样每条直线只在它出队时被扫过一遍，柱子不会被反复检查。
