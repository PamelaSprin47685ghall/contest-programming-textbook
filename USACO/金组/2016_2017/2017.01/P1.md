# P1　平衡的照片（Balanced Photo）

## 题目

Farmer John 把 $N$ 头奶牛（$1 \le N \le 100000$）排成一行拍照，第 $i$ 头牛的身高为 $h_i$，所有身高互不相同。

对第 $i$ 头牛，记 $L_i$ 为她左边比她高的牛数，$R_i$ 为她右边比她高的牛数。如果两者中较大的那个严格大于较小的那个的 2 倍（即 $\max(L_i,R_i) > 2\min(L_i,R_i)$），这头牛就"不平衡"。请统计不平衡的奶牛数量。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行一个非负整数 $h_i$（$0 \le h_i \le 10^9$），表示第 $i$ 头牛的身高，互不相同。

## 输出

一行一个整数，表示不平衡的奶牛数量。

## 样例

输入：

```text
7
34
6
23
0
5
99
2
```

输出：

```text
3
```

解释：身高为 34、5、2 的三头牛不平衡（例如身高 34 的牛左边只有 1 头更高的牛，右边却有 5 头，$5 > 2 \times 1$）。

## 思路

暴力做法是枚举每头牛再往两边扫一遍，$O(N^2)$ 太慢。关键观察：对某头牛来说，"比她高"只与身高大小有关，所以**按身高从高到低**依次处理这些牛是可行的。

处理到第 $k$ 高的牛时，前面 $k-1$ 头已经处理完的牛正好就是所有比它高的牛。这时只需要知道：在这 $k-1$ 头里，有多少头的位置在它左边。这个数量就是 $L_i$，而 $R_i = (k-1) - L_i$，判定条件直接可得。

于是需要一个支持"单点加 1"和"前缀求和"的数据结构，用树状数组即可，两个操作都是 $O(\log N)$：把处理过的牛在其下标处标 1，查询下标小于当前牛的部分和就是 $L_i$。注意高度可能很大，但本题不需要离散化——树状数组建在**下标**上而不是身高上。

最后注意判定的边界：当 $\min(L_i,R_i) = 0$ 时，只要另一边大于 0 就判定为不平衡；两边都为 0 时是平衡的。
