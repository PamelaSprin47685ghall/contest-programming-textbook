# P3　奶牛导航（Cow Navigation）

## 题目

谷仓是一个 $N \times N$ 的方格（$2 \le N \le 20$），每格要么是空地 `E`，要么是无法通过的干草堆 `H`。Bessie 从**左下角**（第 1 列最下面那格）出发，要到**右上角**去。

你可以用三种指令指挥她：`forward`（向前走一格）、`turn left`（左转 90 度）、`turn right`（右转 90 度）。如果她面前是墙或干草堆，她不会移动，直接执行下一条指令。一旦她到达终点，之后的指令都被忽略。

Bessie 自己也不知道出发时是朝上还是朝右。请给出**最短**的指令序列长度，使得无论她开始时朝上还是朝右，都能被引导到终点。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行一个长为 $N$ 的字符串，只含 `E` 或 `H`。**最后一行的第一个字符**是格子 $(1,1)$（左下角），**第一行的最后一个字符**是格子 $(N,N)$（右上角）。

保证 $(1,1)$ 与 $(N,N)$ 都是空地，且存在从 $(1,1)$ 到 $(N,N)$ 的空地路径。

## 输出

一行一个整数，表示最短指令序列的长度。

## 样例

输入：

```text
3
EHE
EEE
EEE
```

输出：

```text
9
```

解释：指令序列 `前、右、前、前、左、前、左、前、前` 长 9，无论 Bessie 初始朝上还是朝右，都能把她送到右上角。

## 思路

先看简单版本：如果已知起点和朝向，就是普通的 BFS——图的顶点是"位置 + 朝向"，最多 $4N^2$ 个，每个顶点只有 3 条出边（前进、左转、右转）。

本题的麻烦在于初始朝向有两种可能，但我们要求的是一条对两种情况都有效的指令序列。关键转化：一条指令序列作用在两种初始朝向上，各自产生一条轨迹，所以整体状态就是**两个（位置, 朝向）的组合**，即 $16N^4$ 个状态；两个"影子牛"同时接收同一条指令，各自按规则移动。在这个大图上做 BFS，边权都是 1，第一次访问到某状态的距离就是最短距离。

终点状态是"两头都站在右上角"，因为 BFS 的层数正好等于指令序列的长度（先到的牛留在原地，等待另一头也到达）。注意两个细节：

- 已经站在终点的牛不再移动，所以前进操作里要特判；
- 撞墙或撞到干草堆时原地不动，但朝向不变。

$N \le 20$ 时状态数 $16 \times 20^4 = 2\,560\,000$，每个状态 3 条边，BFS 完全跑得动。状态用整数编码（按 $行、列、朝向$ 依次拼接），距离数组和队列各开长度 $16N^4$ 的 `int` 数组即可。
