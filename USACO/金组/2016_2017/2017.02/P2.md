# P2　牛为什么过马路 II（Why Did the Cow Cross the Road II）

## 题目

Farmer John 养了 $N$ 个品种的牛（$1 \le N \le 1000$），编号 $1 \ldots N$。两个品种 $a, b$ **友好**当且仅当 $|a - b| \le 4$，否则不友好。

一条长马路穿过农场。马路一侧有 $N$ 块地（每个品种一块），另一侧也有 $N$ 块地（每个品种一块）。FJ 想在马路上面画斑马线，每条斑马线连接一侧的某块地和另一侧的某块地，且两端品种必须友好（牛可以顺路走进别家的地，只要品种友好）。每块地至多作为一条斑马线的端点。

给定马路两侧田地的品种排列顺序，请帮 FJ 求出**最多**能画多少条互不相交的斑马线。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，依次给出马路一侧田地的品种编号；再接下来 $N$ 行，依次给出另一侧的品种编号。每个 $1 \ldots N$ 中的编号在每种排列里恰好出现一次。

## 输出

一行一个整数，表示最多能画的互不相交的友好斑马线条数。

## 样例

输入：

```text
6
1
2
3
4
5
6
6
5
4
3
2
1
```

输出：

```text
5
```

## 思路

把一侧的田地编号记为上边 $A_1 \ldots A_N$，另一侧记为下边 $B_1 \ldots B_N$。两条斑马线 $(i, j)$ 与 $(i', j')$（$i < i'$）不相交，当且仅当另一侧也有 $j < j'$——只要出现 $j > j'$，两条线段在马路中间必然交叉。于是问题变成：在两侧序列中选出尽可能多的配对，使两侧的下标同增，且每对品种友好。

这正是**最长公共子序列（LCS）**的形状，只是"字符相等"换成了"品种友好"。设

$$dp[i][j] = \text{只看 } A \text{ 的前 } i \text{ 项和 } B \text{ 的前 } j \text{ 项时能配对的最大数量}$$

则

$$dp[i][j] = \max\bigl(dp[i-1][j],\ dp[i][j-1],\ dp[i-1][j-1] + [\,|A_i - B_j| \le 4\,]\bigr)$$

前两项表示放弃 $A_i$ 或放弃 $B_j$（两者都不选也已包含在前两项里）；第三项表示把 $A_i$ 和 $B_j$ 配成一条斑马线，此时前面选出的配对两端下标都更小，绝不会与它交叉，所以直接把 $dp[i-1][j-1]$ 加一即可。答案就是 $dp[N][N]$。

这套递推之所以正确，是因为任意合法方案都能按"最后一个被配对的场地"归到上述某一类；反过来每种转移构造出的方案都合法，归纳即得最优。
