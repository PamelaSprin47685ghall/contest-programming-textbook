# P3　牛为什么过马路 III（Why Did the Cow Cross the Road III）

## 题目

Farmer John 的农场中央有一块大草地，草地外围是一条环形马路。每天早晨奶牛们穿过马路进草地，傍晚再穿出去回牛棚。每头牛进出草地的位置固定，且进、出位置不同；所有牛的进出位置两两不同。

FJ 有 $N$ 头牛（$1 \le N \le 50\,000$），编号 $1 \ldots N$，于是环形马路上共有 $2N$ 个穿越点。FJ 沿顺时针扫过一圈，把每个穿越点属于哪头牛记下来，得到长度为 $2N$、每个编号恰好出现两次的序列（他不记录哪个是进、哪个是出）。

若某两头牛 $a, b$ 的路径（进点到出点）**必定**相交，就称 $(a, b)$ 是一对 crossing 对。请统计 crossing 对的总数。

## 输入

第一行一个整数 $N$。

接下来 $2N$ 行，每行一个整数，依次给出绕圈扫过的穿越点所属的牛编号。

## 输出

一行一个整数，表示 crossing 对的总数。

## 样例

输入：

```text
4
3
2
4
4
1
3
2
1
```

输出：

```text
3
```

## 思路

把每头牛的两个穿越点记成它在圈上的首次出现位置 $s$ 和再次出现位置 $e$，于是每头牛对应一条弦的区间 $[s, e]$。两头牛的路径是否相交，取决于四个端点在圈上的相对次序：

- $s_a < s_b < e_a < e_b$（或反过来 $s_b < s_a < e_b < e_a$），即交错成 `ABAB`，两条弦**必然**相交；
- $s_a < s_b < e_b < e_a$（`AABB`），一条区间包含另一条，两牛只是先后进出，**不会**相交。

由于题目不区分进点和出点，而每对牛的两个端点次序只有这两种可能，所以只要数出所有构成 `ABAB` 的牛对即可。

按位置从左到右扫描这 $2N$ 个点，并维护一个树状数组：位置 $p$ 上记 $1$ 表示"有一头牛从 $p$ 进场、此刻还没出场"。当扫到某头牛 `cow` 的第二个点时（此时它的进场位置是 $s$，出场位置是当前 $e$）：

- 仍在场内（树上值为 $1$）的牛，其进场位置 $p$ 满足 $p < e$，且它比 `cow` 晚出场；
- 其中 $p > s$ 的那些，次序正是 $s < p < e <$（对方的出口），也就是 `ABAB`，全是与 `cow` 构成的 crossing 对，个数就是树状数组在 $(s, e)$ 上的区间和；
- 而 $p < s$ 的那些次序是 `AABB`（区间包含），不算 crossing，正好被区间和排除在外。

数完以后把 $s$ 上的标记清掉（这头牛出场了）。每一对 crossing 牛都只在**先出场**的那一方被统计一次，所以既不重复也不遗漏。

## 复杂度

时间 $O(N \log N)$（每个点一次树状数组操作），空间 $O(N)$。答案最多可达 $\binom{N}{2} \approx 1.25 \times 10^9$，需要用 `long long` 保存。
