# P2　现代艺术 2（Modern Art 2）

## 题目

画家 Picowso 改画一维的画：画布是一条长度为 $N$ 的格子（$1 \le N \le 100\,000$），最终每格有一个颜色，格子里的数在 $0 \ldots N$ 之间，其中 0 表示空白。她从空白画布开始，往上叠涂若干个区间（颜色在 $1 \ldots N$ 之间）：每种颜色最多涂**一个**区间，后涂的可以盖住先涂的，最后有些颜色可能被完全盖住、在成品上根本看不见。

Moonet 想用同样的画法复制这幅画：每一轮，他同时涂若干**互不相交**的区间，等颜料干了再涂下一轮；每种颜色从头到尾最多涂一个区间（也可以完全不涂，因为被盖住的上层本来就不需要复现）。请输出复制这幅画**最少**需要的轮数；如果这幅画根本不可能是这样一层层涂出来的，输出 -1。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行一个整数，依次给出画布上每一格的颜色（$0$ 为空白）。

## 输出

一行一个整数：最少轮数；若不可能，输出 -1。

## 样例

输入：

```text
7
0
1
4
5
1
3
3
```

输出：

```text
2
```

解释：颜色 1 出现在第 2、5 格，它的区间至少是 $[2,5]$；颜色 4、5 所在的第 3、4 格被夹在这个区间里面，必须一层层从外往内涂——先涂颜色 1 的区间，干燥后再涂颜色 4、5 的区间（两者不相交，可同轮）。所以至少 2 轮，且 2 轮足够。

## 思路

对每种出现过的颜色 $c$，记它第一次出现的位置为 $S(c)$、最后一次为 $E(c)$。涂一个更长的区间和涂 $[S(c), E(c)]$ 效果一样（区间外的部分反正会被别人盖掉或本来就被盖住），所以每种颜色的区间就取 $[S(c), E(c)]$。

两个区间只有两种合法关系：**完全不相交**，或**一个包含另一个**。交叉（$S(A) < S(B) < E(A) < E(B)$）必定不合法：无论先涂 $A$ 还是先涂 $B$，另一色区间端点处露出的颜色都会和最终不符。

把每个出现过的颜色的两个端点按位置排列，把 $S(c)$ 记作左括号、$E(c)$ 记作右括号，那么合法当且仅当它是一个**正确的括号序列**；不合法就输出 -1。用栈从左到右扫描即可判定：遇到左端点就把颜色压栈，每一步检查栈顶恰好是当前格子的颜色（否则说明该颜色被横穿），遇到右端点就弹栈。

轮数就是括号序列的**最大嵌套深度**：同深度的区间两两不相交，可以放在同一轮；嵌套的区间必须分属不同轮，从外往内依次涂即可达到深度这么多轮。

实现小技巧：在画布两端各补一格颜色 0，相当于给画面加了一层包住一切的底色，栈永远不会空、下标不用特判；最后答案等于最大深度减一（底色那层不用复现）。
