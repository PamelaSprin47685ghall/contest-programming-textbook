# P2　逃脱的奶牛（Cow at Large）

## 题目

农场由 $N$ 个谷仓（$2 \le N \le 10^5$）和 $N-1$ 条双向隧道组成，是一棵树，任意两谷仓之间恰好有一条通路。只有一个隧道的谷仓叫做**出口**。

清晨，Bessie 会在某个谷仓 $K$ 露面，然后试图走到一个出口逃走。她一露面，农场主们就从若干出口出发抓她。农夫和 Bessie 速度相同：每个时间单位里各自可以走一条隧道。农夫时刻知道 Bessie 在哪，Bessie 也知道农夫在哪。只要在某一瞬间农夫和 Bessie 在同一个谷仓、或者正在穿过同一条隧道（相向而行），Bessie 就被抓住。反之，只要 Bessie 先于任何农夫到达某个出口，她就成功逃脱了。

农夫可以最优地分配在各个出口上。给定 Bessie 从谷仓 $K$ 露面，求保证抓住她所需的农夫数的最小值。

## 输入

第一行两个整数 $N$ 和 $K$。

接下来 $N-1$ 行，每行两个整数，表示一条隧道连接的两个谷仓（$1 \ldots N$）。

## 输出

一个整数：保证抓住 Bessie 所需的最少农夫数。

## 样例

输入：

```text
7 1
1 2
1 3
3 4
3 5
4 6
5 7
```

输出：

```text
3
```

解释：出口是谷仓 2、6、7。Bessie 从 1 出发，最短路程到这三个出口分别是 1、3、3。要同时封住 1 的三个儿子方向（2、经 3 到 6、经 3 到 7）至少需要 3 个农夫，且 3 个农夫的确够用。

## 思路

以 $K$ 为根把树提起来。先说明两条最优性观察：

- Bessie 绝不会往根的方向走。往回走等于撤销上一步，纯属浪费时间，只会让农夫更近。
- 农夫绝不会往远离根的方向走。要么他离 Bessie 更远了（无意义），要么 Bessie 就在他的子树里——那他追不上，原地不动更好。

因此，每条"根到叶"的路径都是一条候选逃生路线，而这条路线是否可行，只取决于路径上的每一点是 Bessie 先到还是农夫先到。记

- `depth[i]`：$i$ 到根 $K$ 的距离；
- `distLeaf[i]`：$i$ 到最近出口的距离。

由于农夫从出口出发，两人速度相同，条件 `distLeaf[i] > depth[i]` 意味着 Bessie 能比任何农夫更早到达 $i$，这个谷仓对她是安全的；反之 `distLeaf[i] <= depth[i]` 表示农夫能在她到达之前（或同时）到达 $i$，这条路走不通了。

于是 Bessie 能安全活动的区域正是那些 `distLeaf[i] > depth[i]` 的谷仓；要让她无法逃脱，就必须在她每个"还能安全到达的谷仓"的每个儿子子树里各派一个农夫，把这些子树全部堵死。为了不重复计数，每个儿子子树只记它的根，即：

> 计数满足 `distLeaf[i] <= depth[i]`（自己已不安全）且 `distLeaf[父亲] > depth[父亲]`（父亲仍安全）的谷仓 $i$ 的个数。

每个这样的 $i$ 恰好对应一个必须派驻农夫的子树；反过来，把这些子树各派一个农夫，就挡住了一切可行逃生路线，所以这个计数既是下界也是上界。

实现上：`depth` 从根做一次 BFS；`distLeaf` 从所有出口（度数为 1 的谷仓）做一次多源 BFS；统计时跳过根。另外若 $K$ 自己就是出口，Bessie 一露面就脱身（官方结论按 1 个农夫输出），需要特判。
