# P1　雪地靴（Snow Boots）

## 题目

冬天到了，从农舍到牛棚的小路被分成 $N$ 块地砖，编号 $1 \dots N$，第 $i$ 块砖上积了 $f_i$ 英尺厚的雪。第 $1$ 块和第 $N$ 块砖分别被农舍和牛棚的屋顶遮住，所以 $f_1 = f_N = 0$。

Farmer John 的地窖里有 $B$ 双靴子，编号 $1 \dots B$。第 $i$ 双靴子最多能在 $s_i$ 英尺深的雪里行走，并且每一步最多向前迈 $d_i$ 英尺。FJ 从第 $1$ 块砖出发，必须走到第 $N$ 块砖去叫醒奶牛，**整段路他只能穿同一双靴子**。

请对每双靴子分别判断：穿着它能否走完全程。

## 输入

- 第 1 行：两个整数 $N$、$B$（$1 \le N, B \le 10^5$）。
- 第 2 行：$N$ 个整数 $f_i$（$0 \le f_i \le 10^9$），保证 $f_1 = f_N = 0$。
- 接下来 $B$ 行：每行两个整数 $s_i$、$d_i$（$0 \le s_i \le 10^9$，$1 \le d_i \le N-1$），表示第 $i$ 双靴子能承受的雪深和最大步长。

## 输出

共 $B$ 行。第 $i$ 行输出 $1$ 表示穿着第 $i$ 双靴子可以走到牛棚，否则输出 $0$。

## 样例

输入：

```text
8 7
0 3 8 5 6 9 0 0
0 5
0 6
6 2
8 1
10 1
5 3
150 7
```

输出：

```text
0
1
1
0
1
1
1
```

解释：第 1 双靴子（$s=0$）踩不动任何有雪的砖，而第 2 块砖就有 3 英尺雪，走不了；第 3 双靴子（$s=6$，$d=2$）能踩雪深不超过 6 的砖，即 1、2、4、5、6、7、8 号砖，相邻可踩砖的最大间距是 2（第 2 块和第 4 块之间差 2），所以可以走；第 6 双靴子（$s=5$，$d=3$）可踩的砖是 1、2、4、7、8 号，最大间距为 3，刚好能跳过去。

## 思路

对一双固定的靴子，FJ 能落脚的地砖就是所有满足 $f_i \le s$ 的砖（起点和终点的雪深都是 0，必然包含在内）。他能否从 $1$ 走到 $N$，取决于这些"可踩砖"中**相邻两块之间的最大距离**：只要这个最大间距不超过步长 $d$，就能一块一块地跳过去；否则中间会有一段必须跨过却跨不过去的深雪。

朴素的判断要对每双靴子扫一遍全部砖，$O(NB)$ 太慢。关键观察是：$s$ 越大，可踩的砖越多、最大间距越小，这个最大间距关于 $s$ **单调不增**。于是把砖按雪深降序排、靴子按 $s$ 降序排，用双指针加双向链表处理：

- 链表里保存当前还"踩得动"的砖，初始时全部砖都在链上；
- 按 $s$ 从大到小处理靴子，每处理一双，就把雪深大于当前 $s$ 的砖从链表中依次摘掉（这些砖一定也踩不动 $s$ 更小的靴子，所以指针只前进，总删除次数不超过 $N$）；
- 摘掉一块砖时，只有它的前驱和后继之间会出现一对新的相邻砖，所以最大间距只需更新为 $\max(\text{maxGap},\ nxt - pre)$，$O(1)$。

由于 $s_i \ge 0$ 且 $f_1 = f_N = 0$，第 1 块和第 $N$ 块砖永远不会被摘掉，链表两端始终有砖，不会越界。
