# P2　目录遍历（Directory Traversal）

## 题目

Bessie 在牛棚的电脑上存了很多文件，它们组织成一棵以顶层目录 `bessie` 为根的目录树。她可以站在任意一个目录里，用**相对路径**引用任意文件：路径中 `..` 表示上一层目录，向下进入子目录时写出子目录名加一个斜杠。

例如在 `folder2` 里，四个文件可以分别写成 `../file1`、`file2`、`../../folder3/file3`、`../../file4`。

请找出一个目录，使得从该目录出发到**所有文件**的相对路径长度之和最小，输出这个最小值。

## 输入

- 第 1 行：一个整数 $N$（$2 \le N \le 100000$），表示文件与目录的总数，编号 $1 \dots N$，其中 $1$ 号是顶层目录。
- 接下来 $N$ 行：每行先给出该实体的名字（只含小写字母和数字，长度不超过 16），再给出整数 $m$。$m = 0$ 表示这是一个文件；$m > 0$ 表示这是一个目录，且它内部有 $m$ 个实体，随后跟着这 $m$ 个实体的编号。

## 输出

一个整数：所有可能目录中，到全部文件的相对路径长度之和的最小值。答案可能超出 32 位整数范围。

## 样例

输入：

```text
8
bessie 3 2 6 8
folder1 2 3 4
file1 0
folder2 1 5
file2 0
folder3 1 7
file3 0
file4 0
```

输出：

```text
42
```

解释：站在 `folder1` 里时，四条相对路径分别是 `file1`（5）、`folder2/file2`（$7+1+5=13$）、`../folder3/file3`（$3+7+1+5=16$）、`../file4`（$3+5=8$），总和 $5+13+16+8=42$，是所有目录中最小的。

## 思路

把文件系统看成以顶层目录为根的树，文件是特殊的叶子。对一条从目录 $u$ 指向其目录儿子 $c$ 的边，可以这样理解它给路径长度带来的影响：

- 引用 $c$ **子树内**的文件时，路径必须多写出 $c$ 的名字和一个斜杠，即 $len(c)+1$ 个字符；
- 引用 $c$ **子树外**的文件时，必须先用 `../` 退回上一层再绕过去，多出 3 个字符。

于是先用一次自顶向下的遍历求出站在顶层目录时的总长 $sum[1]$：走到某个文件儿子的路径长恰好是"进入该目录时已累积的前缀长 + 文件名长"。进入目录儿子 $c$ 时，前缀长增加 $len(c)+1$。

接下来**换根**即可得到每个目录的答案。由目录 $u$ 走进它的目录儿子 $c$ 时，$c$ 子树内的每个文件路径都缩短 $len(c)+1$，其余每个文件都加长 3：

$$sum[c] = sum[u] - fileCnt[c]\cdot(len(c)+1) + (totalFiles - fileCnt[c])\cdot 3$$

其中 $fileCnt[c]$ 是 $c$ 子树内的文件数，$totalFiles$ 是文件总数。文件数只要按遍历顺序倒着累加一遍就能求出。

由于 $N$ 可达 $10^5$，目录可能串成一条长链，递归会爆栈，因此用显式的 BFS 顺序数组代替递归遍历：逆序累加子树文件数，正序求前缀长与 $sum[1]$，再正序把 $sum$ 推到每个目录儿子上。

答案就是所有目录（含顶层目录）中 $sum$ 的最小值。路径长度之和最大约有 $10^5 \times 16 \times 10^5$ 量级，必须使用 `long long`。
