# P3　驯服牛群（Taming the Herd）

## 题目

奶牛又一次冲出牛棚，Farmer John 忍无可忍，在墙上钉了一块计数器，记录"距上次破门过了多少天"：破门当天读数为 $0$，若最近一次破门在 $3$ 天前则读数为 $3$。他每天记录一次读数。

一年过去，FJ 想清算这笔账，却发现日志被动过手脚。他唯一确定的是：**日志是从破门那天开始记录的**。对于每一个可能的破门次数，求出与给定日志不一致的记录条数的最小值。

## 输入

- 第 1 行：一个整数 $N$（$1 \le N \le 100$），表示记录的天数。
- 第 2 行：$N$ 个整数 $a_i$（$0 \le a_i \le 100$），表示第 $i$ 天日志上的读数（可能已被篡改）。

## 输出

共 $N$ 行。第 $k$ 行输出：在所有可能的发生 $k$ 次破门的序列中，与实际日志不一致的记录条数的最小值。

## 样例

输入：

```text
6
1 1 2 0 0 1
```

输出：

```text
4
2
1
2
3
4
```

解释：若只破门 1 次（第 1 天），日志应为 `0 1 2 3 4 5`，有 4 处不同；若破门 2 次（第 1、5 天），日志应为 `0 1 2 3 0 1`，有 2 处不同；若破门 3 次（第 1、4、5 天），应有 `0 1 2 0 0 1`，只有 1 处不同。

## 思路

设 $dp[i][j][k]$ 表示：只看前 $i+1$ 天的记录（下标从 0 开始），一共发生 $k$ 次破门、且最后一次破门发生在第 $j$ 天时，最少需要篡改多少条记录。

一旦确定了"最后一次破门在第 $j$ 天"，第 $i$ 天的真实读数就唯一确定为 $i - j$：因为计数器从那天起每天加一。所以如果原日志 $a_i \ne i - j$，第 $i$ 天就必须被篡改（代价 $+1$）；否则不用改。剩下的代价只取决于前 $i$ 天，分两种情况：

- **$j < i$**：第 $i$ 天不是破门日，前 $i$ 天里最后一次破门仍然是第 $j$ 天，于是 $dp[i][j][k] = dp[i-1][j][k]$。
- **$j = i$**：第 $i$ 天就是破门日，前 $i$ 天里最后一次破门可以是任何一天 $j' < i$，并且破门次数少一次：$dp[i][j][k] = \min_{j' < i} dp[i-1][j'][k-1]$。

边界：日志从破门当天开始，所以第 1 天必然破门、读数必然为 0，$dp[0][0][1] = (a_0 \ne 0)$；其余状态初始化为无穷大。

最后对每个 $k$，答案是 $\min_{0 \le j < N} dp[N-1][j][k]$（最后一次破门可以落在任意一天）。

状态共 $O(N^3)$ 个；第一种转移是 $O(1)$，第二种要枚举 $j'$ 是 $O(N)$，但只出现在 $j = i$ 的 $O(N^2)$ 个状态上，所以总时间复杂度仍是 $O(N^3)$，对 $N \le 100$ 绰绰有余。
