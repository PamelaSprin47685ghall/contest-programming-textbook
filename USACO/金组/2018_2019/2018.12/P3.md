# P3　团队合作（Teamwork）

## 题目

为了最爱的节日，农夫约翰想给朋友们送礼物。他不太擅长包装礼物，于是请奶牛们来帮忙——不过奶牛们的包装水平也不怎么样。

约翰的 $N$ 头奶牛（$1 \le N \le 10^4$）站成一排，依次编号 $1 \dots N$，第 $i$ 头牛的包装技能是 $s_i$。他决定把奶牛编成若干个队：每队由**连续**的至多 $K$ 头牛组成（$1 \le K \le 10^3$），且每头牛至多在一个队里。

因为牛会互相学习，一个队里每头牛的技能都会被"提升"为该队中技能最高的那头牛的技能。请帮约翰求出：最优编队下所有奶牛技能之和的最大值。

## 输入

- 第 1 行：两个整数 $N$ 和 $K$。
- 接下来 $N$ 行：每行一个整数，按排队顺序给出每头奶牛的技能值（不超过 $10^5$）。

## 输出

一行一个整数：最优编队后技能总和的最大值。

## 样例

输入：

```text
7 3
1
15
7
9
2
5
10
```

输出：

```text
84
```

解释：最优方案是把前三头牛编成一队、后三头牛编成一队，中间的第 4 头牛单独成一队（队伍长度可以小于 $K$）。这样技能值变成 $15,15,15,9,10,10,10$，总和为 $84$。

## 思路

按排队顺序做划分型 DP。设 $dp[i]$ 表示**前 $i$ 头牛**编队后能获得的最大技能总和，则最后一队必然是从第 $j$ 头到第 $i$ 头的一段连续区间（$i-K+1 \le j \le i$），这一队的贡献是

$$\text{队长技能} \times (i-j+1), \qquad \text{队长技能} = \max_{j \le x \le i} s_x.$$

于是

$$dp[i] = \max_{i-K+1 \le j \le i} \Bigl(dp[j-1] + (i-j+1)\cdot \max_{j \le x \le i} s_x\Bigr), \qquad dp[0] = 0.$$

朴素地对每个 $j$ 再扫一遍求最大值是 $O(NK^2)$，会超时。注意当 $j$ 从 $i$ 递减到 $i-K+1$ 时，区间 $[j, i]$ 只是在左端不断扩展，所以可以用一个变量 `best` 在线维护区间最大值：每次 $j$ 左移一步，就用 $s_j$ 更新 `best`。这样每个状态只需 $O(K)$ 次 $O(1)$ 的转移，总复杂度 $O(NK)$，足以通过。

答案即 $dp[N]$。技能值都是正数，所以 $dp[i]$ 初值取 0 不会影响转移（合法的队伍划分总能给出不小于 0 的候选值）。
