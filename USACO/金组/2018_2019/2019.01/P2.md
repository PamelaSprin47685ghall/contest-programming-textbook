# P2　睡眼惺忪的奶牛（Sleepy Cow Sorting）

## 题目

FJ 想把 $N$ 头奶牛（$1 \le N \le 10^5$）排成 $1, 2, \dots, N$ 的顺序（奶牛 1 站在 FJ 面前）。当前顺序是 $p_1, p_2, \dots, p_N$。

今天奶牛们很困，任意时刻只有站在 FJ 正对面的那头奶牛会听指挥。每个时间步，FJ 可以让这头牛往队尾方向挪 $k$ 步（$1 \le k \le N-1$）：它越过的 $k$ 头牛依次向前补位，而它插到这些牛的身后。

求排好序所需的最少时间步数 $K$，并给出任意一组 $K$ 步的指令 $c_1, \dots, c_K$（$1 \le c_i \le N-1$）。

## 输入

- 第 1 行：一个整数 $N$。
- 第 2 行：$N$ 个整数 $p_1 \dots p_N$，表示初始顺序。

## 输出

- 第 1 行：一个整数 $K$，最少时间步数。
- 第 2 行：$K$ 个整数 $c_1 \dots c_K$，依次表示每一步让队首的牛挪多少步（若有多组最优指令，输出任意一组）。

## 样例

输入：

```text
4
1 2 4 3
```

输出：

```text
3
2 2 3
```

即：奶牛 1 挪 2 步得 $2,4,1,3$，再让奶牛 2 挪 2 步得 $4,1,2,3$，最后让奶牛 4 挪 3 步得到 $1,2,3,4$。共 3 步。

## 思路

**关键观察。** 每一步能指挥的只有当时队首的牛，而这一步只会把它**往后**插到别的牛身后。由此可知：一头从头到尾都没被指挥过的牛，初始时站在它身后的牛永远不可能反超它——因为能让两头牛换序的方式只有"把队首牛往后插"，而被指挥的队首牛在它前面时只会越走越靠后，不可能插到它前面去。

设 $j$ 为初始序列**最长递增后缀**的起点（$p_j < p_{j+1} < \dots < p_N$，且 $j$ 尽量小；也就是从末位往前数，连续递增的那一段有多长），那么：

- **下界**：后缀 $p_j, \dots, p_N$ 的相对顺序本来就是正确的，可以认为这些牛不用动；而一次指挥最多让"最长递增后缀的起点"左移一位（插入动作只在插入点处打断一段连续的递增段），要从 $j$ 走到 $0$（整队有序）至少需要 $j$ 步，故 $K \ge j$。
- **构造**：下面给出恰好 $j$ 步的方案，说明 $K = j$。

**构造方案。** 维护不变式：队伍总是形如 `[尚未处理的 p[i..j-1]]` 接上 `[已归位的牛（编号递增）]`。此时队首正是 $p_i$（$i$ 从 $0$ 数到 $j-1$），让它往后挪

$$k_i = (j - 1 - i) + \#\{\text{已归位的牛中编号小于 } p_i \text{ 的}\}$$

步：先越过剩下的 $j-1-i$ 头尚未处理的牛，再越过已归位牛里编号更小的那些，于是它正好插进已归位序列中自己该在的位置，不变式得以保持。把前 $j$ 头牛依次处理后，整队就是 $1, \dots, N$。

$k_i$ 一定落在 $1 \dots N-1$ 之间：上界显然（最多越过 $N-1$ 头牛）；下界由 $p_{j-1} > p_j$ 保证——处理最后一头 $p_{j-1}$ 时至少会越过比它小的 $p_j$。

"已归位的牛中编号更小的个数"用树状数组维护：初始把后缀 $p_j, \dots, p_N$ 全部标记为已归位，之后每处理一头就标记一头，查询前缀和，单次 $O(\log N)$。
