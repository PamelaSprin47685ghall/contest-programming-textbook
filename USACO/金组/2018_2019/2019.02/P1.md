# P1　奶牛乐园（Cow Land）

## 题目

奶牛乐园是一个很特别的游乐园，里面共有 $N$ 个景点（$2 \le N \le 10^5$），由 $N-1$ 条小路连接，任意两个景点之间恰好有一条唯一的路线，也就是一棵树。

每个景点 $i$ 有一个娱乐值 $e_i$（$0 \le e_i \le 10^9$），而且这个值在一天中会变化。一头从景点 $i$ 走到景点 $j$ 的奶牛会经过 $i$ 到 $j$ 路线上的所有景点（包括两个端点），这条路线的"总娱乐值"被定义为这些景点娱乐值的**按位异或和**。

## 输入

- 第 1 行：两个整数 $N$ 和询问数 $Q$（$1 \le Q \le 10^5$）。
- 第 2 行：$N$ 个整数 $e_1 \ldots e_N$。
- 接下来 $N-1$ 行：每行两个整数 $a, b$，表示一条连接景点 $a$ 和 $b$ 的小路。
- 接下来 $Q$ 行：每行一次操作。
  - `1 i v`：把 $e_i$ 修改为 $v$；
  - `2 i j`：询问景点 $i$ 到景点 $j$ 路线上所有景点娱乐值的异或和。

## 输出

对每个 `2 i j` 询问输出一行，一个整数，表示该路线的娱乐值。

## 样例

输入：

```text
5 5
1 2 4 8 16
1 2
1 3
3 4
3 5
2 1 5
1 1 16
2 3 5
2 1 5
2 1 3
```

输出：

```text
21
20
4
20
```

解释：先询问 $1$ 到 $5$（路线 $1 \to 3 \to 5$），娱乐值为 $1 \oplus 4 \oplus 16 = 21$；随后把 $e_1$ 改成 $16$，于是 $3$ 到 $5$ 为 $4 \oplus 16 = 20$，$1$ 到 $5$ 为 $16 \oplus 4 \oplus 16 = 4$，$1$ 到 $3$ 为 $16 \oplus 4 = 20$。

## 思路

路径异或不好直接维护，但异或有很好的可减性：设

$$\text{pre}(x) = \text{根到 } x \text{ 路径上所有娱乐值的异或}, \qquad r = \mathrm{LCA}(i, j),$$

那么 $\text{pre}(i) \oplus \text{pre}(j)$ 刚好把 $r$（在两条根路径里各出现一次）抵消掉，于是

$$\text{路径异或}(i, j) = \text{pre}(i) \oplus \text{pre}(j) \oplus e_r.$$

其中 $\mathrm{LCA}$ 用**倍增**求：$up[v][d]$ 表示 $v$ 的第 $2^d$ 级祖先，先把较深的点跳到同一深度，再让两点一起往上跳，$O(\log N)$ 一次询问。

难点在修改。改一个 $e_i$ 会让**整棵子树**里所有点的 $\text{pre}$ 都异或上 $\delta = e_i \oplus v$。用 DFS 序把子树变成一段连续区间，问题就成了"区间异或 + 单点询问"，用**树状数组维护差分数组**即可：区间异或 $\delta$ 等价于在差分数组的 $l$ 和 $r+1$ 处各异或 $\delta$，单点询问就是差分数组的前缀异或，两种操作都是 $O(\log N)$。

初始值不需要逐个做区间修改：DFS 时已经算出每个点真实的 $\text{pre}$，把它们按 DFS 序放进数组并直接构造差分数组（$O(N)$ 建树状数组）即可。

DFS 深度可能达到 $10^5$，所以用手工栈写迭代式 DFS，避免递归爆栈。
