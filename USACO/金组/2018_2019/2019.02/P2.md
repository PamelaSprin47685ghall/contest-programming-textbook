# P2　洗碗（Dishwashing）

## 题目

Bessie 负责抹肥皂，Elsie 负责冲洗。Bessie 手里有一摞脏盘子，从上到下标签为 $L_1 \ldots L_N$（$1 \le N \le 10^5$）；Elsie 手里有一个空盘子堆，用来放洗干净的盘子；两人中间有一个台面，可以放若干摞"上过肥皂的盘子"。

每一步只能是下列两种之一：

- Bessie 从脏盘子堆顶取一个盘子，抹上肥皂，放到台面上。放的时候她要么把它压在某摞已有肥皂盘的**顶上**，要么在最右边**新开一摞**。
- Elsie 从**最左边**那摞肥皂盘子的顶部取一个盘子，冲洗干净，放到干净盘子堆顶。

目标：干净盘子堆从下到上标签递增（即冲洗出来的顺序恰好是 $1, 2, \ldots$）。整个流程未必能完成，请输出**能够成功洗完的最长前缀**的长度。

## 输入

- 第 1 行：一个整数 $N$。
- 接下来 $N$ 行：每行一个整数，按 Bessie 的盘子堆**从上到下**的顺序给出盘子标签。

## 输出

一行一个整数：能成功洗完的最长前缀长度。

## 样例

输入：

```text
5
4
5
2
3
1
```

输出：

```text
4
```

解释：盘子依次是 $4,5,2,3,1$。

- $4$：第一摞，编号 $4$。
- $5$：$5 > 4$，不能压在 $4$ 上（否则 $5$ 会先于 $4$ 被冲走），于是在右边新开一摞。
- $2$：$2 < 4$，压在 $4$ 那摞的顶上。
- $3$：$3$ 只能放到 $4$ 那摞上；但此时该摞顶上是 $2$，$3$ 压在 $2$ 上会被先冲走，所以必须让 Elsie 先把 $2$ 冲掉，再把 $3$ 压上去。此时已经冲掉的最大标签是 $2$。
- $1$：$1$ 比已经冲掉的 $2$ 还小，它必须排在 $2$ 之前被冲走，已经来不及了，于是失败。

所以最长前缀长度为 $4$。

## 思路

记盘子标签为 $L_1 \ldots L_N$。核心结论是：每个盘子 $L_i$ 应该放在**最靠左的、栈顶标签大于 $L_i$ 的那一摞**上（若不存在，就在最右边新开一摞）。因为 Elsie 永远从最左边取，任何一摞左侧的盘子都会先被取走，所以放得越靠左越安全；而压在一个比它小的盘子上面必然导致顺序错乱。

于是只需维护 `base[v]`：标签 $v$ 应该去的那摞的编号。栈的编号就取这摞**当前最大的标签**。放 $L_i = x$ 时，从 $x$ 往下把还没有归属的标签 $j$ 的 `base[j]` 都设成 $x$——每个 $j$ 只会被赋值一次，所以这一段均摊 $O(1)$。

还有一个约束：如果目标那一摞的栈顶存放着比 $x$ 小的盘子，$x$ 压上去会先被取走，因此必须让 Elsie 先把这些比 $x$ 小的盘子冲洗掉（它们按递增顺序离开，正好符合要求）。冲洗过程中记录"已经冲掉的最大标签" `placed`：若后面出现 $x <$ `placed`，说明这个盘子应该排在已经冲掉的某个盘子之前，但顺序已无法挽回，此时前缀长度就是它前面的盘子数，输出即可。
