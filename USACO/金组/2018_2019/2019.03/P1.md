# P1　蛇（Snakes）

## 题目

Bessie 要用一张网按顺序捕获排在一条线上的 $N$ 群蛇（$1 \le N \le 400$），第 $i$ 群有 $a_i$ 条蛇。每抓完一群，她可以把蛇放进笼子，然后带着一张空网继续。

大小为 $s$ 的网可以抓下蛇数 $g \le s$ 的任意一群，但每次都会白白浪费 $s - g$ 的空间。网的大小可以任意选择初始值，整场最多改变 $K$ 次（$1 \le K < N$），求捕完全部蛇后总浪费空间的最小值。

## 输入

- 第 1 行：两个整数 $N$ 和 $K$。
- 第 2 行：$N$ 个整数 $a_1, \dots, a_N$（$0 \le a_i \le 10^6$）。

## 输出

一个整数，表示最小的总浪费空间。

## 样例

输入：

```text
6 2
7 9 8 2 3 2
```

输出：

```text
3
```

解释：网先取 7 抓第 1 群，再改成 9 抓第 2、3 群，再改成 3 抓第 4、5、6 群，浪费 $(7-7)+(9-9)+(9-8)+(3-2)+(3-3)+(3-2)=3$。

## 思路

题面问的是"浪费"，但每群的浪费之和是

$$\sum_{i=1}^{N} (s_i - a_i) = \sum_{i=1}^{N} s_i - \sum_{i=1}^{N} a_i ,$$

其中 $s_i$ 是抓第 $i$ 群时网的大小。蛇的总数是定值，所以只要让"网大小之和"最小。

一次改网可以改成任意大小（包括保持不变），所以"恰好改 $K$ 次"与"至多改 $K$ 次"答案相同。问题于是变成：把序列切成 $K+1$ 个连续段，每段共用一张网，段 $[l, r]$ 的代价是 $(r-l+1)\cdot \max(a_l,\dots,a_r)$（网必须装得下段内最大的那一群），求代价和的最小值。

设 $dp[m][j]$ 表示抓完前 $m$ 群、恰好改 $j$ 次网时网大小之和的最小值，则

$$dp[m][0] = m \cdot \max\{a_1,\dots,a_m\},$$

$$dp[m][j] = \min_{j \le i < m}\Big(dp[i][j-1] + (m-i)\cdot \max\{a_{i+1},\dots,a_m\}\Big).$$

转移的含义是：最后一段就是 $a_{i+1},\dots,a_m$，前面 $i$ 群用 $j-1$ 次改网解决。最终答案是 $dp[N][K] - \sum_{i=1}^{N} a_i$。

每个转移如果重新求一次区间最大值，总复杂度是 $O(N^4)$。固定 $m,j$ 后，让 $i$ 从 $m-1$ 递减到 $j$，同时用一个变量维护 $\max\{a_{i+1},\dots,a_m\}$：$i$ 每减小 1，区间只会在左端多出一个数，最大值只需与 $a_i$ 取大，于是每个转移降到 $O(1)$。
