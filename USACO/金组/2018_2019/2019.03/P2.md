# P2　我愿意走五百英里（I Would Walk 500 Miles）

## 题目

Farmer John 要把编号为 $1 \dots N$ 的 $N$ 头奶牛（$N \le 7500$）分成 $K$ 个非空组（$2 \le K \le N$）。奶牛 $x$ 与奶牛 $y$（$1 \le x < y \le N$）愿意为见到对方走

$$(2019201913x + 2019201949y) \bmod 2019201997$$

英里。

对一种分组方案，记 $M$ 为"任意两头处在不同组的奶牛愿意走的英里数"的最小值。Farmer John 想让这些奶牛证明彼此的深情，也就是要让 $M$ 尽量大。请求出最优分组下 $M$ 的最大值。

## 输入

- 一行，两个整数 $N$ 和 $K$，用一个空格隔开。

## 输出

一个整数，表示最优方案下 $M$ 的值。

## 样例

输入：

```text
3 2
```

输出：

```text
2019201769
```

解释：三头牛两两之间愿意走的英里数分别是 $2019201817$（1 与 2）、$2019201685$（2 与 3）、$2019201769$（1 与 3）。把 1 单独放一组、2 和 3 放一组，则 $M=\min(2019201817,2019201769)=2019201769$，这是能取到的最大 $M$。

## 思路

把奶牛看成点，两头牛之间的距离看成一条边，那么一种分组方案要最大化的 $M$，就是"两端点不在同一组的边"里的最小边权。

**关键结构是最小生成树。** 按 Kruskal 的顺序（边权从小到大）不断加边：当已经加入的边让图剩下恰好 $K$ 个连通块时，就把这 $K$ 个连通块当作 $K$ 个组。此刻

- 每个连通块内部的点都是用边权不超过"当前边权"的边连起来的；
- 任意两个连通块之间的边权都至少是"下一条将要加入的边的边权"——否则 Kruskal 早就把这两个块并起来了。

所以这个分组方案给出的 $M$ 正好等于下一条要加的边的边权。生成树一共 $N-1$ 条边，当连通块数降到 $K$ 时（已加入 $N-K$ 条边），下一条是第 $(N-K+1)$ 小的树边，也就是最小生成树中**第 $K-1$ 大**的边权。答案就是它。

例如 $K=2$ 时答案就是树里最大的那条边；$K=N$ 时（每头牛一组）答案是最小的树边，也就是全图的最小边权。

**怎么求树。** 这是完全图，$N=7500$ 时约有 $2.8\times 10^7$ 条边，显式建图再排序太慢；但边权可以 $O(1)$ 现算，所以改用 Jarnik（Prim）算法。数组 `dist[i]` 记录点 $i$ 连到"当前已建成的树"的最小边权，每轮挑出 `dist` 最小的未并入点并进树，然后拿它去更新其余点的 `dist`。某个点被并入时 `dist` 的值就是它接入生成树的那条边权（树根没有任何边接入，留一个比所有边权都大的哨兵 `MOD`）。

把这些"接入边权"（含哨兵，共 $N$ 个值）从小到大排序后，取第 $N-K$ 个（0 起下标）即"第 $K$ 大"的值就是答案：哨兵占据最大值的位置，所以第 $K$ 大的值正是树边里第 $K-1$ 大的。
