# P3　平衡逆序对（Balancing Inversions）

## 题目

Bessie 和 Elsie 在一个长度为 $2N$ 的 01 数组 $A$ 上玩游戏（$1 \le N \le 10^5$）。Bessie 的得分是数组**前半段**里的逆序对数，Elsie 的得分是**后半段**里的逆序对数；逆序对指一对下标 $i<j$ 满足 $A[i]=1$ 且 $A[j]=0$。

Farmer John 希望这场游戏看起来是一场平局——两人的得分相等。求最少需要多少次"交换相邻两个元素"。

## 输入

- 第 1 行：一个整数 $N$。
- 第 2 行：$2N$ 个整数，每个是 0 或 1。

## 输出

一个整数，表示让两人得分相等所需的最少相邻交换次数。

## 样例

输入：

```text
5
0 0 0 1 0 1 0 0 0 1
```

输出：

```text
1
```

解释：一开始前半段有 1 个逆序对、后半段有 3 个。把第 5 个和第 6 个元素交换一次，前半段与后半段就都没有逆序对了。

## 思路

记 `inv0` 为前半段的逆序对数、`inv1` 为后半段的逆序对数，$\Delta = \text{inv0} - \text{inv1}$。目标就是让 $\Delta = 0$。

**一次交换对 $\Delta$ 的影响。** 把跨过中线的交换（第 $N$ 个与第 $N+1$ 个元素之间的交换）叫"中央交换"，其余的叫"半内交换"。

- 半内交换一定是相邻的一个 0 和一个 1 互换：把 1 往右挪过 0，所在那一半的逆序对数减少 1；把 1 往左挪过 0，则增加 1。所以 $\Delta$ 的变化恰好是 $\pm 1$。
- 中央交换 1,0 → 0,1 时，$\Delta$ 的变化是一个只与全数组 1 的个数有关的**常数**。设交换前前半段有 $o$ 个 1、后半段有 $z$ 个 0：被换走的两个元素原来都不贡献逆序（前半段那个 1 在末位，后半段那个 0 在首位，它前面没有 1），而新来的 0 落到前半段末位，与前半段其余 $o-1$ 个 1 各组成一个逆序；新来的 1 落到后半段首位，与后半段其余 $z-1$ 个 0 各组成一个逆序。于是

$$\Delta \mathrel{+}= (o-1)-(z-1) = o-z = \underbrace{(\text{全数组 1 的个数})}_{o+(N-z)} - N .$$

  反方向 0,1 → 1,0 的变动数值相反。这个常数性质是下面能一路累加 $\Delta$ 的原因。

**最优解的形状。** 最优方案不会去交换两个相同的数（纯属浪费），于是每个 1 的移动轨迹是单调的：它要么一路往右、要么一路往左。因此整个方案可以用一个整数 $t$ 概括——净有多少个 1 从**前半段移进后半段**（$t<0$ 就表示有 $|t|$ 个 1 从前半段被移出来、即往后半段"反向"走）。而且搬运时应当挑最靠边的那些元素：每个跨中线的 1 都必须先走到中线，越靠边的 1 需要的半内交换越少。

**固定 $t$ 时的最小步数。** 先看 $t \ge 0$，即把 1 从前半段推到后半段。第 $j$ 次搬运要送走前半段里**第 $j$ 靠右**的 1（位置记为 $q$），同时后半段里**第 $j$ 靠左**的 0（位置记为 $z$）会被换回前半段。这一次搬运必须做三件事：

1. 前半段内部：把这个 1 一路换到中线左侧，越过 $N-1-q$ 个 0，用 $N-1-q$ 步；
2. 后半段内部：把那个 0 一路换到中线右侧，越过 $z-N$ 个 1，用 $z-N$ 步；
3. 一次中央交换，把 1 送出前半段。

这已经是最省的做法，所以 $t$ 次搬运的总步数就是把这些数逐个加起来（位置数组单调，即第 $j$ 靠右的 1、第 $j$ 靠左的 0 都可以一边扫一边取下标）。同时 $\Delta$ 也随之累加：前半段内部交换让 `inv0` 少 $N-1-q$，后半段内部交换让 `inv1` 少 $z-N$，中央交换按上面的常数改变 $\Delta$，合起来是

$$\Delta \mathrel{+}= -(N-1-q) + (z-N) + \big((\text{1 的总数})-N\big).$$

$t=0$（一次中央交换都不用）时需要 $|\Delta|$ 步：在逆序更多的那一半里，只要逆序对数大于 0，就一定能找到相邻的 1,0（取那个前面出现过 1 的最靠左的 0，它左边紧邻的必是 1），换一下就能让这一半的逆序对数恰好减少 1，重复 $|\Delta|$ 次即可配平。

**把两段拼起来。** 做完 $t$ 次搬运后 $\Delta$ 变成 $\Delta_t$，剩下的不平衡再用 $|\Delta_t|$ 次半内交换配平，所以固定 $t$ 的最优步数就是

$$\text{cost}(t) + |\Delta_t| .$$

于是只要让 $t$ 从 0 枚举到"能搬的个数"（前半段 1 的个数与后半段 0 的个数取较小者，否则第 2 步无 0 可搬），一路维护 $\text{cost}$ 与 $\Delta$，并随时更新答案的最小值。

**另一个方向。** 上面只处理了 $t \ge 0$。$t<0$（1 从后半段往前半段走，等价于把前半段的 0 推到后半段）只要把 0 和 1 的角色对调、方向反过来：第 $k$ 次搬运送走前半段里**第 $k$ 靠右的 0**（位置 $p$）、拉回后半段里**第 $k$ 靠左的 1**（位置 $y$）。此时前半段内部交换是把 0 往右挪过 1，会让 `inv0` 增加 $N-1-p$；后半段内部交换是把 1 往左挪过 0，会让 `inv1` 增加 $y-N$；中央交换是 0,1 → 1,0，$\Delta$ 变动 $N-(\text{1 的总数})$。合起来

$$\Delta \mathrel{+}= (N-1-p) - (y-N) + \big(N - (\text{1 的总数})\big), \qquad \text{cost} \mathrel{+}= (N-1-p) + (y-N) + 1 .$$

两个方向各扫一遍，取所有 $t$ 里的最小值就是答案。用样例验证一下：数组的 $\text{inv0}=1$、$\text{inv1}=3$、$\Delta=-2$、1 的总数是 3，不做中央交换要 2 步；而第二个方向第 1 次搬运取 $p=4$（前半段最靠右的 0）、$y=5$（后半段最靠左的 1），$\text{cost}=0+0+1=1$，$\Delta \mathrel{+}= 0-0+(5-3)=+2$ 正好归零，总代价 $1+0=1$，正是答案。
