# P3　奶牛格斗（Moortal Cowmbat）

## 题目

游戏中有 $M$ 个按键，对应前 $M$ 个小写字母（$1 \le M \le 26$）。Bessie 的连招是一个长度为 $N$ 的按键串 $S$（$1 \le N \le 10^5$）。新版本要求连招必须由若干「连段」组成：每个连段是同一种按键连续出现至少 $K$ 次（$1 \le K \le N$）。

把 $S$ 中某个位置从按键 $i$ 改成按键 $j$ 需要 $a_{ij}$ 天，并且可以借助中间按键转换（$i \to k \to j$ 可能比 $i \to j$ 更快）。求把 $S$ 改成合法连招所需的最少天数。

## 输入

第一行三个整数 $N, M, K$。
第二行一个长度为 $N$ 的字符串 $S$。
接下来 $M$ 行，每行 $M$ 个整数，给出矩阵 $a_{ij}$（$0 \le a_{ij} \le 1000$，且 $a_{ii} = 0$）。

## 输出

一个整数，表示最少天数。

## 样例

输入：

```text
5 5 2
abcde
0 1 4 4 4
2 0 4 4 4
6 5 0 3 2
5 5 5 0 4
3 7 0 5 0
```

输出：

```text
5
```

最优做法是把 `a` 改成 `b`、把 `d` 改成 `e`、再把两个 `e` 改成 `c`，共 $1+4+0+0=5$ 天，得到 `bbccc`。

## 思路

**第一步：修正转换代价。** 题目说明可以借道中间按键，所以先对 $M$ 个字母跑一遍 Floyd–Warshall，得到任意两个字母之间的真实最短转换代价 $d[i][j]$。

**第二步：前缀和。** 记 $ps[i][j]$ 为「把 $S$ 的前 $i$ 个位置全部改成 $j$」的花费，则 $ps[i][j] = ps[i-1][j] + d[S_i][j]$，这样任意连续区间 $[l+1, i]$ 全改成 $j$ 的花费可用 $ps[i][j] - ps[l][j]$ 在 $O(1)$ 内求出。

**第三步：DP。** 设 $dp[i][j]$ 表示「前 $i$ 个位置已经构成合法连招，且第 $i$ 位属于一个长度为至少 $K$、字母为 $j$ 的末连段」的最小花费，$mn[i] = \min_j dp[i][j]$（另外令 $mn[0] = 0$ 表示空前缀合法）。转移时只需区分末连段的长度：

- 末连段长度大于 $K$：把第 $i$ 位从原字母改成 $j$ 并接在长度 $i-1$ 的方案后面，即 $dp[i-1][j] + d[S_i][j]$。
- 末连段长度恰为 $K$：前 $i-K$ 位可以是任意合法方案（取 $mn[i-K]$），后面接上 $K$ 个字母 $j$，即 $ps[i][j] - ps[i-K][j] + mn[i-K]$。

两种取最小值即可。答案为 $mn[N]$。

注意 $mn[0] = 0$ 这个「没有末连段」的特殊状态让长度恰为 $K$ 的转移可以覆盖整个串都是同一个连段的情况；而 $dp[0][j] = \infty$ 保证不会从空串凭空延长出末连段。

## 复杂度

时间：Floyd–Warshall 为 $O(M^3)$，前缀和与 DP 为 $O(NM)$，即 $O(M^3 + NM)$。
空间：$O(NM)$（前缀和与 DP 各约 $26 \times 10^5$ 个 int）。
