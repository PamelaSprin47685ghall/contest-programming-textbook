# P1　时间就是金钱（Time is Mooney）

## 题目

Bessie 在 Bovinia 出差，Bovinia 有 $N$（$2 \le N \le 1000$）座城市，编号 $1 \ldots N$，城市之间由 $M$（$1 \le M \le 2000$）条单向道路连接。Bessie 每访问一次城市 $i$ 就能赚到 $m_i$ 块钱（$0 \le m_i \le 1000$，且 $m_1 = 0$）。她从城市 $1$ 出发，最终必须回到城市 $1$；走一条道路需要一天。若整个旅行持续 $T$ 天，出发前的准备花费为 $C \cdot T^2$（$1 \le C \le 1000$）。

求一次旅行最多能净赚多少钱。也可以选择哪里都不去，此时答案为 $0$。

## 输入

第一行三个整数 $N$、$M$、$C$。

第二行 $N$ 个整数 $m_1, \ldots, m_N$。

接下来 $M$ 行，每行两个整数 $a$、$b$（$a \neq b$），表示一条从 $a$ 到 $b$ 的单向道路。

## 输出

一行一个整数，表示最大净收益。

## 样例

输入：

```text
3 3 1
0 10 20
1 2
2 3
3 1
```

输出：

```text
24
```

样例中最优路线是 $1 \to 2 \to 3 \to 1 \to 2 \to 3 \to 1$，共赚 $10+20+10+20 = 60$，减去 $1 \times 6^2 = 36$，净赚 $24$。

## 思路

注意收益只取决于两件事：赚到的钱数与旅行天数 $T$。由于每次访问最多赚 $1000$，走 $T$ 天的净收益满足

$$1000T - C T^2 \le 1000T - T^2,$$

而 $1000T - T^2 < 0$ 当且仅当 $T > 1000$。空旅行（$T = 0$）收益为 $0$，所以最优解的天数一定有 $T \le 1000$：再走就纯亏了。这一观察把无穷多的可能天数压到 $1000$ 以内。

于是按时间做 DP：$dp[t][x]$ 表示「恰好走了 $t$ 天、当前停在城市 $x$」时的最大累计赚钱数（准备费用先不扣，最后统一结算）。转移就是枚举一条边 $(a,b)$：

$$dp[t][b] = \max\bigl(dp[t][b],\; dp[t-1][a] + m_b\bigr).$$

初值 $dp[0][1] = 0$，其余状态不可达。每算完一层 $t$，若 $dp[t][1]$ 可达就更新答案 $dp[t][1] - C t^2$（$t \le 1000$）。

实现细节：

- 每一层只用到上一层，用两个一维数组按天数奇偶滚动（第一维只留 $2$），空间 $O(N)$。
- 用 $-1$ 表示不可达；因为所有 $m_i \ge 0$，可达状态的收益一定 $\ge 0$，不会与 $-1$ 混淆。
- 答案初值为 $0$，对应一天都不走。
