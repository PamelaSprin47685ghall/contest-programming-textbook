# P2　农夫约翰解决三数之和（Farmer John Solves 3SUM）

## 题目

给定长度为 $N$（$1 \le N \le 5000$）的整数数组 $A$，其中每个元素满足 $-10^6 \le A_i \le 10^6$。接着有 $Q$（$1 \le Q \le 10^5$）组询问，每组给出两个下标 $1 \le a_i \le b_i \le N$，要求统计子数组 $A[a_i \ldots b_i]$ 中满足 $i < j < k$ 且 $A_i + A_j + A_k = 0$ 的三元组个数。

## 输入

第一行两个整数 $N$、$Q$。

第二行 $N$ 个整数 $A_1, \ldots, A_N$。

接下来 $Q$ 行，每行两个整数 $a_i$、$b_i$。

## 输出

输出 $Q$ 行，每行一个整数，表示对应询问的答案。答案可能很大，需要用 64 位整数。

## 样例

输入：

```text
7 3
2 0 -1 1 -2 3 3
1 5
2 4
1 7
```

输出：

```text
2
1
4
```

第一组询问（$A[1..5] = 2,0,-1,1,-2$）中合法的三元组是 $(A_1,A_2,A_5)$ 与 $(A_2,A_3,A_4)$。

## 思路

设 $ans[i][k]$ 表示子数组 $A[i \ldots k]$ 的答案，$num[i][k]$（$i < k$）表示满足 $i < j < k$ 且 $A_i + A_j + A_k = 0$ 的中间下标 $j$ 的个数。

一个零和三元组由它的最左、最右下标唯一确定位置，因此按「最右元素是不是 $k$、最左元素是不是 $i$」分类计数：

$$ans[i][k] = num[i][k] + ans[i][k-1] + ans[i+1][k] - ans[i+1][k-1].$$

即：恰以 $(i,k)$ 为两端的三元组（$num[i][k]$），加上最右元素不是 $k$、最左元素不是 $i$ 的部分，后两者有交集，容斥减去 $ans[i+1][k-1]$。

$num$ 的整行可以用滑动计数求出：固定 $i$，让 $k$ 从 $i+1$ 递增，同时用一个计数数组维护 $A_{i+1}, \ldots, A_{k-1}$ 各值的出现次数，则 $num[i][k]$ 就是 $-A_i - A_k$ 的出现次数；$k$ 每加一，只需把 $A_k$ 插入计数数组。因为 $|A_i| \le 10^6$，目标和落在 $[-2 \times 10^6, 2 \times 10^6]$，用大小为 $4 \times 10^6 + 1$、偏移 $2 \times 10^6$ 的数组替代哈希表即可 $O(1)$ 定位（哈希表的常数在这里过不了时限）。

两个关键的空间优化：

- 递推式只依赖 $i$ 与 $i+1$ 两行，所以不需要存 $N \times N$ 个 64 位答案（那会超出内存），只保留相邻两行，从 $i = N-1$ 递减逐行递推即可。
- $num$ 不必存下来，它在同一行内随 $k$ 递增就能增量算出，直接参与该行的 $ans$ 递推。

询问按左端点 $a$ 挂成链表（头插法，$O(1)$ 插入），处理到第 $i$ 行时一次性回答所有 $a = i$ 的询问，每次 $O(1)$ 直接取 $ans[i][b]$。计数数组只需撤销本行插入过的元素，不必整表清零。

## 复杂度

时间：$O(N^2 + Q)$，约为 $5 \times 10^7$ 次基本操作。

空间：$O(N + Q + 4 \times 10^6)$，其中计数数组约 16 MB。
