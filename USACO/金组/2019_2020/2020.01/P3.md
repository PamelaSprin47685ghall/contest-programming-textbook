# P3　跳板（Springboards）

## 题目

Bessie 身处一个二维网格，她只能沿平行于坐标轴的方向行走，并且只允许向上或向右移动，绝不向左或向下。她从 $(0,0)$ 出发，想要到达 $(N,N)$（$1 \le N \le 10^9$）。

网格上有 $P$（$1 \le P \le 10^5$）块跳板，第 $i$ 块位于 $(x_1, y_1)$，Bessie 使用它就会立刻落到 $(x_2, y_2)$；题目保证 $x_1 \le x_2$ 且 $y_1 \le y_2$（跳板同样只会向上、向右传送）。所有跳板位置与目标位置互不相同。

求 Bessie 到达 $(N,N)$ 最少需要走多少距离。

## 输入

第一行两个整数 $N$、$P$。

接下来 $P$ 行，每行四个整数 $x_1$、$y_1$、$x_2$、$y_2$，表示一块从 $(x_1,y_1)$ 传送到 $(x_2,y_2)$ 的跳板。

## 输出

输出一个整数，表示最少步行距离。

## 样例

输入：

```text
3 2
0 1 0 2
1 2 2 3
```

输出：

```text
3
```

样例的最优路径为：$(0,0) \to (0,1)$ 走 1 步，跳到 $(0,2)$，$(0,2) \to (1,2)$ 走 1 步，跳到 $(2,3)$，$(2,3) \to (3,3)$ 走 1 步，合计 $3$。

## 思路

跳板本身不消耗任何距离，只有步行计入答案，所以关键在于「用哪些跳板、以什么次序用」。设 $dp[i]$ 表示走到第 $i$ 块跳板起点所需的最小步行距离。有两种可能：

- 直接从原点走过去：$dp[i] = x_1[i] + y_1[i]$。
- 在此之前最后使用了一块跳板 $j$，再从它的落点走到 $i$ 的起点：
  $$dp[i] = dp[j] + \bigl(x_1[i] + y_1[i] - x_2[j] - y_2[j]\bigr),$$
  这要求 $x_2[j] \le x_1[i]$ 且 $y_2[j] \le y_1[i]$。

因为 $x_1 \le x_2$、$y_1 \le y_2$，沿着「起点→落点→下一块起点」的顺序，$x$ 坐标单调不减，所以不会出现循环依赖：按 $x$ 递增处理即可。

把每块跳板的起点和落点各看成一个事件，全部按 $(x, y)$ 升序扫描。扫描到某个落点就把值 $dp[j] - x_2[j] - y_2[j]$ 插入数据结构；扫描到某个起点就查询所有 $y \le y_1[i]$ 的已插入值中的最小值。于是

$$dp[i] = x_1[i] + y_1[i] + \min\{\,dp[j]-x_2[j]-y_2[j] : y_2[j] \le y_1[i]\,\}.$$

最终答案是最后一段步行的距离：从最优的最后落点走到 $(N,N)$，即 $2N + \min\bigl(dp[j]-x_2[j]-y_2[j]\bigr)$；预先插入一个位于 $y = 0$、值为 $0$ 的「虚落点」，就同时涵盖了「一块跳板都不用」的情形（此时答案是 $2N$）。

数据结构只需支持「单点插入取 min」与「前缀最小值查询」，把落点 $y$ 坐标离散化后用树状数组实现：插入向上更新、查询向下累计，各 $O(\log P)$。

实现细节：

- 同一坐标处先处理落点、再处理起点（$kind$ 小者在前）。这样「某块跳板的落点恰好是另一块跳板的起点」时能连跳，而不会漏掉这条转移。
- 起点与落点重合的跳板（原地跳）永远不花代价也不产生位移，去掉它后答案不变，因此直接忽略；否则它的落点事件会早于自己的起点事件被处理，插入尚未计算的 $dp$。
- 事件排序与坐标离散化都用手写归并排序，$x$ 相同时按 $y$、再按 $kind$ 比较。
