# P1　时间线（Timeline）

## 题目

贝西在过去 $M$ 天（$2 \le M \le 10^9$）里参加了 $N$ 次挤奶（$1 \le N \le 10^5$），但她记不清每次挤奶的具体日期。她掌握的信息有两类：

- 对第 $i$ 次挤奶，她知道它发生在不早于第 $S_i$ 天（$1 \le S_i \le M$）；
- 另外还有 $C$ 条回忆（$1 \le C \le 10^5$），每条形如 $(a, b, x)$，表示第 $b$ 次挤奶至少比第 $a$ 次晚 $x$ 天（$a \ne b$，$1 \le x \le M$）。

题目保证贝西没有记错，即存在一组落在 $1 \ldots M$ 内的日期满足全部约束。请求出每次挤奶可能存在的最早日期。

## 输入

第一行三个整数 $N$、$M$、$C$。
第二行 $N$ 个整数 $S_1, S_2, \ldots, S_N$。
接下来 $C$ 行，每行三个整数 $a, b, x$。

## 输出

输出 $N$ 行，第 $i$ 行给出第 $i$ 次挤奶的最早可能日期。

## 样例

输入：

```text
4 10 3
1 2 3 4
1 2 5
2 4 2
3 4 4
```

输出：

```text
1
6
3
8
```

第 2 次挤奶至少在第 1 次之后 5 天，所以不早于第 $1+5=6$ 天；第 4 次至少在第 2 次之后 2 天，所以不早于第 $6+2=8$ 天。

## 思路

把每条回忆 $(a,b,x)$ 看作一条从 $a$ 指向 $b$、边权为 $x$ 的有向边，含义是 $\text{date}_b \ge \text{date}_a + x$。由于约束可满足，这张有向图里不可能有环：若存在环，沿环把不等式累加会得到 $\text{date}_v \ge \text{date}_v + (\text{正数})$，矛盾。所以图是 DAG，可以拓扑排序。

于是初始化 `date[i] = S[i]`，按拓扑序依次处理每个点 $v$，对它的每条出边 $(v,u,x)$ 做松弛：

$$\text{date}_u = \max(\text{date}_u,\ \text{date}_v + x).$$

一遍拓扑序扫描就够了，理由如下：

- **所有约束都满足**：每次松弛都是把终点抬高到「至少等于起点的当前值加 $x$」，而起点后续只会变大不会变小，所以最终结果仍满足 $\text{date}_b \ge \text{date}_a + x$。
- **每项都取到了最小值**：设最优解为 $\text{date}^*$。按拓扑序归纳可证始终有 $\text{date}_v \le \text{date}^*_v$：初始值 $S_v \le \text{date}^*_v$；松弛时新值是 $\text{date}_v + x$，由归纳假设 $\text{date}_v \le \text{date}^*_v$，再结合最优解满足 $\text{date}^*_u \ge \text{date}^*_v + x$，可知新值也不超过 $\text{date}^*_u$。

两方面的结论合起来：最终得到的既是一组可行解，又是所有可行解的下界，即每项都是最早日期。

实现上就是 Kahn 拓扑排序：入度为 $0$ 的点入队，出队时松弛所有出边，并把终点的入度减一，减到 $0$ 就入队。每个点和每条边只处理一次，因此是 $O(N+C)$。由于保证有解，图中没有环，也不会有点处理不到。

实现上只需要一张 DAG 和入度数组：存图用链式前向星，队列用普通数组。所有日期都不会超过 $M \le 10^9$，`int` 足够，无需 64 位整数。
