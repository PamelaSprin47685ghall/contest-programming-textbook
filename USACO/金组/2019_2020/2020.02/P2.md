# P2　自助（Help Yourself）

## 题目

贝西得到了数轴上的 $N$ 条线段（$1 \le N \le 10^5$），第 $i$ 条覆盖所有满足 $l_i \le x \le r_i$ 的实数 $x$。

一组线段的**并集**是至少被其中一条线段覆盖的点的集合；并集的**连通块个数**称为这组线段的复杂度。

对全部 $2^N$ 个子集求出复杂度之和，模 $10^9+7$ 输出。保证 $l_i < r_i$，且 $2N$ 个端点两两不同、都在 $1 \ldots 2N$ 内。

## 输入

第一行一个整数 $N$。
接下来 $N$ 行，每行两个整数 $l_i$、$r_i$。

## 输出

输出一个整数，即全部子集的复杂度之和对 $10^9+7$ 取模的结果。

## 样例

输入：

```text
3
1 6
2 3
4 5
```

输出：

```text
8
```

各非空子集的复杂度依次为 $1,1,1,1,1,2,1$，相加得 $8$。

## 思路

直接枚子集当然不行，改成**对每个「起点」计数**。一组线段的并集里，每个连通块的左端一定恰好落在某条线段的左端点上；反过来，第 $i$ 条线段的左端点 $l_i$ 会「开出一个新连通块」，当且仅当：

1. 子集包含第 $i$ 条线段（否则这个左端点压根没出现）；
2. 子集中没有别的线段覆盖开区间 $(l_i-1,\ l_i)$——否则 $l_i$ 会被那条线段的覆盖区域连到左边去。

注意第 $i$ 条线段本身不覆盖 $(l_i-1, l_i)$，所以条件 2 排除的线段里不含它自己（它只需被「选上」）。于是

$$\text{答案} = \sum_{i=1}^{N} 2^{\,N-1-\text{cnt}(l_i-1)} \bmod (10^9+7),$$

其中 $\text{cnt}(p)$ 是覆盖位置 $p$ 的线段条数，也就是「需排除」的那些线段：它们必须全不出现在子集里，第 $i$ 条必须出现，剩下的 $N-1-\text{cnt}(l_i-1)$ 条线段可以任意取舍。

$\text{cnt}$ 用差分数组求：每条线段做 `cover[l]++, cover[r]--`，再对位置 $1 \ldots 2N$ 做前缀和，`cover[p]` 就是覆盖 $p$ 的线段条数。因为「覆盖 $p$ 的线段」恰好等价于「$l \le p$ 且 $r > p$」，也就是 $l \le l_i-1$ 且 $r \ge l_i$，正是我们要排除的集合（$p = l_i - 1$ 时下标为 $0$ 也安全，前缀和数组首项是 $0$）。

$2$ 的幂预处理到 $N-1$ 次即可，总复杂度线性。
