# P1　理发（Haircut）

## 题目

农夫约翰有一头乱发，决定去理发。他有 $N$ 根头发排成一排（$1 \le N \le 10^5$），第 $i$ 根头发的初始长度是 $A_i$ 微米（$0 \le A_i \le N$）。他希望头发从左到右单调不降，于是把发型的「糟糕度」定义为逆序对数：满足 $i < j$ 且 $A_i > A_j$ 的数对 $(i,j)$ 的个数。

他想对每个 $j = 0, 1, \ldots, N-1$ 知道：如果所有长度超过 $j$ 的头发都被剪到长度恰好为 $j$，此时发型的糟糕度是多少。

## 输入

第一行一个整数 $N$。

第二行 $N$ 个整数 $A_1, A_2, \ldots, A_N$。

## 输出

输出 $N$ 行，第 $j+1$ 行表示把长度超过 $j$ 的头发都剪到 $j$ 之后的糟糕度。

## 样例

输入：

```text
5
5 2 3 3 0
```

输出：

```text
0
4
4
5
7
```

当 $j=3$ 时头发变为 $[3,2,3,3,0]$，共 5 个逆序对：$(1,2)$、$(1,5)$、$(2,5)$、$(3,5)$、$(4,5)$。

## 思路

「把长度超过 $j$ 的头发都剪到 $j$」就是让第 $i$ 根头发变成 $\min(A_i, j)$。于是 $ans[0] = 0$（全部变成 0，没有一个逆序对），而对其他 $j$，直接重算一遍需要 $O(N^2)$ 或更慢，总量超时。关键观察是相邻两次裁剪只差一点：从 $j-1$ 换成 $j$ 时，**恰好长度不小于 $j$ 的头发从 $j-1$ 变成 $j$，其余头发不变**。

把 $j-1$ 时的每个数对 $(x,y)$（$x<y$）按两边是否变化分四类，看它是否从「不是逆序对」变成「是逆序对」：

- 两边都不变：数值都没变，结论不变；
- 两边都变：两边都是 $j-1$ 变 $j$，始终相等，都不是逆序对；
- 左边不变、右边变：左边值 $A_x \le j-1$，右边从 $j-1$ 变 $j$，两边大小关系始终是「左不大于右」，都不是逆序对；
- 左边变、右边不变：左边从 $j-1$ 变 $j$，右边是某个 $A_y \le j-1$。裁剪前是逆序对当且仅当 $A_y < j-1$，裁剪后是逆序对当且仅当 $A_y < j$。

所以只有第四类里 $A_y = j-1$ 的那些数对会发生变化：裁剪前两边都等于 $j-1$，裁剪后左边变成 $j$、大于右边，恰好新增一个逆序对。其余情况逆序对数目不变。于是

$$ans[j] = ans[j-1] + \sum_{y:\ A_y = j-1} \bigl(\#\{x < y : A_x > A_y\}\bigr).$$

也就是说，只要求出每个位置 $y$ 左边比它长的头发根数 $n[y]$，再把这些数按 $A_y$ 分组、对长度做前缀和，就能一次得到所有答案：

$$ans[j] = \sum_{v < j}\ \sum_{y:\ A_y = v} n[y].$$

$n[y]$ 用树状数组扫一遍求：扫到第 $y$ 个位置时，树状数组里正好存着它左边全部 $y$ 根头发的长度，其中长度不超过 $A_y$ 的根数可以直接查到，用 $y$ 减去它就得到 $n[y]$。长度取值范围是 $0..N$，把长度加一作为树状数组下标即可。

答案最大约为 $N^2/2 \approx 5 \times 10^9$，超过 `int`，要用 `long long`。
