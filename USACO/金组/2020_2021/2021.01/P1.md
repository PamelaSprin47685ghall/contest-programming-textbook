# P1　奶牛字母表（Uddered but not Herd）

## 题目

奶牛有自己的字母表 "cowphabet"，由 'a' 到 'z' 这 26 个字母按某个顺序排列而成，顺序与人类习惯的 `abcdefghijklmnopqrstuvwxyz` 可能不同。

Mildred 把整份 cowphabet 一遍又一遍地循环哼唱，Farmer Nhoj 好奇她到底唱了多少遍。Nhoj 有时走神，只记住了其中一部分字母，于是给你的是他听到的那串小写字母。求 Mildred 至少把整份 cowphabet 完整哼唱了多少遍，Nhoj 才可能听到给出的这串字母。

听到的字符串长度不超过 $10^5$。

## 输入

一行，一个长度在 $1$ 到 $10^5$ 之间的小写字母串，表示 Farmer Nhoj 听到的字母。

## 输出

一个整数：Mildred 至少完整哼唱 cowphabet 的次数。

## 样例

输入：

```text
mildredree
```

输出：

```text
3
```

三遍就够了：只要 cowphabet 以 `mildre` 开头，三遍哼唱中依次听到 `MILDRE...`、`milDRE...`、`mildrE...`（大写字母是 Nhoj 记住的那些），正好拼出 `mildredree`。两遍则不可能。

## 思路

先只保留听到的串里真正出现过的字母，设共有 $N$ 种（官方测试保证 $N \le 20$），其余字母不会影响任何比较。

**固定顺序时怎么算次数。** 设 cowphabet 中字母的顺序为 $p_1, p_2, \ldots, p_N$。铜组题的分析给出了结论：需要的哼唱次数等于

$$1 + \#\{\text{相邻两对字符 } (u,v) \text{ 满足 } u \text{ 在 cowphabet 中不早于 } v\}.$$

道理是：只要相邻两个被听到的字母出现"逆序"（前一个的位置不早于后一个），就说明这两个字母之间一定夹着一次整遍的循环；每个这样的断点都要多唱一遍，而第一个字母之前至少已唱了一遍。

于是把串中所有相邻对统计进 `adj[u][v]`（$u,v$ 是字母编号），固定顺序 $p$ 时的次数就是

$$\text{evaluate}(p) = 1 + \sum_{i=1}^{N}\sum_{j\le i} \texttt{adj}[p_i][p_j].$$

**枚举所有顺序？** $N!$ 太大。换个角度看这份求和：按 cowphabet 的顺序依次确定字母时，"最后放进去的那个字母 $j$"只会和它前面（以及它自己）的字母产生逆序对。因此用状压 DP：

- `dp[mask]`：只用 `mask` 里的字母（它们构成 cowphabet 的一段前缀）时的最小哼唱次数；
- 转移：枚举 $mask$ 中排在最后的字母 $j$，则
  $\text{dp}[mask] = \min_{j \in mask}\left(\text{dp}[mask \setminus \{j\}] + \sum_{k \in mask} \texttt{adj}[j][k]\right)$；
- 边界 `dp[0] = 1`，答案 `dp[全 1]`。

**一个实现细节。** 转移里要对每个 $j$ 求"$mask$ 内所有 $k$ 的 `adj[j][k]` 之和"。若把它存成 $N \times 2^N$ 的表，内存开销约 $20 \times 2^{20}$ 个整数，太大。改成折半：把 `mask` 拆成低 $N/2$ 位与高 $N/2$ 位，分别预处理 `lowSum[子集][j]` 与 `highSum[子集][j]`（用最低位递推），则任意一次查询只需两次查表，空间降到 $2^{N/2}N$。

## 复杂度

时间 $O(2^N N + |s|)$，空间 $O(2^N + 2^{N/2} N)$，其中 $N$ 为出现过的不同字母数（$N \le 20$），$|s|$ 为听到的串长。
