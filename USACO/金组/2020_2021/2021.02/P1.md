# P1　石头游戏（Stone Game）

## 题目

贝茜和埃尔希在玩一个有 $N$（$1 \le N \le 10^5$）堆石子的游戏，第 $i$ 堆有 $a_i$（$1 \le a_i \le 10^6$）颗石子，两头牛轮流行动，贝茜先手：

- 贝茜先选一个正整数 $s_1$，从某一堆至少 $s_1$ 颗石子的堆中取走 $s_1$ 颗；
- 埃尔希再选一个正整数 $s_2$，要求 $s_1$ 整除 $s_2$，同样从某一堆至少 $s_2$ 颗石子的堆中取走 $s_2$ 颗；
- 依此类推，第 $i$ 次取走的 $s_i$ 必须整除下一次取走的 $s_{i+1}$。

轮到某头牛无法取石子时她输掉游戏。请数出贝茜有多少种首步走法能保证获胜（即存在策略，使得不论埃尔希怎么走贝茜都赢）。只要取走的石子数不同、或者取的那一堆不同，就算两种不同的走法。

## 输入

第一行一个整数 $N$。

第二行 $N$ 个空格分隔的整数 $a_1, \ldots, a_N$。

## 输出

一个整数：贝茜首步必胜的走法数（答案可能很大，需要 64 位整数）。

## 样例

输入：

```text
1
7
```

输出：

```text
4
```

只有一堆 7 颗石子时，贝茜取走 4、5、6 或 7 颗都会让埃尔希无子可取，游戏立刻以贝茜获胜结束。

输入：

```text
6
3 2 3 2 3 1
```

输出：

```text
8
```

贝茜从任意一堆取走 2 或 3 颗都能获胜：之后两头牛每回合取走的数量完全相同（后者必须取前者的倍数，而先手总能跟上），贝茜下最后一手。

## 思路

**把局面按当前倍数归一化。** 设上一手取走的石子数是 $s$（首手可看作 $s = 1$），那么之后每一手取走的数量都是 $s$ 的倍数。写 $a = qs + r$（$0 \le r < s$），有恒等式
$$\left\lfloor \frac{a}{ks} \right\rfloor = \left\lfloor \frac{q}{k} \right\rfloor = \left\lfloor \frac{\lfloor a/s \rfloor}{k} \right\rfloor \qquad (k \ge 1),$$
所以把每堆石子换成 $\left\lfloor a_i / s \right\rfloor$ 个"大石子"以后，从某一堆取走 $k$ 个大石子（也就是 $ks$ 颗真石子）得到的后续局面，与限制解除后的原始游戏完全一致。（取不动的大石子堆即 $\lfloor a_i/s \rfloor = 0$ 的堆，与真石子数为 0 一样不可用。）

**败局判据。** 归一化后，局面必败当且仅当每种"大石子"个数都出现偶数次：

- 全是偶数时，后手可以把等大的大石子堆两两配对。对手从某一堆取走 $k$ 个大石子，后手就在与它配对的那堆取走 $k$ 个（配对堆等大，一定取得动），下一层再按 $k$ 归一化时配对的两堆仍然等值，归纳可知后手永远有应手。
- 存在奇数时，先手取"个数为奇数的最大值 $v$"的那一堆整堆（取走 $v$ 个大石子，此时倍数变成 $v$）。归一化后：大石子数 $< v$ 的堆全变成 $0$、直接失效；个数为 $v$ 的这一类恰好变成偶数；大石子数 $> v$ 的各堆本来两两成对，按 $\lfloor \cdot / v \rfloor$ 分组后每组是若干偶数之和，仍是偶数。于是对手面对的是全偶局面，必败。

在首手之前 $s = 1$，所以"必胜首手"就是取完之后让场上的石堆大小每种都恰好出现偶数次。

**把首步换算成商序列。** 固定首步取走的石子数 $x$（显然只需 $x \le \max a_i$）。考察序列
$$S_x=\left[\left\lfloor \frac{a_1}{x}\right\rfloor, \left\lfloor \frac{a_2}{x}\right\rfloor, \ldots, \left\lfloor \frac{a_N}{x}\right\rfloor\right].$$
这一步之后倍数变成 $x$，按上面的判据，胜负取决于 $S_x$ 里各值出现次数的奇偶性。从大小为 $q x + r$（$0 \le r < x$）的一堆中取走 $x$ 颗，商恰好从 $q$ 变成 $q-1$（取空时变成 $0$）。也就是说，首步取 $x$ 颗等价于把 $S_x$ 中的某个正整数 $t$ 减一，然后丢掉所有 $0$。要让局面成为败局（每个正整数的出现次数都是偶数），那么取之前的奇数位置只能有两种情况：

- 只有 $t=1$ 出现奇数次（减一后变成 $0$，被丢弃）；
- 只有 $t-1$ 与 $t$（相邻的两个正整数）出现奇数次（减一后两者都变成偶数次）。

其余任何"奇数位置集合"都不满足条件。对满足条件的 $x$，它对答案的贡献就是从商为 $t$ 的那些堆中任取一堆的堆数，即 $S_x$ 中 $t$ 的出现次数。

**快速求出商的出现次数。** $t$ 在 $S_x$ 中的出现次数就是输入中落在 $[xt,\ x(t+1)-1]$ 内的整数个数。把 $a_i$ 做成前缀和，即可 $O(1)$ 求出任意区间的个数。对每个 $x$ 只枚举 $t = 1 \ldots \lfloor \max a_i / x\rfloor$，边算边记录奇数位置个数与最后两个奇数位置，判断是否为 $\{1\}$ 或相邻两数，再累加答案。

## 复杂度

时间 $O(N + \max a_i \log \max a_i)$：外层枚举 $x$，内层枚举 $t$ 的总次数是调和级数 $O(\max a_i \log \max a_i)$，每个 $t$ 只做常数次前缀和查询。空间 $O(\max a_i)$：两个长度 $\max a_i + 2$ 的数组。
