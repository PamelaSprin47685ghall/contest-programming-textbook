# P3　数奶牛（Count the Cows）

## 题目

奶牛们散布在农夫约翰的大牧场上，牧场可以看成一个巨大的二维方格网。对每个坐标 $(x,y)$（$x \ge 0,\ y \ge 0$），如果对一切整数 $k \ge 0$，$\left\lfloor \frac{x}{3^k}\right\rfloor$ 与 $\left\lfloor \frac{y}{3^k}\right\rfloor$ 除以 3 的余数奇偶性都相同（余数同为奇数，即等于 1；或者同为偶数，即等于 0 或 2），那么 $(x,y)$ 这一格上就有一头奶牛。

农夫约翰有 $Q$（$1 \le Q \le 10^4$）个询问，每个询问给出三个整数 $x_i, y_i, d_i$，想知道从 $(x_i, y_i)$ 到 $(x_i + d_i, y_i + d_i)$ 这条对角线上（含两端）一共有多少头奶牛。

## 输入

第一行一个整数 $Q$。

接下来 $Q$ 行，每行三个整数 $d_i, x_i, y_i$（$0 \le x_i, y_i, d_i \le 10^{18}$）。

## 输出

$Q$ 行，每行一个整数，表示对应询问对角线上奶牛的数量。

## 样例

输入：

```text
8
10 0 0
10 0 1
9 0 2
8 0 2
0 1 7
1 1 7
2 1 7
1000000000000000000 1000000000000000000 1000000000000000000
```

输出：

```text
11
0
4
3
1
2
2
1000000000000000001
```

## 思路

对角线上的点可以统一写成 $(x+k,\ y+k)$，于是每个询问就是要求出满足 $0 \le k \le d$ 且 $(x+k, y+k)$ 有奶牛的 $k$ 的个数。

**逐位确定 $k$ 的三进制数字。** 设 $x,y,k$ 的第 $i$ 位（从低位起）三进制数字分别为 $xd,yd,j$，同时用 $xc, yc$ 记录低位相加产生的进位。令 $sx = xd + xc + j$、$sy = yd + yc + j$，那么 $x+k$ 与 $y+k$ 的第 $i$ 位分别是 $sx \bmod 3$ 与 $sy \bmod 3$，向高位的进位分别是 $\lfloor sx/3 \rfloor$ 与 $\lfloor sy/3 \rfloor$（因为 $xd, j \le 2$、$xc \le 1$，所以 $sx \le 5$，进位只能是 0 或 1）。第 $i$ 位合法的条件就是 $sx \bmod 3$ 与 $sy \bmod 3$ 的奇偶性相同。

**同时管住 $k \le d$。** 从低位向高位处理时，"谁大谁小"由最高的那个差异位决定。于是再记录一个比较状态 $cmp$：

- $cmp = 1$：目前为止 $k$ 的低位与 $d$ 完全相同；
- $cmp = 0$ 或 $2$：已经出现差异，且 $k$ 在该位小于/大于 $d$。由于更高的差异位会覆盖旧结论，每遇到 $j \ne dd$ 就直接按 $j$ 与 $dd$ 的大小重写 $cmp$。

处理完所有位后，$cmp \in \{0, 1\}$ 表示 $k < d$ 或 $k = d$，即 $k \le d$；同时要求最终进位 $xc = yc = 0$，保证求和没有溢出到更多位。

**位数取多少？** $x + k \le 2 \times 10^{18} < 3^{39}$，而 $x,y < 3^{39}$ 时高于第 38 位的所有 $\left\lfloor x/3^k \right\rfloor$ 都是 0，奇偶性自然相同，因此只需处理 $39 = \log_3(2 \times 10^{18})$ 位。

状态只有 $3 \times 2 \times 2 = 12$ 种，每位枚举 $j \in \{0,1,2\}$，单个询问的代价是常数级的 $39 \times 12 \times 3$。

## 复杂度

时间 $O(39 \cdot 12 \cdot 3 \cdot Q)$，即每个询问 $O(\log_{3}(\max(x,y,d)))$；空间 $O(1)$，只用到两个 $3 \times 2 \times 2$ 的 DP 数组和若干个 $3$ 的幂。
