# P3　排列（Permutation）

## 题目

Bessie 有 $N$（$3 \le N \le 40$）个互不相同的二维格点，任意三点不共线。她按如下方式画线段：

- 选择一个 $N$ 个点的排列 $p_1, p_2, \ldots, p_N$；
- 画出线段 $p_1p_2$、$p_2p_3$、$p_3p_1$；
- 对 $i = 4$ 到 $N$ 依次进行：对所有 $j < i$ 且线段 $p_i p_j$ 不与任何已画线段相交（端点处不算）的 $j$，画出 $p_i p_j$。

Bessie 发现对每个 $i$ 她恰好画出了三条新线段。求满足这一性质的排列数，模 $10^9+7$。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个整数 $x_i, y_i$（$0 \le x_i, y_i \le 10^4$）。

## 输出

一行一个整数：合法的排列数模 $10^9+7$。

## 样例

样例 1：

输入：

```text
4
0 0
0 4
1 1
1 2
```

输出：

```text
0
```

没有任何排列可行。

样例 2：

输入：

```text
4
0 0
0 4
4 0
1 1
```

输出：

```text
24
```

所有排列都可行。

样例 3：

输入：

```text
5
0 0
0 4
4 0
1 1
1 2
```

输出：

```text
96
```

一个可行的排列是 $(0,0),(0,4),(4,0),(1,2),(1,1)$：先画前三个点之间的三角形，再从 $(0,0),(0,4),(4,0)$ 连到 $(1,2)$（三条），最后从 $(1,2),(4,0),(0,0)$ 连到 $(1,1)$（三条）。若前四个点是 $(0,0),(1,1),(1,2),(0,4)$ 的任意顺序，则不可行。

## 思路

**图画到任何一步都是"一个大三角形 + 内部剖分"。** 画完前三个点是一个三角形。之后每加一个点 $p_i$：

- 若它落在当前大三角形**内部**，它必定落在某个内部小三角形里，此时它恰好只看得见那个小三角形的三个顶点，于是正好连出三条边，把小三角形剖成三个；
- 若它落在当前大三角形**外部**，内部所有点都被挡住，它至多只能连到大三角形的那三个顶点。要恰好连出三条，就必须三个顶点都连得上。

所以合法的过程是：每一步的新点要么落在当前大三角形内，要么落在外面且能看见大三角形的三个顶点（此时大三角形被"顶"成一个包含原三角形的新大三角形）。

**倒序 DP。** 设 $dp_T$ 表示"当前大三角形为 $T$、$T$ 外部所有点还都没画"时，画完 $T$ 外所有点的方案数。整个过程要求存在一个包住所有 $N$ 个点的三角形（它必须是面积最大的那个三角形，否则答案为 $0$），从这个"最大三角形" $T_{\text{all}}$ 出发，$dp_{T_{\text{all}}} = 1$。

$T$ 变大成 $T'$ 的逆操作是：把 $T$ 的某个顶点换成 $T$ 内部的一个点 $p$，得到 $T'$。设三角形 $T$ 内（含边界）有 $|T|$ 个点，$T$ 外有 $x = N - |T|$ 个点，$T'$ 外有 $y = N - |T'|$ 个点。位于 $T$ 外但在 $T'$ 内的点共有 $x - y - 1$ 个，其中 $T'$ 的那个新顶点必须最先画（否则在 $T$ 还是大三角形时就会画到 $T$ 外面的点）；此后剩下的 $x - y - 1$ 个点都在 $T'$ 内，与 $T'$ 外的 $y$ 个点可以任意交错。记 $P(a, b) = \dfrac{a!}{(a-b)!}$（从 $a$ 个元素中有序取 $b$ 个），则转移为

$$dp_T \mathrel{+}= P(x - 1,\ x - y - 1) \cdot dp_{T'}.$$

把三角形按面积从大到小处理，就满足了转移的先后顺序（转移永远指向面积更小的三角形）。

**统计答案。** 枚举最初三点构成的三角形 $T$：三个顶点有 $3! = 6$ 种顺序；$T$ 外的点按 $dp_T$ 种顺序画；$T$ 内部的 $|T| - 3$ 个点随时可以画（因为大三角形已经是 $T$），只需与其余 $N - 3$ 步交错，有 $P(N-3,\ |T| - 3)$ 种放法。于是

$$\text{ans} = 6 \sum_{T} P(N - 3,\ |T| - 3)\, dp_T \pmod{10^9+7}.$$

## 复杂度

时间 $O(N^4)$：共有 $O(N^3)$ 个三角形，每个三角形向 $O(N)$ 个内部点、每点 $3$ 种替换转移；另有 $O(N^4)$ 的预处理（也可做到更低）。空间 $O(N^3)$。
