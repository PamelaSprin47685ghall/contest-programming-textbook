# P2　高低猜数（HILO）

## 题目

Bessie 心里想了一个数 $x+0.5$，其中 $x$ 是 $0$ 到 $N$ 之间的整数（$1 \le N \le 2 \times 10^5$）。

Elsie 要猜这个数。她可以问形如"$i$ 是高还是低？"的问题，其中 $i$ 是 $1$ 到 $N$ 之间的整数；若 $i > x+0.5$，Bessie 回答 `HI`，若 $i < x+0.5$，回答 `LO`。

Elsie 的策略是：事先给出一个 $1$ 到 $N$ 的排列，依次询问排列中的数，但会跳过"没有必要问"的数——若她打算问 $i$，而之前问过某个 $j < i$ 并得到回答 `HI`，她就不问 $i$；同理，若之前问过某个 $j > i$ 并得到回答 `LO`，她也不问 $i$。可以证明，无论排列是什么，这个策略总能唯一确定 $x$。

把 Bessie 的所有回答按顺序拼成一个字符串 $S$，那么 Bessie 说 `HILO` 的次数就是 $S$ 中长度为 $4$ 的子串等于 `HILO` 的个数。Bessie 已经知道了 Elsie 使用的排列，但她还没决定 $x$。请对每个 $x = 0, 1, \ldots, N$ 求出她说 `HILO` 的次数。

## 输入

第一行一个整数 $N$。
第二行 $N$ 个整数，表示 Elsie 的排列。

## 输出

共 $N+1$ 行，第 $i+1$ 行（$i$ 从 $0$ 开始）输出 $x = i$ 时 Bessie 说 `HILO` 的次数。

## 样例

输入：

```text
5
5 1 2 4 3
```

输出：

```text
0
1
1
2
1
0
```

对 $x=0$，Bessie 会说 `HIHI`，共 $0$ 个 `HILO`；对 $x=2$，她说 `HILOLOHIHI`，共 $1$ 个；对 $x=3$，她说 `HILOLOHILO`，共 $2$ 个。

## 思路

记排列为 $a_1, \ldots, a_N$，$\mathrm{pos}[v]$ 表示值 $v$ 在排列中的下标。

**观察一**：位置 $i$ 处到底会不会被问、回答是 `HI` 还是 `LO`，只取决于当前区间 $[\mathrm{mn}, \mathrm{mx}]$（初始 $\mathrm{mn}=0,\ \mathrm{mx}=N+1$）：若 $a_i$ 落在区间外就跳过；否则 $a_i > x$ 时说 `HI` 并令 $\mathrm{mx} = a_i$，$a_i < x$ 时说 `LO` 并令 $\mathrm{mn} = a_i$。

**观察二**：若位置 $i$ 是某个 `HILO` 对里的那个 `LO`，与它配对的 `HI` 一定是"$i$ 之前出现的、比 $a_i$ 大的最小元素"所在的 $\mathrm{prv}[i]$。因为若在它之前先说了某个更大的值 $HI$，$i$ 就会被跳过而不会被问；而按值从小到大不断收缩 $\mathrm{mx}$ 的过程恰好使 $\mathrm{prv}[i]$ 成为最后一次可能的 `HI`。若这样的元素不存在，$i$ 前面没有任何 `HI`，$i$ 就不可能是 `HILO` 里的 `LO`。

$\mathrm{prv}$ 可以用单调栈一次求出：按值从大到小扫描，栈中保存下标且从栈底到栈顶下标递增，遇到 $\mathrm{pos}[v]$ 就弹掉所有大于它的下标（这些下标在更靠左的位置上永远不可能成为"之前最小更大元素"），栈顶就是答案。

**观察三**：对固定的 $x$，所有被回答 `LO` 的位置构成一个集合，把值 $1, 2, \ldots, x$ 依次按同一个单调栈插入即可得到；$x \gets x+1$ 时只需加入 $\mathrm{pos}[x+1]$ 并弹出其右侧的位置（这些位置从此永远不再回答 `LO`），每个下标至多进出栈一次，总复杂度 $O(N)$。

**观察四**：设 $j$ 为 $i$ 之前最后一次回答 `LO` 的位置（不存在则为 $0$）。则 $i$ 是 `HILO` 中的 `LO` 当且仅当 $\mathrm{prv}[i] \ne 0$，且（$j = 0$ 或 $\mathrm{prv}[i] \ne \mathrm{prv}[j]$）。也就是说：那个 `HI` 必须出现在 $j$ 这个 `LO` 之后。注意对每个 $x$ 只要 $i$ 没被跳过，这个 $j$ 都一样（不同的删减只会让 $i$ 一起消失），并且在单调栈中 $j$ 恰好是弹出后剩余的栈顶。

于是从小到大枚举 $v = x+1$，维护栈与当前答案 `cnt`：弹出时若被弹出的位置曾是 `HILO` 的 `LO` 就减 1，插入 $\mathrm{pos}[v]$ 时按观察四判断并加 1，输出即可。$x=0$ 时全是 `HI`，答案为 $0$。
