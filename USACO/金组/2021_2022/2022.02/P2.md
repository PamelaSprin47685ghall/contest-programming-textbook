# P2　奶牛训练营（Cow Camp）

## 题目

USACOW Open 的最后一题有 $T$ 个测试点（$2 \le T \le 10^3$），等权计分，其中第 1 个是样例点。Bessie 的最终得分等于她**最后一次提交**通过的测试点个数。

她太累了不想思考，于是决定反复提交下面这个随机化的程序：

```text
if input == sample_input:
    print sample_output
else:
    print "yes" or "no" each with probability 1/2, independently for each test case
```

也就是说，样例点必定通过；其余每个测试点无论提交多少次，每次都独立地以 $1/2$ 的概率通过。Bessie 一共最多提交 $K$ 次（$1 \le K \le 10^9$），求她按最优策略行事时最终得分的最大期望值。

## 输入

一行两个整数 $T$ 和 $K$。

## 输出

一个实数，与标准答案的绝对或相对误差不超过 $10^{-6}$ 即可。

## 样例

输入：

```text
2 3
4 2
```

输出：

```text
1.875
2.8750000000000000000
```

第一个样例中应当一直交到满分为止：以 $7/8$ 的概率得 $2$ 分、$1/8$ 的概率得 $1$ 分，期望 $1.875$。第二个样例中只有第一次得分低于 $3$ 时才继续交。

## 思路

**先摘掉样例点。** 样例点必得，所以令 $n = T - 1$，只考虑剩下 $n$ 个随机点，最后把答案加 $1$。一次提交恰好通过 $i$ 个随机点的概率是

$$p_i = \frac{\binom{n}{i}}{2^n}.$$

**DP 结构与策略。** 设 $E_x$ 表示「还剩 $x$ 次提交机会」时的最大期望得分（不含样例那一分），$E_0 = 0$。第一次提交后会看到得分 $i$，此时要么收手拿 $i$ 分，要么继续（期望 $E_x$，其中 $x$ 是剩余次数），所以

$$E_{x+1} = \sum_{i=0}^{n} p_i \cdot \max(i, E_x) = a E_x + b,$$

其中最后一步对 $f = \lfloor E_x \rfloor$ 成立，且

$$a = \sum_{i \le f} p_i \quad (\text{得分不高于 } f \text{ 就继续交}), \qquad b = \sum_{i > f} i\,p_i \quad (\text{得分高于 } f \text{ 就收手}).$$

即：**当前阈值就是 $\lfloor E_x \rfloor$**，一份卷子得分不超过它就继续提交，超过它就停止。

**关键：一次跳过很多次提交。** 只要阈值仍是 $f$，迭代就固定是仿射变换 $E \mapsto aE+b$，它的不动点是

$$\texttt{fix} = \frac{b}{1-a},$$

于是可以直接写出 $q$ 步之后的值：

$$E_{x+q} = \texttt{fix} - a^q\,(\texttt{fix} - E_x).$$

我们只关心「$E$ 首次达到 $f+1$」（阈值变大）发生在第几步：这个步数可以二分（函数关于 $q$ 单调递增，$a < 1$）。$E$ 每越过一个整数阈值才需要重新计算一次 $a, b$，而 $E \le T$，所以阈值最多变大 $T$ 次：总时间 $O(T^2 + T\log K)$。

**实现细节。**

- 概率分布用帕斯卡三角递推：初始 $p_0 = 1$，每加一个随机点就做一次 $p_i \leftarrow (p_i + p_{i-1})/2$。
- 用前缀和 $O(1)$ 查询 $a$ 与 $b$；若 $b = 0$（不可能拿到比 $f$ 更高的分）就直接结束；若 $\texttt{fix} \le f+1$（永远越不过 $f+1$），就用等比级数一次推完剩余次数。
- 二分结束后最多再走一步就会越过阈值；如果剩余次数不够越过，就把剩余次数全部用等比级数推完。
- 精度：标准答案要求 $10^{-6}$ 的误差，但**原题数据把结果保留到 20 位有效数字**，`double` 只有约 16 位有效数字。因此这里用 `__float128`（约 33 位有效数字）做全部运算，并自己输出 20 位有效数字（四舍五入、不足补 0），使输出与官方数据完全一致。

## 复杂度

递推概率分布 $O(T^2)$；之后阈值每变大一次需要 $O(T)$ 求前缀和（实际上 $O(1)$ 查询）加 $O(\log K)$ 的二分与快速幂，阈值最多增大 $T$ 次，故总时间 $O(T^2 + T\log K)$，空间 $O(T)$。
