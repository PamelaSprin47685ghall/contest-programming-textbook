# P2　结对编程（Pair Programming）

## 题目

一个程序是一串指令，指令只有两种：

- $\times d$，其中 $d$ 是 $[0,9]$ 中的一个数字；
- $+s$，其中 $s$ 是变量名，同一个程序内所有变量名互不相同。

程序从 $0$ 开始依次执行，得到的结果是一个表达式。例如 $[\times 3, +x, +y, \times 2, +z]$ 的结果是 $(0\times 3+x+y)\times 2+z = 2x+2y+z$；不同的程序也可能得到同一个表达式，例如 $[+w,\times 0,+y,+x,\times 2,+z,\times 1]$ 同样得到 $2x+2y+z$。

Bessie 和 Elsie 各有一个长度 $N$（$1 \le N \le 2000$）的程序，把它们交错成一个长度 $2N$ 的程序。问执行后能得到多少种不同的表达式，答案对 $10^9+7$ 取模。

## 输入

第一行一个整数 $T$（$1 \le T \le 10$），表示测试数据组数，保证所有测试数据的 $N$ 之和不超过 $2000$。

每组测试数据：

- 第一行一个整数 $N$；
- 第二行 Bessie 的程序，用长度 $N$ 的字符串表示：数字字符 $d$ 表示 $\times d$，字符 `+` 表示一条加法指令；
- 第三行 Elsie 的程序，格式相同。

同一组数据中所有变量名互不相同；变量的具体名字不会影响答案，因此输入不给出。

## 输出

对每组测试数据输出一行一个整数，表示可能得到的不同表达式个数模 $10^9+7$。

## 样例

输入：

```text
4
1
0
1
3
12+
+02
3
0++
++9
4
5+++
+6+1
```

输出：

```text
1
3
9
9
```

第一组中两个交错程序 $[\times 1,\times 0]$ 与 $[\times 0,\times 1]$ 的结果都是 $0$，所以只有 $1$ 种表达式。

## 思路

**第一步：约简程序。**

- $\times 1$ 是恒等指令，直接删掉。
- 读到 $\times 0$ 时，它前面的结果全被清零，所以把它之前的指令全部丢弃。注意 $\times 0$ **本身要保留**，并且看成一条普通的乘法指令：它清零的是"交错之后排在它前面的所有指令"，位置本身影响结果。例如 $[\times 0, +x]$ 单独看与 $[+x]$ 等价，但若在它前面插入别人家的 $+y$，那个 $+y$ 会被清掉，两者就不再等价。
- 剩下的乘法指令都只是"乘一个常数"，语义角色相同，于是统一记成一种类型。这样每个程序都变成只有"乘法"与"加法"两种类型的指令串。

**第二步：什么时候两个交错程序给出同一个表达式。**

结论：当且仅当其中一个交错程序可以通过反复交换"相邻的、类型相同且分别属于 Bessie 和 Elsie 的两条指令"变成另一个（每次交换都不改变最终表达式，因为两条同类型指令作用在不同东西上时可以交换）。于是**不同表达式的个数 = 不含"Elsie 的指令紧挨在 Bessie 同类型指令之前"的交错方案数**：任何含这种相邻对的方案都可以不断交换这对指令，唯一地化成不含它的方案。

**第三步：DP 计数。**

设 $dp[i][j][k]$ 表示"用掉 Bessie 的前 $i$ 条指令、Elsie 的前 $j$ 条指令，最后一条来自 Bessie（$k=0$）或 Elsie（$k=1$）"的规范化方案数。转移只有两条：

- 把 Elsie 的第 $j+1$ 条指令接到末尾：总是允许，因为它不会形成"Elsie 在前、Bessie 同类型在后"的相邻对；
- 把 Bessie 的第 $i+1$ 条指令接到末尾：若上一个状态末尾是 Bessie 的指令（$k=0$）总是允许；若末尾是 Elsie 的第 $j$ 条指令（$k=1$），则要求两者的类型不同。

答案就是 $dp[|A|][|B|][0] + dp[|A|][|B|][1]$，其中 $|A|, |B|$ 是约简后的长度。

**第四步：滚动数组。** $dp[i][j][\cdot]$ 只依赖同一行的左边一格和上一行的同一列，所以按 $i$ 递增、$i$ 内按 $j$ 递增扫描即可，只需保存上一行和当前行，空间从 $O(N^2)$ 降到 $O(N)$。
