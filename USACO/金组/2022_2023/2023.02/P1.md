# P1　等和子数组（Equal Sum Subarrays）

## 题目

农夫约翰给了贝西一个长度为 $N$ 的数组 $a$（$2 \le N \le 500$，$-10^{15} \le a_i \le 10^{15}$），并且保证它的 $\frac{N(N+1)}{2}$ 个连续子段的和两两不同。

对每个下标 $i \in [1, N]$，求出最少需要把 $a_i$ 改变多少，才能使得数组中存在两个不同的连续子段和相等。

## 输入

第一行一个整数 $N$。

第二行 $N$ 个整数 $a_1, a_2, \ldots, a_N$。

## 输出

共 $N$ 行，第 $i$ 行表示 $a_i$ 至少要改变的量。

## 样例

输入：

```text
2
2 -3
```

输出：

```text
2
3
```

对 $i = 1$，把 $a_1$ 减少 $2$ 后 $a_1 + a_2 = a_2$；对 $i = 2$，把 $a_2$ 增加 $3$ 后 $a_1 + a_2 = a_1$。

## 思路

**第一步：修改 $a_i$ 只会影响含有 $i$ 的子段。** 设子段和分别为 $S_1, S_2$。

- 如果两个子段都不含 $i$，它们的和完全不随修改变化，而题目保证初始时没有两个子段和相等，所以永远不可能相等；
- 如果两个子段都含 $i$，它们的和同时增加同一个量，差始终不变，同样不可能相等；
- 只有「一个含 $i$、一个不含 $i$」时，把 $a_i$ 改变 $\pm(S_1 - S_2)$ 就能让两者相等（含 $i$ 的那个子和变化了 $S_1 - S_2$，而不含 $i$ 的那个不变）。

所以答案就是：所有「含 $i$ 的子段」与「不含 $i$ 的子段」之间和的最小绝对差。

**第二步：只需检查排序后相邻的两项。** 把所有 $O(N^2)$ 个子段按和升序排一次序。对某个固定的 $i$，给每个子段打一个标记：是否包含 $i$。设子段 $u$ 含 $i$、子段 $v$ 不含 $i$ 且 $S_u < S_v$ 是全局最接近的一对。在排序后的序列中从 $u$ 走到 $v$，标记必然在某一处从「含 $i$」变成「不含 $i$」，也就是说存在相邻的一对 $(p, q)$ 满足 $S_u \le S_p < S_q \le S_v$ 且标记不同；于是 $S_q - S_p \le S_v - S_u$，相邻的这一对不会比 $(u, v)$ 更差。因此每个 $i$ 的答案等于排序后相邻两项标记不同时它们和之差的最小值。

实现上：对每个 $i$ 扫一遍排序后的子段数组即可，时间是 $O(N^3)$，$N = 500$ 时约为 $6 \times 10^7$ 次简单判断。
