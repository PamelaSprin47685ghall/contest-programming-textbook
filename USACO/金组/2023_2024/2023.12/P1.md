# P1　航班路线（Flight Routes）

## 题目

Bessie 想在 $N$（$2 \le N \le 750$）座城市之间飞行，城市编号 $1 \dots N$。对每一对城市 $(i,j)$ 且 $i<j$，要么存在一条从 $i$ 直飞 $j$ 的航班，要么不存在。

一条从 $a$ 到 $b$（$a<b$）的**飞行路线**是一个序列 $a=c_1<c_2<\dots<c_k=b$（$k\ge 2$），其中每一段 $c_i\to c_{i+1}$ 都是直飞航班。注意 $a\to b$ 的直飞本身也算一条飞行路线（此时 $k=2$）。

现在对每一对 $i<j$ 都给出它们之间飞行路线条数的奇偶性，请你还原出原来有多少对城市之间存在直飞航班。可以证明答案唯一。

## 输入

第一行一个整数 $N$。

接下来 $N-1$ 行，第 $i$ 行有 $N-i$ 个字符（字符间没有空格）。其中第 $j$ 个字符表示从 $i$ 到 $i+j$ 的飞行路线条数的奇偶性，`0` 表示偶数，`1` 表示奇数。

## 输出

一行一个整数，表示存在直飞航班的城市对数。

## 样例

输入：

```text
3
11
1
```

输出：

```text
2
```

城市 $1\to2$ 与 $2\to3$ 有直飞，因此 $1\to2$、$2\to3$ 各有一条飞行路线，$1\to3$ 有一条路线 $1\to2\to3$，奇偶性与输入一致。

## 思路

设 `routes[i][j]` 为输入给出的奇偶性，`directFrom[j][i]` 表示 $i\to j$ 是否存在直飞。关键观察：从 $i$ 到 $j$ 的飞行路线，按**最后一条直飞的起点** $k$（$i\le k<j$）分类，就得到

$$\text{routes}[i][j]\equiv \text{directFrom}[j][i]\oplus\bigoplus_{k=i}^{j-1}\Big(\text{routes}[i][k]\ \&\ \text{directFrom}[j][k]\Big)\pmod 2 .$$

式子左边是题面给的奇偶性，右边的求和项只用到了「更短的区间」：$\text{routes}[i][k]$ 直接来自输入，$\text{directFrom}[j][k]$ 涉及区间 $(k,j)$，比 $(i,j)$ 窄。于是只要按左端点 $i$ 从大到小、右端点 $j$ 从小到大的顺序处理，判断 $(i,j)$ 时右边 $\oplus$ 里的每一项都已经算出来了，可以直接解出

$$\text{directFrom}[j][i]=\text{routes}[i][j]\oplus\bigoplus_{k=i}^{j-1}\Big(\text{routes}[i][k]\ \&\ \text{directFrom}[j][k]\Big).$$

（$k=i$ 这一项里的 `routes[i][i]` 恒为 0，所以循环从 $k=i$ 开始不会带入多余项。）

直飞的条数就是所有解出的 `directFrom` 之和。为了不让内层循环按列跨行访问内存，代码把 `directFrom` 转置成 `directFrom[终点][起点]` 存放，这样两项都沿着一行连续取数。
