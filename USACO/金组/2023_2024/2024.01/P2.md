# P2　奶牛竞争力（Cowmpetency）

## 题目

Farmer John 面试了 $N$（$2 \le N \le 10^9$）头奶牛，并为每头奶牛打了一个 $1$ 到 $C$（$1 \le C \le 10^4$）之间的「竞争力」分数。他已经把所有分数忘光了，但还记得 $Q$（$1 \le Q \le \min(N-1, 100)$）条形如「第 $h_i$ 头奶牛是奶牛 $1 \dots a_i$ 中**第一头**分数严格更大的奶牛」的信息（$1 \le a_i < h_i \le N$，所有 $a_i$ 互不相同）。

请统计有多少种分数序列与这些信息相符，答案对 $10^9 + 7$ 取模。保证至少存在一种相符的序列。

## 输入

第一行三个整数 $N, Q, C$。

接下来 $Q$ 行，每行两个整数 $a_i, h_i$。

## 输出

一行一个整数，表示相符的分数序列个数对 $10^9 + 7$ 取模的结果。

## 样例

输入：

```text
6 2 3
2 3
4 5
```

输出：

```text
6
```

这六种序列分别是 $1\,1\,2\,1\,3\,x$ 与 $1\,1\,2\,2\,3\,x$（$x = 1,2,3$）：分数 $2$ 必须大于前两者的最大值（因此 $c_1 = c_2 = 1$ 且 $c_3 = 2$），同理 $c_4 \le 2$、$c_5 = 3$，而最后一头奶牛不受任何约束。

## 思路

**约束的等价形式。** 记 $c_i$ 为第 $i$ 头奶牛的分数。信息 $(a, h)$ 的意思是：$c_h$ 严格大于 $\max_{k \le a} c_k$，而在 $a$ 与 $h$ 之间的奶牛都没有超过这个前缀最大值，即

$$\max_{a < k < h} c_k \le \max_{k \le a} c_k < c_h .$$

**去掉冗余约束。** 若两条约束有相同的 $h$，比如 $a_1 < a_2$、$h_1 = h_2 = h$，那么约束 $1$ 更强：它要求下标 $a_2$ 也在受限制的区间 $(a_1, h)$ 里，因此 $\max_{k \le a_2} c_k = \max_{k \le a_1} c_k$，于是约束 $1$ 蕴含约束 $2$。所以每个 $h$ 只留 $a$ 最小的那一条。又因为题目保证存在合法序列，不同 $h$ 的区间 $[a, h-1]$ 两两不相交，因此按 $a$ 排序后

$$a_1 < h_1 \le a_2 < h_2 \le \dots \le a_m < h_m ,$$

可以一段一段地处理。

**按约束做 DP。** 设 $dp_i[j]$ 表示「满足前 $i$ 条约束、且 $c_{h_i} = j$」（等价于前 $h_i$ 个位置的最大值为 $j$）的方案数。从 $dp_{i-1}[k]$ 转移时：区间 $(h_{i-1}, a_i]$ 里的 $u = a_i - h_{i-1}$ 个位置完全自由，而 $h_i$ 之前的 $w = h_i - a_i - 1$ 个位置都必须不超过 $S = \max_{k \le a_i} c_k$。于是按自由位置的取值分类：

- 若这 $u$ 个位置的值都不超过 $k$，则 $S = k$，方案数为 $k^{u} \cdot k^{w}$（受限制的位置每个都有 $k$ 种取法）；
- 若其中的最大值恰好为 $t > k$，则这样的填法有 $t^{u} - (t - 1)^{u}$ 种，受限制的位置各要 $\le t$，贡献再乘 $t^{w}$。

综合起来

$$dp_i[j] = \sum_{k < j} dp_{i-1}[k]\cdot k^{u+w} \;+\; \sum_{t < j}\Bigl(t^{u} - (t-1)^{u}\Bigr)\, t^{w} \sum_{k < t} dp_{i-1}[k] .$$

两个和式都可以随着 $j$ 从 $1$ 递增到 $C$ 用累加变量 $O(1)$ 维护（第二个和式内部是 $dp_{i-1}$ 的前缀和），幂用快速幂计算。最后一条约束之后仍有 $N - h_m$ 个位置完全自由，答案再乘上 $C^{\,N - h_m}$。
