# P1　贝斯拉汽车（Bessla Motors）

## 题目

Farmer John 有 $N$（$2 \le N \le 5 \cdot 10^4$）个兴趣点，编号 $1 \dots N$，其中前 $C$（$1 \le C < N$）个是充电站，其余是旅行目的地。这些点之间有 $M$（$1 \le M \le 10^5$）条双向道路，第 $i$ 条连接 $u_i$ 与 $v_i$，长度为 $\ell_i$（$1 \le \ell_i \le 10^9$）英里。

一辆贝斯拉汽车一次充电最多行驶 $2R$ 英里，因此它可以到达距离某个充电站 $R$ 英里以内的任意目的地。如果一个目的地能够从至少 $K$（$1 \le K \le 10$）个不同的充电站到达，就称它是**连接良好**的。

请找出所有连接良好的旅行目的地。

## 输入

第一行五个整数 $N, M, C, R, K$。

接下来 $M$ 行，每行三个整数 $u_i, v_i, \ell_i$（$u_i \ne v_i$）。充电站的编号是 $1, 2, \dots, C$，其余点都是旅行目的地。

## 输出

第一行输出连接良好的旅行目的地个数。接下来按从小到大的顺序，每个这样的目的地占一行。

## 样例

输入：

```text
3 3 1 4 1
1 2 3
1 3 5
2 3 2
```

输出：

```text
1
2
```

只有一个充电站 $1$。点 $2$ 到 $1$ 的距离是 $3 \le 4$，可以被到达；点 $3$ 到 $1$ 的距离是 $5 > 4$，不能被到达。所以只有点 $2$ 是连接良好的。

## 思路

把道路看成带权无向图，问题是：对每个目的地，统计距离它不超过 $R$ 的充电站个数是否达到 $K$。

朴素做法是对每个充电站跑一次单源 Dijkstra，但 $C$ 可以很大。注意到我们其实不关心一个点究竟被多少个充电站访问过，只关心**前 $K$ 个**（$K \le 10$）。于是可以同时跑 $C$ 趟 Dijkstra：优先队列里存放三元组 `(到该点的距离, 点, 出发的充电站 root)`，出队顺序就是所有「(点, 充电站) 对」按距离的全局顺序，等价于 $C$ 趟 Dijkstra 交错执行。每个点最多被 $K$ 个不同的充电站访问，之后再访问到它就直接丢弃。

为什么能这样砍掉多余的访问？设点 $u$ 已经被 $K$ 个充电站访问过（记这些距离为 $d_1 \le d_2 \le \dots \le d_K$），此时又有一个充电站 $r$ 想到达 $u$，其距离 $d_r \ge d_K$（因为它在堆里排在后面）。若从 $r$ 出发经 $u$ 中转能到达目的地 $v$，则有 $d_K + \mathrm{dist}(u,v) \le d_r + \mathrm{dist}(u,v) \le R$，说明前面那 $K$ 个充电站也都能在 $R$ 内到达 $v$，$v$ 的计数不会因此变少。所以每个点保留前 $K$ 次访问就够了。

还有两个细节：一是同一个充电站可能通过两条不同的路到达同一点，必须记录「访问过该点的是哪些充电站」来去重，否则会把同一站数成两次（代码里 `visitorList` 存下最多 $K$ 个 root，线性查重）；二是扩展邻居时只要 $d + \ell > R$ 就不要入队，并且邻居已经访问过 $K$ 次也不要入队，这样每个点入堆次数是 $O(K \deg)$ 级别。

## 复杂度

每个点最多出队 $K$ 次，每条边最多被松弛 $2K$ 次，堆中元素个数为 $O(KM)$，因此时间复杂度为 $O(KM \log(KM))$；去重是 $O(K)$ 的线性查找，不改变阶。空间复杂度为 $O(N + M + NK)$。
