# P2　草地线段（Grass Segments）

## 题目

Bessie 要在正实数轴上种草。她有 $N$（$2 \le N \le 2\cdot 10^5$）个不同的草品种，第 $i$ 个品种种在区间 $[\ell_i, r_i]$ 上（$0 < \ell_i < r_i \le 10^9$）。

此外，如果存在另一个品种 $j$（$j\ne i$）与品种 $i$ 的重叠长度至少为 $k_i$（$0 < k_i \le r_i - \ell_i$），那么品种 $i$ 会长得更好。Bessie 想评估所有品种：对每个 $i$，求出满足上述条件的 $j\ne i$ 的个数。

## 输入

- 第一行：一个整数 $N$。
- 接下来 $N$ 行：每行三个整数 $\ell_i$、$r_i$、$k_i$。

## 输出

共 $N$ 行，第 $i$ 行为品种 $i$ 的答案。

## 样例

输入：

```text
2
3 6 3
4 7 2
```

输出：

```text
0
1
```

两个区间的重叠部分是 $[4,6]$，长度为 $2$，不小于 $2$ 但小于 $3$。

输入：

```text
4
3 6 1
2 5 1
4 10 1
1 4 1
```

输出：

```text
3
3
2
2
```

输入：

```text
5
8 10 2
4 9 2
3 7 4
5 7 1
2 7 1
```

输出：

```text
0
3
1
3
3
```

## 思路

两个区间的重叠长度为 $\min(r_i,r_j)-\max(\ell_i,\ell_j)$，要求它 $\ge k_i$，即 $\min(r_i,r_j)\ge \max(\ell_i,\ell_j)+k_i$；把两边的 $\min$、$\max$ 展开（并利用题目保证的 $r_i-\ell_i\ge k_i$），等价于三个条件同时成立：

$$r_i-\ell_j \ge k_i,\qquad r_j-\ell_i \ge k_i,\qquad r_j-\ell_j \ge k_i .$$

（前两条即 $\min(r_i,r_j)\ge \max(\ell_i,\ell_j)+k_i$；把每条里"自己的量"都挪到同一边、用 $r_j\ge \ell_j+k_i$ 展开，就得到左边三式。）换句话说，对固定的 $i$，满足条件的 $j$ 恰好是：

1. 长度 $r_j-\ell_j \ge k_i$ 的区间；
2. 再减去右端点 $r_j < \ell_i+k_i$ 的（它们整体位于 $[\ell_i,\ell_i+k_i)$ 左边，重叠不足）；
3. 再减去左端点 $\ell_j > r_i-k_i$ 的（它们整体位于 $(r_i-k_i, r_i]$ 右边，重叠不足）。

关键在于第 2、3 两类不可能同时出现：若同时有 $r_j < \ell_i+k_i$ 且 $\ell_j > r_i-k_i$，则 $r_j-\ell_j < (\ell_i+k_i)-(r_i-k_i) = 2k_i-(\text{len}_i) \le k_i$，与条件 1 矛盾。因此不存在被重复减去的区间，直接做减法即可（$j=i$ 自己一定落在条件 1 里，最后减掉 1）。

实现上把所有询问按 $k$ 从大到小处理：随着 $k$ 减小，把长度 $\ge k$ 的区间不断插入两棵树状数组（分别按右端点、左端点计数）。询问"已插入区间中右端点 $\le x$ 的个数"就是树状数组前缀和，$x$ 的位置通过对压缩后的坐标数组二分得到。因为每个区间只会被插入一次，总复杂度 $O(N\log N)$。
