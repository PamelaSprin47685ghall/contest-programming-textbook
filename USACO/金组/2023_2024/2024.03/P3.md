# P3　更小的平均数（Smaller Averages）

## 题目

Bessie 有两个长度为 $N$（$1 \le N \le 500$）的数组。第一个数组的第 $i$ 个元素是 $a_i$（$1 \le a_i \le 10^6$），第二个数组的第 $i$ 个元素是 $b_i$（$1 \le b_i \le 10^6$）。

Bessie 想把两个数组都划分成非空子数组，使得：

- 每个元素恰好属于一个子数组；
- 两个数组被划分成相同数量的子数组，设个数为 $k$；
- 对所有 $1 \le i \le k$，第一个数组从左数第 $i$ 个子数组的平均数**小于等于**第二个数组从左数第 $i$ 个子数组的平均数。

求满足条件的划分方案数（模 $10^9+7$）。两个方案不同，当且仅当子数组个数不同，或某个元素所属的子数组不同。

## 输入

- 第一行：一个整数 $N$。
- 第二行：$a_1, a_2, \dots, a_N$。
- 第三行：$b_1, b_2, \dots, b_N$。

## 输出

一个整数：合法划分方案数模 $10^9+7$。

## 样例

输入：

```text
2
1 2
2 2
```

输出：

```text
2
```

两种合法方案：第一个数组分成 $[1],[2]$、第二个分成 $[2],[2]$；以及第一个数组分成 $[1,2]$、第二个分成 $[2,2]$。

输入：

```text
3
1 3 2
2 2 2
```

输出：

```text
3
```

三种合法方案：第一个数组分成 $[1,3],[2]$，第二个分成 $[2,2],[2]$；第一个数组分成 $[1,3],[2]$，第二个分成 $[2],[2,2]$；以及两个数组都只分成一整段 $[1,3,2]$ 与 $[2,2,2]$。

输入：

```text
5
2 5 1 3 2
2 1 5 2 2
```

输出：

```text
1
```

唯一合法方案：第一个数组分成 $[2],[5,1,3],[2]$，第二个分成 $[2],[1,5],[2,2]$。

输入：

```text
7
3 5 2 3 4 4 1
5 3 5 3 3 4 1
```

输出：

```text
140
```

## 思路

设 $P_a$、$P_b$ 为两个数组的前缀和，$dp[i][j]$ 表示把第一个数组的前 $i$ 个元素、第二个数组的前 $j$ 个元素划分成同样多段的合法方案数。最后一段的划分点分别是 $i'$ 和 $j'$，要求

$$\frac{P_a[i]-P_a[i']}{i-i'} \le \frac{P_b[j]-P_b[j']}{j-j'},$$

于是

$$dp[i][j]=\sum_{\substack{0\le i'<i,\ 0\le j'<j\\ \text{上式成立}}} dp[i'][j'].$$

朴素转移是 $O(N^4)$。优化的想法是"按行看"：固定 $i$ 时，把 $i$ 上方的所有行 $i'$ 按分数 $\frac{P_a[i]-P_a[i']}{i-i'}$ 升序排序。对某个 $j'$，满足条件的所有 $i'$ 恰好是排序后的一段**前缀**（因为不等式左边随序递增），所以只要对每个 $j'$ 求出前缀长度 $r(j')$，答案就是该列的列前缀和。

由于 $dp[i'][j']$ 对 $i'$ 的求和可以用"排序后按行做的列前缀和" $psm[r][c]$ 表示（$psm[r][c]$ 是排序前 $r+1$ 行在第 $c$ 列的 $dp$ 之和），拿到 $r$ 之后 $O(1)$ 就能得到这一段的和。

为了免去二分，再观察：当 $j$ 固定、把 $j'$ 按分数 $\frac{P_b[j]-P_b[j']}{j-j'}$ **升序**枚举时，阈值单调递增，$r(j')$ 也随之单调不减，于是用双指针扫描即可，每个 $r$ 在一个 $(i,j)$ 里最多增加 $i$ 次。所有"以某点为右端点的按平均排序"都可以预先算好（对每个 $i$ 排一次，共 $O(N^2\log N)$），于是总复杂度降到 $O(N^3)$：排序 $O(N^2\log N)$，前缀和构建 $O(N^3)$，转移里的双指针 $O(N^3)$。

分数比较全部用交叉相乘（`long long`）完成，避免浮点误差。
