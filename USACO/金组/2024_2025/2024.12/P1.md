# P1　奶牛的相依（Cowdependence）

## 题目

农夫约翰的 $N$（$1 \le N \le 10^5$）头奶牛排成一排，第 $i$ 头牛的标签是 $a_i$（$1 \le a_i \le N$）。一组奶牛能组成一个**友谊组**，当且仅当它们标签全部相同，且组内任意两头牛的位置之差不超过 $x$，其中 $x$ 是 $[1, N]$ 里的整数。每头牛必须恰好属于一个友谊组。

对每个 $x = 1, 2, \dots, N$，求友谊组数量可能的最小值。

## 输入

第一行一个整数 $N$。

第二行 $N$ 个整数 $a_1, \dots, a_N$。

## 输出

输出 $N$ 行，第 $x$ 行是 $x$ 对应的最小友谊组数。

## 样例

输入：

```text
9
1 1 1 9 2 1 2 1 1
```

输出：

```text
7
5
4
4
4
4
4
3
3
```

## 思路

标签不同的奶牛永远不会同组，所以每个标签可以各自独立地算组数，再把各标签在同一个 $x$ 下的组数相加。

固定一个标签 $L$，把它出现的位置按递增排成
$b_1 < b_2 < \dots < b_k$。在给定的 $x$ 下，一个组就是这个序列里的一段连续下标
$b_l, \dots, b_r$，只要 $b_r - b_l \le x$（这样组内任意两头牛的距离都不超过 $x$；注意"最远的一对"就是两端）。于是"最少组数"就是用贪心把序列切成尽量少的段：从 $b_1$ 开始，把第一个与段首距离超过 $x$ 的位置作为下一段的段首。贪心是对的，因为段首这头牛必然落在某一组里，而最靠左的那个组只有尽量向右多塞，留给后面的牛才最少。

直接对每个标签、每个 $x$ 都跑一遍贪心是 $O(N^2)$。题目的三档部分分提示了两条互补的算法：

- **标签出现次数多（"大标签"）**：预处理一个数组 $\text{next}$，$\text{next}[i]$ 表示 $i$ 处及之后第一个标签为 $L$ 的位置。从当前组的段首出发，下一组的段首就是 $\text{next}[\text{段首} + x + 1]$。每次跳跃至少前进 $x + 1$，所以单个 $x$ 只要 $O(N/x)$ 步，把所有 $x$ 合起来是 $O(N \log N)$（调和级数）。
- **标签出现次数少（"小标签"）**：组数 $g(x)$ 随 $x$ 单调不升，而且 "$g(x) \ge m$" 的那些 $x$ 恰好构成一段前缀。对每个 $m = 1, 2, \dots, k$ 二分出这段前缀的右端点 $lo_m$（在标签自己的坐标列表上做一次 $O(k)$ 的贪心判断），再用差分把"这个标签给 $x \in [1, lo_m]$ 各贡献一组"记下来；对 $m$ 求和，累加到第 $x$ 位就是该标签在 $x$ 下的组数（因为 $g(x)$ 恰好等于满足 $g(x) \ge m$ 的 $m$ 的个数）。

阈值取 $\sqrt N$：出现次数超过 $\sqrt N$ 的标签最多 $N/\sqrt N = \sqrt N$ 个，每个用 $O(N \log N)$ 的大标签算法，合计 $O(N\sqrt N \log N)$；出现次数不超过 $\sqrt N$ 的标签，每个是 $O(k^2 \log N) = O(k \cdot \sqrt N \log N)$，把所有标签的 $k$ 加起来是 $N$，合计同样是 $O(N\sqrt N \log N)$。两侧用同一条阈值互相制约，就是这个数量级。

实现上还有两点细节：

- 同标签的坐标不需要开 $N$ 个动态数组，用一条 `nextSame` 链表把同标签的牛按位置递增串起来即可；需要时顺着链表走一遍就得到递增的坐标序列。
- 小标签的二分上界可以压到上一轮的 $lo + 1$ 上（组数要求越多，需要的 $x$ 越小），这样每轮二分区间很小。
