# P3　完成工作（Job Completion）

## 题目

贝西有 $N$（$1 \le N \le 2 \cdot 10^5$）件工作。第 $i$ 件如果选择去做，就必须在时刻 $s_i$ 或之前开始，并且需要 $t_i$ 时间才能做完（$0 \le s_i \le 10^{18}$，$1 \le t_i \le 10^{18}$）。请问最多能完成多少件工作？

时间从 $0$ 开始，并且一旦开始一件工作，就必须做到底，中途不能开始别的工作。

## 输入

第一行一个整数 $T$（$1 \le T \le 10$），表示独立的测试用例数。

每个测试用例的第一行是 $N$，接下来 $N$ 行每行两个整数 $s_i$ 和 $t_i$。

保证所有测试用例的 $N$ 之和不超过 $3 \cdot 10^5$。

## 输出

每个测试用例输出一行，表示最多能完成的工作件数。

## 样例

输入：

```text
3
2
1 4
1 2
2
2 3
1 2
3
1 4
2 3
1 2
```

输出：

```text
1
2
2
```

## 思路

记 $d_i = s_i + t_i$，它的含义是"这件工作最迟必须在时刻 $d_i$ 做完"（开始时间加上自己的用时）。

**先看判定问题：能不能把所有工作都做完。** 把一个工作集合按 $d$ 递增排列，判断标准是：对每个前缀，用时之和不超过该前缀最后一件工作的 $d$。必要性显然（一件件连着做，做到第 $j$ 件时已经花了前缀之和，而它必须在 $d_j$ 前做完）。充分性用交换论证：假设相邻两件 $a$ 做完后紧接着做 $b$，而 $d_a \ge d_b$，设 $a$ 的开始时刻是 $T$。由 $b$ 不超时得 $T + t_a \le s_b$，即 $T \le s_b - t_a$；交换它们之后需要 $T \le s_b$（更松，显然成立）和 $T + t_b \le s_a$，而

$$s_b - t_a \le s_a - t_b \iff s_b + t_b \le s_a + t_a \iff d_b \le d_a,$$

恰好是假设的条件。所以反复交换相邻逆序对，就能把任何可行方案整理成按 $d$ 递增的顺序，充分性得证。

**原问题。** $d$ 的顺序既是判定问题的关键，也是本题的关键：按 $d$ 递增依次处理每件工作，用一个大根堆维护"当前打算做的工作"的用时。加入第 $i$ 件后，如果堆里所有工作的用时之和超过了 $d_i$，就丢掉堆里用时最长的那一件，堆的大小就是这组数据的答案。

（实现细节：删除前用时之和至多为 $d_i + t_i \le 2 \times 10^{18} + 10^{18}$，用 `long long` 保存不会溢出。）

为什么丢掉最长的那件是安全的？

- **删一次就够**：设加入前总和为 $S$。由于上一轮结束时 $S \le d_{i-1} \le d_i$，加入 $t_i$ 后总和为 $S + t_i$，而堆顶（最长的那件）的用时 $\max \ge t_i$，删完后总和为 $S + t_i - \max \le S \le d_i$，不需要反复删。
- **不丢最优性**：维护的集合 $S_i$ 有一个不变量——存在一个大小等于 $|S_i|$ 的最优解，它只从 $S_i \cup \{i+1, \dots, N\}$ 中取工作。设这一步删掉的是用时最长的 $j$。若某个最优解 $s$ 用到了 $j$，那么 $s$ 不可能用上 $S_i \cup \{j\} = S_{i-1} \cup \{i\}$ 的全部工作——它们一起超过了 $d_i$，按上面的判定标准不可能全部做完；于是 $S_i$ 中至少有一件工作 $x \notin s$，把 $s$ 里的 $j$ 换成 $x$：大小不变，用时不会变多（$j$ 是集合里最长的，$t_x \le t_j$），而 $s$ 中下标不超过 $i$ 的工作现在都是 $S_i$ 的子集（$S_i$ 本身满足判定标准，可以一起做完），下标大于 $i$ 的工作开始时间只会提前，所以换完仍然可行。不变量保持。
