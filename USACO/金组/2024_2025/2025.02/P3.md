# P3　友谊编辑（Friendship Editing）

## 题目

农夫约翰的 $N$ 头奶牛标号为 $1$ 到 $N$（$2 \le N \le 16$），奶牛之间的友谊可以用一张无向图表示，$M$ 条边（$0 \le M \le N(N-1)/2$）：两头奶牛是朋友当且仅当它们之间有一条边。

一次操作可以添加或删除图中的一条边。求最少需要多少次操作，才能让图满足如下性质：如果奶牛 $a$ 和 $b$ 是朋友，那么对任意其他奶牛 $c$，$a$ 与 $c$、$b$ 与 $c$ 中至少有一对是朋友。

## 输入

- 第 1 行：两个整数 $N$ 和 $M$。
- 接下来 $M$ 行：每行两个整数 $a, b$（$1 \le a < b \le N$），表示一对朋友。同一对朋友不会出现两次。

## 输出

一行，一个整数：需要添加或删除的边数。

## 样例

输入：

```text
3 1
1 2
```

输出：

```text
1
```

此时 $(1,2)$ 是唯一边，而奶牛 3 与 1、2 都不是朋友，违反性质。加上边 $(1,3)$ 或 $(2,3)$（或删掉 $(1,2)$）都能修正，所以答案是 1。

## 思路

**性质在补图上的含义。** 把条件写成逆否命题：若 $a$ 与 $c$、$b$ 与 $c$ 都不是朋友，则 $a$ 与 $b$ 也不是朋友。也就是说，在补图中若 $(a,b)$ 与 $(b,c)$ 都是边，则 $(a,c)$ 也必须是边——补图上的"相邻"具有传递性。于是补图的每个连通块都必须是团，反过来只要补图是若干个互不相交的团，性质就成立。等价地：**最终图必须是一个完全多部图**（同部之间没有边，不同部之间全是边）。

**按部划分做子集 DP。** 于是问题变成把点集划分成若干个部，代价为

$$\text{(部内原有的边数，需要删除)} + \text{(部内原有的非边数，需要补上)}.$$

设总点对数 $P = N(N-1)/2$、原边数 $M$。因为所有部内部的两两点数之和恒等于 $P$ 减去跨部点对数，逐部累加可以化简成：

$$\text{总非边数 } (P-M) \;+\; \sum_{\text{部}} \Big(\text{部内原有边数} - \text{部内原有非边数}\Big).$$

其中每部的权值 $groupCost[mask] = \sum_{i<j \in mask} \big([(i,j)\text{ 是原边}] ? +1 : -1\big)$ 用最低位递推预处理：$groupCost[mask] = groupCost[mask \setminus \{i\}] + \sum_{j \in mask \setminus \{i\}} \pm 1$。

然后 $dp[mask]$ 表示把 $mask$ 划分成若干部后 $\sum groupCost$ 的最小值，转移时枚举包含 $mask$ 最低位的那个部（这样每种划分恰好被统计一次，省掉一半枚举量）：

$$dp[mask] = \min_{\emptyset \ne sub \subseteq mask,\; sub \ni \text{lowbit}(mask)} \Big( dp[mask \setminus sub] + groupCost[sub] \Big), \qquad dp[0] = 0.$$

答案就是 $(P-M) + dp[(1 \ll N) - 1]$。

## 复杂度

预处理每部权值 $O(2^N \cdot N)$，子集 DP 枚举含最低位的子集为 $O(3^N)$ 的一半量级，空间 $O(2^N)$。
