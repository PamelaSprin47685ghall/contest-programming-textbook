# P1　哞的分解（Moo Decomposition）

## 题目

给定一个只由 `M` 和 `O` 组成的长字符串 $S$，以及整数 $K \ge 1$。求把 $S$ 划分成若干子序列（每个字符恰好属于一个子序列），使每个子序列都形如 `M` 后紧跟恰好 $K$ 个 `O` 的方案数，对 $10^9+7$ 取模。

$S$ 太长不能直接给出，而是以压缩形式给出：给定 $L$（$1 \le L \le 10^{18}$）和长度为 $N$（$1 \le N \le 10^6$）的字符串 $T$，$S$ 是 $L$ 个 $T$ 首尾拼接而成。保证方案数非零，于是每段里 `O` 的个数恰好是 `M` 个数的 $K$ 倍。

## 输入

- 第 1 行：三个整数 $K$、$N$、$L$。
- 第 2 行：长度为 $N$ 的字符串 $T$，每个字符是 `M` 或 `O`。

## 输出

一行，一个整数：划分方案数对 $10^9+7$ 取模的结果。

## 样例

输入：

```text
2 6 1
MOOMOO
```

输出：

```text
1
```

唯一方案是让前三个字符组成一个 `MOO`、后三个字符组成另一个 `MOO`。

## 思路

**为什么正着做 DP 不行。** 从左往右扫时，每个已经出现的 `M` 处于"已经分到 $0 \sim K$ 个 `O`"中的哪一种状态是不确定的，而后续的计数又依赖于这个分布的直方图，状态会爆炸。

**倒着做。** 从后往前扫，每个 `O` 只有两种状态：已经分配给某个 `M`，或者"待用"。设 $V_i$ 表示后 $i$ 个字符的划分数，其中每个子序列都恰好含 $K$ 个 `O`，剩下的"待用 `O`"单独留出来。转移时：

- 倒数第 $i+1$ 个字符是 `O`：它只能进入待用集合，$V_{i+1}=V_i$；
- 倒数第 $i+1$ 个字符是 `M`：它必须从待用 `O` 里挑恰好 $K$ 个，$V_{i+1}=\binom{O_i-KM_i}{K}V_i$，其中 $O_i,M_i$ 是后 $i$ 个字符中 `O`、`M` 的个数。

关键就在这里：待用 `O` 的个数恒等于 $O_i-KM_i$，与具体怎么划分无关，所以状态里只需要这一个数，不需要记录每个 `M` 的进度。

**改成从前往后扫描。** 维护 `req` = "当前后缀（含当前位置）的 `O` 数减去 $K$ 倍的 `M` 数"。扫到 `M` 时，`req + K` 恰好是它右边那一段后缀的 $O-KM$，于是乘上 $\binom{req+K}{K}$ 后令 `req += K`；扫到 `O` 时 `req--`。这样一次线性扫描即可得到单段 $T$ 的答案。

**多段拼接。** 任何子序列都不会跨过两段 $T$ 的边界：先看最后一段，它的 `M` 只能靠这段里的 `O` 满足，需要恰好 $O_L=K\cdot M_L$ 个；若某个更早段的 `M` 用掉了这段里的一个 `O`，这段的 `M` 就不够用了，矛盾。把最后一段挖掉后对倒数第二段重复同样的论证，归纳可得 $S$ 的划分数正是每段划分数之积，即为单段答案的 $L$ 次方。

组合数用预处理阶乘 + 费马小定理求逆元（快速幂）得到；$L$ 次方同样用快速幂。
