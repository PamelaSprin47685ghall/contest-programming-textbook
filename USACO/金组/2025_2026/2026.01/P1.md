# P1　COW 遍历（COW Traversals）

## 题目

农场上有 $N$ 头奶牛（$1 \le N \le 2 \cdot 10^5$），第 $i$ 头奶牛住在自己的牛棚里，它最好的朋友是 $a_i$（$1 \le a_i \le N$；奶牛可以和自己做最好的朋友，也可以多头奶牛拥有同一个最好的朋友）。

奶牛们要连开 $M$ 晚（$1 \le M \le 2 \cdot 10^5$）派对。第 $i$ 晚，奶牛 $c_i$ 会在自己的牛棚里办一场类型为 $t_i$ 的派对，$t_i \in \{\texttt{C},\texttt{O},\texttt{W}\}$。这场派对会一直存在，直到奶牛 $c_i$ 改办一场不同类型的派对为止。

每一晚，每头奶牛都会去找派对：如果它自己没在办派对，就先去自己最好的朋友的牛棚看；那里也没有派对的话，它就跟着最好的朋友走（最好的朋友可能也在跟着别人走，依此类推）。有可能一头奶牛永远找不到派对，只能放弃这一晚。

求每一晚最终到达 C、O、W 三种类型派对的奶牛数量分别是多少。

## 输入

- 第 1 行：一个整数 $N$。
- 第 2 行：$N$ 个整数 $a_1, \dots, a_N$。
- 第 3 行：一个整数 $M$。
- 接下来 $M$ 行：每行一个整数 $c_i$ 和一个字符 $v_i$，表示这一晚办派对的奶牛和派对类型。

## 输出

共 $M$ 行，第 $i$ 行是 3 个用空格分隔的整数：第 $i$ 晚到达类型 C、O、W 的派对的奶牛数。

## 样例

输入：

```text
5
2 3 4 5 4
4
2 C
4 C
4 W
2 O
```

输出：

```text
2 0 0
5 0 0
2 0 3
0 2 3
```

第 1 晚只有奶牛 $2$ 的牛棚里有 C 型派对，奶牛 $1$ 会跟着最好的朋友 $2$ 过去，所以只有 $1,2$ 两头奶牛到场。第 2 晚奶牛 $4$ 也办起 C 型派对，奶牛 $3,5$ 顺着最好的朋友链走到 $4$，于是共有 $3,4,5$ 加 $1,2$ 这五头奶牛。第 3 晚奶牛 $4$ 的派对换成 W 型，第 4 晚奶牛 $2$ 的派对换成 O 型，结果依次如上。

## 思路

**把"跟朋友走"看成有向边。** 每头办着派对的奶牛就是一个"根"，其余奶牛沿着 $i \to a_i$ 走，最终要么走到某个根，要么绕进一个不含任何根的环而放弃这一晚。所以只要求出每个根所吸引的奶牛数，按类型累加即可。

**正难则反。** 正序看，新办一场派对会把原来的一棵树劈成两棵，劈开很难维护。于是把所有询问离线、**倒序**处理：从"所有派对都已存在"的最后一晚出发，倒着撤销询问，此时只会出现"两棵树合并"，正好可以用并查集维护。

- 初始状态（最后一晚）：奶牛 $i$ 有派对当且仅当它至少开过一次派对，类型是它最后一次开的类型。把所有没开派对的奶牛 $i$ 与 $a_i$ 并起来，每个连通块就是以某个派对为根的树（也可能是不含派对的环状结构），块的 $size$ 就是这场派对吸引到的奶牛数。
- 倒序撤销第 $k$ 个询问（发生在奶牛 $c$ 身上）：此时 $c$ 还开着类型 $v_k$ 的派对，投奔它的奶牛恰好是整个连通块，于是把 $size$ 从 $v_k$ 这一栏减掉。
  - 如果 $c$ 之前还开过派对，说明只是"类型回退"，把同样的 $size$ 加回上一种类型即可。
  - 如果 $c$ 之前没开过派对，这场派对就彻底消失：$c$ 变成普通奶牛并指向 $a_c$，把它所在的块与 $a_c$ 所在的块合并；若合并后的块里还有派对根 $r$（用并查集额外维护"块里的派对点"），这 $size$ 头奶牛就改投奔 $r$ 的派对。

**几个容易写错的地方。** 其一，合并时"派对点"只可能在被指向（父亲）那一侧，而按秩合并会交换两个参数，所以必须在交换之前把父亲一侧的派对点存下来。其二，读入 $c_i$ 与字符时格式串要写成 `scanf("%d %c", ...)`，前面那个空格才能吃掉行内空白、不把换行当字符读进来，这样也完全不需要 `iostream`。其三，每头奶牛"当前最近一次未撤销的询问"要用 `curQ` 动态维护，撤销时同步后退，否则会读到已经被撤销掉的旧类型。

## 复杂度

每条边只会被合并一次，并查集带路径压缩，单次询问的均摊代价为 $O(\alpha(N))$；总时间复杂度 $O((N+M)\alpha(N))$，空间复杂度 $O(N+M)$。
