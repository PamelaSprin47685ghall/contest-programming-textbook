# P2　牛奶桶（Milk Buckets）

## 题目

贝茜向农夫约翰下战书，要比一场关于牛奶桶的游戏。一排有 $N$ 个牛奶桶（$2 \le N \le 2 \cdot 10^5$），第 $i$ 个桶里原本装着 $a_i$ 加仑牛奶（$0 \le a_i \le 10^9$）。

游戏分两个阶段：

- 阶段 1：农夫约翰可以任意次交换相邻的两个桶，每交换一次花费 1 枚金币。
- 阶段 2：交换结束后，约翰反复执行下面的操作直到只剩一个桶：选出相邻的两个桶，把它们替换成装 $\frac{a_i + a_{i+1}}{2}$ 加仑牛奶的一个桶。

请你求出：为了让最后剩下的那桶牛奶尽量多，阶段 1 至少要花多少枚金币。

## 输入

- 第 1 行：一个整数 $T$（$1 \le T \le 100$），表示独立的测试组数。
- 每组测试：第 1 行一个整数 $N$；第 2 行 $N$ 个用空格分隔的整数 $a_1, \dots, a_N$。

保证所有测试组的 $N$ 之和不超过 $5 \cdot 10^5$。

## 输出

对每组测试输出一行：阶段 1 最少需要花费的金币数。

## 样例

输入：

```text
2
3
0 0 1
3
0 1 0
```

输出：

```text
0
1
```

第一组不用交换：阶段 2 里先合并前两个桶、再合并剩下的两个桶，最终得到 $0.5$ 加仑，这也是能取到的最大值（一个 $1$ 与两个 $0$ 无论怎么合并都只能得到 $0.5$）。第二组必须先交换前两个桶变成 $[1,0,0]$，才同样能得到 $0.5$；不交换只能得到 $0.25$。

## 思路

**先看阶段 2。** 每次把两个相邻的桶合并成它们的平均值，相当于给参与合并的桶都乘上 $\frac{1}{2}$。也就是说，整个合并过程是一棵二叉树：原来第 $i$ 个桶的牛奶会带着系数 $2^{-d_i}$ 进入最后一桶，其中 $d_i$ 是它参与的合并次数（深度）。要让总量最大，最大的数应该尽量"晚"被合并，因此**每次合并当前最小的两个桶**最优：最终值为 $\sum_{i} 2^{-i} b_i + 2^{-n} b_n$，其中 $b$ 是把 $a$ 从大到小排序后的序列。

**再回到阶段 1。** 要让"最小的两个桶总是相邻"这件事始终成立，把数组排成**谷形**（先不升、后不降，即存在 $k$ 使 $a_1 \ge \cdots \ge a_k \le a_{k+1} \le \cdots \le a_n$）即可：此时从谷底往两边合并，每一步合并的正是当前最小的两个桶。于是问题化为：用最少的相邻交换把数组变成谷形。

**统计代价。** 把每个元素归到谷底的左侧段（不升）或右侧段（不降）。可以证明：在任意谷形排列里，若元素 $x$ 位于谷底左侧，则所有比它小的元素都在它右边；若位于谷底右侧，则所有比它小的元素都在它左边。于是

> 若 $x$ 放左段，它至少要跨过所有原本在它左边且严格比它小的元素，代价至少 $L_x$；若放右段，至少要跨过所有原本在它右边且严格比它小的元素，代价至少 $R_x$。

因此答案不小于 $\sum_x \min(L_x, R_x)$；而这个下界是可以达到的：按值从小到大依次决定每个元素去左段还是右段，同一值的元素之间不必互相跨越，每个元素恰好跨过"较便宜那一侧"的全部更小元素，总交换次数正好等于该和。

**实现。** 把下标按 $a$ 排序后从值小的开始处理，用树状数组维护"当前已处理（即值严格更小）的元素出现在哪些位置"。对元素 $x$，它在树状数组右半边的计数就是左右两侧严格更小的个数。注意**同值的元素必须先把整组统计完、再整组插入**，否则组内元素会把自己当成"更小"的元素而多算。

## 复杂度

排序与树状数组均为 $O(N\log N)$，单组测试时间复杂度 $O(N \log N)$，空间复杂度 $O(N)$，总时间 $O\left(\sum N \log N\right)$。
