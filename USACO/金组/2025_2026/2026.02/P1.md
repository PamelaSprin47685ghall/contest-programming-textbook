# P1　平衡谷仓（Balancing the Barns）

## 题目

$N$（$1\le N\le 5\cdot 10^4$）个谷仓，第 $i$ 个有 $a_i$ 个干草捆和 $b_i$ 袋饲料。不平衡度是 $\max(a)-\min(b)$。每次操作选一个谷仓，把 $a_i$ 减 1、$b_i$ 加 1。恰好做 $K$（$1\le K\le 10^{18}$）次后，求最小不平衡度。

$T\le 10^3$，所有测试的 $N$ 之和不超过 $5\cdot 10^4$。

## 输入

第一行 $T$。每个测试先给 $N,K$，再给 $a_1\dots a_N$ 和 $b_1\dots b_N$。

## 输出

每个测试一行，输出最小的 $\max(a)-\min(b)$。

## 样例

输入：

```text
4
1 10
5
3
2 6
100 96
0 4
3 3
1 1 2
0 0 1
3 3
1 2 2
0 1 1
```

输出：

```text
-18
90
0
0
```

## 思路

二分答案 $Y$，判断能否让 $\max(a)-\min(b)\le Y$。

令 $x=\min(b)$。第 $i$ 个谷仓要满足 $a_i\le x+Y$ 且 $b_i\ge x$，最少转移次数是 $\max(a_i-x-Y,0,x-b_i)$。这些函数都是凸的，总和 $f(x)$ 也是凸的。

先把本来 $a_i-b_i>Y$ 的谷仓用最少转移压进范围。剩下的折点只在每个 $b_i$ 和 $a_i-Y$ 处。从当前最小 $b$ 出发，斜率还是负数时 $f$ 继续下降；斜率变成非负前的最小值不超过 $K$，就说明 $Y$ 可行。多出来的转移可以加在已经取得最大值的干草上，不会把答案变差。

## 复杂度

每次判定排序 $O(N\log N)$，二分 $O(\log 10^{18})$ 次。总时间 $O(\sum N\log N\log 10^{18})$，空间 $O(N)$。
