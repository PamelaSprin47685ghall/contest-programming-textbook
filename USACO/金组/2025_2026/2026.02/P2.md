# P2　字典序最小路径（Lexicographically Smallest Path）

## 题目

无向连通图有 $N$（$1\le N\le 2\cdot 10^5$）个点、$M$（$N-1\le M\le 2\cdot 10^5$）条边，每条边有一个小写字母。路径可以重复经过同一条边。$f(1,i)$ 是从 1 到 $i$ 的边字母拼出的字典序最小串。输出每个 $i$ 的这个串的长度；若不存在有限的最小串，输出 $-1$。

$T\le 10$，所有测试的 $N$ 之和、$M$ 之和都不超过 $4\cdot 10^5$。

## 输入

第一行 $T$。每个测试先给 $N,M$，再给 $M$ 行，每行两个端点和一个小写字母。

## 输出

每个测试一行 $N$ 个整数。

## 样例

输入：

```text
2
1 0
2 2
1 1 a
2 1 b
```

输出：

```text
0
0 -1
```

## 思路

设 $S_l$ 是从 1 出发、恰好走 $l$ 条边能得到的字典序最小串，$W_l$ 是第一次在第 $l$ 步走到的终点。图无向，所以 $S_l$ 必是 $S_{l+1}$ 的前缀，而且字母不增；否则在上升前的那条边上来回多走两次，会得到更小的串。

于是 $S_{l+1}=S_l+c$，其中 $c$ 是 $W_l$ 邻边的最小字母。更早到达的点不必再扩展：它们旁边不可能有比当前更小的字母。每个点只入队一次，队列空了就停止。没被赋过长度的点，最小串可以无限变长，答案是 $-1$。
