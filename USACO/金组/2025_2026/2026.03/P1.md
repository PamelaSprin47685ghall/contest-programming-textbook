# P1　好的循环移位（Good Cyclic Shifts）

## 题目

对一个 $1 \dots N$ 的排列 $p_1, p_2, \dots, p_N$（$1 \le N \le 2 \cdot 10^5$），定义

$$f(p) = \sum_{i=1}^{N} \frac{|p_i - i|}{2}.$$

如果一个排列能**至多**用 $f(p)$ 次"交换相邻两元素"变成恒等排列，就称它是**好的**。

给定一个排列，请找出它的哪些循环移位是好的。输入含 $T$（$1 \le T \le 10^5$）组独立数据，且 $\sum N \le 10^6$。

## 输入

- 第 1 行：一个整数 $T$。
- 接下来每组数据：第 1 行一个整数 $N$，第 2 行 $N$ 个整数 $p_1, p_2, \dots, p_N$（保证是 $1 \dots N$ 的排列）。

## 输出

每组数据输出两行：第一行是好的循环移位个数 $k$；第二行是 $k$ 个按升序排列的整数 $s$（$0 \le s < N$），表示把 $p$ 向右循环移位 $s$ 次后是好的。若 $k = 0$，第二行留空。

## 样例

输入：

```text
3
5
5 4 3 2 1
4
1 2 4 3
5
1 2 3 4 5
```

输出：

```text
0

2
0 1
5
0 1 2 3 4
```

第二组中 $p = [1,2,4,3]$：$f(p) = (0+0+1+1)/2 = 1$，一次相邻交换即可排序，所以 $p$ 是好的；向右移一次得 $[3,1,2,4]$，$f = 2$，把 $3$ 往前推两格即可排序，也是好的，于是 $s = 0, 1$。第一组是逆序排列，任何循环移位都含下降的连续三段，全都不是好的；第三组是恒等排列，任何循环移位都不含逆序对，全部是好的。

## 思路

**关键结论：** 排列是好的 $\iff$ 它不含 $321$ 子序列（不存在 $i < j < k$ 使 $p_i > p_j > p_k$）。

排序所需的相邻交换次数正好是逆序对数，而 $f(p)$ 是"所有元素位移绝对值之和"的一半：若每个元素在过程中始终朝同一方向移动，两者相等；一旦某个元素需要先向右再向左（或反之），它实际走的步数就多于它最终的位移，于是逆序对数严格大于 $f(p)$，排列就不是好的。含 $321$ 时，取中间那个元素（即"2"）：它左边有个更大的、右边有个更小的，无论先处理哪一侧，它都必须双向移动，所以不是好的。反过来，不含 $321$ 时可以反复"把当前最小值一路换到最左边，然后把它固定住"，每个元素只向左走，所需次数恰好等于 $f(p)$，所以是好的。

于是只需对每个循环移位判断是否含 $321$。把排列首尾相接成环，对每个元素 $j$ 求出

- $g(j)$：从 $j$ 沿环向左找第一个比 $p_j$ 大的位置，距离记为 $d_L(j)$；
- $s(j)$：从 $j$ 沿环向右找第一个比 $p_j$ 小的位置，距离记为 $d_R(j)$。

**为什么只看最近的这两个？** 若某个窗口里存在 $321$，取其中间那个元素 $j$，则窗口内 $j$ 左侧有一个比 $p_j$ 大的点、右侧有一个比 $p_j$ 小的点。而 $g(j)$ 比那个左侧点更靠近 $j$，$s(j)$ 比那个右侧点更靠近 $j$，所以 $g(j), j, s(j)$ 也一定按顺序落在同一个窗口里（$g(j) > p_j > s(j)$）。反之这三点同窗显然就构成 $321$。故

$$\text{该循环移位是坏的} \iff \exists j:\ g(j), j, s(j) \text{ 按顺序落在这个窗口内}.$$

**标记坏移位。** 设窗口对应环上起点 $st$，则 $j$ 在窗口中的位置是 $\mathrm{pos} = (j - st) \bmod N$。要装下三点，需要 $\mathrm{pos} \ge d_L(j)$（左边留得下 $g$）且 $\mathrm{pos} \le N - 1 - d_R(j)$（右边留得下 $s$）。因此当 $d_L(j) + d_R(j) \le N - 1$ 时，恰好有 $N - d_L(j) - d_R(j)$ 个起点会让这个三点组成形，而且这些起点在环上连成一段区间，末端是 $(j - d_L(j)) \bmod N$。

**实现。** 把环拉成长度 $2N$ 的直线，坏区间用差分数组做区间加，前缀和一遍即得每个起点被标记的次数；起点 $st$ 与 $st + N$ 表示同一个循环移位，只要其中之一被标记过就是坏的。求 $g, s$ 时同样把数组复制一份接在后面（断环成链），正反各跑一次单调栈，栈里存下标、算距离时取模即可，全程线性。最后输出的是"向右移 $s$ 次"，与窗口起点的关系是 $st = (N - s) \bmod N$，直接枚举 $s$ 升序输出就是升序答案。

**细节。** 若 $p_j$ 是最大值或最小值，它不可能充当 $321$ 里的"2"，此时 $d_L$ 或 $d_R$ 不存在，直接跳过。环上与自己同余的栈顶不会出现（同值早被弹掉），所以距离恒为正。
