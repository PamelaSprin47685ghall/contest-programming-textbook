# P3　逃离农场（Escaping the Farm）

## 题目

奶牛们想乘一只小充气筏子逃出农场。筏子载重量有限，所以它们要挑一群足够轻的奶牛。

$N$ 头奶牛各有重量 $w_1 \dots w_N$。判断一群牛是否够轻，奶牛们会把所有重量加起来。但奶牛算术很差：如果把这些重量做十进制加法时**产生了任何进位**，它们就认为这群牛太重，放弃上筏。只要相加时不产生任何进位，就认为这群牛够轻。

请帮奶牛们算出：能被认为够轻的**最大牛群**有多大（即这些重量相加不产生任何进位）。

## 输入

- 第一行一个整数 $N$（$1 \le N \le 20$）。
- 接下来 $N$ 行，每行一个整数（范围 $1$ 到 $100000000$），表示一头牛的重量。

## 输出

一个整数：能相加且不产生进位的最大牛群大小。

## 样例

输入：

```text
5
522
6
84
7311
19
```

输出：

```text
3
```

解释：$522, 6, 7311$ 三个重量相加不产生进位：

```text
 522
   6
+7311
-----
7839
```

## 思路

$N \le 20$ 很小，可以枚举每一头牛“选”还是“不选”，检查选出的重量相加是否进位，取能选出的最大个数。这是最直接的搜索。

关键是怎么快速判断“相加是否进位”。一个巧妙的性质：两个数相加不产生进位，当且仅当 **两数之和的数位和 = 两数数位和之和**。因为一旦某一位发生进位，进位的 $1$ 会让和的数位和减少（$10$ 变成 $1$，少了 $9$），两边就不相等了。

于是搜索时维护当前已选重量的和，每次尝试加入一头牛，先判断“当前和 + 这头牛重量”是否进位（用上面的性质），不进位才加入，并更新答案。枚举所有情况即可。

## 复杂度

每个重量有选/不选两种可能，共 $2^N$ 种情况；每次判断进位要算数位和，是 $O(\log W)$。总时间 $O(2^N \log W)$，空间 $O(N)$。$N \le 20$ 时完全可行。
