# P2　干草堆叠放（Haybale Stacking）

## 题目

Bessie 帮农夫约翰把运来的干草堆成 $N$ 个空堆，编号 $1$ 到 $N$。约翰给她 $K$ 条指令，每条形如 “$A$ $B$”，意思是给编号 $A$ 到 $B$ 的每一堆顶上各加一捆干草。

堆完之后，约翰想知道这 $N$ 堆高度的**中位数**——即把各堆高度排序后，位于正中间那堆的高度。$N$ 是奇数，所以这个中间堆是唯一的。

## 输入

- 第一行两个整数 $N$ 和 $K$（$1 \le N \le 1000000$，$N$ 为奇数；$1 \le K \le 25000$）。
- 接下来 $K$ 行，每行两个整数 $A$ $B$（$1 \le A \le B \le N$），表示一条指令。

## 输出

一个整数：堆完后 $N$ 堆高度的中位数。

## 样例

输入：

```text
7 4
5 5
2 4
4 6
3 5
```

输出：

```text
1
```

解释：堆完后各堆高度为 $0,1,2,3,3,1,0$，排序后是 $0,0,1,1,2,3,3$，中位数是第 4 个，即 $1$。

## 思路

$N$ 最大到 $10^6$，如果对每条指令真的把区间里每个位置都加 1，最坏会做 $K \times N$ 次，太大。这里要用**差分数组**来高效地做“区间加”。

差分的思想：开一个数组 `diff`，对指令 “$A$ $B$”，只做 `diff[A]++` 和 `diff[B+1]--`，不做区间里每个位置。全部指令处理完后，对 `diff` 做一遍前缀和（`diff[i] += diff[i-1]`），得到的 `diff[1..N]` 就是每个位置最终的堆叠高度。这样每条指令只改两个位置，总时间只和 $K$ 有关。

得到所有高度后，排序取中间那个（下标 `1 + N/2`）就是中位数。

## 复杂度

差分处理 $K$ 条指令是 $O(K)$，前缀和与排序是 $O(N \log N)$。总时间 $O(K + N \log N)$，空间 $O(N)$。
