# P2　重复种草（Overplanting）

## 题目

农夫约翰买了一台新机器，可以在农场上任意**边平行于坐标轴**的矩形区域里种草。有一天机器出故障，在 $N$ 个不同的矩形区域里都种了草，这些区域可能互相重叠。

给出所有种了草的矩形区域，请帮约翰算出农场里**总共被草覆盖的面积**（重叠部分只算一次）。

## 输入

- 第一行一个整数 $N$（$1 \le N \le 10$）。
- 接下来 $N$ 行，每行四个整数 $x_1\ y_1\ x_2\ y_2$，表示一个矩形区域，$(x_1,y_1)$ 是左上角，$(x_2,y_2)$ 是右下角。所有坐标范围 $-10000$ 到 $10000$。

## 输出

一个整数：被草覆盖的总面积。

## 样例

输入：

```text
2
0 5 4 1
2 4 6 2
```

输出：

```text
20
```

## 思路

$N$ 最多 10，但坐标范围很大（$-10000$ 到 $10000$），不能直接开一个巨大的网格。这里用**离散化**：把所有矩形用到的 $x$ 坐标和 $y$ 坐标分别收集起来、排序去重。这样坐标轴被切成很多小区间，网格单元数只和坐标个数有关，而不是坐标值范围。

离散化后，对每个矩形，找到它覆盖的网格单元范围（用二分找它四条边对应的离散坐标下标），把这些单元标记为“被覆盖”。最后把所有被覆盖单元的真实面积（离散区间宽度之积）累加，就是答案。

注意输入顺序：每行是 $(x_1, y_1, x_2, y_2)$，其中第 2 个数是**最高**的 $y$，第 4 个数是**最低**的 $y$。

## 复杂度

坐标去重 $O(N \log N)$；标记覆盖时每个矩形遍历其覆盖的单元。坐标最多 $2N$ 个，所以网格最多约 $(2N)^2$ 个单元，总时间 $O(N^3)$ 量级，空间 $O(N^2)$。$N \le 10$ 时很小。
