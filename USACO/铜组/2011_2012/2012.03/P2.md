# P2　连接奶牛（Connect the Cows）

## 题目

农夫约翰每天绕着农场巡视他的 $N$ 头奶牛。每头奶牛在平面上有一个坐标，约翰从原点 $(0,0)$ 出发。

为了让路线更有趣，约翰只沿着坐标轴方向走（北、南、东、西），而且只在到达某头奶牛的位置时才改变方向（他也可以经过奶牛位置但不改变方向）。改变方向时可以是 90 度或 180 度转弯。约翰的路线必须访问完所有奶牛后回到原点。

请算出约翰有多少种不同的路线，要求他在**每头奶牛的位置恰好改变一次方向**。他可以任意多次经过奶牛位置而不改变方向。同一条几何路线正着走和反着走算两条不同路线。

## 输入

- 第一行一个整数 $N$（$1 \le N \le 10$）。
- 接下来 $N$ 行，每行两个整数 $x$ $y$（范围 $-1000$ 到 $1000$），表示一头奶牛的位置。

## 输出

一个整数：不同的路线数（没有合法路线则为 0）。

## 样例

输入：

```text
4
0 1
2 1
2 0
2 -5
```

输出：

```text
2
```

解释：两条路线是依次访问 $1\text{-}2\text{-}4\text{-}3$ 或 $3\text{-}4\text{-}2\text{-}1$ 后回到原点。

## 思路

$N \le 10$ 很小，可以**枚举所有访问顺序**（排列），检查每个顺序是否构成合法路线。

关键约束是“每头奶牛处恰好改变一次方向”。约翰只在坐标轴方向走，所以从点 $p$ 到点 $q$ 的移动方向只有 8 种（东、西、南、北，以及斜向的“先水平再垂直”组合）。判断相邻两步方向是否相同：如果相同，说明经过中间那点没有改变方向，不满足“恰好改变一次”的要求，这个顺序就不合法。

做法：把起点（原点）固定在下标 0，枚举其余 $N$ 个点的排列。每相邻两点计算移动方向，要求方向非零（不能原地不动）且与上一步不同；走完所有点后，最后一步回到原点，也要求方向与上一步不同。满足全部条件的排列计数。

## 复杂度

枚举 $N$ 个点的所有排列，共 $N!$ 个，每个排列检查 $O(N)$ 步。总时间 $O(N! \cdot N)$，空间 $O(N)$。$N \le 10$ 时可行。
