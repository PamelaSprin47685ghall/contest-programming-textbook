# P3　方向错误（Wrong Directions）

## 题目

农夫约翰买了一台新的可编程拖拉机。要让它动起来，他输入一串长度为 $N$ 的指令，只含字符 `F`、`L`、`R`。`F` 表示前进一格，`L` 和 `R` 分别表示向左、向右转 90 度。拖拉机从原点 $(0,0)$ 出发，面朝北。

约翰输入完指令后，突然想起自己**恰好打错了一个字符**，但记不清是哪一个。例如，他可能想输入 `R` 却打成了 `F` 或 `L`。

请算出：由于这一个错字，拖拉机**最终可能停在多少个不同的位置**（最终朝向不重要）。

## 输入

一行：约翰原本想输入的指令串。

## 输出

一个整数：拖拉机可能停下的不同位置数。

## 样例

输入：

```text
FF
```

输出：

```text
3
```

解释：有 4 种可能的错误序列 `FL, FR, LF, RF`，分别停在 $(0,1),(0,1),(-1,0),(1,0)$，共 3 个不同位置。

## 思路

$N$ 最大 $10^5$，不能真的对每个位置枚举改法再重新模拟整串。要高效，用**前缀/后缀效果**来复用计算。

把一条指令序列的效果抽象成“位移 $(x,y)$ + 最终朝向”。先预处理后缀效果 `suffix[i]` = 从位置 $i$ 到末尾这段指令的效果。然后从左往右扫描，维护当前位置之前的前缀效果 `prefix`。

对每个位置 $i$，尝试把它改成另外两种指令之一（必须真的改掉这一位），新的总效果 = 前缀效果 + 改后单条指令效果 + 后缀效果。把得到的所有终点（只关心位移，不关心朝向）放进一个集合去重，集合大小就是答案。

合并效果时注意：后执行的序列会影响前一段的朝向，所以合并要按朝向旋转后再叠加位移。

## 复杂度

预处理后缀 $O(N)$，扫描每个位置尝试两种改法 $O(N)$，用哈希集合去重。总时间 $O(N)$，空间 $O(N)$。
