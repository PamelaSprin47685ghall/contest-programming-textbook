# P1　一排奶牛（Cows in a Row）

## 题目

农夫约翰的 $N$ 头奶牛排成一排，每头牛有一个整数“品种编号”，第 $i$ 头牛的编号是 $B(i)$。

约翰觉得如果有一大段**连续**且品种编号相同的牛，队伍会更好看。为此，他决定从队伍里**删掉所有具有某个品种编号的牛**（这个编号由他选）。

请帮约翰算出：通过删掉所有具有某种编号的牛，他能得到的最长的连续同编号牛段有多长。

## 输入

- 第一行一个整数 $N$（$1 \le N \le 1000$）。
- 接下来 $N$ 行，每行一个整数（范围 $0$ 到 $1000000$），表示第 $i$ 头牛的品种编号 $B(i)$。

## 输出

一个整数：能得到的最大连续同编号牛段长度。

## 样例

输入：

```text
9
2
7
3
7
7
3
7
5
7
```

输出：

```text
4
```

解释：删掉所有编号为 3 的牛后，队伍变成 $2,7,7,7,7,5,7$，其中有一段连续的 4 头编号为 7 的牛。

## 思路

先想：删掉某种牛之后，剩下的牛里，一段连续的相同编号是怎么来的？它一定来自原队伍中**被删掉的牛隔开的两段同编号牛**，删掉中间那种牛后它们就拼到一起了。

所以先把原队伍里连续相同的编号合并成一段（记录每段的编号和长度）。然后从左到右扫描这些段，对每一段，看看**隔一段**的那段（中间隔着一整段其他编号）是否和它编号相同。如果相同，删掉中间那段编号的牛，这两段就能拼起来，长度是两段长度之和（若中间段本身还连着更早的同编号段，可以一并接上）。

扫描过程中不断更新答案，同时也要考虑“只保留某一段本身”（不拼）的情况。
