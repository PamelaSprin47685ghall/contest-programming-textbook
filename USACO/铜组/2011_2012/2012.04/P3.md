# P3　岛屿（Islands）

## 题目

一下雨，农夫约翰的田里就会积水。但田地不平，水会不均匀地上涨，露出一些被水分隔的“岛屿”。

田地是一条一维的地形，由 $N$ 个位置的高度 $H(i)$ 描述。下雨时水面从最低处开始不断上升，直到整个田地都被淹没。在某个时刻，露出水面的**连续的高地**算作一个岛屿（相邻位置高度都高于当前水面，且连在一起算同一个岛）。

请算出在整个降雨过程中，任意时刻最多能看到多少个岛屿。

## 输入

- 第一行一个整数 $N$。
- 接下来 $N$ 行，每行一个整数 $H(i)$（$1 \le H(i) \le 1000000000$），表示第 $i$ 个位置的高度。

## 输出

一个整数：降雨过程中任意时刻出现的最大岛屿数。

## 样例

输入：

```text
8
3
5
2
3
1
4
2
3
```

输出：

```text
4
```

## 思路

水面不断上升，等价于**位置从低到高逐个被淹没**。我们按高度从低到高处理：每淹没一个位置，就更新当前的岛屿段数。

关键在于：淹没一个位置时，岛屿数怎么变？看它左右两个邻居是否已经被淹没：

- 如果左右**都没**淹没，这个位置原本把左右连在一起（或者它自己新起一段），淹没后岛屿数**加 1**；
- 如果左右**都**已淹没，它原本是左右两段之间的连接，淹没后把两段连成一段，岛屿数**减 1**；
- 否则（只有一边被淹没），岛屿数不变。

把所有位置按高度从高到低排序，逐批处理（**相同高度的位置必须同时淹没**，因为水面同时到达它们）。每淹没一批就统计当前岛屿数，取历史最大值。

排序 $O(N\log N)$，逐位置处理 $O(N)$。总时间 $O(N\log N)$，空间 $O(N)$。
