# P2　打字错误（Typo）

## 题目

Bessie 想打一串她最喜欢的“平衡括号串”，但她蹄子太大，可能打错了一个字符——把一个 `(` 打成了 `)`，或者反过来。

请你帮她数一数：有多少个位置，只要把那个位置上的括号**翻转一下**（`(` 变 `)`，`)` 变 `(`），整串就变成平衡括号串。

“平衡括号串”的定义：整个串里 `(` 和 `)` 的数量相同，并且任意前缀里 `(` 的数量都不少于 `)` 的数量。比如 `()`、`(())`、`()(()())` 都是平衡的，而 `)(`、`()) (`、`((())))` 不是。

## 输入

一行，一个长度为 $N$ 的括号串（$1 \le N \le 100000$）。

## 输出

一行，一个整数：翻转单个位置后能使整串平衡的位置个数（可能为 0）。

## 样例

输入：

```text
()(())))
```

输出：

```text
4
```

解释：把位置 2、5、6 或 7 处的括号翻转后，整串都会变成平衡串。

## 思路

如果直接对每个位置都试一次翻转再检查整串是否平衡，需要 $O(N^2)$，太慢了。我们要想办法在 $O(1)$ 内判断“翻转第 $i$ 个字符后整串是否平衡”。

关键思想：把一段括号串看成一个“净效果”——它可能剩下 `right` 个没配对的右括号（在开头）和 `left` 个没配对的左括号（在结尾）。两段串接在一起时，相接处的右括号和左括号会互相抵消。

于是：

1. 先预处理 `suffix[i]`：从位置 $i$ 到末尾这一段串的净效果。
2. 从左往右扫，同时维护 `prefix`：位置 $0$ 到 $i-1$ 这一段串的净效果。
3. 对每个位置 $i$，把它翻转后的效果与 `prefix`、`suffix[i+1]` 合并，如果合并结果正好是 `(0,0)`，说明整串平衡。

这样每个位置只需常数次合并，整体 $O(N)$。
