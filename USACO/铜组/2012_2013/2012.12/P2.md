# P2　打乱的字母（Scrambled Letters）

## 题目

农夫约翰在谷房门上贴着一张按字典序排列的奶牛名单，每头牛的名字是一个 1 到 20 个小写字母组成的字符串，互不相同。

爱捣乱的 Bessie 打乱了名单的顺序，还把每头牛名字里的字母也打乱了。给你这份被打乱后的名单，请你帮约翰算出：名单里每个字符串，在**原始名单**里可能出现过的最靠前位置和最靠后位置。

## 输入

- 第一行：整数 $N$（$1 \le N \le 50000$）；
- 接下来 $N$ 行：每行一个被打乱顺序的名字。

## 输出

$N$ 行，第 $i$ 行输出两个整数：第 $i$ 个输入字符串在原始名单里可能出现的最靠前位置和最靠后位置。

## 样例

输入：

```text
4
essieb
a
xzy
elsie
```

输出：

```text
2 3
1 1
4 4
2 3
```

解释：`a` 无论如何都排第一，`xzy` 无论如何都排最后；`essieb` 和 `elsie` 可能分别占据位置 2、3。

## 思路

每个名字的字母可以任意重排，所以一个名字在原始名单里的位置取决于它**所有可能的字母排列**能排到多靠前、多靠后。

- 一个名字能排到的最靠前位置：把它按**升序**排列（字典序最小的排列），看这个最小排列在所有名字的最小排列里能排第几。用 `lower_bound` 找它。
- 一个名字能排到的最靠后位置：把它按**降序**排列（字典序最大的排列），看这个最大排列在所有名字的最大排列里能排第几。用 `upper_bound` 减 1 找它。

具体做法：

1. 对每个名字，生成它升序排列后的串和降序排列后的串；
2. 把“所有名字的升序排列串”排好序，把“所有名字的降序排列串”也排好序；
3. 对每个原始名字：在降序排列串里二分找它升序串的位置（最前），在升序排列串里二分找它降序串的位置（最后）。

这样每个名字只需两次二分，整体很快。
