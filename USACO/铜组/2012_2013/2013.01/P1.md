# P1　镜子（Mirrors）

## 题目

农夫约翰在农场各处装了 $N$（$1 \le N \le 200$）面反光栅栏（镜子），想从自己家（位置 $(0,0)$）看到谷仓（位置 $(a,b)$）。

每面镜子是一个中心在整点 $(x_i, y_i)$、倾斜 45 度（像 `/` 或 `\`）的短线。约翰从家出发朝正右方（$+x$ 方向）看，希望光线经过一些镜子反射后能到达 $(a,b)$。

约翰怀疑自己把某面镜子的方向装反了（`\` 装成了 `/` 或反过来）。请你输出：**第一面**只要翻转它的方向就能让约翰看到谷仓的镜子的编号。如果不用翻转任何镜子就能看到，输出 0；如果翻转一面镜子也看不到，输出 -1。

## 输入

- 第一行：三个整数 $N$、$a$、$b$；
- 接下来 $N$ 行：第 $i+1$ 行是 `x_i y_i /` 或 `x_i y_i \`，描述第 $i$ 面镜子的中心位置和方向。

坐标范围 $-10^6$ 到 $10^6$，没有镜子位于 $(0,0)$ 或 $(a,b)$。

## 输出

一行，一个整数：第一面翻转后能让约翰看到谷仓的镜子编号；若原本就能看到输出 0；若翻转一面也看不到输出 -1。

## 样例

输入：

```text
5 6 2
3 0 /
0 2 /
1 2 /
3 2 \
1 3 \
```

输出：

```text
4
```

解释：翻转位置 $(3,2)$ 的镜子后，约翰能看到谷仓。

## 思路

光线在平面上沿水平或垂直方向直线前进，遇到镜子就反射。我们可以模拟光线的传播：

- 用方向编号表示当前前进方向（右、上、左、下）；
- 每面镜子的反射相当于把方向翻转：`/` 把方向翻转 1 步，`\` 翻转 3 步；
- 用两个映射（按行、按列）快速找到当前方向上最近的下一面镜子。

模拟时，如果光线在到达谷仓前先出界，说明看不到；如果走了足够多步还没到达，说明光线陷入循环，也看不到。

做法：

1. 先按当前所有镜子的方向模拟，看能否直接看到谷仓，能则输出 0；
2. 否则依次翻转每面镜子，重新模拟，找到第一面翻转后能看到的镜子，输出它的编号；
3. 若都不行输出 -1。

因为镜子最多 200 面，每次模拟很快。

## 复杂度

每次模拟最多走 $O(N)$ 步，每步用二分查找找最近的镜子。总时间 $O(N^2 \log N)$，空间 $O(N)$。
