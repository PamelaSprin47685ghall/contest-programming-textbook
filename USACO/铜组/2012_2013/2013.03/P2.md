# P2　品种相近（Breed Proximity）

## 题目

农夫约翰的 $N$（$1 \le N \le 50000$）头牛站成一排，每头牛有一个整数品种编号。

同品种的牛如果站得太近就容易吵架。具体来说，如果两头同品种的牛在队伍中的位置差不超过 $K$（$1 \le K < N$），就说它们“拥挤”。

请你算出存在拥挤的一对牛中，**最大的品种编号**。

## 输入

- 第一行：两个整数 $N$ 和 $K$；
- 接下来 $N$ 行：每行一个整数，表示队伍中一头牛的品种编号（范围 0 到 $10^6$）。

## 输出

一行，一个整数：存在拥挤的一对牛中最大的品种编号；如果没有拥挤的一对牛，输出 -1。

## 样例

输入：

```text
6 3
7
3
4
2
3
4
```

输出：

```text
4
```

解释：品种 3 的两头牛是拥挤的，品种 4 的两头牛也是拥挤的。

## 思路

从左往右扫一遍队伍。对每个品种，记录它**上一次出现的位置**。

- 用一个哈希表 `lastIndex` 存每个品种最近一次出现的下标；
- 每读到一头牛，如果这个品种之前出现过，检查当前位置和上次位置之差是否 $\le K$，是则说明这对牛拥挤，用这个品种编号更新答案；
- 无论是否拥挤，都更新这个品种的上次位置为当前位置。

因为同品种的牛只要有一对位置差 $\le K$ 就拥挤，而我们每次只比较“相邻两次出现”，这已经足够判断——如果某品种有任意一对相距 $\le K$，那么它必然有某对相邻出现也相距 $\le K$。最后取满足条件的最大品种编号。
