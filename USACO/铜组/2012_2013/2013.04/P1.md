# P1　奶牛芭蕾（Bovine Ballet）

## 题目

为了挑战“牛很笨拙”的刻板印象，约翰的明星牛 Bessie 报名了芭蕾入门班。她下周就要表演了，约翰想帮她搭一个足够大的矩形舞台，让她能跳完整支舞不掉下去。

Bessie 的舞蹈发生在一个由 $1\times1$ 小方格组成的矩形舞台上。她的四只脚记为：`FR`（前右）、`FL`（前左）、`RR`（后右）、`RL`（后左）。

四只脚开始时占据相邻的 4 个格子，围成一个正方形，Bessie 面朝北：

```text
FL FR
RL RR
```

舞蹈由 $N$（$1 \le N \le 1000$）条指令组成，每条指令要么让一只脚移动一格，要么绕某只脚顺时针旋转 90 度。

- 移动指令形如 3 个字符：前两个是脚名，最后一个表示方向（`F` 前、`B` 后、`R` 右、`L` 左），方向是相对 Bessie 面朝的方向；
- 旋转指令也是 3 个字符：前两个是指定保持不动的脚，最后一个是 `P`，表示绕这只脚顺时针旋转 90 度。

请你算出能装下 Bessie 整支舞的四只脚所需矩形舞台的最小面积。如果 Bessie 笨拙地把一只脚踩到另一只脚所在的格子上，她会绊倒跳不完，此时输出 -1。

## 输入

- 第一行：整数 $N$；
- 接下来 $N$ 行：每行一条 3 字符指令。

## 输出

一行，一个整数：能装下整支舞的最小矩形舞台面积；如果 Bessie 会绊倒，输出 -1。

## 样例

输入：

```text
3
FRF
FRP
RLB
```

输出：

```text
16
```

解释：Bessie 需要 $4 \times 4$ 的舞台才能完成这支舞。

## 思路

直接模拟整支舞，记录四只脚的位置和 Bessie 的朝向。

- 用一个方向编号表示 Bessie 当前面朝的方向，初始面朝北；
- 移动一只脚时，把“前后左右”换算成相对当前朝向的实际位移；
- 旋转时，以指定的脚为轴，把其他脚绕它旋转 90 度（坐标变换），同时更新朝向；
- 每只脚移动或旋转后，更新四只脚踩过的横纵坐标范围（`minX/maxX/minY/maxY`）。

模拟过程中如果某只脚踩到别的脚所在的格子，就返回失败，输出 -1。否则，舞台的最小面积就是四只脚覆盖的矩形面积：`(maxX - minX + 1) * (maxY - minY + 1)`。
