# P1　镜子田地（Mirror Field）

## 题目

农夫约翰把一些旧镜子放在屋外，结果被调皮的奶牛偷走了。奶牛们在一个 $N$ 行 $M$ 列的矩形田地里布置镜子（$1 \le N, M \le 1000$）。每个格子里放了一面双面镜，连接两个对角，用两种字符表示：

- `/`：镜子连接左下角到右上角；
- `\`：镜子连接左上角到右下角。

一天傍晚，贝茜带了一支激光笔来到镜子田地。她站在田地外面，让光束沿某一行或某一列的横向或纵向射入，光束会被若干面镜子反射。由于所有镜子都是对角放置的，水平光束碰到镜子后会变成竖直，反之亦然。

贝茜想知道：光束最多能被多少面镜子同时反射。给定镜子布局，请帮她算出这个数。

## 输入

- 第一行：两个整数 $N$ 和 $M$。
- 接下来 $N$ 行：每行 $M$ 个 `/` 或 `\` 字符，描述一行镜子。

## 输出

- 一行：从田地外面射入的水平或竖直光束最多能被反射的次数。如果光束能被无限反射，输出 `-1`。

## 样例

输入：

```text
3 3
/\\
\\\
/\/
```

输出：

```text
3
```

样例解释：贝茜可以在中间一列的上方向下射入光束，它会被反射 3 次。

## 思路

光束从田地四条边的任意一个格子射入，方向是水平或竖直的。我们枚举所有可能的入射起点和方向，模拟光束在田地里的运动，统计它照亮的格子数，取最大值。

模拟时用方向编码：0=右、1=上、2=左、3=下。每走一步，如果当前格子是镜子，就按镜子的方向更新光束方向（`/` 和 `\` 各自把入射方向映射到反射方向，可以预先用一张表 `REFLECT` 存好），否则方向不变。

因为田地大小 $N \times M \le 10^6$，从每条边每个格子入射一次，每次模拟最坏走 $N \times M$ 步，总复杂度是 $O((N+M) \times N \times M)$，这个规模下可行。光束离开田地时模拟结束，照亮的格子数就是这次入射的反射次数。

## 复杂度

入射起点共 $O(N + M)$ 个，每次模拟最多走 $O(N \times M)$ 步。总时间复杂度 $O((N+M) \times N \times M)$，空间复杂度 $O(N \times M)$。
