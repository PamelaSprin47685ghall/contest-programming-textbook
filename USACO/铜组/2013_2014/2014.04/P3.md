# P3　装饰牧场（Decorating the Pastures）

## 题目

农夫约翰有 $N$ 个牧场（$1 \le N \le 50{,}000$），编号 $1 \sim N$，由 $M$ 条双向小路连接（$1 \le M \le 100{,}000$）。第 $i$ 条小路连接牧场 $A_i$ 和 $B_i$（$A_i \ne B_i$），可能有两对牧场之间有多条小路。

贝茜决定在约翰生日时装饰牧场。她想在每个牧场放一块大牌子，牌子上写字母 F 或 J。但为了不弄混约翰，她要求：如果两个牧场由一条小路直接相连，它们的牌子字母必须不同。

做牌子的公司对 F 牌收费更高，所以贝茜想尽可能多放 J 牌。请算出她最多能用多少块 J 牌；如果无论如何都无法满足要求，输出 `-1`。

## 输入

- 第一行：两个整数 $N$ 和 $M$。
- 接下来 $M$ 行：每行两个整数 $A_i$ 和 $B_i$，表示一条连接 $A_i$ 和 $B_i$ 的双向小路。

## 输出

- 一行：最多能用的 J 牌数量；如果没有合法方案，输出 `-1`。

## 样例

输入：

```text
4 4
1 2
2 3
3 4
4 1
```

输出：

```text
2
```

样例解释：牧场和路构成一个正方形的顶点和边。贝茜可以给牧场 1 和 3 放 J 牌，或者给牧场 2 和 4 放 J 牌。

## 思路

把牧场看成图的顶点、小路看成边。要求"相邻顶点字母不同"就是给图做**二染色**（两种颜色对应 F 和 J）。

对每个连通分量单独处理：

- 从某个未染色的顶点开始，用 DFS 给它染一种颜色，然后给它的邻居染另一种颜色，依此类推。如果过程中发现某条边的两端已经被染成相同颜色，说明这个连通分量无法二染色，整个问题无解，输出 `-1`。
- 如果成功染色，这个连通分量里两种颜色的顶点数就确定了。为了让 J 尽可能多，我们在这个分量里选择数量较多的那种颜色作为 J（因为两种颜色可以互换，F 和 J 是对称的），累加进答案。

把所有连通分量的"较多颜色数量"加起来，就是最多能用的 J 牌数。

## 复杂度

每个顶点和每条边各访问常数次（DFS）。总时间复杂度 $O(N + M)$，空间复杂度 $O(N + M)$。
