# P2　填字游戏（Crosswords）

## 题目

贝茜的姐姐艾尔希把牛奶洒在了填字游戏书上，字迹被弄花了，看不清每条线索从哪个格子开始。请你帮她恢复线索的编号。

给你一个 $N \times M$ 的网格（$3 \le N,M \le 50$），有的格子是白格（用 `.` 表示，可以填字），有的是黑格（用 `#` 表示，不能填字）。线索编号按下面两步确定：

1. **判断每个格子是否是一条线索的起点。**
   - 横向线索的起点：该格必须是白格，它左边的格子必须是黑格或超出网格，并且它右边连续两格也必须是白格（即横向词长至少 3）。
   - 纵向线索的起点规则类似：该格必须是白格，它上面的格子必须是黑格或超出网格，并且它下面连续两格也必须是白格。

2. **给所有起点编号。** 按读书的顺序从 1 开始依次编号：先第一行从左到右，再第二行，依此类推。只有作为线索起点的格子才编号。

注意：题目给的网格不一定满足正式填字游戏的约束，有些白格可能不属于任何线索。

## 输入

第一行两个整数 $N$ 和 $M$。

接下来 $N$ 行，每行 $M$ 个字符，是 `.`（白格）或 `#`（黑格）。

## 输出

第一行输出线索的总数。

接下来每行输出一个线索起点的行号和列号，按编号顺序输出。左上角格子位置是 $(1,1)$，右下角是 $(N,M)$。

## 样例

输入：

```text
5 3
...
#..
...
..#
.##
```

输出：

```text
4
1 1
1 2
1 3
3 1
```

## 思路

题目就是让按规则"扫描"每个格子，判断它是不是横向或纵向线索的起点。判断时要注意边界：格子左边或上面超出网格时，按"黑格"处理，这样最外圈的线索也能被正确识别。代码里用一个 `cell` 函数，越界就返回 `'#'`，统一处理边界。

对每个格子，分别检查横向和纵向两个条件，只要满足其中一个就把它记下来。因为编号顺序就是从上到下、从左到右扫描的顺序，所以按这个顺序收集起点，输出顺序自然正确。
