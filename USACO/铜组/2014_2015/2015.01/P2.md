# P2　奶牛航线 II（Cow Routing II）

## 题目

背景与上一题相同：贝茜想从城市 $A$ 飞到城市 $B$，Air Bovinia 有 $N$ 条航线，每条航线由若干城市按顺序组成（无重复城市），每条航线有一个固定费用。贝茜可以在航线的任意城市上机、在靠后的任意城市下机。

与上一题不同的是，这次贝茜最多可以使用**两条**航线。注意：每条航线最多用一次，不能先坐某条航线的一段，之后再坐同一条航线的另一段。

请帮她算出从 $A$ 到 $B$ 的最少总费用。

## 输入

第一行三个整数 $A, B, N$。

接下来每两条线描述一条航线：第一行是费用（$1$ 到 $1000$）和城市数（$1$ 到 $500$）；第二行是按顺序列出航线经过的城市，每个城市用 $1$ 到 $10000$ 的整数表示。

## 输出

输出用最多两条航线从 $A$ 到 $B$ 的最小总费用。如果不可能，输出 `-1`。

## 样例

输入：

```text
1 2 3
3 3
3 2 1
4 4
2 1 4 3
8 5
4 1 7 8 2
```

输出：

```text
7
```

先用第 2 条航线从城市 1 到城市 3，再用第 1 条航线从城市 3 到城市 2，总费用 $4+3=7$。

## 思路

最多两条航线，可以枚举所有"第一条航线 + 第二条航线"的组合（允许两条是同一航线，此时只付一次费用）。对每一对航线，判断能否接力完成 $A \to B$：

1. 第一条航线必须能从 $A$ 出发——即航线里出现 $A$，贝茜在 $A$ 上机。
2. 第一条航线在 $A$ **之后**出现的所有城市，都是贝茜可以换乘到达的"中转城市"。
3. 第二条航线必须能到达 $B$——即航线里出现 $B$，且贝茜在 $B$ 下机。
4. 第二条航线在 $B$ **之前**出现的城市中，只要有一个是上面说的"中转城市"，贝茜就能先到那里，再换乘第二条航线到 $B$。

实现时，对每条航线先收集"$A$ 之后的城市集合"，再检查第二条航线里 $B$ 之前的城市是否与这个集合有交集。枚举所有组合取最小费用即可。$N \le 500$，两两组合约 $25$ 万次，完全可行。
