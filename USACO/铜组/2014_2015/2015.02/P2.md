# P2　COW

## 题目

贝茜在一块大石头上发现了一篇神秘铭文，文字来自一种只有 C、O、W 三个字母的古老语言。虽然她看不懂，但她知道 C、O、W 按顺序连起来就是她最喜欢的单词，于是她想知道这篇文字里出现了多少次 COW。

COW 不要求字母连续相邻，只要按 C、O、W 的顺序出现即可；不同的 COW 也可以共用一些字母。例如：`CWOW` 里 COW 出现 1 次，`CCOW` 里出现 2 次，`CCOOWW` 里出现 8 次。

给定文字，请数出 COW 作为子序列出现了多少次。

## 输入

第一行一个整数 $N \le 10^5$。第二行是一个长度为 $N$ 的字符串，每个字符是 C、O 或 W。

## 输出

输出 COW 作为子序列出现的次数。答案可能很大，请用 64 位整数（C++ 的 `long long`）计算。

## 样例

输入：

```text
6
COOWWW
```

输出：

```text
6
```

## 思路

数"子序列"出现次数，可以一边从左到右扫字符串，一边维护三个计数：

- `countC`：到目前为止出现的 C 的个数。每个 C 都可能成为某个 COW 的开头。
- `countCO`：到目前为止能组成多少个"CO"子序列。每遇到一个 O，它都可以和**前面所有的 C** 配对，所以 `countCO += countC`。
- `countCOW`：到目前为止 COW 出现的总次数。每遇到一个 W，它都可以和**前面所有的 CO** 配对，所以 `countCOW += countCO`。

这样扫一遍就能得到答案。这个做法的正确性在于：每读到一个新字母，我们只关心它作为 COW 中"最后一个字母"能新组成多少，而这些数量恰好由前面已经统计好的前缀决定。
