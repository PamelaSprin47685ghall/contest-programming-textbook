# P3　扶正奶牛（Cow Tipping）

## 题目

农夫约翰的 $N^2$ 头奶牛原本排成一个 $N \times N$ 的正方形网格，但夜里被捣蛋的少年们掀翻了一些。约翰有一台机器“Cow-Untipperator 3000”，可以一次性翻转一大群奶牛。

机器只能作用于“左上角矩形”——也就是包含网格左上角那头牛的一个矩形子网格。对这样一个矩形，机器会把矩形里**每一头**牛都翻转：原本站着的被掀倒，原本倒着的被扶正。换句话说，矩形里每头牛的状态都被取反（0 变 1，1 变 0）。

请你算出：约翰最少要用多少次机器，才能把所有奶牛都扶正（全部变成 0）。

## 输入

第一行一个整数 $N$（$1 \le N \le 10$）。

接下来 $N$ 行，每行一个长度为 $N$ 的字符串，只含 `0` 或 `1`：`0` 表示站着的牛，`1` 表示倒着的牛。

## 输出

一个整数：最少需要的机器操作次数。

## 样例

输入：

```text
3
001
111
111
```

输出：

```text
2
```

解释：先对整个网格操作一次，变成：

```text
110
000
000
```

再对左上角那个含两个 `1` 的矩形操作一次，就全部变成 0 了。总共 2 次。

## 思路

机器每次操作都从左上角开始，覆盖一个矩形。想清楚一个关键事实：**右下角的牛只能被“以它为右下角”的那次翻转改变**，因为所有操作都包含左上角，而任何覆盖到右下角的矩形必然以它结尾。

于是从右下角往左上角逐个格子处理：

- 如果当前格子是 `1`（倒着），就必须对“从左上角到这个格子”的矩形操作一次，把它翻成 0；
- 操作之后，这个格子的右方和下方已经处理完、不会再被动到，所以这次操作不会破坏已经扶正的牛；
- 如果当前格子是 `0`，就不用管它，因为之后的操作（更靠左上）都不会碰到它。

这样从右下到左上贪心处理，每遇到一个 `1` 就翻转一次，得到的一定是最少次数。

## 复杂度

最多 $N^2$ 次操作，每次操作翻转一个矩形最多 $N^2$ 个格子，最坏时间 $O(N^4)$（$N \le 10$，完全够快）；空间 $O(N^2)$。
