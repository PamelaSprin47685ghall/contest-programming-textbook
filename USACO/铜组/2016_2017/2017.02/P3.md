# P3　奶牛为什么过马路 III（Why Did the Cow Cross the Road III）

## 题目

农夫约翰在农场入口设了一个大门，来参观的 $N$ 头奶牛只能从这个门依次进入，每头牛都要接受问话。同一时间只能有一头牛在接受问话。

每头奶牛告诉你两件事：她到达大门的时刻，以及接受问话需要的时间。如果很多牛几乎同时到达，后来的牛就得排队，等前面的牛问完才能开始。

请你算出：所有奶牛都能进入农场的最早时刻。

## 输入

第一行一个整数 $N$（$1 \le N \le 100$）。

接下来 $N$ 行，每行两个正整数：这头牛到达的时刻和问话所需时间（每个都不超过 1,000,000）。

## 输出

一个整数：所有奶牛都完成问话的最早时刻。

## 样例

输入：

```text
3
2 1
8 3
5 7
```

输出：

```text
15
```

解释：第一头牛时刻 2 到达，很快问完。大门空着，直到第三头牛时刻 5 到达开始问话。第二头牛时刻 8 到达，要等到 $5+7=12$ 才能开始，到 $12+3=15$ 结束。

## 思路

问话是串行的，所以处理顺序就是“谁先到谁先问”。先把奶牛按到达时刻排序。

维护一个变量 `finish`，表示“当前问话结束的时刻”。按到达顺序处理每头牛：

- 如果这头牛到达时，上一头已经问完（`finish <= 到达时刻`），那么她一到就能开始，`finish` 直接变成 `到达时刻 + 问话时间`；
- 如果她到达时上一头还没问完（`finish > 到达时刻`），她得排队等到 `finish`，所以 `finish` 变成 `finish + 问话时间`。

这两种情况可以统一写成：

$$\text{finish} = \max(\text{finish}, \text{到达时刻}) + \text{问话时间}$$

处理完所有牛后，`finish` 就是全部完成的最早时刻。
