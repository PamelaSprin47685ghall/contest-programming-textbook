# P2　奶牛洗牌（The Bovine Shuffle）

## 题目

Farmer John 想教奶牛跳一种叫“奶牛洗牌”的舞。$N$ 头奶牛排成一排，位置编号 $1$ 到 $N$。一次“洗牌”用 $N$ 个数 $a_1 \dots a_N$ 描述：位置 $i$ 上的奶牛在这次洗牌中会走到位置 $a_i$。所有 $a_i$ 各不相同，所以不会有两头奶牛抢同一个位置。

奶牛连续做**三次**洗牌。现在给你三次洗牌后的排列顺序（每头牛有一个 7 位 ID），请你推出三次洗牌**之前**的初始顺序。

## 输入

第一行一个整数 $N$（$1 \le N \le 100$）。

第二行是 $N$ 个整数 $a_1 \dots a_N$。

第三行是三次洗牌后按位置顺序排列的 $N$ 头奶牛的 ID。

## 输出

输出 $N$ 行，每行一头奶牛的 ID，表示三次洗牌前的初始顺序。

## 样例

输入：

```text
5
1 3 4 5 2
1234567 2222222 3333333 4444444 5555555
```

输出：

```text
1234567
5555555
2222222
3333333
4444444
```

## 思路

先想清楚“洗牌”的方向：一次洗牌把**位置 $i$** 的牛送到**位置 $a_i$**。也就是说，如果一头牛初始在位置 $i$，做一次洗牌后它到了 $a_i$，再做一次又到 $a_{a_i}$，三次之后它到了 $a_{a_{a_i}}$。

题目给的是三次洗牌**之后**的顺序，所以反过来想：初始在位置 $i$ 的那头牛，就是三次洗牌后站在位置 $a_{a_{a_i}}$ 的那头牛。

于是做法很简单：对每个初始位置 $i$，沿着 $a$ 数组连续跳三次，得到一个最终位置，把那个位置上的 ID 输出即可。这里用一个数组 `shuffleTo` 存 $a$（下标从 0 开始），用循环“跳三次”代替三次洗牌，逻辑和题目描述一一对应。
