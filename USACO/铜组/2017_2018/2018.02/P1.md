# P1　粪便传送器（Teleportation）

## 题目

Farmer John 最讨厌的农活之一就是用车搬运大量牛粪。他发明了一个“粪便传送器”：把牛粪带到位置 $x$，就能瞬间传送到位置 $y$（反过来从 $y$ 传到 $x$ 也行）。

John 要把牛粪从位置 $a$ 运到位置 $b$。传送器可能有用也可能没用。请你算出他需要**用拖拉机搬运**的最小总距离。

## 输入

一行四个整数 `a b x y`：`a`、`b` 是起点和终点，`x`、`y` 是传送器的两个端点。所有位置都是 0 到 100 的整数，彼此可能相同。

## 输出

一个整数：John 用拖拉机搬运的最小总距离。

## 样例

输入：

```text
3 10 8 2
```

输出：

```text
3
```

解释：最好的办法是把牛粪从 3 拖到 2，传送器传到 8，再拖到 10。拖拉机总距离是 $1 + 2 = 3$。

## 思路

先想：一共有三种可能的走法，分别算一下距离取最小即可：

1. **不用传送器**：直接从 $a$ 拖到 $b$，距离是 $|a-b|$；
2. **正着用**：从 $a$ 拖到 $x$，传送器传到 $y$，再拖到 $b$，距离是 $|a-x| + |y-b|$；
3. **反着用**：从 $a$ 拖到 $y$，传到 $x$，再拖到 $b$，距离是 $|a-y| + |x-b|$。

因为传送器是瞬间的，中间那一段不花拖拉机距离。把三种走法的距离都算出来，取最小值即可。这里用 `std::abs` 算绝对值，`std::min` 取最小值，代码很短。
