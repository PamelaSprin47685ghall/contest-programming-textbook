# P3　驯服牛群（Taming the Herd）

## 题目

奶牛们又撞破牛棚逃跑了。Farmer John 在牛棚墙上钉了一个计数器，记录“距上次逃跑的天数”：如果某天早上发生了逃跑，那天计数器是 0；如果最近一次逃跑是 3 天前，计数器就显示 3。John 每天都会记录这个计数器的读数。

但有些天的记录**丢失了**。John 确定自己是从一次逃跑的那天开始记录的（即第 1 天一定发生了逃跑）。请你算出：在所有与现有记录一致的事件序列中，逃跑次数**最少**和**最多**分别是多少。

## 输入

第一行一个整数 $N$（$1 \le N \le 100$），表示记录的天数。

第二行 $N$ 个整数：第 $i$ 个整数如果是 $-1$，表示第 $i$ 天的记录丢失；否则是一个不超过 100 的非负整数，表示当天计数器的读数。

## 输出

如果没有任何事件序列和现有记录一致（且第 1 天确实发生逃跑），输出一个整数 `-1`。

否则输出两个空格隔开的整数 `m M`，分别是最少和最多的逃跑次数。

## 样例

输入：

```text
4
-1 -1 -1 1
```

输出：

```text
2 3
```

解释：可以推出第 3 天一定发生了一次逃跑。已知第 1 天也有一次，唯一不确定的是第 2 天有没有逃跑。所以总次数在 2 到 3 之间。

## 思路

先想：计数器的规律是——逃跑那天是 0，之后每天 +1，直到下一次逃跑又变回 0。所以从后往前推会很清楚：如果知道某天是逃跑日，那么它后面的日子数字依次是 0、1、2、3……

做法是从最后一天往前扫描，维护一个 `current` 表示“当前正在倒数的距上次逃跑的天数”：

- 如果 `current` 不为 -1，说明前面某天发生过逃跑，先把 `current` 减一（表示往前推一天）；
- 当 `current` 变成 -1 时，说明前一段结束，从这一天的读数重新开始倒数；
- 如果当天记录未知（-1），就用推导出的 `current` 补上；
- 如果当天有记录但和 `current` 不一致，说明矛盾，输出 -1。

第 1 天必须发生逃跑，所以如果第 1 天的读数不是 0 就矛盾。推完后，读数为 0 的天是**必须逃跑**的日子，读数为 -1（仍未知）的天是**可逃可不逃**的日子。所以最少次数 = 必须逃跑的天数，最多次数 = 必须 + 可选的天数。
