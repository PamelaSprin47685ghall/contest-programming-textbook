# P2　挤奶桶需求（The Bucket List）

## 题目

农夫约翰有 $N$ 头奶牛（$1 \le N \le 100$），编号为 $1 \dots N$。每头牛都有专属的挤奶时间段：第 $i$ 头牛从时间 $s_i$ 开始挤奶，到时间 $t_i$ 结束，且挤奶过程中全程需要占用 $b_i$ 个桶。

不同的奶牛可以在不同时间复用同一个桶。也就是说，如果某头牛在时间 $t$ 结束了挤奶，那么它使用的桶可以在时间 $t$ 立即归还，并供其他牛在随后的时间（或同一时刻）使用。

请计算约翰为了顺利完成所有挤奶工作，最少需要准备多少只桶。

## 输入

第一行一个整数 $N$。
接下来 $N$ 行，每行三个整数 $s_i, t_i, b_i$，表示第 $i$ 头牛的挤奶起始时间、结束时间以及所需桶数。
数据保证 $1 \le s_i < t_i \le 1000$，$1 \le b_i \le 10$。

## 输出

一个整数，表示最少需要的桶的总数。

## 样例

输入：

```text
3
4 10 1
8 13 3
2 6 2
```

输出：

```text
4
```

## 思路

每头牛在区间 $[s_i, t_i]$ 期间持续占用 $b_i$ 个桶。不同时间段桶可以重复使用，因此约翰在任何时刻手头需要的桶数，等于该时刻所有正在挤奶的牛所占用的桶数之和。

全天所需的最少桶数，就等于所有时刻中“瞬时桶需求量”的最大值。

时间范围 $1 \le s_i < t_i \le 1000$ 很小，可以直接开一个大小为 1001 的数组记录时间点：
1. 对每头牛，将其对应时间区间 $[s_i, t_i]$ 内的每个整数时刻都累加 $b_i$。
2. 遍历整个时间轴，统计每个时刻的桶需求，取最大值输出。

## 复杂度

外层循环 $N$ 次，内层遍历时间区间长度（不超过 $1000$）。总时间复杂度为 $O(N \times \max(T))$，空间复杂度为 $O(\max(T))$，其中 $\max(T) = 1000$，能够瞬时完成。
