# P2　贪睡牛排队（Sleepy Cow Sorting）

## 题目

农夫约翰的 $N$ 头奶牛（$1 \le N \le 100$）排成一队准备进谷仓。每头牛身上贴着专属编号 $1 \dots N$，构成一个 $1 \dots N$ 的排列。

现在队伍是乱序的。约翰可以按如下规则进行单步排序：
- 每次取出队伍**最前面**的那头牛；
- 将它插入到队伍中往后数任意位置 $k$（只要保持其他牛的相对顺序不变）。

请计算：最少需要操作多少次，才能使整支队伍从左到右按编号 $1 \dots N$ 严格升序排好？

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个空格隔开的整数，表示当前队伍从队首到队尾各个奶牛的编号。

## 输出

一个整数，表示最少所需的操作步数。

## 样例

输入：

```text
4
1 2 4 3
```

输出：

```text
3
```

## 思路

每次操作只能将最左边的牛插入到后面的某个位置。
观察末尾的若干头牛：如果末尾的一段连续子序列已经是有序升序的（例如 $a_k < a_{k+1} < \dots < a_n$），那么前方的任何一头牛，只要拿出来，都可以恰好插入到这段有序后缀的合适位置中，使得有序后缀的长度增加 1。

但是，只要后缀不是单调上升的，中间倒序的那对相邻元素就不可能在不被拆散移动的情况下变成有序。
因此，最终不需要移动的元素，最多只能是原序列最长的一段连续升序后缀。
其余所有位于该后缀之前的牛都必须被依次移动一次。答案即为 $N$ 减去最长升序后缀的长度。

只需从数组倒数第二位向前线性扫描一次，时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。
