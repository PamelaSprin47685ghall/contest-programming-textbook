# P1　困倦牛赶集（Sleepy Cow Herding）

## 题目

数轴上有 3 头奶牛，位置分别位于互不相同的整数坐标 $a, b, c$ 处。

每次操作，约翰可以选出处于**两端**的某一头奶牛（即坐标最小或最大的牛），将其移动到另外两头牛**之间**的任意一个尚未被占据的整数坐标处。

当三头奶牛占据三个连续的整数位置时（即 $x, x+1, x+2$），游戏结束。

请分别求出游戏结束所需的最少操作步数与最多操作步数。

## 输入

一行包含三个空格隔开的整数 $a, b, c$，表示三头牛的初始坐标（$1 \le a, b, c \le 10^9$）。

## 输出

输出两行，每行一个整数：
- 第一行为最少步数；
- 第二行为最多步数。

## 样例

输入：

```text
4 7 9
```

输出：

```text
1
2
```

## 思路

先将三头牛的坐标从小到大排序为 $p_0 < p_1 < p_2$。

**最少步数分析**：
1. 若三头牛本来就已经紧挨着（$p_0+1=p_1$ 且 $p_1+1=p_2$），不需要任何移动，步数为 $0$；
2. 若某相邻两头牛之间恰好隔着 1 个空格（即 $p_1 - p_0 = 2$ 或 $p_2 - p_1 = 2$），我们只需将外侧的那头牛直接移动到这个空格中，只需 $1$ 步即可连续；
3. 其余情况下，两步必然可以完成（第一步将端点移到距中间牛为 2 的位置，第二步移入空格），故最少步数为 $2$。

**最多步数分析**：
两端牛往中间移时，每一次操作至少会使得外侧的一个间隙减少 1 格。
为了让操作步数尽可能多，第一步应该保留两个间隙中较大的那一个（即 $\max(p_1-p_0, p_2-p_1)$），将另一侧的端点牛移动到离中间牛距离为 1 的位置。此后，每次只需将远端牛前进一步，直到大间隙全部耗尽。
因此，最多步数等于 $\max(p_1 - p_0 - 1, p_2 - p_1 - 1)$。
