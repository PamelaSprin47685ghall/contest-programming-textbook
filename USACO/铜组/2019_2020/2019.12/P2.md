# P2　我在哪？（Where Am I?）

## 题目

农夫约翰沿着马路修建了 $N$ 间邮箱（$1 \le N \le 100$），并给每间邮箱涂上了某种颜色（用单个大写字母表示），连起来构成一个长度为 $N$ 的字符串 $S$。

约翰经常散步，但他方向感不好。为了知道自己当前站在哪个位置，他会观察他身旁连续的 $K$ 个邮箱的颜色序列。

为了保证无论他站在哪一段连续的 $K$ 个邮箱前，看到的颜色组合在整条马路上都是**独一无二**的（即该子串在整个字符串中只出现过恰好一次），$K$ 至少需要多大？

请计算能够唯一标识位置的最小正整数 $K$。

## 输入

第一行一个整数 $N$。
第二行一个长度为 $N$ 的大写字母字符串。

## 输出

一个整数，表示满足条件的最小正整数 $K$。

## 样例

输入：

```text
7
ABCDABC
```

输出：

```text
4
```

## 思路

我们要寻找最小的长度 $K$，使得整个字符串中所有长度为 $K$ 的连续子串彼此互不相同。

因为 $N \le 100$ 较小，我们可以从小到大枚举长度 $K = 1, 2, \dots, N$：
1. 对于当前尝试的 $K$，截取字符串中所有可能的长度为 $K$ 的连续子串 $S[i \dots i+K-1]$；
2. 用集合（哈希表）来检查这些子串中是否存在重复项；
3. 如果全部子串都互不相同，则当前 $K$ 就是满足条件的最小值，直接输出并结束程序。

## 复杂度

外层枚举 $K \le N$，内层提取约 $N$ 个长度为 $K$ 的子串并存入哈希表。总时间复杂度为 $O(N^3)$（或利用滚动哈希优化至更优，但 $N \le 100$ 下暴力截取耗时仅数毫秒）。空间复杂度为 $O(N^2)$。
