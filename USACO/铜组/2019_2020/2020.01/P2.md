# P2　拍照还原（Photoshoot）

## 题目

农夫约翰原计划按 $a_1, a_2, \dots, a_N$ 的排列给 $N$ 头牛拍照（$2 \le N \le 1000$），其中 $a$ 是 $1 \dots N$ 的一个全排列。

但是他把写着排列的纸片弄丢了。幸运的是，贝茜提前记下了长度为 $N-1$ 的相邻和序列：$b_i = a_i + a_{i+1}$（对于 $1 \le i < N$）。

请根据序列 $b$，还原出原始排列 $a$。如果有多种符合条件的排列，输出**字典序最小**的那一个。题目保证至少存在一个合法解。

## 输入

第一行一个整数 $N$。
第二行包含 $N-1$ 个整数 $b_1, b_2, \dots, b_{N-1}$。

## 输出

一行包含 $N$ 个由空格隔开的整数，表示字典序最小的排列 $a$。

## 样例

输入：

```text
5
4 6 7 6
```

输出：

```text
3 1 5 2 4
```

## 思路

注意由于 $b_i = a_i + a_{i+1}$，只要确定了第一项 $a_1$，整条序列 $a_2, a_3, \dots, a_N$ 就被**唯一线性递推决定**：$a_{i+1} = b_i - a_i$。

为了获得字典序最小的解，我们只需从小到大枚举 $a_1 = 1, 2, \dots, N$：
1. 假定第一项为 $a_1$，依序推导后续各元素 $a_{i+1}$；
2. 递推过程中判断 $a_{i+1}$ 是否在 $[1, N]$ 范围内且未曾出现过；
3. 如果推导出的整个长度为 $N$ 的序列恰好是 $1 \dots N$ 的无重复排列，那么这个序列必定就是合法解中字典序最小的一个，直接输出并终止程序即可。

## 复杂度

枚举第一项有 $N$ 种可能，每次线性验证 $N$ 个数，时间复杂度为 $O(N^2)$。当 $N = 1000$ 时，$N^2 = 10^6$，在 0.01 秒内即可完成。空间复杂度为 $O(N)$。
