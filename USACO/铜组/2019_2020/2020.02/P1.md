# P1　三角形牧场（Triangles）

## 题目

农夫约翰想在农场中用三根栅栏柱围成一个直角三角形的牧场。
农场中有 $N$ 根柱子（$3 \le N \le 100$），每根柱子位于互不相同的整数坐标 $(X_i, Y_i)$ 处。

三角形必须满足如下条件：
- 其中一条直角边平行于 $x$ 轴；
- 另一条直角边平行于 $y$ 轴。

请找出能够围成的最大直角三角形牧场。题目保证至少存在一个满足条件的直角三角形。由于三角形的面积可能包含小数部分，请输出**最大面积的 2 倍**（$2 \times \text{Area}$，必定为整数）。

## 输入

第一行一个整数 $N$。
接下来 $N$ 行，每行两个整数 $X_i, Y_i$（$-10^4 \le X_i, Y_i \le 10^4$）。

## 输出

一个整数，表示合法直角三角形最大可能面积的 2 倍。

## 样例

输入：

```text
4
0 0
0 1
1 0
1 2
```

输出：

```text
2
```

## 思路

任何一个两条直角边分别平行于 $x$ 轴和 $y$ 轴的直角三角形，其直角顶点 $i$ 必定与另一个顶点 $j$ 具有相同的纵坐标（$Y_i = Y_j$），且与第三个顶点 $k$ 具有相同的横坐标（$X_i = X_k$）。
此时，三角形面积的两倍恰好就是两个直角边长的乘积：
$$2 \times \text{Area} = |X_j - X_i| \times |Y_k - Y_i|$$

因为 $N \le 100$，柱子总数极少：
我们直接使用三重循环枚举直角顶点 $i$、同横线顶点 $j$ 以及同竖线顶点 $k$，检查是否满足 $Y_j = Y_i$ 且 $X_k = X_i$。在所有满足条件的组合中，计算两倍面积并取最大值输出。

## 复杂度

三重循环枚举三点组合，时间复杂度为 $O(N^3)$。当 $N = 100$ 时，$N^3 = 10^6$，在 0.01 秒内完成。空间复杂度为 $O(N)$。
