# P2　科学怪牛（Mad Scientist）

## 题目

农夫约翰订购了 $N$ 头奶牛（$1 \le N \le 1000$），品种包含荷斯坦牛（H）与娟姗牛（G），对应字符串 $A$。
当奶牛送到农场时，他发现它们的实际品种排布成了另一个字符串 $B$。

为了把字符串 $B$ 纠正为目标字符串 $A$，约翰借用了一台机器：
每次操作可以选择 $B$ 中任意一段连续子串，将其中的所有品种进行翻转（即将该子串中所有的 `H` 变成 `G`，所有的 `G` 变成 `H`）。

请计算约翰最少需要操作多少次机器，才能把字符串 $B$ 变成字符串 $A$？

## 输入

第一行一个整数 $N$。
第二行长度为 $N$ 的字符串 $A$。
第三行长度为 $N$ 的字符串 $B$。

## 输出

一个整数，表示将 $B$ 变为 $A$ 所需的最少操作次数。

## 样例

输入：

```text
7
GHHHGHH
HHGGGHH
```

输出：

```text
2
```

## 思路

对比字符串 $A$ 和 $B$ 的每一位：
如果 $A[i] = B[i]$，该位置已经正确，不需要翻转；
如果 $A[i] \neq B[i]$，该位置必须被翻转奇数次。

每次机器操作可以将一个连续区间全量翻转。显然，任何一次翻转操作都应该尽可能包含一段连续的不匹配字符，并且绝不应该跨过原本就已经匹配正确的位置（否则会把正确的位置反转成错误的，后续还需要再耗费操作纠正）。
因此，最优策略一定是：**将每一个极长的不匹配连续段分别使用 1 次机器操作进行全量翻转**。

所以最少操作次数就等于两字符串不同字符所构成的极长连续块的数量。
只需线性扫描一次字符串，维护一个布尔标志 `inMismatch`：每当进入一个新的不匹配区间时，计数器加 1。

## 复杂度

只需线性遍历一遍长度为 $N$ 的字符串，时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。
