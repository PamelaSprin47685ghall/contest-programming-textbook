# P2　雏菊花环（Daisy Chains）

## 题目

小路上排列着 $N$ 朵雏菊（$1 \le N \le 100$），从左到右编号为 $1 \dots N$。第 $i$ 朵雏菊的花瓣数为 $p_i$（$1 \le p_i \le 1000$）。

贝茜拍摄了所有的连续花朵区间。也就是说，对于每一对满足 $1 \le i \le j \le N$ 的下标对 $(i, j)$，她都拍下了一张包含第 $i$ 朵到第 $j$ 朵花的照片。

如果某张照片中包含的所有花的花瓣数的**精确算术平均值**等于这张照片中的某一朵花的花瓣数，这张照片就被称为拥有“平均花”。

请计算所有可能拍摄的照片中，有多少张照片拥有“平均花”？

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个整数 $p_1, \dots, p_N$。

## 输出

一个整数，表示拥有“平均花”的照片总数。

## 样例

输入：

```text
4
1 1 2 3
```

输出：

```text
6
```

## 思路

照片总数等于子区间的数量 $\frac{N(N+1)}{2}$，在 $N \le 100$ 时不超过 $5050$ 张。

我们可以直接使用双重循环枚举所有照片区间 $[i, j]$：
1. 维护区间花瓣总和 `sum` 与花朵数量 `count = j - i + 1`；
2. 如果 `sum` 不能被 `count` 整除，平均值包含小数，而花瓣数均为整数，不可能存在平均花；
3. 如果 `sum` 可以整除 `count`，算出平均值 $\text{avg} = \text{sum} / \text{count}$，随后遍历该区间 $[i, j]$ 内的所有花朵，判断是否存在某朵花满足 $p_k = \text{avg}$；
4. 若存在，合法照片计数加 1。

## 复杂度

枚举区间对 $(i, j)$ 耗时 $O(N^2)$，内部查找平均花耗时 $O(N)$。总时间复杂度为 $O(N^3)$。当 $N = 100$ 时，$N^3 = 10^6$，在 0.01 秒内即可完成。空间复杂度为 $O(N)$。
