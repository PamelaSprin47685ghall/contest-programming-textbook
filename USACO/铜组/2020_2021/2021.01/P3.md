# P3　进退维谷（Just Stalling）

## 题目

农夫约翰有 $N$ 头奶牛（$1 \le N \le 20$），它们的身高分别为 $a_1, \dots, a_N$。
牛棚有 $N$ 个隔间，每个隔间有最大高度限制 $b_1, \dots, b_N$。如果 $a_i \le b_j$，则牛 $i$ 可以进入隔间 $j$。

请问约翰一共有多少种不同的分配方案，使得每头奶牛独占一个不同的隔间，且每头牛的身高均不超过其所在隔间的最大高度限制？

答案可能超出 32 位整数范围，请使用 64 位整数（C++ 中的 `long long`）。

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个整数 $a_1, \dots, a_N$。
第三行包含 $N$ 个整数 $b_1, \dots, b_N$（高度和限制均在 $[1, 10^9]$ 范围内）。

## 输出

一个整数，表示合法的安排方案总数。

## 样例

输入：

```text
4
1 2 3 4
2 4 3 4
```

输出：

```text
8
```

## 思路

经典受限匹配计数问题。关键在于处理顺序：
如果我们**从最高的身高最高的牛开始考虑**：
- 设当前奶牛为第 $i$ 高的牛（从 0 开始计数，前面已经有 $i$ 头更高的牛做好了安排）；
- 我们统计所有牛棚中高度限制 $\ge a_i$ 的牛棚总数，记为 $C$；
- 注意到：前面被安置的 $i$ 头牛比当前这头牛都要高，所以那 $i$ 头牛所占据的牛棚的高度限制也必然满足 $\ge a_i$！
- 换句话说，前面安排的 $i$ 头牛所占用的隔间集合，完全是这 $C$ 个能够容纳当前牛的隔间集合的子集；
- 因此，当前这头牛可供挑选的空余隔间数量恰好就是 $C - i$ 个，与前面具体选了哪一个无关！

由乘法原理，总方案数即为各步可选数量的乘积：
$$\prod_{i=0}^{N-1} (C_i - i)$$

## 复杂度

排序耗时 $O(N \log N)$，依次统计合法隔间数耗时 $O(N^2)$。由于 $N \le 20$，计算步数极小，耗时小于 1 毫秒。时间复杂度为 $O(N^2)$，空间复杂度为 $O(N)$。
