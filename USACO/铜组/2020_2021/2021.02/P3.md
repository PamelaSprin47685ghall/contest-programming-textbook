# P3　顺时针栅栏（Clockwise Fence）

## 题目

农夫约翰围绕他的牧场修建了一圈栅栏。栅栏是一条闭合路径，起点与终点重合，且除了起点与终点外路径绝不自交。

栅栏的走向可以用只包含四个字母 `N`（北）、`E`（东）、`S`（南）、`W`（西）的字符串描述。每一步沿对应方向行进 1 米。

请判断整个栅栏在围成多边形时，是按照**顺时针方向**（CW）围成的，还是按照**逆时针方向**（CCW）围成的。

## 输入

第一行包含一个整数 $N$（$1 \le N \le 20$），表示测试用例的数量。
接下来 $N$ 行，每行包含一个描述单圈闭合栅栏路径的非空字符串（长度不超过 100）。

## 输出

对每个测试用例输出一行：若为顺时针则输出 `CW`，若为逆时针则输出 `CCW`。

## 样例

输入：

```text
2
NESW
WSSSEEEWNNNESWWN
```

输出：

```text
CW
CCW
```

## 思路

任何一条无自交的封闭多边形简单曲线，在沿着方向绕行一周时，拐角累计变化的总角度具有固定拓扑性质：
- 沿着顺时针方向绕行一周，总转弯角度和必定恰好等于 $+360^\circ$；
- 沿着逆时针方向绕行一周，总转弯角度和必定恰好等于 $-360^\circ$。

在网格四个朝向中：
- 从当前方向到下一个方向，如果是**向右转**（如 `N -> E`，`E -> S`，`S -> W`，`W -> N`），代表顺时针转弯，转角记为 $+90^\circ$；
- 如果是**向左转**（如 `N -> W`，`W -> S`，`S -> E`，`E -> N`），代表逆时针转弯，转角记为 $-90^\circ$；
- 直行不产生角度变化。

我们只需将首尾相连循环计算相邻两步之间的转角代数和，如果总和大于 0 即为顺时针（`CW`），否则为逆时针（`CCW`）。

## 复杂度

每个字符串遍历一遍，时间复杂度为 $O(L)$，其中 $L \le 100$。总时间复杂度为 $O(NL)$，空间复杂度为 $O(L)$。
