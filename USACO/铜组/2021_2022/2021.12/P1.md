# P1　孤独的照片（Lonely Photo）

## 题目

农夫约翰新买了 $N$ 头奶牛（$3 \le N \le 5 \times 10^5$），每头牛的品种为娟姗牛（G）或荷斯坦牛（H）。

奶牛们排成一行，约翰想给每一个长度不小于 3 的连续奶牛子段拍摄一张照片。
如果某张照片中**恰好只有一头**娟姗牛，或者**恰好只有一头**荷斯坦牛，由于这头唯一的奶牛会感到孤单与不合群，约翰会把这张照片称为“孤独的照片”并扔掉。

请帮助约翰计算出他一共会扔掉多少张“孤独的照片”。两个子段只要起点或终点不同即视为不同的照片。

## 输入

第一行一个整数 $N$。
第二行一个长度为 $N$ 的字符串，由字符 `G` 和 `H` 组成。

## 输出

一个整数，表示会被扔掉的孤独照片总数。结果可能超出 32 位整数，请使用 64 位整数（`long long`）。

## 样例

输入：

```text
5
GHGHG
```

输出：

```text
3
```

## 思路

任何一张孤独的照片中，必定存在唯一一头与众不同的牛（记为位置 $i$），照片中其余所有的牛都是另一种品种。
因此，我们可以换位思考：**枚举每一头牛 $i$，计算它作为照片中“唯一孤单牛”时，能形成多少张不同的合法照片**。

设位置 $i$ 的牛品种为 $X$：
- 考察它左边紧邻的连续非 $X$ 牛（全为 $Y$）的数量 $L$；
- 考察它右边紧邻的连续非 $X$ 牛（全为 $Y$）的数量 $R$；

包含牛 $i$ 且内部只有它一头 $X$、其余全为 $Y$ 的连续区间有三种情况：
1. **牛 $i$ 处于照片中间**：左侧取 $1 \dots L$ 头，右侧取 $1 \dots R$ 头。任何这样的区间总长度都至少为 $1 + 1 + 1 = 3$，方案数为 $L \times R$；
2. **牛 $i$ 处于照片最左端**：左侧取 0 头，右侧至少需要取 2 头（以满足照片长度 $\ge 3$），右端点可选范围是 $2 \dots R$，方案数为 $\max(0, R - 1)$；
3. **牛 $i$ 处于照片最右端**：右侧取 0 头，左侧至少需要取 2 头，左端点可选范围是 $2 \dots L$，方案数为 $\max(0, L - 1)$。

预处理出每个位置的 $L$ 和 $R$，累加所有位置的贡献即为答案。

## 复杂度

线性扫描计算 $L$ 与 $R$ 数组耗时 $O(N)$，随后单次线性累加耗时 $O(N)$。时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。在 $N = 5 \times 10^5$ 时耗时约 0.05 秒。
