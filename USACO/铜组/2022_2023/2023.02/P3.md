# P3　观看 Mooloo（Watching Mooloo）

## 题目

贝茜计划在未来的 $N$ 个指定日子里观看 Mooloo 视频网站的节目（$1 \le N \le 10^5$），观看日期分别为 $d_1 < d_2 < \dots < d_N$（$1 \le d_i \le 10^{14}$）。

Mooloo 的订阅计费规则如下：连续订阅 $d$ 天需要支付 $d + K$ 个虚拟币（$1 \le K \le 10^9$）。贝茜可以随时开始订阅，也可以订阅多次。

请计算贝茜为了满足这 $N$ 天的观看计划，最少需要支付的总金额。注意数值较大，请使用 64 位整数。

## 输入

第一行包含两个整数 $N$ 和 $K$。
第二行包含 $N$ 个递增的整数 $d_1, \dots, d_N$。

## 输出

一个整数，表示最少需要的总花销。

## 样例

输入：

```text
2 4
7 9
```

输出：

```text
7
```

## 思路

任何一次连续的订阅都可以看作由基础费用 $K$ 和持续天数按天累计的每天 1 块钱组成。

我们在第 $d_1$ 天必须花费 $1 + K$ 开启第一次订阅。
此后，对于相邻的两个观看日 $d_{i-1}$ 和 $d_i$：
贝茜有两种选择：
1. **连续订阅**：不中断订阅，覆盖中间的空白日子，额外花费天数差 $d_i - d_{i-1}$ 个虚拟币；
2. **断开重开**：中断前一次订阅，在第 $d_i$ 天重新开启一次新的订阅，需要重新支付开台费 $K$ 并支付该天本身的 1 块钱，额外花费 $1 + K$ 个虚拟币。

显然，贪心策略就是在每相邻两个观看日之间，选取这两种方案的较小值：
$$\min(d_i - d_{i-1}, 1 + K)$$
将每次转移的最小增量累加到总费用中即为最优解。

只需一次遍历长度为 $N$ 的数组，时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。在 $N = 10^5$ 时耗时约 0.01 秒。
