# P3　旋转与移位（Rotate and Shift）

## 题目

$N$ 头奶牛（编号 $0 \dots N-1$，$1 \le N \le 2 \times 10^5$）围成一个圆圈，位置顺时针编号为 $0 \dots N-1$。初始时，奶牛 $i$ 位于位置 $i$ 处。

给出 $K$ 个递增的“活跃位置” $0 = A_1 < A_2 < \dots < A_K < N$。

每一分钟进行两步操作：
1. **活跃位置轮转**：处于活跃位置的奶牛顺时针轮转（$A_1$ 处的牛走到 $A_2$，$A_2$ 处的牛走到 $A_3$，……，$A_K$ 处的牛走到 $A_1$）；
2. **活跃位置整体前移**：每个活跃位置顺时针前移 1 格（即 $A_i$ 变为 $(A_i + 1) \bmod N$）。

请计算经过 $T$ 分钟后（$1 \le T \le 10^9$），从位置 0 开始顺时针依次排列的每头奶牛的编号。

## 输入

第一行三个整数 $N, K, T$。
第二行包含 $K$ 个整数 $A_1, A_2, \dots, A_K$。

## 输出

一行输出 $N$ 个空格隔开的整数，表示最终位于位置 $0, 1, \dots, N-1$ 的奶牛编号。

## 样例

输入：

```text
5 3 4
0 2 3
```

输出：

```text
1 2 3 4 0
```

## 思路

如果直接模拟 $T$ 步，时间复杂度为 $O(KT)$，在 $T = 10^9$ 时无法通过。
但是从相对坐标的角度分析：
由于活跃位置集合 $A$ 每分钟都一致向右平移 1 格，我们如果切换到**随活跃位置以恒定速度 1 旋转的参考系**：
- 任何处于相邻两个活跃点区间 $[A_i, A_{i+1})$ 中的奶牛，初始时相对于左端活跃点 $A_i$ 的偏移距离为 $dist = j - A_i$；
- 只有当旋转的活跃点“追上”这头牛（即过去 $dist$ 分钟后），该牛才会首次触发轮转，跳到下一个活跃点区间；
- 随后，每经过间隔周期 $A_{i+1} - A_i$ 分钟，该牛就会再次被轮转一次，跳往下一个活跃位置；
- 因此，总共触发跳跃的次数可以直接用公式计算：
  $$\text{jumps} = 1 + \lfloor \frac{T - dist - 1}{A_{i+1} - A_i} \rfloor \quad (T > dist)$$
- 最终奶牛到达的目标活跃点索引为 $(i + \text{jumps} - 1) \bmod K + 1$；
- 再加上它相对于活跃点的初始相对偏移 $dist$，以及随参考系旋转的全局位移 $T$，即可在 $O(1)$ 时间内直接算出每头牛的最终绝对位置！

## 复杂度

对全部 $N$ 头奶牛各使用常数次算术运算直接计算最终位置，时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。在 $N = 2 \times 10^5$ 时耗时约 0.03 秒。
