# P2　炮弹（Cannonball）

## 题目

数轴上有 $N$ 个位置（编号 $1 \dots N$，$1 \le N \le 10^5$），贝茜被装在炮弹里在数轴上弹跳。初始位置为 $S$（$1 \le S \le N$），初始威力为 1，初始方向为向右。

每个位置可能是：
- 跳板（type=0）：将贝茜的反弹方向取反，并将弹跳威力增加 $v$；
- 目标（type=1）：若贝茜当前弹跳威力大于等于该目标的阻力 $v$，目标被击碎（击碎后仍然保留在原地，但不消耗威力）。

每次贝茜在当前格子触发事件后，会沿着当前方向前进当前威力的距离。若飞出 $[1, N]$ 范围，运动结束。
请计算贝茜总共击碎了多少个不同的目标。

## 输入

第一行两个整数 $N$ 和 $S$。
接下来 $N$ 行，每行两个整数描述位置 $i$ 的类型和属性值 $v$。

## 输出

一个整数，表示被击碎的不同目标总数。

## 样例

输入：

```text
5 2
0 1
1 1
1 2
0 1
1 1
```

输出：

```text
1
```

## 思路

由于威力的增加是单调累加的，每遇到一次跳板威力就会上升。
一旦威力变得较大，贝茜在数轴上弹跳几步就会直接越界飞出。
唯一的循环情况是威力始终为 0 并在两个位置反复震荡（或者跳板威力为 0）。
因此，总有效步数非常有限。我们直接进行朴素模拟，设置安全步数上限（如 $5 \times 10^6$），一旦越界或超时跳出循环，统计击碎的目标总数即可。
