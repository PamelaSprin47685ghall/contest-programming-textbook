# P2　沿着栅栏走（Walking Along a Fence）

## 题目

农夫约翰的栅栏由 $P$ 根柱子（$4 \le P \le 2 \times 10^5$）围成一个封闭多边形，柱子之间由水平或垂直的栅栏相连。所有柱子的坐标都在 $[0, 1000]$ 范围内。

有 $N$ 头奶牛（$1 \le N \le 2 \times 10^5$）位于栅栏上的某些整数坐标处。第 $i$ 头奶牛想沿着栅栏从 $(x_{1,i}, y_{1,i})$ 走到 $(x_{2,i}, y_{2,i})$。
因为栅栏是闭合环路，奶牛可以顺时针或逆时针沿着栅栏行走。

请针对每头奶牛，求出沿着栅栏从起点到终点所需行走的**最短距离**。

## 输入

第一行两个整数 $N$ 和 $P$。
接下来 $P$ 行，每行两个整数描述按顺序排列的每根柱子的坐标 $(x_i, y_i)$。
接下来 $N$ 行，每行四个整数 $x_1, y_1, x_2, y_2$，描述每头牛的起点和终点（保证在栅栏上）。

## 输出

输出共 $N$ 行，每行一个整数，表示对应奶牛的最短距离。

## 样例

输入：

```text
3 4
0 0
0 100
100 100
100 0
0 0 0 100
0 0 100 100
0 50 50 100
```

输出：

```text
100
200
100
```

## 思路

坐标范围非常小：所有坐标都在 $[0, 1000]$ 之间。栅栏总周长不超过 $4000$！

我们可以直接开一个 $1001 \times 1001$ 的数组 `posOnFence[x][y]`：
1. 沿着 $P$ 根柱子顺序走完整个闭合多边形周长，将栅栏上的每个整点标记为其在周长上的累计距离编号 $0, 1, 2, \dots, L-1$；
2. 对于每头牛的起点 $(x_1, y_1)$ 和终点 $(x_2, y_2)$，直接 $O(1)$ 查表获得它们在周长上的距离坐标 $d_1$ 和 $d_2$；
3. 两点之间的距离即为环形两端距离的较小值：
   $$\min(|d_1 - d_2|, L - |d_1 - d_2|)$$

## 复杂度

遍历栅栏周长打表耗时 $O(L)$（$L \le 4000$）。回答每个询问耗时 $O(1)$。总时间复杂度为 $O(P + L + N)$，空间复杂度为 $O(1000^2) = O(1)$。在 $N = 2 \times 10^5$ 时耗时约 0.05 秒。
