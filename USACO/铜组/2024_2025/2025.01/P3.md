# P3　奶牛体检（Cow Checkups）

## 题目

有 $N$ 头奶牛（$1 \le N \le 10^5$），每头牛有一个原始编号数组 $a_1, \dots, a_N$ 和目标编号数组 $b_1, \dots, b_N$。

对于所有可能的区间 $[l, r]$（$1 \le l \le r \le N$），约翰尝试反转子段 $a[l \dots r]$。
反转后，如果某个位置满足 $a[i] = b[i]$，就称该位置匹配成功。

对于每个可能的匹配数 $k \in [0, N]$，请统计共有多少个区间 $[l, r]$ 反转后恰好能使得匹配数量等于 $k$。

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个整数 $a_1, \dots, a_N$。
第三行包含 $N$ 个整数 $b_1, \dots, b_N$。

## 输出

输出共 $N+1$ 行，每行一个整数，分别表示匹配数恰好等于 $0, 1, \dots, N$ 的反转区间数量。

## 样例

输入：

```text
3
1 3 2
3 2 1
```

输出：

```text
3
3
0
0
```

## 思路

任何一个反转区间 $[l, r]$ 是以中心对称点 $mid = (l + r) / 2$ 为轴心展开的。
反转后元素 $a_i$ 与 $a_j$ 对调，若 $a_i = b_j$，则产生匹配贡献。
因为以同一中心展开的区间具有逐层向外扩展的包含关系，我们可以按中心枚举对称轴，利用差分或前缀和快速转移计算每个区间相对于原匹配数的净变化量，最后汇总统计频次。
