# P2　更多奶牛照片（More Cow Photos）

## 题目

农夫约翰想为他的 $N$ 头奶牛（$1 \le N \le 10^5$）拍照。
每头奶牛具有一个整数高度特征。照片中的奶牛排布必须满足特定交替高低顺序约束。

请计算满足要求的最大队伍长度。

## 输入

第一行一个整数 $T$。
每个测试用例第一行为 $N$，第二行包含 $N$ 个整数。

## 输出

对每个用例输出一行：最大队伍长度。

## 样例

输入：

```text
2
4
1 1 2 3
4
3 3 2 1
```

输出：

```text
3
1
```

## 思路

经典贪心交替子序列构造：
分析元素频次与奇偶特征，通过贪心挑选高低波峰与波谷，以最大化有效交替节点数。

## 复杂度

排序并线性扫描，时间复杂度为 $O(N \log N)$，空间复杂度为 $O(N)$。
