# P3　瓷砖兑换（Tile Exchanging）

## 题目

农夫约翰之前买了 $N$ 块正方形瓷砖，边长分别是 $A_1 \dots A_N$。他现在想让所有瓷砖的总面积恰好等于 $M$，因此要把其中一些瓷砖换成新的正方形瓷砖。

商场的优惠规则是：把边长为 $A_i$ 的瓷砖换成边长为 $B_i$ 的瓷砖，花费为 $|A_i - B_i|^2$。注意这个优惠只适用于**最初购买**的瓷砖，也就是说换来的瓷砖不能再次拿去交换（不能用边长 3 的换 2、再换 1）。

请求出使总面积恰好为 $M$ 的最小花费；如果无论如何都办不到，输出 -1。

## 输入

- 第一行两个整数 $N$ 和 $M$（$1 \le N \le 10$，$1 \le M \le 10000$）。
- 接下来 $N$ 行，每行一个整数，表示原有瓷砖的边长 $A_i$（$1 \le A_i \le 100$）。

## 输出

一行一个整数：达到总面积 $M$ 的最小花费，或者 -1（无解）。

## 样例

输入：

```text
3 6
3
3
1
```

输出：

```text
5
```

解释：把一块边长 3 的换成边长 2，另一块边长 3 的换成边长 1，得到面积 $4+1+1=6$，花费 $1^2+2^2=5$。

## 思路

由于每块瓷砖最多只能交换一次，"把每块瓷砖换成什么" 是互相独立的决策，可以按瓷砖逐个做背包式 DP：

设 `best[i][j]` 表示**只考虑前 $j$ 块**瓷砖、凑出总面积恰好为 $i$ 的最小花费（无法凑出记为正无穷）。边界是 `best[0][0] = 0`，其余 `best[i][0] = INF`。

转移时枚举第 $j$ 块瓷砖换成边长 $k$（$k \ge 1$ 且 $k^2 \le i$，因为总面积不能超过 $i$）：

$$best[i][j] = \min_{k}\ \big((A_j - k)^2 + best[i - k^2][j-1]\big)$$

含义是"第 $j$ 块的花费 + 用前 $j-1$ 块凑出剩余面积 $i-k^2$ 的最优花费"。保留原瓷砖相当于取 $k = A_j$，花费为 0，所以不需要额外处理。

状态数 $M \times N$，每个状态枚举 $k$ 到 $\lfloor\sqrt{M}\rfloor$，总转移量约 $N \cdot M \cdot \sqrt{M} \le 10^7$，可以轻松通过。最后 `best[M][N]` 若仍为正无穷则输出 -1。
