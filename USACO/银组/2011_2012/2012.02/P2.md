# P2　奶牛的编号（Cow IDs）

## 题目

身为一个隐藏的电脑极客，Farmer John 给每头奶牛都编了一个二进制编号。不过他有点迷信，只肯用恰好含 $K$ 个 `1` 的二进制数做编号（$1 \le K \le 10$），编号的最高位当然总是 `1`。他按数值从小到大的顺序分配编号，从最小的合法编号——$K$ 位全 `1` 的那个数——开始。

现在他把编号表弄丢了，请你算出：他应该分配的第 $N$ 个编号是什么（$1 \le N \le 10^7$）。

## 输入

一行两个空格分隔的整数，`N` 和 `K`。

## 输出

一行，第 $N$ 个合法编号的二进制写法（没有前导零）。

## 样例

输入：

```text
7 3
```

输出：

```text
10110
```

恰好含 $3$ 个 `1` 的二进制数从小到大依次是 $111, 1011, 1101, 1110, 10011, 10101, 10110$，第 $7$ 个就是 $10110$。

## 思路

要求「第 $N$ 个」，就把这件事拆成两步：先确定答案有几位，再逐位确定每一位是 `0` 还是 `1`。

**定位位数。** 位数恰为 $l$ 的合法编号，最高位固定是 `1`，剩下 $l-1$ 位里还要放 $K-1$ 个 `1`，共有 $\binom{l-1}{K-1}$ 个。于是位数不超过 $L$ 的编号一共

$$\sum_{l=K}^{L}\binom{l-1}{K-1}=\binom{L}{K}$$

个（组合数的求和恒等式）。从小到大找第一个满足 $\binom{L}{K} \ge N$ 的 $L$，答案正好有 $L$ 位。

**定位排名。** 比 $L$ 位更短的编号共有 $\binom{L-1}{K}$ 个，所以答案是「位数恰为 $L$ 的编号中第 $N-\binom{L-1}{K}$ 小」。

**逐位确定。** 假设还剩 $m$ 个空位、还要放 $k$ 个 `1`：这一位填 `0` 的编号有 $\binom{m-1}{k}$ 个，而且它们全部排在填 `1` 的编号前面。若排名不超过 $\binom{m-1}{k}$ 就填 `0`；否则填 `1`，把排名减去 $\binom{m-1}{k}$，待放的 `1` 少一个，继续下一位。

组合数用杨辉三角 $\binom{m}{k}=\binom{m-1}{k-1}+\binom{m-1}{k}$ 预先算好。因为组合数只需要和 $N$ 比较大小，一旦超过 $N$ 就把它截断成 $N$，既不会溢出，也不会影响判断。

**$K=1$ 要单独处理。** 只含 1 个 `1` 的编号只能是 $1, 10, 100, \ldots$，第 $N$ 个就是 `1` 后面跟 $N-1$ 个 `0`，长度会达到 $N$（最大 $10^7$），超出组合数表能覆盖的范围，所以直接输出。
