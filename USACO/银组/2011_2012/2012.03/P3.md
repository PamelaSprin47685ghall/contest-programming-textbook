# P3　景观美化（Landscaping）

## 题目

约翰在修一座漂亮的花园，需要搬很多土。

花园由一排 $N$ 个花坛组成，第 $i$ 个花坛原来有 $A_i$ 单位土，约翰希望改造成每坛 $B_i$ 单位土。

他可以选择：

- 花 $X$ 买一单位土，放进任意一个花坛；
- 花 $Y$ 从任意一个花坛运走一单位土；
- 花 $Z \times |i-j|$ 把一单位土从第 $i$ 个花坛运到第 $j$ 个花坛。

求完成改造的最小总花费。

## 输入

第一行四个整数 $N$、$X$、$Y$、$Z$（$1 \le N \le 100$，$0 \le X, Y, Z \le 1000$）。

接下来 $N$ 行，每行两个整数 $A_i$、$B_i$（$0 \le A_i, B_i \le 10$）。

## 输出

一行一个整数：最小总花费。

## 样例

输入：

```text
4 100 200 1
1 4
2 3
3 2
4 0
```

输出：

```text
210
```

解释：4 个花坛原来分别有 1、2、3、4 单位土，目标是 4、3、2、0。必须运走一单位土（花 200，来自 4 号花坛），其余泥土搬运共花 10：3 单位从 4 号搬到 1 号，1 单位从 3 号搬到 2 号。总计 $200+10=210$。

## 思路

花坛数量少、每坛土量小，因此**泥土总单位数不超过 $100 \times 10 = 1000$**。这正是拆开看的关键。

把"每个花坛有几单位土"摊平成一条序列：把每单位土都单独记下来，记它现在属于哪个花坛，就得到一条长度为总土量的、**非递减**的序列。例如原土量 $3,1,4,1$ 变成 $0,0,0,1,2,2,2,2,3$。对目标土量同样做一遍。

这样一来，每种操作都有了对应：

- 买一单位土放进第 $j$ 个花坛 ⇒ 往目标序列里"插入"一项；
- 从第 $i$ 个花坛运走一单位土 ⇒ 从原序列里"删除"一项；
- 把原第 $i$ 单位土搬去当目标第 $j$ 单位土 ⇒ 两项配对，花费 $Z \times |p_i - q_j|$，其中 $p_i$、$q_j$ 是这两单位土所在的花坛编号。

这正是经典的**编辑距离**（把一条序列改成另一条序列的最小代价），直接套动态规划：设 $f_{i,j}$ 表示把原序列前 $i$ 单位土改造成目标序列前 $j$ 单位土的最小花费，则

$$f_{i,j} = \min\bigl(f_{i,j-1} + X,\; f_{i-1,j} + Y,\; f_{i-1,j-1} + Z\,|p_i - q_j|\bigr)$$

三条转移分别对应"买土""运走土""搬运这一单位土"。边界是 $f_{0,j} = jX$（全买）和 $f_{i,0} = iY$（全运走）。

为什么配对只需考虑"同序号配对"这一种？两条序列都是非递减的，如果第 $i$ 单位土配到更远的花坛、第 $i'$ 单位土（$i' > i$）反而配到更近的花坛，交换两者目标，代价之和不会变大（绝对值之和的交换不等式）。所以最优方案里一定存在一种不交叉的配对，逐项对应的 DP 就能覆盖它。

## 复杂度

泥土地总单位数至多 1000，时间 $O(1000^2)$（即 $O(N_{\text{土}} \times N_{\text{目标土}})$ 的填表），空间同样 $O(1000^2)$。
