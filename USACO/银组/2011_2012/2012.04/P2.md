# P2　书架（Bookshelf (Silver)）

## 题目

FJ 有 $N$ 本书要放上书架，第 $i$ 本书宽 $W(i)$、高 $H(i)$。书必须按编号顺序摆放：第一层放第 $1 \sim k$ 本，第二层接着放第 $k+1$ 本开始的一段，以此类推。每层书的总宽度不能超过 $L$，一层的高度等于这层里最高那本书的高度，整套书架的高度是各层高度之和。

请算出书架高度的最小值。

## 输入

第一行两个整数 $N$ 和 $L$（$1 \le N \le 2000$，$1 \le L \le 10^9$）。

接下来 $N$ 行，第 $i+1$ 行是两个整数 $H(i)$ 和 $W(i)$（$1 \le H(i) \le 10^6$，$1 \le W(i) \le L$）。

## 输出

一行一个整数：书架高度的最小值。

## 样例

输入：

```text
5 10
5 7
9 2
8 5
13 2
3 8
```

输出：

```text
21
```

一共三层：第 1 本单独一层（高 5、宽 7）；第 $2 \sim 4$ 本一层（宽 $2+5+2=9 \le 10$，最高 13）；第 5 本一层（高 3、宽 8）。总高度 $5+13+3=21$。

## 思路

书必须按顺序连续分段，每段是一层，这正好是「划分序列」的模型，用动态规划。

设 `best[i]` 表示前 $i$ 本书摆好的最小总高度。最后一层如果放第 $j \sim i$ 本（$1 \le j \le i$），这一层的高度就是这段里最高的书，于是

$$
\text{best}[i] = \min_{j} \left( \text{best}[j-1] + \max(H(j), \dots, H(i)) \right),
$$

其中 $j$ 要满足第 $j \sim i$ 本的宽度和不超过 $L$。答案就是 `best[N]`。

实现时对每个 $i$ 从后往前枚举 $j$：宽度用前缀和一步算出，越界立刻 `break`（$j$ 再往前只会更宽，一定也不合法）；同时顺手维护这一小段的最大高度，不必每个 $j$ 都重新扫一遍区间。这样每对 $(i, j)$ 只花常数时间。

宽度和会到 $N \times L = 2 \times 10^{12}$，超过 `int` 的范围，前缀和与答案都要用 `long long` 存。
