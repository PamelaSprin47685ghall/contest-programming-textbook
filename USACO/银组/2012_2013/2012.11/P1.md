# P1　笨拙的奶牛（Clumsy Cows）

## 题目

奶牛 Bessie 想在笔记本电脑上敲一个平衡的括号串，可她蹄子太大，总是敲错。给定她敲出来的串，请算出最少要翻转多少个字符（把 `(` 改成 `)`，或把 `)` 改成 `(`），才能让它变成平衡的括号串。

一个括号串"平衡"的含义是：左括号与右括号总数相同，并且任意前缀里左括号的个数都不少于右括号。

## 输入

- 第一行：一个括号串，长度为不超过 $100{,}000$ 的偶数，只含 `(` 与 `)` 两种字符。

## 输出

- 第一行：一个整数，表示使串平衡所需翻转的最少字符数。

## 样例

输入：

```text
())(
```

输出：

```text
2
```

解释：最后一个括号必须翻转；中间那两个右括号里也要翻转一个，例如把第 3 个字符翻成 `(`，得到 `()()`。

## 思路

用 `depth` 记录"到目前为止还没有被配对的左括号数"，从左往右扫一遍：读到 `(` 就加 1，读到 `)` 就减 1。

如果某一步之后 `depth` 变成负数，说明这个前缀里右括号已经多于左括号，后面再读什么都救不回它，必须在这个前缀之内把某个 `)` 翻转成 `(`。翻转当前位置的字符（也就是最靠后的那个右括号）一定不劣：它让当前前缀恰好恢复平衡，而且不会影响更早的前缀。翻转后这个字符变成左括号，深度从 $-1$ 变成 $1$，所以计一次翻转，并给 `depth` 加 2。

扫完之后 `depth` 可能是正数，表示还有 `depth` 个左括号没有配对。这时翻转靠后的 `depth/2` 个左括号即可：每翻转一个 `(` 成 `)`，`depth` 减 2，翻够 `depth/2` 个就刚好归零；因为翻的是最后面的括号，前面各前缀不会受影响，仍然合法。串长为偶数，所以 `depth` 一定是偶数，不存在半个括号要多翻的情况。

最后解释这两批翻转为什么能加起来就是答案：所有"`(` 翻 `)`"都必须发生在最后一次"`)` 翻 `(`"之后（否则中途还有前缀为负），两类翻转作用在不同位置上，不会互相抵消。

样例 `())(` 的深度依次为 1、0、-1、2：在深度变 -1 时翻转一次，最后剩 2 再翻一次，共 2 次。
