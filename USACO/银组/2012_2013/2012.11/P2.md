# P2　遥远的牧场（Distant Pastures）

## 题目

农夫约翰的农场是一个 $N \times N$ 的牧场网格，每个牧场里种着两种草之一，题目用 `(` 与 `)` 代表这两种草。Bessie 从一个牧场走到上、下、左、右相邻的牧场时，若两块牧场的草相同需要 $A$ 个单位时间，不同则需要 $B$ 个单位时间。她在任意两个牧场之间移动时，总是选择用时最少的走法。

请求出：在所有牧场对中，Bessie 最少用时最长的那个用时是多少。

## 输入

- 第一行：三个整数 $N$（$1 \le N \le 30$）、$A$（$0 \le A \le 1{,}000{,}000$）、$B$（$0 \le B \le 1{,}000{,}000$）；
- 接下来 $N$ 行：每行是一个长度为 $N$ 的括号串，这 $N$ 行共同组成农场的网格。

## 输出

- 第一行：一个整数，表示牧场对之间最少用时的最大值。

## 样例

输入：

```text
3 1 2
(((
()(
(()
```

输出：

```text
5
```

解释：从左上角走到右下角需要 5 个单位时间，没有任何一对牧场需要走得更久。

## 思路

把每个牧场看成一个点，相邻牧场之间连一条边：草相同则边权为 $A$，不同则边权为 $B$。题目要求的其实是这张图的"直径"——任意两点间最短路的最大值，也就是从每个点出发单源最短路后，取所有源点的最远距离的最大值。

点数 $V = N^2 \le 900$，边数约 $2V$。最短路不能直接做成 BFS（边权不一定是 1），所以对每个点跑一次 Dijkstra。原题要求同时考虑 $N$ 最大到 40 的更大规模，用 Floyd-Warshall 的 $O(V^3)$ 会太慢；$V$ 次堆优化 Dijkstra 是 $O(V^2 \log V)$，对本题的规模有充足余量。

堆里的 `State` 记录"从源点走到 (r,c) 的用时 d"。同一牧场可能被多次入堆，出堆时若它的 `d` 与 `dist[r][c]` 不符，说明这一条已经过期，直接跳过；这条懒惰删除的判断让代码不必维护额外的"是否已定稿"数组。出堆的合法条目用时是非递减的，所以最后一个合法出堆的用时就是这个源点的最远距离。

还有一个细节：$A$、$B$ 允许为 $0$，此时边权为 0，Dijkstra 依然正确（只有 BFS 那种"按层数计数"的做法才会出错）。
