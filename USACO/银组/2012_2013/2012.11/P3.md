# P3　平衡的奶牛品种（Balanced Cow Breeds）

## 题目

农夫约翰养着 Holstein 与 Guernsey 两个品种的奶牛，他给每头牛都烙上一个括号形状的印记；因为牛站的方向不同，从正面看过去像 `(` 或者 `)`。$N$ 头牛排成一列，从左往右看就得到一个长度为 $N$ 的括号串。

FJ 发现，如果只看 Holstein，把它们按在队列中出现的先后顺序连起来读，得到一个平衡的括号串；只看 Guernsey 也一样。请计算一共有多少种给 $N$ 头牛分配品种的方案，能让这两条性质同时成立。由于答案可能很大，输出它对 $2012$ 取模的结果。全部牛都是同一个品种的方案也算合法。

（括号串平衡的含义：左右括号数量相同，并且任意前缀里左括号不少于右括号。）

## 输入

- 第一行：一个括号串，长度 $N$（$1 \le N \le 1000$），只含 `(` 与 `)`。

## 输出

- 第一行：一个整数，表示合法分配方案数对 $2012$ 取模的结果。

## 样例

输入：

```text
(())
```

输出：

```text
6
```

解释：下面 6 种分配满足要求（第一行是原来的括号串，第二行写每个位置分给哪个品种）：

```text
(())    (())    (())    (())    (())    (())
HHHH    GGGG    HGGH    GHHG    HGHG    GHGH
```

## 思路

从左往右逐个字符决定归属。要让两个品种各自读出来都平衡，只需要随时清楚"每个品种还欠着多少个没配对的左括号"。

关键观察：处理完前 $i$ 个字符时，两个品种未配对的左括号数之和 $a + b$ 必定等于前 $i$ 个字符的整体深度 $balance_i$（`(` 记加 1、`)` 记减 1），因为每个括号不论归谁都会让对应品种的未配对左括号数变化 1。于是 $b = balance_i - a$，状态只需 $(i, a)$ 两维：$dp[i][a]$ 表示前 $i$ 个字符中分给 Holstein 的未配对左括号数为 $a$ 的方案数。

转移时记 $b = balance_i - a$：

- 第 $i$ 个字符是 `(`：分给 Holstein 则 $dp[i+1][a+1] += dp[i][a]$；分给 Guernsey 则 $dp[i+1][a] += dp[i][a]$。
- 第 $i$ 个字符是 `)`：只有当某一边还欠着左括号时才能分给它，否则这个品种读到这里前缀就比左括号多了，必然不平衡。于是 $a > 0$ 时可以把 `)` 分给 Holstein（$dp[i+1][a-1] += dp[i][a]$），$b > 0$ 时可以分给 Guernsey（$dp[i+1][a] += dp[i][a]$）。

初值 $dp[0][0] = 1$（还没读字符，两边都没有未配对的左括号）。答案取 $dp[n][0]$：两个品种都恰好没有剩余的未配对左括号，两条子序列才都是平衡的。如果整个串本身就不平衡（$balance_n \ne 0$），那么 $a = 0$ 时 $b = balance_n \ne 0$，不存在合法方案，直接输出 0。

样例 `(())` 的答案是 6，与转移过程一致：前两个左括号可以任意分配（4 种），后面两个右括号各自只能交给还有欠账的一边。
