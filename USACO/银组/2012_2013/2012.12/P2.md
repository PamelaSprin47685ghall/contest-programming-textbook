# P2　无线网络架设（Wifi Setup）

## 题目

农夫约翰的 $N$（$1 \le N \le 2000$）头奶牛全部站在从谷仓到牧场的直线路径上，可以看成一条一维数轴。他想安装若干 Wifi 基站，让所有奶牛都能上网。

一个发射距离为 $r$ 的基站花费 $A + B \cdot r$，其中 $A$ 是安装的固定成本，$B$ 是单位距离的成本。把基站放在位置 $x$，它就能覆盖 $[x-r, x+r]$ 范围内的所有奶牛。允许 $r = 0$，此时只能覆盖与基站位置相同的牛。

给定 $A$、$B$ 以及奶牛的位置，求覆盖全部奶牛的最小花费。

## 输入

- 第一行：三个整数 $N$、$A$、$B$（$0 \le A, B \le 1000$）；
- 接下来 $N$ 行：每行一个整数（范围 $0$ 到 $1{,}000{,}000$），表示一头奶牛的位置。

## 输出

一行：覆盖所有奶牛的最小花费。答案可能是 $0.5$ 的整数倍，例如 `57.5`。

## 样例

输入：

```text
3 20 5
7
0
100
```

输出：

```text
57.5
```

解释：在位置 3.5 建一个发射距离 3.5 的基站（覆盖 0 和 7 处的牛），在位置 100 建一个发射距离 0 的基站，花费为 $(20+5 \times 3.5) + 20 = 57.5$。

## 思路

先把奶牛位置排序。最优方案一定把奶牛分成若干**连续段**，每段用一座基站覆盖：基站实际覆盖到的那些牛必然是一段连续的牛，而把基站收窄到恰好覆盖这段牛（放在这段牛的最左、最右位置的中点，取半径 $= \frac{1}{2}(\text{右端点}-\text{左端点})$）只会更便宜。

设排序后奶牛位置为 $x_1 < x_2 < \dots < x_N$，用 $dp[i]$ 表示覆盖前 $i$ 头牛的最小花费。枚举最后一座基站覆盖第 $j+1$ 到第 $i$ 头牛（$0 \le j < i$）：

- 基站放在 $\frac{x_{j+1} + x_i}{2}$，半径 $r = \frac{x_i - x_{j+1}}{2}$；
- 这座基站的花费是 $A + \frac{B}{2}(x_i - x_{j+1})$。

于是

$$dp[i] = \min_{0 \le j < i} \left( dp[j] + A + \frac{B}{2}(x_i - x_{j+1}) \right), \qquad dp[0] = 0.$$

因为花费可能出现 $\frac{1}{2}$ 的小数部分，为了避免浮点误差，全程用**两倍花费**做整数运算：

$$dp2[i] = \min_{0 \le j < i} \left( dp2[j] + 2A + B(x_i - x_{j+1}) \right).$$

最后如果 $dp2[N]$ 是偶数就输出 $dp2[N]/2$，否则输出整数部分再接上 `.5`。
