# P3　牛奶运输路线（Milk Routing）

## 题目

农夫约翰的农场里有一套过时的管道网络，由 $M$（$1 \le M \le 500$）条管道组成，用来把牛奶从谷仓泵到储奶罐。他打算明年拆掉并更新大部分管道，但想留下**一条**从谷仓通往储奶罐的路径。

管道网络由 $N$（$1 \le N \le 500$）个结点描述：$1$ 号结点是谷仓，$N$ 号结点是储奶罐。每条管道是双向的，连接两个结点，并有一个延迟（牛奶从一端到另一端所需的时间）和一个容量（稳态下单位时间能泵过的牛奶量）。同一对结点之间可能有多条管道。

对一条从谷仓到储奶罐的路径：延迟 $L$ 是路径上所有管道延迟之和，容量 $C$ 是路径上所有管道容量的**最小值**（瓶颈）。如果要通过一条延迟为 $L$、容量为 $C$ 的路径输送总共 $X$ 单位牛奶，所需时间为 $L + X/C$。

给定管道网络，请帮他选出一条路径，使输送 $X$ 单位牛奶的总时间最少。

## 输入

- 第一行：三个整数 $N$、$M$、$X$（$1 \le X \le 1{,}000{,}000$）；
- 接下来 $M$ 行：每行四个整数 $I, J, L, C$。$I, J$（$1 \le I, J \le N$）是管道两端的结点，$L, C$（$1 \le L, C \le 1{,}000{,}000$）分别是延迟与容量。

## 输出

一行：输送牛奶所需的最少时间，**向下取整**到最近的整数。

## 样例

输入：

```text
3 3 15
1 2 10 3
3 2 10 2
1 3 14 1
```

输出：

```text
27
```

解释：走 1→3 需要 $14 + 15/1 = 29$；走 1→2→3 需要 $20 + 15/2 = 27.5$，向下取整为 27，是最优解。

## 思路

难点在于延迟与容量要一起权衡：容量大的路径往往延迟也大。

关键观察：一条路径的容量一定等于它某条“瓶颈”管道的容量，所以**最优路径的容量只有 $M$ 种可能取值**。

一旦把容量 $C$ 固定下来，问题就退化成：只允许走容量 $\ge C$ 的管道，求 1 号点到 $N$ 号点的最短延迟——跑一次 Dijkstra 即可。

于是做法是：枚举每条管道的容量 $C$，在“只保留容量 $\ge C$ 的管道”的子图上求最短延迟 $L$，用 $L + X/C$ 更新答案。

为什么这样枚举是完备的：

- 对任意 $C$，算出的 $L$ 所对应的路径，其真实瓶颈 $C' \ge C$，真实时间为 $L + X/C' \le L + X/C$，所以枚举得到的每个候选值都不小于真正的最优值。
- 取 $C$ 等于最优路径的瓶颈时，子图包含这条最优路径，最短延迟 $L \le$ 最优路径的延迟，于是候选值又不大于真正的最优值。

两边夹逼，最小值就是正确答案。输出要求向下取整，而 $L$ 是整数，所以 $L + X/C$ 直接用整数除法（等价于先算 $\lfloor X/C \rfloor$ 再相加）即可。

## 复杂度

枚举 $M$ 个容量取值，每次 Dijkstra 为 $O(M \log N)$。时间 $O(M^2 \log N)$，空间 $O(N + M)$。
