# P2　正方形重叠（Square Overlap）

## 题目

农夫约翰打算建 $N$（$2 \le N \le 50000$）个正方形牧场，每个牧场的边长都是 $K$（$1 \le K \le 10^6$，且 $K$ 是偶数）。第 $i$ 个牧场的中心在整点 $(x_i, y_i)$ 上，$|x_i|, |y_i| \le 10^6$，任意两个牧场的中心都不相同。

如果两个牧场有**正的公共面积**（只是碰到边不算），就说它们重叠。请你求出唯一一对重叠牧场的公共面积；如果没有牧场重叠，输出 `0`；如果重叠的牧场不止一对，输出 `-1`。

## 输入

- 第一行：两个整数 $N$、$K$；
- 接下来 $N$ 行：第 $i+1$ 行是两个整数 $x_i$、$y_i$，表示第 $i$ 个牧场的中心。

## 输出

一行：唯一一对重叠牧场的公共面积；没有重叠输出 `0`；重叠多于一对输出 `-1`。

## 样例

输入：

```text
4 6
0 0
8 4
-2 1
0 7
```

输出：

```text
20
```

解释：1 号（中心 $(0,0)$）和 3 号（中心 $(-2,1)$）牧场重叠，公共面积 $(6-2)\times(6-1)=20$。其余两两之间的横坐标或纵坐标距离都不小于 $6$，不重叠。

## 思路

两个边长 $K$、中心为 $(x_1,y_1)$ 和 $(x_2,y_2)$ 的正方形，公共面积为正当且仅当 $|x_1-x_2| < K$ 且 $|y_1-y_2| < K$；这时公共面积就是 $(K-|x_1-x_2|)(K-|y_1-y_2|)$，因为两个方向上的交叠长度分别是 $K$ 减去中心距离。

于是问题变成：找出所有满足这两个距离条件的点对并数出个数。直接枚举点对是 $O(N^2)$，太慢。

用扫描线：把所有中心按 $x$ 排序，从左往右处理，用一个**按 $y$ 排序的有序集合**维护「当前窗口」。窗口里留下的点与当前点的 $x$ 距离都小于 $K$；一旦某个点与当前点的 $x$ 距离达到 $K$，它与后面所有点也不可能再重叠，可以永久删掉。此时只要在集合里取出 $y$ 方向距离也小于 $K$ 的邻居，这些邻居与当前点就一定是真正重叠的一对，直接算出面积即可。

每找到一对就记下面积；一旦找到第二对，立刻输出 `-1`。由于枚举到的每一对都真的重叠，找到第二对就停止，扫描的总代价仍是 $O(N\log N)$。
