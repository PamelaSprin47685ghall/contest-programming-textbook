# P1　周长（Perimeter）

## 题目

农夫约翰把 $N$（$1 \le N \le 50\,000$）块干草垛摆在田地里。把田地看成 $1\,000\,000 \times 1\,000\,000$ 个 $1 \times 1$ 格子的网格，每块干草垛正好占其中一个格子，当然没有两块干草垛占同一个格子。

这些干草垛正好构成一整块连通区域：从任意一块干草垛出发，每次朝南北东西中的一个方向踏上相邻的干草垛，都能走到其他任意一块。不过这块区域内部可能含有“洞”，也就是被干草垛完全包围的空区域。

请帮助约翰求出干草垛区域的周长。注意洞不贡献周长。

## 输入

- 第一行：干草垛数量 $N$；
- 第 $2$ 到第 $N+1$ 行：每行两个整数 $x,y$，表示一块干草垛的位置（$1 \le x,y \le 1\,000\,000$）。其中 $(1,1)$ 是田地左下角的格子，$(1000000,1000000)$ 是右上角的格子。

## 输出

一行，一个整数：干草垛区域的周长。

## 样例

输入：

```text
8
10005 200003
10005 200004
10008 200004
10005 200005
10006 200003
10007 200003
10007 200004
10006 200005
```

输出：

```text
14
```

解释：这块区域长这样（`X` 表示干草垛，中间留了一个洞）：

```text
XX
X XX
XXX
```

周长是 14（例如左侧边贡献了 3），中间那个洞不计入周长。

## 思路

难点在于“洞的边界不算”。如果直接数 $4N$ 减去 $2 \times$ 相邻干草垛对数，得到的是包含洞的周长。

换个角度：把干草垛区域看成一块实心形状，想象自己贴着它的最外圈走一圈，让干草垛始终在自己的左手边。这一圈的总长度就是答案，而且因为洞被干草垛和外界隔开，只要在每个岔路口选对方向，就不会拐进洞里。

把格子坐标提升到“格点”上：格子 $(x,y)$ 就是方格 $[x,x+1] \times [y,y+1]$，边界由格点之间的单位边组成。设当前在格点 $(x,y)$，方向 $d$ 取 0 东、1 北、2 西、3 南（逆时针排列），沿 $d$ 走一个单位就是一条候选边。这条边是“贴着区域左侧”的边界边，当且仅当：

- 它左手边的格子是干草垛，说明它紧贴区域；
- 它右手边的格子是空地，否则这条边夹在两块干草垛中间，属于区域内部。

每走一步的选边规则是：**能右转就右转，否则直行，否则左转**。之所以强调右转优先，是因为外边界和某个洞的边界可能共用同一个格点（两块对角相邻的干草垛让顶点处只剩两个对角的空格）：此时左转和右转都是合法的边界边，优先右转才会顺着外圈走，优先左转则会拐进洞的边界，把洞的周长也加进来。回到出发点、并且下一步的方向与出发时相同时，说明整圈已经走完。

起点取最下（$y$ 最小）、最左（$x$ 最小）的那块干草垛，从它的左下角向东出发，区域正好落在左手边。

坐标范围有 $10^6$，开不下二维数组，所以把格子坐标编码成一个整数，用 set 保存干草垛，每次判断 $O(\log N)$；总步数就是周长，不超过 $4N$。
