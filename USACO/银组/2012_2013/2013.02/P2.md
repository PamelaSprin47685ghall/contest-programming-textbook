# P2　拖拉机（Tractor）

## 题目

农夫约翰有一块地特别崎岖，他想买一台新拖拉机在上面开。这块地是一个 $N \times N$（$1 \le N \le 500$）的网格，每格有一个非负整数高度。一台能跨越高度差 $D$ 的拖拉机可以在一个格子与相邻（北、东、南、西）格子之间行驶，前提是两格高度差的绝对值不超过 $D$，而它的价格恰好是 $D$。

约翰希望从某个格子出发，能开着拖拉机访问到至少一半的格子（如果格子总数是奇数，则至少一半向上取整）。请帮他算出实现这个目标最便宜要花多少钱。

## 输入

- 第一行：整数 $N$；
- 第 $2$ 到第 $N+1$ 行：每行 $N$ 个用空格隔开的非负整数（每个都不超过 $1\,000\,000$），表示田地的一行。

## 输出

一行，一个整数：能让约翰访问到至少一半格子的拖拉机的最低价格。

## 样例

输入：

```text
5
0 0 0 3 3
0 0 0 0 3
0 9 9 3 3
9 9 9 3 3
9 9 9 9 3
```

输出：

```text
3
```

解释：价格为 3 的拖拉机能在高度 0 和高度 3 之间移动，因此它可以访问全部高度为 0 的格子以及高度为 3 的那一片格子，合起来不少于全田 25 个格子的一半。价格更低时无法做到。

## 思路

先看固定价格 $D$ 时能否达成目标：把格子看成点，凡是高度差不超过 $D$ 的相邻两格之间连一条边，那么“能否访问至少一半格子”就等价于“是否存在一个大小至少为 $\lceil N^2/2 \rceil$ 的连通块”。一次洪水填充（BFS/DFS）即可判断。这里用数组模拟栈做迭代式填充，避免 $N = 500$ 时递归 $25$ 万层把栈撑爆。

价格越高，能通行的相邻格对就越多，所以可行性关于 $D$ 单调：若某个 $D$ 可行，比它大的价格一定也可行。于是二分答案，每次用 $O(N^2)$ 的洪水填充判断。高度最大为 $10^6$，取 $D = 10^6$ 时所有相邻格对都能通行，整个网格必然连通，可以当作二分上界。
