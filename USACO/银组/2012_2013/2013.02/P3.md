# P3　挤奶调度（Milk Scheduling）

## 题目

农夫约翰的 $N$（$1 \le N \le 10\,000$）头牛编号为 $1$ 到 $N$。给第 $i$ 头牛挤奶需要 $T(i)$ 单位时间。由于牛棚的布局，有些牛必须比另一些牛先挤：如果 $A$ 必须在 $B$ 之前挤奶，那么约翰必须把 $A$ 完全挤完才能开始挤 $B$。

为了尽快干完活，约翰雇了一大批帮工——多到可以同时给任意多头牛挤奶。不过即使可以并行，整个过程还是受“某些牛必须先挤”的限制。请帮约翰算出挤完所有牛所需的最短总时间。

## 输入

- 第一行：两个用空格隔开的整数 $N$ 和 $M$（挤奶约束的条数，$1 \le M \le 50\,000$）；
- 第 $2$ 到第 $N+1$ 行：第 $i+1$ 行是 $T(i)$（$1 \le T(i) \le 100\,000$）；
- 第 $N+2$ 到第 $N+M+1$ 行：每行两个整数 $A,B$，表示 $A$ 必须完全挤完才能开始挤 $B$。这些约束保证不会成环，所以答案总是存在。

## 输出

一行，一个整数：挤完所有牛所需的最短时间。

## 样例

输入：

```text
3 1
10
5
6
3 2
```

输出：

```text
11
```

解释：一共 3 头牛，挤奶时间分别是 10、5、6，并且牛 3 必须在牛 2 之前挤完。牛 1 和牛 3 可以一开始同时挤；牛 3 挤完后才轮到牛 2。全部挤完共用 11 个单位时间。

## 思路

既然可以同时给任意多头牛挤奶，等待就没有任何好处：每头牛都应该尽早开始挤，也就是在它所有前驱（必须在它之前挤完的牛）都挤完的那一刻立刻开始。于是第 $i$ 头牛的完成时刻为

$$finish(i) = T(i) + \max\{\,finish(j) \;:\; j \text{ 必须在 } i \text{ 之前挤完}\,\}$$

一开始就能挤的牛（没有前驱）满足 $finish(i) = T(i)$，把它们先放进队列，然后按拓扑序递推：每处理完一头牛 $u$，就用 $finish(u) + T(v)$ 去更新所有“在 $u$ 之后才能挤”的牛 $v$ 的完成时刻；当 $v$ 的所有前驱都处理完时（用入度计数，每处理一个前驱就减一）把 $v$ 入队。所有完成时刻的最大值就是答案。

用入度做拓扑排序还有个好处：只需要存“$u$ 之后有哪些牛”这一方向的边，不用额外建反向边。
