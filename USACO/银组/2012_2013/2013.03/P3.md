# P3　奶牛奔跑（The Cow Run）

## 题目

农夫约翰忘了修补栅栏上的一个洞，他的 $N$（$1 \le N \le 1000$）头奶牛跑了出去、四处乱窜！每分钟每头还在栅栏外的奶牛造成 1 美元损失。约翰必须逐头找到奶牛、给它套上绳套，让它安静下来。

奶牛恰好分布在小屋外一条公路上的不同位置：第 $i$ 头在坐标 $P_i$（$-500000 \le P_i \le 500000$，$P_i \ne 0$）。约翰从大门（位置 $0$）出发，速度是每分钟 1 个单位距离，套绳套不需要时间。求最小的总损失。

## 输入

- 第一行：奶牛数 $N$；
- 接下来 $N$ 行：第 $i+1$ 行是 $P_i$。

## 输出

一行：最小的总损失。

## 样例

输入：

```text
4
-2
-12
3
7
```

输出：

```text
50
```

解释：最优顺序是 $-2, 3, 7, -12$。到 $-2$ 用 2 分钟，到 3 时这头牛累计损失 $2+5=7$，到 7 时累计 $7+4=11$，最后到 $-12$ 时累计 $11+19=30$，总损失 $2+7+11+30=50$。

## 思路

总损失等于每头奶牛「被套上绳套的时刻」之和：某一分钟还有几头牛没套上绳套，这一分钟就损失几美元。

把起点 0 也看成一开头就套好的虚拟奶牛，把所有位置排序。关键观察是：已经套好的奶牛在排好序后一定是连续的一段——约翰走过的是一条连续的路，路过的奶牛自然被按顺序处理完。所以状态只要记录区间两端以及约翰现在站在哪一端：

- `dp[l][r][0]`：已经处理完第 $l..r$ 头奶牛、约翰站在左端 `pos[l]` 时的最小累计损失；
- `dp[l][r][1]`：约翰站在右端 `pos[r]` 时的最小累计损失。

转移就是把区间向左或向右扩一头。走这段路的时候，所有还没套上绳套的奶牛都在继续破坏，所以这一步的代价是「距离 × 还没套上的奶牛数」。区间 $[l,r]$ 的长度为 `len`，其中已经处理了 `len - 1` 头真牛（虚拟牛不算），所以还剩 `n - (len - 1)` 头。

从 `dp[start][start][0] = dp[start][start][1] = 0` 出发（`start` 是虚拟牛 0 的下标），按区间长度从小到大递推，答案取整个区间两端状态的最小值。
