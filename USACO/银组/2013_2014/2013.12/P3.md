# P3　贝西洗牌（The Bessie Shuffle）

## 题目

Bessie 在练习纸牌魔术。她已经掌握了“贝西洗牌”：对 $M$ 张牌做一次洗牌（$2 \le M \le 100000$），洗牌后第 $i$ 张（从顶部数）牌会跑到第 $P[i]$ 个位置。

现在她用更大的一副牌练习。这副牌有 $N$ 张牌（$M \le N \le 100000$），从上到下标记为 $1 \sim N$。她这样洗牌：先取出最上面的 $M$ 张做一次贝西洗牌，把洗好的牌放回整副牌的最上面；然后拿走最顶上的一张牌，正面朝下放到一边。她不断重复这个操作，每次把新拿走的牌叠在之前那些牌的上面，直到牌用完为止。当剩下不足 $M$ 张牌时，她不再做贝西洗牌，只是继续把顶牌一张张放到那叠牌的上面。

已知这副牌最初是有序的（最上面是 1，最下面是 $N$）。给你贝西洗牌的描述，请帮她算出最后位于指定位置的牌分别是什么。查询有 $Q$ 个（$1 \le Q \le N$，$Q \le 5000$）。

## 输入

- 第 1 行：三个整数 $N$、$M$、$Q$。
- 第 2 到 $M+1$ 行：第 $i+1$ 行给出 $P[i]$，即洗牌前第 $i$ 张牌洗完后所处的位置（$1 \le P[i] \le M$）。
- 第 $M+2$ 到 $M+Q+1$ 行：每行一个整数 $q_i$，表示一次查询：求从上往下第 $q_i$ 个位置上的牌的编号（$1 \le q_i \le N$）。

## 输出

$Q$ 行，第 $i$ 行输出一次查询的答案。

## 样例

输入：

```text
5 3 5
3
1
2
1
2
3
4
5
```

输出：

```text
4
5
3
1
2
```

解释：这副牌共 5 张，初始为 `[1, 2, 3, 4, 5]`。洗牌作用于 3 张牌，效果是把第一张牌移到最后。整个过程如下（括号里表示这次拿走并放下的牌）：

```text
[1, 2, 3, 4, 5] -> [2, 3, 1, 4, 5] （放下 2）
[3, 1, 4, 5] -> [1, 4, 3, 5]       （放下 1）
[4, 3, 5] -> [3, 5, 4]             （放下 3）
[5, 4]                             （放下 5）
[4]                                （放下 4）
```

最终从上往下的顺序是 `[4, 5, 3, 1, 2]`。

## 思路

直接按照题意模拟，每一轮都要重排 $M$ 张牌，总共要做 $N-M+1$ 次洗牌，时间复杂度 $O((N-M+1)M)$，$N=M=100000$ 时会超时。

换一个等价的视角：把整副牌看成一个**长度恒为 $N$ 的数组**，牌从不真正被删除。每一轮做的事情是

1. 对数组最前面的 $M$ 个位置做一次贝西洗牌（其他位置不动）；
2. 把整个数组**左移一格**（第 $i$ 个位置的牌来到第 $i-1$ 个位置，最前面的那张绕到末尾）。

第 2 步正是“拿走顶牌”的等价写法：拿走顶牌后剩下的牌整体上提一位，而被拿走的那张牌被绕到数组末尾。可以验证，被拿走的牌此后一直停留在数组末尾附近（每轮再往前挪一格），始终**不在最前面的 $M$ 个位置里**；而洗牌恰好只在剩余牌数不少于 $M$ 时发生，也就是前 $N-M+1$ 轮。所以这个定长数组模型和真实过程完全一致。

在这两步中，洗牌是对前 $M$ 个位置的固定置换，左移也是固定置换，把它们**复合**起来就得到每轮都要作用的同一个置换 `step`。于是整个前 $N-M+1$ 轮等价于把 `step` 连续作用 $N-M+1$ 次，用二进制快速幂即可在 $O(N \log (N-M+1))$ 内求出结果。

实现时按“拉取式”记录置换，即 `new[i] = old[step[i]]`：原题说“第 $i$ 张牌洗完后到第 $P[i]$ 个位置”，反过来就是“位置 $P[i]-1$ 上的牌原来在第 $i-1$ 个位置（0 下标）”。这样复合写作 `r[i] = a[b[i]]`，含义是“先作用 $b$，再作用 $a$”，两种操作可以任意地拼接、平方。

剩下还有 $M-1$ 轮（此时剩余牌数已不足 $M$，只做左移）需要补上。做完快速幂后，第 $j$ 轮被拿走的那张牌停在数组下标 $j$ 上，而被最先拿走的第一张牌是最下面的一张，最后拿走的牌在牌堆最上面——也就是说“从上往下第 $x$ 个位置”对应数组下标 $N-x$。再把最后的 $M-1$ 次左移补回来，位置 $x$ 上的牌就是

$$\text{cur}\big[(N + M - 1 - x) \bmod N\big]$$

（数组里的数值用 0 表示第 1 张牌，输出时加 1 即可）。
