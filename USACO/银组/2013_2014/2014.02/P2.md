# P2　路障（Roadblock）

## 题目

每天早上，农夫约翰从家出发穿过农场走到谷仓。农场由 N 块田（$1 \le N \le 250$）和 M 条双向小路（$1 \le M \le 25000$）组成，每条路有一个长度。约翰的家在 1 号田，谷仓在 N 号田。任意两块田之间都可以沿着若干条小路互相到达，并且任意一对田之间没有多余的重复小路。从一个田走到另一个田时，约翰总是选择总长度最小的路线。

奶牛们决定捣乱：它们要在恰好一条路上堆一堆干草，把这条路的长度变成原来的两倍。奶牛希望选一条路，使约翰从家到谷仓的最短距离增加得尽可能多。请帮奶牛算出它们最多能让约翰的路线变长多少。

## 输入

- 第 1 行：两个整数 N 和 M。
- 接下来 M 行：每行三个整数 $A_j$、$B_j$、$L_j$，表示第 j 条双向小路连接 $A_j$ 和 $B_j$，长度为 $L_j$（$1 \le L_j \le 1000000$）。

## 输出

- 一行：把一条小路的长度翻倍后，约翰最短路线总长度增加的最大值。

## 样例

输入：

```text
5 7
2 1 5
1 3 1
3 2 8
3 5 7
3 4 3
2 4 7
4 5 2
```

输出：

```text
2
```

样例说明：当前最短路是 1-3-4-5，长度 1+3+2=6。若把 3 到 4 之间的小路从 3 翻倍为 6，新的最短路变成 1-3-5，长度 1+7=8，比原来多 2。

## 思路

先在原图上跑一次 Dijkstra，求 1 号田到 N 号田的最短路，并记下每个点最短路上的最后一条边，从而还原出这条最短路上经过的所有边（至多 N − 1 条）。

关键观察：如果奶牛翻倍的边不在这条最短路上，那么原来的最短路完全不受影响，仍然存在且长度不变；而把边变长只会让最短路变长，不可能变短，所以增量只能是 0。因此只需枚举这条最短路上的每条边：把它的长度乘 2，重新跑一次 Dijkstra 求新的最短距离，取所有结果中的最大值，最后输出它与原始最短距离之差。由于「不在最短路上的边」贡献恒为 0，这个枚举不会漏掉最优解。

路径上至多有 N − 1 条边，因此最多做 O(N) 次 Dijkstra。
