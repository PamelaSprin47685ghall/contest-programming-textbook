# P3　秘密代码（Secret Code）

## 题目

农夫约翰有一条想瞒着奶牛们的秘密消息，消息是一个长度至少为 2、只由大写字母 A..Z 组成的字符串。

为了加密，约翰对消息施加一系列「操作」。一次操作作用于一个字符串 S：先删掉 S 开头的一些（但不是全部）字符，或者删掉末尾的一些（但不是全部）字符，得到较短的串；然后把原来的 S 接在这个短串的前面或者后面。例如对 ABC 做一次操作，可能得到 8 个字符串：

AABC、ABABC、BCABC、CABC、ABCA、ABCAB、ABCBC、ABCC

给定最终加密得到的字符串，请统计约翰用一次或多次连续操作、从某个长度至少为 2 的初始串出发得到这个字符串的方案数。即使两个操作给出相同的加密结果，它们也视为不同的操作；例如从 AA 得到 AAA 共有 4 种不同的方式。答案对 2014 取模。

## 输入

- 一行：一个加密后的字符串，长度不超过 100。

## 输出

- 一行：用一次或多次连续操作从某个长度至少为 2 的初始串得到该字符串的方案数，对 2014 取模；若不存在这样的方案，输出 0。

## 样例

输入：

```text
ABABA
```

输出：

```text
8
```

样例说明：得到 ABABA 的 8 种方式分别是：以 ABA 为初始串的 AB+ABA、ABA+BA 两种；以 AB 为初始串的 AB → AB+A → AB+ABA、AB → AB+A → ABA+BA 两种；以 BA 为初始串的 BA → A+BA → AB+ABA、BA → A+BA → ABA+BA 两种；以 ABAB 为初始串的 ABAB+A；以 BABA 为初始串的 A+BABA。

## 思路

正向枚举构建过程做不下去，于是倒着考虑。加密串 S 的最后一次操作，一定是由某个更长的串 T 生成 S 的：设 S 中另一截短串为 X、长度为 k，那么 T 就是 S 中长度为 $|S| - k$ 的那一段，并且 T 必须比 X 长，即 $2k < |S|$。根据 T 取 S 的前缀还是后缀，以及 X 等于 T 的真前缀还是真后缀（对应「删掉 T 的末尾」或「删掉 T 的开头」这两种不同的删法），一共有 4 种可能的逆操作，每种都对应一种不同的操作方案：

- $S = T + X$（T 是 S 的前缀，X 是 S 长为 k 的后缀）：X 等于 T 的真前缀时，对应删掉 T 的末尾再把 T 接在 X 后面；X 等于 T 的真后缀时，对应删掉 T 的开头再拼出同样的 S。两种删法都要分别计入。
- $S = X + T$（T 是 S 的后缀，X 是 S 长为 k 的前缀）：同理，X 等于 T 的真前缀或真后缀各对应一种不同的操作。

据此设 $f[i][j]$ 为子串 $s[i..j)$ 的分解方案数，其中计入「该子串本身就是初始串、不再做任何操作」这一种方案（初值 1），再加上所有可能的逆操作对应的 $f$ 值。每次逆操作得到的仍是原串的一段连续子串，所以按区间长度从小到大递推即可，无需字符串哈希或 map。两段等长子串是否相同用预处理的 LCP（最长公共前缀）表 $O(1)$ 判断。

由于循环条件 $2k < \text{len}$ 保证了 X 非空、T 中被删掉的部分也非空，并且递归到的子串长度至少为 2，刚好满足「初始串长度至少为 2」的要求。最后把 $f[0][n]$ 减去 1（去掉「零次操作」那一种方案）再对 2014 取模。
