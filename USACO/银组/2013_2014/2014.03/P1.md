# P1　灌溉田地（Watering the Fields）

## 题目

由于缺少降雨，农夫约翰想建一套灌溉系统，让水能在他的 $N$ 个田地之间流动（$1 \le N \le 2000$）。第 $i$ 个田地位于平面上互不相同的点 $(x_i, y_i)$，其中 $0 \le x_i, y_i \le 1000$。在两个田地 $i$ 和 $j$ 之间铺设管道的费用等于它们之间的平方欧氏距离：$(x_i - x_j)^2 + (y_i - y_j)^2$。

FJ 想用一套费用最小的管道把所有的田地连通起来，使得任意田地里的水都能沿着管道流到任何其他田地。

可惜帮忙安装的承包商会拒绝安装任何费用（即平方欧氏距离）小于 $C$ 的管道（$1 \le C \le 1000000$）。请帮 FJ 计算连通所有田地所需的最小花费。

## 输入

- 第 1 行：两个整数 $N$ 和 $C$。
- 第 2..N+1 行：第 $i+1$ 行包含两个整数 $x_i$ 和 $y_i$。

## 输出

共 1 行：连通所有田地的最小费用；如果无法建成这样的管道网络，输出 -1。

## 样例

输入：

```text
3 11
0 2
5 0
4 3
```

输出：

```text
46
```

样例说明：承包商不肯安装 $(4,3)$ 与 $(5,0)$ 之间的管道，因为它的费用只有 10。于是 FJ 在 $(0,2)$ 与 $(5,0)$ 之间铺一条费用 29 的管道，在 $(0,2)$ 与 $(4,3)$ 之间铺一条费用 17 的管道。

## 思路

把田地看作顶点、平方欧氏距离看作边权，问题就是「去掉所有权值小于 $C$ 的边之后的最小生成树」。因为每个点对之间都有一条边（完全图），不需要真的把边存下来：用 Prim 算法，维护 `best[j]` 表示「已接入部分」到未接入点 $j$ 的最短合法边。每轮先加入一个新点，用它与所有未接入点的距离（不足 $C$ 的忽略）松弛 `best`，再取 `best` 最小的点接入，累加费用。

若某一轮所有未接入点的 `best` 都还是「无穷大」，说明有点永远无法接入，输出 -1。费用总和可能达到 $2000 \times 2 \times 10^6$，超过 `int`，所以用 `long long` 累加。$N = 1$ 时不需要任何管道，循环不执行，直接输出 0。
