# P1　公平摄影（Fair Photography）

## 题目

农夫约翰的 N 头奶牛站在一条很长的篱笆旁，第 i 头奶牛站在位置 $x_i$（$0 \le x_i \le 10^9$），花色要么是纯白的（W），要么是带斑点的（S）。$2 \le N \le 100000$，没有两头牛站在同一位置，并且至少有一头白牛。

约翰要在县集市上拍一张"公平"的照片：照片拍下位置连续的一段奶牛，其中白牛和花牛的数量必须相等。为了能拍到更大的照片，他还带了一桶颜料，可以把任意多头白牛涂上斑点（涂完后它们算作花牛）。

照片的尺寸是照片中奶牛位置的最大值减去最小值。请求出他能拍出的最大尺寸。

## 输入

- 第 1 行：一个整数 $N$（$2 \le N \le 100000$）。
- 第 2..N+1 行：每行一个整数 $x_i$ 和一个字母 W 或 S，表示一头奶牛的位置和花色。保证所有位置互不相同，且至少有一头白牛。

## 输出

- 一行：最大照片尺寸。

## 样例

输入：

```text
5
8 W
11 S
3 W
10 W
5 S
```

输出：

```text
7
```

样例说明：拍下位置 3 到 10 的四头牛（3 W、5 S、8 W、10 W），其中 3 头白牛、1 头花牛，把一头白牛涂成花牛后正好各 2 头；尺寸为 $10-3=7$。

## 思路

先想清楚一段奶牛什么时候能变成"公平"的。设这段里有 $W$ 头白牛、$S$ 头花牛，要涂 $k$ 头白牛，则需要 $W-k=S+k$，即 $W-S=2k\ge 0$。所以条件只有两条：**白牛不少于花牛**，且**总头数 $W+S$ 是偶数**（否则白花之差是奇数，永远配不平）。

把奶牛按位置排序，白牛记 $+1$、花牛记 $-1$，做前缀和 $\text{prefix}[i]$。照片取 $\text{cows}[left+1 \ldots right]$ 时，两条条件写成：

1. $\text{prefix}[right]-\text{prefix}[left]\ge 0$，即 $\text{prefix}[left]\le\text{prefix}[right]$；
2. 头数 $right-left$ 是偶数，即 $left$ 与 $right$ 同奇偶。

于是把前缀下标按奇偶分成两类分别处理。对每个 $right$，我们要在同类里找一个**下标最小**的 $left$（且 $left \le right-2$，因为头数至少要 2）满足 $\text{prefix}[left]\le\text{prefix}[right]$：$left$ 越小，照片最左边的位置就越靠左，照片一定越大。注意这一步只可能新"解锁" $left=right-2$（再往前的更小下标在更早的 $right$ 上已经加过了）。

怎样快速回答"前缀和不超过给定值的最靠前下标"？观察：若两个同奇偶的下标 $a<b$ 满足 $\text{prefix}[a]\le\text{prefix}[b]$，那 $b$ 永远用不上——任何能拿 $b$ 当左端点的照片，换成更靠左的 $a$ 只会更大。所以每个类别里真正有用的下标，是那些不断刷新前缀和最小值的下标：把它们按加入顺序排列，**下标递增、前缀和严格递减**，形成一条阶梯；新下标只有在它的前缀和严格小于阶梯末尾时才加入，否则会被末尾那一项完全取代。

阶梯在两个方向上都单调（下标递增、前缀和递减），给定 $\text{prefix}[right]$ 后二分即可找出"前缀和不超过它的最靠前一项"，得到 $left$，再用 $\text{cows}[right]$ 与 $\text{cows}[left+1]$ 的位置差更新答案。

## 复杂度

时间 $O(N\log N)$：排序 $O(N\log N)$，每个 $right$ 在阶梯上二分一次 $O(\log N)$，每个下标最多入阶梯一次。空间 $O(N)$。
