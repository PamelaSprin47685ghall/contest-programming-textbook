# P2　马拉松（Marathon）

## 题目

贝茜报名了一个跑步班，老师让她跑一场马拉松。马拉松路线由 $N$ 个检查点组成，必须按顺序依次经过：第 $1$ 个检查点是起点，第 $N$ 个是终点。贝茜很懒，她决定最多跳过 $K$ 个检查点来缩短总路程，但她不能跳过第 $1$ 个和第 $N$ 个检查点（那样太明显了）。

请你帮贝茜算出：最多能跳过 $K$ 个检查点时，她最少要跑多远。

城市是网格状街道，所以两个检查点 $(x_1,y_1)$ 与 $(x_2,y_2)$ 之间的距离是曼哈顿距离 $|x_1-x_2|+|y_1-y_2|$。

## 输入

第一行两个整数 $N,K$（$3 \le N \le 500$，$K < N$）。

接下来 $N$ 行，每行两个整数 $x,y$（$-1000 \le x,y \le 1000$），表示一个检查点的坐标。检查点按必须经过的顺序给出。路线可能多次穿过自己，也可能有多个检查点在同一位置；跳过某个检查点时只跳过那一个实例。

## 输出

输出一个整数：最多跳过 $K$ 个检查点后，贝茜最少要跑的总距离。

## 样例

输入：

```text
5 2
0 0
8 3
1 1
10 -5
2 2
```

输出：

```text
4
```

样例中跳过 $(8,3)$ 与 $(10,-5)$ 两个检查点，总距离为 $4$，是最小的。

## 思路

跳过检查点之后，贝茜实际停留的检查点构成原序列的一个子序列，且必须包含第 $1$ 个和第 $N$ 个，被跳过的检查点就是"没有停留"的那些。所以问题等价于：选出一个包含首尾的子序列，使相邻停留点之间的曼哈顿距离之和最小，且被跳过的个数不超过 $K$。

这是典型的按"上一个停留点"转移的 DP。设 `dp[skipped][i]` 表示已经跳过了 `skipped` 个检查点、最后停留（必须经过）在第 $i$ 个检查点时，从起点跑到这里的最小距离。转移时枚举下一个停留点 $l$（$l>i$），中间被跳过的正是 $l-i-1$ 个：

```text
dp[skipped + (l - i - 1)][l] = min(dp[skipped][i] + dist(i, l))
```

这样按停留点逐步向后推进，天然保证了检查点必须按顺序经过。注意跳过数不能超过 $\min(K, N-2)$，因为首尾不能跳；`l` 一旦让跳过数越界就可以直接 `break`（$l$ 继续增大只会跳得更多）。

题目允许"至多跳过 $K$ 个"，所以最后要把恰好跳过 $0 \dots \min(K,N-2)$ 个、终点为第 $N$ 个检查点的所有状态取最小值作为答案（多跳过几个不会让路程变长，但直接取最小更稳妥）。

## 复杂度

时间 $O(NK^2)$：每个状态枚举下一个停留点时，最多只有 $K+1$ 种跳过的段长，$N,K \le 500$ 时约 $6\times10^7$ 次转移。空间 $O(NK)$：状态表 `dp[K+1][N]`。
