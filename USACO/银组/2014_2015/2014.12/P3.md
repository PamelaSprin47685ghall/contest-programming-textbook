# P3　奶牛慢跑（Cow Jog）

## 题目

奶牛们又出来活动蹄子啦！有 $N$ 头奶牛在一条无限长的单车道跑道上慢跑。每头奶牛从跑道上不同的位置出发，有些奶牛的速度还不一样。

跑道只有一条，奶牛之间不能互相超越。当一头跑得快的奶牛追上前面一头奶牛时，她必须减速以免撞上，于是两头牛就变成了同一个跑步小组。

奶牛们会跑 $T$ 分钟，请帮农夫约翰算出这段时间结束后还剩下多少个小组。两头奶牛在 $T$ 分钟结束时处在同一位置，就认为它们属于同一个小组。

## 输入

第一行两个整数 $N,T$（$1 \le N \le 100000$，$1 \le T \le 10^9$）。

接下来 $N$ 行，每行两个整数，表示一头奶牛的位置和速度。位置是非负整数，速度是正整数，两个数都不超过 $10^9$。所有奶牛初始位置互不相同，且按从小到大的顺序给出。

## 输出

输出一个整数：$T$ 分钟后剩下的组数。

## 样例

输入：

```text
5 3
0 1
1 2
2 3
3 2
6 1
```

输出：

```text
3
```

## 思路

先算每头奶牛"一路不被挡住"时 $T$ 分钟后的位置 $x_i + s_i\cdot T$。真正能决定分组的是：一头奶牛会不会被前面的牛拦下来。

因为跑道单车道、不能超车，后面的奶牛永远不可能超过前面的奶牛，所以第 $i$ 头奶牛的实际终点一定等于

$$\min\big(x_i+s_iT,\ \text{前面所有奶牛实际终点的最小值}\big).$$

位置按升序给出，也就是下标小的奶牛在后面、下标大的在前面。于是从最前面的奶牛（下标 $N$）往回想，用一个变量维护"已经扫过的、更靠前的那些牛的实际终点中最靠后的那个值"：

- 如果当前奶牛的自由终点比它更靠后（严格小于），说明这头牛不会被任何前面的牛拦住，它会自己形成一个新的小组，同时把这个更小的值变成新的"最靠后的实际终点"；
- 否则这头牛一定会追上前面的某个小组并停在同一个位置，不产生新的组。

最前面的奶牛没有人挡它，必定是一个组的起点，所以答案从 $1$ 开始累加。注意判断必须用严格小于：如果自由终点与前面实际终点相等，说明这头牛恰好并到同一位置，应当算作同一组。

位置、速度、时间都能到 $10^9$，终点位置在 $10^{18}$ 量级，因此位置和答案都要用 `long long`。
