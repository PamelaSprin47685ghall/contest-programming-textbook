# P1　惊逃的牛群（Stampede）

## 题目

FJ 的 $N$ 头奶牛看似沿着农场前的路惊逃，其实是在赛跑，比谁跑得最快。

从上方看，每头奶牛是一段长度为 1 的水平线段。题目给出她在 $t=0$ 时左端点的坐标 $(x,y)$，也就是说这头牛此刻占据从 $(x,y)$ 到 $(x+1,y)$ 的线段。每头奶牛都以固定速度向右（$+x$ 方向）走：每 $r$ 单位时间移动 1 个单位长度。

FJ 站在原点 $(0,0)$，沿 $+y$ 方向看出去。一头奶牛被她挡住时，就是她"可见"的；如果一头奶牛曾经是这条视线（直线 $x=0$）上最靠前（$y$ 最小）的那一头，FJ 就能看到她。问整场比赛下来，FJ 一共能看到多少头奶牛。

## 输入

第一行一个整数 $N$（$1 \le N \le 50000$）。

接下来 $N$ 行，每行三个整数 $x$、$y$、$r$：左端点 $t=0$ 时在 $(x,y)$，其中 $-1000 \le x \le -1$，$1 \le y \le 1000000$（所有 $y$ 互不相同，保证不会有两头牛恰好并列），$1 \le r \le 1000000$。

## 输出

一个整数：FJ 能看到的奶牛数量。

## 样例

输入：

```text
3
-2 1 3
-3 2 3
-5 100 1
```

输出：

```text
2
```

解释：FJ 能看到 1、2 号奶牛，看不到 3 号。

## 思路

奶牛会不会被看到，只取决于她经过视线 $x=0$ 的那段时间里，有没有别的牛比她更靠前。

先算这段时间。$t$ 时刻这头牛占据的线段是 $[x + t/r,\ x+1+t/r]$，它盖住 $x=0$ 当且仅当

$$x + \frac{t}{r} \le 0 \le x+1+\frac{t}{r},$$

解得 $t \in [-(x+1)r,\ -xr]$。右端点先到原点（时刻 $-(x+1)r$），她开始进入视线；左端点走过原点（时刻 $-xr$），她离开视线。于是每头奶牛都变成时间轴上的一个区间，问题变成：

> 在时间轴上扫描，每个"视线非空"的时刻，$y$ 最小的那头牛被看到；问一共能记录到几头不同的牛。

用扫描线做。把每头牛的进入、离开当成两个事件，按时间排序；用 `set` 维护当前在视线上的奶牛（按 $y$ 有序，队首就是最靠前的那头）。每当有牛进入视线，就把她插入集合；离开就删除。处理完一个时刻的所有事件后，如果集合非空，队首的 $y$ 就是此刻被看到的牛。

有一个容易出错的细节：**同一时刻的进入和离开必须一起处理完再取最小值**。因为区间是闭的，那一瞬间新牛和老牛的线段都盖在 $x=0$ 上，谁都不能漏掉。样例里第 6 时刻 1 号牛离开、2 号牛进入，处理完这一组事件后 2 号牛就被看到，答案才是 2。

题目保证 $y$ 互不相同，所以"当前最靠前的牛"唯一，不会出现并列导致的歧义；也正因为 $y$ 互不相同，我们可以直接用 $y$ 当作这头牛的编号来记录她是否被看到过。

## 复杂度

每头牛产生 2 个事件，排序与集合操作都是 $O(N \log N)$。时间 $O(N \log N)$，空间 $O(N)$。
