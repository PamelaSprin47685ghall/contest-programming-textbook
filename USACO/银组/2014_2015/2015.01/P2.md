# P2　奶牛航线（Cow Routing）

## 题目

Bessie 受够了农场的寒冬，打算飞去温暖的地方度假。可唯一愿意卖票给奶牛的是 Air Bovinia 航空公司，而且它的票有点特别：

公司有 $N$ 架飞机，每架飞一条固定的"航线"，航线是一串不同的城市。如果 Bessie 用某条航线出行，她可以在航线上的任意一个城市登机、在之后的任意一个城市下机（不必是第一站或最后一站），但要为这条航线付一整笔固定的机票钱；一条航线如果用了多次（中途离开后又回来接着用），每次都要付钱。

Bessie 想从农场所在的城市 $A$ 飞到度假城市 $B$。请算出最少要花多少钱；如果不止一种办法花到最少的钱，还要算出最少要坐多少次航班（相邻两站之间算一次）。

## 输入

第一行三个整数 $A$、$B$、$N$，用空格隔开（$1 \le N \le 1000$）。

接下来每条航线占两行，共 $2N$ 行：

- 第一行两个整数：用这条航线的花费（$1 \le$ 花费 $\le 10^9$）和航线上城市的个数（$1 \le$ 个数 $\le 100$）；
- 第二行是航线上按顺序排列的城市编号（每个城市编号在 $1$ 到 $1000$ 之间）。

注意总花费可能超过 32 位整数能表示的范围，要用 64 位整数（C/C++ 的 `long long`）。

## 输出

一行两个整数：从 $A$ 到 $B$ 的最小花费，以及在这个最小花费下最少需要坐的航班数。如果无解，输出 `-1 -1`。

## 样例

输入：

```text
3 4 3
3 5
1 2 3 4 5
2 3
3 5 4
1 2
1 5
```

输出：

```text
2 2
```

解释：买第二条航线（花费 2）的票，从 3 号城登机，坐 3 → 5 → 4 共 2 个航班到达。第一条航线能 3 → 4 一步直达（只坐 1 个航班），但要花 3，比 2 贵，所以不选。答案是 `2 2`。

## 思路

把行程拆成两步看：先确定"从 $u$ 买一张票一步直飞到 $v$"的最优代价，再把这些直飞串起来。

**第一步：预处理直飞。** 对于一条航线，枚举其中任意一前一后的两站 $k < j$：花这笔机票钱就能从第 $k$ 站一站直飞到第 $j$ 站，航班数是沿途经过的站数 $j-k$。于是每对 $(u,v)$ 只需保留最小的二元组 $(\text{花费},\ \text{航班数})$，记为 `direct[u][v]`。这种做法是安全的：被支配的直飞（花费更高，或花费相同但航班更多）永远不会出现在最优行程里。

**第二步：在直飞网络上跑最短路。** 把城市当点、`direct` 中有限的二元组当边权，从 $A$ 出发做 Dijkstra。边权是二元组，但加法是分量相加、比较是先比花费再比航班数，这正是字典序；由于它满足"两边同时加上同一个量后大小关系不变"，Dijkstra 依然成立。

城市总共只有 $1000$ 个，而直飞边可能很稠密，所以这里用不借助堆的 $O(V^2)$ 写法：每一轮扫一遍所有未定城市，挑出代价最小的那个，再用它松弛所有城市。这比堆版本更好写，也不会更慢。

最后如果 $B$ 的代价仍是无穷大就输出 `-1 -1`，否则输出 $B$ 的二元组。起始时把 $A$ 的代价设为 $(0,0)$，待在同城不花钱也不坐飞机，所以 $A = B$ 时会输出 `0 0`。

## 复杂度

预处理要枚举每条航线的所有前后站对，共 $O(N M^2)$（$M \le 100$ 是航线长度）；Dijkstra 是 $O(V^2)$（$V \le 1000$）。总时间 $O(NM^2 + V^2)$，空间 $O(V^2)$。
