# P2　被困在干草堆里（Trapped in the Haybales (Silver)）

## 题目

农夫约翰收到了一批共 $N$ 块（$1 \le N \le 100000$）大干草堆，把它们放在连接谷仓和他家的那条路两旁。第 $j$ 块干草堆的大小是 $S_j$，位置是 $P_j$（位置互不相同）。贝茜站在位置 $B$，那里没有干草堆。

贝茜可以沿路自由走动，甚至能走到干草堆所在的位置，但不能穿过去。唯一的例外是：如果她朝同一个方向连续跑了 $D$ 个单位距离，就积累了足够的速度，可以撞穿并永久消灭任何大小**严格小于** $D$ 的干草堆。撞穿之后她可能有更大的活动空间，去撞别的干草堆。

约翰正在粉刷房子和谷仓，他不能让贝茜跑到两边去。于是他希望贝茜永远撞不穿最左和最右的干草堆，也就是被干草堆牢牢困住。他可以给选定的**一块**干草堆补加干草。请帮他求出：为了困住贝茜，最少需要补加多少干草。

## 输入

第一行两个整数 $N$ 和贝茜的初始位置 $B$。

接下来 $N$ 行，每行两个整数，表示一块干草堆的大小和位置。所有大小和位置都在 $1 \dots 10^9$ 之间。

## 输出

一个整数：为了阻止贝茜逃跑最少要补加的干草量。如果无论如何都拦不住她，输出 `-1`。

## 样例

输入：

```text
5 7
8 1
1 4
3 8
12 15
20 20
```

输出：

```text
4
```

解释：贝茜在位置 $7$，左边的干草堆在位置 $1$（大小 8）和 $4$（大小 1），右边的在位置 $8$（大小 3）、$15$（大小 12）、$20$（大小 20）。给位置 $8$ 的那块补 4 单位干草（大小变成 7）她就被困住了：她最多能从位置 $1$ 助跑到位置 $8$，距离 $7$，撞不破大小 7 的这块；反过来从位置 $8$ 向左跑到位置 $1$，距离也是 $7$，而那块大小是 8，同样撞不破。一块都不补则不行：她可以从左边一路助跑，先后撞穿位置 $8$、$4$、$1$ 的三块，逃到左边去。枚举所有可行方案，需要的干草都不少于 4，所以答案是 4。

## 思路

先按位置排序，这样贝茜左边的干草堆是一段前缀 $[0, start-1]$，右边是一段后缀 $[start, N-1]$（`start` 是第一块位于 $B$ 右侧的干草堆）。

贝茜被夹在两块撞不破的干草堆之间时，她向一侧助跑的距离就是这两块干草堆之间的距离。所以整个局面只由一对"墙"决定：设左边第 $i$ 块、右边第 $j$ 块是两块墙，距离 $d = P_j - P_i$，那么

- 只有当 $d \le S_i$ 时，第 $i$ 块才挡得住她（撞穿需要 $D > S$，$D \le S$ 就撞不破）；
- 同理，只有当 $d \le S_j$ 时第 $j$ 块才挡得住她。

我们只有一次补加干草的机会，所以两只墙里至少有一只本来就挡得住，另一只才需要补：补完后的新大小要 $\ge d$。

- 若 $d \le S_i$：补右边第 $j$ 块，需要补 $d - S_j$；
- 若 $d \le S_j$：补左边第 $i$ 块，需要补 $d - S_i$；
- 两个条件都不满足：这一对不可能用一次补加救回来。

答案就是所有可行方案里补加量的最小值；如果一对可行的都没有，输出 `-1`。

直接枚举所有 $(i,j)$ 对是 $O(N^2)$ 的，太慢。关键观察是：固定左边的一块 $i$，"左边已经挡得住"的条件 $P_j - P_i \le S_i$ 对 $j$ 是一条前缀。当 $i$ 向左移动时 $P_i$ 变小，$P_j - P_i$ 变大，满足条件的 $j$ 只会变少，也就是**前缀长度单调不增**。于是两个指针 $i$（从 $start-1$ 递减）和 $j$（从 $start$ 递增）各自只需单向走一遍：

```text
for i = start-1 down to 0:
    while j < N 且 P_j <= P_i + S_i:
        用 (P_j - P_i - S_j) 更新答案;  j++
```

注意这里被跳过的 $(i,j)$ 对不会漏掉最优解：指针 $j$ 停住，说明对当前的 $i$ 来说，$j$ 已经远到能被她撞破（$P_j - P_i > S_i$），那么 $i$ 再往左移只会更拦不住，这一对永远不可行；而 $j$ 之后的对更是如此。对右边做同样的镜像扫描（固定右边第 $i$ 块挡得住，向右补左边第 $j$ 块），两种情况合起来就覆盖了全部可行方案。答案可能是负数（本来就不需要补，或者补的量算出来小于 0），最后要和 $0$ 取最大值。

另外两处边界：如果所有干草堆都在贝茜的一侧，就找不到任何一对把她夹住的墙，答案就是 `-1`；最后输出时用 `max(result, 0)` 处理"不用补"的情形。

## 复杂度

排序 $O(N \log N)$，之后两个指针各自单调移动，扫描共 $O(N)$；总时间 $O(N \log N)$，空间 $O(N)$。
