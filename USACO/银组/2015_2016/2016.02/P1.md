# P1　圆形谷仓（Circular Barn）

## 题目

农夫约翰建了一座圆形谷仓，里面是 $n$ 个房间，沿圆周顺时针编号 $1$ 到 $n$（$3 \le n \le 1000$）。每个房间有门通向左右两个相邻房间，还有一扇通向室外的门。

约翰有 $n$ 头奶牛，他希望每个房间最终恰好住一头牛。奶牛们稀里糊涂地在门口排队，第 $i$ 个房间的室外门口有 $c_i$ 头奶牛排队，保证 $\sum c_i = n$。

每头奶牛从自己排队的那扇门进场，然后沿顺时针方向走过若干个房间，直到走到一间空房住下。一头奶牛走过 $d$ 扇内部门要消耗 $d^2$ 单位能量。请算出把所有奶牛安排好的最小总能量消耗。

## 输入

第一行一个整数 $n$。

接下来 $n$ 行，每行一个整数，依次是 $c_1 \ldots c_n$。

## 输出

一行一个整数：最小的总能量消耗。

## 样例

输入：

```text
10
1
0
0
2
0
0
1
2
2
2
```

输出：

```text
33
```

## 思路

先想清楚"谁先住下"。设奶牛甲比奶牛乙先进场，两人的进场位置分别是 $a \le b$。如果甲被安排到了靠后的房间 $r_1$，而乙住进了靠前的房间 $r_2$（$r_1 \ge r_2$，位置都按顺时针度量），那么交换两人的目的地并不会破坏方案的合法性（两人的新目的地仍在自己起点的顺时针方向），而能量之差

$$(r_1-a)^2+(r_2-b)^2-\left[(r_2-a)^2+(r_1-b)^2\right]=(r_1-r_2)(2b-2a)\ge 0$$

说明交换后不会变差。因此**先进场的奶牛先住下**（先来先服务）总可以得到最优解。

圆环上的难点是"绕圈"：某头奶牛可能跨过我们观察的起点。由上面的交换论证可以知道，最优解中一定存在一个合适的起点，使得从它开始顺时针模拟时每一间房都能分到一头牛（也就是没有任何奶牛需要跨过这道"接缝"）。于是：

1. 枚举 $n$ 个可能的起点（接缝）；
2. 对每个起点把圆环剪成一条链，从左到右模拟：维护一个"已经进场、还没住下"的奶牛队列，每走到一间房，先把在这扇门口排队的 $c_i$ 头奶牛加入队尾，然后让队首（进场最早、走得最远的奶牛）住下，能量增加 $d^2$，其中 $d$ 是它走过的房间数；
3. 如果某一间房轮到时队列为空（没有奶牛能住进去，等价于要求某些奶牛逆时针走），说明这个接缝不合法，直接丢弃——绝不能把这种方案的能量计入答案，否则会得到比真正最优解还小的错误值。

有 $n$ 个起点，每个起点 $O(n)$ 模拟，$n \le 1000$ 完全够用。
