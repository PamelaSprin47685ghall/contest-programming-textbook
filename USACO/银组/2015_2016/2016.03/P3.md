# P3　关闭农场（Closing the Farm）

## 题目

农夫约翰和奶牛们准备出远门度假，为了省钱他想暂时关闭农场。

农场由 $N$ 个谷仓和 $M$ 条双向道路构成（$1 \le N, M \le 3000$）。关闭农场的流程是：每次关闭一个谷仓；某个谷仓关闭后，与它相连的所有道路也一并关闭，不能再走。

约翰关心在每一个时刻（最初，以及每次关闭之后）农场是否「完全连通」——也就是能否从任意一个仍开着的谷仓沿道路走到任意另一个仍开着的谷仓。由于农场本来就年久失修，最初它甚至可能就不连通。

## 输入

第一行两个整数 $N$ 和 $M$。

接下来 $M$ 行，每行两个整数，表示一条道路连接的两个谷仓（谷仓编号 $1 \ldots N$）。

最后 $N$ 行给出 $1 \ldots N$ 的一个排列，表示谷仓的关闭顺序。

## 输出

输出 $N$ 行，每行 `YES` 或 `NO`。第一行表示最初农场是否完全连通，第 $i+1$ 行表示第 $i$ 次关闭之后农场是否完全连通。

## 样例

输入：

```text
4 3
1 2
2 3
3 4
3
4
1
2
```

输出：

```text
YES
NO
YES
YES
```

## 思路

每次删掉一个点并重新做一次搜索是 $O(N(N+M))$，在 $N, M \le 3000$ 时虽然能过，但更漂亮的做法是**把过程倒过来**。

正着走是「删点、删边」，并查集只擅长加边，不擅长删边；倒着走就变成「从空农场出发，按关闭顺序的逆序逐个重新开放谷仓」，每开放一个谷仓 $u$，就把它与所有**已经开放**的邻居合并——这全是加边操作，正好用并查集维护。

用一个变量 `comps` 记录当前连通块个数：每开放一个谷仓先 `comps++`，每次成功合并两个不同的连通块就 `comps--`。那么「剩余谷仓完全连通」等价于 `comps <= 1`。

倒序处理时，状态 $i$（已开放 $order[i \ldots N-1]$）恰好对应「前 $i$ 次关闭之后」的状态，因此 `ans[i] = (comps <= 1)`，最后按 $i$ 从 $0$ 到 $N-1$ 依次输出，第一行就是最初的状态。
