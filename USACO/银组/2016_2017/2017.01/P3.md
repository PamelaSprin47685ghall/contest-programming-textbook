# P3　秘密奶牛代码（Secret Cow Code）

## 题目

奶牛们正在试验一种密码，并设计出一种生成无限长字符串的方法。

给定字符串 $s$，记 $F(s)$ 为"$s$ 后面接上 $s$ 向右循环移位一位的结果"（右移一位时，$s$ 的最后一个字符绕到最前面）。从一个初始串出发，反复施加 $F$，每一步长度翻倍，就得到奶牛们的无限长密码串。

给定初始串与下标 $N$，求无限长串第 $N$ 个字符（下标从 $1$ 开始）。

## 输入

一行，包含一个字符串（长度不超过 $30$，只含大写字母）和一个整数 $N$（$N \le 10^{18}$）。

注意 $N$ 可能超出 32 位整数范围，需要使用 64 位整数类型（C/C++ 中的 `long long`）。

## 输出

初始串生成的无限长串中第 $N$ 个字符。

## 样例

输入：

```text
COW 8
```

输出：

```text
C
```

解释：初始串按如下方式扩张，第 $8$ 个字符是 `C`。

```text
COW -> COWWCO -> COWWCOOCOWWC
 12345678
```

## 思路

虽然串是无限的，但它的结构非常规整，可以**逆向缩小下标**而不需要真的构造串。

设当前考虑的层级长度为 $2m$，它由长度 $m$ 的上一层串 $s'$ 翻倍而成：即 $s' + \text{rot}(s')$。若目标下标落在后半段 $[m, 2m-1]$，就把它换算回上一层中的位置：

- 若下标恰好是 $m$（后半段的第一个字符），它是 $\text{rot}(s')$ 的首字符，也就是 $s'$ 的最后一个字符，位置为 $m-1$；
- 否则，该位置是 $\text{rot}(s')$ 中整体后移了一位的结果，对应 $s'$ 中位置 $m$ 之后的下标减去 $m$ 再减 $1$。

于是从初始长度 $len = |s|$ 出发，反复令 $len \times 2$ 直到 $2 \cdot len > N$（即 $N$ 落在区间 $[len, 2\cdot len)$ 的后半段），再用上面的映射把下标缩小到上一层，递归（或循环）下去；当下标小于 $|s|$ 时，答案就是初始串中对应的字符。每缩小一层长度至少减半，因此总共只有 $O(\log N)$ 次换算。
