# P3　奶牛为什么要过马路 III（Why Did the Cow Cross the Road III）

## 题目

奶牛为什么要过马路？原因之一是 FJ 农场里的路实在太多，牛到处走动时不得不穿过很多条路。

FJ 的农场是一个 $N \times N$ 的正方形网格（$2 \le N \le 100$）。某些相邻的格子之间（南北向或东西向）被路隔开，整个网格的外围还有一道高高的栅栏，牛无法离开农场。牛可以在任意两个相邻（北、东、南、西）的格子之间自由移动，只是除非万不得已，它们不愿穿过马路。

农场上有 $K$ 头牛（$1 \le K \le 100$，$K \le N^2$），每头牛位于不同的格子里。如果一头牛要拜访另一头牛时至少得穿过一条路，就称这对牛是"远距离"的。请帮 FJ 统计远距离牛对的数量。

## 输入

第一行三个整数 `N K R`。

接下来 $R$ 行，每行四个整数 `r c r' c'`（均在 $1 \ldots N$ 范围内），表示 $(r,c)$ 与相邻格子 $(r',c')$ 之间存在一条路。

最后 $K$ 行，每行两个整数，表示一头牛所在的行和列。

## 输出

一个整数：远距离牛对的数量。

## 样例

输入：

```text
3 3 3
2 2 2 3
3 3 3 2
3 3 2 3
3 3
2 2
2 3
```

输出：

```text
2
```

解释：$(2,3)$ 到 $(3,3)$ 有路，$(3,2)$ 到 $(3,3)$ 也有路，而 $(3,3)$ 的另外两个方向已经出界，所以 $(3,3)$ 被单独围成一个连通块，其余格子（含 $(2,2)$、$(2,3)$）构成另一个连通块。位于 $(3,3)$ 的牛与另外两头牛相会都得穿路，故远距离牛对数为 $2$。

## 思路

把每个格子看成图中的一个点，相邻且之间没有路的格子连一条边。这样牛能自由走动的范围就是图的一个连通块；位于同一连通块内的两头牛可以不相穿任何路就相会，位于不同连通块的两头牛之间必定至少隔着一条路。

因此"远距离"牛对数 $=$ 总牛对数 $-$ 同一连通块内的牛对数。

做法是：

1. 对每个格子做一次 BFS，得到它所在的连通块编号（遇到某个方向有路就不能往那边走，出界也不行）；
2. 在 BFS 过程中顺便统计每个连通块里的牛数；
3. 设连通块 $i$ 里有 $c_i$ 头牛，则答案为 $\binom{K}{2} - \sum_i \binom{c_i}{2}$。
