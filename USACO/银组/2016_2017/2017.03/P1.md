# P1　配对（Paired Up）

## 题目

农民约翰发现，如果自己的奶牛身边有另一头奶牛陪伴，挤奶会更容易。因此他想把 $M$ 头奶牛（$M \le 10^9$，$M$ 为偶数）分成 $M/2$ 对，每对奶牛被送到牛棚中一间单独的小隔间里挤奶，所有隔间同时开始挤奶。

每头奶牛的产奶量都不相同。如果产奶量分别为 $A$ 和 $B$ 的两头奶牛配成一对，那么把它们两个都挤完需要 $A+B$ 单位时间。

请帮助约翰确定整个挤奶过程最少需要多长时间，假设他按最优方式配对。

## 输入

第一行一个整数 $N$（$1 \le N \le 10^5$）。接下来 $N$ 行，每行两个整数 $x$ 和 $y$，表示约翰有 $x$ 头产奶量均为 $y$ 的奶牛（$1 \le y \le 10^9$）。所有 $x$ 之和为 $M$，即奶牛总数。

## 输出

一个整数：最优配对下整个挤奶过程所需的最少时间。

## 样例

输入：

```text
3
1 8
2 5
1 2
```

输出：

```text
10
```

解释：把产奶量为 $8$ 的奶牛和产奶量为 $2$ 的奶牛配对，两头产奶量为 $5$ 的奶牛互相配对，两间隔间都耗时 $10$。由于挤奶同时进行，整个过程在 $10$ 单位时间后结束；其他任何配对方式都会让某个隔间耗时超过 $10$。

## 思路

先看两头奶牛配对的规律。设有四头奶牛，产奶量满足 $A < B < C < D$：

- 若配成 $(A,B)$ 与 $(C,D)$，两间隔间耗时 $A+B$ 与 $C+D$，整个过程的耗时是 $C+D$。把 $B$ 和 $D$ 互换，改成 $(A,D)$ 与 $(B,C)$，此时 $A+D < C+D$、$B+C < C+D$，最大耗时变小。
- 若配成 $(A,C)$ 与 $(B,D)$，最大耗时是 $B+D$。把 $C$ 和 $D$ 互换，改成 $(A,D)$ 与 $(B,C)$，同样有 $A+D < B+D$、$B+C < B+D$。

也就是说，只要最低产奶量的奶牛没有和最高产奶量的奶牛配对，总能把配对改成"最小配最大"而不会让结果变差。于是最优方案是：产奶量最低的奶牛与最高的配对，剩下的奶牛重复同样的操作。

但奶牛总数可达 $10^9$，不能逐头处理。输入已经按产奶量把奶牛分组，所以把各组按 $y$ 升序排序后，用两个下标分别指向当前最低和最高的两组，每次让两边各取 $\min(x_{low}, x_{high})$ 头牛配对——这样每一轮一定会有一组被取空，组数减少，总轮数是 $O(N)$。若最后两个下标重合，说明只剩一种产奶量，剩下的奶牛只能同产奶量互相配对，每对耗时就是 $2y$。

答案取各轮耗时的最大值。
