# P2　奶牛基因组（Bovine Genomics）

## 题目

农民约翰有 $N$ 头有斑点的奶牛和 $N$ 头没有斑点的奶牛。他相信斑点是由奶牛基因组中的突变引起的。

每头奶牛的基因组都是一个长度为 $M$、只由 `A`、`C`、`G`、`T` 组成的字符串。把这些基因组上下对齐后，就得到一张表，每一列是一个位置。

约翰认为斑点不是由某一个或两个位置决定的，而是由三个不同的位置决定的。如果只观察某三个位置上的字符，就能在约翰的牛群中完美判断出哪头牛有斑点、哪头牛没有，那么这三个位置就能"解释斑点"。

请数出能解释斑点的三个不同位置的选择方案数。

## 输入

第一行两个整数 $N$ 和 $M$（$1 \le N \le 500$，$3 \le M \le 50$）。

接下来 $N$ 行，每行一个长度为 $M$ 的字符串，描述一头有斑点的奶牛的基因组。

最后 $N$ 行，每行一个长度为 $M$ 的字符串，描述一头没有斑点的奶牛的基因组。

## 输出

一个整数：能解释斑点的三位置方案数。

## 样例

输入：

```text
3 8
AATCCCAT
GATTGCAA
GGTCGCAA
ACTCCCAG
ACTCGCAT
ACTTCCAT
```

输出：

```text
22
```

## 思路

一组三个位置能解释斑点，等价于：不存在一头有斑点的奶牛和一头没有斑点的奶牛，在这三个位置上的字符完全相同。因为一旦出现这样的两头牛，只看这三个位置就无法把它们区分开。

于是枚举所有 $\binom{M}{3}$ 组位置。对每组位置，先把 $N$ 头有斑点奶牛在这三个位置上的字符记下来，再看 $N$ 头无斑点奶牛中是否有哪一头也产生了同样的记录；若有，这组位置就作废。

判断"同样的记录"不必真的存字符串：把 `A`、`C`、`G`、`T` 编码为 $0,1,2,3$，三个位置的编码为 $a,b,c$，则三元组可以用四进制数 $16a+4b+c$ 唯一表示，取值范围恰好是 $0 \ldots 63$，用一个大小为 $64$ 的数组打标记即可。每组位置用完后要把标记清空。
