# P3　贝茜在哪里？（Where's Bessie?）

## 题目

农夫约翰正在测试一台无人机挂载的自动奶牛定位相机。相机能拍下农场俯视图，但找牛的算法不够好，需要你帮忙改进。

俯视图是一个 $N \times N$ 的字符网格，每个字符是 `A` 到 `Z` 之一，表示 $26$ 种颜色之一。

约翰把一个"潜在奶牛位置"（PCL）定义为满足以下条件的矩形子网格（可以覆盖整张图，边与网格边平行）：

- 它不被任何其他 PCL 包含（即不能再往外套一个更大的 PCL）；
- 只看该矩形内部、忽略外部，矩形中恰好出现两种颜色，其中一种颜色形成一个连通区域，另一种颜色形成两个或更多连通区域。

例如矩形内容为

```text
AAAAA
ABABA
AAABB
```

时就是一个 PCL：`A` 只形成一个连通块，`B` 形成多个连通块，可以理解为一只带 `B` 色斑点的 `A` 色奶牛。

"连通"指从区域中任一格子出发，每次向上、下、左、右移动一格，都能走到区域内其他格子。

给定相机拍到的图像，请数出 PCL 的个数。

## 输入

第一行一个整数 $N$（$1 \le N \le 20$）。

接下来 $N$ 行，每行 $N$ 个字符，描述图像。

## 输出

一个整数：图像中 PCL 的个数。

## 样例

输入：

```text
4
ABBC
BBBC
AABB
ABBC
```

输出：

```text
2
```

解释：两个 PCL 分别是内容为

```text
ABB
BBB
AAB
ABB
```

和

```text
BC
BC
BB
BC
```

的矩形。

## 思路

矩形由左上角和右下角唯一确定，上下端点各有 $\binom{N+1}{2}$ 种选法，因此总共有 $O(N^4)$ 个矩形。$N \le 20$ 时矩形总数不超过 ${21 \choose 2}^2 = 44100$，可以全部枚举。

对每个矩形判断它是否满足"两色 + 连通块条件"：在矩形内做一遍洪水填充，用 `visited` 记录每格属于哪个连通块，同时统计每种颜色形成了几个连通块。最终要求颜色数恰好为 $2$，且一种颜色的连通块数为 $1$、另一种至少为 $2$。一次填充每个格子只访问一次，单个矩形耗时 $O(N^2)$。

第二步处理"不被任何其他 PCL 包含"。把所有满足上述条件的矩形记下来：若某个这样的矩形 $R$ 被另一个这样的矩形 $S$ 包含，则 $R$ 不是 PCL（$S$ 若不满足条件，也总存在包含 $S$ 的极大合法矩形把 $R$ 一起包住）。因此只需把所有合法矩形两两比较包含关系，没有被别人包含的就是 PCL。

## 复杂度

时间 $O(N^6 + |V|^2)$，其中 $|V|$ 是满足两色与连通块条件的矩形个数（不超过 $44100$）；空间 $O(N^2 + |V|)$。
