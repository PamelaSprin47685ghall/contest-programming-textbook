# P3　哞Tube（MooTube）

## 题目

农夫约翰办了一个视频网站，叫做 MooTube。网站上一共有 $N$ 个视频（$1 \le N \le 5000$），编号 $1 \ldots N$。他手工比较了 $N-1$ 对视频的相关度 $r_i$，并且这些比较恰好把视频连成一棵树：任意两个视频之间有且只有一条由比较连成的通路。

两个视频的相关度定义为它们之间通路上所有比较的相关度的**最小值**。约翰想回答 $Q$ 个询问：给 $K$ 和视频 $v$，与 $v$ 的相关度至少为 $K$ 的其他视频有多少个？

## 输入

第一行两个整数 $N$、$Q$（$1 \le Q \le 5000$）。

接下来 $N-1$ 行，每行三个整数 $p_i$、$q_i$、$r_i$（$1 \le p_i, q_i \le N$，$1 \le r_i \le 10^9$），表示视频 $p_i$ 与 $q_i$ 之间有一条相关度为 $r_i$ 的比较。

接下来 $Q$ 行，每行两个整数 $k_i$、$v_i$（$1 \le k_i \le 10^9$，$1 \le v_i \le N$），表示一个询问。

## 输出

$Q$ 行，第 $i$ 行是第 $i$ 个询问的答案：与视频 $v_i$ 的相关度至少为 $k_i$ 的其他视频数量。

## 样例

输入：

```text
4 3
1 2 3
2 3 2
2 4 4
1 2
4 1
3 1
```

输出：

```text
3
0
2
```

解释：视频 1 与 2 的相关度是 3，2 与 3 是 2，2 与 4 是 4。于是与 1、3 的相关度是 $\min(3,2)=2$，与 1、4 是 $\min(3,4)=3$，与 3、4 是 $\min(2,4)=2$。所以 $K=1$、$v=2$ 时有 3 个视频（1、3、4）；$K=4$、$v=1$ 时没有（与 1 相关度最高只有 3）；$K=3$、$v=1$ 时有 2 个（2 和 4）。

## 思路

关键是把相关度的定义反过来读：两个视频之间的相关度是通路上边权的最小值，所以“与 $v$ 的相关度至少为 $K$”等价于“存在一条从 $v$ 出发、只经过权值不小于 $K$ 的边就能到达的路径”。换句话说，把所有权值小于 $K$ 的边从树上删掉后，$v$ 所在连通块里除 $v$ 以外的视频数就是答案。

于是每个询问做一遍 BFS：从 $v$ 出发，只走权值不小于 $K$ 的边，数一数能到达多少个别的视频。$N$ 和 $Q$ 都只有 5000，每次询问 $O(N)$，总计约 $2.5 \times 10^7$ 次操作，完全够快。

实现上树用“链式前向星”存邻接表：`head[v]` 指向从 $v$ 出发的第一条边，每条边再记下同起点的下一条边。这样与教科书里的数组写法一致，也不需要在 BFS 里使用额外的容器。
