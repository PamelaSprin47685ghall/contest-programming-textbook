# P3　传送（Teleportation）

## 题目

FJ 最讨厌的农活之一就是把大量牛粪搬来搬去。为此他发明了「牛粪传送器」：把牛粪运到位置 $x$，就能瞬间传送到位置 $y$。

FJ 的农场沿着一条笔直的长路分布，任何地点都可以用数轴上的一个点表示。传送器由 $x$、$y$ 两个数描述。FJ 决定把传送器的一端固定在 $x = 0$，请你帮他选择另一端 $y$ 的最佳位置。

农场上有 $N$ 堆牛粪（$1 \le N \le 100{,}000$），第 $i$ 堆需要从 $a_i$ 运到 $b_i$，各堆分别独立运输。设 $d_i$ 为第 $i$ 堆运输时拖拉机载着牛粪行驶的距离。若直接从 $a_i$ 开到 $b_i$，则 $d_i = |a_i - b_i|$；若借助传送器（例如从 $a_i$ 开到 $0$，传送后再从 $y$ 开到 $b_i$），则 $d_i$ 会更小。同一个 $y$ 对所有牛粪堆都是相同的。

请选择 $y$，使 $\sum d_i$ 最小。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个整数 $a_i$、$b_i$，范围 $-10^8 \dots 10^8$，数值可能有重复。

## 输出

一个整数：$\sum d_i$ 的最小值。答案可能超过 32 位整数范围，需要用 `long long` 保存。

## 样例

输入：

```text
3
-5 -7
-3 10
-2 7
```

输出：

```text
10
```

解释：取 $y = 8$，可达到 $d_1 = 2$、$d_2 = 5$、$d_3 = 3$，总和为 10。$y$ 取 $[7, 10]$ 中任何值同样最优。

## 思路

先写出单堆的代价函数。第 $i$ 堆 либо直达，要么「开到 $0$，传送，再从 $y$ 开到 $b_i$」，于是

$$f_i(y) = \min\bigl(|a_i - b_i|,\; |a_i| + |b_i - y|\bigr).$$

记 $C_i = |a_i - b_i| - |a_i|$，则有

$$f_i(y) = |a_i - b_i| - \max\bigl(0,\; C_i - |y - b_i|\bigr).$$

也就是说，相对于直达的基线 $\sum |a_i - b_i|$，每堆能省下的部分是一个顶点在 $y = b_i$、高度为 $C_i$ 的等腰三角形（$C_i \le 0$ 时永远省不了，直接忽略）。于是问题变成：选择 $y$，使这些三角形（即"帐篷函数"）在 $y$ 处的取值之和最大，答案等于基线减去这个最大节省量。

所有帐篷都可用斜率事件描述：在 $y = b_i - C_i$ 处斜率 $+1$，在 $y = b_i$ 处斜率 $-2$，在 $y = b_i + C_i$ 处斜率 $+1$。把 $3N$ 个事件按位置排序，沿数轴从左往右扫描，维护当前的节省量和斜率即可。

正确性说明：节省量之和是分段线性连续函数，且在两端趋于 0；每一段线性区间的最大值必在端点取到，所以全局最大值一定出现在某个断点处。所有断点 $b_i - C_i$、$b_i$、$b_i + C_i$ 都是整数，逐一在断点处取值比较即可（也说明了答案必为整数）。

数值范围：$|a_i - b_i| \le 2 \times 10^8$，$\sum |a_i - b_i| \le 2 \times 10^{13}$，必须用 `long long`。
