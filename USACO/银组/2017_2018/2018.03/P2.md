# P2　柠檬水队列（Lemonade Line）

## 题目

炎热的夏日，Farmer John 在给 $N$ 头奶牛（编号 $1 \dots N$）发柠檬水。每头奶牛都想要柠檬水，但喜欢的程度不同：第 $i$ 头牛最多愿意排在 $w_i$ 头牛后面。

现在所有奶牛都在田里，FJ 一摇铃，奶牛们会立刻赶到柠檬水摊前。她们会在 FJ 开始发柠檬水之前全部到达，但没有两头牛同时到达，而且**到达顺序可以任意**。当第 $i$ 头牛到达时，只有当队伍中已有的牛数不超过 $w_i$ 时她才会排队，否则直接离开。

FJ 想提前准备好固定数量的柠檬水，又不想浪费。请帮助他求出在所有可能的到达顺序中，**最少**可能有多少头牛排进队伍。

## 输入

第一行一个整数 $N$（$1 \le N \le 10^5$）。

第二行 $N$ 个空格分隔的整数 $w_1, w_2, \dots, w_N$（$0 \le w_i \le 10^9$）。

## 输出

一个整数：所有到达顺序中可能排进队伍的最少牛数。

## 样例

输入：

```text
5
7 1 400 2 2
```

输出：

```text
3
```

让 $w = 7$ 和 $w = 400$ 的两头牛先进队。此时队伍里有 2 头牛，$w = 1$ 的牛到达后离开；随后两头 $w = 2$ 的牛到达，其中一头进队（此时队伍里仍是 2 头，$2 \le 2$），另一头因为队伍已有 3 头而离开。最终队伍里有 3 头牛。

## 思路

贪心：让 $w_i$ 最大的牛尽量先到，这样队伍增长得最快，最能「挡住」后面挑剔（$w_i$ 小）的牛。

把 $w$ 从大到小排序后依次让牛到达。设当前队伍里已有 $k$ 头牛，轮到的是 $w$ 值第 $k$（从大往小）大的牛：

- 若 $w \ge k$，她愿意排队，队伍变成 $k + 1$ 头；
- 若 $w < k$，她不肯排队，且在她之后到达的牛 $w$ 值都不比她的更大，而队伍规模也不会再变小，所以后面的牛同样不会排队。此时队伍规模就此定型，答案就是 $k$。

为什么这样最优：任意方案中都可以把不肯排队的牛全部挪到最后（她们仍然不肯排队），从而不妨设「进队的牛都排在不进队的牛前面」。若某个进队的牛 $i$ 与不进队的牛 $j$ 满足 $w_i < w_j$，交换这两头牛后 $j$ 会进队、$i$ 不进队，队伍规模不变——这说明存在一个最优解，进队的牛恰好是 $w$ 值最大的 $k$ 头。而「前 $k$ 大的牛都进队」等价于第 $k+1$ 大的牛到达时 $k \le w_{k+1}$ 不成立（即 $w_{k+1} < k$），所以按上述扫描找到的第一个分界点就同时是最优的 $k$。
