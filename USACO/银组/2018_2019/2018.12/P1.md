# P1　接机巴士（Convention）

## 题目

农夫约翰在机场迎接前来参加吃草大会的 $N$ 头奶牛（$1 \le N \le 10^5$），第 $i$ 头奶牛在时刻 $t_i$ 到达（$0 \le t_i \le 10^9$）。

他准备了 $M$ 辆巴士（$1 \le M \le 10^5$），每辆巴士最多坐 $C$ 头奶牛（$1 \le C \le N$）。每头奶牛坐哪辆车由约翰安排，一辆巴士在它所载最后一名乘客到达时发车。一头奶牛的等待时间，是她到达的时刻与所乘巴士发车时刻之差。

约翰想让候机时间尽量短，请求出在最优安排下，所有奶牛中最大等待时间的最小可能值。题目保证 $MC \ge N$。

## 输入

第一行三个整数 $N$、$M$、$C$。

第二行 $N$ 个整数，表示每头奶牛的到达时刻。

## 输出

一行一个整数，表示最小的最大等待时间。

## 样例

输入：

```text
6 3 2
1 1 10 14 4 3
```

输出：

```text
4
```

时刻 $1$ 到达的两头奶牛坐第一辆车，时刻 $3$、$4$ 到达的两头坐第二辆车，时刻 $10$、$14$ 到达的两头坐第三辆车。等待最久的是时刻 $10$ 到达的那头，她从时刻 $10$ 等到发车的时刻 $14$，等待了 $4$ 个单位时间。

## 思路

先问一个更容易回答的问题：如果允许的最大等待时间被定为 $T$，$M$ 辆车够不够用？

奶牛互相之间只按到达时间区分，所以先把到达时间从小到大排序。此时每一辆车的乘客一定是排序后连续的一段：

- 一辆车不能等到晚于「它接到的第一头奶牛到达后 $T$ 个时刻」才发车，否则那位先到的乘客就超时了；
- 也没有理由提前发车，因为让车多等一会儿只可能多捎上后来者，不会让任何人超时。

于是这辆车的乘客就是「最早到达的那批人」里较先结束的一批：要么是前 $C$ 头奶牛（车坐满了），要么是在 $T$ 个时刻内到达的全部奶牛（窗口到头了）。接着对剩下的奶牛重复同样的做法，就能求得 $T$ 固定时的最少用车数；用车数不超过 $M$ 就说明 $T$ 可行。

判定的结果关于 $T$ 单调：$T$ 放宽之后，原来的分车方案依然合法。因此可以二分答案，在 $[0,\ \max t - \min t]$ 中找出最小的可行 $T$。取右端点为最大到达时间差时，窗口约束自动满足，用车数只受容量限制为 $\lceil N/C \rceil \le M$（由 $MC \ge N$ 保证），所以右端点一定可行。

## 复杂度

排序 $O(N \log N)$；每次判定扫描一趟为 $O(N)$，共二分 $O(\log T)$ 轮。总时间复杂度 $O(N \log N + N \log T)$，空间复杂度 $O(N)$。
