# P1　种草（Grass Planting）

## 题目

农夫约翰要给他的整个农场种草。农场由 $N$ 块田地组成（$1 \le N \le 10^5$），编号 $1 \ldots N$，由 $N-1$ 条双向小路连通，且任意两块田地之间都能互相到达——也就是说，农场的结构是一棵树。

约翰可以在每块田里种不同种类的草，但他想尽量少用草的种类以节省开支。

麻烦的是，奶牛们对草的种类十分挑剔：如果两块相邻的田地（直接由小路相连）种了同一种草，那么约翰就失败了。不仅如此，即使两块田地只是"几乎相邻"——都直接与某一块公共田地相连——种了同一种草也会让奶牛们抱怨。

请帮约翰求出他最少需要用多少种草。

## 输入

第一行一个整数 $N$。

接下来 $N-1$ 行，每行两个整数，描述一条小路连接的两块田地。

## 输出

一行一个整数，表示最少的草的种类数。

## 样例

输入：

```text
4
1 2
4 3
2 3
```

输出：

```text
3
```

四块田地连成一条链。可以按 A - B - C - A 种，需要三种草。

## 思路

设所有点中最大的度数为 $D$。取度数最大的那个点 $v$，它有 $D$ 个邻居。这 $D$ 个邻居两两之间都隔着 $v$（距离为 2），而每个邻居与 $v$ 本身相邻，所以这 $D+1$ 个点必须两两异色，答案至少是 $D+1$。

$D+1$ 也是够用的。把树以任意点为根，根染 1 号色：根至多 $D$ 个儿子，可以依次染 $2, \ldots, D+1$；此后每个非根点 $u$ 已经连向自己的父亲，儿子数不超过 $D-1$，而避开 $u$ 的颜色和 $u$ 父亲的颜色后还剩 $D-1$ 种颜色可用，于是总能给 $u$ 的每个儿子分配互不相同的颜色。这样逐层构造下去，兄弟之间必然异色（满足距离 2 的约束），祖孙之间也必然异色（儿子避开了父亲的颜色），相邻的点更是异色，所以 $D+1$ 种颜色总能染完。

于是答案就是最大度数加一，只需统计每个点的度数。
