# P3　山景（Mountain View）

## 题目

贝茜从农场眺望远处的山脉，视野中有 $N$ 座山（$1 \le N \le 10^5$）。把她的视野看作 $xy$ 平面，每座山是一个底边落在 $x$ 轴上的三角形，两条侧边与底边都成 45 度，因此山峰处是直角。于是第 $i$ 座山由山峰坐标 $(x_i, y_i)$ 完全确定，且没有两座山的山峰位置完全相同。

贝茜想数清山脉中共有多少座山，但由于颜色相近，如果一座山的峰位于（含边界）另一座山的三角形内部，她就看不见它。

请统计她能看见的不同山峰、也就是不同山的数量。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个整数 $x_i$（$0 \le x_i \le 10^9$）和 $y_i$（$1 \le y_i \le 10^9$）。

## 输出

一行一个整数，表示贝茜能分辨出的山的数量。

## 样例

输入：

```text
3
4 6
7 2
2 5
```

输出：

```text
2
```

第一座和第三座山可见，第二座被第一座挡住了。

## 思路

两腰与底边成 45 度，说明这座山的形状恰好对应底边区间 $[x_i - y_i,\ x_i + y_i]$：山峰在其正中央上方，且从山峰向两侧以 1:1 的斜率下降。于是"山 $i$ 的峰落在山 $j$ 内"等价于山 $i$ 的底边区间被山 $j$ 的区间包含，即

$$x_i - y_i \ge x_j - y_j \quad\text{且}\quad x_i + y_i \le x_j + y_j.$$

把所有的山按左端点 $x - y$ 从小到大排序，左端点相同时按右端点 $x + y$ 从大到小排序（左端点相同而右端点更大的山会遮住右端点更小的那座，所以它必须排在前面对后者起过滤作用）。这样一来，排在前面的山左端点都不大于当前山，当前山可见当且仅当它的右端点严格大于此前所有山的右端点——也就是说，它不被任何区间包含。

因此一遍扫描，维护已出现过的最大右端点：若当前山的右端点大于它，则这座山可见，答案加一并更新最大值；否则它已被之前某座山包含，不计入。
