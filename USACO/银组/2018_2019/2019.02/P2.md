# P2　粉刷谷仓（Painting the Barn）

## 题目

约翰做事总是不能一心一意，刷谷仓也常常半途被奶牛叫走，结果墙面上有的地方刷了好几层，有的地方只有薄薄一层。

把谷仓的一面墙看成二维的 $x$-$y$ 平面，约翰在上面刷了 $N$ 个矩形，每个矩形的边都与坐标轴平行，用左下角 $(x_1, y_1)$ 和右上角 $(x_2, y_2)$ 描述，矩形内部（含边界）都被刷上一层漆。

约翰希望刷上恰到好处的 $K$ 层漆。请算出刷完所有矩形之后，被**恰好 $K$ 层**漆覆盖的面积是多少。

## 输入

第一行两个整数 $N$ 和 $K$（$1 \le K \le N \le 10^5$）。

接下来 $N$ 行，每行四个整数 $x_1, y_1, x_2, y_2$，描述一个被刷的矩形，$(x_1, y_1)$ 是左下角、$(x_2, y_2)$ 是右上角。所有坐标都在 $0 \ldots 1000$ 之间，且每个矩形面积都大于 $0$。

## 输出

一个整数：被恰好 $K$ 层漆覆盖的面积。

## 样例

输入：

```text
3 2
1 1 5 5
4 4 7 6
3 3 8 7
```

输出：

```text
8
```

## 思路

如果直接一个矩形一个矩形地往格子里加漆，$N$ 最大 $10^5$ 而每个矩形又能盖住成片的格子，太慢了。注意"面积"在这里其实是 $1 \times 1$ 小格的个数，所以我们真正想要的只是**每一小格被涂的次数**。

先在**差分数组**上记录：一次矩形涂色，等价于在差分数组的四个角上各做一次加减（左下角加一，两个相邻角各减一，对角再加一）。这样处理一个矩形只要 $O(1)$。

然后做一次**二维前缀和**，把差分还原成每格真实的涂漆层数：

$$f(i,j) = g(i,j) + f(i-1,j) + f(i,j-1) - f(i-1,j-1)$$

其中 $g$ 是差分数组（越界的位置当作 $0$）。还原时顺便统计数值恰好等于 $K$ 的格子个数。由于坐标范围只有 $0 \ldots 1000$，这一趟枚举是 $1000 \times 1000$ 次，完全可以接受。

## 复杂度

差分标记 $O(N)$，前缀和枚举 $O(1000^2)$。时间 $O(N + 1000^2)$，空间 $O(1000^2)$，即一个约 $4$ MB 的二维整型数组。
