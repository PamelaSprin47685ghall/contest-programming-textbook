# P1　落单的奶牛（Left Out）

## 题目

农夫约翰想给他的 $N$ 头奶牛拍一张航拍照片。奶牛们站在一个 $N \times N$ 的方格牧场里（$2 \le N \le 1000$），每头奶牛要么面朝左（记作 `L`），要么面朝右（记作 `R`）。

约翰不能走到某头奶牛跟前单独让它转身，他只能对着**一整行**或**一整列**奶牛喊话：被喊到的这一行（列）里的奶牛全部转向，`L` 变 `R`、`R` 变 `L`。他可以喊任意多次，也可以对同一行（列）重复喊。

约翰发现他没办法让所有奶牛朝向同一个方向，最好的情况也只是"除了一头牛之外，其余牛朝向一致"。请你找出这头牛：如果把它**单独**翻转一次，约翰就能通过喊话让所有奶牛朝向一致。如果不存在这样的牛，输出 `-1`；如果有多个，输出行号最小的那个，行号相同时输出列号最小的那个。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行是一个长度为 $N$ 的字符串，只由 `L` 和 `R` 组成，第 $i$ 行第 $j$ 个字符表示第 $i$ 行第 $j$ 列奶牛的朝向。

## 输出

一行两个整数，表示这头奶牛的行号与列号（都从 $1$ 开始编号）。若不存在这样的奶牛，输出 `-1`。

## 样例

输入：

```text
3
RLR
RRL
LLR
```

输出：

```text
1 1
```

解释：左上角 $(1,1)$ 这头牛就是"罪魁祸首"。把它单独翻转一次之后，再对第 $2$ 行和第 $3$ 列喊话，所有奶牛就都朝左了；而只喊话不翻这头牛，无论怎么喊都没法做到全朝一个方向。

## 思路

把 `L` 记作 $1$、`R` 记作 $0$，设第 $i$ 行第 $j$ 列的值为 $a_{i,j}$。若第 $i$ 行被喊了奇数次记 $r_i=1$、第 $j$ 列被喊了奇数次记 $c_j=1$，那么最终格子是

$$b_{i,j} = a_{i,j} \oplus r_i \oplus c_j .$$

**坏矩形不变量。** 任取一个矩形，看它四个角的值。行喊话会翻转同一行里的两个角，列喊话会翻转同一列里的两个角，每次翻转的角数都是偶数，所以四角异或值在喊话下**不变**。于是：

- 如果某个矩形四角里恰好有三个相等（称这样的矩形为**坏矩形**，此时四角异或为 $1$），那么无论怎么喊它都不会消失，"全部朝向一致"（四角异或为 $0$）永远做不到；
- 反过来，如果没有坏矩形就一定能做到：对第一行取反的那些行各喊一次（$r_i = a_{i,0} \oplus a_{0,0}$），再把第一行里是 $1$ 的那些列各喊一次（$c_j = a_{0,j}$），除 $(0,0)$ 外所有格子都变成 $0$，而 $(0,0)$ 也恰好变成 $0$。

换句话说：**没有坏矩形 $\iff$ 每一行都等于第一行或者第一行的取反**。这与行、列的选取无关，所以翻转一个格子之后只需检查这条性质。

**翻转一个格子后怎么判定。** 以第一行为基准。对 $i \ge 1$ 记

$$base_i = a_{i,0} \oplus a_{0,0},$$

表示第 $i$ 行相对第一行"整体是否应该取反"。称内部格子 $(i,j)$（$i,j \ge 1$）**不符**，如果

$$a_{i,j} \oplus a_{0,j} \ne base_i .$$

不符格子就是让第 $i$ 行无法与第一行对齐的格子。注意 $j=0$ 那一列不会出现不符：$base_i$ 正是用它定义的。

于是按翻转格子的位置分四类，恰好对应代码里的四个分支（按行号优先、再列号最小的顺序检查）：

| 翻转 | 影响范围 | 成立条件 |
| --- | --- | --- |
| $(1,1)$ | 第一行与第一列都变了，每一行整体都要"反过来对齐" | 内部 $1..N$ 行、$2..N$ 列的 $(N-1)^2$ 个格子**全部**不符 |
| $(1,j)$，$j>1$ | 第一行只有第 $j$ 列变，基准列没变，于是每行都必须恰好错在第 $j$ 列 | 不符格子总数 $= N-1$ 且全部落在第 $j$ 列（该列整列不符），取最小的 $j$ |
| $(i,1)$，$i>1$ | 只影响第 $i$ 行，且它自己就是基准位，$base_i$ 被取反 | 不符格子总数 $= N-1$ 且全部落在第 $i$ 行（该行整行不符），取最小的 $i$ |
| $(i,j)$，$i,j>1$ | 只影响第 $i$ 行的一个格子 | 不符格子总数恰好为 $1$，就是它 |

每行、每列的不符个数在扫描时统计好，判每个条件都是 $O(1)$。按行号优先的顺序枚举（$(1,1)$ 先，再看最靠左的整列 $j$，再看最靠上的整行 $i$，最后看唯一的内部不符格子），第一个成立的解就是题目要求的字典序最小解；四个分支都不成立就输出 `-1`。
