# P2　奶牛相遇（Meetings）

## 题目

两个谷仓位于一根数轴上的 $0$ 与 $L$（$1 \le L \le 10^9$）处，另有 $N$ 头奶牛（$1 \le N \le 5 \cdot 10^4$）位于数轴上互不相同的整数位置。第 $i$ 头奶牛初始位置为 $x_i$，以每秒 1 个单位的速度沿方向 $d_i$（$1$ 表示向右，$-1$ 表示向左）匀速运动，体重为 $w_i \in [1, 10^3]$。所有奶牛始终匀速运动，直到发生下列事件之一：

- 若奶牛 $i$ 到达某个谷仓，则它停下不动。
- 当两头奶牛 $i$ 与 $j$ 位于同一点且该点不是谷仓时，它们相遇，此时奶牛 $i$ 获得奶牛 $j$ 原来的速度，反之亦然。

设 $T$ 为"已经停下（因为到达谷仓）的奶牛体重之和至少达到全部奶牛体重之和的一半"的最早时刻。请求出在时间区间 $0 \ldots T$（含时刻 $T$）内发生的奶牛相遇对总数。

## 输入

第一行两个整数 $N$ 和 $L$。

接下来 $N$ 行，每行三个整数 $w_i, x_i, d_i$。所有 $x_i$ 互不相同且满足 $0 < x_i < L$。

## 输出

一行一个整数，表示相遇的总次数。

## 样例

输入：

```text
3 5
1 1 1
2 2 -1
3 3 -1
```

输出：

```text
2
```

样例解释：第 1、2 头牛在时刻 $0.5$ 于 $1.5$ 处相遇并交换速度；第 2、3 头牛在时刻 $1$ 于 $2$ 处相遇并交换速度；第 1 头牛在时刻 $2$ 到达左谷仓，第 2 头牛在时刻 $3$ 到达左谷仓，此时停下的体重为 $1 + 2 = 3 \ge \frac{1+2+3}{2}$，过程结束，共 2 次相遇。

## 思路

问题分成互不干扰的两部分：先求 $T$，再在这个 $T$ 内数相遇次数。

**第一部分：求 $T$。**

关键观察是"两头牛交换速度"与"两头牛互相穿过"在**位置的多重集合**上完全等价：任意时刻，两个模型中占据的位置集合一模一样。因此在两个模型里，奶牛到达谷仓的时刻集合也相同。穿过模型下每头牛只是沿初始方向直线走到谷仓，所以

- 向左走的牛贡献到达左谷仓的时刻 $x_i$；
- 向右走的牛贡献到达右谷仓的时刻 $L - x_i$。

而"交换速度"模型里奶牛永远不会互相越过，即奶牛之间的左右次序始终不变。所以设向左走的牛有 $z$ 头，真正走到左谷仓的必然是排序后最左边的 $z$ 头牛，走到右谷仓的是剩下 $n - z$ 头；把到达时刻从小到大与这些牛按顺序一一对应，就给每头牛算出了它的到达时刻。

把这些 $(\text{到达时刻}, \text{体重})$ 按时刻排序，从小到大扫描，用 `remaining = 总体重 - 2 × 已停下体重` 记录状态：某头牛停下后 `remaining` 减去它体重的两倍，一旦 `remaining <= 0` 就说明停下体重已达到一半，当前时刻即为 $T$。由于同一时刻可能有若干头牛同时到达，依次处理即可，得到的正是最早的满足时刻。

**第二部分：数相遇次数。**

$T$ 确定后体重再无用处，可以把整个过程重新看成"互相穿过"：轨迹的交点与真实的相遇一一对应，且交点必在 $0$ 与 $L$ 之间（不是谷仓）。位置靠左且向右的牛 $i$ 与位置靠右且向左的牛 $j$ 会在时刻 $\frac{x_j - x_i}{2}$ 相交，该时刻不超过 $T$ 等价于

$$x_i + 2T \ge x_j .$$

把奶牛按位置从左到右扫描，用队列维护当前"还在考虑中的向右走的牛"。遇到向左走的牛 $j$ 时，队首那些满足 $x_i + 2T < x_j$ 的牛之后更不可能与任何牛相交，直接弹出；剩下的队内元素个数就是与 $j$ 相交的牛数，累加即可。
