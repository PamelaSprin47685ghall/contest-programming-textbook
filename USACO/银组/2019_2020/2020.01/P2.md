# P2　偿还贷款（Loan Repayment）

## 题目

Farmer John 欠 Bessie $N$ 加仑牛奶（$1 \le N \le 10^{12}$），必须在 $K$ 天内还清（$1 \le K \le 10^{12}$）。他不想还得太快，但每天必须至少还 $M$ 加仑（$1 \le M \le 10^{12}$，保证 $K \cdot M < N$）。

他先选定一个正整数 $X$，然后每天重复以下过程：

- 设已经还给 Bessie $G$ 加仑，计算 $Y = \left\lfloor \dfrac{N-G}{X} \right\rfloor$；
- 若 $Y < M$，则令 $Y = M$；
- 当天还给 Bessie $Y$ 加仑。

求最大的正整数 $X$，使得按上述过程在 $K$ 天之后 FJ 至少还了 $N$ 加仑。

## 输入

一行三个正整数 $N$、$K$、$M$，满足 $K \cdot M < N$。

## 输出

一行一个整数：最大的合法 $X$。

## 样例

输入：

```text
10 3 3
```

输出：

```text
2
```

当 $X = 2$ 时，第一天还 $10/2 = 5$ 加仑，后两天都还 $M = 3$ 加仑，共 $11 \ge 10$；$X = 3$ 时三天分别还 $3, 3, 3$，只有 $9 < 10$，所以答案是 2。

## 思路

先看单调性：$X$ 越小，$\lfloor (N-G)/X \rfloor$ 越大，每天还的牛奶越多，因此"$X$ 可行"这个性质关于 $X$ 单调递减，可以二分答案。由于 $X > N$ 时每天只能还 $M$，总共 $K\cdot M < N$ 一定失败，答案不超过 $N$，二分区间取 $[1, N]$（按题面数字上界取 $[1, 10^{12}]$ 亦可）。

直接按天模拟 check 是 $O(K)$ 的，$K$ 可达 $10^{12}$，无法接受。但 $Y = \lfloor (N-G)/X \rfloor$ 随已还金额 $G$ 增大而单调不增，所以可以把 $Y$ 取值相同的连续天数一次性跳过：

当 $G \le N - X \cdot Y$ 时，恒有 $\lfloor (N-G)/X \rfloor = Y$。这一段共有

$$\left\lfloor \frac{N - X\cdot Y - G}{Y} \right\rfloor + 1$$

天，把这整段的天数和牛奶量一起累加即可；每跳一段，$Y$ 至少减少 1。

为什么段数是 $O(\sqrt N)$：若 $Y$ 出现了 $t$ 个互不相同的取值，那么仅由这些取值贡献的牛奶量至少有 $1+2+\cdots+t$；一旦超过 $N$，牛奶就已经还清，判定会提前结束。因此 $t \le \lceil \sqrt{2N} \rceil$，每次 check 只花 $O(\sqrt N)$ 时间。

另外，若某一天算出 $Y < M$，说明此后每天只能还 $M$，此时只需检查剩余天数是否足够：$\left\lceil \dfrac{N-G}{M} \right\rceil \le K - \text{已用天数}$，直接返回即可。

注意所有运算都在 $10^{12}$ 量级乘以天数后可能接近 $10^{24}$？不会——累计值不会超过 $N$ 的判定范围：我们只在 $G < N$ 时继续，且每段跳过的天数不会超过剩余天数 $K - \text{days}$，故全程用 64 位整数（`long long`）即可，无需高精度。
