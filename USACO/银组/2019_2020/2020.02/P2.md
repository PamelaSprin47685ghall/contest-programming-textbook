# P2　三角形牧场（Triangles）

## 题目

农夫约翰想给奶牛们围出一片三角形牧场。

农场上有 $N$ 个栅栏柱（$3 \le N \le 10^5$），位置是互不相同的整点 $(X_1,Y_1),\dots,(X_N,Y_N)$。他可以任选三个柱子当作三角形的顶点，但要求三角形有一条边平行于 $x$ 轴、另一条边平行于 $y$ 轴。

请问所有合法牧场的面积之和是多少？

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个整数 $X_i,Y_i$，均在 $-10^4 \dots 10^4$ 之间，且所有点互不相同。

## 输出

面积之和可能不是整数，也可能很大，因此输出 $2$ 倍面积之和模 $10^9+7$ 的余数。

## 样例

输入：

```text
4
0 0
0 1
1 0
1 2
```

输出：

```text
3
```

解释：$(0,0),(1,0),(1,2)$ 围出的三角形面积为 $1$；$(0,0),(1,0),(0,1)$ 围出的面积为 $0.5$。所以答案是 $2 \times (1+0.5) = 3$。

## 思路

**每个三角形只数一次。** 合法的三角形一定有一条水平边和一条竖直边，这两条边共用一个顶点，直角就落在那个顶点上。因此可以按"直角顶点"分类：对每个柱子 $i$ 分别统计以它为直角顶点的所有三角形，再相加，不会重复也不会遗漏。

**固定直角顶点时的贡献。** 设 $A_i$ 是所有与 $i$ 横坐标相同的柱子到 $i$ 的纵坐标距离之和，$B_i$ 是所有与 $i$ 纵坐标相同的柱子到 $i$ 的横坐标距离之和。任取一个同 $x$ 的柱子 $j$ 和一个同 $y$ 的柱子 $k$，就能配出一个以 $i$ 为直角的三角形，它的 $2$ 倍面积是 $|Y_i-Y_j|\cdot|X_i-X_k|$。把所有配法加起来，

$$\text{该顶点的贡献} = \left(\sum_{j} |Y_i-Y_j|\right)\cdot\left(\sum_{k} |X_i-X_k|\right) = A_i \cdot B_i .$$

**怎么快速求距离和。** 问题归结为：给出一列有序数 $v_1 \le v_2 \le \dots \le v_m$，对每个 $t$ 求 $s_t=\sum_{u}|v_t-v_u|$。用前缀和 $P_k = v_1 + \dots + v_k$ 就能 $O(m)$ 全部算完，因为排序后 $v_t$ 左边 $t-1$ 个都比它小、右边都比它大：

$$s_t = \big(v_t\,(t-1) - P_{t-1}\big) + \big((P_m - P_t) - v_t\,(m-1-t)\big).$$

把柱子按 $(x,y)$ 排序得到每一组同 $x$ 的柱子并求 $A_i$；再按 $(y,x)$ 排序求 $B_i$。整组距离和不超过 $10^5 \times 2\times10^4 = 2\times10^9$，用 `long long` 保存；乘积取模后再相加。
