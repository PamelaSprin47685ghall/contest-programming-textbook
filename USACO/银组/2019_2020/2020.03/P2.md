# P2　麦片（Cereal）

## 题目

农夫约翰的奶牛最爱早餐吃麦片，每头牛一顿就能吃掉一整盒。农场最近收到一批货，共有 $M$ 种麦片（$1 \le M \le 10^5$），但每种只有一盒。每头牛（共 $N$ 头，$1 \le N \le 10^5$）都有一个最爱的麦片和一个第二喜欢的麦片，轮到她时按下面的顺序行动：

- 如果她最爱的麦片还有货，就拿走并离开。
- 否则，如果她第二喜欢的麦片还有货，就拿走并离开。
- 否则，她失望地哞一声，空手离开。

奶牛们排成一列依次取麦片。对于每个 $0 \le i \le N-1$，求农夫约翰把队列最前面的 $i$ 头牛赶走之后，有多少头牛能拿到麦片。

## 输入

第一行两个整数 $N$ 和 $M$。

接下来 $N$ 行，第 $i$ 行两个整数 $f_i$ 和 $s_i$（$1 \le f_i,s_i \le M$，$f_i \ne s_i$），表示队伍中第 $i$ 头牛最爱的和第二喜欢的麦片。

## 输出

输出 $N$ 行，第 $i$ 行（$0 \le i \le N-1$）是赶走最前面 $i$ 头牛后的答案。

## 样例

输入：

```text
4 2
1 2
1 2
1 2
1 2
```

输出：

```text
2
2
2
1
```

只要还剩至少两头牛，就恰好有两头牛能拿到麦片。

## 思路

**正向暴力太慢。** 对每个 $i$ 重新模拟一遍队列是 $O(N^2)$，需要找到增量更新的办法。

**倒着往队首加牛。** 记 $\texttt{ans}[i]$ 为"队伍里只剩第 $i \ldots N$ 头牛"时的答案。我们从 $i=N$ 开始，每次把第 $i$ 头牛插到队首，把 $\texttt{ans}[i+1]$ 更新成 $\texttt{ans}[i]$。要用到的状态只有 `occupied[pos]`：当前拿着麦片 `pos` 的奶牛编号（没人拿就是 0）。

**插入一头牛只会引发一条链的传递。** 新来的牛 $j$ 一定先拿她最爱的 $f_j$：

- 如果 `occupied[f_j]` 为空，她直接拿走，答案加一，其他牛全都不变。
- 如果 `occupied[f_j] = k` 且 $k$ 排在 $j$ 前面，$j$ 抢不到，空手离开，其他牛不变。
- 否则 $k$ 原本的麦片被 $j$ 抢走，$k$ 要重新安排：若 $f_j$ 就是 $k$ 的第二志愿，$k$ 什么都拿不到，链条结束；否则 $k$ 去试她的第二志愿 $s_k$，并可能以同样的方式挤掉别人。

**总传递次数是 $O(N)$。** 链条中每被挤掉一次，这头牛的处境只能从"第一志愿"变成"第二志愿"，或从"第二志愿"变成"什么都没有"；而往队首加牛永远不会让某头牛从"什么都没有"变回"有"，所以每头牛一生最多被挤两次，总长度不超过 $2N$。于是整个算法均摊 $O(N+M)$。

实现上，用 `occupied[pos]` 记录持有者，每次传递都是常数次数组访问，无需其他数据结构。
