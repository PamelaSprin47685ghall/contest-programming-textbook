# P3　哞粒子（The Moo Particle）

## 题目

奶牛们为解闷研究起了高深物理，还发现了一种新的亚原子粒子"哞粒子"。实验中有 $N$ 个哞粒子（$1 \le N \le 10^5$），第 $i$ 个粒子的自旋由两个整数 $x_i$ 和 $y_i$ 描述（$-10^9 \le x_i,y_i \le 10^9$）。两个粒子 $(x_i,y_i)$ 和 $(x_j,y_j)$ 只有在 $x_i \le x_j$ 且 $y_i \le y_j$ 时才能相互作用；此时这两个粒子中恰好有一个可能消失（另一个不受影响）。同一时刻至多发生一次相互作用。求经过任意多次相互作用后，最少可能剩下多少个哞粒子。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个整数，表示一个粒子的自旋。所有粒子的自旋两两不同。

## 输出

输出一个整数，表示经过任意序列的相互作用后最少可能剩下的粒子数。

## 样例

样例 1：

输入：

```text
4
1 0
0 1
-1 0
0 -1
```

输出：

```text
1
```

一种可能的相互作用顺序：

- 粒子 1 和粒子 4 作用，粒子 1 消失。
- 粒子 2 和粒子 4 作用，粒子 4 消失。
- 粒子 2 和粒子 3 作用，粒子 3 消失。

最后只剩粒子 2。

样例 2：

输入：

```text
3
0 0
1 1
-1 3
```

输出：

```text
2
```

粒子 3 和另外两个都无法作用，一定留下；粒子 1 和粒子 2 至少要留下一个。

## 思路

**转化成图上的删点。** 把每个粒子看成一个点，能相互作用的两个粒子之间连一条无向边。一次相互作用就是"删掉一个还有邻居的点"，所以：

- 每个连通分量里至少留下一个粒子（分量内最后一个点时它已经没有邻居，删不掉）；
- 每个连通分量恰好能只剩一个：取它的任意一棵生成森林，不断删去森林中的叶子即可，叶子在自己的连通分量里始终有邻居。

因此答案就是图的连通分量个数。

**$O(N \log N)$ 数出连通分量。** 把粒子按 $x$ 递增、$x$ 相同按 $y$ 递增排序。注意排序后，若第 $i$ 个和第 $i+1$ 个粒子仍然连通（它们自己有边，或通过别的分量间接相连），那么"前缀 $1..i$ 的最小 $y$"就一定不超过"后缀 $i+1..N$ 的最大 $y$"：记前者为 $\texttt{minLeft}[i]$、后者为 $\texttt{maxRight}[i+1]$。反过来，若

$$\texttt{minLeft}[i] > \texttt{maxRight}[i+1],$$

则前缀里所有点的 $y$ 都大于后缀里所有点的 $y$，而前缀里所有点的 $x$ 又都不超过后缀里的（已排序），于是两边任何一对粒子都无法满足 $x_i \le x_j$ 与 $y_i \le y_j$，前后缀之间没有边，必然分属不同连通分量。

所以排序后只需扫一遍：每当 $\texttt{minLeft}[i] > \texttt{maxRight}[i+1]$ 就把答案加一（初值为 1）。
