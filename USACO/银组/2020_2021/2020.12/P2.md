# P2　矩形牧场（Rectangular Pasture）

## 题目

农夫约翰最大的牧场可以看成一个巨大的二维方格棋盘。目前有 $N$ 头奶牛占据了其中一些格子（$1 \le N \le 2500$）。

约翰想修建围栏围出一个矩形区域，矩形的边与 $x$、$y$ 轴平行，可以小到只包含一个格子。请帮他计算：一共能围出多少种**不同的奶牛子集**（也就是说，围栏内的奶牛集合的种数）。注意空集也要算作其中一种。

所有奶牛的 $x$ 坐标互不相同，所有 $y$ 坐标也互不相同，$x, y$ 的取值都在 $0 \dots 10^9$ 之间。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个整数，表示一头奶牛所在的格子坐标 $(x, y)$。

## 输出

输出一个整数，表示约翰能围出的奶牛子集数量。可以证明答案在 64 位有符号整数范围内。

## 样例

输入：

```text
4
0 2
1 0
2 3
3 5
```

输出：

```text
13
```

一共有 $2^4$ 个奶牛子集，但约翰无法围出只包含第 1、2、4 头奶牛的子集，也无法围出只包含第 2、4 头或只包含第 1、4 头奶牛的子集，因此答案为 $2^4 - 3 = 13$。

## 思路

每个能被围出的非空子集，都与它的**最小包围矩形**一一对应：这个矩形的四条边上都必须有牛，否则可以把边界向内收缩。反过来，任何一个四条边上都有牛的矩形也唯一确定一个可围出的子集，即矩形内的所有奶牛。又因为所有 $x$ 坐标互不相同、所有 $y$ 坐标互不相同，所以每条边上恰好有一头牛。

于是问题转化为：统计四条边上都各有一头牛的矩形数量，再加上空集 $1$。

先把 $x$、$y$ 分别坐标压缩到 $0 \dots N-1$（排序后取名次即可，坐标互异保证了名次唯一），并预处理二维前缀和，从而 $O(1)$ 求出任意矩形内的奶牛数。

接着枚举矩形的**下边牛 $a$ 与上边牛 $b$**。把奶牛按压缩后的 $y$ 升序排列，这样枚举下标对 $i \le j$ 时，$p_i$ 就是下边牛、$p_j$ 就是上边牛，$y$ 的范围自然是 $[y_i, y_j]$。设 $lo = \min(x_a, x_b)$、$hi = \max(x_a, x_b)$：

- 左边牛必须落在 $x \le lo$ 且 $y \in [y_a, y_b]$ 的区域里；
- 右边牛必须落在 $x \ge hi$ 且 $y \in [y_a, y_b]$ 的区域里。

两类候选数分别用前缀和求出，相乘累加。由于四边的牛都唯一确定矩形，且每个合法矩形只会在“下边、上边”这一对奶牛处被统计一次，所以不重不漏。

注意 $i = j$ 时左右两侧的候选各只有这头牛自己，贡献的正是只包含一个格子的 $N$ 个矩形；最后再补上空集。
