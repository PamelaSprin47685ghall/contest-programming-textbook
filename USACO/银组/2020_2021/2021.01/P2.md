# P2　没时间刷漆（No Time to Paint）

## 题目

贝西得到了一套绘画工具，她想给牧场一头的长栅栏刷漆。栅栏由 $N$ 个连续的 $1$ 米长的段组成（$1 \le N \le 10^5$）。贝西有 $26$ 种颜色，依次用字母 `A` 到 `Z` 表示，越靠后的字母越深（`A` 是最浅的颜色，`Z` 是最深的颜色），因此她可以把每段栅栏想要的编号写成一个长度为 $N$ 的字符串。

一开始所有段都没有颜色。贝西每次可以选一段**连续**的栅栏，用同一种颜色刷一笔，唯一限制是**永远不能把浅色刷在深色上面**（只能把深色刷在浅色上）。例如，长度 $4$ 的一段可以从无色刷成：

```text
.... -> BBB. -> BBLL -> BQQL
```

时间不够了，贝西想留出一段连续的栅栏不刷。她正在考虑 $Q$ 个候选区间（$1 \le Q \le 10^5$），每个用两个整数 $(a,b)$（$1 \le a \le b \le N$）描述。对每个候选区间，求出：把该区间以外的每一段都刷成她想要的颜色、而该区间内的所有段保持无色，最少需要多少笔？

各候选区间之间互相独立，贝西并不会真的去刷漆。

## 输入

第一行两个整数 $N,Q$。

第二行一个长度为 $N$ 的字符串，表示每段栅栏想要的颜色。

接下来 $Q$ 行，每行两个整数 $a,b$，表示一个候选区间。

## 输出

对每个候选区间输出一行，表示最少笔画数。

## 样例

输入：

```text
8 2
ABBAABCB
3 6
1 4
```

输出：

```text
4
3
```

第一个询问要留下 `BAAB`，剩下 `ABB` 与 `CB` 两段，需要 $4$ 笔；第二个询问要留下 `ABBA`，剩下 `AB` 与 `CB` 两段，只需要 $3$ 笔：

```text
.... -> AA.. -> ABBB -> ABCB
```

## 思路

**一次询问的答案可以拆成两半。** 留下区间 $[a,b]$ 不刷时，区间的左边（前 $a-1$ 段）和右边（后 $N-b$ 段）互相独立：一笔刷出的连续区段不能跨越 $[a,b]$（否则就会刷到区间内的段），所以总笔画数就是"刷好前 $a-1$ 段的最少笔画数 + 刷好后 $N-b$ 段的最少笔画数"。于是只需预处理出所有前缀与所有后缀的答案。

**怎么求一个前缀的答案？** 从左往右扫描，同时维护一个"还没结束的笔画"的栈。因为只能深刷浅，任一时刻这些笔画的颜色从栈底到栈顶**严格递增**（越深的越晚刷、越靠上）。

扫到颜色 $c$ 时：

1. 所有比 $c$ 更深的笔画都必须在 $c$ 之前结束，否则它们会盖住 $c$，于是把它们弹栈；
2. 此时若栈顶恰好还是 $c$，说明之前有一笔颜色 $c$ 还在有效期内，直接在原来的位置上把它延伸到当前段，不增加笔画数；
3. 否则（栈空或栈顶颜色比 $c$ 浅）只能新起一笔 $c$，把它压栈，笔画数加一。

于是**压栈的次数**就是该前缀的最少笔画数。这样贪心是最优的：比 $c$ 深的颜色已经无法再延伸，弹栈不会损失什么；而 $c$ 若能延伸就免费，若不能延伸，任何方案都至少要再开一笔来覆盖当前段（因为此刻浅色在深色之上的限制使 $c$ 不可能由更早的某个笔画顺带刷出来）。

后缀的答案等于把字符串反转后求前缀答案，所以从右往左做完全相同的扫描即可。

## 复杂度

预处理时间 $O(N)$（每个颜色最多被压栈一次，弹栈均摊 $O(1)$），每次询问 $O(1)$，总时间 $O(N+Q)$。

空间 $O(N)$。
