# P3　间隔放置（Spaced Out）

## 题目

农夫约翰想给在牧场吃草的奶牛拍一张照片挂在墙上。牧场是一个 $N \times N$ 的方格棋盘（$2 \le N \le 1000$），他要求：

- 任何两头牛都不能放在同一个格子里；
- 每一个 $2\times 2$ 的子方格（共有 $(N-1)\times(N-1)$ 个）里必须恰好有 $2$ 头牛。

例如下面这种摆放是合法的：

```text
CCC
...
CCC
```

而下面这种不合法，因为包含右下角格子的那个 $2\times 2$ 方块里只有 $1$ 头牛：

```text
C.C
.C.
C..
```

没有其他限制，牛的数量无限。当一头牛被放在格子 $(i,j)$ 时，照片的美观度增加 $a_{ij}$（$0 \le a_{ij} \le 1000$）。请求出合法摆放能获得的最大总美观度。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行 $N$ 个整数，第 $i$ 行第 $j$ 个数为 $a_{ij}$。

## 输出

输出一个整数，表示最大的总美观度。

## 样例

输入：

```text
4
3 3 1 1
1 1 3 1
3 3 1 1
1 1 3 3
```

输出：

```text
22
```

样例中的最优摆放为：

```text
CC..
..CC
CC..
..CC
```

美观度为 $3+3+3+1+3+3+3+3=22$。

## 思路

**关键观察：任何合法摆放中，要么每一行都按"放、空、放、空……"或"空、放、空、放……"交替，要么每一列都这样交替。**

证明分两种情况：

- 如果任意两头牛都不相邻（上下左右都不挨着），那么每行、每列都是交替的，两类都满足。
- 否则存在两头相邻的牛，不妨设它们在 $(i,j)$ 与 $(i,j+1)$ 水平相邻。这两头牛所在的那个 $2\times 2$ 方块必须恰好有 $2$ 头牛，所以第 $i-1$ 行和第 $i+1$ 行在这两列上都必须是空格；再往外看，包含第 $i+1$ 行那对空格的 $2\times 2$ 方块又要凑满 $2$ 头牛，于是第 $i+2$ 行在这两列上又都放牛……如此推下去，这两列各自都是"逐行交替"的。
- 再看与它们相邻的列：若某列不是逐行交替的，那么它和某个已经交替的列组成的 $2\times 2$ 方块里必然出现 $1$ 头或 $3$ 头牛，矛盾；因此所有列都逐行交替，也就是**每一行都逐列交替**。（两头牛竖直相邻时同理，得到**每一列都逐行交替**。）

于是只需分别计算两类的最优值：

- 每行交替：行与行之间互不影响（任一 $2\times 2$ 方块中两行各贡献恰好一头牛），所以每行只有两种相位（从第 $1$ 列开始放，或从第 $2$ 列开始放），各自独立取较大的求和；
- 每列交替：同理，每列独立在两种相位中取较大的求和。

答案就是两者的较大值。
