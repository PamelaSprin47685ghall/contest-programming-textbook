# P1　舒适的奶牛（Comfortable Cows）

## 题目

农夫 Nhoj 的牧场可以看成一个巨大的二维方格棋盘，起初一头牛也没有。

Nhoj 会一头接一头地往里加入 $N$（$1 \le N \le 10^5$）头牛，第 $i$ 头牛占据格子 $(x_i, y_i)$，且与之前所有牛的格子互不相同（$0 \le x_i, y_i \le 1000$）。

如果一头牛上下左右相邻的 4 个格子中恰好有 3 个格子里有牛，就称这头牛"很舒适"。过于舒适的牛产奶量会下降，所以 Nhoj 想继续往牧场里加牛，直到没有任何牛（包括他新加的牛）是舒适的。注意他新加的牛坐标不一定要在 $0 \dots 1000$ 范围内。

对每个 $i = 1 \dots N$，请输出：如果一开始牧场里只有第 $1 \dots i$ 头牛，最少需要额外加入多少头牛，才能让所有牛都不舒适。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，每行两个整数 $x_i, y_i$，表示第 $i$ 头牛所在的格子，保证所有格子互不相同。

## 输出

输出 $N$ 行，第 $i$ 行表示初始只有前 $i$ 头牛时最少需要追加的牛数。

## 样例

输入：

```text
9
0 1
1 0
1 1
1 2
2 1
2 2
3 1
3 2
4 1
```

输出：

```text
0
0
0
1
0
0
1
2
4
```

对于 $i=4$，必须在 $(2,1)$ 补一头牛才能让 $(1,1)$ 的牛不再舒适。对于 $i=9$，最优做法是补在 $(2,0),(3,0),(2,-1),(2,3)$。

## 思路

关键观察：**只要有一头牛恰好有 3 个相邻的牛，那么它缺的第 4 个位置就必然要放一头牛。** 因为那头牛只有这 4 个邻居位置，空缺的那个不补上，它就永远是舒适的；而把牛放在别处也无法改变它的相邻牛数。

于是答案集合是完全确定的：从初始牛群出发，反复执行"某头牛恰有 3 个邻居 $\Rightarrow$ 在它缺的邻居处补一头牛"，直到没有牛舒适为止。这就是一个和初始牛群无关的闭包过程。

处理每个询问时用一个队列模拟这个扩张过程：弹出待补位置 $(x,y)$，若那里已经有牛就跳过，否则放上牛；随后只需检查 $(x,y)$ 自己和它的 4 个相邻位置——放一头牛只会改变这 5 个位置的相邻牛数。若其中某个位置的牛恰好有 3 个邻居，就把它缺的位置入队。

相邻两次询问之间**不需要清空状态**，因为闭包关于初始集合单调递增：设 $S \subseteq T$，把 $\mathrm{close}(S)$ 中每个格子按加入顺序归纳即可证明它也在 $\mathrm{close}(T)$ 中——若某步因 $q$ 在 $S$ 中恰有 3 个邻居而要补 $p$，那么在 $T$ 中要么 $p$ 本来就在 $T$ 里，要么 $p \notin T$，此时 $q$ 的邻居仍是原来那 3 个（$q$ 只有 4 个邻居），于是 $p$ 同样会被补出。所以第 $i$ 头牛加入后，在前 $i-1$ 头牛的闭包上继续跑队列即可，答案为「当前牧场上的牛总数 $- \ i$」。

关于坐标范围：可以证明补出的格子一定落在以 $(500,500)$ 为中心、曼哈顿半径 $1000$ 的菱形内。若 $(x,y)$ 在这个菱形之外，则它朝"远离中心"的两个方向的邻居也一定在菱形之外，于是 $(x,y)$ 最多只有 2 个已存在的邻居，不可能被补出。因此把坐标统一 $+1000$ 平移后，下标始终在 $[500, 2500]$ 内，开 $3000 \times 3000$ 的数组足够；该菱形恰好有 $2 \cdot 1000^2 + 2 \cdot 1000 + 1 = 2002001$ 个格子，而每个格子最多被入队一次（入队前记 `queued` 标记，出队后该格子必然被放上牛，此后不会再成为候选），所以队列容量取这个数量级即可。

## 复杂度

时间 $O(N + \text{最终牧场上的牛数})$，最终牛数不超过菱形格子数 $2002001$；空间 $O(3000^2)$。
