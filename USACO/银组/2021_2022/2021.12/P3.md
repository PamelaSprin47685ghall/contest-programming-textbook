# P3　卷积区间（Convoluted Intervals）

## 题目

奶牛们有一组 $N$ 个区间，第 $i$ 个区间从 $a_i$ 开始、到 $b_i \ge a_i$ 结束，$a_i$ 和 $b_i$ 都是 $0 \ldots M$ 内的整数。

游戏由 Bessie 和她的表亲 Elsie 一起玩：Bessie 选一个区间（第 $i$ 个），Elsie 选一个区间（第 $j$ 个，可以和 Bessie 选同一个）。给定数值 $k$，两人获胜当且仅当 $a_i + a_j \le k \le b_i + b_j$。

对 $0 \ldots 2M$ 中的每个 $k$，统计能让她们获胜的有序对 $(i, j)$ 的数量。

## 输入

第一行两个整数 `N M`（$1 \le N \le 2\cdot 10^5$，$1 \le M \le 5000$）。

接下来 $N$ 行，每行两个整数 `a_i b_i`，描述一个区间。

## 输出

输出 $2M + 1$ 行，第 $k$ 行（从 $0$ 开始编号）是 $k$ 的答案。答案可能超过 32 位整数。

## 样例

输入：

```text
2 5
1 3
2 5
```

输出：

```text
0
0
1
3
4
4
4
3
3
1
1
```

解释：例如 $k = 3$ 时，能让两人获胜的有序对是 $(1, 1)$、$(1, 2)$、$(2, 1)$，共 $3$ 个。

## 思路

直接按定义做要枚举所有有序对并逐个 $k$ 累加，是 $O(N^2 M)$，太慢。

**拆开获胜条件**。$a_i + a_j \le k \le b_i + b_j$ 等价于两个互不相干的不等式：

$$a_i + a_j \le k \qquad \text{且} \qquad b_i + b_j \ge k .$$

后者又等价于「$b_i + b_j \le k - 1$ 不成立」。于是

$$\text{答案}(k) = \#\{a_i + a_j \le k\} - \#\{b_i + b_j \le k - 1\},$$

右端两项都只和「两个端点之和的分布」有关，可以各自预处理。

**用出现次数代替逐个区间**。有很多区间会共享同一个左端点。设 $x$ 作为左端点出现 `countA[x]` 次，那么左端点之和恰为 $x + y$ 的有序对就有 `countA[x] * countA[y]` 个。$M \le 5000$，直接枚举 $x, y$ 只有约 $2.5 \times 10^7$ 次，足以在时限内跑完；右端点同理。

这一步本质上就是让频次数组与自己做卷积（多项式平方），也因此本题有一个用快速多项式乘法做到 $O(N + M \log M)$ 的进阶做法。本题的规模用平方级别的枚举就足够了。

**前缀累加输出**。随着 $k$ 从 $0$ 增到 $2M$，把当前 $k$ 对应的一份分布累加进前缀和，再输出「左端点和前缀」减去「上一步为止的右端点和前缀」即可，全程 $O(M)$。
