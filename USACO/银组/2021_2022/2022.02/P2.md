# P2　机器人指令（Robot Instructions）

## 题目

Bessie 的机器人一开始在平面直角坐标系的原点 $(0,0)$，她希望机器人最后停在 $(x_g, y_g)$。Bessie 手上有 $N$ 条指令（$1 \le N \le 40$），第 $i$ 条会让机器人向右移 $x_i$、向上移 $y_i$（$x_i、y_i$ 为负时分别表示向左、向下）。

对每个 $K = 1 \sim N$，求从这 $N$ 条指令中选出 $K$ 条、使得依次执行这 $K$ 条后机器人恰好停在 $(x_g, y_g)$ 的方案数（只与选了哪几条有关，与顺序无关）。

保证 $(x_g, y_g) \ne (0,0)$，且每条指令 $(x_i, y_i) \ne (0,0)$。

## 输入

第一行一个整数 $N$。

第二行两个整数 $x_g, y_g$（$-10^9 \le x_g, y_g \le 10^9$）。

接下来 $N$ 行，每行两个整数 $x_i, y_i$（$-10^9 \le x_i, y_i \le 10^9$），描述一条指令。

## 输出

$N$ 行，第 $K$ 行是选出恰好 $K$ 条指令使机器人到达目标点的方案数。

## 样例

输入：

```text
7
5 10
-2 0
3 0
4 0
5 0
0 10
0 -10
0 10
```

输出：

```text
0
2
0
3
0
1
0
```

## 思路

指令的执行顺序无关紧要，所以一个方案就是一个子集，直接枚举有 $2^{40}$ 种，太多；把指令分成两半，每半不超过 $20$ 条，用**折半枚举**（meet in the middle）。

- 枚举前一半的所有子集，记下每个子集的位移 $(x, y)$ 以及用掉的指令条数；后一半同理。
- 若前一半某子集的位移是 $(a, b)$、用了 $c_1$ 条，则后一半需要补上位移 $(x_g - a, y_g - b)$，且后一半要用 $c_2$ 条，那么 $K = c_1 + c_2$ 的方案数就要加上「后一半中位移恰为 $(x_g-a, y_g-b)$ 且用了 $c_2$ 条的子集个数」，对所有 $c_2$ 累加。

实现上把两半的子集分别按位移的字典序排序。枚举前一半时，位移相同的子集在排序后是连续的一段，于是对每一段：用二分在后一半里圈出「位移恰好等于所需值」的区间，再统计这个区间里每种「指令条数」的出现次数，最后把这段里每个子集按条数查表累加到答案上。这样每段只做 $O(\log)$ 次比较加 $O(N)$ 的统计，不需要哈希表。

数组开到 $2^{20}$，两半共用约 $48\text{ MB}$；答案最大可以到 $\binom{40}{20} \approx 1.4 \times 10^{11}$，坐标最大到 $40 \times 10^9 = 4 \times 10^{10}$，都要用 `long long`。
