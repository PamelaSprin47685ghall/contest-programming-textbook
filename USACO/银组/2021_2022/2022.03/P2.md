# P2　子集相等（Subset Equality）

## 题目

奶牛们尝试用一种新的方式交换密文：在有用的字母之间混入无关字母，让信息难以破译。

两头牛传递两个串 $s$ 与 $t$（长度均不超过 $10^5$），其中只包含小写字母 `a` 到 `r`。为了理解密文，你会被问到 $Q$ 个询问（$1 \le Q \le 10^5$）：每个询问给出一个 `a` 到 `r` 的子集。你需要判断，$s$ 与 $t$ 只保留询问中出现的字母后，得到的两个串是否相等。

## 输入

第一行是串 $s$。

第二行是串 $t$。

第三行是询问个数 $Q$。

接下来 $Q$ 行，每行一个询问串：串内字母不重复，按字典序排列，且没有两个询问串相同。

## 输出

对每个询问输出一个字符 `Y`（只保留询问字母后两串相等）或 `N`（不相等）；输出为长度 $Q$ 的一行字符串。

## 样例

输入：

```text
aabcd
caabd
4
a
ac
abd
abcd
```

输出：

```text
YNYN
```

解释：第一个询问里两串都变成 `aa`；第二个询问里 $s$ 变成 `aac` 而 $t$ 变成 `caa`，不相等；第三个询问里两串都变成 `abd`；第四个询问里 $s$ 只保留 `abcd` 得到 `aabcd`，$t$ 只保留 `abcd` 得到 `caabd`，因 `a` 与 `c` 的先后顺序不同而不相等。

## 思路

记 $s|X$ 表示把 $s$ 中不属于字母集 $X$ 的字符全部删掉后得到的串。核心结论是：

$$s|X = t|X \iff \begin{cases}\text{(1) } s \text{ 与 } t \text{ 在 } X \text{ 上的字母计数总和相等；}\\[2pt] \text{(2) 对 } X \text{ 中任意一对字母 } \{x,y\} \text{，都有 } s|\{x,y\} = t|\{x,y\}。\end{cases}$$

必要性是显然的：只保留更少的字母不会破坏「两串相等」，计数也必然相等。

充分性用逆否命题证明：若 $s|X \ne t|X$，则要么两者长度不同（即计数总和不相等，条件 (1) 不成立），要么存在第一个不同位置，那里 $s|X$ 与 $t|X$ 分别放着字母 $x$ 与 $y$。因为该位置之前两串完全相同，把其它字母全部删掉后（只留 $x, y$），前面那段相同的部分仍然相同，$x$ 与 $y$ 仍然会落在同一个位置上，于是 $s|\{x,y\} \ne t|\{x,y\}$，条件 (2) 不成立。

据此可以预处理两样东西：

- 每个字母分别出现在 $s$、$t$ 中的次数，用于判断条件 (1)（把询问里每个字母的频数加起来比较即可）；
- 对每一对字母 $\{x,y\}$，判断 $s|\{x,y\}$ 与 $t|\{x,y\}$ 是否相等，用于判断条件 (2)。

字母只有 18 个，字母对只有 $\frac{18 \times 17}{2} = 153$ 对。每一对用双指针在同一时刻从两个串里各取出「下一个属于该对的字母」并比较，不需要真的构造缩小后的串，单对 $O(|s| + |t|)$。每次询问先把频数和加起来判断 (1)，再枚举询问内的字母对检查 (2)，$O(18^2)$。

## 复杂度

预处理 $O\big(153 \cdot (|s| + |t|)\big)$（约 $6 \times 10^7$ 次简单操作），每个询问 $O(18^2)$，总时间 $O\big(153 \cdot (|s| + |t|) + 18^2 Q\big)$；空间 $O(|s| + |t| + Q)$。
