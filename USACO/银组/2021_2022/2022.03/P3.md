# P3　COW 操作（COW Operations）

## 题目

Bessie 得到一个长度不超过 $2 \cdot 10^5$ 的串 $s$，只含 `C`、`O`、`W` 三种字符。她想知道能否通过下面两种操作把串变成单个 `C`：

1. 选择两个相邻且相同的字母，把它们删掉；
2. 选择一个字母，把它替换成另外两个字母（这两种字母一前一后，顺序任意）。

Bessie 不满足于只回答整串，她会询问 $Q$（$1 \le Q \le 2 \cdot 10^5$）个子串，每个子串形如 $s_l \ldots s_r$，问它能否被化简成单独的 `C`。

## 输入

第一行是串 $s$。

第二行是整数 $Q$。

接下来 $Q$ 行，每行两个整数 $l, r$（$1 \le l \le r \le |s|$），表示一个子串。

## 输出

长度 $Q$ 的一行字符串，第 $i$ 个字符是 `Y` 表示第 $i$ 个子串可以化简成 `C`，否则是 `N`。

## 样例

输入：

```text
COW
6
1 1
1 2
1 3
2 2
2 3
3 3
```

输出：

```text
YNNNYN
```

解释：第一个子串已经是 `C`；第五个子串 `OW` 可以先变成 `CWW`，再删掉相邻的 `WW` 得到 `C`；其余子串都不行。

## 思路

记子串中 `C`、`O`、`W` 的个数分别为 $c, o, w$。**答案是 `Y` 当且仅当 $o + w$ 是偶数，且 $c + o$ 是奇数。**

先看两个量的奇偶性在操作下如何变化：

- 操作 1 删掉两个相同字母：三个计数中只有一个减 $2$，于是 $o+w$、$c+o$ 的奇偶性都不变；
- 操作 2 把一个字母换成另外两个字母，例如 `C -> OW` 使 $o + w$ 增加 $2$（奇偶性不变）、$c + o$ 不变；`O -> CW` 使 $o + w$ 不变、$c + o$ 不变；`W -> CO` 同理。因此 $o + w$ 与 $c + o$ 的奇偶性都是操作下的不变量。

目标串是单个 `C`，此时 $o + w = 0$（偶）、$c + o = 1$（奇），所以这两个条件是**必要的**：若 $o + w$ 为奇数，它永远不可能降到 $0$；若 $c + o$ 为偶数，也不可能变成单个 `C`（单 `C` 的 $c+o$ 为奇数）。

**充分性**：任意相邻两个字符总能合并成至多一个字符——两者相同时直接删掉；两者不同（设为 $x, y$）时，把 $x$ 换成「第三个字母 $z$ 和 $y$」，得到相邻的 $yy$ 后删掉，就只剩 $z$。不断合并，任何串都能缩短到长度至多 $1$。而在这个终点上不变量必须与初值相同：满足 $o + w$ 偶、$c + o$ 奇的状态只有单 `C`（单 `O`、单 `W` 的 $o+w$ 是奇数，空串的 $c+o$ 是偶数，都被排除）。所以条件满足时就一定可以化简成功。

于是用三个前缀和数组（或一个前缀计数数组）预处理，每个询问 $O(1)$ 求出 $c, o, w$ 并判断即可。
