# P3　极差重构（Range Reconstruction）

## 题目

Bessie 有一个长度为 $N$ 的数组 $a_1,\dots,a_N$（$1 \le N \le 300$，$0 \le a_i \le 10^9$）。她不肯直接告诉你 $a$，但会告诉你每个子区间的极差：对所有 $i \le j$，$r_{i,j} = \max a[i \dots j] - \min a[i \dots j]$。

给定所有 $r_{i,j}$，请构造一个可能是 Bessie 原始数组的数组。你输出的每个数必须在 $[-10^9, 10^9]$ 之间，并且对所有的 $i \le j$ 都满足 $r_{i,j} = \max b[i \dots j] - \min b[i \dots j]$。

题目保证一定存在满足条件的数组。

## 输入

第一行一个整数 $N$。

接下来 $N$ 行，第 $i$ 行包含 $N-i+1$ 个整数 $r_{i,i}, r_{i,i+1}, \dots, r_{i,N}$。

## 输出

一行 $N$ 个整数 $b_1,\dots,b_N$，表示你构造的数组。

答案不唯一，输出任意一个合法数组即可。

## 样例

输入：

```text
3
0 2 2
0 1
0
```

输出：

```text
1 3 2
```

（输出 `0 2 1`、`2 4 3` 等同样合法：对任意合法数组整体取负、整体平移都不会改变任何极差。）

## 思路

**第一步：相邻两项只差一个已知量。** $r_{i,i+1} = |a_i - a_{i+1}|$，所以

$$a_i \in \{\, a_{i+1} + r_{i,i+1},\ a_{i+1} - r_{i,i+1} \,\}.$$

**第二步：倒着确定，并整行校验。** 下标 $N$ 的元素没有限制（$r_{N,N}=0$），先令 $a_N = 0$。接着按 $i = N-1, N-2, \dots, 1$ 依次确定 $a_i$：此时 $a_{i+1},\dots,a_N$ 已经固定，所以第 $i$ 行的**全部** $r_{i,j}$（$j \ge i$）都已经可以计算，于是先试 $a_i = a_{i+1} + r_{i,i+1}$，若第 $i$ 行有任何一处极差不符，就改成 $a_i = a_{i+1} - r_{i,i+1}$。由归纳可知两者中必有一个可行，因此这样一定能恢复出原数组（最多相差一个整体取负与平移）。校验一行的代价是 $O(N)$，确定 $a_i$ 只需两次校验，总代价 $O(N^2)$。

**第三步：规范化输出。** 题目的答案本来就不唯一：若 $b$ 合法，则 $-b + c$（整体取负再整体平移任意常数 $c$）同样合法。程序最后把最小元素平移到 $0$，这样输出一定落在 $[0, 10^9]$ 内（原数据本来就在这个范围内），并且数值都是非负整数，便于检查。也正因如此，程序在样例上会输出 `0 2 1` 而不是题面给出的 `1 3 2`，两者都是合法答案。
