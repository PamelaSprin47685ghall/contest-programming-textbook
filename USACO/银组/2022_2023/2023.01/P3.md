# P3　哞路线（Moo Route）

## 题目

$t=0$ 时 Bessie 位于数轴原点 $x=0$，她每秒向左或向右移动 1 个单位，$T$ 秒后回到 $x=0$；她不会走到 $x>N$ 或 $x<0$。农夫 Nhoj 只知道她穿过 $x=0.5,1.5,\dots,(N-1).5$ 的次数，依次为 $A_0,A_1,\dots,A_{N-1}$（$1 \le N \le 10^5$，$1 \le A_i \le 10^6$，$\sum A_i \le 10^6$）。

路线可以写成长度为 $T=\sum_{i=0}^{N-1}A_i$ 的 `L`/`R` 串，第 $i$ 个字符表示第 $i$ 秒的方向。一次「转向」指的是出现一次 `LR` 或一次 `RL`。请输出任意一条与 $A$ 相符且转向次数最少的路线。题目保证至少存在一条合法路线。

## 输入

第一行一个整数 $N$。

第二行 $N$ 个整数 $A_0,A_1,\dots,A_{N-1}$。

## 输出

一行一个长度为 $T=\sum A_i$ 的字符串，只含 `L` 与 `R`。若有多条最优路线，输出任意一条。

## 样例

样例 1：

输入：

```text
2
2 4
```

输出：

```text
RRLRLL
```

（$A=[2,4]$ 只有这一条合法路线，对应 $0\to1\to2\to1\to2\to1\to0$。）

样例 2：

输入：

```text
3
2 4 4
```

输出：

```text
RRRLLRRLLL
```

（这个输入共有 3 条合法路线：`RRLRRLRLLL`、`RRRLRLLRLL`、`RRRLLRRLLL`；前两条有 5 次转向，只有最后一条是 3 次，所以答案唯一。）

## 思路

**下界。** 每向右穿过一次 $i.5$ 就必须再向左穿回来，所以 $A_i$ 全是偶数（题目保证有解）。令 $A_{-1}=A_N=0$。若 $A_i<A_{i+1}$，那么从 $i+1$ 向右到 $i+2$ 一共要走 $A_{i+1}/2$ 次，而每次这样的向右移动前面最多只有 $A_i/2$ 个字符是 `R`（因为从 $i$ 向右到 $i+1$ 只能发生 $A_i/2$ 次），所以至少有 $(A_{i+1}-A_i)/2$ 次是在位置 $i+1$ 处「先向左掉头、再向右」（即一个 `LR`）。同理 $A_i>A_{i+1}$ 时至少有 $(A_i-A_{i+1})/2$ 次 `RL`。把这些加起来，再减掉 $i=-1$ 处多算的那一次（路线的第一个字符前面没有字符，不可能形成 `LR`），得到转向次数的下界

$$\left(\sum_{i=-1}^{N-1}\frac{|A_i-A_{i+1}|}{2}\right)-1 .$$

**构造：把转向看成括号。** 位置 $0$ 放 $A_0/2$ 个左括号（对应 $A_{-1}\to A_0$ 这一段）；对 $i=0,\dots,N-2$，若 $A_i<A_{i+1}$ 就在位置 $i+1$ 放 $(A_{i+1}-A_i)/2$ 个左括号，若 $A_i>A_{i+1}$ 就在位置 $i+1$ 放 $(A_i-A_{i+1})/2$ 个右括号；位置 $N$ 放 $A_{N-1}/2$ 个右括号（对应 $A_{N-1}\to A_N=0$）。左括号表示「由向左改向右」，右括号表示「由向右改向左」。

左右括号总数相等，并且处理完 $A_i$ 之后「左括号数减右括号数」恰好等于 $A_i/2>0$，也就是说这个括号序列的每个前缀都是左括号更多，因此总能按位置从大到小配对。

**从右往左扫描。** 取最靠右的一对括号：先向右走到右括号所在位置，再向左走到配对的左括号位置（于是每个位置的穿越次数自动增加 2）；然后换下一对位置更靠左的括号，位置只减不增。这样每个 $A_i$ 恰好被穿越 $A_i$ 次，转向次数等于括号总数 $=$ 上面的下界，因此是最优解。

**实现。** 左右括号的位置数组本身按位置升序存放（生成顺序就是升序），于是从两个数组的末尾往前逐对处理即可：先 `R` 到右括号位置，再 `L` 到左括号位置。总长度不超过 $10^6$，用 `char` 数组存路线，最后一次性输出。
