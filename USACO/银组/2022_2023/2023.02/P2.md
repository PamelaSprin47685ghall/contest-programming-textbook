# P2　不在场证明（Cow-libi）

## 题目

有人一直在农夫约翰的 $G$ 个（$1 \le G \le 10^5$）私人花园里偷吃！凭借专家级的现场勘查本事，约翰确定了每次偷吃的准确时间，还断定所有这些案件都是同一头奶牛干的。

为此，约翰的 $N$ 头（$1 \le N \le 10^5$）奶牛各自提交了一份不在场证明，说明自己在某个具体时刻位于某个具体地点。请帮约翰判断，哪些不在场证明能证明提交者无罪。

如果一头奶牛不可能在走遍全部偷吃地点的同时又出现在它自己声称的地点，就可以断定它无罪。奶牛以每单位时间 1 单位距离的速度行走。

## 输入

第一行两个整数 $G$ 和 $N$。

接下来 $G$ 行，每行三个整数 $x, y, t$（$-10^9 \le x, y \le 10^9$，$0 \le t \le 10^9$），描述一次偷吃发生的精确地点与时刻。数据保证同一头奶牛能够走遍所有偷吃地点。

接下来 $N$ 行，每行三个整数 $x, y, t$（范围同上），描述一份不在场证明。

## 输出

输出一个整数：不在场证明能够证明自己无罪的奶牛数量。

## 样例

输入：

```text

2 4
0 0 100
50 0 200
0 50 50
1000 1000 0
50 0 200
10 0 170

```

输出：

```text

2

```

数据中有两次偷吃：第一次在时刻 $100$、地点 $(0, 0)$；第二次在时刻 $200$、地点 $(50, 0)$。

第一头奶牛（$(0, 50)$，时刻 $50$）的不在场证明不能证明它无罪——它刚好有足够的时间赶到第一次偷吃。第二头奶牛（$(1000, 1000)$，时刻 $0$）的无罪证明成立，因为它离所有偷吃地点都太远了。第三头奶牛（$(50, 0)$，时刻 $200$）就倒霉了：出现在作案现场并不能证明无罪。第四头奶牛（$(10, 0)$，时刻 $170$）无罪，因为它不可能在第二次偷吃的时刻赶到那里。

## 思路

**一步能不能走。** 从 $(x_1, y_1)$ 时刻 $t_1$ 出发，想在时刻 $t_2$ 到达 $(x_2, y_2)$，最短路线是直线，长度 $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$，因此可行的充要条件是

$$(t_2 - t_1)^2 \ge (x_2 - x_1)^2 + (y_2 - y_1)^2 .$$

两边都是整数且平方后最大约 $8 \times 10^{18}$，用 `long long` 直接比较，不必开根号（也就避开了浮点误差）。

**只需检查时间上最近的前后两次偷吃。** 设这头奶牛不在场证明的时刻为 $t$。对时刻更早的偷吃，只需检查时刻最大的那一次：设某次较早偷吃在时刻 $t_2$，而时刻最大的那次在 $t_3$（$t_2 \le t_3 \le t$）。数据保证一头牛能走遍所有偷吃，说明任意两次偷吃之间都满足上式（奶牛的位置随时间 1-Lipschitz 变化）。于是若它能从不在场证明赶到 $t_3$ 那次，就有

$$\text{dist}(\text{证明}, g_2) \le \text{dist}(\text{证明}, g_3) + \text{dist}(g_3, g_2) \le (t - t_3) + (t_3 - t_2) = t - t_2,$$

更早的每一次偷吃也都自动能赶到。时刻更晚的偷吃同理：检查时刻最小的那一次就够，它能赶到则更晚的也都能赶到。

**实现。** 把所有偷吃按时间升序排序，用一次二分求出"第一个时间严格大于 $t$ 的下标" `after`：

- 如果 `after - 1` 处的时间恰好等于 $t$，说明有一次偷吃与不在场证明同时发生。同时刻只能身处一个地点，而数据保证同一头牛能走遍所有偷吃（因此同时刻的偷吃必然同地点），所以只要那次偷吃的地点与证明中的地点不同，这头奶牛立刻被判无罪。
- 时间不晚于 $t$ 的最近一次偷吃是 `same - 1`（没有同时刻偷吃时是 `after - 1`），检查它能否按时赶到；
- 时间晚于 $t$ 的最近一次偷吃是 `after`，同样检查。

有任何一次赶不到，就说明这份证明与"同一头牛完成所有偷吃"矛盾，计一次无罪。

## 复杂度

排序 $O(G \log G)$，每份不在场证明只做一次二分与两次常数判断，时间 $O(G \log G + N \log G)$，空间 $O(G + N)$。
