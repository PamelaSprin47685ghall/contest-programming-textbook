# P2　户外活动日（Field Day）

## 题目

农夫约翰的每个谷仓（共 $N$ 个，$2 \le N \le 10^5$）都派出了一支 $C$ 头奶牛的队伍（$1 \le C \le 18$）参加户外活动日，每头牛的品种是 Guernsey（G）或 Holstein（H）。

两支队伍的**差异**定义为：位置 $i$（$1 \le i \le C$）上两头牛品种不同的位置个数。对第 $1$ 到第 $N$ 支队伍，分别求出它与**其它**任意一支队伍的差异的最大值。

## 输入

第一行两个整数 $C$ 和 $N$。

接下来 $N$ 行，每行一个长度为 $C$ 的只含 G 和 H 的字符串，依次描述每一支队伍。

## 输出

对每支队伍输出一行，表示它与其它队伍的最大差异。

## 样例

输入：

```text
5 3
GHGGH
GHHHH
HGHHG
```

输出：

```text
5
3
5
```

第一支和第三支队伍在 5 个位置上全部不同；第二支和第三支队伍差异为 3。

## 思路

把每支队伍看成长度 $C$ 的二进制串：第 $i$ 位为 1 表示该位置是 Holstein。两支队伍的差异就是两个掩码的**汉明距离**，即按位异或后 1 的个数。

**关键转化。** 与掩码 $x$ 差异最大的队伍，就是把 $x$ 逐位取反得到 $\bar{x}$ 之后**距离最近**的队伍。因为 $(x \oplus y)$ 与 $(\bar{x} \oplus y)$ 逐位互补，两者 1 的个数之和恒为 $C$，也就是

$$\operatorname{popcount}(x \oplus y) = C - \operatorname{popcount}(\bar{x} \oplus y).$$

要让左边的差异最大，等价于让右边的 $\operatorname{popcount}(\bar{x} \oplus y)$ 最小。因此

$$\text{ans}_x = C - \min_{y \in \text{teams}} \operatorname{popcount}(\bar{x} \oplus y).$$

（若所有队都相同，最小值会在 $y = x$ 处取到，此时 $\operatorname{popcount}(\bar{x} \oplus x) = C$，得到答案 $0$，正好正确。）

**求最近距离。** 在 $2^C$ 个掩码构成的图上，$x$ 与 $x \oplus (1 \ll b)$ 连一条边，边权为 1。把所有队伍掩码作为源点做**多源 BFS**，得到的 $\text{dist}[x]$ 就是到最近队伍的距离。图上有 $2^C$ 个点、$2^C \cdot C$ 条边，$C \le 18$ 时总运算量约 $4.7 \times 10^6$，足够快。

对每支队伍输出 $C - \text{dist}[\bar{x}]$ 即可。
