# P3　打靶练习（Target Practice）

## 题目

Bessie 是一头机器牛。她站在一条数轴上，试图打掉 $T$（$1 \le T \le 10^5$）个位置互不相同的靶子。
Bessie 从位置 $0$ 出发，依次执行长度为 $C$（$1 \le C \le 10^5$）的命令串，每条命令是 L、F、R 之一：

- L：Bessie 向左移动一个单位。
- R：Bessie 向右移动一个单位。
- F：Bessie 开火。如果当前位置有靶子，它就被打掉，且不会被重复打掉。

如果允许你在 Bessie 出发前把命令串中至多一条命令改成别的命令，Bessie 最多能打掉多少个靶子？

## 输入

第一行包含两个整数 $T$ 和 $C$。

第二行包含 $T$ 个互不相同的整数，表示靶子的位置，落在 $[-C, C]$ 内。

第三行包含长度为 $C$ 的命令串，只由 F、L、R 组成。

## 输出

输出一行一个整数，表示至多改动一条命令后 Bessie 能打掉的靶子数量的最大值。

## 样例

输入：

```text
3 7
0 -1 1
LFFRFRR
```

输出：

```text
3
```

输入：

```text
1 5
0
FFFFF
```

输出：

```text
1
```

输入：

```text
5 6
1 2 3 4 5
FFRFRF
```

输出：

```text
3
```

第一组样例中，把最后一条 R 改成 F，Bessie 就能依次打掉 $-1, 0, 1$ 三个靶子。

## 思路

记 $p_t$ 为执行完前 $t$ 条命令后 Bessie 的位置。改动第 $i$ 条命令只影响时刻 $i$ 之后的位置，
而且只是把这一段整体平移 $\Delta \in \{-2, -1, 0, 1, 2\}$：L 改成 F、R 平移 $+1$；
L 改成 R、R 改成 L 分别平移 $+2$、$-2$；R 改成 F 与 F 改成 L 平移 $-1$；F 改成 R 平移 $+1$。
于是只要预先知道「每段后缀在平移 $d$ 后能打掉哪些靶」，就能 $O(1)$ 地算出每种改法。

- 先按原命令模拟一遍：用 `inPrefix` 标记被前缀（前 $i$ 条命令）打掉过的靶子，`prefixHits` 记录数量；
  同时记下每个靶子第一次被打掉的时刻，便于之后把 $i$ 往左退时把它移出前缀集合。
- 从右往左扫描第 $i$ 条命令，同时维护五份后缀信息 `inSuffix[d]`：把第 $i+1$ 条起的命令整体平移 $d-2$
  之后能打到的靶子里、前缀还没有打掉的那些，`suffixSize[d]` 记录它们的大小。
- 枚举第 $i$ 条命令改成什么：改完之后后缀只是整体平移，直接查 `suffixSize` 即可；
  如果改成 F，还要额外判断脚下 $p_i$ 是不是一个「前缀和后缀都没打掉」的靶子（最多只能多打一个）。
- 「前缀已经打掉、后缀也能打到」的靶子会被重复计数，所以先把它们放进缓冲区 `inBuffer`，
  等 $i$ 继续左移、该靶子被移出前缀集合时，再补进 `inSuffix`。
- 一条命令都不改的情况由 `best` 的初值（完整模拟的结果）覆盖。
