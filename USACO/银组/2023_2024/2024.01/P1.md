# P1　奶牛竞争力（Cowmpetency）

## 题目

农夫约翰要为新一届牛群首领面试 $N$（$2 \le N \le 10^5$）头奶牛。面试第 $i$ 头候选人时，
他给出一个 $1$ 到 $C$（$1 \le C \le 10^9$）之间的「竞争力」分数 $c_i$。

面试的奶牛太多，约翰记不清每头牛的分数：$c_i = 0$ 表示第 $i$ 头牛的分数已被遗忘。
但他还记得 $Q$（$1 \le Q < N$）条信息，每条给出两个数 $(a_j, h_j)$（$1 \le a_j < h_j \le N$），
意思是：第 $h_j$ 头奶牛是奶牛 $1 \dots a_j$ 中第一头分数严格更高的奶牛。
同一组数据内所有 $a_j$ 互不相同。

请找出与这些记忆相符的字典序最小的分数序列；若不存在，输出 $-1$。

输入文件含 $T$（$1 \le T \le 20$）组独立数据，保证所有数据的 $N$ 之和不超过 $3 \times 10^5$。

## 输入

第一行一个整数 $T$。

接下来每组数据：

- 第一行三个整数 $N$、$Q$、$C$；
- 第二行 $N$ 个整数 $c_1 \dots c_N$（$0 \le c_i \le C$，$0$ 表示约翰忘记了这头牛的分数）；
- 再接下来 $Q$ 行，每行两个整数 $a_j$、$h_j$。

## 输出

每组数据输出一行：字典序最小的合法分数序列（相邻分数用一个空格隔开）；
若不存在这样的序列，输出 $-1$。

## 样例

输入：

```text
1
7 3 5
1 0 2 3 0 4 0
1 2
3 4
4 5
```

输出：

```text
1 2 2 3 4 4 1
```

输出满足全部三条记忆：$c_2 = 2 > \max(c_1) = 1$；$c_4 = 3 > \max(c_1, c_2, c_3) = 2$；
$c_5 = 4 > \max(c_1, c_2, c_3, c_4) = 3$。也有别的合法序列（如 `1 2 2 3 5 4 1`），
但都没有这个字典序小。

## 思路

**把记忆翻译成一个函数。** 记 $B(k)$ 为「第一个分数严格大于前 $k$ 头中最大分数的奶牛编号」。
第 $j$ 条记忆无非就是 $B(a_j) = h_j$；展开成对分数的要求就是两条：

1. $\max(c_1 \dots c_{a_j}) = \max(c_1 \dots c_{h_j - 1})$；
2. $c_{h_j} > \max(c_1 \dots c_{a_j})$。

**第一步：把每条记忆向后铺满它管辖的区间。** 若 $B(i) = h$，那么对每个 $i \le j < h$ 都有 $B(j) = h$：
前 $j$ 头里还没轮到第 $h$ 头，前缀最大值与前 $i$ 头相同。所以记忆 $B(a_j) = h_j$
可以直接复制到整个区间 $[a_j, h_j)$。复制过程中若撞上另一个已记录且不同的 $B$ 值，
说明约翰的记忆自相矛盾，整组数据无解。

**第二步：从左往右贪心。** 约翰没给出的分数先全部填 $1$——这是字典序最小的起点。

走到位置 $i$（记 $h = B(i)$）时：

- 维护 $mx = \max(c_1 \dots c_i)$ 和 $mx' = \max(c_1 \dots c_{h-1})$，显然 $mx' \ge mx$。
- 若 $mx' > mx$，第 1 条不成立，必须把某个 $j \le i$ 的分数抬到 $mx'$。
  为了让序列字典序最小，$j$ 取尽量靠后、且约翰没给出过的位置；
  但若存在 $k \le j$ 且 $B(k) < h$，抬高 $c_j$ 会同时抬高那条记忆的前缀最大值，
  与已经定好的 $c_{B(k)}$ 打架，此时无解。
- 再保证第 2 条：$c_h$ 若没给出就设成 $mx + 1$（刚好大一档，最小可能值）；
  若它给出过且不大于 $mx$，无解。
- 处理完直接把 $i$ 跳到 $h$：$[i, h)$ 内每个位置的 $B$ 都等于 $h$，
  它们的信息已经蕴含在这一步里，不必逐个重复处理。

最后逐个数检查是否都不超过 $C$，超了就无解。

每加一条约束只会让序列字典序变大，而贪心每次都把改动推到最靠后的位置，
所以得到的正是字典序最小的序列。

## 复杂度

时间 $O(N)$：铺满记忆时每个位置最多被写入一次，贪心里的区间扫描与查找合计也是线性的。
空间 $O(N)$。所有数据的 $N$ 之和不超过 $3 \times 10^5$。
