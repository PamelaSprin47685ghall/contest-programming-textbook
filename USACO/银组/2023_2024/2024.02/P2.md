# P2　试管（Test Tubes）

## 题目

Bessie 有两根容量无限、各装 $N$（$1 \le N \le 10^5$）单位液体的试管，液体分两种颜色，互不相溶、分成一层一层。
第一根试管可以看作字符串 $f_1f_2\ldots f_N$，第二根看作 $s_1s_2\ldots s_N$，
下标 $i$ 表示从管底数第 $i$ 单位的颜色（颜色取值 $1$ 或 $2$，两种颜色都至少出现一次）。

Bessie 还有一个容量无限的第三个容器：烧杯。一次「倒液」（pour）是把某根试管或烧杯**顶部同一种颜色**的所有液体整体移到另一个容器里。

Bessie 想让两根试管各自只装一种颜色的液体，并且烧杯最终为空。
求最少的倒液次数 $M$，并按查询类型给出方案：

- $P = 1$：只要输出 $M$；
- $P = 2$：输出 $A$（$M \le A \le M+5$），再输出 $A$ 行方案；
- $P = 3$：输出 $M$，再输出恰好 $M$ 行方案。

每行方案两个整数，表示源容器和目标容器（$1$、$2$ 是两根试管，$3$ 是烧杯）；源容器必须非空，不能倒给自己。
至于哪种颜色最终在哪根试管，没有要求。

## 输入

第一行一个整数 $T$（$1 \le T \le 10$）。

每个测试点：

- 一行两个整数 $N$ 和 $P$；
- 一行长度为 $N$ 的字符串，表示第一根试管（$f_1$ 在管底）；
- 一行长度为 $N$ 的字符串，表示第二根试管（$s_1$ 在管底）。

## 输出

每个测试点先输出最少倒液次数 $M$（$P = 2$ 时可以输出 $M$ 到 $M+5$ 之间的数），
$P \ge 2$ 时再输出若干行倒液方案。

## 思路

**先算次数。** 把每根试管里相邻的同色单位压成一层：`1221` 变成 `121`，`2211` 变成 `21`。
一次倒液只可能让「两根试管的层数之和」减少 $1$（倒进同色的容器时并层）或不变（倒进颜色不同的容器时新起一层），
所以层数之和 $L$ 给出下界。

- 目标状态里每根试管只剩一层（或为空），最终层数之和是 $0$（烧杯为空），故次数至少是 $L - 2$。
- 若两根试管最底层颜色相同，那么这两层最终只能有一层留下，另一层必须整体搬走，于是还要多 $1$ 次。
  实现上不必特殊处理：在 $f$ 的最底部补一层相反颜色再压缩，这次额外搬运就记在账上了——
  它永远待在管底、不会被倒出去，只会占掉「第一根试管要留下的那一层」的位置。
- 压缩后层数之和还大于 $2$ 时，必须先有液体进入烧杯，所以再用 $+1$ 次借道烧杯。

于是答案是：压缩后层数之和 $- 2$，若上一步算出的值大于 $1$ 再加 $1$。

**再给方案。** 依次做下面五步（每一步都是一次倒液，除第一步借道烧杯外每步都让总层数减少 $1$，因此步数恰好等于上面的答案）：

1. 若两根试管顶部同色，把较长的整根倒进另一根（并层，层数减少 $1$）。
2. 若还有长度大于 $1$ 的试管，把它倒进烧杯。此时两根试管的顶部一定同色。
3. 选出「底层颜色与烧杯底层颜色不同」的那根，反复倒它：顶部颜色等于烧杯底层颜色就倒进烧杯，
   否则倒进另一根试管。两种倒法都会让它的顶部那一层并掉，所以它最终只剩底层一层。
4. 另一根做同样的处理，也只剩底层一层。
5. 此时烧杯里全是一种颜色，把它倒回第 4 步留下的那根试管，收尾。

第 3、4 步挑「底层颜色与烧杯底层不同」的那根，是为了让保留下来的底层与烧杯里倒回来的颜色不同，
两根试管最终各装一种颜色。
