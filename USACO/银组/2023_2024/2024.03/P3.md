# P3　「制胜」基因（The 'Winning' Gene）

## 题目

农夫约翰怀疑 Bessie 的基因组里写死了「必胜」，于是想找出这个「制胜」基因。

他有一个长度为 $N$ 的字符串 $S$（$1 \le N \le 3000$，只含大写字母）。他先选定一对
$(K, L)$（$1 \le L \le K \le N$）：候选基因长度为 $L$，都藏在某个长度为 $K$ 的子串里。
接着他取出 $S$ 的所有 $K$ 长子串（称为 $k$-mer），对每个 $k$-mer 找出其中字典序最小的
$L$ 长子串（并列时取最靠左的那个），把该子串在原串 $S$ 中的起始位置 $p_i$（0 起）
记入集合 $P$。

约翰还没想好 $K$ 和 $L$，所以他想知道：对每个 $v = 1 \dots N$，有多少对 $(K,L)$ 使得
$|P| = v$。

## 输入

第一行一个整数 $N$。

第二行一个长度为 $N$ 的字符串 $S$，只含大写字母。

## 输出

输出 $N$ 行，第 $v$ 行表示满足 $|P| = v$ 的 $(K,L)$ 对数。

## 样例

输入：

```text
8
AGTCAACG
```

输出：

```text
11
10
5
4
2
2
1
1
```

例如 $(K,L) = (4,2)$ 时，五个 $4$-mer 各自的最小 $2$ 长子串分别从位置 $0,1,3,3,4$
开始，去重后 $P = \{0,3,4\}$，$|P| = 3$；恰好有 $5$ 对 $(K,L)$ 满足 $|P| = 3$。

## 思路

**反向计数。** 与其枚举 $(K,L)$ 对每个窗口求最小值，不如固定位置 $p$ 与长度 $L$，
问「哪些 $K$ 能让 $p$ 进入 $P$」。

固定 $p, L$（要求 $p + L \le N$）后，能让 $p$ 胜出的窗口 $[s, s+K)$ 必须满足：

- 窗口要装得下 $S[p:p+L]$，即 $p + L - K \le s \le p$；
- 设 $a$ 为左侧最后一个满足 $S[a:a+L] \le S[p:p+L]$ 的位置（并列也算输，因为并列时
  取更靠左的），则窗口不能捎上它，需要 $s \ge a + 1$；
- 设 $b$ 为右侧第一个满足 $S[b:b+L] < S[p:p+L]$ 的位置，则窗口的比较范围
  $[s, s+K-L]$ 不能延伸到 $b$，需要 $s + K - L < b$。

这些条件同时成立当且仅当 $K \le \min(b + L, N+1) - (a+1) - 1$，而所有不超过这个
上界的 $K \ge L$ 都恰好对应一个可行窗口，于是 $p$ 的贡献是「从 $L$ 到 $\text{maxK}$
的一段连续 $K$」。用差分数组在 $L$ 这一行记下 $\text{maxK}$ 的出现次数，最后对每个
$L$ 做后缀和就得到每个 $K$ 下 $|P|$ 的分布，累加进答案。

**两个关键技术。** 其一，比较子串不能真的截取字符串：预处理
$\text{lcp}[i][j]$ 表示后缀 $i$ 与后缀 $j$ 的最长公共前缀，利用
$\text{lcp}[i][j] = (S_i = S_j) + \text{lcp}[i+1][j+1]$ 从后往前 $O(N^2)$ 递推，
之后任何两个等长子串都能 $O(1)$ 比较。其二，$a$ 随 $L$ 单调左移、$b$ 随 $L$ 单调
右移，所以每个 $p$ 只需用两个指针各扫一遍，就把所有 $L$ 的 $a, b$ 求出来了。
