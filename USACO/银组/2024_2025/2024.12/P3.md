# P3　二维传送带（2D Conveyor Belt）

## 题目

农夫约翰的牛奶工厂可以描述为一个 $N \times N$（$1 \le N \le 1000$）的传送带网格，位置 $(a, b)$ 表示从上往下第 $a$ 行、从左往右第 $b$ 列的格子。格子有五种可能：`L`/`R`/`U`/`D` 分别表示向左/右/上/下移动物品，`?` 表示该格还没有建传送带。物品每个时间单位沿所在格子的传送带移动一格，也可能被送出网格。

如果放在格子 $c$ 上的物品永远无法离开网格（即在网格中无限打转），就称 $c$ 是**不可用**的。

起初所有格子都是 `?`。接下来的 $Q$ 天（$1 \le Q \le 2 \cdot 10^5$），每天农夫约翰会挑一个还没有传送带的格子建一条传送带（保证该格此前为空）。每天结束后，请计算：如果把他尚未修建的 `?` 全部建成传送带（方向可以任意选择），最少能有多少个不可用格子。

## 输入

第一行两个整数 $N$ 和 $Q$。
接下来 $Q$ 行，第 $i$ 行包含 $r_i$、$c_i$ 和一个字符 $t_i \in \{\text{L,R,U,D}\}$，表示第 $i$ 天在 $(r_i, c_i)$ 建一条方向为 $t_i$ 的传送带。

## 输出

输出 $Q$ 行，第 $i$ 行表示第 $i$ 天结束时能达到的最小不可用格子数。

## 样例

输入：

```text
3 5
1 1 R
3 3 L
3 2 D
1 2 L
2 1 U
```

输出：

```text
0
0
0
2
3
```

## 思路

反过来定义"**好格子**"＝物品放上去一定能离开网格的格子，那么最少不可用格子数就是 $N^2$ 减去最多能有的好格子数。好格子由下面两条规则刻画：

- 已经建好的传送带：它指向网格外，或者指向一个好格子；
- `?` 格子：方向可以任选，只要四个方向中有一个指向网格外或指向好格子。

每个 `?` 的方向互不影响，可以独立选择，所以按这两条规则扩散出的格子集合是能同时实现的；从所有"恰好指向界外"的格子出发做一次可达性扩散（DFS/BFS），标记出的格子数 $good$ 就是好格子的最大值，答案即 $N^2 - good$。

直接对每天重算一遍是 $O(QN^2)$，需要优化。做法是**离线倒着处理**：先把 $Q$ 天要建的传送带全部建好，得到第 $Q$ 天结束时的网格并扩散一次；然后从第 $Q$ 天倒着往回撤销，每撤销一天就把当天建的格子变回 `?`。

- 撤销只会把某格的"固定方向"变成"任意方向"，所以好格子集合单调不减（原本指向它的格子仍然好，它自己还有更多选择）。
- 一个格子变回 `?` 后可能自己变成好格子，也可能让它周围指向它的格子变好；这些新变好的格子必然通过指向关系与这次改动连成一片，因此只要从这个刚变回 `?` 的格子出发再扩散一次就够了。

每个格子最多被标记一次，于是总复杂度为 $O(N^2 + Q)$。记录答案时要注意：撤销第 $i$ 天之前先把"第 $i$ 天结束"对应的答案存进数组，最后按原顺序输出。实现上用数组模拟栈代替递归，避免深达 $N^2$ 的递归爆栈。
