# P1　奶牛体检（Cow Checkups）

## 题目

农夫约翰的 $N$ 头奶牛（$1 \le N \le 5 \cdot 10^5$）排成一列，第 $i$ 头牛的品种为 $a_i$（$1 \le a_i \le N$）。兽医只肯检查第 $i$ 个位置上品种为 $b_i$ 的奶牛（$1 \le b_i \le N$）。

约翰不想把队伍完全重排，他只会做恰好一次操作：选择两个整数 $1 \le l \le r \le N$，把第 $l$ 头到第 $r$ 头奶牛的顺序整体反转。

对所有 $N(N+1)/2$ 种操作，求"被检查的奶牛数量"的总和。

## 输入

第一行一个整数 $N$。
第二行包含 $N$ 个整数 $a_1, \dots, a_N$。
第三行包含 $N$ 个整数 $b_1, \dots, b_N$。

## 输出

输出一行一个整数，表示所有操作中被检查的奶牛数量之和。

## 样例

输入：

```text
3
1 3 2
3 2 1
```

输出：

```text
3
```

## 思路

一个位置被检查，等价于"存在某个位置 $i$ 与某个位置 $j$ 满足 $a_i = b_j$，并且这次操作把 $i$ 处的牛送到了 $j$"。于是可以**逐对**统计：对每个满足 $a_i = b_j$ 的位置对 $(i, j)$，算出有多少种操作会把 $i$ 送到 $j$，再把所有位置对的结果加起来。

固定一对 $(i, j)$（下标从 $0$ 开始），不妨设 $i < j$：

- 反转 $[l, r]$ 会把位置 $i$ 的牛送到 $l + r - i$，因此要送到 $j$ 就必须有 $l + r = i + j$（区间关于 $(i+j)/2$ 对称）且区间同时覆盖 $i$、$j$。此时 $r$ 可以取遍 $j, j+1, \dots, \min(N-1, i+j)$，共 $\min(i, N-1-j) + 1$ 种：$+1$ 对应区间 $[i, j]$ 本身，其余对应向两侧同步扩展的区间。对 $i > j$，把两个数组整体反转就化归成同一情形。
- 特别地，当 $i = j$ 时，让第 $i$ 个位置不动的操作分三类：完全落在 $i$ 左侧的共 $\binom{i+1}{2}$ 种，完全落在 $i$ 右侧的共 $\binom{N-i}{2}$ 种，以 $i$ 为中心左右对称（含 $[i,i]$）的共 $\min(i, N-1-i)+1$ 种，三者相加就是这一对的贡献。

这样朴素地对所有位置对求和仍是 $O(N^2)$，需要优化。注意一对 $i<j$ 的贡献是 $\min(i, N-1-j) + 1 = \min(i+1, N-j)$：

- 把所有满足 $a_i = b_j$、$i < j$ 的对按数值分组统计。对每个数值 $v$，把 $a$ 中出现 $v$ 的下标看作"查询"，把 $b$ 中出现 $v$ 的下标看作"候选"，从右往左扫描：遇到候选就把 $N-j$ 压入单调栈并按"小贡献"（贡献 $N-j$）记账；遇到下标 $i$ 的查询时，把栈中所有 $> i+1$ 的 $N-j$ 弹出，它们改为贡献 $i+1$。栈内数值单调递增，每个数只入栈出栈一次，于是每个数值的总代价与它出现的次数成正比，整体 $O(N)$。
- $i > j$ 的对只要把 $a, b$ 两个数组整体反转后套用同样的统计即可（反转后下标关系变成递增）。
- $i = j$ 的对数量最多 $O(N)$，直接按公式累加。

三部分相加即为答案，注意答案量级可达 $N^3$ 级别，需要用 `long long`。
