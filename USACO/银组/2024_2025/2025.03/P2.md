# P2　兼容配对（Compatible Pairs）

## 题目

农场里共有 $N$（$1 \le N \le 2 \cdot 10^5$）个不同的 ID 号，第 $i$ 个 ID 为 $d_i$（$0 \le d_i \le 10^9$），有 $n_i$（$1 \le n_i \le 10^9$）头牛使用这个 ID。

两头**不同**的牛可以通信，当且仅当它们的 ID 之和等于 $A$ 或 $B$（$0 \le A \le B \le 2 \cdot 10^9$）。每头牛同一时刻只能参与一次通信。求最多能同时进行多少对通信。

## 输入

第一行三个整数 $N, A, B$。

接下来 $N$ 行，每行两个整数 $n_i$ 和 $d_i$，保证所有 $d_i$ 互不相同。

## 输出

输出一个整数，表示最多能同时进行的通信对数。

## 样例

输入：

```text
4 4 5
17 2
100 0
10 1
200 4
```

输出：

```text
118
```

## 思路

把每个出现过的 ID 看成一个点，若两个 ID 之和等于 $A$ 或 $B$ 就在它们之间连一条边（$2 \cdot id = A$ 或 $B$ 时是一条自环）—— 只有由边相连的两头牛才能配对。因为每个点最多有一条"和为 $A$"的边和一条"和为 $B$"的边，所以每个点的度数都不超过 $2$，整张图是若干条路径（含自环）的并。

**贪心摘叶子。** 设点 $x$ 只连一条边到 $y$，那么在这条边上配尽可能多的对（$\min(cnt_x, cnt_y)$ 对，自环时是 $\lfloor cnt_x / 2 \rfloor$ 对）不会使答案变差：每多配一对最多只是让 $y$ 少配一对，收益不减。配完后这条边已经用尽，可以连同点 $x$ 一起删掉，只需把 $y$ 重新放回待处理队列。反复执行"取出一个点，若它度数为 $1$ 就榨干它的唯一边并删除"，直到队列为空。

**为什么最后所有边都会被删掉。** 若图上还有边，就必存在度数为 $1$ 的点：$A \ne B$ 时每条边有"$A$ 边"或"$B$ 边"的类型，从任意度数为 $2$ 的点出发交替走 $A$ 边、$B$ 边，每次移动都会把 ID 增大 $B - A$，点有限，所以这个走法必然终止在一个度数为 $1$ 的点上（$A = B$ 时所有点度数都不超过 $1$，结论显然）。因此"边数不为零 $\Rightarrow$ 存在度数为 $1$ 的点"，贪心一定能处理完所有边。

处理方式：把所有点先压入手写栈；每弹出一个点，若它度数正好为 $1$，就按上面的规则配对这一整条边、删掉这条边，并把另一端点重新入栈（度数为 $0$ 或 $2$ 的点直接跳过）。总配对数可能达到 $10^{14}$ 量级，需要用 `long long`。
