# P2　牛奶桶（Milk Buckets）

## 题目

有 $N$（$1 \le N \le 2 \cdot 10^5$）个牛奶桶摞在一起，从上往下第 $i$ 个的容量是 $a_i$（$1 \le a_i \le 10^9$）加仑。最上面的桶上方有一个水龙头，每秒向第一个桶注入 $1$ 加仑牛奶；最下面的桶下方有一个池子。

一个桶装满后，会在下一整秒里翻转、把里面的牛奶倒进它下面的桶（最下面的桶则倒进池子），这一整秒它不能收集牛奶（此时从上面落下的牛奶会损失掉），倒给他的牛奶若超过下一个桶的容量，多出的部分也会损失掉。

要处理 $Q$（$1 \le Q \le 3 \cdot 10^5$）个询问，每个询问给出 $i, v, t$：先把 $a_i$ 改成 $v$（$1 \le v \le 10^9$，改动保留到后面），再假设第 $0$ 秒时所有桶和池子都是空的，回答 $t$ 秒后池子里有多少加仑牛奶（$1 \le t \le 10^{18}$）。

## 输入

第一行一个整数 $N$。

第二行 $N$ 个整数 $a_1, \dots, a_N$。

第三行一个整数 $Q$，接下来 $Q$ 行每行三个整数 $i, v, t$。

## 输出

每个询问输出一行，表示 $t$ 秒后池子里的牛奶量。

## 思路

**每个桶的翻转是周期的。** 设 $b_i$ 是第 $i$ 个桶相邻两次倒空的间隔。最上面的桶装满要 $a_1$ 秒、翻转要 $1$ 秒，所以 $b_1 = a_1 + 1$。桶 $i-1$ 每次倒空时正好是满的，给桶 $i$ 送去 $a_{i-1}$ 加仑，因此桶 $i$ 装满需要 $\lceil a_i / a_{i-1} \rceil$ 次桶 $i-1$ 的倒空，于是

$$b_i = \left\lceil \frac{a_i}{a_{i-1}} \right\rceil b_{i-1}.$$

牛奶一层层往下传，第 $i$ 个桶第 $k$ 次倒空发生在 $(i-1) + k \cdot b_i$ 秒，池子只接收最下面那个桶倒出的 $a_N$ 加仑，所以

$$\text{答案} = a_N \cdot \left\lfloor \frac{\max(t-(N-1), 0)}{b_N} \right\rfloor.$$

**计算时不要真的乘出 $b_N$。** $a_i$ 可达 $10^9$，连乘会远远超过 $10^{18}$。可以改用除法逐层推进：先算 $\lfloor x / b_1 \rfloor$，再依次除以每个 $\lceil a_i / a_{i-1} \rceil$，因为对正整数有 $\lfloor \lfloor x/p \rfloor / q \rfloor = \lfloor x/(pq) \rfloor$，逐一取整不会改变结果，也不会溢出。

**每个询问只除很少几次。** $a_i \le a_{i-1}$ 时因子 $\lceil a_i/a_{i-1} \rceil = 1$，除不除一样。用 `set` 只存 $a_i > a_{i-1}$ 的下标，这些位置的因子至少是 $2$；修改 $a_i$ 只影响下标 $i$ 与 $i+1$ 两处是否"上升"，就地增删即可。由于 $x \le 10^{18} < 2^{60}$，每个因子 $\ge 2$，每询问至多除 $60$ 次商就变成 $0$，一旦为 $0$ 可以立即退出循环。

## 复杂度

预处理 $O(N \log N)$，每个询问 $O(\log N)$ 次 `set` 更新加至多 $60$ 次除法，$O(60 \log N)$。总时间 $O((N + Q)\log N)$，空间 $O(N)$。
